## 二、两个值得记的观察

### 2.1 `scenes → unityshaders` 的依赖关系正好证明了"共享规则"在工作

`Summary` 里 **`EnableSharePackRule = True`**、`SingleReferencedPackAlone = True`。
实测表现：`assets__project_scenes.bundle` **依赖 1 个包**（就是 `unityshaders.bundle`），
而 `unityshaders.bundle` **被引用 1 次**、自身依赖 0。

→ **场景包引用内置 shader 包，而没有把 shader 复制进自己** —— 这就是"公共依赖单独成包"（`YOO-02`③）在真实数据上的样子。

### 2.2 ⚠️ 这一版**还带着** `_design` 包（下次打包会消失）

`assets__project_configs_design.bundle`（2.1 KB）收集的是
`Assets/_Project/Configs/Design/` 里的策划 CSV。
**该目录已在 2026-09-22 挪到仓库根 `Configs/Design/`**（方案 A，见 `Docs\18` §9.4），
所以**下一次 ForceRebuild 后这个包应当消失**，总大小应降到 **≈124.2 KB / 3 个包**。

## 三、重复资源检查的**判据**（写清楚，否则等于没查）

⚠️ **第一版我查错了**：我猜字段叫 `BundleSize` / `AssetInfos.BundleName`，打印全是空/0，
于是得出"✅ 无重复"——**那是个空结论**（本项目的老毛病：检查没在工作却报通过）。

`.report` 的**真实字段名**（实测）：

| 数组 | 字段 |
| --- | --- |
| `Summary` | `YooVersion` `UnityVersion` `BuildDate` `BuildSeconds` `BuildPipeline` `BuildPackageVersion` `CompressOption` `DisableWriteTypeTree` `FileNameStyle` `EnableSharePackRule` `AllBundleTotalCount` `AllBundleTotalSize` `AssetFileTotalCount` … |
| `BundleInfos[]` | `BundleName` `FileName` `FileHash` `FileCrc` **`FileSize`** `Encrypted` `Tags[]` `DependBundles[]` `ReferenceBundles[]` `BundleContents[]` |
| `AssetInfos[]` | `Address` `AssetPath` `AssetGuid` `AssetTags[]` **`MainBundleName`** `MainBundleSize` `DependAssets[]` `DependBundles[]` |

**判据**（`YOO-02` 的验收）：遍历每个包的 `BundleContents`，
若某个资源出现在包 **B** 的内容里、但它的 `MainBundleName` **不是 B** → **可疑（同一份数据被放进了多个包）**。

实测 **可疑项 = 0** ✅。

## 四、采集脚本（**可重跑**，数字由它算）

```powershell
# ① 找最新一次构建报告
$p = Get-ChildItem "Client\Bundles" -Recurse -Filter *.report |
     Sort-Object LastWriteTime | Select-Object -Last 1
$j = [System.IO.File]::ReadAllText($p.FullName, [System.Text.Encoding]::UTF8) | ConvertFrom-Json

# ② 头部指标
$j.Summary | Select-Object BuildPackageVersion, UnityVersion, YooVersion, BuildSeconds,
    BuildPipeline, CompressOption, DisableWriteTypeTree, FileNameStyle,
    AllBundleTotalCount, AllBundleTotalSize, AssetFileTotalCount

# ③ 逐包大小（升序看谁最大）
$j.BundleInfos | Sort-Object FileSize -Descending |
    Select-Object BundleName, @{n='KB';e={[math]::Round($_.FileSize/1KB,1)}}

# ④ 重复资源检查（判据见 §三）
$mainOf = @{}; foreach ($a in $j.AssetInfos) { $mainOf[$a.AssetPath] = $a.MainBundleName }
$suspect = 0
foreach ($b in $j.BundleInfos) { foreach ($c in $b.BundleContents) {
    if ($mainOf[$c] -and $mainOf[$c] -ne $b.BundleName) {
        "⚠️ $c 在 $($b.BundleName) 里，但归属 $($mainOf[$c])"; $suspect++ } } }
"可疑项 = $suspect"
```
