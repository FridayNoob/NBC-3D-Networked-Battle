# 问题排查手册（索引 + 方法论）

> 用途：**遇到问题时不靠猜**。每篇都是"现象 → 先确认是哪一类 → 定位步骤 → 根因 → 解决 → 防复发"。
> 定位日期：2026-09-23 建立（负责人要求：**重点提升 Unity 底层 / C# 底层 / GC / 内存** 这几类的定位能力）

## 一、怎么用这个文件夹

| 场景 | 怎么做 |
| --- | --- |
| **正卡在一个问题上** | 先看下面第二节的"分层排查图"，判断**它属于哪一层**，再打开对应那篇 |
| **想练排查能力** | 拿一篇的"④ 定位步骤"去对当前工程实操一遍（**不要只读**：排查是手上功夫） |
| **面试前** | 每篇最后的"⑦ 一句话讲清"可以直接背；面试官爱问的就是"你怎么定位的" |
| **发现新问题** | 按同一结构补一篇（见第四节模板），**并把"防复发"落成代码或检查**，别只写文档 |

## 二、分层排查图（**先定位层，再谈原因**）

一个"游戏不对"的现象，几乎总能先被归到下面某一层。**层的判据写在这里，是为了避免"从第一层跳到第五层瞎试"**：

| 层 | 典型现象 | **第一个判据**（先跑这个，别猜） |
| --- | --- | --- |
| **① 资产 / 导入** | 面板找不到控件、字体是方框、材质丢失、配置是旧的 | Console 有没有导入报错？**资产的修改时间**是否早于源文件？（本项目有"资产过期检查"菜单） |
| **② 编译 / 程序集边界** | `CS0246` / `CS0012` / 类型"明明在"却找不到 | **读编译器原文**：`CS0012` 会点名缺哪个程序集；`CS0246` 不会（要自己推断）→ 看 `01-Unity编译与程序集边界.md` |
| **③ 托管运行时（C#）** | 空引用、集合被改、闭包抓错变量、GC 卡顿 | 断点/日志确认**哪一个对象是 null**；`.NET` 层的问题**能在 EditMode/探针里复现**（本项目的老手法） |
| **④ 引擎运行时（Unity）** | 生命周期顺序、`Awake` 没调、物理/导航不对 | **EditMode 下 Unity 不调用 `Awake`**（本项目实测过）；先确认"这个方法到底有没有被调" |
| **⑤ 原生 / IL2CPP / 打包** | 编辑器里好好的、打包后崩；`ECall` 异常；反射被裁剪 | 看是不是**只在 IL2CPP/Mono 某个后端**出现 → 见 `01` 与 `Docs\09-IL2CPP验证清单.md` |
| **⑥ 网络 / 时序** | 偶尔丢一条、偶尔卡住、两端数据不一致 | 是"每次都错"还是"偶尔错"？**偶尔错优先怀疑分帧/时序**，不是逻辑（见 `Docs\教学\M3-A-网络层.md`） |

> 📌 **一条硬规矩**：**先拿到"能证明是哪一层"的那个数字/报错，再去改代码。**
> 没有证据就改代码 = 把问题从一个地方挪到另一个地方。

## 三、通用排查手法（本项目反复用过、有效的）

| 手法 | 怎么用 | 为什么有效 |
| --- | --- | --- |
| **读报错原文，别读印象** | `CS0012` 会**点名**要加哪个程序集；`MSB3027` 会**点名**哪个进程锁了文件 | 报错里的名字是"唯一确定的线索"，猜则要试很多次 |
| **最小可复现** | 新建 20 行的对照工程/一条最小用例 | 把"环境问题"和"代码问题"分开（本项目用它把 `dotnet build` 静默失败摘干净过） |
| **阳性 + 阴性对照** | 故意做对一次、故意做错一次 | 证明"检查真的在工作"，而不是恰好通过 |
| **让数字说话** | GC 分配、耗时、帧数、内存都读**真实 API**，不写"大概" | "读不到 ≠ 是 0"；平均值会掩盖卡顿（见 `03`） |
| **注入时间/设备** | 时间、输入、网络都做成可注入的接缝 | 让"偶尔"变成"必然"，问题就能在 EditMode 里复现 |
| **二分法** | 一半代码注释掉/一半资产不加载，看现象还在不在 | 定位"是哪一半引起的"最快的手段，尤其对"打包后才崩" |
| **回读确认** | 改完**回读**文件/回读 `git status` | 本项目栽过：`Set-Content` 把中文写坏、`git add` 白名单漏文件 —— 都是"以为改了" |

## 四、每篇的标准结构（照这个写，别自由发挥）

1. **现象**（一句话，最好带原始报错全文）
2. **先确认是哪一层**（用第二节的判据）
3. **定位步骤**（可照着做的一步步；每步要能得出"是/不是"）
4. **根因**（为什么会长这样）
5. **解决方案**（改什么；如果有多种，写清取舍）
6. **防复发**（落成机械检查 / 菜单 / 预检 / 测试，而不是"下次注意"）
7. **一句话讲清**（面试版）
