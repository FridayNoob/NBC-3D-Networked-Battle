# 05 · 怎么测 M3 联机（Edit 模式 vs Play 模式）

> 现象归类：**不是 bug，是"怎么把问题复现出来"的前提**
> 建立日期：2026-09-23（负责人问："我是在 Play 模式下测试还是 Editor 模式？"）

---

## 一、结论先说

| 我要测什么 | 用哪种模式 | 为什么 |
| --- | --- | --- |
| **M3 联机**（连接 / 房间 / 世界 / 输入 / 掉落） | ✅ **Editor 模式（不按 Play）** | 调试窗口 `NetDebugWindow` 是**编辑器工具**：它挂 `EditorApplication.update` **自己每帧推动会话**（`session.Pump(deltaMs)`），不需要游戏在跑 |
| M2 单机 demo（任务面板 / HUD / 战斗） | Play 模式 | 那条线是 `M2DemoBehaviour`（MonoBehaviour），只在 Play/打包里跑 |
| ⏳ 联机 + 看得见 3D 表现 | Play 模式（**等表现层做完**） | 现在**没有任何 GameObject**：怪只存在于窗口的「世界」列表里（见 §四） |

---

## 二、为什么"进 Play 会把连接弄断"（实测依据，不是猜）

| 依据 | 实测值 |
| --- | --- |
| 窗口靠什么驱动 | `EditorApplication.update += Tick`（`NetDebugWindow.OnEnable`）→ 编辑器空闲时也跑 |
| 进 Play 会发生什么 | `Client\ProjectSettings\EditorSettings.asset` 里 **`m_EnterPlayModeOptionsEnabled: 0`** ⇒ **域重载（Domain Reload）是开着的** |
| 后果 | 域重载会重建所有程序集与静态状态 ⇒ **窗口状态/会话引用全丢，连接随之断开**（窗口文件头"已知局限"里写着这条） |

⇒ 所以：**测试时不要按 Play**。真要进 Play，就得先断开、进 Play 后重新连（或者等表现层做完，把会话交给游戏流程管）。

---

## 三、"两个客户端"怎么造（三种方式，按方便程度）

| 方式 | 怎么做 | 代价 / 前提 |
| --- | --- | --- |
| **① ParrelSync 两个编辑器** | 原工程 + `Client_clone_0` 各开一次，**两边都开调试窗口、都连同一个服务端** | 最方便；两次 `Library` 各占一份磁盘 |
| **② 一个编辑器窗口 + 一个探针客户端** | 起服务端 → Editor 里连接/进房 → 另开一个终端跑 `NetProbe --session=7777` | 不用第二个 Unity；但第二个"客户端"是命令行，看不到界面 |
| **③ 一个 Editor + 一个打包版** | ⚠️ **现在做不到**：`NetSession` 目前**只被编辑器窗口使用**（实测 grep 过），而编辑器窗口**不进包** | 需要先把会话接进 `M2DemoBehaviour`（游戏流程）——这是**表现层切片**里该一起做的（也是 `Docs\25` D8 原方案的缺口） |

## 四、⚠️ 编辑器里的读数哪些不可信（免得把"编辑器特性"当成 bug）

| 读数 | 为什么会偏 | 怎么办 |
| --- | --- | --- |
| **RTT** | `EditorApplication.update` 的间隔不稳（编辑器忙/失焦时会变慢） | 看趋势不看绝对值；要准数字就打包成 Development Build 再看 |
| **心跳/超时** | 同上；我为此把单帧 `deltaMs` **夹到 250ms**（`NetDebugWindow.MaxDeltaMs`），宁可时钟走慢，也不许跳 | 这是**故意**的：不夹的话编辑器卡一下就会判"心跳超时"（假掉线） |
| **帧率 / GC** | 编辑器自身开销 + `Debug.Log` 抓堆栈 | 性能数字一律在 Development Build 上取（见 `03-GC与内存`） |
| **"连不上"** | 服务端没起 / 端口不对 | 看窗口状态是不是 `Failed` 且原因是"对端没有在监听（连接被拒绝）" |

---

## 五、一分钟讲清（面试版）

> 我们客户端联机的入口是**编辑器工具窗口**（挂 `EditorApplication.update` 自己推会话），
> 所以**在 Edit 模式下就能测联机**，不必进 Play；进 Play 反而会因为**域重载**把连接丢掉。
> 两个客户端我用 **ParrelSync 开第二个编辑器**，开发期也会用**命令行探针**当第二端；
> 打包版目前还没接联机入口（会话只被编辑器窗口用），那属于表现层要补的一步。
> 另外编辑器里的 RTT 只能看趋势 —— `EditorApplication.update` 节奏不稳，我为此把单帧时间夹到 250ms，
> 免得编辑器一卡就判"心跳超时"。
