### 1.1 每块一句话

| 方块 | 一句话职责 | 为什么单独存在 |
| --- | --- | --- |
| **`NBC.Framework`** | 框架底座：单例 / 池 / 事件 / 宿主 / 场景 / 输入 / 音频 / UI / 日志 / 性能 / 状态机 | `references: []` —— **它不认识任何东西**，包括 YooAsset 和业务 |
| **`NBC.Framework.UI`** | UI 框架（`UIManager` / `BasePanel` / 四层 / 加载遮罩） | 它要依赖 `UnityEngine.UI`（**包**程序集），而框架的引用必须为空（A9 决策 7） |
| **`NBC.Framework.YooAsset`** | 用 YooAsset 实现 `IAssetProvider` | **唯一**接触第三方的程序集（B2 / ADR-001） |
| **`NBC.Shared`** | 双端共享：定点数学（D2）+ 共享类型（D1） | `noEngineReferences: true` → **跨端位级一致的前提** |
| **`NBC.Boot`** | **组合根**：`AssetBootstrapper.InstallAsync(mode)` | M1 末才补上 —— 少了它接缝**永远空着**（报"还没有装上底层加载器"） |
| **`NBC.Game`** | 业务：`ConfigMgr` + 生成的行类型/SO 类型 | 有一条机械检查：**业务层零 `YooAsset` 字样**（YOO-09） |
| **`NBC.Editor`** | 编辑器工具：配置表导入器、资源运行模式冒烟 | Editor-only，不进包 |
| **`Tools\ConfigKit`** | 配置表工具链（Excel/CSV → C# + TSV + JSON） | **独立于 Unity 依赖图** → 所以能被 49 条零依赖自测覆盖 |

## 三、8 条方法论母题（**M1 最值钱的东西**）

这些教训**跨模块反复出现**，比任何单个 API 都值钱：

| # | 母题 | 具体例子 |
| --- | --- | --- |
| 1 | **静默失败最危险**（出错但不报错） | A3 字符串 key 拼错不触发 · A5 `float` 当等待指令 · A8 兜底字符串 · A9 `Find` 返回 null · E1 `N/A` 被写成 `0` · C2 空格子被当成 0 · **C4 我的探针把 `Asset = null` 报成 ✅** |
| 2 | **把不可控环境变成可注入参数** | A5 `Tick(dt)` · A7 假 `IInputSource` · A8 探针 · E1 `IPerfCounterSource` · C2 `ITableSource` · C4 `IConfigSource` · **B2 `IAssetProvider`** |
| 3 | **"没报错"可能是"实验没跑"** | A1 对照实验基线全 0 · A2 asmdef 实验 inconclusive（时间戳证明没编译） · C2 `dotnet restore` 实测 `NU1301` |
| 4 | **验证器本身必须先被验证**（W9） | A2 阳性对照 · A8 产物字符串表 · A10 检查命中注释 · **"机械检查命中注释"在 M1 栽了 6 次** · C4 我猜错字段名却报"✅ 无重复" |
| 5 | **断言里的数字必须算出来** | D2 相对误差界 · **E1 三次栽在阈值** → 最终**把"阈值"这个形式从断言里去掉**（改用独立模型 + 比值） |
| 6 | **写可以手写，验必须用真工具** | C2 手写 JSON → **用 `System.Text.Json` 反向解析它**；能用编译器就别用 grep |
| 7 | **输出/报告类方法不该改数据** | C2 `ExportReport.Render` **就地排序**诊断集合 → 调用方一边遍历一边渲染就抛 `Collection was modified` |
| 8 | **"删除/替换"类改动必须回读确认** | C4 我那条"清理编辑"**报了成功、代码却还在**，多出来的那段照常能跑，只以"另一条测试红了"的面目出现 |

### 3.1 第 4 条单独展开：**"机械检查命中注释" 6 次**

| 次 | 场景 | 修法 |
| --- | --- | --- |
| 1 | ASCII 搜 DLL 找字符串 → 字面量在 `#US` 堆里是 UTF-16 | 改看 `#Strings` 堆 / 换判据 |
| 2 | grep 命中**注释里的**字样 | 剥注释 |
| 3 | FSM-09 的机械检查命中 7 处**全是注释** | 排除注释后重查 |
| 4 | `Math\.` 正则误报**转换边界与字符串字面量** | 收紧正则 |
| 5 | 配置表**架构守卫**命中 csproj 注释里的 `ConfigKit.Sources.*` | **先剥 XML 注释再匹配**（且落在守卫侧，不是改注释） |
| 6 | 断言"生成物里不该有 `JsonUtility`"，被**生成的注释**（写着"不用 JsonUtility"）骗过 | 判据改成**调用点形式** `JsonUtility.FromJson` |

📌 **结论（可直接背）**：
**用裸词/正则做检查，注释迟早会骗过它。**
正确做法三句：**能剥注释就剥、能用调用点形式就别用裸词、能用编译器就别用 grep。**

## 六、面试怎么讲 M1（5 段，每段 ~30 秒）

**① 框架底座**
> "M1 我把唐老师那套框架底座重写了一遍，核心是**把静默失败改成显式失败**：单例不许 `new` 第二个（运行时断言 + 明确报错）、事件 key 从字符串换成编译期结构体、对象池给统计数字而不是把容器敞开。有一条取舍值得说：我**主动放弃**了'编译期禁止 new 单例'，因为那需要 `private` 构造 + 反射，而本项目在 IL2CPP 上已经实测过反射的代价。"

**② 资源层**
> "资源层是**依赖倒置**：框架侧只定义 `IAssetProvider` 接缝，**一个 YooAsset 类型都不认识**；适配层是唯一接触第三方的地方。回报是**可测性** —— 21 条框架侧测试用一个假加载器就能跑，不需要 YooAsset 在场。M1 末尾还补了一个**组合根**程序集：接缝、实现、装配是三件事，少了装配那一层，接缝就永远空着，而且报错形态是运行时的。"

**③ 配置表工具链**
> "Excel → SO 我做成了一条**独立工具链**（.NET 控制台 + Unity 薄导入器），核心是四个**可替换接缝**：从哪读、表头约定、**项目策略**、输出去向。判据很清楚：**如果一条规则别的项目可能不想要，它就必须是策略字段，而不是代码里的 `if`**。校验分三趟（逐格/逐列/跨表），报错**定位到文件+表+行+列**——这是需求里点名的验收，我逐字断言过。"

**④ 确定性**
> "为了帧同步，共享层不许有浮点：我用 Q32.32 定点数 + CORDIC 三角/反三角，并写了一个**数值对拍探针**（.NET 控制台）拿 `double` 当参照——它抓出 3 个真 bug，全是'正数上对、负数上错'。最有价值的不是 bug，而是**探针的覆盖盲区**：`ToInt` 那个 bug 是手写测试抓到的，探针没覆盖到。"

**⑤ 可观测性**
> "性能看板和日志。看板有个我很喜欢的矛盾：**观测工具不能自己制造被观测的问题** —— 它要显示 GC 分配，所以自己就不能每帧拼字符串；于是拆成'采样每帧、文字限频 4 Hz'，分配从 240 次/秒降到 16 次。另外一条原则：**读不到就填 `NaN` 显示 `N/A`，绝不填 0** —— 因为'DrawCall = 0'是一个**看起来正常的假数字**。"
