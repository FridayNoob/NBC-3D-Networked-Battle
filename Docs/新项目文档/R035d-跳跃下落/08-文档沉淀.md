## 2. 模块文档

### 2.1 PlayerVerticalMotion（纯 C#）

- 简介：只算「竖直方向」，不碰 Transform、不读 Time；给状态机提供 `Grounded / VerticalSpeed / JustLanded`。
- 接口：`Jump(float heightMeters)`、`Step(float deltaSeconds)`、`ResetToGround()`；属性 `VerticalSpeed`、`Height`、`Grounded`、`JustLanded`。
- 示例：

```csharp
var motion = new PlayerVerticalMotion();
motion.Jump(1.2f);                 // 起跳速度 = sqrt(2 * 9.8 * 1.2) ≈ 4.85 米/秒
motion.Step(1f / 60f);             // 由调用方给 dt，单测里可以给任意值
```

- 原理：`v -= g·dt`，`h += v·dt`；`h <= 0.0005 && v <= 0` 判落地。用 `System.Math` 不用 `Mathf`，因为要能在纯 .NET 测试里跑。
- 坑：`Jump` 只在 `Grounded` 时生效，空中调用直接忽略（防二段跳）。
- 维护：改重力/跳高只动这里，别在 `PlayerJumpMotor` 里再写一份。

### 2.2 PlayerJumpMotor（MonoBehaviour 胶水）

- 简介：把「物理高度」写进 `transform.position.y`，探地、贴地、空中漂移都在这里。
- 接口：`Bind(PlayerStateMachine)`、`TryJump()`、`Step(float)`、`SetJumpDrift(Vector3, float)`。
- 示例：`PlayerBrain` 每帧先 `TryJump()`（Space 按下）再 `Step(Time.deltaTime)`。
- 原理：`ProbeGround` 用 `Physics.RaycastNonAlloc` 向下打，**跳过自己与子物体**（剑的 `BoxCollider`）；`position.y = m_groundY + motion.Height`；`LateUpdate` 里按脚骨把厘米级偏差按回地面。
- 坑：探地不排自己 ⇒ 剑摆到正下方时把角色抬起来（R035b 已踩过同一个坑，这里显式 `IsChildOf` 跳过）。
- 维护：换角色模型要重设 `m_jumpHeight` 与鞋底偏移（现在自动校准）。

### 2.3 控制器 Jump / Fall / Land

- `S_Jump`：`Mixamo_Jump`，speed 1，进入 offset 0.30（脚离地那刻）。
- `S_Fall`：`Mixamo_Falling`，loop，speed 1，offset 0。
- `S_Land`：`Mixamo_FallingToLanding`，speed 1.6，offset 0.33（触地前一瞬），配合 `Landing` 参数播 0.2 秒。
- 三条 AnyState 条件都带 `!ActionBusy && !Dead`，回移动层两条带 `Grounded If && Landing IfNot`。
- 坑：`AnyState` 的数组顺序改不动（setter 无效），要优先级就用「互斥条件」而不是「靠顺序」。

### 2.4 Mixamo 资产管线

- 导入：`Animation Type = Human` + `Avatar Definition = CreateFromThisModel`（**不要** CopyFromOther）。
- clip：`loopTime` 起跳 false / 滞空 true / 落地 false；`Root Transform Position (Y)` **不烘**（`lockRootHeightY=false`、`keepOriginalPositionY=true`），Y 交给物理。
- offset 推导：在 clip 里找「脚离地」和「触地」两个时刻，除以 clip 总长。`Jump` 的 0.30 × 1.667 ≈ 0.50 秒，`FallingToLanding` 的 0.33 × 1.067 ≈ 0.35 秒。
- 坑：`SaveAndReimport` 会按 take 名重置 clip 名与 Loop，必须在同一个批次里写回 `name` 与 `loopTime`。

### 2.5 定向跳方向

- 走路与跳跃共用 `PlayerMove.GetMoveDirection(x, z)`：相机轴压平 → 前/右主导轴 → 世界轴兜底。
- `PlayerBrain.ApplyJumpDirection` 必须用 `m_motion`（`Awake` 解析的那个），不能用 Inspector 的 `m_move`（场景里可能是空引用）。
- 起跳锁定方向、空中不能改向；无方向输入时显式 `SetJumpDrift(Vector3.zero, 0f)`。

## 3. 踩坑清单

1. **`Bake Into Pose` 烘 Y**：clip 根 Y 会带着整个身体下沉，和物理高度叠加后就是「半身入地」。
2. **CopyFromOther 得 0 clip**：Humanoid Avatar 复制要求骨骼名一致，Mixamo 的 `mixamorig:*` 对不上剑士骨骼。
3. **importer 重设会改 clip 名/Loop**：`defaultClipAnimations` 是按 take 重建的，改完必须回写。
4. **空引用不报错、只退化**：`m_move` 为 null 时走 `Vector3.forward`，表现为「所有方向都跳 +Z」。
5. **两处兜底口径不一致**：一个用相机轴、一个用世界轴，走路与跳跃就会分叉。
6. **贴地修正要有上限与死区**：上限太小会跳过真实偏差，太大又会被天花板/台阶带飞。
7. **判断「新代码有没有生效」看反射**：`typeof(X).GetMethod("新方法")` 比 `isCompiling` 可靠。
