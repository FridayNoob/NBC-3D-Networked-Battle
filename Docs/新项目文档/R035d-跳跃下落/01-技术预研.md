# R035d 跳跃下落 —— 01 技术预研

需求编号：R035d
所属阶段：M4
作者：AI 辅助
状态：草稿

## 1. 调研目标与约束

- 目标：World 里按 `Space` 起跳，角色真的离地、滞空、下落、落地，动画跟着切 `Jump` / `Fall`，落地回移动层。
- 约束一：复用 R035a 的分层状态机——`EPlayerState.Jump=8` / `Fall=9` 与 `Grounded` / `VerticalSpeed` 参数早已定义，但**至今没有任何代码写过它们**（默认 `Grounded=true`、`VerticalSpeed=0`）。
- 约束二：零新增 Trigger，控制器仍只用 bool/float 参数。
- 约束三：只改客户端 World；Battle 的服务器权威位移不动（跳跃是单机表现，不参与联机同步）。
- 约束四：只改控制器副本 `_Project/Animator/Player_Sword_Controller.controller`，不碰美术包。
- 约束五：垂直运动逻辑不直接读 `Time`，由 Brain 每 tick 注入 `deltaSeconds`，保证 EditMode 可测。

## 2. 核心 API 清单

| API | 用途 | 注意 |

| `Transform.position` | 唯一位移手段（角色没有 `CharacterController`，也没有 Rigidbody） | 全身只有剑上的 `BoxCollider`，不能靠物理推 |

## 4. 最小可运行示例

```csharp
// 每帧：先算垂直速度与位移，再判落地
m_verticalSpeed -= gravity * deltaSeconds;
transform.position += Vector3.up * (m_verticalSpeed * deltaSeconds);
if (m_verticalSpeed <= 0f && TryFindGround(out RaycastHit ground)) { /* 落地：贴到 ground.point.y，Grounded=true */ }
```

要点：起跳只给一次初速度（`v = sqrt(2 * g * height)`），之后全交给重力，动画只读 `VerticalSpeed` 的正负。

## 5. 方案对比

| 方案 | 做法 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- | --- |
| A 物理驱动 + 短动画 | 起跳播 `JUMP01` 前段（约 0.35 秒），滞空切 `S_Fall`（`JUMP00` 中段定格/循环），落地回移动层 | 手感可控、滞空时长与跳高一致 | 需要手动挑 clip 的起跳帧 | **推荐** |
| B 整段 clip 驱动 | 直接播完整 `JUMP01`（2.03 秒），位移曲线跟着 clip 走 | 最省事 | 2 秒滞空像月球，且只能跳一种高度 | 不做 |
| C 纯代码无动画 | 只改 y，不切状态 | 改动最小 | 玩家看不出在跳，验收无法通过 | 不做 |

## 6. 已知坑与版本兼容

1. **`JUMP00` / `JUMP01` 是「完整跳跃动作」**：包含下蹲、起跳、空中、落地四段，直接整段播会和物理时间打架。
2. **贴地射线会把人按回地面**：`Client/Assets/_Project/Game/GameFlow/WorldPlayerSetup.cs` 的 `LateUpdate` 每帧把 `y` 设成命中点；离地时必须让它让位，否则跳不起来。
3. **根运动不生效**：`applyRootMotion=false` 是三处代码共同保证的，clip 里的位移曲线不会真的移动角色，垂直位移必须自己算。
4. **Humanoid 重定向的脚部偏移**：UnityChan 的跳跃 clip 重定向到剑士后，脚底可能不贴地，落地那一帧要按包围盒校正（`PlayerSkinnedMeshGuard` 已有类似做法）。
5. **`Grounded` 一直是 true**：控制器里现在没有任何过渡读它，加了 `S_Jump`/`S_Fall` 之后才真正生效，改完必须回读过渡表。

## 6.5 负责人决策（2026-11-14 弹窗）

| 问题 | 选择 | 落地方式 |
| --- | --- | --- |
| 跳多高、多久 | **0.9 米 / 约 0.86 秒**（重力 9.8） | `v = 根号(2 g h)`，只给一次初速度 |
| 空中能不能改方向 | **完全不能**（起跳锁定水平方向） | 离地期间 `MovementEnabled=false`、`Speed=0` |
| 用哪段动画 | **`JUMP01` 起跳 + `JUMP00` 滞空** | `S_Jump` 播 JUMP01（speed 2.5）、`S_Fall` 播 JUMP00（speed 2.5、offset 0.45） |
| 落地怎么收尾 | **缓冲 0.2 秒再回移动层** | 新增 `Land=10` 状态 + `Landing`(bool) 参数 + `LandFrames=12`，`S_Land` 播 JUMP00（offset 0.8） |

## 7. 结论

采用方案 A：`PlayerVerticalMotion` 负责重力与落地判定（纯 C#，注入 `deltaSeconds`），`PlayerJumpMotor` 负责地面探测与写 `transform.y`，`PlayerStateMachine` 按 `Grounded` / `VerticalSpeed` / `Landing` 选 `Jump` / `Fall` / `Land`，控制器新增三个状态与三条过渡，`WorldPlayerSetup` 见到电机就让位。
代码量预估约 480 行（含测试与文档内嵌代码），仍在 500 行预算内。
