## 2. 正常流程走查

打开 `Client/Assets/_Project/Scenes/World.unity`，进 Play，按下面顺序走：

1. 站定，按 `Space`：角色离地，Console 出现 `[PlayerJumpMotor] 起跳，目标高度 0.90 米`；看 Inspector 的 `Player_Hero` y 轴，约 0.43 秒到最高（+0.9 米）。
2. 空中按 `W/A/S/D`：水平位置不变（Scene 视图看 x/z 不动），Animator 停在 `S_Jump` 或 `S_Fall`。
3. 停顿看下落：约 0.86 秒后落地，Console 出现 `[PlayerJumpMotor] 落地，地面高度 …`，状态短暂进 `S_Land`。
4. 落地瞬间按住 `W`：0.2 秒内角色不动；0.2 秒后恢复跑动。
5. 连按两次 `Space`（落地后立刻再按）：第二次要能正常起跳，y 回到同一个地面高度。

判据：每一步的 Console 数字与动画状态对得上，且**角色没有一帧被弹到半空又落回**。

## 3. 异常场景

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 攻击中起跳 | 按 `J` 后立刻按 `Space` | 不起跳，攻击照常播完 |
| 死亡后起跳 | 按 `L` 后再按 `Space` | 不起跳，仍是 `S_Die` |
| 空中按动作键 | 起跳后按 `J`/`Q`/`E`/`R`/`F` | 不进入动作层，状态仍是 Jump/Fall |
| 空中再按 Space | 空中连按 `Space` | 不二段跳，高度不叠加 |
| 空中按住右键 | 起跳后按住右键 | 不切格挡，落地后格挡才生效 |

## 4. 性能

1. 连续跳 10 次：每次落地 y 与第一次一致（±1 厘米），Console 地面高度数字不变。
2. 静止站立 10 秒：Console 不刷日志、Animator 参数不抖动（发布器按 0.01 阈值幂等）。
