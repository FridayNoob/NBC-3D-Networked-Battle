# R035d 跳跃下落 —— 04 代码实现

## 1. 子任务与约束

| 子任务 | 产出 |
| --- | --- |
| 1 纯逻辑竖直运动 | `PlayerVerticalMotion.cs`（重力积分、落地判定） |
| 2 世界侧电机 | `PlayerJumpMotor.cs`（探地、写 y、起跳入口） |
| 3 状态机接竖直状态 | `PlayerStateMachine.cs`（Jump/Fall/Land、落地缓冲、空中禁移动） |
| 4 参数与上下文 | `PlayerAnimatorParams.cs` / `PlayerStateContext.cs` / `PlayerAnimatorPublisher.cs` |
| 5 接线 | `PlayerBrain.cs` / `WorldPlayerSetup.cs` |
| 6 控制器 | 副本加 `Landing`、`S_Jump`/`S_Fall`/`S_Land`、三条 AnyState |
| 7 测试 | `PlayerJumpLayerTests.cs` 9 条 |

约束：

1. 垂直运动逻辑不读 `Time`，由 `PlayerBrain` 注入 `deltaSeconds`。
2. 只有 `PlayerJumpMotor` 写 `transform.y`；`WorldPlayerSetup` 见到电机就让位。
3. 零新增 Trigger，控制器只用 bool/float。
4. 只改控制器副本，不碰美术包与 UnityChan 的 fbx。
5. 空中禁移动靠 `Grounded`，不能只靠 `BlocksMovement`（层判断不包含"是否离地"）。

## 2. 功能概述

按 `Space` 给一次向上的初速度（`v = 根号(2 * 9.8 * 0.9) ≈ 4.2 米/秒`），之后每帧减重力、加高度，写回 `transform.y`；状态机据 `Grounded` 与 `VerticalSpeed` 选 `Jump`（上升）/ `Fall`（下降），落地那帧进 `Land` 缓冲 12 帧（0.2 秒），期间不能移动、不能起跳，缓冲结束回移动层。

## 3. 接口与入参出参

| 接口 | 入参 | 返回 | 约定 |
| --- | --- | --- | --- |
| `PlayerVerticalMotion.Jump(float heightMeters)` | 目标高度（米） | `bool` 是否起跳 | 只允许从地面起跳；高度 ≤0 拒绝 |
| `PlayerVerticalMotion.Step(float deltaSeconds)` | 帧间隔（秒） | 无 | 先减速度再加高度；到地后 `JustLanded` 只 true 一帧 |
| `PlayerJumpMotor.TryJump()` | 无 | `bool` | 状态机拒绝时回滚落地状态 |
| `PlayerJumpMotor.Step(float deltaSeconds)` | 帧间隔（秒） | 无 | 探地 → 积分 → 写 y → 回报状态机 |
| `PlayerStateMachine.SetVertical(bool, float)` | 是否踩地、竖直速度 | 无 | 落地时竖直速度归零 |
| `PlayerStateMachine.NotifyJump()` | 无 | `bool` | 已死/动作中/有待执行动作/格挡/落地缓冲/离地 → false |
| `PlayerStateMachine.NotifyLand()` | 无 | `bool` | 死亡或已在缓冲 → false |

## 4. 逐段讲解

1. **为什么单独一个 `PlayerVerticalMotion`**：它只有数学，没有 `Transform` 也没有 `Time`，EditMode 能用固定步长精确断言"0.9 米、52 帧"。
2. **为什么 `JustLanded` 只 true 一帧**：落地通知必须一次性，否则状态机会每帧重置缓冲，`Land` 永远退不出去。
3. **探地为什么跳过自己**：R035b 的血泪教训——剑上的 `BoxCollider` 会被竖直射线打到，把角色抬到剑的高度；这里同样跳过 `transform` 与其子物体。
4. **为什么 `canMove` 要判 `Grounded`**：`BlocksMovement` 只看"当前下层是不是移动层"，`Jump` 本身属于移动层，所以必须再判一次是否离地；第一轮测试就是漏了这个。
5. **为什么 `NotifyJump` 要判 `m_hasPendingAction`**：`NotifyAttack` 先写 pending、下一帧 `Tick` 才置 `ActionBusy`，中间这一帧不判就会被跳起来。
6. **落地缓冲为什么放状态机而不是电机**：缓冲是"能不能动"的规则，属于状态机；电机只负责物理。
7. **`WorldPlayerSetup` 为什么直接 return**：电机已经把 `y` 写好了，再贴一次地会把起跳按回去。
8. **控制器为什么用三条 AnyState**：`Jump`/`Fall` 靠 `VerticalSpeed` 正负切换，`Land` 靠 `Landing` 布尔；回移动层的两条过渡补 `Grounded=true` 与 `Landing=false`，避免落地缓冲期间被拉回 `S_Locomotion`。

### 5.1 纯逻辑：PlayerVerticalMotion.cs

```csharp
// 这个文件里有：
//   PlayerVerticalMotion（纯逻辑类）：跳跃的竖直速度、离地高度与落地判定，不依赖 UnityEngine

using System;

namespace NBC.Game.Player
{
    // 主要功能：按重力积分算出「离地多高、竖直速度多少、什么时候落地」，供状态机与电机共用。
    // 主要数据成员：m_gravity（重力，米/秒²）、Height（离地高度，米）、VerticalSpeed（竖直速度，米/秒）、Grounded、JustLanded。
    // 主要外部方法：Jump 起跳、Step 推进一帧、ResetToGround 强制落地。
    // 谁在用它：PlayerJumpMotor 每帧推进；EditMode 测试直接 new 出来断言高度与滞空时间。
    // 注意：纯 C#，不引用 UnityEngine —— 数学用 System.Math，保证 EditMode 无场景也能跑。
    public sealed class PlayerVerticalMotion
    {
        // 默认重力，米/秒²（地球重力；跳 0.9 米约 0.86 秒滞空）
        public const float DefaultGravity = 9.8f;

        // 认为「已经贴地」的容差，米（浮点积分会留下极小的正高度，不清零会一直离地）
        private const float LandEpsilon = 0.0005f;

        // 重力加速度，米/秒²
        private readonly float m_gravity;

        // 竖直速度，米/秒（上升为正、下落为负）
        public float VerticalSpeed { get; private set; }

        // 离地高度，米（0 表示站在地面上）
        public float Height { get; private set; }

        // 是否踩在地面上
        public bool Grounded { get; private set; }

        // 本次 Step 是否刚落地（只有落地那一帧为 true）
        public bool JustLanded { get; private set; }

        // 功能：建一个竖直运动器。
        // 入参：gravityMetersPerSecondSquared 重力加速度，米/秒²，必须大于 0。
        // 返回：实例，初始状态是站在地面上。
        // 步骤：校验重力后保存；高度与速度都是 0。
        // 上游/下游：PlayerJumpMotor 构造；测试直接 new。
        public PlayerVerticalMotion(float gravityMetersPerSecondSquared = DefaultGravity)
        {
            if (gravityMetersPerSecondSquared <= 0f)
            {
                throw new ArgumentOutOfRangeException(
                    nameof(gravityMetersPerSecondSquared),
                    "[PlayerVerticalMotion] 重力必须大于 0。");
            }

            m_gravity = gravityMetersPerSecondSquared;
            Grounded = true;
        }

        // 功能：起跳，按目标高度反算初速度。
        // 入参：heightMeters 目标跳高，米，必须大于 0。
        // 返回：true 表示起跳成功；false 表示已经离地或高度非法（调用方不用报错）。
        // 步骤：1) 只允许从地面起跳 2) 用 v = 根号(2 g h) 反算初速度 3) 清零高度、置空中。
        // 上游/下游：PlayerJumpMotor.TryJump 调用。
        public bool Jump(float heightMeters)
        {
            if (!Grounded || heightMeters <= 0f)
            {
                return false;
            }

            VerticalSpeed = (float)Math.Sqrt(2d * m_gravity * heightMeters);
            Height = 0f;
            Grounded = false;
            JustLanded = false;
            return true;
        }

        // 功能：推进一帧的竖直运动。
        // 入参：deltaSeconds 帧时长，秒；小于等于 0 时只清标记、不做积分。
        // 返回：无。
        // 步骤：1) 先清刚落地标记 2) 站着就保持 0 3) 空中先减速度、再按新速度加高度 4) 高度归零那帧判落地。
        // 上游/下游：PlayerJumpMotor.Step 调用；下游 PlayerJumpMotor 把 Height 写到 transform。
        public void Step(float deltaSeconds)
        {
            JustLanded = false;
            if (deltaSeconds <= 0f)
            {
                return;
            }

            if (Grounded)
            {
                VerticalSpeed = 0f;
                Height = 0f;
                return;
            }

            VerticalSpeed -= m_gravity * deltaSeconds;
            Height += VerticalSpeed * deltaSeconds;

            if (Height <= LandEpsilon && VerticalSpeed <= 0f)
            {
                Height = 0f;
                VerticalSpeed = 0f;
                Grounded = true;
                JustLanded = true;
            }
        }

        // 功能：强制回到地面（传送、重生、脚下没地面时兜底）。
        // 入参：无。
        // 返回：无。
        // 步骤：高度与竖直速度清零、置落地、清刚落地标记。
        // 上游/下游：PlayerJumpMotor 在地面探测失败时调用。
        public void ResetToGround()
        {
            Height = 0f;
            VerticalSpeed = 0f;
            Grounded = true;
            JustLanded = false;
        }
    }
}

```

### 5.2 世界侧电机：PlayerJumpMotor.cs

```csharp
// 这个文件里有：
//   PlayerJumpMotor（MonoBehaviour）：把 PlayerVerticalMotion 算出的高度写到 transform，并负责地面探测与起跳入口

using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：驱动玩家的竖直位移 —— 起跳、重力下落、落地判定，并把结果告诉状态机（Grounded / VerticalSpeed / 落地事件）。
    // 主要数据成员：m_motion（纯逻辑积分器）、m_machine（状态机，可空）、m_groundY（最近一次探到的地面高度，米）。
    // 主要外部方法：TryJump 起跳、Step 每帧推进、Bind 绑定状态机、IsAirborne 是否离地。
    // 谁在用它：PlayerBrain（Awake 里补挂并 Bind，Update 里每帧 Step，Space 键调 TryJump）；WorldPlayerSetup 见到它就不再自己贴地。
    // 注意：地面探测跳过玩家自己的碰撞体 —— 手里的剑有 BoxCollider，姿势动作会把它摆到脚下，命中它会把角色顶起来。
    [DisallowMultipleComponent]
    public sealed class PlayerJumpMotor : MonoBehaviour
    {
        // 重力加速度，米/秒²
        [SerializeField] private float m_gravity = PlayerVerticalMotion.DefaultGravity;

        // 起跳高度，米（默认 0.9 米，约 0.86 秒滞空）
        [SerializeField] private float m_jumpHeight = 0.9f;

        // 地面探测的起点高度（相对脚底），米
        [SerializeField] private float m_probeHeight = 5f;

        // 地面探测的最大距离（从起点往下），米
        [SerializeField] private float m_probeDistance = 20f;

        // 哪些层算地面；默认全部层，靠「跳过自己」排除武器
        [SerializeField] private LayerMask m_groundMask = ~0;

        // 是否打印起跳/落地日志（验收时开，平时关）
        [SerializeField] private bool m_logDiagnostics = true;

        // 复用的射线命中缓冲，避免每帧分配（16 个够用：地面 + 少量装饰）
        private readonly RaycastHit[] m_hits = new RaycastHit[16];

        // 竖直运动积分器（纯逻辑）
        private PlayerVerticalMotion m_motion;

        // 状态机引用，可空（没 Bind 时只做位移，不回报状态）
        private PlayerStateMachine m_machine;

        // 最近一次探到的地面高度，米；没探到就一直沿用上一次
        private float m_groundY;

        // 是否已经拿到过地面高度
        private bool m_hasGround;

        // 是否在空中（离地且不是在落地缓冲）
        public bool IsAirborne
        {
            get { return m_motion != null && !m_motion.Grounded; }
        }

        // 功能：绑状态机，让电机能把 Grounded / VerticalSpeed / 落地事件写回去。
        // 入参：machine 玩家状态机，可为 null（测试或纯表现场景）。
        // 返回：无。
        // 步骤：保存引用并确保积分器已创建。
        // 上游/下游：PlayerBrain.Awake 调用；内部调 EnsureMotion。
        public void Bind(PlayerStateMachine machine)
        {
            m_machine = machine;
            EnsureMotion();
        }

        // 功能：请求起跳。
        // 入参：无。
        // 返回：true 表示真的跳了；false 表示在空中、已死、有动作在播或正在落地缓冲。
        // 步骤：1) 先让积分器算初速度 2) 状态机拒绝就回滚到地面 3) 都通过才算成功。
        // 上游/下游：PlayerBrain 的 Space 键调用；下游 PlayerVerticalMotion.Jump、PlayerStateMachine.NotifyJump。
        public bool TryJump()
        {
            EnsureMotion();
            if (!m_motion.Jump(m_jumpHeight))
            {
                return false;
            }

            if (m_machine != null && !m_machine.NotifyJump())
            {
                m_motion.ResetToGround();
                return false;
            }

            if (m_logDiagnostics)
            {
                Debug.Log("[PlayerJumpMotor] 起跳，目标高度 " + m_jumpHeight.ToString("0.00") + " 米");
            }

            return true;
        }

        // 功能：推进一帧的竖直运动并写到 transform。
        // 入参：deltaSeconds 帧时长，秒。
        // 返回：无。
        // 步骤：1) 先探地面（拿到脚下地面高度）2) 积分高度 3) 把 y 设成地面高度加离地高度 4) 回报状态机 5) 落地打日志。
        // 上游/下游：PlayerBrain.Update 每帧调用；下游 PlayerStateMachine.SetVertical / NotifyLand。
        public void Step(float deltaSeconds)
        {
            EnsureMotion();
            ProbeGround();
            m_motion.Step(deltaSeconds);

            Vector3 position = transform.position;
            position.y = m_groundY + m_motion.Height;
            transform.position = position;

            if (m_machine != null)
            {
                m_machine.SetVertical(m_motion.Grounded, m_motion.VerticalSpeed);
                if (m_motion.JustLanded)
                {
                    m_machine.NotifyLand();
                }
            }

            if (m_logDiagnostics && m_motion.JustLanded)
            {
                Debug.Log("[PlayerJumpMotor] 落地，地面高度 " + m_groundY.ToString("0.000") + " 米");
            }
        }

        // 功能：往上找「不是自己」的最近地面，记下它的高度。
        // 入参：无。
        // 返回：无；没命中时保留上一次的地面高度。
        // 步骤：1) 从脚底上方 m_probeHeight 处向下打一条射线 2) 跳过自己与子物体（手里的剑） 3) 取最近命中的点。
        // 上游/下游：Step 每帧调用；不依赖 WorldPlayerSetup 的贴地逻辑。
        private void ProbeGround()
        {
            Vector3 origin = transform.position + Vector3.up * m_probeHeight;
            int count = Physics.RaycastNonAlloc(
                origin,
                Vector3.down,
                m_hits,
                m_probeHeight + m_probeDistance,
                m_groundMask,
                QueryTriggerInteraction.Ignore);

            float nearest = float.MaxValue;
            bool found = false;
            for (int i = 0; i < count; i++)
            {
                RaycastHit hit = m_hits[i];
                Transform hitTransform = hit.transform;
                if (hitTransform == null)
                {
                    continue;
                }

                if (hitTransform == transform || hitTransform.IsChildOf(transform))
                {
                    continue;
                }

                if (hit.distance < nearest)
                {
                    nearest = hit.distance;
                    m_groundY = hit.point.y;
                    found = true;
                }
            }

            if (found)
            {
                m_hasGround = true;
                return;
            }

            if (!m_hasGround)
            {
                m_groundY = transform.position.y;
                m_hasGround = true;
            }
        }

        // 功能：确保积分器存在。
        // 入参：无。
        // 返回：无。
        // 步骤：为空就按 Inspector 的重力 new 一个。
        // 上游/下游：Awake / Bind / TryJump / Step 调用。
        private void EnsureMotion()
        {
            if (m_motion == null)
            {
                m_motion = new PlayerVerticalMotion(m_gravity);
            }
        }

        // 功能：初始化地面高度，避免第一帧把角色拽到 0。
        // 入参：无。
        // 返回：无。
        // 步骤：记下当前 y、标成已有地面，再建积分器。
        // 上游/下游：Unity 生命周期调用。
        private void Awake()
        {
            EnsureMotion();
            m_groundY = transform.position.y;
            m_hasGround = true;
        }
    }
}
```

### 5.3 状态机（完整文件）

```csharp
// 这个文件里有：
//   PlayerStateMachine（类）：玩家分层状态机 —— 纯逻辑，不读 Time / Input / Animator，测试可直接驱动

using System;
using NBC.Framework.Fsm;

namespace NBC.Game.Player
{
    // 主要功能：按「反应 > 动作 > 移动」的优先级决定当前该在哪个状态，并把结果翻译成移动闸门与动画参数。
    // 主要数据成员：m_context（共享状态）、m_timings（动作帧数）、m_speeds（五档速度）、m_fsm（三层状态机）。
    // 主要外部方法：Tick 推进一帧；NotifyAttack/NotifyHit/NotifyDead 接收外部事件；Parameters 读当前动画参数。
    // 谁在用它：PlayerBrain 每帧调 Tick 并发布 Parameters；EditMode 测试用假 IPlayerMotion 驱动它。
    // 注意：本类不引用 UnityEngine —— 取绝对值用 System.Math，状态名用枚举，保证能在 EditMode 无场景下跑。
    public sealed class PlayerStateMachine
    {
        // 共享状态（蹲/动作/死亡等），每帧读写
        private readonly PlayerStateContext m_context;

        // 各动作持续帧数，60fps 口径
        private readonly PlayerTimings m_timings;

        // 五档移动速度，米/秒
        private readonly PlayerSpeeds m_speeds;

        // 三层状态机：移动层 / 动作层 / 反应层
        private readonly HierarchicalStateMachine<EPlayerState> m_fsm;

        // 有没有「等着这一帧执行」的动作请求
        private bool m_hasPendingAction;

        // 待执行动作的状态
        private EPlayerState m_pendingState;

        // 待执行动作的编号（写进 ActionId）
        private float m_pendingActionId;

        // 待执行动作的总帧数
        private int m_pendingFrames;

        // 连击是否已排队：窗口内按过攻击键，等当前段播完再切下一段
        private bool m_comboQueued;

        // 是否正在按住格挡；格挡不占 ActionBusy，但会关掉移动闸门
        private bool m_blocking;

        // 当前姿势序号 0~6，按 F 轮换
        private int m_poseIndex;

        // 落地缓冲剩余帧数；大于 0 时不能移动，动画停在 S_Land
        private int m_landingFrames;

        // 功能：注册三层状态机并进入移动层的 Idle。
        // 入参：context 共享状态（不能为 null，且 Motion 不能为 null）；timings 动作帧数；speeds 五档速度。
        // 返回：无。
        // 步骤：1) 校验参数 2) 依次注册三层（先上层后下层，第一层下层自动成为入口）3) 启动到移动层。
        // 上游/下游：PlayerBrain.Awake 构造；内部调用 RegisterLocomotion/Action/Reaction。
        public PlayerStateMachine(PlayerStateContext context, PlayerTimings timings, PlayerSpeeds speeds)
        {
            if (context == null)
            {
                throw new ArgumentNullException(nameof(context), "[PlayerStateMachine] 缺少共享状态。");
            }

            if (context.Motion == null)
            {
                throw new ArgumentNullException(nameof(context), "[PlayerStateMachine] 共享状态里没有 IPlayerMotion。");
            }

            m_context = context;
            m_timings = timings;
            m_speeds = speeds;
            m_fsm = new HierarchicalStateMachine<EPlayerState>();

            m_fsm.RegisterUpper(EPlayerState.Locomotion, new PlayerLayeredState(EPlayerState.Locomotion), EPlayerState.Idle);
            RegisterLocomotionStates();
            m_fsm.RegisterUpper(EPlayerState.Action, new PlayerLayeredState(EPlayerState.Action), EPlayerState.Attack1);
            RegisterActionStates();
            m_fsm.RegisterUpper(EPlayerState.Reaction, new PlayerLayeredState(EPlayerState.Reaction), EPlayerState.HitLeft);
            RegisterReactionStates();
            m_fsm.Start(EPlayerState.Locomotion);

            m_context.Motion.MovementEnabled = true;
        }

        // 当前上层（Locomotion / Action / Reaction）
        public EPlayerLayer Layer
        {
            get { return PlayerStateCatalog.LayerOf(m_fsm.UpperCurrent); }
        }

        // 当前下层状态（真正的「在干什么」）
        public EPlayerState State
        {
            get { return m_fsm.LowerCurrent; }
        }

        // 当前状态路径，形如 "Locomotion/Run"；给日志与调试面板看
        public string CurrentPath
        {
            get { return m_fsm.CurrentPath; }
        }

        // 是否已死亡（死亡后 Tick 只维持参数、不再切换状态）
        public bool IsDead
        {
            get { return m_context.Dead; }
        }

        // 这一帧要写给 Animator 的参数快照
        public PlayerAnimatorParams Parameters
        {
            get { return m_context.BuildParams(); }
        }

        // 当前姿势序号 0~6；按 F 依次轮换
        public int PoseIndex
        {
            get { return m_poseIndex; }
        }

        // 是否正按住格挡
        public bool Blocking
        {
            get { return m_blocking; }
        }

        // 是否在空中（离地）
        public bool Airborne
        {
            get { return !m_context.Grounded; }
        }

        // 是否正在落地缓冲
        public bool Landing
        {
            get { return m_context.Landing; }
        }

        // 功能：把电机算好的竖直状态写进上下文，供这一帧选 Jump / Fall。
        // 入参：grounded 是否踩地；verticalSpeed 竖直速度，米/秒（上升为正）。
        // 返回：无。
        // 步骤：直接写入两个字段；落地时顺手清掉竖直速度，避免残留值影响下一跳。
        // 上游/下游：PlayerJumpMotor.Step 每帧调用；内部用于 ChooseLocomotion 与参数发布。
        public void SetVertical(bool grounded, float verticalSpeed)
        {
            m_context.Grounded = grounded;
            m_context.VerticalSpeed = grounded ? 0f : verticalSpeed;
        }

        // 功能：请求起跳（不管物理，只标状态）；真正的初速度由 PlayerJumpMotor 施加。
        // 入参：无。
        // 返回：true 表示可以起跳；false 表示已死、有动作在播、正在格挡、正在落地缓冲、或已经离地。
        // 步骤：1) 五类前置拒绝 2) 取消落地缓冲 3) 置空中并把竖直速度设为向上，让本帧就选 Jump。
        // 上游/下游：PlayerBrain 的 Space 键 → PlayerJumpMotor.TryJump → 本方法。
        public bool NotifyJump()
        {
            if (m_context.Dead || m_context.ActionBusy || m_hasPendingAction || m_blocking || m_context.Landing || !m_context.Grounded)
            {
                return false;
            }

            m_landingFrames = 0;
            m_context.Landing = false;
            m_context.Grounded = false;
            m_context.VerticalSpeed = 1f;
            return true;
        }

        // 功能：通知落地，开始约 0.2 秒的缓冲（期间不能移动）。
        // 入参：无。
        // 返回：true 表示这次真的落地了；false 表示本来就在落地缓冲里或已经死了。
        // 步骤：1) 死亡与重复落地拒绝 2) 置落地与缓冲帧数 3) 清竖直速度。
        // 上游/下游：PlayerJumpMotor 检测到 JustLanded 时调用；Tick 每帧递减缓冲帧数。
        public bool NotifyLand()
        {
            if (m_context.Dead || m_landingFrames > 0)
            {
                return false;
            }

            m_context.Grounded = true;
            m_context.VerticalSpeed = 0f;
            m_landingFrames = m_timings.LandFrames;
            m_context.Landing = m_landingFrames > 0;
            return true;
        }

        // 状态真的发生切换后触发；参数是切换记录（含帧号与前后状态名）
        public event Action<StateChangeRecord> StateChanged
        {
            add { m_fsm.StateChanged += value; }
            remove { m_fsm.StateChanged -= value; }
        }

        // 功能：推进一帧 —— 先看有没有动作要播，再决定移动状态，最后同步移动闸门与速度。
        // 入参：frame 逻辑帧号（必须单调递增，60fps 口径）；input 这一帧的输入快照。
        // 返回：无。
        // 步骤：1) 死亡时只维持零速 2) 处理蹲切换 3) 推进/消费动作 4) 动作中不选移动态 5) 同步 MovementEnabled 与速度 6) 推状态机帧。
        // 上游/下游：PlayerBrain.Update 每个固定步长调用一次；内部调用 ChooseLocomotion/ApplyLocomotion。
        public void Tick(int frame, in PlayerInput input)
        {
            if (m_context.Dead)
            {
                m_context.Speed = 0f;
                m_context.Direction = 0f;
                m_context.ResetAction();
                m_context.Motion.MovementEnabled = false;
                m_context.Motion.SetMoveSpeed(0f);
                m_fsm.Tick(frame);
                return;
            }

            if (m_landingFrames > 0)
            {
                m_landingFrames--;
            }
            m_context.Landing = m_landingFrames > 0;

            if (input.CrouchToggle && !m_context.ActionBusy && m_context.Grounded)
            {
                m_context.Crouch = !m_context.Crouch;
            }

            AdvanceAction();

            if (m_hasPendingAction)
            {
                ApplyPendingAction();
            }

            if (!m_context.ActionBusy)
            {
                ApplyLocomotion(ChooseLocomotion(input));
            }

            // 空中、落地缓冲、格挡都不许水平移动；动作层/反应层按 BlocksMovement 判
            bool canMove = m_context.Grounded
                && !m_blocking
                && !m_context.Landing
                && !PlayerStateCatalog.BlocksMovement(m_fsm.LowerCurrent);
            m_context.Speed = canMove ? SpeedOf(m_fsm.LowerCurrent) : 0f;
            m_context.Direction = canMove ? ClampDirection(input.MoveX) : 0f;
            m_context.Motion.SetMoveSpeed(m_context.Speed);
            m_context.Motion.MovementEnabled = canMove;

            m_fsm.Tick(frame);
        }

        // 功能：请求播攻击；空闲时起手第 1 段，连击窗口内则排队下一段。
        // 入参：无。
        // 返回：true 表示已起手或已排队；false 表示已死、动作不在攻击链上、或不在窗口内。
        // 步骤：1) 死亡拒绝 2) 空闲直接起手第 1 段 3) 动作层里只接第 1/2 段 4) 帧号不在窗口内拒绝 5) 只做排队，不切当前状态。
        // 上游/下游：PlayerBrain 攻击键调用；内部调用 BeginAction，下一段在 AdvanceAction 里接。
        public bool NotifyAttack()
        {
            if (m_context.Dead || m_blocking)
            {
                return false;
            }

            if (!m_context.ActionBusy)
            {
                return BeginAction(EPlayerState.Attack1, PlayerActionId.Attack1, m_timings.AttackFrames);
            }

            if (PlayerStateCatalog.LayerOf(m_fsm.LowerCurrent) != EPlayerLayer.Action)
            {
                return false;
            }

            if (m_context.ActionId != PlayerActionId.Attack1 && m_context.ActionId != PlayerActionId.Attack2)
            {
                return false;
            }

            if (m_context.ActionFrame < m_timings.ComboWindowStart)
            {
                return false;
            }

            if (m_context.ActionFrames > 0 && m_context.ActionFrame > m_context.ActionFrames - m_timings.ComboEndBuffer)
            {
                return false;
            }

            m_comboQueued = true;
            return true;
        }

        // 功能：请求播第 index 个技能（只播动画，不产生伤害）。
        // 入参：index 取 1~3，超出范围拒绝。
        // 返回：true 表示已排队；false 表示已死、有动作在播、或正在格挡。
        // 步骤：先做前置拒绝，再按序号取状态、ActionId 与帧数。
        // 上游/下游：PlayerBrain 的 Q/E/R 调用；内部调用 BeginAction。
        public bool NotifySkill(int index)
        {
            if (m_context.Dead || m_context.ActionBusy || m_blocking)
            {
                return false;
            }

            if (index < 1 || index > 3)
            {
                return false;
            }

            EPlayerState state = (EPlayerState)((int)EPlayerState.Skill1 + index - 1);
            int frames = index == 1 ? m_timings.Skill1Frames : (index == 2 ? m_timings.Skill2Frames : m_timings.Skill3Frames);
            return BeginAction(state, PlayerActionId.OfSkill(index), frames);
        }

        // 功能：请求前冲一段。
        // 入参：无。
        // 返回：true 表示已排队；false 表示已死、有动作在播、或正在格挡。
        // 步骤：前置拒绝后进 Dash，帧数取 DashFrames；位移由 PlayerBrain 通过 IPlayerDash 触发。
        // 上游/下游：PlayerBrain 的 V 键调用；内部调用 BeginAction。
        public bool NotifyDash()
        {
            if (m_context.Dead || m_context.ActionBusy || m_blocking)
            {
                return false;
            }

            return BeginAction(EPlayerState.Dash, PlayerActionId.Dash, m_timings.DashFrames);
        }

        // 功能：轮换到下一个姿势（七个 CBG 表情动作）。
        // 入参：无。
        // 返回：true 表示已排队；false 表示已死、有动作在播、或正在格挡。
        // 步骤：先把当前 PoseIndex 写进参数上下文，再对 7 取模准备下一次，最后进 Pose。
        // 上游/下游：PlayerBrain 的 F 键调用；内部调用 BeginAction。
        // 注意：PoseIndex 必须同时写进 m_context，否则 BuildParams 发出去永远是 0，七个表情只有第一个能命中；
        // 用「先发布再自增」是为了第一次按 F 播第一个表情（Index 0 = CBG_Angry）。
        public bool NotifyPose()
        {
            if (m_context.Dead || m_context.ActionBusy || m_blocking)
            {
                return false;
            }

            m_context.PoseIndex = m_poseIndex;
            m_poseIndex = (m_poseIndex + 1) % 7;
            return BeginAction(EPlayerState.Pose, PlayerActionId.Pose, m_timings.PoseFrames);
        }

        // 功能：按住/松开格挡。格挡是常驻动作，不占 ActionBusy。
        // 入参：blocking 为 true 表示按住右键。
        // 返回：无。
        // 步骤：按住时若有动作在播就忽略；否则写 ActionId=8 并关移动闸门。松开时清回 None。
        // 上游/下游：PlayerBrain 每帧调用；动画控制器按 ActionId==8 进 S_Block。
        public void SetBlocking(bool blocking)
        {
            if (m_context.Dead)
            {
                return;
            }

            if (blocking)
            {
                if (m_blocking || m_context.ActionBusy)
                {
                    return;
                }

                m_blocking = true;
                m_context.ActionId = PlayerActionId.Block;
                m_context.ActionFrame = 0;
                m_context.ActionFrames = 0;
                return;
            }

            if (!m_blocking)
            {
                return;
            }

            m_blocking = false;
            m_context.ActionId = PlayerActionId.None;
        }

        // 功能：请求播受击；硬直期间免疫，死亡后拒绝，其余情况可打断攻击/技能。
        // 入参：fromLeft 为 true 表示从左侧被打（决定 StackSide 与 HitLeft/HitRight）。
        // 返回：true 表示请求已受理；false 表示已死或正在硬直。
        // 步骤：死亡与硬直都直接拒绝；否则写 StackSide 并排队受击。
        // 上游/下游：PlayerBrain 受击调试键 / 将来网络受击消息调用。
        public bool NotifyHit(bool fromLeft)
        {
            if (m_context.Dead || IsStunned)
            {
                return false;
            }

            m_context.StackSide = fromLeft ? -1f : 1f;
            m_comboQueued = false;
            m_blocking = false;
            EPlayerState state = fromLeft ? EPlayerState.HitLeft : EPlayerState.HitRight;
            return BeginAction(state, PlayerActionId.Hit, m_timings.HitFrames);
        }

        // 功能：请求进入硬直；硬直优先级高于动作层（能打断攻击、技能、冲刺、姿势），低于死亡。
        // 入参：无。
        // 返回：true 表示已受理；false 表示已死或已在硬直中。
        // 步骤：死亡与重复硬直直接拒绝；否则清连击/格挡并排队硬直。
        // 上游/下游：PlayerBrain 的 T 键调用 / 将来网络控制消息调用。
        public bool NotifyStun()
        {
            if (m_context.Dead || IsStunned)
            {
                return false;
            }

            m_comboQueued = false;
            m_blocking = false;
            return BeginAction(EPlayerState.Stun, PlayerActionId.Stun, m_timings.StunFrames);
        }

        // 功能：当前是否处于硬直。
        // 入参：无。
        // 返回：true 表示硬直中。
        // 步骤：硬直期间 ActionBusy 为 true 且 ActionId 为 11，两者都要判（最后一帧 ActionId 会先清）。
        // 上游/下游：NotifyHit / 外部查询调用。
        public bool IsStunned => m_context.ActionBusy && m_context.ActionId == PlayerActionId.Stun;

        // 功能：请求进入死亡状态，之后任何移动/动作请求都无效。
        // 入参：无。
        // 返回：true 表示这次真的死了；false 表示之前已经死了。
        // 步骤：1) 置死亡标记 2) 清动作与位移闸门 3) 强制切到反应层的 Die（跳过准入检查）。
        // 上游/下游：PlayerBrain 死亡调试键 / 将来网络死亡消息调用。
        public bool NotifyDead()
        {
            if (m_context.Dead)
            {
                return false;
            }

            m_context.Dead = true;
            m_context.ResetAction();
            m_hasPendingAction = false;
            m_comboQueued = false;
            m_blocking = false;
            m_landingFrames = 0;
            m_context.Landing = false;
            m_context.Motion.MovementEnabled = false;
            m_context.Motion.SetMoveSpeed(0f);
            m_fsm.ForceChange(EPlayerState.Reaction, EPlayerState.Die);
            return true;
        }

        // 功能：按输入选一个移动状态（只在没有动作在播时用）。
        // 入参：input 这一帧的输入。
        // 返回：Idle / Walk / Run / Sprint / CrouchIdle / CrouchWalk / CrouchJog / Jump / Fall / Land 之一。
        // 步骤：1) 离地先按竖直速度分 Jump / Fall（空中不响应方向）2) 落地缓冲选 Land 3) 其余按方向与蹲 Shift Alt。
        // 上游/下游：Tick 调用。
        private EPlayerState ChooseLocomotion(in PlayerInput input)
        {
            if (!m_context.Grounded)
            {
                return m_context.VerticalSpeed > 0f ? EPlayerState.Jump : EPlayerState.Fall;
            }

            if (m_context.Landing)
            {
                return EPlayerState.Land;
            }

            if (!input.HasDirection())
            {
                return m_context.Crouch ? EPlayerState.CrouchIdle : EPlayerState.Idle;
            }

            if (m_context.Crouch)
            {
                return input.SprintHeld ? EPlayerState.CrouchJog : EPlayerState.CrouchWalk;
            }

            if (input.SprintHeld)
            {
                return EPlayerState.Sprint;
            }

            return input.WalkHeld ? EPlayerState.Walk : EPlayerState.Run;
        }

        // 功能：把目标移动状态落到状态机上（同层只换下层，跨层才换上层）。
        // 入参：desired 目标移动状态。
        // 返回：无；切换被拒绝时保持原状态。
        // 步骤：当前已在移动层就 TryChangeLower，否则 TryChangeUpper(移动层, desired)。
        // 上游/下游：Tick 调用；下游 HierarchicalStateMachine.TryChangeLower/TryChangeUpper。
        private void ApplyLocomotion(EPlayerState desired)
        {
            if (m_fsm.UpperCurrent == EPlayerState.Locomotion)
            {
                if (m_fsm.LowerCurrent != desired)
                {
                    m_fsm.TryChangeLower(desired);
                }

                return;
            }

            m_fsm.TryChangeUpper(EPlayerState.Locomotion, desired);
        }

        // 功能：推进当前动作的帧计数，到点就结束动作或接上排队的下一段连击。
        // 入参：无。
        // 返回：无。
        // 步骤：没有动作直接返回；有动作就 +1 帧；到点先看有没有排队连击，能接就接下一段，否则清动作。
        // 上游/下游：Tick 调用；下游 TryStartNextCombo / PlayerStateContext.ResetAction。
        private void AdvanceAction()
        {
            if (!m_context.ActionBusy)
            {
                return;
            }

            m_context.ActionFrame++;
            if (m_context.ActionFrames <= 0 || m_context.ActionFrame < m_context.ActionFrames)
            {
                return;
            }

            if (m_comboQueued && TryStartNextCombo())
            {
                m_comboQueued = false;
                return;
            }

            m_comboQueued = false;
            m_context.ResetAction();
        }

        // 功能：把当前攻击段接到下一段（1→2、2→3）。
        // 入参：无。
        // 返回：true 表示已登记下一段；false 表示当前不是第 1/2 段。
        // 步骤：按当前 ActionId 决定目标状态与帧数，再 BeginAction 排队，下一帧生效。
        // 上游/下游：AdvanceAction 调用；下游 BeginAction。
        private bool TryStartNextCombo()
        {
            if (m_context.ActionId == PlayerActionId.Attack1)
            {
                return BeginAction(EPlayerState.Attack2, PlayerActionId.Attack2, m_timings.Attack2Frames);
            }

            if (m_context.ActionId == PlayerActionId.Attack2)
            {
                return BeginAction(EPlayerState.Attack3, PlayerActionId.Attack3, m_timings.Attack3Frames);
            }

            return false;
        }

        // 功能：把排队中的动作请求真正执行（切到对应层与状态）。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 先写 ActionBusy/ActionId/帧数 2) 目标就是当前配置时只重置计时 3) 否则 TryChangeUpper，被拒绝则回滚为「没有动作」。
        // 上游/下游：Tick 调用；下游 HierarchicalStateMachine.TryChangeUpper。
        private void ApplyPendingAction()
        {
            m_hasPendingAction = false;
            m_context.ActionBusy = true;
            m_context.ActionId = m_pendingActionId;
            m_context.ActionFrame = 0;
            m_context.ActionFrames = m_pendingFrames;

            EPlayerState upper = PlayerStateCatalog.UpperOf(PlayerStateCatalog.LayerOf(m_pendingState));

            if (m_fsm.UpperCurrent == upper && m_fsm.LowerCurrent == m_pendingState)
            {
                return;
            }

            if (!m_fsm.TryChangeUpper(upper, m_pendingState))
            {
                m_context.ResetAction();
            }
        }

        // 功能：登记一个待执行动作。
        // 入参：state 目标状态；actionId 写进动画参数的动作编号；frames 总帧数（60fps，<=0 表示不自动结束）。
        // 返回：true 表示已登记。
        // 步骤：只写 pending 字段，下一帧 Tick 再执行 —— 保证一帧内只发生一次状态切换。
        // 上游/下游：NotifyAttack / NotifyHit 调用。
        private bool BeginAction(EPlayerState state, float actionId, int frames)
        {
            m_pendingState = state;
            m_pendingActionId = actionId;
            m_pendingFrames = frames;
            m_hasPendingAction = true;
            return true;
        }

        // 功能：按状态取这一档移动速度。
        // 入参：state 当前移动状态。
        // 返回：米/秒；非移动状态返回 0。
        // 步骤：switch 一一映射到 PlayerSpeeds 的五个字段。
        // 上游/下游：Tick 调用。
        private float SpeedOf(EPlayerState state)
        {
            switch (state)
            {
                case EPlayerState.Walk:
                    return m_speeds.Walk;
                case EPlayerState.Run:
                    return m_speeds.Run;
                case EPlayerState.Sprint:
                    return m_speeds.Sprint;
                case EPlayerState.CrouchWalk:
                    return m_speeds.CrouchWalk;
                case EPlayerState.CrouchJog:
                    return m_speeds.CrouchJog;
                default:
                    return 0f;
            }
        }

        // 功能：把横向输入夹到 -1~1。
        // 入参：value 原始横向输入。
        // 返回：夹紧后的值。
        // 步骤：两段比较，不调用 UnityEngine.Mathf（本类保持纯 C#）。
        // 上游/下游：Tick 调用。
        private static float ClampDirection(float value)
        {
            if (value < -1f)
            {
                return -1f;
            }

            return value > 1f ? 1f : value;
        }

        // 功能：注册移动层的九个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：Idle 必须第一个注册（它会成为入口），其余顺序无关。
        // 上游/下游：构造函数调用。
        private void RegisterLocomotionStates()
        {
            RegisterSub(EPlayerState.Idle);
            RegisterSub(EPlayerState.Walk);
            RegisterSub(EPlayerState.Run);
            RegisterSub(EPlayerState.Sprint);
            RegisterSub(EPlayerState.CrouchIdle);
            RegisterSub(EPlayerState.CrouchWalk);
            RegisterSub(EPlayerState.CrouchJog);
            RegisterSub(EPlayerState.Jump);
            RegisterSub(EPlayerState.Fall);
            RegisterSub(EPlayerState.Land);
        }

        // 功能：注册动作层的九个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：Attack1 第一个注册（成为入口）。
        // 上游/下游：构造函数调用。
        private void RegisterActionStates()
        {
            RegisterSub(EPlayerState.Attack1);
            RegisterSub(EPlayerState.Attack2);
            RegisterSub(EPlayerState.Attack3);
            RegisterSub(EPlayerState.Skill1);
            RegisterSub(EPlayerState.Skill2);
            RegisterSub(EPlayerState.Skill3);
            RegisterSub(EPlayerState.Dash);
            RegisterSub(EPlayerState.Block);
            RegisterSub(EPlayerState.Pose);
        }

        // 功能：注册反应层的四个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：HitLeft 第一个注册（成为入口）。
        // 上游/下游：构造函数调用。

            RegisterSub(EPlayerState.HitRight);
            RegisterSub(EPlayerState.Stun);
            RegisterSub(EPlayerState.Die);

        // 入参：sub 下层状态。
        // 返回：无。
        // 步骤：用 LayerOf 算出层，再 UpperOf 换成上层标识 —— 层归属只在这里推一次。

        private void RegisterSub(EPlayerState sub)

            EPlayerState upper = PlayerStateCatalog.UpperOf(PlayerStateCatalog.LayerOf(sub));
            m_fsm.RegisterSub(upper, sub, new PlayerLayeredState(sub));
```

```csharp
// 这个文件里有：
//   PlayerAnimatorPublisher（组件）：把一帧动画参数写进 Animator，并保证「值没变就不写」

using System.Collections.Generic;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：实现 IPlayerAnimatorSink —— 状态机算好的 bool/float 参数由它统一写进 Animator；Speed 在这里从旧档位平滑到新档位。
    // 主要数据成员：m_animator（目标动画机）、参数哈希与上次写入值（用于幂等）、m_speedSmoother（Speed 的线性平滑器）。
    // 主要外部方法：Apply 写一帧参数；Reset 在编辑器里自动抓 Animator。
    // 谁在用它：PlayerBrain.Update 每帧调一次；本身挂在玩家根节点上。
    // 注意：控制器没声明的参数只告警一次并跳过，不要每帧 SetFloat —— Unity 会为每个缺失参数刷一条警告， Console 会被淹掉。
    [DisallowMultipleComponent]
    public sealed class PlayerAnimatorPublisher : MonoBehaviour, IPlayerAnimatorSink
    {
        // 浮点参数在数组里的下标
        private const int FloatSpeed = 0;
        private const int FloatDirection = 1;
        private const int FloatVerticalSpeed = 2;
        private const int FloatActionId = 3;
        private const int FloatStackSide = 4;
        private const int FloatPoseIndex = 5;
        private const int FloatCount = 6;

        // 布尔参数在数组里的下标
        private const int BoolCrouch = 0;
        private const int BoolGrounded = 1;
        private const int BoolActionBusy = 2;
        private const int BoolDead = 3;
        private const int BoolLanding = 4;
        private const int BoolCount = 5;

        // Speed 的变化小于这个值就不写 Animator（混合树上看不出来，省掉每帧 SetFloat）
        private const float FloatWriteEpsilon = 0.01f;

        // 六个浮点参数的控制器名字，顺序与上面的下标一致
        private static readonly string[] FloatNames =
        {
            PlayerAnimatorNames.Speed,
            PlayerAnimatorNames.Direction,
            PlayerAnimatorNames.VerticalSpeed,
            PlayerAnimatorNames.ActionId,
            PlayerAnimatorNames.StackSide,
            PlayerAnimatorNames.PoseIndex,
        };

        // 五个布尔参数的控制器名字，顺序与上面的下标一致
        private static readonly string[] BoolNames =
        {
            PlayerAnimatorNames.Crouch,
            PlayerAnimatorNames.Grounded,
            PlayerAnimatorNames.ActionBusy,
            PlayerAnimatorNames.Dead,
            PlayerAnimatorNames.Landing,
        };

        // 目标动画机；为空时 Awake 自动往子物体找
        [SerializeField] private Animator m_animator;

        // 控制器缺参数时是否打一条警告（只打一次）
        [SerializeField] private bool m_logMissingParameters = true;

        // Speed 从旧档位滑到新档位用多少秒（秒）；混合树靠它把「站→跑」变成连续过渡，0 表示不平滑
        [SerializeField] private float m_speedSmoothSeconds = 0.12f;

        // Speed 的平滑器；EnsureReady 里按 m_speedSmoothSeconds 创建
        private PlayerSpeedSmoother m_speedSmoother;

        // 参数哈希
        private int[] m_floatHashes;

        // 上次写入的浮点值（NaN 表示还没写过）
        private float[] m_floatLast;

        // 该浮点参数是否存在于控制器里
        private bool[] m_floatValid;

        // 参数哈希
        private int[] m_boolHashes;

        // 上次写入的布尔值
        private bool[] m_boolLast;

        // 该布尔参数是否存在于控制器里
        private bool[] m_boolValid;

        // 是否已经写过至少一次（用于首次必写）
        private bool[] m_boolWritten;

        // 是否完成了初始化（找 Animator + 查参数）
        private bool m_ready;

        // 功能：在编辑器里加组件时自动抓子物体的 Animator，省得手拖。
        // 入参：无。
        // 返回：无。
        // 步骤：直接 GetComponentInChildren 赋给序列化字段。
        // 上游/下游：Unity 编辑器调用。
        private void Reset()
        {
            m_animator = GetComponentInChildren<Animator>();
        }

        // 功能：场景启动时完成初始化。
        // 入参：无。
        // 返回：无。
        // 步骤：调用 EnsureReady 一次。
        // 上游/下游：Unity 生命周期；下游 EnsureReady。
        private void Awake()
        {
            EnsureReady();
        }

        // 功能：把一帧参数写进 Animator（幂等：没变就不写）。
        // 入参：parameters 是状态机产出的只读快照。
        // 返回：无。
        // 步骤：1) 确保初始化 2) 先把 Speed 平滑一帧（混合树要连续值）3) 其余浮点 4) 四个布尔。
        // 上游/下游：PlayerBrain.Update 调用；下游 WriteFloat / WriteBool。
        public void Apply(in PlayerAnimatorParams parameters)
        {
            EnsureReady();

            if (m_animator == null)
            {
                return;
            }

            float smoothedSpeed = m_speedSmoother == null
                ? parameters.Speed
                : m_speedSmoother.Step(parameters.Speed, Time.deltaTime);

            WriteFloat(FloatSpeed, smoothedSpeed, FloatWriteEpsilon);
            WriteFloat(FloatDirection, parameters.Direction);
            WriteFloat(FloatVerticalSpeed, parameters.VerticalSpeed);
            WriteFloat(FloatActionId, parameters.ActionId);
            WriteFloat(FloatStackSide, parameters.StackSide);
            WriteFloat(FloatPoseIndex, parameters.PoseIndex);

            WriteBool(BoolCrouch, parameters.Crouch);
            WriteBool(BoolGrounded, parameters.Grounded);
            WriteBool(BoolActionBusy, parameters.ActionBusy);
            WriteBool(BoolDead, parameters.Dead);
            WriteBool(BoolLanding, parameters.Landing);
        }

        // 功能：找 Animator、查参数表、缓存哈希。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 已初始化直接返回 2) 找 Animator，找不到就禁用本组件 3) 关根运动 4) 按参数表建哈希，缺的标 invalid 并告警一次。
        // 上游/下游：Awake / Apply 调用。
        private void EnsureReady()
        {
            if (m_ready)
            {
                return;
            }

            m_ready = true;

            if (m_animator == null)
            {
                m_animator = GetComponentInChildren<Animator>();
            }

            if (m_animator == null)
            {
                Debug.LogError("[PlayerAnimator] 找不到 Animator，动画参数不会生效。", this);
                return;
            }

            m_animator.applyRootMotion = false;

            if (m_speedSmoother == null)
            {
                m_speedSmoother = new PlayerSpeedSmoother(m_speedSmoothSeconds);
            }

            Dictionary<string, AnimatorControllerParameterType> existing = new Dictionary<string, AnimatorControllerParameterType>();
            AnimatorControllerParameter[] parameters = m_animator.parameters;
            for (int i = 0; i < parameters.Length; i++)
            {
                existing[parameters[i].name] = parameters[i].type;
            }

            m_floatHashes = new int[FloatCount];
            m_floatLast = new float[FloatCount];
            m_floatValid = new bool[FloatCount];
            m_boolHashes = new int[BoolCount];
            m_boolLast = new bool[BoolCount];
            m_boolValid = new bool[BoolCount];
            m_boolWritten = new bool[BoolCount];

            List<string> missing = new List<string>();

            for (int i = 0; i < FloatCount; i++)
            {
                m_floatHashes[i] = Animator.StringToHash(FloatNames[i]);
                m_floatLast[i] = float.NaN;
                m_floatValid[i] = HasParameter(existing, FloatNames[i], AnimatorControllerParameterType.Float);
                if (!m_floatValid[i])
                {
                    missing.Add(FloatNames[i] + "(Float)");
                }
            }

            for (int i = 0; i < BoolCount; i++)
            {
                m_boolHashes[i] = Animator.StringToHash(BoolNames[i]);
                m_boolValid[i] = HasParameter(existing, BoolNames[i], AnimatorControllerParameterType.Bool);
                if (!m_boolValid[i])
                {
                    missing.Add(BoolNames[i] + "(Bool)");
                }
            }

            if (missing.Count > 0 && m_logMissingParameters)
            {
                Debug.LogWarning("[PlayerAnimator] 控制器缺少参数：" + string.Join("、", missing) + "；对应的动画切换不会生效。", this);
            }
        }

        // 功能：判断控制器里有没有指定名字、指定类型的参数。
        // 入参：existing 参数名到类型的表；name 参数名；type 期望类型。
        // 返回：存在且类型一致返回 true。
        // 步骤：先查表再比类型。
        // 上游/下游：EnsureReady 调用。
        private static bool HasParameter(
            Dictionary<string, AnimatorControllerParameterType> existing,
            string name,
            AnimatorControllerParameterType type)
        {
            AnimatorControllerParameterType actual;
            return existing.TryGetValue(name, out actual) && actual == type;
        }

        // 功能：写一个浮点参数，值没变就跳过。
        // 入参：index 参数下标；value 目标值；epsilon 变化小于它就算没变（0 表示只跳过完全相等）。
        // 返回：无。
        // 步骤：参数缺失直接返回；与上次值差在 epsilon 内也返回；否则 SetFloat 并记下。
        // 上游/下游：Apply 调用；下游 Animator.SetFloat。
        private void WriteFloat(int index, float value, float epsilon = 0f)
        {
            if (!m_floatValid[index])
            {
                return;
            }

            if (!float.IsNaN(m_floatLast[index]))
            {
                float delta = Mathf.Abs(m_floatLast[index] - value);
                if (epsilon <= 0f ? Mathf.Approximately(m_floatLast[index], value) : delta <= epsilon)
                {
                    return;
                }
            }

            m_floatLast[index] = value;
            m_animator.SetFloat(m_floatHashes[index], value);
        }

        // 功能：写一个布尔参数，值没变就跳过。
        // 入参：index 参数下标；value 目标值。
        // 返回：无。
        // 步骤：参数缺失直接返回；写过且值相同也返回；否则 SetBool 并记下。
        // 上游/下游：Apply 调用；下游 Animator.SetBool。
        private void WriteBool(int index, bool value)
        {
            if (!m_boolValid[index])
            {
                return;
            }

            if (m_boolWritten[index] && m_boolLast[index] == value)
            {
                return;
            }

            m_boolWritten[index] = true;
            m_boolLast[index] = value;
            m_animator.SetBool(m_boolHashes[index], value);
        }
    }
}
```

```csharp
        // 死亡调试键

        [SerializeField]

        [SerializeField]

        private KeyCode m_poseKey = KeyCode.F;

        // 跳跃键（R035d）
        [SerializeField]
        private KeyCode m_jumpKey = KeyCode.Space;

        // 落地缓冲帧数（12 帧 = 0.2 秒，期间不能移动）
        [SerializeField]
        private int m_landFrames = 12;

        // 是否接受本地攻击键（Battle 可关掉，避免和网络输入双触发）
        [SerializeField]
        private bool m_enableLocalAttack = true;

        // 是否启用调试键 K/L（编辑器里始终启用，方便验收；构建版本按这个开关决定）
        [SerializeField]
        private bool m_enableDebugKeys = false;

        // 是否把每次状态切换打到 Console
        [SerializeField]
        private bool m_logStateChanges = true;

        // 位移组件（IPlayerMotion 的实现者）
        private PlayerMove m_motion;

        // 动画参数发布器
        private PlayerAnimatorPublisher m_publisher;

        // 竖直运动电机（跳跃/下落/落地，R035d）
        private PlayerJumpMotor m_jumpMotor;

        // 状态机共享状态
        private PlayerStateContext m_context;

        // 三层状态机
        private PlayerStateMachine m_machine;

        // 已推进的逻辑帧号（必须单调递增）

        // 距上一个逻辑帧攒下的时间，秒

        // 功能：找齐组件、构造状态机、订阅状态切换日志。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 找 PlayerMove（找不到就禁用自己）2) 找或加 Publisher 3) 关旧动画 4) 换控制器副本、清掉表情动作的收剑事件、给蒙皮网格补包围盒守卫 5) 建上下文与状态机 6) 订阅日志。
        // 上游/下游：Unity 生命周期；下游 PlayerStateMachine 构造函数。
        private void Awake()
        {
            m_motion = m_move != null ? m_move : GetComponent<PlayerMove>();

            if (m_motion == null)
            {
                Debug.LogError("[PlayerBrain] 根节点上没有 PlayerMove，状态机无法驱动位移。", this);
                enabled = false;
                return;
            }

            m_publisher = GetComponent<PlayerAnimatorPublisher>();
            if (m_publisher == null)
            {
                m_publisher = gameObject.AddComponent<PlayerAnimatorPublisher>();
            }

            if (m_disableLegacyAnimation)
            {
                PlayerAnimation legacy = GetComponent<PlayerAnimation>();
                if (legacy != null)
                {
                    legacy.enabled = false;
                }
            }

            Animator animator = GetComponentInChildren<Animator>();
            if (animator != null)
            {
                if (m_animatorControllerOverride != null && animator.runtimeAnimatorController != m_animatorControllerOverride)
                {
                    animator.runtimeAnimatorController = m_animatorControllerOverride;
                }

                StripPoseClipEvents(animator);

                if (GetComponent<PlayerSkinnedMeshGuard>() == null)
                {
                    gameObject.AddComponent<PlayerSkinnedMeshGuard>();
                }
            }

            m_context = new PlayerStateContext(m_motion);
            PlayerTimings timings = new PlayerTimings(
                m_attack1Frames,
                m_attack2Frames,
                m_attack3Frames,
                m_skill1Frames,
                m_skill2Frames,
                m_skill3Frames,
                m_dashFrames,
                m_hitFrames,
                m_stunFrames,
                m_poseFrames,
                m_comboWindowStart,
                m_comboEndBuffer,
                m_landFrames);
            PlayerSpeeds speeds = new PlayerSpeeds(
                m_walkSpeed,
                m_runSpeed,
                m_sprintSpeed,
                m_crouchWalkSpeed,
                m_crouchJogSpeed);
            m_machine = new PlayerStateMachine(m_context, timings, speeds);

            m_jumpMotor = GetComponent<PlayerJumpMotor>();
            if (m_jumpMotor == null)
            {
                m_jumpMotor = gameObject.AddComponent<PlayerJumpMotor>();
            }

            m_jumpMotor.Bind(m_machine);

            if (m_logStateChanges)
            {
                m_machine.StateChanged += OnStateChanged;
            }
        }

        // 功能：把七个表情动作（CBG）里的「收剑到背后」动画事件清掉，剑在姿势期间保持握在手里。
        // 入参：animator 是玩家模型上的动画器。
        // 返回：无。
        // 步骤：1) 取控制器里的全部 clip 2) 只挑名字以 CBG 开头的 3) 把事件数组清空（改的是内存里的 clip，不会写回美术包）。
        // 上游/下游：Awake 调用；下游 AnimationClip.events。
        // 注意：这些 clip 第 0 帧带 SwitchSocket/To_Put_Socket_Sword，进姿势瞬间会把剑从右手切到背后，退出又切回来，看起来像闪一下。
        private static void StripPoseClipEvents(Animator animator)
        {
            RuntimeAnimatorController controller = animator.runtimeAnimatorController;
            if (controller == null)
            {
                return;
            }

            AnimationClip[] clips = controller.animationClips;
            for (int i = 0; i < clips.Length; i++)
            {
                AnimationClip clip = clips[i];
                if (clip == null || !clip.name.StartsWith(PoseClipPrefix) || clip.events.Length == 0)
                {
                    continue;
                }

                clip.events = new AnimationEvent[0];
            }
        }

        // 功能：每帧读输入、按固定步长推进逻辑、发布动画参数。
        // 入参：无。

        // 上游/下游：Unity 生命周期；下游 PlayerJumpMotor.Step、PlayerStateMachine.Tick、PlayerAnimatorPublisher.Apply。
        private void Update()
        {
            if (m_machine == null)
            {
                return;
            }

            PlayerInput input = ReadInput();
            HandleActionKeys();

            // 右键是「按住格挡」：每帧同步一次，松开当帧就退出
            m_machine.SetBlocking(m_enableLocalAttack && Input.GetMouseButton(1));

            // 跳跃：按下当帧请求；电机先算初速度，状态机拒绝（动作中/已死/空中）就回滚
            if (Input.GetKeyDown(m_jumpKey))
            {
                m_jumpMotor.TryJump();
            }

            // 先把竖直位移推进一步，下面状态机就能读到这一帧的 Grounded / VerticalSpeed
            m_jumpMotor.Step(Time.deltaTime);

            m_frameAccumulator += Time.deltaTime;
            int steps = 0;
            bool firstStep = true;

            while (m_frameAccumulator >= FixedDeltaSeconds && steps < MaxCatchUpSteps)
            {
                m_frameAccumulator -= FixedDeltaSeconds;
                steps++;
                m_frame++;

                PlayerInput stepInput = firstStep
                    ? input
                    : new PlayerInput(input.MoveX, input.MoveY, input.WalkHeld, input.SprintHeld, false);
                firstStep = false;
                m_machine.Tick(m_frame, stepInput);
            }

            if (steps == 0)
            {
                return;
            }

            if (m_frameAccumulator > FixedDeltaSeconds * MaxCatchUpSteps)
            {
                m_frameAccumulator = 0f;
            }

            m_publisher.Apply(m_machine.Parameters);
        }

        // 功能：请求播攻击（本地键与网络消息都走这里）。
        // 入参：无。
        // 返回：无。
        // 步骤：转给状态机；被拒绝（已死/动作中）时什么都不做。
        // 上游/下游：Update 的攻击键、外部网络消息；下游 PlayerStateMachine.NotifyAttack。
        public void NotifyAttack()
        {

        }

        // 功能：请求播受击。

        // 返回：无。

        // 上游/下游：Update 的调试键、外部网络消息；下游 PlayerStateMachine.NotifyHit。
        public void NotifyHit(bool fromLeft)
        {

            {
                m_machine.NotifyHit(fromLeft);
            }
        }

        // 功能：请求进入硬直。
        // 入参：无。
        // 返回：无。
        // 步骤：转给状态机；被拒绝（已死/已在硬直）时什么都不做。
        // 上游/下游：Update 的 T 键、外部网络消息；下游 PlayerStateMachine.NotifyStun。
        public void NotifyStun()
        {
            if (m_machine != null)
            {
                m_machine.NotifyStun();
            }
        }

        // 功能：请求进入死亡状态。
        // 入参：无。
        // 返回：无。
        // 步骤：转给状态机。
        // 上游/下游：Update 的调试键、外部网络消息；下游 PlayerStateMachine.NotifyDead。
        public void NotifyDead()
        {
            if (m_machine != null)
            {
                m_machine.NotifyDead();
            }
        }

        // 当前是否已死亡
        public bool IsDead
        {
            get { return m_machine != null && m_machine.IsDead; }
        }

        // 当前下层状态（日志/调试面板用）
        public EPlayerState CurrentState
        {
            get { return m_machine != null ? m_machine.State : EPlayerState.Idle; }
        }

        // 功能：处理攻击/受击/死亡的按键请求。
        // 入参：无。
        // 返回：无。
        // 步骤：调试键先判（K 左受击、L 死亡），再看攻击键（J 或鼠标左键）；编辑器里调试键始终可用，构建版本看 Inspector 开关。
        // 上游/下游：Update 调用；下游 Notify*。
        private void HandleActionKeys()
        {
            if (m_enableDebugKeys || Application.isEditor)
            {
                if (Input.GetKeyDown(m_hitKey))
                {
                    NotifyHit(true);
                }

                if (Input.GetKeyDown(m_hitRightKey))
                {
                    NotifyHit(false);
                }

                {
                    NotifyStun();
                }

                {
                    NotifyDead();
                }
            }

            {
                return;
            }

            {
                NotifyAttack();
            }

            if (Input.GetKeyDown(m_skill1Key))
            {
                NotifySkill(1);
            }

            if (Input.GetKeyDown(m_skill2Key))

                NotifySkill(2);

            }

            {
                NotifyDash();
            }

            if (Input.GetKeyDown(m_poseKey))
            {
                NotifyPose();
            }
        }

        // 功能：请求播第 index 个技能（只播动画）。
        // 入参：index 取 1~3。
        // 返回：无。
        // 步骤：转给状态机；被拒绝（动作中/格挡/已死）时什么都不做。
        // 上游/下游：Update 的 Q/E/R、外部网络消息；下游 PlayerStateMachine.NotifySkill。
        public void NotifySkill(int index)
        {
            if (m_machine != null)
            {
                m_machine.NotifySkill(index);
            }
        }

        // 功能：请求前冲：状态机接了就同时让位移组件真的往前挪。
        // 入参：无。
        // 返回：无。
        // 步骤：状态机接受后，把速度与时长交给实现了 IPlayerDash 的位移组件。
        // 上游/下游：Update 的 V 键；下游 PlayerStateMachine.NotifyDash、IPlayerDash.StartDash。
        public void NotifyDash()
        {
            if (m_machine == null || !m_machine.NotifyDash())
            {
                return;
            }

            IPlayerDash dash = m_motion as IPlayerDash;
            if (dash != null)
            {
                dash.StartDash(m_dashSpeedMetersPerSecond, m_dashSeconds);
            }
        }

        // 功能：请求轮换到下一个姿势。
        // 入参：无。
        // 返回：无。
        // 步骤：转给状态机，由它把 PoseIndex 加一。
        // 上游/下游：Update 的 F 键；下游 PlayerStateMachine.NotifyPose。
        public void NotifyPose()
        {
            if (m_machine != null)
            {
                m_machine.NotifyPose();
            }
        }

        // 功能：把这一帧的键位读成 PlayerInput。
        // 入参：无。
        // 返回：输入快照。
        // 步骤：移动轴取 InputManager（-1000~1000 除 1000）；Alt=慢走、Shift=冲刺、Ctrl 按下=切换蹲；输入被禁用时轴按 0。
        // 上游/下游：Update 调用；下游 PlayerStateMachine.Tick。
        private static PlayerInput ReadInput()
        {
            float x = 0f;
            float y = 0f;

            InputManager manager = InputManager.Instance;
            if (manager != null && manager.IsEnabled)
            {
                InputCommand command = manager.Current;
                x = (float)command.MoveX / InputCommand.MoveScale;
                y = (float)command.MoveY / InputCommand.MoveScale;
            }

            bool walk = Input.GetKey(KeyCode.LeftAlt) || Input.GetKey(KeyCode.RightAlt);
            bool sprint = Input.GetKey(KeyCode.LeftShift) || Input.GetKey(KeyCode.RightShift);
            bool crouch = Input.GetKeyDown(KeyCode.LeftControl) || Input.GetKeyDown(KeyCode.RightControl);
            return new PlayerInput(x, y, walk, sprint, crouch);
        }

        // 功能：把一次状态切换打到 Console。
        // 入参：record 切换记录（含帧号与前后状态名）。
        // 返回：无。
        // 步骤：直接用记录自带的 ToString，格式 "[f12] Locomotion/Idle -> Locomotion/Run"。
        // 上游/下游：PlayerStateMachine.StateChanged 事件。
        private void OnStateChanged(StateChangeRecord record)
        {
            Debug.Log("[PlayerBrain] " + record);
        }

        // 功能：组件销毁时退订事件，避免状态机持有已销毁的 MonoBehaviour。
        // 入参：无。
        // 返回：无。
        // 步骤：有状态机就退订。
        // 上游/下游：Unity 生命周期。
        private void OnDestroy()
        {
            if (m_machine != null)
            {
                m_machine.StateChanged -= OnStateChanged;
            }
        }
    }
```

```csharp
// 这个文件里有：
//   WorldPlayerSetup（MonoBehaviour）：把 World 里的玩家接到跟随相机上，并让他贴着地面走。
//
// 为什么需要它：World 场景原来只有观察相机（WorldOrbitCamera）；有了玩家之后，
// 相机要跟人走，人还要贴地形高度 —— 这两件事不能写死在相机/玩家各自的脚本里。

using NBC.Game.Player;

using UnityEngine;

namespace NBC.Game.GameFlow
{
    // 主要功能：找到玩家 → 把跟随相机的目标设成他 → 关掉观察相机 → 没有 PlayerJumpMotor 时每帧把人贴到地面（有电机就交给电机）。
    // 主要数据成员：m_player（玩家根节点）、m_followCamera、m_orbitCamera、m_groundMask（哪些层算地面）、m_jumpMotor。
    // 主要外部方法：Unity 的 Start / LateUpdate。
    // 谁在用它：World 场景里的玩家对象（[Player_Hero]）。
    // 注意：贴地用的是向下射线；地形/房子都要有碰撞体，否则人会穿下去。
    public sealed class WorldPlayerSetup : MonoBehaviour
    {
        // 玩家根节点（留空 = 用挂这个组件的对象）
        [SerializeField]
        private Transform m_player;

        // 跟随相机（World 场景的 Main Camera；旧版：世界固定偏移）
        [SerializeField]
        private FollowCamera m_followCamera;

        // 第三人称跟随相机（优先用这个：会绕到角色背后）
        [SerializeField]
        private WorldFollowCamera m_worldFollowCamera;

        // 观察相机（没有玩家时用的那个；有玩家就关掉它）
        [SerializeField]
        private WorldOrbitCamera m_orbitCamera;

        // 贴地射线的层遮罩（默认全部）
        [SerializeField]
        private LayerMask m_groundMask = ~0;

        // 贴地射线的起点高度（米，够高才能打到地面）
        [SerializeField]
        private float m_probeHeight = 5f;

        // 贴地射线的最长距离（米）
        [SerializeField]
        private float m_probeDistance = 50f;

        // 玩家身上的竖直运动电机；有它时贴地由电机负责，本组件不再写 y
        private PlayerJumpMotor m_jumpMotor;

        // 贴地射线的命中缓冲（复用以避免每帧分配；16 个足够覆盖脚下几层物体）
        private readonly RaycastHit[] m_groundHits = new RaycastHit[16];

        // 贴地诊断：命中点让 y 变化超过 1 厘米时打一行日志（排查「角色上下跳」用；验收完可关掉）
        [SerializeField]
        private bool m_logGroundSnap = true;

        // 功能：启动时接线：相机跟人、关观察相机。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 玩家没配就用自己
        //   2) 关掉观察相机（避免两套相机抢着写位置）
        //   3) 把跟随相机的目标设成玩家
        // 上游：Unity
        // 下游：FollowCamera / WorldOrbitCamera
        private void Start()
        {
            if (m_player == null)
            {
                m_player = transform;
            }

            // World 玩家现在由 PlayerJumpMotor 负责贴地（R035d 起）；这里只记下来，LateUpdate 里让位
            m_jumpMotor = m_player.GetComponent<PlayerJumpMotor>();

            if (m_orbitCamera != null)
            {
                m_orbitCamera.enabled = false;
            }

            // 没在 Inspector 里配第三人称相机 ⇒ 运行时给 Main Camera 加一个（场景不用改）
            if (m_worldFollowCamera == null)
            {
                Camera mainCamera = Camera.main;

                if (mainCamera != null)
                {
                    m_worldFollowCamera = mainCamera.GetComponent<WorldFollowCamera>();

                    if (m_worldFollowCamera == null)
                    {
                        m_worldFollowCamera = mainCamera.gameObject.AddComponent<WorldFollowCamera>();
                    }
                }
            }

            if (m_worldFollowCamera != null)
            {
                m_worldFollowCamera.enabled = true;
                m_worldFollowCamera.SetTarget(m_player);
            }

            if (m_followCamera != null)
            {
                // 旧的"世界固定偏移"相机：有新的就关掉，避免两套都写位置
                m_followCamera.enabled = m_worldFollowCamera == null;

                if (m_worldFollowCamera == null)
                {
                    m_followCamera.SetTarget(m_player);
                }
            }

            if (m_worldFollowCamera == null && m_followCamera == null)
            {
                Debug.LogWarning("[WorldPlayerSetup] 没配跟随相机，画面会停在原地");
            }

            // World 需要「镜头相对移动」：W 永远是镜头前方（Battle 用世界轴，那边不动）
            PlayerMove relativeMove = GetComponent<PlayerMove>();

            if (relativeMove != null)
            {
                Camera mainCameraForAxes = Camera.main;
                relativeMove.SetReferenceAxes(true, mainCameraForAxes != null ? mainCameraForAxes.transform : null);
            }
            // 防"双份移动"：模型身上若也挂了 PlayerMove / PlayerAnimation，两套会各读一份输入、各走一次
            PlayerMove[] moves = GetComponentsInChildren<PlayerMove>(true);

            for (int i = 0; i < moves.Length; i++)
            {
                if (moves[i].gameObject != gameObject && moves[i].enabled)
                {
                    moves[i].enabled = false;
                    Debug.LogWarning("[WorldPlayerSetup] 关掉子物体 " + moves[i].name + " 上重复的 PlayerMove（会造成双份位移）");
                }
            }

            PlayerAnimation[] animations = GetComponentsInChildren<PlayerAnimation>(true);

            for (int i = 0; i < animations.Length; i++)
            {
                if (animations[i].gameObject != gameObject && animations[i].enabled)
                {
                    animations[i].enabled = false;
                    Debug.LogWarning("[WorldPlayerSetup] 关掉子物体 " + animations[i].name + " 上重复的 PlayerAnimation");
                }
            }
            // World 的动画改由 PlayerBrain + 动画参数驱动；旧的 PlayerAnimation 还会自己 SetTrigger，会和状态机打架
            PlayerAnimation selfAnimation = GetComponent<PlayerAnimation>();

            if (selfAnimation != null)
            {
                bool closedByUs = selfAnimation.enabled;

                selfAnimation.enabled = false;
                Debug.Log("[WorldPlayerSetup] 根节点上的 PlayerAnimation 已关闭（World 动画改由状态机参数驱动）"
                    + (closedByUs ? "：本次由 WorldPlayerSetup 关掉" : "：此前已被 PlayerBrain 关掉"));
            }
            else
            {
                Debug.Log("[WorldPlayerSetup] 根节点上没有 PlayerAnimation，动画只由状态机参数驱动");
            }

            Debug.Log("[WorldPlayerSetup] 玩家已就位：" + m_player.name
                + "，第三人称相机=" + (m_worldFollowCamera != null)
                + "，旧跟随相机=" + (m_followCamera != null));
        }

        // 诊断：是否打印「输入 → 朝向/速度」日志（排查转身/动画问题用，默认关）
        [SerializeField]
        private bool m_debugLog = false;

        // 诊断用：上一次打印的时间
        private float m_lastLogTime;

        // 功能：临时诊断，打印输入轴、当前朝向、速度。
        // 入参：无
        // 返回：无
        // 步骤：每 0.5 秒一条，内容含 MoveX/MoveY、yaw、速度
        // 上游：LateUpdate
        // 下游：Debug.Log
        private void LogDiagnostics()
        {
            if (!m_debugLog)
            {
                return;
            }

            if (Time.time - m_lastLogTime < 0.5f)
            {
                return;
            }

            m_lastLogTime = Time.time;

            NBC.Framework.Input.InputManager input = NBC.Framework.Input.InputManager.Instance;
            int moveX = input != null ? input.Current.MoveX : 0;
            int moveY = input != null ? input.Current.MoveY : 0;
            NBC.Game.Player.PlayerMove move = GetComponent<NBC.Game.Player.PlayerMove>();

            Debug.Log("[玩家诊断] 输入 X=" + moveX + " Y=" + moveY
                + " 朝向 y=" + transform.eulerAngles.y.ToString("0")
                + " 速度=" + (move != null ? move.CurrentSpeed.ToString("0.00") : "?")
                + " 移动组件启用=" + (move != null && move.enabled));
        }

        // 功能：每帧把玩家贴到地面（地形有起伏，不贴会浮空/陷地）。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 从玩家上方往下打一条射线（收集全部命中）
        //   2) 跳过玩家自己身上的碰撞体（手里的剑有一个 BoxCollider，摆姿势时会被打到，角色就会往上跳一下又落回来）
        //   3) 取最近的有效命中点，把 y 设成它（保留 x/z）
        // 上游：Unity
        // 下游：Transform.position
        // 注意：只改 y；水平移动仍由 PlayerMove 负责
        private void LateUpdate()
        {
            if (m_player == null)
            {
                return;
            }

            LogDiagnostics();

            // 有 PlayerJumpMotor 时贴地归它管（它要同时处理起跳高度与落地），这里不能抢着写 y
            if (m_jumpMotor != null)
            {
                return;
            }

            Vector3 origin = m_player.position + Vector3.up * m_probeHeight;
            int count = Physics.RaycastNonAlloc(origin, Vector3.down, m_groundHits, m_probeDistance, m_groundMask, QueryTriggerInteraction.Ignore);

            bool found = false;
            float nearest = float.MaxValue;
            RaycastHit ground = default;

            for (int i = 0; i < count; i++)
            {
                RaycastHit hit = m_groundHits[i];
                if (hit.collider == null)
                {
                    continue;
                }

                Transform hitTransform = hit.collider.transform;
                if (hitTransform == m_player || hitTransform.IsChildOf(m_player))
                {
                    continue;
                }

                if (hit.distance < nearest)
                {
                    nearest = hit.distance;
                    ground = hit;
                    found = true;
                }
            }

            if (!found)
            {
                return;
            }

            float previousY = m_player.position.y;
            Vector3 position = m_player.position;
            position.y = ground.point.y;
            m_player.position = position;

            if (m_logGroundSnap && Mathf.Abs(ground.point.y - previousY) > 0.01f)
            {
                Debug.Log("[贴地] y " + previousY.ToString("F3") + " -> " + ground.point.y.ToString("F3")
                    + "（命中 " + ground.collider.name + "，layer=" + ground.collider.gameObject.layer + "）", this);
            }
        }
    }
}
```

> **为什么换成 Mixamo（2026-11-15 返修）**：原 UnityChan `JUMP01`/`JUMP00` 是整段动作，被 2.5 倍速截断后只剩"一小段定格姿势"，观感发僵。
> 换成 Mixamo 的 `Jump` / `Falling` / `Falling To Landing` 后，用 `speed=1.0` 播真实节奏，靠 offset 只取需要的片段。
>
> **offset 怎么定**：读 clip 里根节点 `RootT.y` 的关键帧——`Mixamo_Jump` 在 0.90 秒到最高点 1.273、0.33 秒是下蹲最低 0.705，脚离地大约在 0.50 秒，所以 offset 取 0.30（0.30 × 1.667 ≈ 0.50 秒）。
> `Mixamo_FallingToLanding` 在 0.40 秒触地（`RootT.y` 0.643）、0.53 秒压到最低 0.609，所以 offset 取 0.33（0.33 × 1.067 ≈ 0.35 秒），再用 1.6 倍速把 0.32 秒的尾段压进 0.2 秒缓冲。
>
> **导入设置**：三份 fbx 都是 `Animation Type = Human` + `Avatar Definition = CreateFromThisModel`（Mixamo 骨骼名标准，Unity 自建 Avatar），勾 `Bake Into Pose` 的 `Root Transform Position (Y)` / `Rotation`，取消 `Based Upon` 的 `Original` 两个勾（即 `keepOriginalPositionY=false`、`keepOriginalOrientation=false`），这样根位移烘进姿势、不会和代码算的 `position.y` 叠加。

## 10. 返修记录（2026-11-15）

上文第 5 节嵌的是首版代码；这一节记录之后的返修，看代码以仓库里的文件为准。

### 10.1 跳高 0.9 米改 1.2 米

负责人反馈「跳起来高度不够」，弹窗决定改成 **1.2 米 / 约 0.99 秒**（重力 9.8）。

- `Client/Assets/_Project/Game/Player/PlayerJumpMotor.cs` 的 `m_jumpHeight` 默认值改 `1.2f`，Inspector 可继续调。
- 物理自洽：`v = 根号(2 * 9.8 * 1.2) ≈ 4.85 米/秒`，滞空 `2v/g ≈ 0.99 秒`。
- EditMode 用例仍按 0.9 米断言（用自己传的参数，不受默认值影响）。

### 10.2 下落/落地时下半身陷进地面

现象：按 Space 跳，下落或落地后角色下半身像插进地面。第一版「按脚骨骼对齐」的上限写成 0.8 米，实测下沉量超过它，每帧被跳过，等于没生效。

第二版改动（同一个文件）：

1. `m_alignFeetToGround`（默认开）、`m_alignMaxOffset`（默认 2 米）、`m_alignDeadZone`（默认 5 毫米）三个 Inspector 字段。
2. `LateUpdate`：只在贴地（含落地缓冲）时工作；`Animator` 还没初始化就下一帧再来。
3. `TryCalibrateSole`：量一次「脚骨骼比所有渲染器最低点高多少」，存进 `m_soleOffset`。
4. `AlignFeetToGround`：算两只脚较低的那只减鞋底偏移，得到脚底高度；差值小于死区或大于上限就跳过，否则把 `transform.y` 平移过去。
5. 日志：`[PlayerJumpMotor] 贴地修正 x.xxx 米（地面 …，脚底 …，鞋底偏移 …）`，每 0.3 秒最多一条；落地日志补 `脚骨 / 胯 / 鞋底偏移` 三个数字。

判据：落地缓冲那 0.2 秒里，Console 不再连续刷「贴地修正」，且角色脚底与地面齐平。

### 10.3 已知边界

- 鞋底偏移靠一次采样，换模型或换动画后要重新校准。
- 只在 `Grounded` 时对齐；空中不做，避免把跳跃高度也"贴"掉。
- 若日志显示「地面」值本身不对（例如探到的是剑或别的碰撞体），要查 `ProbeGround` 的过滤，不是这套对齐。
### 10.4 真根因：根 Y 被烘进姿势（不是对齐上限）

落地日志实据（负责人 2026-11-15 12:32 提供）：`地面高度 1.414 米，脚骨 0.554 米，胯 1.376 米`。脚骨比根节点低 0.86 米、胯几乎与根齐平 —— 这不是「深蹲」，是**整个身体被压到原点以下 0.86 米**。

原因在导入设置：三条 Mixamo clip 一开始把 `Root Transform Position (Y)` 也勾了 `Bake Into Pose`，clip 自带的根 Y 曲线（`Mixamo_FallingToLanding` 从 1.561 掉到 0.609）被烘进姿势，身体就跟着曲线往下走；代码又把角色根节点按物理高度钉在地面，两者叠加 = 半身入地。

修法：把三条 clip 的 `Root Transform Position (Y)` 改回**不勾**（`lockRootHeightY=false`、`keepOriginalPositionY=true`），`Root Transform Rotation` 仍勾；`applyRootMotion=false` 让根 Y 曲线被丢弃，竖直高度只由 `PlayerJumpMotor` 算。

改完实测（`AnimationMode` 采样脚骨相对原点）：`Mixamo_Jump` 最低 0.034 米、`Mixamo_Falling` 最低 -0.124 米、`Mixamo_FallingToLanding` 最低 -0.011 米 ⇒ 最坏 12 厘米，10.2 的脚底对齐足够兜住。

顺带修：重设 clip 时 `defaultClipAnimations[i].name` 必须显式写回 `Mixamo_Jump` 等名字、`loopTime` 也要重写，否则 Unity 会用 take 名 `mixamo.com` 覆盖、并把 `Falling` 的循环关掉。

### 10.5 定向跳跃：按方向键 + Space 朝那个方向跳

负责人 2026-11-15 的要求：想往某个方向跳，就同时按方向键和跳跃键。设计上沿用「空中不能改向」的决策——**方向在起跳那一帧算好并锁死**，空中只沿这个方向飞、并平滑转身面向它。

三个文件的改动：

1. `Client/Assets/_Project/Game/Player/PlayerMove.cs`：把 `Update` 里「方向键 → 世界方向」的换算抽成 `public Vector3 GetMoveDirection(float x, float z)`（含相机轴压平、前/右主导轴、世界轴兜底），`Update` 自己改为调用它；这样跳跃可以直接复用同一套换算，不会出现「走的方向」和「跳的方向」两套算法。
2. `Client/Assets/_Project/Game/Player/PlayerJumpMotor.cs`：
   - 新增 `m_airDirection`（世界空间单位向量）、`m_airSpeed`（米/秒，0 表示原地跳）、`m_airTurnSharpness`（默认 12，空中转身收敛速度）。
   - 新增 `public void SetJumpDrift(Vector3 worldDirection, float speedMetersPerSecond)`：压平 y、归一化；零向量或速度非正就清成原地跳。
   - `Step` 里在算出竖直位置后叠加水平漂移 `position += m_airDirection * (m_airSpeed * deltaSeconds)`，并用 `Quaternion.Slerp(..., 1 - exp(-sharpness * dt))` 转身；落地那一帧 `m_airSpeed = 0`。
3. `Client/Assets/_Project/Game/Player/PlayerBrain.cs`：
   - 新增 `m_jumpDriftMinSpeed`（默认 2 米/秒）：站着按方向起跳也给一个最小水平速度，避免「按了方向却几乎原地跳」。
   - 跳跃分支改成 `if (Input.GetKeyDown(m_jumpKey) && m_jumpMotor.TryJump()) { ApplyJumpDirection(input); }`——只有起跳真的成功才锁方向，被动作/硬直拒绝时不改电机状态。
   - `ApplyJumpDirection`：无方向输入直接返回；有输入就调 `m_move.GetMoveDirection(input.MoveX, input.MoveY)` 拿「走路会走的方向」，速度取 `Mathf.Max(当前地面速度, m_jumpDriftMinSpeed)`。

为什么锁在起跳那一帧：Unity 的角色控制器一旦在空中接受转向，就会出现「原地转圈」的手感；锁死方向既符合「惯性」直觉，也让状态机不必在空中处理朝向，测试里可以直接断言「空中给方向输入，位置只按锁定方向变化」。

第一版踩的坑（2026-11-15 负责人反馈「跳跃方向不对」）：`ApplyJumpDirection` 当时自己拼 `reference.forward * MoveY + reference.right * MoveX`，而 `PlayerMove` 的兜底是「`m_reference` 为空就用 `Camera.main`」——两处兜底不一致，场景里 `m_reference` 是空的，于是走路用相机轴、跳跃退回世界轴。现在统一走 `GetMoveDirection`，这条分支差异被删掉了。
