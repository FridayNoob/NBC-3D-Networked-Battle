# R035d 跳跃下落 —— 02 需求

需求编号：R035d
所属阶段：M4
作者：AI 辅助
状态：草稿

## 1. 业务目标（一句话）

在 World 里按 `Space`，角色真的跳起来、约 0.99 秒后落回地面，动画跟着起跳 / 滞空 / 落地，落地 0.2 秒内不能移动。

## 2. 用户与场景

- 场景一：玩家在 World 里走/跑，按 `Space` 起跳，看到角色离地、地面在脚下变远。
- 场景二：空中按 A/D 或 W/S，角色方向不变（起跳瞬间锁死），落地后恢复控制。
- 场景三：空中按 J/Q 等动作键，不响应（动作层不能在空中插播）。
- 场景四：落地瞬间有 0.2 秒落地缓冲，按 W 也不动，之后正常跑。

## 3. 功能列表

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0 | 起跳 | `Space`，跳高 1.2 米，滞空约 0.99 秒 |
| P0 | 重力下落 | 上升速度按 9.8 米/秒² 递减，到顶转负 |
| P0 | 落地判定 | 射线探地，落地那帧贴回地面 |
| P0 | 三态动画 | `S_Jump`（JUMP01）→ `S_Fall`（JUMP00）→ `S_Land`（JUMP00 尾段） |
| P0 | 空中禁移动 | 离地期间水平速度为 0；着陆方向在起跳瞬间锁死 |
| P0 | 落地缓冲 | 12 帧（0.2 秒）不能移动，然后回移动层 |
| P1 | 诊断日志 | 起跳/落地各打一行（含地面高度），可关 |

## 4. 边界（不做什么）

1. **不做二段跳 / 跳跃高度蓄力**（R035d 只做单次固定高度）。
2. **不做空中技能 / 空中攻击**（动作层在空中一律拒绝）。
3. **不做服务器同步**：跳跃只是 World 单机表现，Battle 的权威位移不受影响。
4. **不改美术包的 clip 与 fbx**：只读 UnityChan 的 JUMP00/JUMP01 并重定向。
5. **不做斜坡特殊处理**：地面高度取射线命中点，斜面上直接贴。

## 5. 优先级

P0 全部完成后才能进 06 手工验收；P1 只是一行日志，验收时用来确认"落到了哪个高度"。

## 6. 验收标准（当…时，应…）

| # | 当…时 | 应… |
| --- | --- | --- |
| 1 | 站在地上按 `Space` | 角色离地，Console 出现「起跳，目标高度 1.20 米」 |
| 2 | 起跳后看 Inspector | 约 0.5 秒到最高点（1.2 米），再约 0.5 秒落地 |
| 3 | 空中按 W/A/S/D | 方向不变（仍沿起跳瞬间锁定的方向飞），状态停在 Jump/Fall |
| 4 | 空中按 J / Q / E / R / F | 不进入攻击/技能/姿势（状态仍是 Jump/Fall） |
| 5 | 落地瞬间 | Console 出现「落地，地面高度 …」，状态短暂变 `Land` |
| 6 | 落地后 0.2 秒内按 W | 角色不动；0.2 秒后恢复跑 |
| 7 | 落地后看 Animator | `S_Jump` → `S_Fall` → `S_Land` → `S_Locomotion`，无 T-pose 闪 |
| 8 | 站在地上按 `Space` 时正在播攻击 | 不起跳（动作优先） |
| 9 | 死亡后按 `Space` | 不起跳 |
| 10 | 控制器副本 | 参数 50（多 `Landing`）、状态 44（多 3 个）、AnyState 65（多 3 条） |
| 11 | 连续跳 10 次 | 每次都回到同一地面高度，不累积漂移 |
| 12 | 站着按住 W（或 W+A 等方向）再按 `Space` | 朝该方向跳（水平约 2 米/秒），空中方向不再改变，落地后可继续朝该方向跑 |
| 13 | 跑动中按住 W 再按 `Space` | 水平速度取起跳瞬间的移动速度（Run 约 5 米/秒），跳出去的距离明显比站着跳远 |
