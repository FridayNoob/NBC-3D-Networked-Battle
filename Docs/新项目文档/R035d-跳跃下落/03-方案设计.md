# R035d 跳跃下落 —— 03 方案设计

需求编号：R035d
所属阶段：M4
作者：AI 辅助
状态：草稿

## 1. 整体架构

```
Space ──► PlayerBrain ──► PlayerJumpMotor.TryJump ──► PlayerVerticalMotion.Jump
                              │                            │
                              ▼                            ▼
                        PlayerStateMachine.NotifyJump   VerticalSpeed = 根号(2gh)
                              │
每帧：PlayerJumpMotor.Step ──► 探地 + 积分高度 + 写 transform.y
                              │
                              ▼
                 PlayerStateMachine.SetVertical(Grounded, VerticalSpeed)
                              │
                              ▼
                 ChooseLocomotion：Jump / Fall / Land / 地面档位
                              │
                              ▼
                 PlayerAnimatorPublisher ──► Animator（S_Jump / S_Fall / S_Land）
```

## 2. 模块划分

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| `PlayerVerticalMotion` | 重力积分、最高点、落地判定、`JustLanded` | 不碰 Transform、不读 Time |
| `PlayerJumpMotor`（MonoBehaviour） | 探地、写 `transform.y`、起跳入口、回报状态机 | 不决定状态、不管水平移动 |
| `PlayerStateMachine` | 按竖直状态选 Jump/Fall/Land、落地缓冲帧数、禁移动 | 不算物理、不碰 Transform |
| `PlayerAnimatorPublisher` | 多发一个 `Landing`(bool) | 不做判断 |
| `WorldPlayerSetup` | 有电机时不再贴地（让位） | 不参与跳跃逻辑 |
| 控制器副本 | 三个状态 + 三条过渡 + `Landing` 参数 | 不改美术包 |

## 3. 接口（方法 + 入参 + 出参 + 约定）

```csharp
public sealed class PlayerVerticalMotion
{
    public const float DefaultGravity = 9.8f;
    public float VerticalSpeed { get; }   // 米/秒，上升为正
    public float Height { get; }          // 离地高度，米
    public bool Grounded { get; }
    public bool JustLanded { get; }       // 只有落地那一帧为 true
    public PlayerVerticalMotion(float gravityMetersPerSecondSquared = DefaultGravity);
    public bool Jump(float heightMeters); // 只允许从地面起跳
    public void Step(float deltaSeconds); // 先减速度、再加高度
    public void ResetToGround();
}

public sealed class PlayerJumpMotor : MonoBehaviour
{
    public bool IsAirborne { get; }
    public void Bind(PlayerStateMachine machine);
    public bool TryJump();
    public void Step(float deltaSeconds);
}

// PlayerStateMachine 新增
public void SetVertical(bool grounded, float verticalSpeed);
public bool NotifyJump();   // 已死/动作中/格挡/落地缓冲/空中 → false
public bool NotifyLand();   // 死亡或已在缓冲 → false；否则开 12 帧缓冲
public bool Airborne { get; }
public bool Landing { get; }
```

约定：`PlayerVerticalMotion` 纯 C#（只 `System.Math`）；`PlayerJumpMotor` 是唯一写 `transform.y` 的地方（World）。

## 4. 数据结构

- `PlayerTimings` 新增 `LandFrames`（默认 12 帧 = 0.2 秒），构造从 12 参变 13 参。
- `PlayerStateContext` 新增 `Landing`（bool）。
- `PlayerAnimatorParams` 新增 `Landing`（bool），构造从 10 参变 11 参。
- `EPlayerState` 新增 `Land=10`（落在移动层区间，`LayerOf` 不用改）。

## 5. 时序与流程

1. `Update`：读输入 → 处理动作键 → `Space` 按下则 `TryJump()`。
2. `TryJump`：`motion.Jump(0.9)` 算初速度 → 状态机 `NotifyJump()`；状态机拒绝就 `ResetToGround()` 回滚。
3. 同帧 `Step(deltaTime)`：探地（跳过自己）→ 积分 → 写 `transform.y` → `SetVertical` → 落地则 `NotifyLand()`。
4. 状态机 `Tick`：先递减落地缓冲 → 蹲切换（只在落地时）→ 动作 → `ChooseLocomotion`：离地按 `VerticalSpeed` 选 Jump/Fall；`Landing` 选 Land；否则原四档。
5. 发布器把 `Landing` 与 `Grounded/VerticalSpeed` 一起写给 Animator。

## 6. 选型与理由

1. **物理驱动而不是整段 clip**：0.9 米/0.86 秒与重力自洽；整段 `JUMP01` 会变成 2 秒月球跳。
2. **三态而不是两态**：加 `Land` 才能把"落地缓冲"从"播放时长"里解耦，缓冲改帧数不用改 clip。
3. **电机单独一个组件**：`PlayerBrain` 已 500+ 行，竖直位移有自己的状态（groundY、缓冲）放进去会继续膨胀。
4. **`SetVertical` 由电机推、状态机只读**：方向单一，避免状态机反算物理。
5. **`WorldPlayerSetup` 让位而不是删除**：Battle 与旧场景没有电机，保留兜底。

## 8. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 起跳被贴地射线按回地面 | `WorldPlayerSetup` 见到 `PlayerJumpMotor` 直接 return |
| 探地打到手里的剑 | `RaycastNonAlloc` + 跳过自己与子物体 |
| 控制器过渡互相打架 | 回移动层两条过渡补 `Grounded=true`、`Landing=false`；跳跃过渡要求 `!Grounded` |
| 落地缓冲与动作冲突 | 缓冲只在移动层生效；动作优先，起跳也拒绝 |
| Humanoid 脚部偏移 | 落地仍以 `hit.point.y` 为准，`PlayerSkinnedMeshGuard` 兜包围盒 |
