# 01 技术预研

需求编号：R045
所属阶段：M4
作者：AI（DeepSeek）
状态：开发中

## 一、调研目标与约束

- 目标：从 `Login` 场景一路点进 `World`，中途不用打开编辑器窗口。
- 约束 1：只在 `Login` 场景做 UI，不改 `World`/`Battle` 的既有流程。
- 约束 2：连接仍走 `RuntimeNetDriver`（它能复用就不要另写一套网络）。
- 约束 3：本步不引第三方 UI 框架，沿用 `UIManager` / 运行时 UGUI。
- 约束 4：设置页只做占位（音量/画质留给 R047）。

## 三、最小可运行示例

```csharp
// 1) 点「开始游戏」：建一个常驻会话物体（和副本入口用的是同一套驱动）
var go = new GameObject("[MenuSession]");
Object.DontDestroyOnLoad(go);
RuntimeNetDriver driver = go.AddComponent<RuntimeNetDriver>();
driver.ConfigureSession("127.0.0.1", 7778, 1001);
driver.AutoJoin = false;          // 主菜单阶段不进房
driver.BindPresentation = false;  // 也不接管表现层
// 2) 等 IsOnline 为真再切场景，失败就把 FailureReason 显示在按钮下方
SceneFlow.Instance.LoadAsync(GameScene.World);
```

## 四、方案对比

| 方案 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A 运行时 UGUI**（采用） | 代码建 Canvas + 按钮 + 输入框 | 零资源依赖、和 R041 黑幕一致 | 美术不能在 Inspector 调 |
| B 预制体 + `UIManager` | 做 `MainMenuPanel.prefab` 进 `ui` 组 | 可视化调、可复用 | 要先有面板资产与地址，R046 才做 |
| C 第三方 UI 框架 | 引入新库 | 功能全 | 违反规则 12（已有底座） |

连服时机对比：主菜单连（当场报错）/ 进副本才连（现状，问题发现晚）/ 启动就连（失败也要弹窗）。采用**主菜单点开始时连**。

## 五、已知坑与版本兼容

1. `UIManager.ShowPanel` 依赖 YooAsset，本步不用它，避免「地址没配好 → 黑屏」。
2. `RuntimeNetDriver` 默认 `AutoJoin=true`，主菜单阶段必须关掉，否则一连上就进房。
3. 场景里的 `RuntimeNetDriver` 会被 `DontDestroyOnLoad` 带进 `World`，而 `DungeonEntrance` 会 `Find` 复用同一份 —— 不建第二个。
4. 编辑器内 `SceneFlow` 走 `SceneManager`（R052 已修），`Login → World` 不依赖资源包。
5. 昵称走握手，改名字要在**建会话之前**定下来，连上之后改不了。

## 六、结论

- 采用 A：`Login` 场景里一个 `MainMenuController` + 运行时 UGUI（标题、昵称输入、剑士卡片、开始/设置/退出）。
- 点「开始游戏」→ 建 `[MenuSession]`（常驻）+ 连服 → 成功切 `World`，失败把原因落在按钮下方。
- 设置页先做占位面板，写明「音量/画质在 R047」。
- 预估 380 行（控制器 240 + 面板 120 + 测试 20）。
