# 06 手工验收

需求编号：R045
所属阶段：M4
作者：AI（DeepSeek）
状态：开发中

## 一、计划

- 正常：打开 Login → 改名 → 点开始 → 进 World。
- 异常：空昵称、连点开始、服务端没开。
- 边界：昵称 12 字上限、失败后重试。
- 性能：点开始到切场景的耗时（正常应在 1 秒内）。

## 二、正常流程走查

| # | 步骤 | 判据 |
| --- | --- | --- |
| 1 | 打开项目，双击 `Client/Assets/_Project/Scenes/Login.unity` | Hierarchy 里有 `[MainMenu]`，Inspector 里 `MainMenuController` 不是 Missing |
| 2 | 直接 Play（不动鼠标） | 屏幕中央出现标题、昵称框（默认「玩家」）、剑士卡片、三个按钮 |
| 3 | 在昵称框里改成「狼王」 | 输入框显示「狼王」，不超过 12 字 |
| 4 | 确认服务端已启动（`NBC.Server.Host.exe --dev-accounts`） | 服务端窗口有「已就绪，监听 7778」 |
| 5 | 点「开始游戏」 | 按钮变灰、文案变「连接中…」，下方提示「正在连接服务器…」 |
| 6 | 等待 | 1 秒内切到 World 场景，角色出现在村口，Console 有 `[MainMenu] 已连上服务器` |
| 7 | 关闭客户端再打开 Login | 昵称框里还是「狼王」（PlayerPrefs 记住） |

## 三、异常场景

| # | 操作 | 期望 |
| --- | --- | --- |
| 1 | 清空昵称后点开始 | 以「玩家」进入，不报错 |
| 2 | 快速连点 3 次「开始游戏」 | 只建一个会话，Console 里只有一条「正在连接服务器…」 |
| 3 | 不启动服务端就点开始 | 3 秒内按钮恢复、提示写明「连不上服务器（127.0.0.1:7778）」或服务端返回的具体原因；**不切场景** |
| 4 | 失败后改昵称再点开始 | 提示被清空、重新走一次连接；旧会话物体已销毁（Hierarchy 只有一个 `[MenuSession]`） |

## 四、性能

| 指标 | 目标 |
| --- | --- |
| 点开始 → 切场景 | ≤ 1 秒（本机） |
| 失败超时 | 3 秒（`m_connectTimeoutSeconds`） |
