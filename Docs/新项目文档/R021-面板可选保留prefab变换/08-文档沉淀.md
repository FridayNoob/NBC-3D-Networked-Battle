## 二、模块文档

### 简介与使用场景

`UIManager.ShowPanel("名字")` 打开面板时，会把面板实例挂到对应 UI 层，并**默认把它的 RectTransform 铺满**。
若某个面板希望**保留 prefab 里摆好的位置与尺寸**（典型：HUD 小面板），在该面板 prefab 的**根节点**加一个
`KeepPrefabTransform` 组件即可 —— `UIManager` 见到它就只挂载、不归零。

### 挂载时到底做了什么

| 步骤 | 行为 | 备注 |
| --- | --- | --- |
| 1 | 检查根节点是 `RectTransform` | 不是就抛异常（3D 物体不能当 UI 面板） |
| 2 | `rect.SetParent(parent, false)` | **永远这么传**：默认参数会反算 `localScale`，UI 被拉变形 |
| 3 | 有 `KeepPrefabTransform` ⇒ **结束** | prefab 的 anchoredPosition/sizeDelta 原样保留 |
| 4 | 没有 ⇒ `localPosition=0`、`localScale=1`、`offsetMin/Max=0` | 全屏面板自动铺满 |

### 什么面板该挂

| 该挂 | 不该挂 |
| --- | --- |
| 固定在屏幕某处的 HUD：血条、小地图、技能栏、飘窗提示 | 全屏面板：背包、设置、断线提示 |

### 排查「位置不对」三步

1. 看 prefab 根节点有没有 `KeepPrefabTransform` —— 没挂就会被归零。
2. 看面板锚点是不是 `anchorMin == anchorMax` —— 这种（非拉伸）锚点下，`offset=0` 会连 `sizeDelta` 一起清零。
3. 看是不是挂了标记却仍被撑满 —— 检查是不是挂到了**子物体**而不是根节点（只认根）。

## 三、踩坑清单（现象 / 原因 / 解决）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| Play 后面板位置/尺寸与 prefab 不同 | 框架默认归零铺满 | 根上加 `KeepPrefabTransform` |
| 挂了标记还是被撑满 | 组件挂在子物体上 | 挂到**根节点** |
| 面板被拉扁/变形 | 有人把 `SetParent` 改成默认参数 | 必须传 `worldPositionStays: false` |
| 全屏面板停在小位置 | 给全屏面板误挂了标记 | 去掉标记 |
