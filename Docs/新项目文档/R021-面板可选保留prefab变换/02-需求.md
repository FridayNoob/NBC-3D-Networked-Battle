# 02 需求

需求：R021-面板可选保留 prefab 变换
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-11-06）

## 一、业务目标（一句话）

**HUD 类小面板能保留 prefab 里摆好的位置与尺寸**，不再被 `UIManager` 归零。

## 二、用户与使用场景

- 用户：开发期负责人（调 UI 的人）。
- 场景：在 prefab 里把血条 HUD 摆到左下角 `(125.6, -83.5)`，Play 后**就该在那个位置**，数值与 prefab 一致。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| `KeepPrefabTransform` 标记组件 | P0 | 挂在面板根上即生效（opt-in） |
| `UIManager` 见到标记就跳过归零 | P0 | 只跳过 position/scale/offset，**保留 `SetParent(parent,false)`** |
| 给 `HpBarPanel` 挂上标记 | P0 | 让血条 HUD 立刻受益 |
| 全局默认行为不变 | P0 | 没挂标记的面板照旧归零铺满 |
| 按分辨率自适应 | P2 | 不做（HUD 固定尺寸是预期） |

## 四、边界（**本版明确不做**）

- 不改 `SetParent(parent, false)` 这条（防 UI 拉变形）。
- 不做「按百分比自动摆位」之类的布局系统。
- 不改其它面板的 prefab。

## 五、优先级

**P0**。依赖：无（框架层小改动），但影响所有面板的挂载逻辑，需回归。

## 六、验收标准（「当…时，应…」）

- [ ] 当 `HpBarPanel` 打开时，其根 `anchoredPosition` 应等于 prefab 的 `(125.6, -83.5)`、`sizeDelta` 等于 `(330, 2)`
- [ ] 当 其它未挂标记的面板打开时，仍应按原行为归零铺满（`anchoredPosition (0,0)`）
- [ ] 当 面板被复用（池中复活）时，保留行为同样生效
- [ ] 当 面板挂载时，`localScale` 不应被 `SetParent` 反算成奇怪的值（必须仍是 1）
- [ ] 当 屏幕分辨率变化时，HUD 保持固定尺寸（不拉伸）
