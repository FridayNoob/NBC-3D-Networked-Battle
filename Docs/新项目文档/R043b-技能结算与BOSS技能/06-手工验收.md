## 二、正常流程走查

1. 停掉服务端 → `dotnet build Server\NBC.Server.Host\NBC.Server.Host.csproj -m:1` → 重启（**必须重编**，新协议与技能系统都在服务端）。
2. Unity 里 Play → 主菜单点「开始游戏」→ 按 E 进副本。
3. 靠近一只狼（约 1.5 米），按 **Q**。
4. 看三处：
   - 狼头顶血条掉一大截（300 血直接没）；
   - Console 有 `[技能] 请求释放 2001 → 单位 N`；
   - 服务端控制台有 `玩家 1 释放技能 2001 → 单位 N（客户端第 X 帧发起）`。
5. 再按一次 Q：狼已死或冷却中，服务端打「技能 2001 还没冷却好（还剩 182 帧）」。
6. 走向狼王（6003），站着别动 4 秒：英雄掉约 580（旋风斩 500 + 上挑斩 80），服务端日志出现两条「释放技能」；旁边野狼的突进斩（120）可能也一起打上来，那不算 BOSS 的。

## 三、异常场景

| 现象 | 先看什么 | 判据 |
| --- | --- | --- |
| 按 Q 完全没反应 | Console 有没有 `[技能] 请求释放` | 没有 ⇒ 动画没接下（正在出招/格挡/已死），不是协议问题 |
| 有请求、服务端没日志 | 服务端是否重编重启 | 旧服务端不认识 `skill_cast`，会当成未知消息丢掉 |
| 服务端拒绝「没有配置技能」 | `Hero.csv` 的 `skillIds` | 1001 应为 `"2001,2002,2003"` |
| 狼王不放技能 | `Monster.csv` 6003 的 `skillIds` | 应为 `"2001,2002"` |
| 冷却明显不对 | `Skill.csv` 的 `cooldownMs` | 6000ms ⇒ 182 帧 ≈ 6 秒 |
