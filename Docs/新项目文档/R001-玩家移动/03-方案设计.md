# 03 方案设计

需求：R001-玩家移动
所属阶段：M4
作者：AI 起草，LYF 确认　状态：已确认（2026-10-26）

## 一、整体架构

表现层两个独立组件，互不引用：`PlayerMove`（把按键变成位移）→ 改自身 Transform；
`FollowCamera`（读角色 Transform 决定机位）→ 改相机 Transform。逻辑层、网络层本需求不涉及。

## 二、模块划分

| 模块（类） | 负责什么 | **不负责**什么 |
| --- | --- | --- |
| `PlayerMove` | 读键、算方向、转身、位移 | 不管相机、不管碰撞、不管网络 |
| `FollowCamera` | 算机位、平滑跟随、看向角色 | 不读按键、不改角色 |

## 三、接口（★ 先定死，代码必须与此逐字一致）

```
PlayerMove : MonoBehaviour
    Update()          -> void        无入参；引擎每帧调用；不抛异常
    字段 m_moveSpeed  -> float       默认 5     单位 米/秒
    字段 m_turnSpeed  -> float       默认 720   单位 度/秒

FollowCamera : MonoBehaviour
    LateUpdate()      -> void        无入参；引擎在 Update 之后调用；不抛异常
    字段 m_target     -> Transform   默认 空（Inspector 拖入）
    字段 m_offset     -> Vector3     默认 (0, 4, -6)  单位 米
    字段 m_smooth     -> float       默认 8          无单位（Lerp 系数倍率）
```

## 四、数据结构

| 数据 | 类型 | 含义 / 单位 | 谁改它 |
| --- | --- | --- | --- |
| `transform.position` | Vector3 | 世界坐标，米 | `PlayerMove.Update`（角色）/ `FollowCamera.LateUpdate`（相机） |
| `transform.rotation` | Quaternion | 朝向 | `PlayerMove.Update` |
| `InputCommand.MoveX/MoveY` | int | -1000..1000 的量化轴（÷`MoveScale` 得 -1..1） | `InputManager.Tick` |
| `m_moveSpeed` | float | 米/秒 | Inspector |
| `m_turnSpeed` | float | 度/秒 | Inspector |
| `m_offset` | Vector3 | 相对角色的偏移，米 | Inspector |

## 五、时序与流程

1. `InputManager` 每帧自己 `Tick` 一次（挂 `MonoManager`），把采集结果写进 `Current`。
2. 引擎调 `PlayerMove.Update`：读 `InputManager.Current` → 还原轴 → 零判断 → 归一化 → 转身 → 位移。
3. 引擎再调 `FollowCamera.LateUpdate`：读角色**新**位置 → 算目标机位 → Lerp → LookAt。
4. `FollowCamera` 只读角色 Transform，不反向写；两者可独立替换。

## 六、技术选型与理由

| 选择 | 选定 | 理由 | 被否的方案 |
| --- | --- | --- | --- |
| 移动方式 | 直接改 Transform | 第一版无碰撞需求，行为可预测 | Rigidbody（惯性难调）、CharacterController（复杂度高） |
| 输入 | **A7 输入框架**：`InputManager.Tick` → `InputCommand`，`PlayerMove` 只读 `Current` | 键位可改（`InputMapping`）、可注入假源测试、与网络 `SendInput` 同一套量化 | `Input.GetAxis`（自带平滑，与「松手即停」冲突）、直读 `Input.GetKey`（绕过框架、键位写死） |
| 跟随时机 | `LateUpdate` | 拿得到角色移动后的位置 | `Update`（慢一帧，会抖） |

## 七、风险与对策

- 无碰撞会穿墙掉出地面 ⇒ 本版接受，做地形时换 `CharacterController`。
- `GetKey` 依赖旧输入系统 ⇒ 切 New Input System 时把读键两行换成 `Keyboard.current`。
- 相机 Lerp 系数随帧率变化 ⇒ 系数乘 `Time.deltaTime` 并 `Clamp01`。
