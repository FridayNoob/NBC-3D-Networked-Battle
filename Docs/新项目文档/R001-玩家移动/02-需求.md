# 02 需求

需求：R001-玩家移动
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-10-26）

## 一、业务目标（一句话）

**让玩家能用自己的手控制角色在世界里走动** —— 后面所有战斗、任务、联机需求都以它为基础。

## 二、用户与使用场景

- 用户：开发期的负责人（单人本地）；最终面向上 PC 玩家。
- 场景：进战斗场景后，用键盘走到想看的位置；后续需求（打怪、进副本）都从这一步开始。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 键盘移动（W/S/A/D + 方向键） | P0 | 必须 |
| 转身朝向移动方向 | P0 | 必须，否则像横着平移 |
| 第三人称相机跟随 | P0 | 必须，否则看不到人在哪 |
| 斜向移动速度一致 | P1 | 归一化即可满足 |
| 鼠标转视角 | P2 | 本版不做，见边界 |
| 走路动画 | P2 | 单独开需求 |

## 四、边界（**本版明确不做**）

- 不做碰撞与围栏：走出地面会掉下去，本版允许。
- 不做多角色：只有一个可控角色。
- 不做鼠标转视角、不做手柄、不做移动端摇杆。
- 不做跳跃、冲刺、下蹲。
- 不做动画与脚步声。
- 不接网络：位置只存在本机。

## 五、优先级

**P0**（没有它后续角色相关需求都无法验收）。依赖：无。

## 六、验收标准（「当…时，应…」）

- [ ] 当 按住 W 时，角色应朝屏幕里侧移动，相机在其后上方跟随
- [ ] 当 按住 A 或 D 时，角色应朝左/右移动，且身体转向该方向（不是平移）
- [ ] 当 松开所有按键时，角色应在 0.1 秒内停住，不滑行
- [ ] 当 同时按 W + D 时，移动速度不应明显快于单按 W
- [ ] 当 连续走 1 分钟时，角色 y 应保持 1（不下沉、不飞天）
