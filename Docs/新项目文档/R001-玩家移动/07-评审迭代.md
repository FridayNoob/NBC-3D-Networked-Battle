## 八、教训（可复用判据）

1. **写表现层代码前，先搜项目里已有的同类框架**（输入 / 音频 / 资源 / 事件），别自造一套。
   判据：新代码里出现 `Input.`、`Resources.`、`Camera.main` 这类直连引擎 API 时，先问「框架层有没有等价入口」。
2. **交付物的定义是「对方能读懂并签字」**，不是「文件已经在磁盘上」。
   判据：如果对方必须打开另一个文件才能看懂这一步，那就是黑盒。
