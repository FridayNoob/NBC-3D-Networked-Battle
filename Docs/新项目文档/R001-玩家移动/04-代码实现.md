## 一、子任务与设计约束

- 本单元：`PlayerMove.Update` 与 `FollowCamera.LateUpdate` 两个回调（不越界到别的类）
- 约束：**必须走 A7 输入框架**（`InputManager` / `InputCommand`），不直读 `Input`；可调参数一律 `[SerializeField]`；注释按 `csharp-code-comment`

## 二、功能概述

两个脚本各管一件事：`PlayerMove` 把按键变成位移与转身；`FollowCamera` 让相机待在角色斜后方并看向它。
不做物理、不做动画、不联网。

## 三、接口与入参出参

| 单元 | 入参 | 出参 | 异常 |
| --- | --- | --- | --- |
| `PlayerMove.Update` | 无（引擎每帧调用） | 无；副作用是改 `transform.position` 与 `rotation` | 不抛 |
| `FollowCamera.LateUpdate` | 无（引擎在 Update 之后调用） | 无；副作用是改相机自身位置与朝向 | 不抛 |

字段：`m_moveSpeed`（米/秒，默认 5）、`m_turnSpeed`（度/秒，默认 720）、
`m_target`（跟谁）、`m_offset`（相对位置，默认 0,4,-6）、`m_smooth`（跟随顺滑，默认 8）。

## 四、逐段讲解（完整代码在第五节）

1. **取命令**：`InputManager.Instance.Current` 是每帧由框架 Tick 出来的 `InputCommand`，轴已经是 -1000..1000。
   不直读 `Input` 的原因：键位要能改（`InputMapping`）、要能注入假输入做测试、且与网络同一套量化。
2. **还原轴**：`MoveX / MoveScale`（1000）得到 -1..1；**零方向提前 return**，否则转身会把朝向强行设成默认方向。
3. **归一化**：`Normalize()` 把长度压成 1；W+D 长度是 1.41，不压就比直走快 41%。
4. **转身**：`LookRotation(方向)` 得到目标朝向，`RotateTowards` 每帧最多转 `m_turnSpeed * deltaTime` 度。
5. **位移**：`方向 * m_moveSpeed * deltaTime`；deltaTime 是上一帧秒数，乘它才是每秒 5 米。
6. **机位**：`target.position + target.rotation * offset` —— 偏移量随角色朝向转，所以转身时相机绕到背后。
7. **跟随**：`Lerp(当前, 目标机位, Clamp01(m_smooth * deltaTime))`，系数钳在 0~1 防过冲。

`Client/Assets/_Project/Game/Player/PlayerMove.cs`

```csharp
// 这个文件里有：
//   PlayerMove（类）：把 InputManager 产出的输入命令变成角色的移动与转身

using NBC.Framework.Input;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧读 InputManager 的当前命令，把量化轴还原成方向，转身并位移。
    // 主要数据成员：m_moveSpeed（米/秒）、m_turnSpeed（度/秒）。
    // 主要外部方法：无，只有 Unity 的 Update 回调。
    // 谁在用它：挂在角色物体上；输入取自 InputManager.Instance.Current，键位在 InputMapping 里可改。
    public sealed class PlayerMove : MonoBehaviour
    {
        // 每秒走多少米。场景里 1 单位 = 1 米，5 就是每秒 5 米
        [SerializeField] private float m_moveSpeed = 5f;

        // 转身速度，度/秒。720 约等于 0.2 秒转半圈，手感不拖
        [SerializeField] private float m_turnSpeed = 720f;

        // 入参：无（引擎每帧调用）
        // 返回：无
        // 步骤：
        //   1) 取 InputManager 单例；播放模式下它已经把 LegacyInputSource 装好，并每帧自己 Tick 一次
        //   2) 读 Current 的 MoveX / MoveY（已是 -1000..1000 的量化轴），除以 MoveScale 还原成 -1..1
        //   3) 方向是零就返回；不返回会把朝向强行转到默认方向
        //   4) 归一化；斜着走（W+D）不归一化会比直走快 1.41 倍
        //   5) 由方向求朝向，按 m_turnSpeed 限速转过去
        //   6) 位移 = 方向 乘 速度 乘 deltaTime
        // 上游：Unity 引擎每帧调用
        // 下游：InputManager.Current、Transform.rotation、Transform.position
        // 注意：这里不要再调 InputManager.Tick。它每帧已经自己 Tick 过一次，再调一次会打乱"刚按下/刚松开"的边沿判定
        private void Update()
        {
            InputManager input = InputManager.Instance;

            if (input == null || !input.IsEnabled)
            {
                return;
            }

            InputCommand command = input.Current;

            float x = (float)command.MoveX / InputCommand.MoveScale;
            float z = (float)command.MoveY / InputCommand.MoveScale;

            Vector3 direction = new Vector3(x, 0f, z);

            if (direction.sqrMagnitude < 0.0001f)
            {
                return;
            }

            direction.Normalize();

            Quaternion target = Quaternion.LookRotation(direction, Vector3.up);
            transform.rotation = Quaternion.RotateTowards(
                transform.rotation, target, m_turnSpeed * Time.deltaTime);

            transform.position += direction * (m_moveSpeed * Time.deltaTime);
        }
    }
}
```

`Client/Assets/_Project/Game/Player/FollowCamera.cs`

```csharp
// 这个文件里有：
//   FollowCamera（类）：相机保持在被跟随角色身后上方，并始终看向它

using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧算出相机该待的位置（角色斜后方），平滑追过去，再看住角色胸口高度。
    // 主要数据成员：m_target（跟谁）、m_offset（相对位置）、m_smooth（跟随顺滑程度）。
    // 主要外部方法：无。只有 Unity 的 LateUpdate 回调。
    // 谁在用它：挂在主相机上，Target 槽指向角色；由引擎每帧调用。
    public sealed class FollowCamera : MonoBehaviour
    {
        // 跟着谁：把角色拖进来。留空则不做事，不报错
        [SerializeField] private Transform m_target = null;

        // 相对角色的偏移：x 左右，y 高度，z 前后（负数表示在身后）
        [SerializeField] private Vector3 m_offset = new Vector3(0f, 4f, -6f);

        // 跟随顺滑程度：0 是死贴（会硬），越大越跟手，8 比较稳
        [SerializeField] private float m_smooth = 8f;

        // 入参：无（引擎每帧调用）
        // 返回：无
        // 步骤：
        //   1) 没设 Target 就返回，避免空引用刷屏
        //   2) 想要的机位 = 角色位置 + 按角色朝向旋转过的偏移；这样角色转身时相机绕到背后
        //   3) 用 Lerp 从当前机位追向目标机位，系数乘 deltaTime，避免帧率变化导致跟随速度不同
        //   4) 看向角色胸口高度（抬高 1.5 米），不要盯着脚
        // 上游：Unity 引擎每帧调用（在 Update 之后）
        // 下游：Transform.position、Transform.LookAt
        // 注意：必须用 LateUpdate。放 Update 会拿到角色移动前的位置，画面会抖一下
        private void LateUpdate()
        {
            if (m_target == null)
            {
                return;
            }

            Vector3 desired = m_target.position + (m_target.rotation * m_offset);

            transform.position = Vector3.Lerp(
                transform.position, desired, Mathf.Clamp01(m_smooth * Time.deltaTime));

            transform.LookAt(m_target.position + Vector3.up * 1.5f);
        }
    }
}
```

## 七、风险与幻觉自查

- 幻觉自查：`InputManager` / `InputCommand` / `InputCommand.MoveScale` 均存在于 `Framework\Input`（命名空间 `NBC.Framework.Input`），已逐个核对；其余只用 `UnityEngine`。无第三方库。
- 本版改动来源：审读意见 —— 原版直读 `Input.GetKey` 绕过了 A7 输入框架，已改为读 `InputManager.Current`。
- 会穿墙、会掉出地面：本版确认不做碰撞。
- `Input.GetKey` 属旧输入系统；工程若切到 New Input System 会全部失效。
- 相机 `Lerp` 系数是 `m_smooth * deltaTime`，编辑器帧率极低（<10fps）时会一顿一顿，属正常。
