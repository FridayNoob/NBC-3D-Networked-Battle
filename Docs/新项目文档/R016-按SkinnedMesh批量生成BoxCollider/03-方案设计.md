# 03 方案设计

需求：R016-按 Skinned Mesh 批量生成 BoxCollider
所属阶段：M4
作者：AI 起草　状态：已确认（2026-11-02）

## 一、整体架构

纯编辑器工具，**不进运行时**：

```
Project 里选中 N 个 prefab
        │  菜单 Tools/NBC/怪物/生成 BoxCollider（选中 prefab）
        ▼
MonsterColliderTool.BuildForSelection()
        │  逐个 prefab：
        ▼
PrefabUtility.EditPrefabContentsScope(path)      ← 自动保存
        ├─ 已有 Collider 或 Rigidbody ? → 跳过（日志「已有」）
        ├─ 收集 Renderer（含隐藏）→ 求本地 AABB
        ├─ 加 BoxCollider(center, size)（底面 = 模型最低点）
        └─ 加 Rigidbody(重力开、冻结旋转)
```

## 三、接口（★ 先定死）

```
静态类 MonsterColliderTool
    [MenuItem("Tools/NBC/怪物/生成 BoxCollider（选中 prefab）")]
    static void BuildForSelection()

    // 单个 prefab 的处理（便于以后给场景实例复用）
    static bool TryBuildForAsset(string prefabPath, out string message)

算法契约：
    1) 只接受 .prefab 资产路径；其它跳过
    2) 根上（GetComponent，不看子物体）已有 Collider 或 Rigidbody ⇒ 返回 false + 「已有」
    3) 收集 GetComponentsInChildren<Renderer>(true)，跳过 bounds.size == 0
    4) 8 角点 root.InverseTransformPoint → 本地 AABB → center / size
    5) BoxCollider 加在根上；Rigidbody 加在根上（useGravity、freezeRotation、!isKinematic）
日志契约：
    每个 prefab 一行：`[R016] <名字>：已生成 BoxCollider（尺寸 …）/ 跳过（已有碰撞体或刚体）/ 跳过（不是 prefab）/ 跳过（没有可用的 Renderer）`
    结尾一行：`[R016] 完成：成功 N，跳过 M`
```

## 四、数据结构

无（一次执行的临时数据；不写 ScriptableObject、不留配置）。

## 五、时序与流程

1. 取 `Selection.objects`；非 prefab 直接记「跳过（不是 prefab）」。
2. 对每个 prefab 路径开 `EditPrefabContentsScope`。
3. 根上查 `Collider` / `Rigidbody`：命中任一个 ⇒ 记「跳过（已有）」，不修改。
4. 求 AABB：世界 8 角点转本地。
5. 加 `BoxCollider`、加 `Rigidbody`，`EditorUtility.SetDirty(root)`。
6. scope 结束自动保存；最后打汇总。

## 六、技术选型与理由

| 选择 | 选定 | 理由 | 被否的方案 |
| --- | --- | --- | --- |
| 改 prefab 的方式 | **`EditPrefabContentsScope`** | 官方推荐、自动保存、不怕漏 `SaveAsPrefabAsset` | 手动 `LoadPrefabContents` + 手写保存（易漏） |
| 碰撞体 | **BoxCollider** | 便宜、跟 Transform、脚底好对齐 | MeshCollider（不跟蒙皮）、Capsule（身长模型偏大） |
| 已有组件 | **整体跳过** | 只补缺的，绝不改坏手工调过的模型 | 覆盖更新（有风险） |
| 包围盒算法 | **角点转本地求 AABB** | 正确处理缩放/旋转 | 直接照抄 `bounds.size`（缩放会错） |

## 七、风险与对策

- **未激活渲染器给零盒** ⇒ 跳过 `size == 0`；全部为零则记「没有可用 Renderer」。
- **SkinnedMesh bounds 是绑定姿势** ⇒ 大幅动作可能略微超出；写进文档（要精确另做低模代理）。
- **prefab 变体 / 嵌套 prefab** ⇒ 只改根节点，不碰嵌套内部。
- **批量中途异常** ⇒ 每个 prefab 单独 try/catch，一个失败不影响其它。
- **重复执行** ⇒ 靠「已有就跳过」保证安全。
