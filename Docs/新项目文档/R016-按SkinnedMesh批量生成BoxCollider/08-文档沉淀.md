## 二、模块文档

### 简介与使用场景

`MonsterColliderTool`（`_Project\Editor\`）：**编辑器工具**，给选中的怪物 prefab 自动加「贴合模型、底面水平」的 `BoxCollider` 与 `Rigidbody`。
批量配怪物时用：选一批 → 执行菜单 → 每个都配好碰撞体与刚体。

### 核心接口

| 成员 | 说明 |
| --- | --- |
| 菜单 `Tools/NBC/怪物/生成 BoxCollider（选中 prefab）` | 批量入口，处理 Project 里选中的 prefab |
| `MonsterColliderTool.TryBuildForAsset(path, out msg)` | 单个 prefab 的处理（可被脚本/测试复用） |

### 生成规则（写死了，别凭感觉改）

| 项 | 规则 |
| --- | --- |
| 跳过条件 | 根上**同时**有 `Collider` 与 `Rigidbody` ⇒ 整体跳过 |
| 缺一个 | 只补缺的那个，**不改**已有组件的参数 |
| 体积来源 | 蒙皮网格：`mesh.vertices` × `renderer.localToWorldMatrix` 求 AABB；无蒙皮才回落 `Renderer.bounds` |
| 对齐 | 碰撞体底面 = 模型最低点（脚底） |
| 斜根 | 根倾斜（pitch/roll > 0.5°）⇒ 碰撞体挂到 `NBC-ColliderRoot`（反向旋转子物体），保证世界空间水平 |
| 刚体 | 只有缺的时候才加：`useGravity = true`、`freezeRotation = true`、`isKinematic = false` |
| 日志 | 每个 prefab 一行（含尺寸或跳过原因），结尾一行汇总 |

### 使用示例（负责人亲手跑通，2026-11-02）

```text
Project 里选中狼 prefab → 执行菜单
  → 日志：已生成 BoxCollider 在根节点，尺寸 0.50 × 0.98 × 2.04 米
再执行一次
  → 日志：跳过（Collider 与 Rigidbody 都已存在）
Play → 狼的脚着地 ✔
```

### 已知限制与坑点

- **不删除已有碰撞体**：要重建先手工删掉，再跑工具。
- **只处理 prefab 资产**，不处理场景实例。
- **斜根分支没有真实样本验证**（现有 prefab 根都不倾斜）。
- 蒙皮网格的顶点是**绑定姿势**：播大幅动作时模型可能略微超出碰撞体 —— 要精确得另做低模代理。
- 不做 MeshCollider：不跟蒙皮、动态刚体只能凸包、更贵。

### 修改维护注意事项

- **改体积算法前先想清楚**：`Renderer.bounds` 是动画包围盒，轴系与体积都可能错（这是本次最大的坑）。
- **跳过规则不要退回「有任一个就跳过」**：那样「只有刚体」的 prefab 会掉穿地面。
- **别在代码里写死 prefab 路径**：prefab 可以移动，GUID 会跟着走，字符串不会。

## 三、踩坑清单（现象 / 原因 / 解决）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 绿框比模型大一圈、悬空 | 用了 `Renderer.bounds`（蒙皮动画盒） | 改按顶点 AABB |
| 有刚体没碰撞体时被跳过 → 掉穿地面 | 跳过条件写成「有任一个」 | 改成「两个都在才跳过」 |
| 斜根模型碰撞体歪 | 本地 AABB 跟着根倾斜 | 挂到反向旋转子物体 |
| 脚本路径失效 | prefab 被移到别的目录 | 用 GUID 引用；脚本里别写死路径 |
