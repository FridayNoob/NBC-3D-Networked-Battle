# 01 技术预研

需求：R016-按 Skinned Mesh 批量生成 BoxCollider
所属阶段：M4
作者：AI　状态：已确认（2026-11-02）

## 一、调研目标与约束

- 目标：一个**编辑器菜单**，选一批 prefab 就能给每个自动加「贴合模型的 BoxCollider + Rigidbody」，不用手调。
- 约束（负责人 2026-11-02 定）：
  1. 只做 **BoxCollider**（已论证：MeshCollider 不跟蒙皮、动态刚体只能凸包、性能更贵）；
  2. 只处理 **Project 里选中的 prefab 资产**（批量）；
  3. 碰撞体**底部对齐脚底**（模型最低点 = 碰撞体底面）；
  4. 顺手加 **Rigidbody**（开重力、冻结旋转、非运动学）；
  5. **缺什么补什么**：Collider 与 Rigidbody **都在**才整体跳过；只缺一个就补那个，不覆盖已有参数（2026-11-02 修订：原规则「有任一个就跳过」会让「只有刚体没有碰撞体」的 prefab 一直往下掉）。

## 二、要用的编辑器 API（确认存在）

| API | 用途 | 备注 |
| --- | --- | --- |
| `PrefabUtility.EditPrefabContentsScope(path)` | 打开 prefab 内容并提供自动保存的 scope | Unity 2020+ 有；2022.3 可用 |
| `Selection.objects` / `AssetDatabase.GetAssetPath` | 取选中的 prefab 路径 | — |
| `GetComponentsInChildren<Renderer>(true)` | 含隐藏子物体 | `SkinnedMeshRenderer` 继承 `Renderer` |
| `Renderer.bounds` | 世界空间包围盒 | **要求物体激活**；未激活时可能是零尺寸 |
| `Transform.InverseTransformPoint` | 8 个角点转回根本地坐标 | 这样能正确处理缩放/旋转 |
| `EditorUtility.SetDirty` + scope 自动保存 | 落盘 | — |

## 五、算法要点（包围盒 → 本地 AABB）

1. 收集根下所有 `Renderer`（含隐藏）。
2. 跳过 `bounds.size == 0` 的（未激活的渲染器会给出零盒）。
3. 把每个 renderer 的 8 个世界坐标角点用 `root.InverseTransformPoint` 转到根本地。
4. 在本地空间取 min/max → `center`、`size`。
5. `BoxCollider.center = center`、`BoxCollider.size = size`（根上若有缩放，这样处理自然正确）。
6. `Rigidbody`：`useGravity = true`、`freezeRotation = true`、`isKinematic = false`。

## 六、已知坑

1. **`Renderer.bounds` 对未激活物体可能为零** ⇒ 必须跳过零尺寸，否则会生成 0 体积碰撞体（等于没加）。
2. **SkinnedMesh 的 bounds 是绑定姿势** ⇒ 播放大幅动作时模型可能略微超出碰撞体；对「站地上 + 粗略命中」够用，要精确得另做低模代理。
3. **prefab 变体 / 嵌套 prefab**：只在**根**上加 BoxCollider 与 Rigidbody，避免改到嵌套 prefab 内部（那需要 `PrefabUtility` 的 override 机制）。
4. **已有 Collider/Rigidbody**：按负责人的要求**直接跳过整个 prefab**。这样重复执行安全，也不会把手工调过的模型改坏。
5. **缩放**：模型可能带非 1 缩放；用角点变换而不是直接 `bounds.size`，否则尺寸会错。
6. **批量失败要能定位**：每个 prefab 都要打一行日志（成功/跳过/原因），不能静默。

## 七、结论与改动清单

结论：**做一个编辑器菜单工具**，批量给选中的 prefab 生成「贴合的 BoxCollider + 刚体」，底部对齐脚底；**已有碰撞体或刚体的 prefab 一律跳过**。
