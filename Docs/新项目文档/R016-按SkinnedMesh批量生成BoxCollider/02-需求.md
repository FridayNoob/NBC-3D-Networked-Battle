# 02 需求

需求：R016-按 Skinned Mesh 批量生成 BoxCollider
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-11-02）

## 一、业务目标（一句话）

**选一批 prefab，点一下菜单，每个都自动获得「贴合模型、脚底对齐」的 BoxCollider + Rigidbody**，不用手调。

## 二、用户与使用场景

- 用户：开发期负责人（配置怪物 prefab 时）。
- 场景：在 Project 里框选 10 个怪物 prefab → 右键/菜单执行 → 每个 prefab 都长出一个刚好的 BoxCollider 与刚体；已有碰撞体的老 prefab 被跳过（不会被改坏）。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 批量处理选中的 prefab | P0 | 只处理 `.prefab` 资产 |
| 按 SkinnedMesh 包围盒生成 BoxCollider | P0 | 含隐藏子物体；处理缩放 |
| 底部对齐脚底 | P0 | 碰撞体底面 = 模型最低点 |
| 顺手加 Rigidbody | P0 | 开重力、冻结旋转、非运动学 |
| **缺什么补什么，两个都有才跳过** | P0 | Collider 与 Rigidbody 都在 ⇒ 跳过；只缺一个就补那个，不覆盖已有参数 |
| 每个 prefab 一行日志 | P1 | 成功/跳过/原因，便于定位 |
| 处理场景实例 | P2 | 本版不做（只做 prefab 资产） |
| MeshCollider / Capsule 选项 | P2 | 本版不做（已论证 Box 最合适） |

## 四、边界（**本版明确不做**）

- 不做 MeshCollider（不跟蒙皮、动态刚体只能凸包、更贵）。
- 不处理场景里的实例（只处理 prefab 资产）。
- 不删除已有碰撞体、不覆盖已有刚体参数。
- 不做「自动识别哪些 prefab 缺碰撞体」的扫描（只处理你选中的）。

## 五、优先级

**P0**。依赖：R015（怪物换模型）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 选中一个没有碰撞体的怪物 prefab 并执行菜单时，应在**根节点**生成一个 `BoxCollider`，其底面与模型最低点重合
- [ ] 当 同一 prefab 再执行一次时，应**被跳过**（不再重复添加，日志写明「已有」）
- [ ] 当 选中多个 prefab 时，应**逐个处理**并各打一行日志（成功数 / 跳过数）
- [ ] 当 prefab 根上**同时**已有 `Collider` 与 `Rigidbody` 时，应**整体跳过**，不做任何修改
- [ ] 当 只缺其中一个（例如手工加了刚体但没有碰撞体）时，应只补缺的那个，且不改动已有的那个
- [ ] 当 生成完成后，prefab 应带 `Rigidbody`（`useGravity = true`、`freezeRotation = true`、`isKinematic = false`）
- [ ] 当 模型带非 1 缩放时，碰撞体尺寸应**与模型实际外观一致**（不能按原始 bounds 直接照抄）
