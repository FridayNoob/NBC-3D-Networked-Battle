## 三、根因分析

- #1：我只看了 `ITransport` 的四个方法（`Connect/Send/Pump/Close`），没读完整接口体 ⇒ 漏了三个属性。
  **教训**：实现一个已有接口前，把接口体读全（`grep 'public interface' -A 40`），别只看到几个方法就动手。
- #2：`Box` 只挂 `RectTransform`，而 `BasePanel` 的 `CollectControls` 只收 `UIBehaviour` ⇒ `GetControl<...>("Box")` 恒为 null
  ⇒ 我的兜底 `m_box = gameObject` 把**面板自己**隐藏了 ⇒ `Update` 停 ⇒ F1 再也读不到。
  **教训**：「兜底到 self」这类写法在「self 的 Update 是唯一入口」时等于自杀 —— 兜底应该是**报错并保持可用**，不是静默退化。
- #3：固定 KB/s + 一位小数，几十字节/秒被四舍五入成 `0.0`。
  **教训**：显示小量级数据要**自适应单位**，否则「有数据」和「没数据」在界面上长得一样。
- #4：状态同步的帧号取自快照 tick，没进房就没有快照 ⇒ −1 ⇒ `--`。行为正确，只是没提前说明。

## 八、教训（可复用判据）

1. **实现已有接口前，把接口体读全** —— 只读方法名会漏属性（`CS0535` 就是这么来的）。
2. **兜底不要「退化到 self」**：当 self 的 `Update` 是唯一驱动时，隐藏自己＝永久失效。兜底要么保持可用，要么报错。
3. **小量级数字必须用自适应单位**（B/s ↔ KB/s），否则「很小」和「没有」长得一模一样。
4. **凡「某字段显示 --」都要先问清：是没数据，还是没进那个状态** —— 这次是后者（未进房）。
