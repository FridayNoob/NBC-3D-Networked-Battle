## 三、异常场景（本轮三处，全部修掉）

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| `CS0535` 编译失败 | `ITransport` 除 `Connect/Send/Pump/Close` 外还有 `State` / `Stats` / `Description` 三个成员，装饰器漏实现 | 补齐三个转发属性 |
| **F1 收起后按不回来** | `Box` 只挂 `RectTransform`（不是 `UIBehaviour`）⇒ `CollectControls` 收不到 ⇒ `GetControl` 返回 null ⇒ 回退成「隐藏自己」⇒ `Update` 停掉 | 改用 `transform.Find("Box")` |
| **带宽一直 0.0** | 只有心跳时约几十字节/秒，固定按 KB/s 保留一位小数 ⇒ `0.04 → 0.0` | 小于 1 KB/s 改用 `B/s` |
| 帧号显示 `--`（连上但没进房） | 状态同步帧号 = 快照 `ServerTick`，无快照时为 −1 | **不是 bug**，进房后自然递增；已确认 |
