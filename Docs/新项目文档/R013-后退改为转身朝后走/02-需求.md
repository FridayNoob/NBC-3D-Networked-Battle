# 02 需求

需求：R013-后退改为转身朝后走
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-10-31）

## 一、业务目标（一句话）

**按 S 时角色转身朝后走，和 A/D 一样** —— 四个方向的手感彻底统一，不再有「倒着走」这个特例。

## 二、用户与使用场景

- 用户：开发期负责人；最终玩家。
- 场景：按 S → 角色 180° 转身 → 朝后前进；再按 W → 转回原朝向继续前进。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| S 转身朝后 + 前进 | P0 | 与 A/D 完全同一条逻辑 |
| 四向行为一致 | P0 | W/A/S/D 都是「转身朝目标方向 + 沿目标方向前进」 |
| 转身速度可调 | P1 | 复用现有 `m_turnSpeed`（720°/秒 ⇒ 180° 约 0.25 秒） |
| 恢复「倒退走」 | P2 | 以后若需要，作为可选模式另开需求 |

## 四、边界（**本版明确不做**）

- 不改移动速度（仍 5 米/秒）。
- 不改相机（仍世界固定偏移，镜头不跟随转身）。
- **不加「S 是否转身」的开关** —— 一个行为就够，开关只会多一个状态。
- 不碰 `UnityChanLocomotions.controller`（`WalkBack` 状态留着不用即可）。

## 五、优先级

**P0**。依赖：R012（四向移动 + 镜头不跟随转身）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 按住 S 时，角色应**转身朝后**并在约 0.25 秒内开始向后走
- [ ] 当 按住 S 移动时，动画应播**走路**（`Walk`），**不再播倒退走**（`WalkBack`）
- [ ] 当 松开 S 时，角色应保持当前朝向停下并回 Idle
- [ ] 当 先按 S 再按 W 时，角色应转回原朝向继续前进
- [ ] 当 同时按 S + A 时，应只向后走（主导轴：相等时前后优先，沿用 R012 规则）
- [ ] 当 按 S 时，**镜头方向不变**（沿用 R012 的约束）
