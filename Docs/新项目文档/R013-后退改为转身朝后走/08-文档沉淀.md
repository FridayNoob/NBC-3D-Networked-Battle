## 二、模块文档

### 简介与使用场景

`PlayerMove`（`Game\Player\`）：把 `InputManager` 的量化轴变成**四向移动**。
W/A/S/D 全部是「转身朝该方向 + 沿该方向前进」，不斜走，朝向只由方向键决定。

### 核心接口

| 接口 / 字段 | 入参 | 出参 | 说明 |
| --- | --- | --- | --- |
| `ForwardSpeed` | — | float，米/秒 | 前后分量，**现在恒 ≥ 0**（朝向跟着走） |
| `SideSpeed` | — | float，米/秒 | 左右分量，转身瞬间短暂非零 |
| `MoveSpeed` | — | float，米/秒 | 归一化分母（5） |
| `CurrentSpeed` | — | float，米/秒 | 合速度 |
| `m_turnSpeed`（Inspector） | — | 度/秒，720 | 180° 约 0.25 秒 |
| `m_moveSpeed`（Inspector） | — | 米/秒，5 | 不改 |

### 四向行为表（本次定稿）

| 按键 | targetDirection | 是否转身 | 动画 |
| --- | --- | --- | --- |
| W | (0, 0, +1) | 是 | Walk |
| S | (0, 0, -1) | **是（本次改）** | Walk（**不再是 WalkBack**） |
| A | (-1, 0, 0) | 是 | Walk |
| D | (+1, 0, 0) | 是 | Walk |
| W+D 或 S+A 同按 | 取主导轴（相等时前后优先） | 是 | Walk / 不斜走 |

### 使用示例（负责人亲手跑通，2026-10-31）

```text
Play → 按 S：转身朝后并向后走（播走路）
     → 按 W：转回继续前进
     → S+A 同按：只向后走，不斜走
     → 全程镜头方向不变
```

### 实现原理（简要）

取主导轴得 `targetDirection` → `Quaternion.RotateTowards` 限速转身 → **沿 `targetDirection`** 位移（不是沿当前朝向，避免转身走弧线）
→ 位移按 `forward / right` 点乘拆成前后 / 左右分量。

### 已知限制与坑点

- **`WalkBack` 动画不再出现**：Controller 零改动，状态留着不用。
- 转身 180° 需约 0.25 秒；期间位移已生效，不会站定。
- 脚打滑仍存在（移动 5 米/秒 vs 动画约 1.3 米/秒，R002 起的遗留）。
- 没有起步/停步缓冲、没有跑（Run）。

### 修改维护注意事项

- 想恢复「倒退走」：把 `backpedal` 分支加回来（详见 07 第九节），Controller 无需改。
- 改转身速度只动 `m_turnSpeed`，别动位移方向逻辑。
- **不要**把位移改成 `transform.forward` —— 会走出弧线。
