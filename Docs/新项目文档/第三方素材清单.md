## 一、为什么要这份清单

项目里用到的**第三方模型/动画/贴图**都不进 Git 仓库（授权 + 体积）。但「谁要跑这个项目，得去哪儿补、补到哪个路径」必须写清楚，否则别人 clone 下来是一堆报错。
本清单是唯一入口；`Assets` 里那些被忽略的目录只放实际文件。

## 三、各素材补法（clone 之后怎么做）

### Unity-chan

1. 从官网/Asset Store 下载；
2. 导入到 `Assets/UnityChan/`；
3. 详见 `Client/Assets/_Project/Art/Characters/README.md`（含许可要点与放置细节）。

### CombatGirls（SwordShield）

1. 在 Asset Store 购买/下载 **CombatGirls_SwordShieldCharacterPack**（同系列其它包也可，结构类似）；
2. 导入到 `Assets/Art/Model/CombatGirlsCharacterPack/`（目录名可以不同，能对上即可）；
3. 包里自带 UTS 的 `.unitypackage`：需要卡通渲染时再导入，**先把基础 FBX 跑通**。

## 四、忽略规则（`.gitignore` 里对应的两段）

```text
Client/Assets/UnityChan/
Client/Assets/UnityChan.meta

Client/Assets/Art/Model/
Client/Assets/Art/Model.meta
```

判据：**凡是「授权不明或禁止再分发」的素材，一律先进 `.gitignore`，再往工程里放**（R002 与 R004 各踩过一次）。

## 五、使用边界（重要）

- **本地开发/试验**：可以随便用。
- **进公开仓库**：❌ 一律不行（上面两个素材都明确禁止再分发原始文件）。
- **进演示视频 / 简历项目**：
  - Unity-chan：按 Unity-Chan License 署名的前提下可以用；
  - CombatGirls：Asset Store EULA 允许用在你的作品里，但**不要在视频里宣称素材是你做的**，也不要把模型文件当作下载提供。
