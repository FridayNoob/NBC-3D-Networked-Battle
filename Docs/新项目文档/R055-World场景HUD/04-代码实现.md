## 二、功能概述

Login 启动时装一次资源层并常驻；World 的 `[Player_Hero]` 等资源层就绪后打开血条、网络状态、任务追踪三块面板，离开场景时关掉。

## 四、逐段讲解

1. `AppBootstrap.Awake`：`s_instance` 已有别人就销毁自己；否则记住并 `DontDestroyOnLoad`。这样 Login 与 World 各挂一份也只会存活一份。
2. `AppBootstrap.Start`：先判 `Ready || AssetManager.Instance.IsInitialized` 跳过；`AssetPackageRoot.Resolve()` 拿到模拟清单目录后 `InstallAsync`；成功后对齐 `UIManager` 的两个地址（必须在第一次 `ShowPanel` 之前，之后会抛异常）；最后交给 `BattleConfigBootstrap.Ensure` 预加载配置表。
3. `WorldHudDriver.BindRoutine`：每帧问 `BattleReadiness.AssetsReady`，15 秒还没好只告警一次（继续等）；就绪后取血上限、开三块面板，任务区写 `SetHint`。
4. `WorldHudDriver.OnDestroy`：`m_bound` 为真才关面板，避免「没打开过却去关」的无意义调用。
5. 场景挂载：Login 加 `[AppBootstrap]`（guid `f2bce4b815b3e994bad60f15b6bcb8b0`），World 给 `[Player_Hero]` 加 `WorldHudDriver`（guid `0686a35b6bc3d6248b4ca797aab06c6a`），World 另加一个 `[AppBootstrap]` 供「直接按 Play」调试。

### 5.1 `Client/Assets/_Project/Boot/AssetPackageRoot.cs`

```csharp
// 这个文件里有：
//   AssetPackageRoot（静态类）：找「模拟清单（EditorSimulateBuildPipeline）」最新的输出目录。

using System;
using System.IO;
using UnityEngine;

namespace NBC.Boot
{
    // 主要功能：在 <工程根>/Bundles/<平台>/<包名>/ 下找清单文件最新的那个目录，交给资源层安装。
    // 主要数据成员：无。
    // 主要外部方法：Resolve（返回目录全路径，找不到返回空串）。
    // 谁在用它：AppBootstrap（Login 启动装资源层）、HpBarDemoBehaviour（直接进 Battle 调试时兜底）。
    // 注意：只认目录里有 DefaultPackage*.bytes 的子目录（把 OutputCache 之类排除），
    //       这样「重新构建内容包」之后不用改代码，运行时自动取最新那份清单。
    public static class AssetPackageRoot
    {
        // 功能：找出最新的模拟清单目录。
        // 入参：无（平台与包名用 AssetBootstrapper 的默认值）。
        // 返回：目录全路径；找不到返回空串（让底层自己报错，别在这里假装成功）。
        // 步骤：
        //   1) 拼出 <工程根>/Bundles/<平台>/<包名>/，不存在直接返回空串
        //   2) 遍历子目录，只看里面有 DefaultPackage*.bytes 的
        //   3) 比清单文件的最后写入时间，取最新的那个
        // 上游：AppBootstrap.Start、HpBarDemoBehaviour.ResolveSimulatePackageRoot。
        // 下游：AssetBootstrapper.InstallAsync。
        public static string Resolve()
        {
            string projectRoot = Directory.GetParent(Application.dataPath).FullName;
            string packageFolder = Path.Combine(
                projectRoot,
                "Bundles",
                "StandaloneWindows64",
                AssetBootstrapper.DefaultPackageName);

            if (!Directory.Exists(packageFolder))
            {
                return string.Empty;
            }

            string newest = string.Empty;
            DateTime newestTime = DateTime.MinValue;
            string[] subDirectories = Directory.GetDirectories(packageFolder);

            for (int i = 0; i < subDirectories.Length; i++)
            {
                string[] manifests = Directory.GetFiles(
                    subDirectories[i],
                    AssetBootstrapper.DefaultPackageName + "*.bytes");

                if (manifests.Length == 0)
                {
                    continue;
                }

                DateTime time = File.GetLastWriteTime(manifests[0]);

                if (time > newestTime)
                {
                    newestTime = time;
                    newest = subDirectories[i];
                }
            }

            return newest;
        }
    }
}
```

### 5.2 `Client/Assets/_Project/Boot/AppBootstrap.cs`

```csharp
// 这个文件里有：
//   AppBootstrap（类）：整个客户端只装一次资源层与配置表，并把自己带到后面所有场景。

using System;
using System.Threading.Tasks;
using NBC.Framework.Asset;
using NBC.Framework.UI;
using NBC.Game.Bootstrap;
using UnityEngine;

namespace NBC.Boot
{
    // 主要功能：在 Login 场景启动时装好资源层、对齐 UIManager 的地址、预加载配置表，然后跨场景常驻。
    // 主要数据成员：m_mode（资源模式）、m_logDiagnostics（是否打日志）、Ready（是否装好）。
    // 主要外部方法：Ready（静态属性，供 World 的 HUD 判断能不能开始加载面板）。
    // 谁在用它：Login 场景的 [AppBootstrap]；World 的 WorldHudDriver 读 Ready 等着。
    // 注意：装在 Login 是因为「整局只该装一次」——World 与 Battle 都用同一份资源层，
    //       以前只有 Battle 的 HpBarDemo 会装，结果 World 里连一个 HUD 面板都加载不出来。
    [DefaultExecutionOrder(-200)]
    public sealed class AppBootstrap : MonoBehaviour
    {
        // 资源模式：编辑器里用 EditorSimulate（免打包，但要先构建过模拟清单）
        [SerializeField]
        private AssetRuntimeMode m_mode = AssetRuntimeMode.EditorSimulate;

        // 是否打诊断日志（默认开：启动阶段只有几条，值得看）
        [SerializeField]
        private bool m_logDiagnostics = true;

        // 资源层是否已经装好（静态：后面场景里的组件不用找物体就能问）
        public static bool Ready { get; private set; }

        // 最近一次失败原因（空串 = 没失败）
        public static string LastError { get; private set; } = string.Empty;

        // 进程里唯一的那一个（从 Login 带过来的那份；World 里自带的会在 Awake 里自杀）
        private static AppBootstrap s_instance;

        // 功能：保证整局只有一份，并把自己标记成常驻。
        // 入参：无（引擎调用）。
        // 返回：无。
        // 步骤：1) 已经有别人了就销毁自己 2) 否则记下自己并 DontDestroyOnLoad。
        // 上游：Unity 引擎（场景加载时）。
        // 注意：World 场景也挂了一份（方便直接从 World 按 Play 调试），靠这里去重。
        private void Awake()
        {
            if (s_instance != null && s_instance != this)
            {
                Destroy(gameObject);
                return;
            }

            s_instance = this;
            DontDestroyOnLoad(gameObject);
        }

        // 功能：启动时装资源层、对齐地址、预加载配置表，并把自己标记成常驻。
        // 入参：无（引擎调用）。
        // 返回：无（async void 只用于 Unity 生命周期，内部自己兜异常）。
        // 步骤：
        //   1) 先 DontDestroyOnLoad，保证切场景不销毁（后续场景都靠这份资源层）
        //   2) 已经装过就跳过（重开编辑器播放、或有人先装过）
        //   3) 找模拟清单目录 → InstallAsync
        //   4) 第一次装好后对齐 UIManager 地址（之后再设会抛异常）
        //   5) 让 Game 层把配置表来源设好并预加载（幂等）
        // 上游：Unity 引擎（Login 场景启动）。
        // 下游：AssetPackageRoot.Resolve、AssetBootstrapper.InstallAsync、UIManager、BattleConfigBootstrap.Ensure。
        private async void Start()
        {
            if (Ready || AssetManager.Instance.IsInitialized)
            {
                Ready = true;
                Log("资源层已经就绪，直接复用");
                EnsureConfigs();
                return;
            }

            try
            {
                string root = AssetPackageRoot.Resolve();
                Log("开始装资源层，清单目录=" + (string.IsNullOrEmpty(root) ? "(空)" : root));
                await AssetBootstrapper.InstallAsync(
                    m_mode, AssetBootstrapper.DefaultPackageName, root);
            }
            catch (Exception ex)
            {
                LastError = ex.Message;
                Debug.LogError("[AppBootstrap] 资源层初始化失败：" + ex.Message);
                return;
            }

            // ⚠️ 地址对齐：UIManager 默认找 "UI/Canvas" 与 "UI/<面板名>"，
            //   而收集器规则是 AddressByFileName ⇒ 真实地址只是 "Canvas" / "HpBarPanel"。
            //   这一步必须在第一次 ShowPanel 之前做，之后再做会抛异常。
            UIManager.Instance.SetCanvasLocation("Canvas");
            UIManager.Instance.SetPanelLocationPrefix(string.Empty);

            Ready = true;
            LastError = string.Empty;
            Log("资源层已就绪");

            EnsureConfigs();
        }

        // 功能：接上配置表来源并预加载（World 的任务追踪也要查表）。
        // 入参：无。
        // 返回：无。
        // 步骤：转交 BattleConfigBootstrap.Ensure（设来源 + 空表时预加载，重复调用无害）。
        // 上游：Start。
        // 下游：BattleConfigBootstrap.Ensure。
        private void EnsureConfigs()
        {
            BattleConfigBootstrap.Ensure(reason => Debug.LogError("[AppBootstrap] 预加载配置表失败：" + reason));
        }

        // 功能：打一条启动日志。
        // 入参：message 内容。
        // 返回：无。
        // 步骤：m_logDiagnostics 关掉时直接返回。
        // 上游：Start 的各个阶段。
        private void Log(string message)
        {
            if (m_logDiagnostics)
            {
                Debug.Log("[AppBootstrap] " + message);
            }
        }
    }
}
```

### 5.3 `Client/Assets/_Project/Game/UI/WorldHudDriver.cs`

```csharp
// 这个文件里有：
//   WorldHudDriver（类）：World 场景的常驻 HUD 驱动，显示玩家血条、网络状态与任务追踪。

using System.Collections;
using NBC.Framework.UI;
using NBC.Game.Bootstrap;
using NBC.Game.Config;
using UnityEngine;

namespace NBC.Game.UI
{
    // 主要功能：World 场景里把三块 HUD 面板打开（玩家血条 / 网络状态 / 任务追踪），离开场景时关掉。
    // 主要数据成员：m_heroId（英雄编号，取血上限用）、m_maxHp/m_hp（当前显示的血量）。
    // 主要外部方法：无（挂在 [Player_Hero] 上自动跑）。
    // 谁在用它：World 场景的 [Player_Hero]；面板本体在 Client/Assets/_Project/UI/ 下。
    // 注意：World 没有网络会话、也没有任务数据，所以血条按满血、任务行显示一句提示；
    //       真正随时变化的血量与任务进度在副本里由 RuntimeHudDriver 负责。
    public sealed class WorldHudDriver : MonoBehaviour
    {
        // 血条面板地址（= prefab 文件名）
        public const string HpBarPanelName = "HpBarPanel";

        // 网络状态面板地址（= prefab 文件名）
        public const string NetHudPanelName = "NetHudPanel";

        // 任务追踪面板地址（= prefab 文件名）
        public const string QuestPanelName = "HudQuestPanel";

        // 默认英雄编号（与 Dungeon/Login 里的 1001 剑士一致）
        public const int DefaultHeroId = 1001;

        // 查不到英雄表时的血量兜底（点）
        public const int FallbackMaxHp = 1200;

        // World 里任务追踪区显示的一句话（没有任务数据时的占位）
        public const string QuestHint = "世界区域：暂无进行中的任务";

        // 等资源层的上限（秒）；超时只告警，不影响后面继续等
        public const float AssetsWaitTimeoutSeconds = 15f;

        // 英雄编号（取血上限用）
        [SerializeField]
        private int m_heroId = DefaultHeroId;

        // 是否打诊断日志
        [SerializeField]
        private bool m_logDiagnostics = true;

        private bool m_bound;
        private bool m_warnedTimeout;
        private HpBarPanel m_hpPanel;
        private HudQuestPanel m_questPanel;
        private int m_maxHp = FallbackMaxHp;
        private int m_hp = FallbackMaxHp;

        // 功能：启动后等资源层就绪，再把三块面板打开。
        // 入参：无（引擎调用）。
        // 返回：无。
        // 步骤：起协程，逐帧问 BattleReadiness.AssetsReady。
        // 上游：Unity 引擎。
        // 下游：BindRoutine。
        private void Start()
        {
            StartCoroutine(BindRoutine());
        }

        // 功能：等资源层就绪后打开三块 HUD 面板。
        // 入参：无。
        // 返回：协程迭代器。
        // 步骤：
        //   1) 每帧问一次就绪；超过上限只告警一次，继续等（资源层可能慢，但一定会好）
        //   2) 就绪后读英雄表取血上限、血条按满血
        //   3) 依次 ShowPanel：血条、网络状态、任务追踪（任务区写占位提示）
        // 上游：Start。
        // 下游：UIManager.ShowPanel、HudQuestPanel.SetHint。
        private IEnumerator BindRoutine()
        {
            float waited = 0f;

            while (!BattleReadiness.AssetsReady)
            {
                if (!m_warnedTimeout && waited >= AssetsWaitTimeoutSeconds)
                {
                    m_warnedTimeout = true;
                    Debug.LogWarning("[WorldHud] 资源层 " + AssetsWaitTimeoutSeconds + " 秒还没就绪，继续等…");
                }

                waited += Time.unscaledDeltaTime;
                yield return null;
            }

            UIManager ui = UIManager.Instance;

            if (ui == null)
            {
                Debug.LogWarning("[WorldHud] 没有 UIManager，跳过 HUD。");
                yield break;
            }

            ResolveMaxHp();

            ui.ShowPanel(
                HpBarPanelName,
                UILayer.Bot,
                panel =>
                {
                    m_hpPanel = panel as HpBarPanel;

                    if (m_hpPanel != null)
                    {
                        m_hpPanel.SetHp(m_hp, m_maxHp);
                    }
                },
                error => Debug.LogError("[WorldHud] 打不开血条面板：" + error.Message));

            ui.ShowPanel(
                NetHudPanelName,
                UILayer.Bot,
                null,
                error => Debug.LogError("[WorldHud] 打不开网络面板：" + error.Message));

            ui.ShowPanel(
                QuestPanelName,
                UILayer.Bot,
                panel =>
                {
                    m_questPanel = panel as HudQuestPanel;

                    if (m_questPanel != null)
                    {
                        m_questPanel.SetHint(QuestHint);
                    }
                },
                error => Debug.LogError("[WorldHud] 打不开任务面板：" + error.Message));

            m_bound = true;

            if (m_logDiagnostics)
            {
                Debug.Log("[WorldHud] World HUD 已打开：血条 " + m_hp + "/" + m_maxHp + "、网络状态、任务追踪");
            }
        }

        // 功能：从英雄表取血上限，取不到就用兜底值。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 配置表没来源就先用兜底 2) TryGet 命中就取 hp 3) 当前血先按满血。
        // 上游：BindRoutine。
        // 下游：ConfigMgr.TryGet(HeroConfig)。
        private void ResolveMaxHp()
        {
            m_maxHp = FallbackMaxHp;

            ConfigMgr configs = ConfigMgr.Instance;
            HeroConfig heroes = null;

            if (configs != null && configs.Source != null && configs.TryGet(out heroes))
            {
                Config_Hero row;

                if (heroes.TryGet(m_heroId, out row) && row.hp > 0)
                {
                    m_maxHp = row.hp;
                }
            }

            m_hp = m_maxHp;
        }

        // 功能：离开场景时把三块面板关掉（面板挂在常驻 Canvas 下，不会自己消失）。
        // 入参：无（引擎调用）。
        // 返回：无。
        // 步骤：停协程；有 UIManager 就逐个 HidePanel。
        // 上游：Unity 引擎（场景卸载）。
        // 下游：UIManager.HidePanel。
        private void OnDestroy()
        {
            StopAllCoroutines();

            if (!m_bound)
            {
                return;
            }

            UIManager ui = UIManager.Instance;

            if (ui == null)
            {
                return;
            }

            ui.HidePanel(HpBarPanelName);
            ui.HidePanel(NetHudPanelName);
            ui.HidePanel(QuestPanelName);
        }
    }
}
```

## 七、风险与幻觉自查

| 检查 | 结论 |
| --- | --- |
| `ShowPanel` 是否返回面板 | **否**，返回 void，只能从 `onShown` 回调拿（CS0039 的教训） |
| `SetCanvasLocation` 能否重复调 | 不能，第二次抛异常；只放在「首次安装」分支里 |
| World 有没有会话 | 没有，所以血条固定满血、任务区用提示 |
| 面板会不会自己消失 | 不会，挂 DDOL 的 Canvas 下；必须 `OnDestroy` 里 `HidePanel` |
| 场景 YAML 的 guid | 用 Unity 导入后生成的 `.meta` 里的真实 guid，不是编的 |
