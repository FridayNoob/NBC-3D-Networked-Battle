## 二、正常流程走查

1. 关掉旧进程（含服务端）→ 打开 Unity → 按 Play（从 Login 场景开始）。
2. 输入昵称 → 点「开始游戏」。
3. World 加载完，看屏幕左下角：血条显示 `1200 / 1200`；右上角：网络状态面板；右上/左侧：任务区显示「世界区域：暂无进行中的任务」。
4. 走到 `[DungeonEntrance]` 按 E 进副本：World 的三块 HUD 消失，副本里出现 BOSS 条与目标条。
5. 打完点「返回世界」：World 的三块 HUD 重新出现。

## 三、异常场景

1. 把 `Client/Bundles/StandaloneWindows64/DefaultPackage` 临时改名 → 进 Play：Console 应出现 `[AppBootstrap] 资源层初始化失败`，WorldHud 不再刷屏。
2. 保持资源层正常，但在 World 里按 Stop → 再 Play：不应出现「已经装过加载器」的报错（上次进程已退出）。

## 四、性能

记录「点开始游戏 → 看到血条」的秒表读数；超过 2 秒先看 Console 里 `[AppBootstrap]` 三条日志的时间戳，判断是资源层还是 Canvas 加载慢。
