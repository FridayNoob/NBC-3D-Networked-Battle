## 二、模块文档

### 简介与使用场景

`HpBarPanel`（NBC.Game）+ `HpBarDemoBehaviour`（NBC.Boot，演示用）：屏幕 HUD 显示血量。
凡是要「常驻屏幕的血条/状态条」，都可以照这套：**prefab 决定外观、代码只改 `fillAmount` 与颜色**。

### 核心接口

| 接口 / 常量 | 入参 | 出参 | 说明 |
| --- | --- | --- | --- |
| `HpBarPanel.SetHp(int current, int max)` | 当前 / 最大 | 无 | 钳 0..max，算比例并更新数字 |
| `HpBarPanel.SetRatio(float ratio)` | 0..1 | 无 | 设 `fillAmount` 与颜色 |
| `HpBarPanel.Ratio` | — | float | 当前比例 |
| `HpBarPanel.FillControl` | — | `"Img_Fill"` | 必需，`Image Type` 必须是 Filled |
| `HpBarPanel.BgControl` / `ValueControl` | — | `"Img_Bg"` / `"Text_Value"` | 可选 |

### 使用示例（负责人亲手跑通，2026-10-26）

```text
1) prefab：HpBarPanel（根，挂脚本）→ Bar（固定 320x24，锚定左上）→ Img_Bg / Img_Fill（拉满 Bar）
2) Canvas prefab：Canvas → Bot/Mid/Top/System 四层，挂 UILayers 并绑好
3) 收集器：ui 组 CollectPath = Assets/_Project/UI，AddressByFileName + PackDirectory，重建清单
4) 场景：空物体挂 HpBarDemoBehaviour → Play → 按空格掉血
```

### 实现原理（简要）

`HpBarDemoBehaviour` 先装资源层（`AssetBootstrapper.InstallAsync`），再把地址对齐成 `Canvas` / `HpBarPanel`，
然后 `ShowPanel` 挂到 `Bot` 层；`BasePanel.Initialize` 按物体名字收集控件并调 `OnInit`；
`HpBarPanel.SetHp` 把比例写进 `Img_Fill.fillAmount`，颜色用 `Color.Lerp(red, green, ratio)`。

### 已知限制与坑点

- 面板根**运行时会被铺满整层**（`UIManager.AttachToLayer`）⇒ HUD 必须有自己的固定尺寸容器（`Bar`）。
- 只支持一条血条、本地数据；没有平滑过渡与飘字。
- 依赖项目 UI 框架的三个默认值：`UI/Canvas` 地址前缀、`Bot/Mid/Top/System` 层名、控件按名字收集。

### 修改维护注意事项

- 改外观（位置/尺寸/图片/颜色）**只改 prefab**，不要改代码。
- 控件名是契约：`Img_Fill` 必须存在且是 Filled，否则 `RequireControl` 会抛异常点名。
- 接入正式战斗时：把 `HpBarDemoBehaviour` 删掉，改由战斗 HUD 调 `HpBarPanel.SetHp(快照里的 hp, maxHp)`。

## 三、踩坑清单（现象 / 原因 / 解决）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `CS0234 命名空间 NBC 中不存在 Boot` | 文件放进了 `NBC.Game`，而 `AssetBootstrapper` 在 `NBC.Boot`（引用单向） | 演示驱动搬到 `Assets/_Project/Boot/` |
| `Location is invalid: 'UI/Canvas'` | `UIManager` 默认地址带 `UI/` 前缀，收集器给的是纯文件名 | 开面板前 `SetCanvasLocation("Canvas")` + `SetPanelLocationPrefix("")` |
| 血条铺满全屏、Inspector 里尺寸为 0 | `AttachToLayer` 把面板根铺满整层 | prefab 加固定尺寸 `Bar` 容器 |
| 改了 `fillAmount` 没反应 | `Image Type` 不是 `Filled` | prefab 里设 Filled / Horizontal / Left |
| 报「找不到叫 Img_Fill 的控件」 | 名字不一致，或脚本没挂在 prefab 根上 | 名字对齐；脚本挂根 |
| 面板打不开但没细说原因 | `ShowPanel` 是异步，失败走 `onFailed` | 一定给 `onFailed` 打日志（本项目已打） |
