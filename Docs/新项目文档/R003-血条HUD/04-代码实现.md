## 一、子任务与设计约束

- 本单元：`HpBarPanel`（表现，住 NBC.Game）与 `HpBarDemoBehaviour`（演示驱动，**住 NBC.Boot**），不碰 UIManager 内部、不建任何 UI 物体。
- 约束：**外观全在 prefab 里**，代码不写坐标；`Img_Fill` 缺失要**抛异常点名**；注释按 `csharp-code-comment`。

## 二、功能概述

`HpBarPanel` 把「当前血 / 最大血」变成血条的 `fillAmount`（变短）与颜色（绿→红）；
`HpBarDemoBehaviour` 只负责“打开面板 + 按空格扣血”，是演示用脚手架，正式接战斗后删除。

## 三、接口与入参出参

| 单元 | 入参 | 出参 | 异常 |
| --- | --- | --- | --- |
| `HpBarPanel.OnInit` | 无 | 无 | `Img_Fill` 找不到时 `RequireControl` 抛 `InvalidOperationException` |
| `HpBarPanel.SetHp` | `current` 当前血、`max` 最大血 | 无（改 fillAmount/颜色/数字） | 不抛；`max <= 0` 按 0 处理 |
| `HpBarPanel.SetRatio` | `ratio` 0..1 | 无 | 不抛；越界钳住 |
| `HpBarDemoBehaviour.Update` | 无 | 无 | 不抛 |

## 四、逐段讲解

1. **取控件靠名字**：`BasePanel.CollectControls()` 在 `Initialize()` 时把子物体的 `UIBehaviour` 按**物体名**建索引。
   所以 `Img_Fill` 这个名字是**契约**，改了 prefab 里的名字就要改常量。
2. **必需的用 `RequireControl`**：取不到就抛带指引的异常（“找不到叫 Img_Fill 的控件”），
   而不是静默返回 null —— 静默正是「血条不动也不报错」的根源。
3. **可选控件用 `GetControl`**：`Img_Bg`、`Text_Value` 没有就跳过，不逼你摆。
4. **数字兼容两种文字**：先试 `TMP_Text`，没有再试 UGUI `Text`，这样你 prefab 用哪种都行。
5. **变短的秘密就是 `Image.fillAmount`**：它要求 `Image Type = Filled`，否则改了也没反应（第三节说过的坑）。
6. **颜色用 `Color.Lerp(red, green, ratio)`**：一行搞定，绿→红连续过渡。
7. **演示驱动只在 `onShown` 回调里用面板**：`ShowPanel` 是异步的，回调前 `m_panel` 还是 null。

```csharp
// 这个文件里有：
//   HpBarPanel（类）：屏幕 HUD 的血条面板，只负责“按名字找控件 + 改长度与颜色”

using NBC.Framework.UI;
using TMPro;
using UnityEngine;
using UnityEngine.UI;

namespace NBC.Game.UI
{
    // 主要功能：把「当前血 / 最大血」画成一条会变短、会变色的血条；外观、位置、图片全部由 prefab 决定。
    // 主要数据成员：m_fill（填充图，必需）、m_bg（背景，可选）、m_tmpValue / m_legacyValue（数字，可选）。
    // 主要外部方法：SetHp（按当前/最大设置）、SetRatio（直接按 0..1 设置）。
    // 谁在用它：UIManager.ShowPanel("HpBarPanel", UILayer.Bot) 打开；由战斗 HUD 或演示驱动调 SetHp。
    public sealed class HpBarPanel : BasePanel
    {
        // 填充图的名字：prefab 里必须有，且 Image Type 必须是 Filled
        public const string FillControl = "Img_Fill";

        // 背景图的名字：可选，没有就不改颜色
        public const string BgControl = "Img_Bg";

        // 数字文字的名字：可选，TMP 或 UGUI Text 都支持
        public const string ValueControl = "Text_Value";

        private Image m_fill;
        private Image m_bg;
        private TMP_Text m_tmpValue;
        private Text m_legacyValue;

        // 当前比例：0 = 空血，1 = 满血
        public float Ratio { get; private set; }

        // 入参：无（BasePanel.Initialize 里调）
        // 返回：无
        // 步骤：
        //   1) 取 Img_Fill（必需，取不到就抛带指引的异常，避免“没反应又不说为什么”）
        //   2) 取 Img_Bg、Text_Value（可选，没有就跳过）
        // 上游：BasePanel.Initialize
        // 下游：BasePanel.GetControl / RequireControl
        protected override void OnInit()
        {
            m_fill = RequireControl<Image>(FillControl);
            m_bg = GetControl<Image>(BgControl);
            m_tmpValue = GetControl<TMP_Text>(ValueControl);

            if (m_tmpValue == null)
            {
                m_legacyValue = GetControl<Text>(ValueControl);
            }
        }

        // 入参：current 当前血（会被钳在 0..max）；max 最大血（<= 0 时按 0 比例处理）
        // 返回：无
        // 步骤：
        //   1) 钳住 current 到 0..max
        //   2) 算比例（max <= 0 时按 0）
        //   3) 转给 SetRatio 统一处理显示
        // 上游：战斗 HUD / 演示驱动
        // 下游：SetRatio
        public void SetHp(int current, int max)
        {
            if (max <= 0)
            {
                SetRatio(0f);
                return;
            }

            int hp = current < 0 ? 0 : (current > max ? max : current);
            SetRatio((float)hp / max);

            if (m_tmpValue != null)
            {
                m_tmpValue.text = hp + " / " + max;
            }
            else if (m_legacyValue != null)
            {
                m_legacyValue.text = hp + " / " + max;
            }
        }

        // 入参：ratio 0..1（越界会被钳住）
        // 返回：无
        // 步骤：
        //   1) 记录比例
        //   2) 改填充图的 fillAmount（这就是“血条变短”的全部秘密）
        //   3) 按比例把颜色从红渐变到绿；背景图若存在则不动
        // 上游：SetHp
        // 下游：Image.fillAmount、Image.color
        public void SetRatio(float ratio)
        {
            Ratio = Mathf.Clamp01(ratio);

            if (m_fill != null)
            {
                m_fill.fillAmount = Ratio;
                m_fill.color = Color.Lerp(Color.red, Color.green, Ratio);
            }

            if (m_bg != null && m_bg.color.a <= 0f)
            {
                m_bg.color = new Color(m_bg.color.r, m_bg.color.g, m_bg.color.b, 1f);
            }
        }
    }
}
```

`Client/Assets/_Project/Boot/HpBarDemoBehaviour.cs`

```csharp
// 这个文件里有：
//   HpBarDemoBehaviour（类）：演示脚手架，装资源层 → 开血条面板 → 按空格扣血

using System;
using System.IO;
using System.Threading.Tasks;
using NBC.Framework.Asset;
using NBC.Framework.UI;
using NBC.Game.UI;
using UnityEngine;

namespace NBC.Boot
{
    // 主要功能：把「资源层初始化 + 打开血条 HUD + 按空格扣血」合成一个演示脚手架，只用于人工验收。
    // 主要数据成员：m_mode（资源模式）、m_maxHp（最大血）、m_damagePerPress（每次扣多少）。
    // 主要外部方法：无（挂到场景物体上自动跑）；正式战斗 HUD 接上后本类可删。
    // 谁在用它：只挂在验收场景里。
    // 为什么放在 NBC.Boot 而不是 NBC.Game：它要用 AssetBootstrapper，而 asmdef 的引用方向是
    //   NBC.Boot -> NBC.Game（单向）。放进 Game 会报 CS0234 —— 这正是 2026-10-26 踩过的坑。
    public sealed class HpBarDemoBehaviour : MonoBehaviour
    {
        // 资源模式：编辑器里用 EditorSimulate（免打包，但要先构建过模拟清单）
        [SerializeField] private AssetRuntimeMode m_mode = AssetRuntimeMode.EditorSimulate;

        // 最大血：血条满的时候的值
        [SerializeField] private int m_maxHp = 100;

        // 每次按空格扣多少血
        [SerializeField] private int m_damagePerPress = 10;

        // 当前血
        private int m_hp;

        // 血条面板（打开成功后才有）
        private HpBarPanel m_panel;

        // 资源层是否已经装好
        private bool m_assetsReady;

        // 入参：无（引擎在开始帧调一次）
        // 返回：无（异步方法，内部 await）
        // 步骤：
        //   1) 当前血设为满
        //   2) 找模拟清单目录，调组合根装资源层（先装加载器，再初始化，顺序不能反）
        //   3) 装好后打开血条面板并挂到 HUD 层（Bot）
        // 上游：Unity 引擎
        // 下游：AssetBootstrapper.InstallAsync、UIManager.ShowPanel
        // 注意：Battle 场景原本没有任何启动器，初始化必须由这里做，否则加载 prefab 会报“还没有装上底层加载器”
        private async void Start()
        {
            m_hp = m_maxHp;

            try
            {
                string root = ResolveSimulatePackageRoot();
                await AssetBootstrapper.InstallAsync(m_mode, AssetBootstrapper.DefaultPackageName, root);
                m_assetsReady = true;
            }
            catch (Exception ex)
            {
                Debug.LogError("[HpBarDemo] 资源层初始化失败：" + ex.Message);
                return;
            }

            // ⚠️ 地址对齐（2026-10-26 实际踩过）：
            //   UIManager 的默认地址是 "UI/Canvas" 与 "UI/<面板名>"，
            //   而我们的收集器规则是 AddressByFileName ⇒ 地址只是 "Canvas" / "HpBarPanel"。
            //   不对齐就会报 Location is invalid: 'UI/Canvas'。必须**在第一次 ShowPanel 之前**设（之后会抛异常）。
            UIManager.Instance.SetCanvasLocation("Canvas");
            UIManager.Instance.SetPanelLocationPrefix(string.Empty);

            UIManager.Instance.ShowPanel(
                "HpBarPanel",
                UILayer.Bot,
                panel =>
                {
                    m_panel = panel as HpBarPanel;

                    if (m_panel != null)
                    {
                        m_panel.SetHp(m_hp, m_maxHp);
                    }
                },
                error => Debug.LogError("[HpBarDemo] 打不开血条面板：" + error.Message));
        }

        // 入参：无（引擎每帧调）
        // 返回：无
        // 步骤：
        //   1) 资源没装好、或面板还没打开 ⇒ 什么都不做
        //   2) 按空格才处理
        //   3) 扣血（钳到 0）后交给面板
        // 上游：Unity 引擎
        // 下游：HpBarPanel.SetHp
        // 注意：这里只为演示扣血；正式战斗的血量必须来自服务端快照
        private void Update()
        {
            if (!m_assetsReady || m_panel == null || !Input.GetKeyDown(KeyCode.Space))
            {
                return;
            }

            m_hp = Mathf.Max(0, m_hp - m_damagePerPress);
            m_panel.SetHp(m_hp, m_maxHp);
        }

        // 入参：无
        // 返回：模拟清单目录（找不到返回空串，让底层自己报错）
        // 步骤：
        //   1) 在 <工程根>/Bundles/<平台>/<包名>/ 下遍历子目录
        //   2) 只认里面有 DefaultPackage*.bytes 的目录（把 OutputCache 之类排除）
        //   3) 取清单文件最新的那一个
        // 上游：Start
        // 下游：AssetBootstrapper.InstallAsync
        private static string ResolveSimulatePackageRoot()
        {
            string projectRoot = Directory.GetParent(Application.dataPath).FullName;
            string packageFolder = Path.Combine(projectRoot,
                "Bundles", "StandaloneWindows64", AssetBootstrapper.DefaultPackageName);

            if (!Directory.Exists(packageFolder))
            {
                return string.Empty;
            }

            string newest = string.Empty;
            DateTime newestTime = DateTime.MinValue;
            string[] subDirectories = Directory.GetDirectories(packageFolder);

            for (int i = 0; i < subDirectories.Length; i++)
            {
                string[] manifests = Directory.GetFiles(
                    subDirectories[i], AssetBootstrapper.DefaultPackageName + "*.bytes");

                if (manifests.Length == 0)
                {
                    continue;
                }

                DateTime time = File.GetLastWriteTime(manifests[0]);

                if (time > newestTime)
                {
                    newestTime = time;
                    newest = subDirectories[i];
                }
            }

            return newest;
        }
    }
}
```

## 七、风险与幻觉自查

- 幻觉自查：`BasePanel.RequireControl<T>` / `GetControl<T>` / `UIManager.Instance.ShowPanel(string, UILayer, Action<BasePanel>, Action<Exception>)` / `UILayer.Bot` / `Image.fillAmount` 均已核对源码，无编造 API。
- 风险：`UIManager` 是**异步加载**，prefab 或收集器没配好会在 `onFailed` 回调里报错（我打了 `Debug.LogError`）。
- 风险（2026-10-26 真踩）：演示驱动要用 AssetBootstrapper，而 asmdef 方向是 NBC.Boot -> NBC.Game 单向；放进 NBC.Game 会报 CS0234（命名空间 NBC 中不存在 Boot）⇒ 它必须住在 Assets/_Project/Boot/。
- 风险（2026-10-26 真踩）：UIManager 默认地址是 UI/Canvas 与 UI/<面板名>，而收集器用 AddressByFileName 时地址只有 Canvas / HpBarPanel ⇒ 必须**在第一次 ShowPanel 之前**调 SetCanvasLocation("Canvas") 与 SetPanelLocationPrefix("")，否则报 Location is invalid: 'UI/Canvas'。
- 风险：`Img_Fill` 的 `fillAmount` 方向由 prefab 的 `Fill Method / Origin` 决定；想从左往右就用 `Horizontal` + `Left`。
- 已知缺陷（本版不修）：血量是**跳变**，没有平滑过渡动画。
