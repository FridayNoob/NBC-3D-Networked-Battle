## 三、异常场景（本次三轮报错都在这段发生，已全部修掉）

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| `CS0234 命名空间 NBC 中不存在 Boot` | 演示驱动放在 `NBC.Game`，却引用 `NBC.Boot`（引用方向是 Boot→Game 单向） | 驱动搬到 `Assets/_Project/Boot/HpBarDemoBehaviour.cs` |
| `Location is invalid: 'UI/Canvas'` | `UIManager` 默认地址是 `UI/Canvas`，而收集器 `AddressByFileName` 只给 `Canvas` | 首次 `ShowPanel` 前调 `SetCanvasLocation("Canvas")` + `SetPanelLocationPrefix("")` |
| 血条位置/宽高为 0、**铺满全屏** | `UIManager.AttachToLayer` 会把**面板根铺满整层**（`offsetMin/Max = 0`），而血条直接挂在根上 | prefab 里加固定尺寸的 `Bar` 容器，把两个 Image 放进去 |
