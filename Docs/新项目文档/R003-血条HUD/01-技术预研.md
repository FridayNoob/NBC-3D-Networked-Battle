## 一、调研目标与约束

- 目标：屏幕上显示自己的血条，掉血时长度与颜色变化。
- 约束（负责人 2026-10-26 定）：
  1. **走项目 UI 框架**（`UIManager` + `BasePanel`），不用代码临时建 Canvas；
  2. 位置：屏幕 HUD（不跟随角色）；
  3. 数据：本地假数据（不接服务端快照）；
  4. 范围：只要自己一条血条（不做敌人血条、不做飘字）。

## 二、核心 API 清单（含出处）

| API | 用途 | 出处 |
| --- | --- | --- |
| `UIManager.Instance.ShowPanel(name, layer, onShown, onFailed)` | 打开面板；`layer` 用 `UILayer.Bot`（HUD） | `Framework.UI/UIManager.cs` |
| `UIManager` 的资源约定 | Canvas prefab 地址 `UI/Canvas`；面板 prefab 地址 `UI/<面板名>` | 同上（`DefaultCanvasLocation` / `DefaultPanelLocationPrefix`） |
| `BasePanel` 生命周期 | `OnInit` → `CollectControls`（按 GameObject 名字收集控件）→ `ShowMe/HideMe` | `Framework.UI/BasePanel.cs` |
| `BasePanel.GetControl<T>(string name)` | 按物体名取控件（`Image` / `TMP_Text`） | 同上 |
| `UILayers` | Canvas 下必须有 4 个层根：`Bot` / `Mid` / `Top` / `System` | `Framework.UI/UILayers.cs`（`GetLayerName`） |
| `Image.fillAmount` | 血条长度 = 当前比例（`Image.Type` 必须是 `Filled`） | Unity UGUI 文档：Image |
| `TMP_Text.text` | 血条上的数字（若需要） | TextMeshPro 文档 |

## 三、实现方式：**prefab**（负责人 2026-10-26 明确要求，不用运行时生成）

血条的整体外观、位置、图片、大小，全部由**你做的 prefab** 决定；代码只做两件事：**按名字找控件**、**改 `fillAmount` 与颜色**。
这样你以后想改位置/换图/加边框，只动 prefab，不用改代码。

**prefab 契约（代码只认这三样，其余随便改）**：

| 项 | 要求 | 谁定 |
| --- | --- | --- |
| 面板根 | 挂 `NBC.Game.UI.HpBarPanel` 组件（我写），物体名随便 | 你 |
| 控件 `Img_Fill` | **必需**，一个 `Image`，`Image Type` 必须是 **Filled** | 你，名字必须一样 |
| 控件 `Img_Bg` / `Text_Value` | 可选；有就自动用，没有也不报错 | 你 |
| 位置 / 锚点 / 大小 / 颜色 / 图片 / 层级 | **全部由你定**，代码不写死任何坐标 | 你 |

```text
代码只做这些（不建物体、不设坐标）：
  找到 Img_Fill  ->  fillAmount = 当前血 / 最大血
  找到 Img_Bg（可选）
  找到 Text_Value（可选）->  text = "80 / 100"
```

⚠️ 下面这 5 行**只是预研里验证「`fillAmount` 确实能画出血条」**，不是实现方案，也不会进项目代码：

```csharp

img.type = UnityEngine.UI.Image.Type.Filled;
```

## 五、已知坑与版本兼容

- `BundleCollectorSetting` 里 **`ui` 组的收集器为空**（`Collectors: []`），工程里**一个 UI prefab 都没有** ⇒ 走 A 的第一步是造资源，不是写代码。
- YooAsset 清单会过期（2026-10-26 已踩过一次：`AchievementConfig` 不在清单里）⇒ 新增 prefab 后**必须重建**，否则 `AssetManager` 报 `Location is invalid`。
- Canvas prefab 下必须有 `UILayers` 组件且四个层根名字**恰好**叫 `Bot`/`Mid`/`Top`/`System`，否则面板找不到父节点。
- 血条用 `Image` 必须把 `Image Type` 设成 **Filled**，否则 `fillAmount` 不起作用（这是新手最常见的一个「改了没反应」）。
- 面板与控件的**关联靠物体名字**（`CollectControls` 按名字收集）⇒ 控件名写错不会报错，只会 `GetControl` 返回 null ⇒ 必须自己断言。

## 六、结论与要负责人手动做的事

结论：**走 A，且实现 100% 是 prefab**（运行时一行创建代码都不写，见第三节的契约）。R003 的价值不只是「一条血条」，而是**把 prefab + 资源链路第一次跑通**（第一个 prefab 最贵，后面所有面板都复用），并且**外观以后由你自己改 prefab**。

需要你在 Unity 里做（我做不到，规则 13）：

1. 建目录 `Assets/_Project/Resources/UI`（或按收集器的方案定一个 `Assets/_Project/UI`）。
2. 做 **Canvas prefab**：`GameObject > UI > Canvas`，改名 `Canvas`，下面挂 4 个空物体 `Bot`/`Mid`/`Top`/`System`，再加 `UILayers` 组件并把四个层根绑上。
3. 做 **血条面板 prefab**：改名 `HpBarPanel`，根上挂 `NBC.Game.UI.HpBarPanel`（我写这个类），里面放两个 `Image`：`Img_Bg`（背景）与 `Img_Fill`（填充，Type 设 Filled），控件名必须一模一样。
4. `BundleCollectorSetting` 的 `ui` 组加收集器，路径指向上面那个 UI 目录。
5. `YooAsset → Bundle Builder → EditorSimulateBuildPipeline → Click Build` 重建清单。
