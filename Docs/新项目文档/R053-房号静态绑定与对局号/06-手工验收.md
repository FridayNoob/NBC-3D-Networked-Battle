## 一、计划

| 类别 | 内容 |
| --- | --- |
| 正常 | 单人进副本 → 打一局 → 再来一次 → 返回世界 → 再进副本 |
| 异常 | 房间满员（4 人）时第五人进房 |
| 边界 | 最后一个人离开再进来 |
| 性能 | 进出副本 5 次后，`RoomCount` 与 `BattleCount` 不涨 |

## 二、正常流程走查

1. **进副本**：Console 出现「进入房间 d1001（副本 1001，第 1 局），广播 N 份席位表」。
2. **打一局**：清完怪弹「胜利」，Console 出现「房间 d1001 开打：副本 1001（第 1 局，…）」。
3. **再来一次**：房号仍是 `d1001`，服务端日志「第 2 局」，怪满血、1 秒内出现。
4. **返回世界**：回到村口，血条与网络面板不残留。
5. **再进副本**：仍是 `d1001`，局号继续 +1（不是回到第 1 局）。

## 三、异常场景

1. 4 人满员时第五人进房：应收到「房间已满」拒绝，且不新开房。
2. 直接 `JoinRoom` 指定 `r99`：应收到「房间不存在」。
3. 客户端崩溃（拔线）：席位释放，房间保留。

## 四、性能

进出副本 5 次后：`RoomCount == 1`、`BattleCount == 0`（人不在了世界就该回收），进程内存没有持续上涨。
