## 三、它抓不到什么（文件头已如实记录）

1. **全限定名**：直接写 `TMPro.TMP_Text` 而不用 `using` ⇒ 按 `using` 行匹配会漏。
2. **通过被调方法签名泄漏的类型**：调用方源码一个字都没提那个类型（例如 `BattleSession.FromConfigMgr` 的可选参数）。
   - 这一类由**编译闸**（`Check-AsmdefBoundaries.ps1`，按 12 个 asmdef 分别编译）覆盖。

所以两者是**互补**的，不是重复：
- `using` 扫描：报错早、信息可读（「你 using 了但没引」）
- 逐 asmdef 编译：兜底（连签名泄漏、全限定名一起抓）
