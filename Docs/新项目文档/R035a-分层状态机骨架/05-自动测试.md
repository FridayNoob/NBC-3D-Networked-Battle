## 范围与框架

被测对象是纯逻辑层，不依赖 Unity 对象：`PlayerStateMachine` + `PlayerStateContext` + `PlayerStateCatalog`。
框架是 Unity Test Runner 的 EditMode（NUnit 3），文件 `Client/Assets/_Project/Tests/EditMode/Game/PlayerStateMachineTests.cs`（293 行）。
位移与动画发布用两个假实现替代：`FakeMotion : IPlayerMotion`（记录最后速度与闸门）、`RecordingSink : IPlayerAnimatorSink`（记录参数快照）。
这样测试**只验状态机算法**，不验 Animator、不验场景，EditMode 下无需进 Play。
