## 二、功能概述

进 World，按 W：角色跑步（5 m/s），动画直接切 `S_Run`（不再等 Trigger）。
按住 Alt 走路 2 m/s、按住 Shift 冲刺 8 m/s；Ctrl 切蹲，蹲下后是「蹲站/蹲走 1.5/蹲跑 3」三档。
按 J 或鼠标左键：播攻击一段 36 帧，这 36 帧里按方向键角色**不动**，动作结束自动回到当前该有的移动状态。
动作期间按 Ctrl/Shift 不会把层切走；按 K 受击（18 帧，可打断攻击），按 L 死亡（永久，之后输入无效）。

编辑期看得见的东西：`[Player_Hero]` 的 Inspector 多了「动画控制器」一栏，指向项目内控制器副本；
Animator 的参数面板里多出 `Crouch/Grounded/VerticalSpeed/ActionBusy/ActionId/StackSide/PoseIndex/Dead` 八个参数。

## 四、逐段讲解

1. **一个枚举当三个用**：`EPlayerState` 用数值分段表达「层 + 状态」——`<100` 是移动层、`<200` 是动作层、其余是反应层；
   `0/100/200` 这三个值本身又是三个上层。好处是 `HierarchicalStateMachine<EPlayerState>` 只要一个泛型参数，
   不用为「上层枚举 / 下层枚举」写两套；坏处是数值一旦手改就会错层，所以 `PlayerStateCatalog.LayerOf` 是唯一的判定入口，别处不许再写区间比较。

2. **速度语义换了口径**：旧 `PlayerAnimation` 往 `Speed` 里写的是「−1~1 的归一化速度」，新方案写「米/秒（0~8）」。
   控制器过渡因此从「靠 Trigger 切走/跑/冲」改成「按 Speed 阈值切」：`>6` 冲刺、`>3` 跑、`>0.1` 走、`<0.1` 站。
   这条必须记住：以后谁再往 `Speed` 写 0.5 表示「半速」，画面会直接变成走。

3. **按输入算目标速度，而不是拿当前速度反推状态**：`ChooseLocomotion` 只看「有没有方向 + Alt/Shift/Ctrl」，
   现场算出该去哪个状态、该用哪档速度；状态机每帧把 `Speed` 写成这一档的标称速度，再交给 `PlayerMove` 当实际移动速度。
   好处是状态和速度永远一致，不会出现「动画在跑、人走 2 m/s」的错位。

4. **动作期禁移动的两道闸**：`BlocksMovement(state)` 决定 `Speed/Direction` 是否清零；
   `Motion.MovementEnabled = canMove` 让 `PlayerMove` 直接停位移。两道都做，是因为动画参数与位移是两条独立的线，
   只关一条会出现「人不动但脚在跑」或「动画站着人却滑行」。

5. **待处理动作（pending）而不是立刻切**：`NotifyAttack/NotifyHit` 只记下「想做什么、多少帧」，
   真正的 `TryChangeUpper` 放到下一次 `Tick` 里做。原因有两个：一是网络消息可能在任意时刻到达，立刻切会让同一帧里的
   输入与状态判定顺序错乱；二是 `HierarchicalStateMachine` 不可重入，在 `OnEnter` 里再切只会排队，不如自己排队更可控。

6. **死亡是 `ForceChange`**：`NotifyDead` 不走 `TryChangeUpper`，因为 `CanEnterFrom` 可能被未来的子类拦；
   死亡必须无条件成立，所以直接 `ForceChange(Reaction, Die)`，并把 `Dead/Grounded` 等参数写死，之后 `Tick` 一进门就返回。

7. **参数发布要幂等**：`PlayerAnimatorPublisher` 记住每个参数上次写的值，值没变就不写。
   Animator 的 `SetFloat` 每次都会标记 dirty 并触发过渡重算，静止站 10 秒会白烧 CPU；幂等之后静止时零写入（05 有断言）。

8. **控制器副本 + 场景引用**：控制器从美术包复制到 `_Project/Animator/Player_Sword_Controller.controller`，
   在副本里加 8 个参数、Mute 掉 37 条旧 Trigger 过渡、添加 12 条参数驱动的 AnyState 过渡。
   **偏差（如实）**：03 写的是「World 场景里剑士实例的 Animator 直接指向副本」。实测分两半：
   ① 用脚本改 `Animator.runtimeAnimatorController` **不会**被记录成预制体覆盖（连 `m_Enabled` 都记不上）；
   ② 在 Inspector 里手动拖 `Controller` 字段**可以**记录（场景里已出现 `propertyPath: m_Controller` 覆盖，负责人手改成功）。
   最终两层都有：场景实例手动指向副本，同时 `PlayerBrain` 上保留「控制器副本」字段在 `Awake` 兜底（换场景/换实例时仍能自动换）。
   好处：Battle 用原控制器不受影响；坏处：Inspector 里要看 `PlayerBrain` 才看得到兜底那一栏。

```csharp
// 这个文件里有：
//   EPlayerLayer（枚举）：状态机三层 —— 移动层 / 动作层 / 反应层
//   EPlayerState（枚举）：所有状态的取值；前三个是「上层标识」，其余是「下层状态」

namespace NBC.Game.Player
{
    // 主要功能：标明一个状态属于哪一层，决定它的优先级与「谁先被让路」。
    // 主要数据成员：Locomotion（移动）、Action（动作）、Reaction（反应）。
    // 主要外部方法：无；层归属请用 PlayerStateCatalog.LayerOf 从状态值推。
    // 谁在用它：PlayerStateCatalog、PlayerStateMachine。
    public enum EPlayerLayer
    {
        // 移动层：站 / 走 / 跑 / 冲 / 蹲三态
        Locomotion = 0,

        // 动作层：攻击 / 技能 / 冲刺 / 格挡 / 姿势
        Action = 1,

        // 反应层：受击 / 硬直 / 死亡（被打断的那一类）
        Reaction = 2,
    }

    // 主要功能：给分层状态机一个统一的标识类型 —— 上层与下层共用这一个枚举。
    // 主要数据成员：三个上层标识（Locomotion/Action/Reaction）+ 全部下层状态。
    // 主要外部方法：无；层归属、入口、是否禁移动都由 PlayerStateCatalog 提供。
    // 谁在用它：PlayerStateMachine（HierarchicalStateMachine<EPlayerState>）、PlayerBrain（只读当前状态）。
    // 注意：数值按层分段（0/100/200 与 1~9 / 101~109 / 201~204），LayerOf 靠区间判断，新增状态必须落在本段内。
    public enum EPlayerState
    {
        // 上层：移动层
        Locomotion = 0,

        // 上层：动作层
        Action = 100,

        // 上层：反应层
        Reaction = 200,

        // 站着不动，米/秒 = 0
        Idle = 1,

        // 慢走，默认 2 米/秒（按住 Alt）
        Walk = 2,

        // 跑，默认 5 米/秒（默认可移动速度）
        Run = 3,

        // 冲刺，默认 8 米/秒（按住 Shift）
        Sprint = 4,

        // 蹲着不动
        CrouchIdle = 5,

        // 蹲着慢走，默认 1.5 米/秒
        CrouchWalk = 6,

        // 蹲着快走，默认 3 米/秒（蹲着按 Shift）
        CrouchJog = 7,

        // 跳跃上升段（R035d 接线，本步只占位）
        Jump = 8,

        // 下落段（R035d 接线，本步只占位）
        Fall = 9,

        // 攻击第 1 段
        Attack1 = 101,

        // 攻击第 2 段（R035b 接线）
        Attack2 = 102,

        // 攻击第 3 段（R035b 接线）
        Attack3 = 103,

        // 技能 1（R035b 接线）
        Skill1 = 104,

        // 技能 2（R035b 接线）
        Skill2 = 105,

        // 技能 3（R035b 接线）
        Skill3 = 106,

        // 冲刺动作（R035b 接线）
        Dash = 107,

        // 格挡（按住右键，R035b 接线）
        Block = 108,

        // 姿势 / 表情（R035c 接线）
        Pose = 109,

        // 左侧受击
        HitLeft = 201,

        // 右侧受击（R035c 接线）
        HitRight = 202,

        // 硬直（R035c 接线）
        Stun = 203,

        // 死亡：永久，不可离开

    }
```

### `Game/Player/State/PlayerStateCatalog.cs`

```csharp
// 这个文件里有：
//   PlayerStateCatalog（静态类）：状态值到「层 / 上层标识 / 入口」的换算，以及动作编号常量 PlayerActionId

namespace NBC.Game.Player
{
    // 主要功能：把 EPlayerState 的分段数值翻译成层归属、上层标识与入口状态。
    // 主要数据成员：无字段，全是静态换算（数值区间就是唯一真源）。
    // 主要外部方法：LayerOf / UpperOf / EntryOf / IsUpper / BlocksMovement。
    // 谁在用它：PlayerStateMachine 注册状态机与判断「现在能不能移动」时。
    public static class PlayerStateCatalog
    {
        // 功能：算一个状态属于哪一层。
        // 入参：state 是任意状态值（含三个上层标识本身）。
        // 返回：Locomotion / Action / Reaction。
        // 步骤：直接按数值区间判 —— 小于 100 是移动层，小于 200 是动作层，其余是反应层。
        // 上游/下游：PlayerStateMachine.构造函数、ApplyDesired 调用；不调用别人。
        public static EPlayerLayer LayerOf(EPlayerState state)
        {
            int value = (int)state;
            if (value < 100)
            {
                return EPlayerLayer.Locomotion;
            }

            if (value < 200)
            {
                return EPlayerLayer.Action;
            }

            return EPlayerLayer.Reaction;
        }

        // 功能：把层换算成状态机上层要用的标识值。
        // 入参：layer 是三层之一。
        // 返回：Locomotion / Action / Reaction 三个上层标识。
        // 步骤：一一对应，不做别的判断（层枚举的顺序就是标识值的顺序）。
        // 上游/下游：PlayerStateMachine 切层时调用。
        public static EPlayerState UpperOf(EPlayerLayer layer)
        {
            switch (layer)
            {
                case EPlayerLayer.Action:
                    return EPlayerState.Action;
                case EPlayerLayer.Reaction:
                    return EPlayerState.Reaction;
                default:
                    return EPlayerState.Locomotion;
            }
        }

        // 功能：给出某一层的入口状态（第一次进这层时停在哪个下层状态）。
        // 入参：layer 是三层之一。
        // 返回：移动层给 Idle，动作层给 Attack1，反应层给 HitLeft。
        // 步骤：只做固定映射；入口状态必须与 PlayerStateMachine 里第一个注册的下层一致，否则 HierarchicalStateMachine.Start 会抛异常。
        // 上游/下游：PlayerStateMachine.构造函数调用。
        public static EPlayerState EntryOf(EPlayerLayer layer)
        {
            switch (layer)
            {
                case EPlayerLayer.Action:
                    return EPlayerState.Attack1;
                case EPlayerLayer.Reaction:
                    return EPlayerState.HitLeft;
                default:
                    return EPlayerState.Idle;
            }
        }

        // 功能：判断一个值是不是「上层标识」而不是真正的下层状态。
        // 入参：state 是状态值。
        // 返回：true 表示它是 Locomotion / Action / Reaction 之一。
        // 步骤：与三个已知标识直接比较。
        // 上游/下游：PlayerStateMachine 的参数发布与日志过滤使用。
        public static bool IsUpper(EPlayerState state)
        {
            return state == EPlayerState.Locomotion
                || state == EPlayerState.Action
                || state == EPlayerState.Reaction;
        }

        // 功能：判断这个状态下角色还能不能自己走动。
        // 入参：state 是当前下层状态。
        // 返回：true 表示可以走（只有移动层可以），false 表示动作/反应期间必须站住。
        // 步骤：先求层，再与该层比较 —— 不要在别处复制这套判断。
        // 上游/下游：PlayerStateMachine.Tick 写 IPlayerMotion.MovementEnabled 时调用。
        public static bool BlocksMovement(EPlayerState state)
        {
            return LayerOf(state) != EPlayerLayer.Locomotion;
        }
    }

    // 主要功能：动画参数 ActionId 的取值表 —— 控制器里的 Float 参数按这些数字选动作。
    // 主要数据成员：常量（0 无动作、1~3 攻击、4~6 技能、7 冲刺、8 格挡、9 姿势、10 受击、11 硬直）。
    // 主要外部方法：OfAttack / OfSkill 把「第几段」换成 ActionId。
    // 谁在用它：PlayerStateMachine 设置 context.ActionId；动画控制器按同值判断。
    public static class PlayerActionId
    {
        // 没有动作在播
        public const float None = 0f;

        // 攻击第 1 段
        public const float Attack1 = 1f;

        // 攻击第 2 段
        public const float Attack2 = 2f;

        // 攻击第 3 段
        public const float Attack3 = 3f;

        // 技能 1
        public const float Skill1 = 4f;

        // 技能 2
        public const float Skill2 = 5f;

        // 技能 3
        public const float Skill3 = 6f;

        // 冲刺
        public const float Dash = 7f;

        // 格挡
        public const float Block = 8f;

        // 姿势 / 表情
        public const float Pose = 9f;

        // 受击
        public const float Hit = 10f;

        // 硬直
        public const float Stun = 11f;

        // 功能：把攻击段号换成 ActionId。
        // 入参：comboIndex 取 1~3，超出范围按 1 处理（调用方自己保证正确）。
        // 返回：1~3 的浮点值。
        // 步骤：直接整数转换；不查表，避免多一份数据要维护。
        // 上游/下游：PlayerStateMachine.NotifyAttack 使用（R035b 连击）。
        public static float OfAttack(int comboIndex)
        {
            if (comboIndex <= 1)
            {
                return Attack1;
            }

            return comboIndex >= 3 ? Attack3 : Attack2;
        }

        // 功能：把技能序号换成 ActionId。
        // 入参：skillIndex 取 1~3，超出范围按 1 处理。
        // 返回：4~6 的浮点值。
        // 步骤：先归一到 1~3，再加 3。
        // 上游/下游：PlayerStateMachine.NotifySkill 使用（R035b）。
        public static float OfSkill(int skillIndex)
        {
            int index = skillIndex < 1 ? 1 : (skillIndex > 3 ? 3 : skillIndex);
            return Skill1 + (index - 1);
        }
    }
}
```

### `Game/Player/State/PlayerAnimatorParams.cs`

```csharp
// 这个文件里有：
//   PlayerAnimatorNames（静态类）：动画参数名常量，状态机与发布器共用
//   PlayerAnimatorParams（只读结构）：一帧要写给 Animator 的全部参数值

namespace NBC.Game.Player
{
    // 主要功能：集中放动画参数名，避免「一个地方写 "Speed"、另一个地方写 "speed"」这种拼写事故。
    // 主要数据成员：十个参数名常量（前两个是控制器原有参数，其余是 R035a 新增）。
    // 主要外部方法：无。
    // 谁在用它：PlayerAnimatorPublisher（把它们换成哈希）、PlayerAnimation（沿用原有 Speed/Direction）。
    public static class PlayerAnimatorNames
    {
        // 移动速度（-1~1 的归一化值，控制器按阈值判走/跑/冲）
        public const string Speed = "Speed";

        // 横向速度（-1 左 ~ 1 右；目前只用于表现）
        public const string Direction = "Direction";

        // 是否蹲下（true 时走蹲三态）
        public const string Crouch = "Crouch";

        // 是否踩在地面上（跳跃时 false）
        public const string Grounded = "Grounded";

        // 竖直速度（米/秒，正数上升、负数下落）
        public const string VerticalSpeed = "VerticalSpeed";

        // 是否有动作在播（true 时进动作状态）
        public const string ActionBusy = "ActionBusy";

        // 动作编号（0 无 / 1~3 攻击 / 4~6 技能 / 7 冲刺 / 8 格挡 / 9 姿势 / 10 受击 / 11 硬直）
        public const string ActionId = "ActionId";
```

### `Game/Player/State/PlayerStateMachine.cs`

```csharp
// 这个文件里有：
//   PlayerStateMachine（类）：玩家分层状态机 —— 纯逻辑，不读 Time / Input / Animator，测试可直接驱动

using System;
using NBC.Framework.Fsm;

namespace NBC.Game.Player
{
    // 主要功能：按「反应 > 动作 > 移动」的优先级决定当前该在哪个状态，并把结果翻译成移动闸门与动画参数。
    // 主要数据成员：m_context（共享状态）、m_timings（动作帧数）、m_speeds（五档速度）、m_fsm（三层状态机）。
    // 主要外部方法：Tick 推进一帧；NotifyAttack/NotifyHit/NotifyDead 接收外部事件；Parameters 读当前动画参数。
    // 谁在用它：PlayerBrain 每帧调 Tick 并发布 Parameters；EditMode 测试用假 IPlayerMotion 驱动它。
    // 注意：本类不引用 UnityEngine —— 取绝对值用 System.Math，状态名用枚举，保证能在 EditMode 无场景下跑。
    public sealed class PlayerStateMachine
    {
        // 共享状态（蹲/动作/死亡等），每帧读写
        private readonly PlayerStateContext m_context;

        // 各动作持续帧数，60fps 口径
        private readonly PlayerTimings m_timings;

        // 五档移动速度，米/秒
        private readonly PlayerSpeeds m_speeds;

        // 三层状态机：移动层 / 动作层 / 反应层
        private readonly HierarchicalStateMachine<EPlayerState> m_fsm;

        // 有没有「等着这一帧执行」的动作请求
        private bool m_hasPendingAction;

        // 待执行动作的状态
        private EPlayerState m_pendingState;

        // 待执行动作的编号（写进 ActionId）
        private float m_pendingActionId;

        // 待执行动作的总帧数
        private int m_pendingFrames;

        // 功能：注册三层状态机并进入移动层的 Idle。
        // 入参：context 共享状态（不能为 null，且 Motion 不能为 null）；timings 动作帧数；speeds 五档速度。
        // 返回：无。
        // 步骤：1) 校验参数 2) 依次注册三层（先上层后下层，第一层下层自动成为入口）3) 启动到移动层。
        // 上游/下游：PlayerBrain.Awake 构造；内部调用 RegisterLocomotion/Action/Reaction。
        public PlayerStateMachine(PlayerStateContext context, PlayerTimings timings, PlayerSpeeds speeds)
        {
            if (context == null)
            {
                throw new ArgumentNullException(nameof(context), "[PlayerStateMachine] 缺少共享状态。");
            }

            if (context.Motion == null)
            {
                throw new ArgumentNullException(nameof(context), "[PlayerStateMachine] 共享状态里没有 IPlayerMotion。");
            }

            m_context = context;
            m_timings = timings;
            m_speeds = speeds;
            m_fsm = new HierarchicalStateMachine<EPlayerState>();

            m_fsm.RegisterUpper(EPlayerState.Locomotion, new PlayerLayeredState(EPlayerState.Locomotion), EPlayerState.Idle);
            RegisterLocomotionStates();
            m_fsm.RegisterUpper(EPlayerState.Action, new PlayerLayeredState(EPlayerState.Action), EPlayerState.Attack1);
            RegisterActionStates();
            m_fsm.RegisterUpper(EPlayerState.Reaction, new PlayerLayeredState(EPlayerState.Reaction), EPlayerState.HitLeft);
            RegisterReactionStates();
            m_fsm.Start(EPlayerState.Locomotion);

            m_context.Motion.MovementEnabled = true;
        }

        // 当前上层（Locomotion / Action / Reaction）
        public EPlayerLayer Layer
        {
            get { return PlayerStateCatalog.LayerOf(m_fsm.UpperCurrent); }
        }

        // 当前下层状态（真正的「在干什么」）
        public EPlayerState State
        {
            get { return m_fsm.LowerCurrent; }
        }

        // 当前状态路径，形如 "Locomotion/Run"；给日志与调试面板看
        public string CurrentPath
        {
            get { return m_fsm.CurrentPath; }
        }

        // 是否已死亡（死亡后 Tick 只维持参数、不再切换状态）
        public bool IsDead
        {
            get { return m_context.Dead; }
        }

        // 这一帧要写给 Animator 的参数快照
        public PlayerAnimatorParams Parameters
        {
            get { return m_context.BuildParams(); }
        }

        // 状态真的发生切换后触发；参数是切换记录（含帧号与前后状态名）
        public event Action<StateChangeRecord> StateChanged
        {
            add { m_fsm.StateChanged += value; }
            remove { m_fsm.StateChanged -= value; }
        }

        // 功能：推进一帧 —— 先看有没有动作要播，再决定移动状态，最后同步移动闸门与速度。
        // 入参：frame 逻辑帧号（必须单调递增，60fps 口径）；input 这一帧的输入快照。
        // 返回：无。
        // 步骤：1) 死亡时只维持零速 2) 处理蹲切换 3) 推进/消费动作 4) 动作中不选移动态 5) 同步 MovementEnabled 与速度 6) 推状态机帧。
        // 上游/下游：PlayerBrain.Update 每个固定步长调用一次；内部调用 ChooseLocomotion/ApplyLocomotion。
        public void Tick(int frame, in PlayerInput input)
        {
            if (m_context.Dead)
            {
                m_context.Speed = 0f;
                m_context.Direction = 0f;
                m_context.ResetAction();
                m_context.Motion.MovementEnabled = false;
                m_context.Motion.SetMoveSpeed(0f);
                m_fsm.Tick(frame);
                return;
            }

            if (input.CrouchToggle && !m_context.ActionBusy)
            {
                m_context.Crouch = !m_context.Crouch;
            }

            AdvanceAction();

            if (m_hasPendingAction)
            {
                ApplyPendingAction();
            }

            if (!m_context.ActionBusy)
            {
                ApplyLocomotion(ChooseLocomotion(input));
            }

            bool canMove = !PlayerStateCatalog.BlocksMovement(m_fsm.LowerCurrent);
            m_context.Speed = canMove ? SpeedOf(m_fsm.LowerCurrent) : 0f;
            m_context.Direction = canMove ? ClampDirection(input.MoveX) : 0f;
            m_context.Motion.SetMoveSpeed(m_context.Speed);
            m_context.Motion.MovementEnabled = canMove;

            m_fsm.Tick(frame);
        }

        // 功能：请求播攻击第 1 段。
        // 入参：无。
        // 返回：true 表示请求已受理（下一帧生效）；false 表示已死或已有动作在播。
        // 步骤：死亡与动作忙碌时直接拒绝；连击（第 2/3 段）留给 R035b。
        // 上游/下游：PlayerBrain 攻击键调用；内部调用 BeginAction。
        public bool NotifyAttack()
        {
            if (m_context.Dead || m_context.ActionBusy)
            {
                return false;
            }

            return BeginAction(EPlayerState.Attack1, PlayerActionId.Attack1, m_timings.AttackFrames);
        }

        // 功能：请求播受击；受击优先级高于攻击，会把正在播的攻击打断。
        // 入参：fromLeft 为 true 表示从左侧被打（决定 StackSide 与 HitLeft/HitRight）。
        // 返回：true 表示请求已受理；false 表示已死。
        // 步骤：死亡直接拒绝；否则写 StackSide 并排队受击。
        // 上游/下游：PlayerBrain 受击调试键 / 将来网络受击消息调用。
        public bool NotifyHit(bool fromLeft)
        {
            if (m_context.Dead)
            {
                return false;
            }

            m_context.StackSide = fromLeft ? -1f : 1f;
            EPlayerState state = fromLeft ? EPlayerState.HitLeft : EPlayerState.HitRight;
            return BeginAction(state, PlayerActionId.Hit, m_timings.HitFrames);
        }

        // 功能：请求进入死亡状态，之后任何移动/动作请求都无效。
        // 入参：无。
        // 返回：true 表示这次真的死了；false 表示之前已经死了。
        // 步骤：1) 置死亡标记 2) 清动作与位移闸门 3) 强制切到反应层的 Die（跳过准入检查）。
        // 上游/下游：PlayerBrain 死亡调试键 / 将来网络死亡消息调用。
        public bool NotifyDead()
        {
            if (m_context.Dead)
            {
                return false;
            }

            m_context.Dead = true;
            m_context.ResetAction();
            m_hasPendingAction = false;
            m_context.Motion.MovementEnabled = false;
            m_context.Motion.SetMoveSpeed(0f);
            m_fsm.ForceChange(EPlayerState.Reaction, EPlayerState.Die);
            return true;
        }

        // 功能：按输入选一个移动状态（只在没有动作在播时用）。
        // 入参：input 这一帧的输入。
        // 返回：Idle / Walk / Run / Sprint / CrouchIdle / CrouchWalk / CrouchJog 之一。
        // 步骤：没方向就站着；蹲着优先蹲三态；否则按 Shift→冲刺、Alt→慢走、默认跑。
        // 上游/下游：Tick 调用。
        private EPlayerState ChooseLocomotion(in PlayerInput input)
        {
            if (!input.HasDirection())
            {
                return m_context.Crouch ? EPlayerState.CrouchIdle : EPlayerState.Idle;
            }

            if (m_context.Crouch)
            {
                return input.SprintHeld ? EPlayerState.CrouchJog : EPlayerState.CrouchWalk;
            }

            if (input.SprintHeld)
            {
                return EPlayerState.Sprint;
            }

            return input.WalkHeld ? EPlayerState.Walk : EPlayerState.Run;
        }

        // 功能：把目标移动状态落到状态机上（同层只换下层，跨层才换上层）。
        // 入参：desired 目标移动状态。
        // 返回：无；切换被拒绝时保持原状态。
        // 步骤：当前已在移动层就 TryChangeLower，否则 TryChangeUpper(移动层, desired)。
        // 上游/下游：Tick 调用；下游 HierarchicalStateMachine.TryChangeLower/TryChangeUpper。
        private void ApplyLocomotion(EPlayerState desired)
        {
            if (m_fsm.UpperCurrent == EPlayerState.Locomotion)
            {
                if (m_fsm.LowerCurrent != desired)
                {
                    m_fsm.TryChangeLower(desired);
                }

                return;
            }

            m_fsm.TryChangeUpper(EPlayerState.Locomotion, desired);
        }

        // 功能：推进当前动作的帧计数，到点就结束动作。
        // 入参：无。
        // 返回：无。
        // 步骤：没有动作直接返回；有动作就 +1 帧，到达 ActionFrames 时清动作（0 表示不自动结束）。
        // 上游/下游：Tick 调用；下游 PlayerStateContext.ResetAction。
        private void AdvanceAction()
        {
            if (!m_context.ActionBusy)
            {
                return;
            }

            m_context.ActionFrame++;
            if (m_context.ActionFrames > 0 && m_context.ActionFrame >= m_context.ActionFrames)
            {
                m_context.ResetAction();
            }
        }

        // 功能：把排队中的动作请求真正执行（切到对应层与状态）。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 先写 ActionBusy/ActionId/帧数 2) 目标就是当前配置时只重置计时 3) 否则 TryChangeUpper，被拒绝则回滚为「没有动作」。
        // 上游/下游：Tick 调用；下游 HierarchicalStateMachine.TryChangeUpper。
        private void ApplyPendingAction()
        {
            m_hasPendingAction = false;
            m_context.ActionBusy = true;
            m_context.ActionId = m_pendingActionId;
            m_context.ActionFrame = 0;
            m_context.ActionFrames = m_pendingFrames;

            EPlayerState upper = PlayerStateCatalog.UpperOf(PlayerStateCatalog.LayerOf(m_pendingState));

            if (m_fsm.UpperCurrent == upper && m_fsm.LowerCurrent == m_pendingState)
            {
                return;
            }

            if (!m_fsm.TryChangeUpper(upper, m_pendingState))
            {
                m_context.ResetAction();
            }
        }

        // 功能：登记一个待执行动作。
        // 入参：state 目标状态；actionId 写进动画参数的动作编号；frames 总帧数（60fps，<=0 表示不自动结束）。
        // 返回：true 表示已登记。
        // 步骤：只写 pending 字段，下一帧 Tick 再执行 —— 保证一帧内只发生一次状态切换。
        // 上游/下游：NotifyAttack / NotifyHit 调用。
        private bool BeginAction(EPlayerState state, float actionId, int frames)
        {
            m_pendingState = state;
            m_pendingActionId = actionId;
            m_pendingFrames = frames;
            m_hasPendingAction = true;
            return true;
        }

        // 功能：按状态取这一档移动速度。
        // 入参：state 当前移动状态。
        // 返回：米/秒；非移动状态返回 0。
        // 步骤：switch 一一映射到 PlayerSpeeds 的五个字段。
        // 上游/下游：Tick 调用。
        private float SpeedOf(EPlayerState state)
        {
            switch (state)
            {
                case EPlayerState.Walk:
                    return m_speeds.Walk;
                case EPlayerState.Run:
                    return m_speeds.Run;
                case EPlayerState.Sprint:
                    return m_speeds.Sprint;
                case EPlayerState.CrouchWalk:
                    return m_speeds.CrouchWalk;
                case EPlayerState.CrouchJog:
                    return m_speeds.CrouchJog;
                default:
                    return 0f;
            }
        }

        // 功能：把横向输入夹到 -1~1。
        // 入参：value 原始横向输入。
        // 返回：夹紧后的值。
        // 步骤：两段比较，不调用 UnityEngine.Mathf（本类保持纯 C#）。
        // 上游/下游：Tick 调用。
        private static float ClampDirection(float value)
        {
            if (value < -1f)
            {
                return -1f;
            }

            return value > 1f ? 1f : value;
        }

        // 功能：注册移动层的九个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：Idle 必须第一个注册（它会成为入口），其余顺序无关。
        // 上游/下游：构造函数调用。
        private void RegisterLocomotionStates()
        {
            RegisterSub(EPlayerState.Idle);
            RegisterSub(EPlayerState.Walk);
            RegisterSub(EPlayerState.Run);
            RegisterSub(EPlayerState.Sprint);
            RegisterSub(EPlayerState.CrouchIdle);
            RegisterSub(EPlayerState.CrouchWalk);
            RegisterSub(EPlayerState.CrouchJog);
            RegisterSub(EPlayerState.Jump);
            RegisterSub(EPlayerState.Fall);
        }

        // 功能：注册动作层的九个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：Attack1 第一个注册（成为入口）。
        // 上游/下游：构造函数调用。
        private void RegisterActionStates()
        {
            RegisterSub(EPlayerState.Attack1);
            RegisterSub(EPlayerState.Attack2);
            RegisterSub(EPlayerState.Attack3);
            RegisterSub(EPlayerState.Skill1);
            RegisterSub(EPlayerState.Skill2);
            RegisterSub(EPlayerState.Skill3);
            RegisterSub(EPlayerState.Dash);
            RegisterSub(EPlayerState.Block);
            RegisterSub(EPlayerState.Pose);
        }

        // 功能：注册反应层的四个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：HitLeft 第一个注册（成为入口）。
        // 上游/下游：构造函数调用。
        private void RegisterReactionStates()
        {
            RegisterSub(EPlayerState.HitLeft);
            RegisterSub(EPlayerState.HitRight);
            RegisterSub(EPlayerState.Stun);
            RegisterSub(EPlayerState.Die);
        }

        // 功能：把某个下层状态注册到它所属的层下。
        // 入参：sub 下层状态。
        // 返回：无。
        // 步骤：用 LayerOf 算出层，再 UpperOf 换成上层标识 —— 层归属只在这里推一次。
        // 上游/下游：上面三个 Register*States 调用；下游 HierarchicalStateMachine.RegisterSub。
        private void RegisterSub(EPlayerState sub)
        {
            EPlayerState upper = PlayerStateCatalog.UpperOf(PlayerStateCatalog.LayerOf(sub));
            m_fsm.RegisterSub(upper, sub, new PlayerLayeredState(sub));
        }
    }
}
```

```csharp
// 这个文件里有：
//   PlayerAnimatorPublisher（组件）：把一帧动画参数写进 Animator，并保证「值没变就不写」

using System.Collections.Generic;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：实现 IPlayerAnimatorSink —— 状态机算好的 bool/float 参数由它统一写进 Animator。
    // 主要数据成员：m_animator（目标动画机）、参数哈希与上次写入值（用于幂等）。
    // 主要外部方法：Apply 写一帧参数；Reset 在编辑器里自动抓 Animator。
    // 谁在用它：PlayerBrain.Update 每帧调一次；本身挂在玩家根节点上。
    // 注意：控制器没声明的参数只告警一次并跳过，不要每帧 SetFloat —— Unity 会为每个缺失参数刷一条警告， Console 会被淹掉。
    [DisallowMultipleComponent]
    public sealed class PlayerAnimatorPublisher : MonoBehaviour, IPlayerAnimatorSink
    {
        // 浮点参数在数组里的下标
        private const int FloatSpeed = 0;
        private const int FloatDirection = 1;
        private const int FloatVerticalSpeed = 2;
        private const int FloatActionId = 3;
        private const int FloatStackSide = 4;
        private const int FloatPoseIndex = 5;
        private const int FloatCount = 6;

        // 布尔参数在数组里的下标
        private const int BoolCrouch = 0;
        private const int BoolGrounded = 1;
        private const int BoolActionBusy = 2;
        private const int BoolDead = 3;
        private const int BoolCount = 4;

        // 六个浮点参数的控制器名字，顺序与上面的下标一致
        private static readonly string[] FloatNames =
        {
            PlayerAnimatorNames.Speed,
            PlayerAnimatorNames.Direction,
            PlayerAnimatorNames.VerticalSpeed,
            PlayerAnimatorNames.ActionId,
            PlayerAnimatorNames.StackSide,
            PlayerAnimatorNames.PoseIndex,
        };

        // 四个布尔参数的控制器名字，顺序与上面的下标一致
        private static readonly string[] BoolNames =
        {
            PlayerAnimatorNames.Crouch,
            PlayerAnimatorNames.Grounded,
            PlayerAnimatorNames.ActionBusy,
            PlayerAnimatorNames.Dead,
        };

        // 目标动画机；为空时 Awake 自动往子物体找
        [SerializeField] private Animator m_animator;

        // 控制器缺参数时是否打一条警告（只打一次）
        [SerializeField] private bool m_logMissingParameters = true;

        // 参数哈希
        private int[] m_floatHashes;

        // 上次写入的浮点值（NaN 表示还没写过）
        private float[] m_floatLast;

        // 该浮点参数是否存在于控制器里
        private bool[] m_floatValid;

        // 参数哈希
        private int[] m_boolHashes;

        // 上次写入的布尔值
        private bool[] m_boolLast;

        // 该布尔参数是否存在于控制器里
        private bool[] m_boolValid;

        // 是否已经写过至少一次（用于首次必写）
        private bool[] m_boolWritten;

        // 是否完成了初始化（找 Animator + 查参数）
        private bool m_ready;

        // 功能：在编辑器里加组件时自动抓子物体的 Animator，省得手拖。
        // 入参：无。
        // 返回：无。
        // 步骤：直接 GetComponentInChildren 赋给序列化字段。
        // 上游/下游：Unity 编辑器调用。
        private void Reset()
        {
            m_animator = GetComponentInChildren<Animator>();
        }

        // 功能：场景启动时完成初始化。
        // 入参：无。
        // 返回：无。
        // 步骤：调用 EnsureReady 一次。
        // 上游/下游：Unity 生命周期；下游 EnsureReady。
        private void Awake()
        {
            EnsureReady();
        }

        // 功能：把一帧参数写进 Animator（幂等：没变就不写）。
        // 入参：parameters 是状态机产出的只读快照。
        // 返回：无。
        // 步骤：1) 确保初始化 2) 六个浮点 3) 四个布尔。
        // 上游/下游：PlayerBrain.Update 调用。
        public void Apply(in PlayerAnimatorParams parameters)
        {
            EnsureReady();

            if (m_animator == null)
            {
                return;
            }

            WriteFloat(FloatSpeed, parameters.Speed);
            WriteFloat(FloatDirection, parameters.Direction);
            WriteFloat(FloatVerticalSpeed, parameters.VerticalSpeed);
            WriteFloat(FloatActionId, parameters.ActionId);
            WriteFloat(FloatStackSide, parameters.StackSide);
            WriteFloat(FloatPoseIndex, parameters.PoseIndex);

            WriteBool(BoolCrouch, parameters.Crouch);
            WriteBool(BoolGrounded, parameters.Grounded);
            WriteBool(BoolActionBusy, parameters.ActionBusy);
            WriteBool(BoolDead, parameters.Dead);
        }

        // 功能：找 Animator、查参数表、缓存哈希。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 已初始化直接返回 2) 找 Animator，找不到就禁用本组件 3) 关根运动 4) 按参数表建哈希，缺的标 invalid 并告警一次。
        // 上游/下游：Awake / Apply 调用。
        private void EnsureReady()
        {
            if (m_ready)
            {
                return;
            }

            m_ready = true;

            if (m_animator == null)
            {
                m_animator = GetComponentInChildren<Animator>();
            }

            if (m_animator == null)
            {
                Debug.LogError("[PlayerAnimator] 找不到 Animator，动画参数不会生效。", this);
                return;
            }

            m_animator.applyRootMotion = false;

            Dictionary<string, AnimatorControllerParameterType> existing = new Dictionary<string, AnimatorControllerParameterType>();
            AnimatorControllerParameter[] parameters = m_animator.parameters;
            for (int i = 0; i < parameters.Length; i++)
            {
                existing[parameters[i].name] = parameters[i].type;
            }

            m_floatHashes = new int[FloatCount];
            m_floatLast = new float[FloatCount];
            m_floatValid = new bool[FloatCount];
            m_boolHashes = new int[BoolCount];
            m_boolLast = new bool[BoolCount];
            m_boolValid = new bool[BoolCount];
            m_boolWritten = new bool[BoolCount];

            List<string> missing = new List<string>();

            for (int i = 0; i < FloatCount; i++)
            {
                m_floatHashes[i] = Animator.StringToHash(FloatNames[i]);
                m_floatLast[i] = float.NaN;
                m_floatValid[i] = HasParameter(existing, FloatNames[i], AnimatorControllerParameterType.Float);
                if (!m_floatValid[i])
                {
                    missing.Add(FloatNames[i] + "(Float)");
                }
            }

            for (int i = 0; i < BoolCount; i++)
            {
                m_boolHashes[i] = Animator.StringToHash(BoolNames[i]);
                m_boolValid[i] = HasParameter(existing, BoolNames[i], AnimatorControllerParameterType.Bool);
                if (!m_boolValid[i])
                {
                    missing.Add(BoolNames[i] + "(Bool)");
                }
            }

            if (missing.Count > 0 && m_logMissingParameters)
            {
                Debug.LogWarning("[PlayerAnimator] 控制器缺少参数：" + string.Join("、", missing) + "；对应的动画切换不会生效。", this);
            }
        }

        // 功能：判断控制器里有没有指定名字、指定类型的参数。
        // 入参：existing 参数名到类型的表；name 参数名；type 期望类型。
        // 返回：存在且类型一致返回 true。
        // 步骤：先查表再比类型。
        // 上游/下游：EnsureReady 调用。
        private static bool HasParameter(
            Dictionary<string, AnimatorControllerParameterType> existing,
            string name,
            AnimatorControllerParameterType type)
        {
            AnimatorControllerParameterType actual;
            return existing.TryGetValue(name, out actual) && actual == type;
        }

        // 功能：写一个浮点参数，值没变就跳过。
        // 入参：index 参数下标；value 目标值。
        // 返回：无。
        // 步骤：参数缺失直接返回；与上次值近似相等也返回；否则 SetFloat 并记下。
        // 上游/下游：Apply 调用；下游 Animator.SetFloat。
        private void WriteFloat(int index, float value)
        {
            if (!m_floatValid[index])
            {
                return;
            }

            if (!float.IsNaN(m_floatLast[index]) && Mathf.Approximately(m_floatLast[index], value))
            {
                return;
            }

            m_floatLast[index] = value;
            m_animator.SetFloat(m_floatHashes[index], value);
        }

        // 功能：写一个布尔参数，值没变就跳过。
        // 入参：index 参数下标；value 目标值。
        // 返回：无。
        // 步骤：参数缺失直接返回；写过且值相同也返回；否则 SetBool 并记下。
        // 上游/下游：Apply 调用；下游 Animator.SetBool。
        private void WriteBool(int index, bool value)
        {
            if (!m_boolValid[index])
            {
                return;
            }

            if (m_boolWritten[index] && m_boolLast[index] == value)
            {
                return;
            }

            m_boolWritten[index] = true;
            m_boolLast[index] = value;
            m_animator.SetBool(m_boolHashes[index], value);
        }
    }
}
```

```csharp
// 这个文件里有：
//   PlayerBrain（组件）：玩家的输入适配层 —— 读键位、按固定 60fps 驱动机器、把参数写给 Animator
//
// 它只做三件事：读输入、按固定步长推进 PlayerStateMachine、发布动画参数。
// 具体「什么状态、什么时候切」全在 PlayerStateMachine 里，本类不做判断。

using NBC.Framework.Fsm;
using NBC.Framework.Input;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：把玩家输入与角色状态机接起来，并保证逻辑按固定 60fps 推进（不随渲染帧率抖动）。
    // 主要数据成员：m_move（位移）、m_publisher（动画参数）、m_context（共享状态）、m_machine（三层状态机）。
    // 主要外部方法：NotifyAttack / NotifyHit / NotifyDead（给网络消息与调试键用）。
    // 谁在用它：挂在 World 的 [Player_Hero] 根节点上；Battle 不用这套（Battle 走网络快照）。
    // 注意：只有本类允许读 Input 与 Time —— 状态机是纯逻辑，测试直接喂 PlayerInput 与帧号。
    public sealed class PlayerBrain : MonoBehaviour
    {
        // 每秒逻辑帧数（动作帧数都按这个口径标）
        private const float FixedDeltaSeconds = 1f / 60f;

        // 一帧最多补几个逻辑步（卡顿后防止一次补几百帧把角色瞬移）
        private const int MaxCatchUpSteps = 4;

        // 玩家身上的移动组件（Awake 自动找）
        [SerializeField]
        private PlayerMove m_move;

        // 是否关掉旧的 PlayerAnimation（World 改由状态机 + 参数驱动；关掉避免它继续 SetTrigger）
        [SerializeField]
        private bool m_disableLegacyAnimation = true;

        // World 专用的动画控制器副本（为空则沿用模型自带控制器；Battle 不挂本组件，不受影响）
        [SerializeField]
        private RuntimeAnimatorController m_animatorControllerOverride;

        [Header("速度档位（米/秒）")]
        // 慢走速度
        [SerializeField]
        private float m_walkSpeed = 2f;

        // 默认跑速
        [SerializeField]
        private float m_runSpeed = 5f;

        // 冲刺速度
        [SerializeField]
        private float m_sprintSpeed = 8f;

        // 蹲走速度
        [SerializeField]
        private float m_crouchWalkSpeed = 1.5f;

        // 蹲跑速度
        [SerializeField]
        private float m_crouchJogSpeed = 3f;

        [Header("动作时长（60fps 帧数）")]
        // 攻击一段帧数
        [SerializeField]
        private int m_attackFrames = 36;

        private int m_frame;

        private float m_frameAccumulator;

        // 功能：找齐组件、构造状态机、订阅状态切换日志。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 找 PlayerMove（找不到就禁用自己）2) 找或加 Publisher 3) 关旧动画 4) 换控制器副本 5) 建上下文与状态机 6) 订阅日志。
        // 上游/下游：Unity 生命周期；下游 PlayerStateMachine 构造函数。
        private void Awake()

            if (m_motion == null)

                enabled = false;
                return;

            if (m_publisher == null)
            {
                m_publisher = gameObject.AddComponent<PlayerAnimatorPublisher>();
            }

            if (m_disableLegacyAnimation)
            {
                PlayerAnimation legacy = GetComponent<PlayerAnimation>();
                if (legacy != null)
                {
                    legacy.enabled = false;
                }
            }

            if (m_animatorControllerOverride != null)
            {
                Animator animator = GetComponentInChildren<Animator>();
                if (animator != null && animator.runtimeAnimatorController != m_animatorControllerOverride)
                {
                    animator.runtimeAnimatorController = m_animatorControllerOverride;
                }
            }

            m_context = new PlayerStateContext(m_motion);
            PlayerTimings timings = new PlayerTimings(
                m_attackFrames,
                m_hitFrames,
                m_skillFrames,
                m_dashFrames,
                m_stunFrames,
                m_poseFrames);
            PlayerSpeeds speeds = new PlayerSpeeds(
                m_walkSpeed,
                m_runSpeed,
                m_sprintSpeed,
                m_crouchWalkSpeed,
                m_crouchJogSpeed);
            m_machine = new PlayerStateMachine(m_context, timings, speeds);

            if (m_logStateChanges)
            {
                m_machine.StateChanged += OnStateChanged;
            }
        }

        // 功能：每帧读输入、按固定步长推进逻辑、发布动画参数。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 读一次输入 2) 先处理攻击/受击/死亡键（写 pending）3) 累加时间并按 1/60 秒补步 4) 只让第一步消费「蹲切换」 5) 发布了就写一次参数。
        // 上游/下游：Unity 生命周期；下游 PlayerStateMachine.Tick、PlayerAnimatorPublisher.Apply。
        private void Update()
        {
            if (m_machine == null)
            {
                return;
            }

            PlayerInput input = ReadInput();
            HandleActionKeys();

            m_frameAccumulator += Time.deltaTime;
            int steps = 0;
            bool firstStep = true;

            while (m_frameAccumulator >= FixedDeltaSeconds && steps < MaxCatchUpSteps)
            {
                m_frameAccumulator -= FixedDeltaSeconds;
                steps++;
                m_frame++;

                PlayerInput stepInput = firstStep
                    ? input
                    : new PlayerInput(input.MoveX, input.MoveY, input.WalkHeld, input.SprintHeld, false);
                firstStep = false;
                m_machine.Tick(m_frame, stepInput);
            }

            if (steps == 0)
            {
                return;
            }

            if (m_frameAccumulator > FixedDeltaSeconds * MaxCatchUpSteps)
            {
                m_frameAccumulator = 0f;
            }

            m_publisher.Apply(m_machine.Parameters);
        }

        public EPlayerState CurrentState
        {
            get { return m_machine != null ? m_machine.State : EPlayerState.Idle; }
        }

        // 功能：处理攻击/受击/死亡的按键请求。
        // 入参：无。
        // 返回：无。
        // 步骤：调试键先判（K 左受击、L 死亡），再看攻击键（J 或鼠标左键）；是否启用由 Inspector 开关决定。
        // 上游/下游：Update 调用；下游 Notify*。
        private void HandleActionKeys()
        {
            if (m_enableDebugKeys)
            {
                if (Input.GetKeyDown(m_hitKey))
                {
                    NotifyHit(true);
                }

                if (Input.GetKeyDown(m_dieKey))
                {
                    NotifyDead();
                }
            }

            if (!m_enableLocalAttack)
            {
                return;
            }

            if (Input.GetKeyDown(m_attackKey) || Input.GetMouseButtonDown(0))
            {
                NotifyAttack();
            }
        }

        // 功能：把这一帧的键位读成 PlayerInput。
        // 入参：无。
        // 返回：输入快照。
        // 步骤：移动轴取 InputManager（-1000~1000 除 1000）；Alt=慢走、Shift=冲刺、Ctrl 按下=切换蹲；输入被禁用时轴按 0。
        // 上游/下游：Update 调用；下游 PlayerStateMachine.Tick。
        private static PlayerInput ReadInput()
        {
            float x = 0f;
            float y = 0f;

            InputManager manager = InputManager.Instance;
            if (manager != null && manager.IsEnabled)
            {
                InputCommand command = manager.Current;
                x = (float)command.MoveX / InputCommand.MoveScale;
                y = (float)command.MoveY / InputCommand.MoveScale;
            }

            bool walk = Input.GetKey(KeyCode.LeftAlt) || Input.GetKey(KeyCode.RightAlt);
            bool sprint = Input.GetKey(KeyCode.LeftShift) || Input.GetKey(KeyCode.RightShift);
            bool crouch = Input.GetKeyDown(KeyCode.LeftControl) || Input.GetKeyDown(KeyCode.RightControl);
            return new PlayerInput(x, y, walk, sprint, crouch);
        }

        // 功能：把一次状态切换打到 Console。
        // 入参：record 切换记录（含帧号与前后状态名）。
        // 返回：无。
        // 步骤：直接用记录自带的 ToString，格式 "[f12] Locomotion/Idle -> Locomotion/Run"。
        // 上游/下游：PlayerStateMachine.StateChanged 事件。
        private void OnStateChanged(StateChangeRecord record)
        {
            Debug.Log("[PlayerBrain] " + record);
        }

        // 功能：组件销毁时退订事件，避免状态机持有已销毁的 MonoBehaviour。
        // 入参：无。
        // 返回：无。
        // 步骤：有状态机就退订。
        // 上游/下游：Unity 生命周期。
        private void OnDestroy()
        {
            if (m_machine != null)
            {
                m_machine.StateChanged -= OnStateChanged;
            }
        }
    }
}
```

```csharp
// 这个文件里有：
//   PlayerMove（类）：四向移动（W/A/S/D 都是转身朝该方向再前进）；不斜走，朝向只由方向键决定

using NBC.Framework.Input;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧读输入，取主导轴得到 W/A/S/D 四种之一，统一「转身朝该方向 + 沿该方向前进」。
    // 主要数据成员：m_moveSpeed（米/秒）、m_turnSpeed（度/秒）、m_forwardSpeed / m_sideSpeed（给动画的分量）。
    // 主要外部方法：ForwardSpeed / SideSpeed / MoveSpeed / CurrentSpeed（只读属性）、SetMoveSpeed、MovementEnabled。
    // 谁在用它：挂在角色物体上；输入取自 InputManager.Instance.Current，键位在 InputMapping 里可改；World 里由 PlayerBrain 通过 IPlayerMotion 驱动。
    public sealed class PlayerMove : MonoBehaviour, IPlayerMotion
    {
        // 每秒走多少米。场景里 1 单位 = 1 米，5 就是每秒 5 米
        [SerializeField] private float m_moveSpeed = 5f;

        // 转身速度，度/秒。720 约等于 0.125 秒转 90 度
        [SerializeField] private float m_turnSpeed = 720f;

        // 是否用「参考体的坐标轴」来算方向（World 场景用相机轴；Battle 保持世界轴）
        [SerializeField] private bool m_useReferenceAxes = false;

        // 参考体：留空时用 Camera.main；只有 m_useReferenceAxes 为 true 才用
        [SerializeField] private Transform m_reference = null;

        // 是否允许位移：动作/受击/死亡期间由状态机置 false，实现「动作即停」（组件本身不禁用）
        private bool m_movementEnabled = true;

        // 功能：读/写位移闸门。
        // 入参：true 允许移动；false 原地站住。
        // 返回：当前是否允许移动。
        // 步骤：置 false 时顺手把三个速度清零，避免下游读到「停之前那一帧」的旧值。
        // 上游/下游：PlayerStateMachine.Tick 每帧写；Update 开头读。
        public bool MovementEnabled
        {
            get { return m_movementEnabled; }
            set
            {
                m_movementEnabled = value;

                if (!value)
                {
                    m_forwardSpeed = 0f;
                    m_sideSpeed = 0f;
                    m_currentSpeed = 0f;
                }
            }
        }

        // 功能：设置这一帧的移动速度（状态机按走/跑/冲/蹲档位传进来）。
        // 入参：metersPerSecond 米/秒；负数视为非法，直接忽略。
        // 返回：无。
        // 步骤：写 m_moveSpeed，Update 下一次位移就用新值。
        // 上游/下游：PlayerStateMachine.Tick 调用；Update 读取。
        public void SetMoveSpeed(float metersPerSecond)
        {
            if (metersPerSecond < 0f)
            {
                return;
            }

            m_moveSpeed = metersPerSecond;
        }

        // 功能：运行时开关"用参考体坐标轴"（World 场景由 WorldPlayerSetup 打开）。

                m_reference = reference;

        private float m_forwardSpeed;

        // 左右分量，米/秒：转身后基本为 0（留着给以后侧移用）
        private float m_sideSpeed;

        // 合速度，米/秒（≥ 0），给 HUD 之类用
        private float m_currentSpeed;

        // 功能：读当前的前后速度分量（米/秒，W 正、S 负）。

            get { return m_sideSpeed; }
        }

        // 功能：读配置的移动速度，给动画做归一化的分母。
        // 入参：无
        // 返回：配置的移动速度，米/秒（给动画做归一化的分母）

        // 入参：无
        // 返回：合速度，米/秒（≥ 0）

        }

        // 功能：每帧把输入压成四向之一，转身朝该方向并位移，同时算出前后 / 左右分量。
        // 入参：无（引擎每帧调用）
        // 返回：无
        // 步骤：
        //   1) 三个速度先清 0；提前 return 的分支不会残留上一帧的值
        //   2) 取 InputManager；把量化轴还原成 -1..1（x 左右、z 前后）
        //   3) 取主导轴：|z| >= |x| 用前后，否则用左右 ⇒ 只有四种方向，不斜走
        //   4) 按四种情况决定「朝向」与「位移方向」：
        //        W（z>0）  ：朝向 = 世界前方，沿该方向前进
        //        A（x<0）  ：朝向 = 世界左方，转身后沿该方向前进
        //        D（x>0）  ：朝向 = 世界右方，转身后沿该方向前进
        //        S（z<0）  ：朝向 = 世界后方，转身后沿该方向前进
        //   5) 转身用 RotateTowards 限速（0.125 秒转 90 度），位移用「目标方向」而不是当前朝向，避免转弯时走弧线
        //   6) 位移后按 forward / right 点乘，拆出前后 / 左右分量
        // 上游：Unity 引擎每帧调用
        // 下游：InputManager.Current、Transform.rotation、Transform.position
        // 注意：四向一律会转身（S 也转身，2026-10-31 由负责人改；R012 时曾是「S 不转身倒退」）
        private void Update()
        {
            m_forwardSpeed = 0f;
            m_sideSpeed = 0f;
            m_currentSpeed = 0f;

            // 状态机说了「动作中/已死」就不位移：这里只是不移动，组件保持启用，动画参数照常发布
            if (!m_movementEnabled)
            {
                return;
            }

            InputManager input = InputManager.Instance;

            if (input == null || !input.IsEnabled)
            {
                return;
            }

            InputCommand command = input.Current;

            float x = (float)command.MoveX / InputCommand.MoveScale;
            float z = (float)command.MoveY / InputCommand.MoveScale;

            if (Mathf.Abs(x) < 0.0001f && Mathf.Abs(z) < 0.0001f)
            {
                return;
            }

            bool forwardWins = Mathf.Abs(z) >= Mathf.Abs(x);

            // 四个基本方向：默认是世界轴；打开开关后改成"参考体的轴"（World 用相机轴）
            Vector3 forwardAxis = new Vector3(0f, 0f, 1f);
            Vector3 rightAxis = new Vector3(1f, 0f, 0f);

            if (m_useReferenceAxes)
            {
                Transform reference = m_reference != null ? m_reference : (Camera.main != null ? Camera.main.transform : null);

                if (reference != null)
                {
                    // 压到水平面：镜头俯视时也不能让角色往地里钻
                    forwardAxis = Vector3.ProjectOnPlane(reference.forward, Vector3.up).normalized;
                    rightAxis = Vector3.ProjectOnPlane(reference.right, Vector3.up).normalized;

                    if (forwardAxis.sqrMagnitude < 0.0001f)
                    {
                        forwardAxis = new Vector3(0f, 0f, 1f);
                    }

                    if (rightAxis.sqrMagnitude < 0.0001f)
                    {
                        rightAxis = new Vector3(1f, 0f, 0f);
                    }
                }
            }

            Vector3 targetDirection = forwardWins
                ? forwardAxis * Mathf.Sign(z)
                : rightAxis * Mathf.Sign(x);

            // 四向统一：先转身朝目标方向（限速），位移仍用目标方向，避免边走边转出弧线
            Quaternion targetRotation = Quaternion.LookRotation(targetDirection, Vector3.up);
            transform.rotation = Quaternion.RotateTowards(
                transform.rotation, targetRotation, m_turnSpeed * Time.deltaTime);

            Vector3 moveDirection = targetDirection;

            Vector3 before = transform.position;
            transform.position += moveDirection * (m_moveSpeed * Time.deltaTime);

            float dt = Time.deltaTime;
            if (dt <= 0f)
            {
                return;
            }

            Vector3 moved = transform.position - before;

            // 实测位移拆成前后 / 左右：以后加碰撞，被挡住时这两个值会自然变小
            m_forwardSpeed = Vector3.Dot(moved, transform.forward) / dt;
            m_sideSpeed = Vector3.Dot(moved, transform.right) / dt;
            m_currentSpeed = moved.magnitude / dt;
        }

        // 功能：被禁用时把三个速度清零，避免下游继续读到「停之前那一帧」的旧速度。
        // 入参：无
        // 返回：无
        // 步骤：直接归零（这三个字段只在 Update 里写，禁用后不会再被刷新）
        // 上游：Unity 引擎（组件被禁用时调用）、PlayerBrain 的状态闸门
        // 下游：PlayerAnimation 读这三个值
        // 注意：不清零的话，状态机禁用本组件后动画会一直保持「在走」——因为 PlayerAnimation 读到的是旧值
        private void OnDisable()
        {
            m_forwardSpeed = 0f;
            m_sideSpeed = 0f;
            m_currentSpeed = 0f;
        }
    }
}
```

```csharp
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 玩家没配就用自己
        //   2) 关掉观察相机（避免两套相机抢着写位置）
        //   3) 把跟随相机的目标设成玩家
        // 上游：Unity
        // 下游：FollowCamera / WorldOrbitCamera
        private void Start()
        {
            if (m_player == null)
            {
                m_player = transform;
            }

            if (m_orbitCamera != null)
            {
                m_orbitCamera.enabled = false;
            }

            // 没在 Inspector 里配第三人称相机 ⇒ 运行时给 Main Camera 加一个（场景不用改）
            if (m_worldFollowCamera == null)
            {
                Camera mainCamera = Camera.main;

                if (mainCamera != null)
                {
                    m_worldFollowCamera = mainCamera.GetComponent<WorldFollowCamera>();

                    if (m_worldFollowCamera == null)
                    {
                        m_worldFollowCamera = mainCamera.gameObject.AddComponent<WorldFollowCamera>();
                    }
                }
            }

            if (m_worldFollowCamera != null)
            {
                m_worldFollowCamera.enabled = true;
                m_worldFollowCamera.SetTarget(m_player);
            }

            if (m_followCamera != null)
            {
                // 旧的"世界固定偏移"相机：有新的就关掉，避免两套都写位置
                m_followCamera.enabled = m_worldFollowCamera == null;

                if (m_worldFollowCamera == null)
                {
                    m_followCamera.SetTarget(m_player);
                }
            }

            if (m_worldFollowCamera == null && m_followCamera == null)
            {
                Debug.LogWarning("[WorldPlayerSetup] 没配跟随相机，画面会停在原地");
            }

            // World 需要「镜头相对移动」：W 永远是镜头前方（Battle 用世界轴，那边不动）
            PlayerMove relativeMove = GetComponent<PlayerMove>();

            if (relativeMove != null)
            {
                Camera mainCameraForAxes = Camera.main;
                relativeMove.SetReferenceAxes(true, mainCameraForAxes != null ? mainCameraForAxes.transform : null);
            }
            // 防"双份移动"：模型身上若也挂了 PlayerMove / PlayerAnimation，两套会各读一份输入、各走一次
            PlayerMove[] moves = GetComponentsInChildren<PlayerMove>(true);

            for (int i = 0; i < moves.Length; i++)
            {
                if (moves[i].gameObject != gameObject && moves[i].enabled)
                {
                    moves[i].enabled = false;
                    Debug.LogWarning("[WorldPlayerSetup] 关掉子物体 " + moves[i].name + " 上重复的 PlayerMove（会造成双份位移）");
                }
            }

            PlayerAnimation[] animations = GetComponentsInChildren<PlayerAnimation>(true);

            for (int i = 0; i < animations.Length; i++)
            {
                if (animations[i].gameObject != gameObject && animations[i].enabled)
                {
                    animations[i].enabled = false;
                    Debug.LogWarning("[WorldPlayerSetup] 关掉子物体 " + animations[i].name + " 上重复的 PlayerAnimation");
                }
            }
            // World 的动画改由 PlayerBrain + 动画参数驱动；旧的 PlayerAnimation 还会自己 SetTrigger，会和状态机打架
            PlayerAnimation selfAnimation = GetComponent<PlayerAnimation>();

            if (selfAnimation != null && selfAnimation.enabled)
            {
                selfAnimation.enabled = false;
                Debug.Log("[WorldPlayerSetup] 关掉根节点上的 PlayerAnimation（World 动画改由状态机参数驱动）");
            }

            Debug.Log("[WorldPlayerSetup] 玩家已就位：" + m_player.name
                + "，第三人称相机=" + (m_worldFollowCamera != null)
                + "，旧跟随相机=" + (m_followCamera != null));
        }

        // 诊断：是否打印「输入 → 朝向/速度」日志（排查转身/动画问题用，默认关）
        [SerializeField]
        private bool m_debugLog = false;

        // 诊断用：上一次打印的时间
        private float m_lastLogTime;

        // 功能：临时诊断，打印输入轴、当前朝向、速度。
        // 入参：无
        // 返回：无
        // 步骤：每 0.5 秒一条，内容含 MoveX/MoveY、yaw、速度
        // 上游：LateUpdate
        // 下游：Debug.Log
        private void LogDiagnostics()
        {
            if (!m_debugLog)
            {
                return;
            }

            if (Time.time - m_lastLogTime < 0.5f)
            {
                return;
            }

            m_lastLogTime = Time.time;

            NBC.Framework.Input.InputManager input = NBC.Framework.Input.InputManager.Instance;
            int moveX = input != null ? input.Current.MoveX : 0;
            int moveY = input != null ? input.Current.MoveY : 0;
            NBC.Game.Player.PlayerMove move = GetComponent<NBC.Game.Player.PlayerMove>();

            Debug.Log("[玩家诊断] 输入 X=" + moveX + " Y=" + moveY
                + " 朝向 y=" + transform.eulerAngles.y.ToString("0")
                + " 速度=" + (move != null ? move.CurrentSpeed.ToString("0.00") : "?")
                + " 移动组件启用=" + (move != null && move.enabled));
        }

        // 功能：每帧把玩家贴到地面（地形有起伏，不贴会浮空/陷地）。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 从玩家上方往下打一条射线
        //   2) 打到地面就把 y 设成命中点（保留 x/z）
        // 上游：Unity
        // 下游：Transform.position
        // 注意：只改 y；水平移动仍由 PlayerMove 负责
        private void LateUpdate()
        {
            if (m_player == null)
            {
                return;
            }

            LogDiagnostics();

            Vector3 origin = m_player.position + Vector3.up * m_probeHeight;

            if (Physics.Raycast(origin, Vector3.down, out RaycastHit hit, m_probeDistance, m_groundMask, QueryTriggerInteraction.Ignore))
            {
                Vector3 position = m_player.position;
                position.y = hit.point.y;
                m_player.position = position;
            }
        }
    }
}
```

```csharp
// 这个文件里有：
//   PlayerSpeedSmoother（纯逻辑）：把速度从当前值线性平滑到目标值，供动画混合树使用

using System;

namespace NBC.Game.Player
{
    // 主要功能：把「档位速度」变成「连续速度」——站到跑不是 0 直接跳 5，而是在固定时长内滑过去。
    // 主要数据成员：m_durationSeconds（从旧值滑到新值用多少秒）、m_from/m_to（本次滑动的起点与终点）、m_elapsed（已经滑了多久）。
    // 主要外部方法：Step 推进一帧并返回当前速度；Current 读当前值；IsSettled 判断是否已经到位。
    // 谁在用它：PlayerAnimatorPublisher.Apply 每帧喂 Speed 参数；EditMode 单测用固定步长验证曲线。
    // 注意：目标值中途又变了就从「当前值」重新起滑，不会跳回起点；这样连续按键不会出现速度突变。
    public sealed class PlayerSpeedSmoother
    {
        // 一次滑动的最短时长（秒）；小于等于 0 时按 0.0001 秒处理，避免除零
        private const float MinDurationSeconds = 0.0001f;

        // 目标变化小于这个值时认为没变，不重新起滑（避免浮点抖动反复重置）
        private const float TargetEpsilon = 0.0001f;

        // 一次滑动用多少秒（秒）
        private readonly float m_durationSeconds;

        // 本次滑动的起点速度（米每秒）
        private float m_from;

        // 本次滑动的终点速度（米每秒）
        private float m_to;

        // 本次滑动已经过去的时间（秒）
        private float m_elapsed;

        // 是否已经收到过第一个目标值
        private bool m_started;

        // 功能：记住滑动时长。
        // 入参：durationSeconds 是滑动时长，单位秒；小于等于 0 会被夹到 0.0001。
        // 返回：无。
        // 步骤：只把入参夹紧后存下。
        // 上游/下游：PlayerAnimatorPublisher.EnsureReady 创建。
        public PlayerSpeedSmoother(float durationSeconds)
        {
            m_durationSeconds = durationSeconds > MinDurationSeconds ? durationSeconds : MinDurationSeconds;
        }

        // 当前速度，单位米每秒
        public float Current { get; private set; }

        // 是否已经滑到目标值（第一次 Step 之前为 false）
        public bool IsSettled
        {
            get { return m_started && m_elapsed >= m_durationSeconds; }
        }

        // 功能：推进一帧，返回平滑后的速度。
        // 入参：target 是目标速度（米每秒）；deltaSeconds 是这一帧的时长（秒，小于 0 按 0 处理）。
        // 返回：当前速度（米每秒）。
        // 步骤：1) 第一次调用直接对齐目标，不滑 2) 目标变了就从当前值重新起滑 3) 按已滑时间做线性插值 4) 到时后精确等于目标。
        // 上游/下游：PlayerAnimatorPublisher.Apply 调用。
        public float Step(float target, float deltaSeconds)
        {
            if (!m_started)
            {
                m_started = true;
                m_from = target;
                m_to = target;
                m_elapsed = m_durationSeconds;
                Current = target;
                return Current;
            }

            if (Math.Abs(target - m_to) > TargetEpsilon)
            {
                m_from = Current;
                m_to = target;
                m_elapsed = 0f;
            }

            if (m_elapsed < m_durationSeconds)
            {
                m_elapsed += deltaSeconds > 0f ? deltaSeconds : 0f;
                if (m_elapsed > m_durationSeconds)
                {
                    m_elapsed = m_durationSeconds;
                }

                float t = m_elapsed / m_durationSeconds;
                Current = m_from + (m_to - m_from) * t;
            }
            else
            {
                Current = m_to;
            }

            return Current;
        }
    }
}
```

```csharp
            EnsureReady();
        }

        // 功能：把一帧参数写进 Animator（幂等：没变就不写）。
        // 入参：parameters 是状态机产出的只读快照。
        // 返回：无。
        // 步骤：1) 确保初始化 2) 先把 Speed 平滑一帧（混合树要连续值）3) 其余浮点 4) 四个布尔。
        // 上游/下游：PlayerBrain.Update 调用；下游 WriteFloat / WriteBool。
        public void Apply(in PlayerAnimatorParams parameters)
        {
            EnsureReady();

            if (m_animator == null)
            {
                return;
            }

            float smoothedSpeed = m_speedSmoother == null
                ? parameters.Speed
                : m_speedSmoother.Step(parameters.Speed, Time.deltaTime);

            WriteFloat(FloatSpeed, smoothedSpeed, FloatWriteEpsilon);
            WriteFloat(FloatDirection, parameters.Direction);
            WriteFloat(FloatVerticalSpeed, parameters.VerticalSpeed);
            WriteFloat(FloatActionId, parameters.ActionId);
            WriteFloat(FloatStackSide, parameters.StackSide);
            WriteFloat(FloatPoseIndex, parameters.PoseIndex);

            WriteBool(BoolCrouch, parameters.Crouch);
            WriteBool(BoolGrounded, parameters.Grounded);
            WriteBool(BoolActionBusy, parameters.ActionBusy);
            WriteBool(BoolDead, parameters.Dead);
        }

        // 功能：找 Animator、查参数表、缓存哈希。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 已初始化直接返回 2) 找 Animator，找不到就禁用本组件 3) 关根运动 4) 按参数表建哈希，缺的标 invalid 并告警一次。
        // 上游/下游：Awake / Apply 调用。
        private void EnsureReady()
        {
            if (m_ready)
            {
                return;
            }

            m_ready = true;

            if (m_animator == null)
            {
                m_animator = GetComponentInChildren<Animator>();
            }

            if (m_animator == null)
            {
                Debug.LogError("[PlayerAnimator] 找不到 Animator，动画参数不会生效。", this);
                return;
            }

            m_animator.applyRootMotion = false;

            if (m_speedSmoother == null)
            {
                m_speedSmoother = new PlayerSpeedSmoother(m_speedSmoothSeconds);
            }

            Dictionary<string, AnimatorControllerParameterType> existing = new Dictionary<string, AnimatorControllerParameterType>();
            AnimatorControllerParameter[] parameters = m_animator.parameters;
            for (int i = 0; i < parameters.Length; i++)
            {
                existing[parameters[i].name] = parameters[i].type;
            }

            m_floatHashes = new int[FloatCount];
            m_floatLast = new float[FloatCount];
            m_floatValid = new bool[FloatCount];
            m_boolHashes = new int[BoolCount];
            m_boolLast = new bool[BoolCount];
            m_boolValid = new bool[BoolCount];
            m_boolWritten = new bool[BoolCount];

            List<string> missing = new List<string>();

            for (int i = 0; i < FloatCount; i++)
            {
                m_floatHashes[i] = Animator.StringToHash(FloatNames[i]);
                m_floatLast[i] = float.NaN;
                m_floatValid[i] = HasParameter(existing, FloatNames[i], AnimatorControllerParameterType.Float);
                if (!m_floatValid[i])
                {
                    missing.Add(FloatNames[i] + "(Float)");
                }
            }

            for (int i = 0; i < BoolCount; i++)
            {
                m_boolHashes[i] = Animator.StringToHash(BoolNames[i]);
                m_boolValid[i] = HasParameter(existing, BoolNames[i], AnimatorControllerParameterType.Bool);
                if (!m_boolValid[i])
                {
                    missing.Add(BoolNames[i] + "(Bool)");
                }
            }

            if (missing.Count > 0 && m_logMissingParameters)
            {
                Debug.LogWarning("[PlayerAnimator] 控制器缺少参数：" + string.Join("、", missing) + "；对应的动画切换不会生效。", this);
            }
        }

        // 功能：判断控制器里有没有指定名字、指定类型的参数。
        // 入参：existing 参数名到类型的表；name 参数名；type 期望类型。
        // 返回：存在且类型一致返回 true。
        // 步骤：先查表再比类型。
        // 上游/下游：EnsureReady 调用。
        private static bool HasParameter(
            Dictionary<string, AnimatorControllerParameterType> existing,
            string name,
            AnimatorControllerParameterType type)
        {
            AnimatorControllerParameterType actual;
            return existing.TryGetValue(name, out actual) && actual == type;
        }

        // 功能：写一个浮点参数，值没变就跳过。
        // 入参：index 参数下标；value 目标值；epsilon 变化小于它就算没变（0 表示只跳过完全相等）。
        // 返回：无。
        // 步骤：参数缺失直接返回；与上次值差在 epsilon 内也返回；否则 SetFloat 并记下。
        // 上游/下游：Apply 调用；下游 Animator.SetFloat。
        private void WriteFloat(int index, float value, float epsilon = 0f)
        {
            if (!m_floatValid[index])
            {
                return;
            }

            if (!float.IsNaN(m_floatLast[index]))
            {
                float delta = Mathf.Abs(m_floatLast[index] - value);
                if (epsilon <= 0f ? Mathf.Approximately(m_floatLast[index], value) : delta <= epsilon)
                {
                    return;
                }
            }

            m_floatLast[index] = value;
            m_animator.SetFloat(m_floatHashes[index], value);
        }

        // 功能：写一个布尔参数，值没变就跳过。
        // 入参：index 参数下标；value 目标值。
        // 返回：无。
        // 步骤：参数缺失直接返回；写过且值相同也返回；否则 SetBool 并记下。
        // 上游/下游：Apply 调用；下游 Animator.SetBool。
        private void WriteBool(int index, bool value)
        {
            if (!m_boolValid[index])
            {
                return;
            }

            if (m_boolWritten[index] && m_boolLast[index] == value)
            {
                return;
            }

            m_boolWritten[index] = true;
            m_boolLast[index] = value;
            m_animator.SetBool(m_boolHashes[index], value);
        }
    }
}
```

### 为什么平滑必须自己算

混合树只认一个连续参数。状态机给的是档位（0/2/5/8），直接写进去混合树会在两档之间瞬间跳权重，看起来还是硬切。
Animator 自带的 dampTime 需要每帧 `SetFloat` 才推进，会破坏「值没变不写」；自己插值则是纯逻辑，EditMode 能用固定步长断言（见 05 的 11~15 条）。

### 运行时怎么走

1) 状态机算出目标 Speed（5）→ 2) `PlayerAnimatorPublisher.Apply` 调 `PlayerSpeedSmoother.Step(5, dt)` → 3) 0.12 秒内从旧值滑到 5，变化超过 0.01 才 `SetFloat` → 4) 混合树按当前 Speed 在 Idle/Walk/Run/Sprint 之间插值。
蹲下时 `Crouch` 布尔把 AnyState 从 `S_Locomotion` 切到 `S_Crouch`，第二棵树按同一套 Speed 值（0/1.5/3）插值。
