# 02 需求

需求：R035a-分层状态机骨架（移动层 + 参数驱动）
所属阶段：M4
作者：AI 起草／LYF 确认　状态：已确认（2026-11-13）

## 一、业务目标（一句话）

**玩家能用「走 / 跑 / 冲 / 蹲」四种地面移动方式动起来，且动作（打、被打、死）一进来就立刻停步。**

## 二、用户与场景

- 用户：玩家（在 World 里用 WASD 跑图，按住 Alt 慢走、按住 Shift 冲刺、按 Ctrl 蹲着走）。
- 场景：Play World → W 前进（跑）→ 按住 Alt（慢走）→ 按住 Shift（冲刺）→ 按 Ctrl（蹲）→ 蹲着 W（蹲走）
  → 按 J 挥剑（0.6 秒不能动）→ 动作结束自动回跑 → 按 L 倒地（之后按键无效）。

## 四、边界（本版明确不做）

- 不做跳跃 / 下落（R035d，含重力与落地判定）。
- 不做技能 2/3、冲刺、格挡、姿势（R035b；本步只接回攻击第 1 段）。
- 不做受击左右区分 / 硬直（R035c；本步受击统一走 HitLeft）。
- 不做根运动（`applyRootMotion` 保持 false）、不接伤害与网络（World 是本地演示）。
- 不改 Battle 的 `PlayerAnimation` + `RuntimeNetDriver` 链路，不改相机。

## 五、优先级

**P0**。依赖：R034（World 玩家角色）、`Framework/Fsm/HierarchicalStateMachine`（已有）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 只按 W 时，应进入 `Locomotion/Run`，实测速度约 5 米/秒，Console 有 `Idle → Run` 一行
- [ ] 当 按住 Alt + W 时，应切 `Locomotion/Walk`（2 米/秒），松开 Alt 回 Run
- [ ] 当 按住 Shift + W 时，应切 `Locomotion/Sprint`（8 米/秒）
- [ ] 当 松开方向键 0.3 秒内，应回 `Locomotion/Idle` 且 `Speed` 归零
- [ ] 当 按 Ctrl 时，应切 `CrouchIdle`；蹲着按 W 切 `CrouchWalk`（1.5），按住 Shift 切 `CrouchJog`（3）；再按 Ctrl 站起
- [ ] 当 按 J 时，应进 `Action/Attack1`，`ActionBusy=true`，**0.6 秒内 WASD 不产生位移**，36 帧后自动回移动层
- [ ] 当 动作期间按 Ctrl/Shift 时，不应改变 `ActionId`，也不应切层（动作优先）
- [ ] 当 按 L 时，应进 `Reaction/Die`，`Dead=true`，之后 WASD/J 全部无效
- [ ] 当 Animator 缺参数时，Console 只告警一次，且不刷屏、不抛异常
- [ ] 当 站着不动 10 秒时，`Speed`/`Direction` 不重复写入（值没变就不写）
- [ ] 当 从站到跑（`Speed` 0→5）时，应由混合树在约 0.12 秒内连续过渡（能看到 Idle→Walk→Run 权重变化），不是一帧硬切；蹲走→蹲跑同理
