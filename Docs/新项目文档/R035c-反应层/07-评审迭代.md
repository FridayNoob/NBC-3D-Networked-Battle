## 3. 根因分析

1. `PlayerStateMachine.NotifyAttack()` 的前置判断只写了 `if (m_context.Dead)`，漏了 `m_blocking`。动作层的技能入口写了格挡判断，攻击入口没写——两处不对称，属于「同类判断只改了一半」。
2. `AdvanceTo(int targetFrame)` 的循环条件是「帧号小于目标就继续 `Tick`」，而连击会在第 60 帧把下一段接上，循环继续把下一段推完，断言自然落在 `Idle`。测试读起来像「推到第 60 帧就停」，实际是「至少推 60 帧」。
3. 测试的 `Tick()` 不传方向输入，`ChooseLocomotion` 走「无方向」分支返回 `Idle`；写用例时按「跑动状态」的直觉填了 `Run`。
4. 结果文件写在 `Temp/nbc-test-results.txt`，上一轮跑完不会自动删除；我先轮询再判断，读到的可能是旧文件。
5. 规则 13 改成 §4.3（AI 代跑）之前写的 05 只能写「未执行」；规则放开后文档没同步。
