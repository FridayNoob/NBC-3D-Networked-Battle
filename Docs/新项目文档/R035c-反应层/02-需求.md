# R035c 反应层 —— 02 需求

需求编号：R035c
所属阶段：M4
作者：AI 辅助，负责人确认
状态：开发中

## 1. 业务目标（一句话）

挨打要有受击动作（分左右），被控要有硬直动作，倒下要真的倒到底——三种反应都不能被移动打断，死亡之后任何输入都无效。

## 2. 用户与场景

玩家在 World 里试动作：按 `K` 从左侧挨一下 → 角色播左受击、约 1.5 秒不能走；按 `Y` 从右侧挨一下 → 播右受击；先打攻击再按 `T` → 攻击被打断，进入硬直约 2 秒，期间再按 `K` 无反应；按 `L` → 倒地，之后 WASD/J/Q/E/R 全部无效。

## 3. 功能列表

| # | 功能 | 优先级 |
| --- | --- | --- |
| 1 | 左受击：`StackSide=-1`，播 `S_Hit_L`，88 帧禁移动 | P0 |
| 2 | 右受击：`StackSide=+1`，播 `S_Hit_R`，88 帧禁移动 | P0 |
| 3 | 硬直：播 `S_Stun`，120 帧禁移动，可打断攻击/技能/冲刺/姿势 | P0 |

| 6 | 受击/硬直结束时按当前输入回移动层（蹲着回蹲姿） | P0 |
| 7 | 反应切换打日志（`[PlayerBrain] ...`） | P1 |
| 8 | 死亡后相机继续跟随，不弹窗、不重开 | P2 |

## 4. 边界（不做什么）

- 不做击退位移（受击只播动画，位置不动）。
- 不做伤害数值、血条、死亡结算（R041 死亡与复活再做）。
- 不做受击音效/屏幕特效（R044）。
- 不改美术包控制器；只改副本 `Player_Sword_Controller.controller`。
- 不做网络同步的受击来源判定（本步只接本地调试入口）。

## 5. 优先级

P0：1~6。P1：7。P2：8。本步只交 P0 + P1。

## 6. 验收标准

1. 当 按 `K` 时，应 播 `S_Hit_L`，`StackSide=-1`，88 帧内按 W 不走。
2. 当 按 `Y` 时，应 播 `S_Hit_R`，`StackSide=+1`。
3. 当 攻击/技能播放中按 `T` 时，应 立刻切到 `S_Stun`，`ActionId=11`。
4. 当 硬直中按 `K`/`Y` 时，应 无反应（`NotifyHit` 返回 false，状态不变）。
5. 当 硬直结束（120 帧）时，应 按当前输入回 `Locomotion/*`，蹲着回 `CrouchIdle`。
6. 当 按 `L` 时，应 播 `S_Die` 并在 130 帧后停在最后一帧。
7. 当 死亡后按 W/J/Q/K/Y/T 时，应 全部无效，角色位置与动画都不变。
8. 当 受击中再按 `T` 时，应 进入硬直（硬直优先级高于受击）。
9. 当 控制器回读时，应 参数仍 49、AnyState Active 由 20 变 21（新增 `S_Stun`）。
10. 当 静止 30 秒时，应 不重复写动画参数。
