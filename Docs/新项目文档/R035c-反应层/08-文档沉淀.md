## 1. 文档范围

本需求把「受击 / 硬直 / 死亡」三种反应接进分层状态机，并让 AI 第一次真正代跑 Unity Test Runner。
沉淀四块：反应入口、控制器过渡、测试执行方式、踩坑清单。移动层与动作层的原理见 R035a / R035b 的 08。

## 2. 模块文档

### 2.1 反应入口（`Client/Assets/_Project/Game/Player/State/PlayerStateMachine.cs`）

- 简介：三个公开方法收外部事件，内部统一走「写 pending → 下一帧 `TryChangeUpper`」；死亡是唯一直接 `ForceChange` 的路径。
- 接口：
  - `bool NotifyHit(bool fromLeft)`：写 `StackSide = fromLeft ? -1 : +1`，进 `HitLeft` / `HitRight`；死亡或硬直中返回 false。
  - `bool NotifyStun()`：进 `Stun`；死亡或已在硬直中返回 false。
  - `void NotifyDead()`：置 `Dead=true`、清连击与格挡、`ForceChange(Reaction, Die)`；之后所有请求都返回 false。
  - `bool IsStunned`：`ActionBusy && ActionId == PlayerActionId.Stun`。
- 示例：`if (m_brain.NotifyStun()) { /* 硬直开始 */ }`
- 原理：优先级的唯一判据在状态机里，不在 Animator 里；Animator 只负责「按参数选 clip」。
- 坑：`IsStunned` 必须同时判 `ActionBusy` 与 `ActionId`——动作最后一帧只清 `ActionId`，只判 `ActionId` 会提前一帧解除免疫。
- 维护：新增反应类型时，先加 `EPlayerState` 值与 `PlayerActionId`，再加 `Notify*` 与控制器过渡，最后补测试。

### 2.2 控制器过渡（`Client/Assets/_Project/Animator/Player_Sword_Controller.controller`）

- 简介：`S_Stun` 的进入条件是一条 AnyState 过渡：`ActionBusy If` + `ActionId > 10.5` + `ActionId < 11.5` + `Dead IfNot`。
- 接口：无（资产）。
- 示例：硬直时 `ActionBusy=true / ActionId=11`，AnyState 命中 `S_Stun`。
- 原理：`S_Stun` 的 clip 是循环的，退出靠 `ActionId` 被清后回移动层那条过渡接管。
- 坑：`sm.anyStateTransitions` 用数组 setter 重排**不生效**（新过渡仍排在数组末尾），所以死亡要靠 `Dead IfNot` 显式排除，不能靠「死亡那条排在前面」。
- 维护：改优先级时先回读整张 AnyState 表，别只看新建的那条。

### 2.3 测试执行方式（AI 代跑，`AGENTS.md` §4.3）

- 简介：用 `UnityEditor.TestTools.TestRunner.Api.TestRunnerApi` 触发，回调把结果写成文本，脚本轮询读取。
- 接口：`TestRunnerApi.Execute(new ExecutionSettings(new Filter { testMode = TestMode.EditMode }))` + `ICallbacks`。
- 原理：`Execute` 是异步的；`RunFinished` 才是「跑完」的信号，不能靠固定等待。
- 坑：结果文件要先删；一次只跑一轮；`TestFinished` 要跳过 `IsSuite`，否则总数会被套件重复计数。
- 维护：本次的临时桥 `Client/Assets/TestRunnerBridge/` 已删，做法记在这里，下次照此重建即可。

## 3. 踩坑清单

| # | 坑 | 判据 |
| --- | --- | --- |
| 1 | 同类判断只改一半（技能入口判了格挡、攻击入口没判） | 同一族入口的守卫要并排看一遍 |
| 2 | `AdvanceTo(60)` 是「至少推 60 帧」，不是「停在第 60 帧」 | 连击必须用 `TickFrames(N)` |
| 3 | 无方向输入的 `ChooseLocomotion` 回 `Idle` 不是 `Run` | 断言前先问「这帧的输入是什么」 |
| 4 | 结果文件残留会假报 | 先删文件再 Execute |
| 5 | AnyState 数组重排无效 | 用条件互斥表达优先级 |
