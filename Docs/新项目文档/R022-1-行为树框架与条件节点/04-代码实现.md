## 二、功能概述

组合节点只做「遍历 + 聚合」；条件节点只读 `BtContext` 判断真假；参数在 `Configure` 一次性读进字段，`Tick` 不分配。

## 三、接口与入参出参

| 成员 | 入参 | 出参 |
| --- | --- | --- |
| `BtNode.Tick(ctx)` | `BtContext` | `BtStatus`（三态） |
| `BtNode.Configure(source)` | `IBtParamSource` | 无（写字段） |
| `BtSelector/Sequence/Parallel.AddChild(node)` | 子节点 | 无 |
| `BtOps.DistanceTo(ctx)` / `DistanceToHome(ctx)` | 上下文 | 距离（毫米），无目标 `int.MaxValue` |

## 四、逐段讲解

1. **`BtCore.cs`**：三态 + 参数接口 + 特性 + 基类。特性 `[BtNode("TypeName")]` 供 R022-3 扫描注册；基类只有 `Configure` 与 `Tick`。
2. **`BtComposites.cs`**：`Selector` 第一个非 Failure 即返回；`Sequence` 遇 Failure/Running 短路；`Parallel` 全部跑完再聚合。
3. **`BtContext.cs`**：`MonsterAiProfile`（近战 / BOSS 两套常量）、`BtContext`（每只怪一个、跨帧复用）、`BtOps`（两个距离）。
4. **`Conditions.cs`**：6 个条件，判定与边界见下：

| 节点 | 判定 | 边界 |
| --- | --- | --- |
| `IsDead` | `Self.Alive` 取反 | HP=0 → Success |
| `HasTarget` | 目标非空且 `Alive` | 目标死 → Failure |
| `InAttackRange` | `DistanceTo <= (rangeMm>0 ? rangeMm : 2000)` | 2000 → Success，2001 → Failure |
| `AttackReady` | `skillId=0` 看冷却；`>0` 恒 Failure + 首告警 | 剩 1 帧 → Failure |
| `HPBelow` | 百分比：`hp*100 < threshold*maxHp`；否则 `hp < threshold` | 严格小于 |
| `HomeFar` | `DistanceToHome > Profile.LeashRadiusMm` | 等于 → Failure |

```csharp
// 这个文件里有：
//   BtStatus（枚举）：节点一次 Tick 的三种结果。
//   IBtParamSource（接口）：节点读参数的抽象来源（JSON 解析在 R022-3 提供实现）。
//   BtNodeAttribute（特性）：把节点类登记到某个类型名，类型名与客户端 BTNodeDefinitions 一致。
//   BtNode（抽象类）：所有行为树节点的基类，只要求 Tick；参数在读配置时一次性读进字段。

using System;

namespace NBC.Server.Game.Ai.Bt
{
    // 一次 Tick 的三种结果：动作没结束时用 Running，让上层知道"本帧还没完"
    public enum BtStatus
    {
        // 成功
        Success = 0,

        // 失败
        Failure = 1,

        // 运行中（本帧未结束）
        Running = 2
    }

    // 参数来源：节点只通过它读参数，不关心背后是 JSON、字典还是测试桩
    public interface IBtParamSource
    {
        // 功能：读一个整数参数。
        // 入参：key 参数键；value 读到的值
        // 返回：true 表示存在且可解析
        // 步骤：由实现决定
        // 上游：BtNode.Configure
        // 下游：无
        bool TryGetInt(string key, out int value);

        // 功能：读一个布尔参数。
        // 入参：key 参数键；value 读到的值
        // 返回：true 表示存在且可解析
        // 步骤：由实现决定
        // 上游：BtNode.Configure
        // 下游：无
        bool TryGetBool(string key, out bool value);

        // 功能：读一个浮点参数。
        // 入参：key 参数键；value 读到的值
        // 返回：true 表示存在且可解析
        // 步骤：由实现决定
        // 上游：BtNode.Configure
        // 下游：无
        bool TryGetFloat(string key, out float value);
    }

    // 节点类型名：与客户端 BTNodeDefinitions.asset 里的 TypeName 完全一致，发布后不许改名
    [AttributeUsage(AttributeTargets.Class, Inherited = false, AllowMultiple = false)]
    public sealed class BtNodeAttribute : Attribute
    {
        // 类型名（JSON 的 NodeType）
        public string TypeName { get; }

        // 功能：登记类型名。
        // 入参：typeName 与客户端一致的节点类型名
        // 返回：无
        // 步骤：保存
        // 上游：节点类声明处
        // 下游：R022-3 的工厂扫描
        public BtNodeAttribute(string typeName)
        {
            TypeName = typeName;
        }
    }

    // 主要功能：所有节点的基类 —— 只要求实现 Tick，参数在读配置时读进字段。
    // 主要数据成员：无（子类自己存参数）。
    // 主要外部方法：Configure（读参数）、Tick（跑一帧）。
    // 谁在用它：BtComposites、Conditions、R022-3 的工厂、R022-2 的大脑。
    // 注意：GetTypeName 是抽象属性而不是字段，避免子类忘记赋值；条件节点 Tick 内不得修改 ctx 或世界。
    public abstract class BtNode
    {
        // 节点类型名（与特性上的名字一致，写日志用）
        public abstract string TypeName { get; }

        // 功能：读参数（只在建树时调用一次）。
        // 入参：source 参数来源
        // 返回：无
        // 步骤：由子类实现；本基类默认什么都不读
        // 上游：R022-3 建节点后立即调用
        // 下游：子类字段
        public virtual void Configure(IBtParamSource source)
        {
        }

        // 功能：跑一帧。
        // 入参：ctx 执行上下文
        // 返回：三态之一
        // 步骤：由子类实现
        // 上游：父节点或大脑的根
        // 下游：无
        public abstract BtStatus Tick(BtContext ctx);
    }
}
```

### `Ai/Bt/BtComposites.cs`

```csharp
// 这个文件里有：
//   BtSelector（类）：选择节点，按顺序跑，第一个非失败的结果就是它的结果。
//   BtSequence（类）：顺序节点，遇到失败或运行中就短路，全成功才成功。
//   BtParallel（类）：并行节点，全部跑一遍后聚合：有失败即失败，全成功才成功，否则运行中。
//
// 三个组合节点都只负责"遍历 + 聚合"，不含任何具体行为；子节点按添加顺序执行。

using System.Collections.Generic;

namespace NBC.Server.Game.Ai.Bt
{
    // 主要功能：选择节点 —— 按顺序跑子节点，第一个非 Failure 的结果直接作为结果。
    // 主要数据成员：m_children（子节点，按添加顺序）。
    // 主要外部方法：AddChild、Tick。
    // 谁在用它：R022-3 建树、R022-2 的怪物大脑。
    // 注意：子节点若返回 Success 就会打断后续分支，所以条件节点必须无副作用、动作节点不能"假装成功"。
    [BtNode("Selector")]
    public sealed class BtSelector : BtNode
    {
        // 子节点（顺序即优先级）
        private readonly List<BtNode> m_children = new List<BtNode>();

        // 类型名
        public override string TypeName => "Selector";

        // 功能：追加一个子节点。
        // 入参：child 子节点
        // 返回：无
        // 步骤：判空后加入列表
        // 上游：R022-3 建树
        // 下游：Tick
        public void AddChild(BtNode child)
        {
            if (child != null)
            {
                m_children.Add(child);
            }
        }

        // 功能：按顺序跑子节点，第一个非 Failure 即返回。
        // 入参：ctx 执行上下文
        // 返回：第一个非 Failure 的状态；全部失败则 Failure
        // 步骤：遍历子节点 → 非 Failure 立即返回 → 全失败返回 Failure
        // 上游：父节点或大脑
        // 下游：子节点.Tick
        public override BtStatus Tick(BtContext ctx)
        {
            for (int i = 0; i < m_children.Count; i++)
            {
                BtStatus status = m_children[i].Tick(ctx);

                if (status != BtStatus.Failure)
                {
                    return status;
                }
            }

            return BtStatus.Failure;
        }
    }

    // 主要功能：顺序节点 —— 依次跑子节点，遇 Failure 或 Running 立刻短路。
    // 主要数据成员：m_children（子节点）。
    // 主要外部方法：AddChild、Tick。
    // 谁在用它：R022-3 建树、R022-2 的怪物大脑。
    // 注意：Running 也短路，否则"追到一半"会把后面的攻击也执行了。
    [BtNode("Sequence")]
    public sealed class BtSequence : BtNode
    {
        // 子节点（顺序即执行顺序）
        private readonly List<BtNode> m_children = new List<BtNode>();

        // 类型名
        public override string TypeName => "Sequence";

        // 功能：追加一个子节点。
        // 入参：child 子节点
        // 返回：无
        // 步骤：判空后加入列表
        // 上游：R022-3 建树
        // 下游：Tick
        public void AddChild(BtNode child)
        {
            if (child != null)
            {
                m_children.Add(child);
            }
        }

        // 功能：依次跑子节点，遇 Failure 或 Running 立即返回。
        // 入参：ctx 执行上下文
        // 返回：Failure / Running / Success
        // 步骤：遍历子节点 → 非 Success 立即返回 → 全成功返回 Success
        // 上游：父节点或大脑
        // 下游：子节点.Tick
        public override BtStatus Tick(BtContext ctx)
        {
            for (int i = 0; i < m_children.Count; i++)
            {
                BtStatus status = m_children[i].Tick(ctx);

                if (status != BtStatus.Success)
                {
                    return status;
                }
            }

            return BtStatus.Success;
        }
    }

    // 主要功能：并行节点 —— 所有子节点都跑一遍，再按"有失败即失败、全成功才成功"聚合。
    // 主要数据成员：m_children（子节点）。
    // 主要外部方法：AddChild、Tick。
    // 谁在用它：R022-3 建树、R022-2 的怪物大脑。
    // 注意：并行只是"都跑一遍"，不是多线程；同一帧内顺序执行，保证确定性。
    [BtNode("Parallel")]
    public sealed class BtParallel : BtNode
    {
        // 子节点
        private readonly List<BtNode> m_children = new List<BtNode>();

        // 类型名
        public override string TypeName => "Parallel";

        // 功能：追加一个子节点。
        // 入参：child 子节点
        // 返回：无
        // 步骤：判空后加入列表
        // 上游：R022-3 建树
        // 下游：Tick
        public void AddChild(BtNode child)
        {
            if (child != null)
            {
                m_children.Add(child);
            }
        }

        // 功能：跑全部子节点后聚合。
        // 入参：ctx 执行上下文
        // 返回：有 Failure → Failure；全 Success → Success；否则 Running
        // 步骤：遍历累计 → 先判失败再判未完成 → 否则成功
        // 上游：父节点或大脑
        // 下游：子节点.Tick
        public override BtStatus Tick(BtContext ctx)
        {
            bool anyNotSuccess = false;

            for (int i = 0; i < m_children.Count; i++)
            {
                BtStatus status = m_children[i].Tick(ctx);

                if (status == BtStatus.Failure)
                {
                    return BtStatus.Failure;
                }

                if (status != BtStatus.Success)
                {
                    anyNotSuccess = true;
                }
            }

            return anyNotSuccess ? BtStatus.Running : BtStatus.Success;
        }
    }
}
```

### `Ai/Bt/BtContext.cs`

```csharp
// 这个文件里有：
//   MonsterAiProfile（结构体）：每种怪的 AI 参数（仇恨范围、移速、回位半径、是否巡逻）。
//   BtContext（类）：一次 Tick 需要的全部上下文（世界、自己、出生点、目标、帧号、参数）。
//   BtOps（静态类）：节点能用的世界操作薄封装（找最近英雄、算距离、移动、普攻、回位）。
//
// 本文件只做"数据 + 读世界/操作世界"的薄封装，不含任何具体节点行为。

namespace NBC.Server.Game.Ai.Bt
{
    // 一种怪的 AI 参数（数值都带单位：毫米 / 毫米每逻辑帧）
    public readonly struct MonsterAiProfile
    {
        // 仇恨范围（毫米）：英雄进入这个范围就被盯上
        public readonly int AggroRangeMm;

        // 移动速度（毫米每逻辑帧，30Hz 下 40 约等于 1.2 米每秒）
        public readonly int MoveSpeedMmPerTick;

        // 回位半径（毫米）：离家超过它就回位
        public readonly int LeashRadiusMm;

        // 空闲时是否允许巡逻（BOSS 为 false，守着出生点）
        public readonly bool PatrolWhenIdle;

        // 近战普通怪参数：4 米仇恨、40mm/帧、基本不回位、允许巡逻
        public static MonsterAiProfile Melee => new MonsterAiProfile(4000, 40, 100000, true);

        // BOSS 参数：4 米仇恨、40mm/帧、离家 200mm 就回位、不巡逻
        public static MonsterAiProfile Boss => new MonsterAiProfile(4000, 40, 200, false);

        // 功能：构造参数。
        // 入参：aggroRangeMm 仇恨范围；moveSpeedMmPerTick 移速；leashRadiusMm 回位半径；patrolWhenIdle 是否巡逻
        // 返回：无
        // 步骤：逐个赋值
        // 上游：Melee / Boss 以及后续的配置表
        // 下游：BtContext.Profile
        public MonsterAiProfile(int aggroRangeMm, int moveSpeedMmPerTick, int leashRadiusMm, bool patrolWhenIdle)
        {
            AggroRangeMm = aggroRangeMm;
            MoveSpeedMmPerTick = moveSpeedMmPerTick;
            LeashRadiusMm = leashRadiusMm;
            PatrolWhenIdle = patrolWhenIdle;
        }
    }

    // 主要功能：一次 Tick 的上下文 —— 世界、自己、出生点、目标、帧号、AI 参数。
    // 主要数据成员：World / Self / HomeXmm / HomeZmm / Target / Tick / Profile / Chasing / LastAction。
    // 主要外部方法：无（纯数据，节点只读）。
    // 谁在用它：所有节点的 Tick。
    // 注意：每只怪一个实例、跨帧复用；条件节点不得修改这里任何字段（Chasing/LastAction 只由动作节点写）。
    public sealed class BtContext
    {
        // 世界（DungeonBattle）
        public DungeonBattle World;

        // 自己
        public BattleEntity Self;

        // 出生点 X（毫米）
        public int HomeXmm;

        // 出生点 Z（毫米）
        public int HomeZmm;

        // 当前目标（由大脑每帧刷新；null 表示没有）
        public BattleEntity Target;

        // 当前逻辑帧号
        public int Tick;

        // AI 参数
        public MonsterAiProfile Profile;

        // 是否正在追击（动作节点写，实体 Step 据此让位）
        public bool Chasing;

        // 上一次动作名（日志用）
        public string LastAction;
    }

    // 主要功能：节点能用的世界操作 —— 找目标、算距离、移动、攻击、回位。
    // 主要数据成员：无（全静态）。
    // 主要外部方法：DistanceTo / DistanceToHome（动作类操作在 R022-2 再加）。
    // 谁在用它：条件节点（本需求）；R022-2 的动作节点会在此基础上补移动/攻击操作。
    // 注意：所有距离一律整数毫米；不在这里做任何规则判断（射程/冷却都在 DungeonBattle）。
    public static class BtOps
    {
        // 默认普攻射程（毫米）：节点参数 rangeMm 为 0 时用它
        public const int DefaultAttackRangeMm = 2000;


        // 功能：自己到目标的距离。
        // 入参：ctx 上下文
        // 返回：距离（毫米）；没有目标返回 int.MaxValue
        // 步骤：目标为空就返回极大值 → 否则算距离
        // 上游：条件节点 InAttackRange
        // 下游：DungeonBattle.DistanceMm
        public static int DistanceTo(BtContext ctx)
        {
            if (ctx?.Self == null || ctx.Target == null)
            {
                return int.MaxValue;
            }

            return DungeonBattle.DistanceMm(ctx.Self, ctx.Target);
        }

        // 功能：自己到出生点的距离。
        // 入参：ctx 上下文
        // 返回：距离（毫米）
        // 步骤：直接算点到点距离
        // 上游：条件节点 HomeFar
        // 下游：DungeonBattle.DistanceMmToPoint
        public static int DistanceToHome(BtContext ctx)
        {
            if (ctx?.Self == null)
            {
                return int.MaxValue;
            }

            return DungeonBattle.DistanceMmToPoint(ctx.Self, ctx.HomeXmm, ctx.HomeZmm);
        }




    }
}
```

### `Ai/Bt/Conditions.cs`

```csharp
// 这个文件里有：
//   六个条件节点：IsDead / HasTarget / InAttackRange / AttackReady / HPBelow / HomeFar。
//
// 条件节点只回答"是/否"：成功表示成立、失败表示不成立，绝不返回 Running，也不修改 ctx 或世界。
// 参数在 Configure 里读进字段，Tick 内不再分配、不再读参数。

using System;

namespace NBC.Server.Game.Ai.Bt
{
    // 主要功能：自己是否已经死了（HP <= 0）。
    // 主要数据成员：无。
    // 主要外部方法：Tick。
    // 谁在用它：怪物树的第一个分支（死了就什么都不做）。
    // 注意：用 Alive 而不是 Hp，语义与实体一致。
    [BtNode("IsDead")]
    public sealed class IsDeadCondition : BtNode
    {
        // 类型名
        public override string TypeName => "IsDead";

        // 功能：判断自己是否死亡。
        // 入参：ctx 上下文
        // 返回：死亡 → Success；否则 Failure
        // 步骤：读 Self.Alive 取反
        // 上游：父节点
        // 下游：无
        public override BtStatus Tick(BtContext ctx)
        {
            if (ctx?.Self == null)
            {
                return BtStatus.Failure;
            }

            return ctx.Self.Alive ? BtStatus.Failure : BtStatus.Success;
        }
    }

    // 主要功能：当前是否有活着的目标。
    // 主要数据成员：无。
    // 主要外部方法：Tick。
    // 谁在用它：追击与攻击分支的前置判断。
    // 注意：目标可能刚被打死但引用还在，所以必须同时判断 Alive。
    [BtNode("HasTarget")]
    public sealed class HasTargetCondition : BtNode
    {
        // 类型名
        public override string TypeName => "HasTarget";

        // 功能：判断有没有活着的目标。
        // 入参：ctx 上下文
        // 返回：有 → Success；没有 → Failure
        // 步骤：判空 + 判存活
        // 上游：父节点
        // 下游：无
        public override BtStatus Tick(BtContext ctx)
        {
            return ctx?.Target != null && ctx.Target.Alive ? BtStatus.Success : BtStatus.Failure;
        }
    }

    // 主要功能：目标是否在射程内（圆形射程，整数毫米）。
    // 主要数据成员：m_rangeMm（射程，0 表示用默认 2000）。
    // 主要外部方法：Configure、Tick。
    // 谁在用它：攻击分支的前置判断。
    // 注意：射程边界包含等于（2000 算"在"），与客户端 InAttackRange 的预期一致。
    [BtNode("InAttackRange")]
    public sealed class InAttackRangeCondition : BtNode
    {
        // 射程（毫米）；0 表示用默认值
        private int m_rangeMm;

        // 类型名
        public override string TypeName => "InAttackRange";

        // 功能：读 rangeMm 参数。
        // 入参：source 参数来源
        // 返回：无
        // 步骤：读不到就保持 0（默认射程）
        // 上游：R022-3 建树
        // 下游：Tick
        public override void Configure(IBtParamSource source)
        {
            if (source != null && source.TryGetInt("rangeMm", out int rangeMm))
            {
                m_rangeMm = rangeMm;
            }
        }

        // 功能：判断目标是否在射程内。
        // 入参：ctx 上下文
        // 返回：在 → Success；不在或没目标 → Failure
        // 步骤：定射程 → 算距离 → 比较（含等于）
        // 上游：父节点
        // 下游：BtOps.DistanceTo
        public override BtStatus Tick(BtContext ctx)
        {
            if (ctx?.Target == null || !ctx.Target.Alive)
            {
                return BtStatus.Failure;
            }

            int range = m_rangeMm > 0 ? m_rangeMm : BtOps.DefaultAttackRangeMm;
            return BtOps.DistanceTo(ctx) <= range ? BtStatus.Success : BtStatus.Failure;
        }
    }

    // 主要功能：指定技能的冷却是否已经好了（普攻 skillId = 0）。
    // 主要数据成员：m_skillId（技能编号）、s_warned（是否已提示过技能未实现）。
    // 主要外部方法：Configure、Tick。
    // 谁在用它：攻击/技能分支的前置判断。
    // 注意：技能系统还没做，skillId 大于 0 时一律返回 Failure 并只提示一次，避免刷屏。
    [BtNode("AttackReady")]
    public sealed class AttackReadyCondition : BtNode
    {
        // 技能编号（0 = 普攻）
        private int m_skillId;

        // 是否已经提示过"技能冷却未实现"
        private static bool s_warned;

        // 类型名
        public override string TypeName => "AttackReady";

        // 功能：读 skillId 参数。
        // 入参：source 参数来源
        // 返回：无
        // 步骤：读不到就用 0（普攻）
        // 上游：R022-3 建树
        // 下游：Tick
        public override void Configure(IBtParamSource source)
        {
            if (source != null && source.TryGetInt("skillId", out int skillId))
            {
                m_skillId = skillId;
            }
        }

        // 功能：判断冷却是否已好。
        // 入参：ctx 上下文
        // 返回：好了 → Success；没好或技能未实现 → Failure
        // 步骤：技能编号大于 0 时提示并失败 → 普攻看 AttackCooldownTicksLeft
        // 上游：父节点
        // 下游：无
        public override BtStatus Tick(BtContext ctx)
        {
            if (ctx?.Self == null)
            {
                return BtStatus.Failure;
            }

            if (m_skillId > 0)
            {
                if (!s_warned)
                {
                    s_warned = true;
                    Console.WriteLine("[BT] 服务端还没有技能系统：AttackReady(skillId=" + m_skillId + ") 暂时恒为失败。");
                }

                return BtStatus.Failure;
            }

            return ctx.Self.AttackCooldownTicksLeft <= 0 ? BtStatus.Success : BtStatus.Failure;
        }
    }

    // 主要功能：血量是否低于阈值（可选按百分比）。
    // 主要数据成员：m_hpThreshold（阈值）、m_percentOfMax（是否按百分比）。
    // 主要外部方法：Configure、Tick。
    // 谁在用它：BOSS 分阶段、残血逃跑等分支。
    // 注意：比较是严格小于（HP 等于阈值不算"低于"），与客户端 HPBelow 一致。
    [BtNode("HPBelow")]
    public sealed class HpBelowCondition : BtNode
    {
        // 阈值：绝对值或百分比（1~100）
        private int m_hpThreshold;

        // 是否按最大血量的百分比理解
        private bool m_percentOfMax;

        // 类型名
        public override string TypeName => "HPBelow";

        // 功能：读 hpThreshold 与 percentOfMax。
        // 入参：source 参数来源
        // 返回：无
        // 步骤：先读阈值再读开关，读不到用默认（0 / false）
        // 上游：R022-3 建树
        // 下游：Tick
        public override void Configure(IBtParamSource source)
        {
            if (source == null)
            {
                return;
            }

            if (source.TryGetInt("hpThreshold", out int threshold))
            {
                m_hpThreshold = threshold;
            }

            if (source.TryGetBool("percentOfMax", out bool percent))
            {
                m_percentOfMax = percent;
            }
        }

        // 功能：判断血量是否低于阈值。
        // 入参：ctx 上下文
        // 返回：低于 → Success；否则 Failure
        // 步骤：百分比时用 hp*100 与 threshold*maxHp 比较（避免浮点）→ 否则直接比 hp
        // 上游：父节点
        // 下游：无
        public override BtStatus Tick(BtContext ctx)
        {
            if (ctx?.Self == null)
            {
                return BtStatus.Failure;
            }

            if (m_percentOfMax)
            {
                long left = (long)ctx.Self.Hp * 100L;
                long right = (long)m_hpThreshold * ctx.Self.MaxHp;
                return left < right ? BtStatus.Success : BtStatus.Failure;
            }

            return ctx.Self.Hp < m_hpThreshold ? BtStatus.Success : BtStatus.Failure;
        }
    }

    // 主要功能：是否离家（出生点）太远。
    // 主要数据成员：无（半径来自 ctx.Profile）。
    // 主要外部方法：Tick。
    // 谁在用它：BOSS 回位分支、巡逻怪的 leash。
    // 注意：等于半径不算"太远"，必须严格大于。
    [BtNode("HomeFar")]
    public sealed class HomeFarCondition : BtNode
    {
        // 类型名
        public override string TypeName => "HomeFar";

        // 功能：判断离家距离是否超过回位半径。
        // 入参：ctx 上下文
        // 返回：超过 → Success；否则 Failure
        // 步骤：算离家距离 → 与 Profile.LeashRadiusMm 比较
        // 上游：父节点
        // 下游：BtOps.DistanceToHome
        public override BtStatus Tick(BtContext ctx)
        {
            if (ctx?.Self == null)
            {
                return BtStatus.Failure;
            }

            return BtOps.DistanceToHome(ctx) > ctx.Profile.LeashRadiusMm ? BtStatus.Success : BtStatus.Failure;
        }
    }
}
```
