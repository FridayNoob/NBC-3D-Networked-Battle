# 02 需求

需求：R022-1-行为树框架与条件节点
所属阶段：M4
作者：AI 起草／LYF 确认　状态：待确认（2026-11-09）

## 一、业务目标（一句话）

**让服务端能"判断"**：有一套纯 C# 的行为树内核（3 个组合节点）与 6 个条件节点，怪物 AI 的"该不该追/该不该打/该不该回位"全部由它们决定。

## 二、用户与场景

- 用户：服务端 AI（`MonsterBrain`，R022-2 接入）；开发（编树、查问题）。
- 场景：策划在编辑器里搭好的树被 R022-3 解析成节点树后，每个逻辑帧（30Hz）由 `MonsterBrain` 调用根节点 Tick，条件节点回答"是/否"。

## 三、功能列表

| # | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 1 | 三态 `BtStatus`（Success / Failure / Running） | P0 | 动作需要「本帧未结束」 |
| 2 | `Selector` | P0 | 按顺序跑，**第一个非 Failure** 就是结果；全失败才 Failure |
| 3 | `Sequence` | P0 | 按顺序跑，遇 Failure 或 Running 立即短路；全成功才 Success |
| 4 | `Parallel` | P0 | 全跑；有 Failure 即 Failure；全 Success 才 Success；否则 Running |
| 5 | `IsDead` | P0 | 自己血量 ≤ 0 → 成功 |
| 6 | `HasTarget` | P0 | 有目标且目标活着 → 成功 |
| 7 | `InAttackRange(rangeMm)` | P0 | 目标在射程内；`rangeMm = 0` 用默认射程 2000 |
| 8 | `AttackReady(skillId)` | P0 | 指定技能冷却已好；`skillId = 0` 表示普攻 |
| 9 | `HPBelow(hpThreshold, percentOfMax)` | P0 | 血量低于阈值；`percentOfMax=true` 时 `hpThreshold` 按**百分比**理解（1~100） |
| 10 | `HomeFar` | P0 | 离出生点超过该怪的「回位半径」 |
| 11 | 上下文与操作薄封装 `BtContext` / `BtOps` | P0 | 世界、自己、出生点、目标、帧号、AI 参数；不每帧 new |
| 12 | 节点可被 R022-3 扫描注册 | P0 | 每类一个文件、无参构造 + `Configure(params)`、`[BtNode("名字")]` 标记 |

## 四、边界（本版明确不做）

- **不做动作节点**（追/打/放技能/回位/巡逻/站桩/等待）→ R022-2。
- **不做** `MonsterBrain`、**不改** `DungeonBattle` 的怪行为 → R022-2。
- **不做** JSON 读取与节点工厂 → R022-3。
- **不改玩家侧**（玩家保持状态机）。
- 不做可视化/编辑器内调试（编辑器侧已由 R023/R024 负责）。
- `Parallel` 只要求"全跑一遍再聚合"，**不做**并行线程。

## 五、优先级

**P0**。依赖：无（纯 C#）。被依赖：R022-2（动作与接线）、R022-3（JSON 工厂）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 子节点依次返回 Failure、Success 时，`Selector` 应返回 Success，且**第三个子节点不再执行**
- [ ] 当 任一子节点返回 Running 时，`Sequence` 应立即返回 Running，**后面的子节点不再执行**
- [ ] 当 子节点为 Success、Failure、Success 时，`Parallel` 应返回 Failure
- [ ] 当 自己 HP = 0 时，`IsDead` 应返回 Success；HP = 1 时应返回 Failure
- [ ] 当 目标为 null 或已死亡时，`HasTarget` 应返回 Failure
- [ ] 当 距离 = 射程边界（2000mm）时，`InAttackRange(0)` 应返回 Success；2001mm 时应返回 Failure
- [ ] 当 普攻冷却剩 1 帧时，`AttackReady(0)` 应返回 Failure；0 帧时应返回 Success
- [ ] 当 `HPBelow(30, false)` 且 HP = 30（满血 100）时应返回 **Failure**（严格小于）；HP = 29 时应返回 Success
- [ ] 当 `HPBelow(30, true)` 且 HP = 30/100 时应返回 **Failure**；29/100 时应返回 Success
- [ ] 当 离家距离 = 回位半径时，`HomeFar` 应返回 Failure；超过 1mm 时应返回 Success
- [ ] 当 **连跑 1000 帧**时，不应产生每帧堆分配（`BtContext` 复用）
- [ ] 当 用同一组输入跑两局时，相同帧的条件结果应**完全一致**（无随机、无真实时间）
- [ ] 当 新增一个条件节点时，应**只新增一个文件**，`BtContext`/组合节点/工厂代码一行不改
