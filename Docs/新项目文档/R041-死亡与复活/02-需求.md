# R041 死亡与复活 —— 02 需求

需求编号：R041
所属阶段：M4
作者：AI 辅助
状态：开发中

## 1. 业务目标（一句话）

玩家被打死后不再"卡在尸体上"：主世界回出生点满血复活，副本里按单人/多人分流退出或旁观，全程有 5 秒黑屏倒计时，不结算、不掉落。

## 2. 用户与场景

| 场景 | 玩家经历 | 期望 |
| --- | --- | --- |
| 主世界 `World` | 被怪（或调试键 `L`）打死 | 黑屏 + 倒计时 5 秒 → 回村口出生点，满血、能继续走 |
| 副本 `Battle`（单人） | 被 BOSS/小怪打死 | 黑屏 + 倒计时 5 秒 → 回到 `World`，副本下次进去是新的 |
| 副本 `Battle`（多人） | 同上 | 黑屏 + 倒计时 5 秒 → 角色隐藏、输入禁用、屏幕提示「旁观中」，其他人继续打；可手动退出回 `World` |

## 3. 功能列表

| 优先级 | 功能 |
| --- | --- |
| P0 | 死亡检测：自己的英雄 `Alive=false`（客户端）或本地 `PlayerBrain` 进入死亡（主世界调试键）时触发流程 |
| P0 | 全屏黑幕 + 倒计时（5 → 0）+ 文案（`已复活` / `即将退出副本` / `旁观中`） |
| P0 | 主世界：倒计时结束 → 传送回出生点、满血、清状态、恢复输入 |
| P0 | 副本单人：倒计时结束 → `SceneFlow` 切回 `World`，并通知服务端离开房间 |
| P0 | 副本多人：倒计时结束 → 隐藏自己角色、禁用输入、显示旁观提示；按 `Esc`/按钮退出回 `World` |
| P1 | 死亡瞬间播死亡动画（`PlayerBrain.NotifyDead`）并停止移动/攻击 |
| P1 | 复活/退出后 HUD 血条回到满血 |
| P2 | 倒计时秒数从配置读（默认 5），改配置不需要改代码 |

## 4. 边界（不做什么）

1. 不做结算面板、不做战败统计（属于 R042）。
2. 不做掉落/惩罚（负责人明确「不掉落」）。
3. 不做"多人整房解散"（多人选的是留房旁观）。
4. 不做复活次数限制（主世界无限复活）。
5. 不做新协议字段（`EntitySnapshot.Alive` 已够用）。
6. 不做副本内原地复活（副本死亡一律退出或旁观）。

## 5. 优先级

先做 P0 的三条主路径（主世界 / 单人副本 / 多人旁观）+ 黑幕倒计时；P1 补动画与 HUD；P2 把 5 秒挪进配置。

## 6. 验收标准

| # | 当…时 | 应… |
| --- | --- | --- |
| 1 | 主世界里按 `L`（或血量归零） | 立刻黑幕、显示 5→0 倒计时，期间 WASD/攻击/跳跃全部无反应 |
| 2 | 主世界倒计时结束 | 角色出现在出生点 `(280.799, 1.450, 425.014)`，血条满、能立刻移动 |
| 3 | 副本里单人被打死 | 黑幕 5 秒，文案「即将退出副本」 |
| 4 | 副本单人倒计时结束 | 回到 `World` 场景，角色满血；再次进副本怪物是满血的新局 |
| 5 | 副本里多人（≥2 人）之一被打死 | 其他玩家画面正常；死者黑幕 5 秒后进入旁观态（自己角色隐藏、输入无效、提示「旁观中，按 Esc 退出」） |
| 6 | 旁观者按 `Esc` | 回到 `World`，房间与其他人不受影响 |
| 7 | 死亡流程进行中重复按攻击/跳跃/再按 `L` | 不重复触发、不叠加黑幕、不重复切场景 |
| 8 | 主世界复活后 | HUD 血条为满值，且不与服务端血量打架（复活后第一次快照 HP=MaxHp） |
| 9 | 任意死亡流程结束 | 没有结算面板弹出、没有掉落、没有日志报错 |
| 10 | 修改配置里的倒计时秒数并重进 | 黑幕倒计时按新值走（默认 5） |
