# R041 死亡与复活 —— 06 手工验收

需求编号：R041
所属阶段：M4
作者：AI 辅助
状态：待验收

## 1. 计划

- 正常：World 里按 L 死亡 → 黑幕 + 5 秒倒计时 → 回到出生点、满血、能动。
- 异常：死亡瞬间按方向键 / Space / 左键，不应把角色拉起来；倒计时中再按 L 不应重新计时。
- 边界：Level 表把 `deathCountdownSeconds` 改成 3 / 15 时倒计时跟着变（改表要重新生成 + 重开 Unity）。
- 性能：倒计时期间 Console 每帧刷日志数量可控（`m_logDiagnostics` 只为诊断，验收后可关）。

## 2. 正常流程走查

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | 打开 `Client/Assets/_Project/Scenes/World.unity`，进 Play | 角色站在村口，能走能跑 |
| 2 | 按 `L`（死亡调试键） | 角色播死亡动画、不能再移动，屏幕渐黑 |
| 3 | 看画面中央 | 显示「你已倒下」与「5 秒」倒数：5→4→3→2→1 |
| 4 | 数到 0 | 黑幕消失，角色站在出生点 `(280.799, 1.45, 425.014)`，镜头正常 |
| 5 | 按 `W` | 能正常走/跑，状态机回到 `Idle/Run`（Console 有 `[PlayerBrain]` 转移日志） |
| 6 | 再按 `L` | 能再次进入同一套流程（可重复） |

## 3. 异常场景

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | 死亡瞬间按住 `W` + `Space` | 不复活、不位移；倒计时照常走 |
| 2 | 倒计时中再按 `L` | 不重新计时、不重置秒数 |
| 3 | 倒计时中按 `Ctrl+Shift+1` 切场景 | 允许切换，黑幕随场景销毁（不残留） |

## 4. 性能

- 进 Play 后静止 10 秒：Console 不应刷屏（只有状态转移日志）。
- 死亡一次：`PlayerDeathFlow` 只在开始时打印一行诊断，不产生每帧日志。
