约束：

1. 服务端一行不改：死亡判定仍由服务端（`AliveHeroCount`）、客户端只负责表现与分流。
2. 黑幕不用 YooAsset 预制体（UI 收集器还没配），运行时用 UGUI 现建，字体取内置 `LegacyRuntime.ttf`。
3. 倒计时秒数读 `Level.csv` 的 `deathCountdownSeconds`，读不到退回 Inspector 的 5 秒。
4. 世界复活不扣血、不掉落、不结算（负责人 2026-11-15 决策）。
5. 多人副本「留房旁观」= 隐藏自己 + 禁用输入 + 黑幕提示 + 按 Esc 退出。

## 2. 功能概述

玩家在世界里被怪打死：屏幕变黑、显示「你已倒下」「5 秒」，倒计时结束后角色回到村口出生点、满血、能继续走。

玩家在单人副本里倒下：黑屏 5 秒后自动退出房间、回到世界。

玩家在多人副本里倒下：黑屏 5 秒后进入旁观（自己消失、不能操作），其他玩家继续打；按 Esc 手动退出副本。

## 4. 逐段讲解

### 4.1 死亡检测：两条来源，一个出口

本地世界没有网络快照，只能看 `PlayerBrain.IsDead`（调试键 L 或以后的血量归零）。联网副本里英雄是服务端实体，客户端每帧在 `TrackHeroHealth` 里拿快照，`hero.Alive == false` 就把 `m_heroAlive` 置 false。

`IsDeadNow()` 先看大脑、再看驱动，任一为真就走死亡流程——这样同一套代码在两个场景都能用。

### 4.2 倒计时为什么读表

§0.4 规定界面/手感数据从配置来。`Level.csv` 新增 `deathCountdownSeconds`（1~15 秒，三行都是 5），`ResolveCountdownSeconds()` 通过 `ConfigMgr.TryGet<LevelConfig>()` 取第 `m_levelId` 行；取不到就用 Inspector 的 `m_countdownSeconds`。改完 CSV 要重跑 ConfigKit，再在 Unity 里重导 `LevelConfig.asset`。

### 4.3 黑幕为什么运行时建

UI 收集器（`ui_*`）还没配，`UIManager.ShowPanel` 找不到预制体会直接失败。R041 用 `DeathScreenOverlay` 在第一次需要时建 Canvas + Image + 三个 Text，字体走 `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")`（Unity 2022 起 Arial 改名），拿不到再试 `Arial.ttf`。好处是不依赖任何资产，坏处是不能在 Inspector 里调样式——样式参数都写成常量。

### 4.4 分流：靠「场景名 + 人数」

- 场景名是 `World` ⇒ `ReviveInWorld()`：传送 `m_worldSpawn`、`PlayerJumpMotor.ResetToGround()`（死亡时可能在空中）、`NotifyRevive()`、恢复渲染器、关黑幕。
- 副本且 `HeroEntityCount > 1` ⇒ `EnterSpectator()`：关渲染器、`PlayerMove.MovementEnabled = false`、`PlayerJumpMotor.enabled = false`，黑幕提示「按 Esc 退出副本」，`Update` 里轮询 Esc。
- 副本且只有 1 个英雄 ⇒ `ExitToWorld()`：`LeaveRoom()` 后 `SceneFlow.LoadAsync(GameScene.World)`。

人数用快照里 `Kind == 0` 的实体数，不额外加协议。

### 4.5 复活为什么必须在状态机里做

`Dead` 标记在 `PlayerStateContext` 里，`Tick` 一旦看到它就把移动闸门关死、每帧只同步参数。只在外面把 `MovementEnabled` 打开没用，下一帧 `Tick` 又会关掉。所以 `NotifyRevive()` 必须清 `Dead`、清动作残留、把 `Grounded` 置真、`ForceChange(Locomotion, Idle)`，再开闸门。

### 4.6 副本里组件从哪来

World 场景的 `[Player_Hero]` 上手动挂 `PlayerDeathFlow`。Battle 的英雄是 `SnapshotSceneBinder` 运行时生成的，挂不到预制体；所以 `RuntimeNetDriver.TrackHeroHealth` 第一次拿到英雄快照时调 `EnsureDeathFlow()`，把组件挂到驱动自己身上，`EnsureFallbackRefs()` 再全场景找 `PlayerBrain` / `PlayerMove` / 渲染器。

## 5. 完整代码

### 5.1 PlayerDeathFlow.cs

```csharp
// 这个文件里有：
//   PlayerDeathFlow：角色死后的分流处理（世界回出生点复活 / 副本单人退出 / 副本多人留房旁观）。

using System;
using NBC.Game.Bootstrap;
using NBC.Game.Config;
using NBC.Game.GameFlow;
using NBC.Game.UI;
using UnityEngine;
using UnityEngine.SceneManagement;

namespace NBC.Game.Player
{
    // 主要功能：发现角色死亡 → 黑屏倒计时 → 按场景分流（世界复活、副本单人退出、副本多人旁观）。
    // 主要数据成员：m_countdownSeconds（秒）、m_worldSpawn（世界出生点）、m_levelId（读 Level 表用）、m_brain / m_move / m_jumpMotor / m_driver。
    // 主要外部方法：无（挂在玩家根节点上，Update 里自己驱动）。
    // 谁在用它：World 与 Battle 两个场景里的 [Player_Hero] 根节点。
    public sealed class PlayerDeathFlow : MonoBehaviour
    {
        // 世界场景名（用来区分「本地世界」与「联网副本」）
        private const string WorldSceneName = "World";

        // 读不到 Level 表时的兜底倒计时（秒）
        private const float FallbackCountdownSeconds = 5f;

        // 倒计时秒数；Start 里会优先用 Level 表的 deathCountdownSeconds
        [SerializeField] private float m_countdownSeconds = FallbackCountdownSeconds;

        // 世界出生点（村口，和 R034 记的坐标一致）
        [SerializeField] private Vector3 m_worldSpawn = new Vector3(280.799f, 1.45f, 425.014f);

        // 读哪一行 Level 配置（默认第 1 行）
        [SerializeField] private int m_levelId = 1;

        // 死亡期间要不要把角色藏起来（旁观模式用；世界复活不需要）
        [SerializeField] private bool m_hideWhenDead = true;

        // 要不要打诊断日志
        [SerializeField] private bool m_logDiagnostics = true;

        // 玩家根节点上的大脑 / 移动 / 跳跃电机（懒找）
        private PlayerBrain m_brain;
        private PlayerMove m_move;
        private PlayerJumpMotor m_jumpMotor;

        // 联网驱动（只有 Battle 场景有）
        private RuntimeNetDriver m_driver;

        // 角色身上所有渲染器（隐藏/恢复用）
        private Renderer[] m_renderers;

        // 是否正在倒计时
        private bool m_counting;

        // 剩余秒数
        private float m_remaining;

        // 是否已进入旁观模式
        private bool m_spectating;

        // 倒计时结束后的分流是否已经执行过
        private bool m_resolved;

        // 功能：缓存引用、读配置、确保死亡黑幕存在。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 找大脑/移动/跳跃电机 2) 收渲染器列表 3) 读 Level 表倒计时 4) 建黑幕单例。
        // 上游/下游：Unity 生命周期；下游 LevelConfig.Get、DeathScreenOverlay.Ensure。
        private void Awake()
        {
            m_brain = GetComponent<PlayerBrain>();
            m_move = GetComponent<PlayerMove>();
            m_jumpMotor = GetComponent<PlayerJumpMotor>();
            m_renderers = GetComponentsInChildren<Renderer>(true);
            m_countdownSeconds = ResolveCountdownSeconds();
            DeathScreenOverlay.Ensure();
        }

        // 功能：补找 Component 式的引用（Battle 场景里本组件挂在别的物体上时用）。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 缺大脑就全场景找一个 2) 缺移动就全场景找一个 3) 渲染器为空就从角色模型上收一遍。
        // 上游/下游：BeginCountdown / EnterSpectator 前调用。
        private void EnsureFallbackRefs()
        {
            if (m_brain == null)
            {
                m_brain = UnityEngine.Object.FindObjectOfType<PlayerBrain>();
            }

            if (m_move == null)
            {
                m_move = UnityEngine.Object.FindObjectOfType<PlayerMove>();
            }

            if (m_jumpMotor == null && m_move != null)
            {
                m_jumpMotor = m_move.GetComponent<PlayerJumpMotor>();
            }

            if ((m_renderers == null || m_renderers.Length == 0) && m_move != null)
            {
                m_renderers = m_move.GetComponentsInChildren<Renderer>(true);
            }
        }

        // 功能：每帧看角色死没死，死了就开始倒计时，倒计时结束做分流。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 没死就返回 2) 第一次发现死亡就开倒计时 3) 倒计时递减并刷黑幕 4) 到点分流。
        // 上游/下游：Unity 生命周期；下游 DeathScreenOverlay、ResolveWorld / ResolveBattle。
        private void Update()
        {
            if (!IsDeadNow())
            {
                return;
            }

            if (!m_counting && !m_resolved)
            {
                BeginCountdown();
            }

            if (m_spectating)
            {
                if (Input.GetKeyDown(KeyCode.Escape))
                {
                    ExitToWorld("手动退出副本");
                }

                return;
            }

            if (!m_counting)
            {
                return;
            }

            m_remaining -= Time.deltaTime;
            DeathScreenOverlay overlay = DeathScreenOverlay.Ensure();
            overlay.SetCountdown(m_remaining);

            if (m_remaining <= 0f)
            {
                m_counting = false;
                m_resolved = true;
                ResolveDeath();
            }
        }

        // 功能：判断「现在算不算死了」。
        // 入参：无。
        // 返回：true 表示该走死亡流程。
        // 步骤：本地世界看大脑的死亡标记；联网副本先看驱动有没有收到「英雄已倒下」。
        // 上游/下游：Update 调用。
        private bool IsDeadNow()
        {
            if (m_brain != null && m_brain.IsDead)
            {
                return true;
            }

            RuntimeNetDriver driver = GetDriver();

            if (driver != null && driver.IsJoined && !driver.HeroAlive)
            {
                return true;
            }

            return false;
        }

        // 功能：开始倒计时并显示黑幕。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 标记倒计时 2) 复位剩余秒数 3) 判断单人还是多人，写不同提示 4) 显示黑幕。
        // 上游/下游：Update 调用；下游 DeathScreenOverlay.Show。
        private void BeginCountdown()
        {
            EnsureFallbackRefs();
            m_counting = true;
            m_remaining = m_countdownSeconds;

            DeathScreenOverlay overlay = DeathScreenOverlay.Ensure();
            overlay.Show("你已倒下", HintForMode());
            overlay.SetCountdown(m_remaining);

            if (m_logDiagnostics)
            {
                Debug.Log("[死亡流程] 开始倒计时 " + m_countdownSeconds.ToString("0.0") + " 秒"
                    + "（场景=" + SceneManager.GetActiveScene().name
                    + "，英雄数=" + (GetDriver() != null ? GetDriver().HeroEntityCount : 0) + "）");
            }
        }

        // 功能：倒计时结束后按场景与人数分流。
        // 入参：无。
        // 返回：无。
        // 步骤：世界场景直接复活；副本里多人留房旁观、单人退出回世界。
        // 上游/下游：Update 调用；下游 ReviveInWorld / EnterSpectator / ExitToWorld。
        private void ResolveDeath()
        {
            if (IsWorldScene())
            {
                ReviveInWorld();
                return;
            }

            RuntimeNetDriver driver = GetDriver();
            int heroes = driver != null ? driver.HeroEntityCount : 1;

            if (heroes > 1)
            {
                EnterSpectator();
            }
            else
            {
                ExitToWorld("单人副本倒下");
            }
        }

        // 功能：在世界里把角色原地复活并送回出生点。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 传送 2) 竖直积分清零 3) 让状态机复活 4) 关黑幕。
        // 上游/下游：ResolveDeath 调用；下游 PlayerBrain.NotifyRevive、PlayerJumpMotor.ResetToGround。
        private void ReviveInWorld()
        {
            transform.position = m_worldSpawn;

            if (m_jumpMotor != null)
            {
                m_jumpMotor.ResetToGround();
            }

            if (m_brain != null)
            {
                m_brain.NotifyRevive();
            }

            SetRenderersVisible(true);
            DeathScreenOverlay.Ensure().Hide();
            m_resolved = false;

            if (m_logDiagnostics)
            {
                Debug.Log("[死亡流程] 已在世界复活，位置=" + m_worldSpawn);
            }
        }

        // 功能：多人副本里进入旁观：藏起自己、关掉操作、黑幕改成提示。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 标记旁观 2) 藏渲染器 3) 关移动与跳跃 4) 黑幕写「按 Esc 退出」。
        // 上游/下游：ResolveDeath 调用；下游 DeathScreenOverlay。
        private void EnterSpectator()
        {
            EnsureFallbackRefs();
            m_spectating = true;

            if (m_hideWhenDead)
            {
                SetRenderersVisible(false);
            }

            if (m_move != null)
            {
                m_move.MovementEnabled = false;
            }

            if (m_jumpMotor != null)
            {
                m_jumpMotor.enabled = false;
            }

            DeathScreenOverlay overlay = DeathScreenOverlay.Ensure();
            overlay.Show("你已倒下", "正在观战，按 Esc 退出副本");
            overlay.SetStatusText("观战中");

            if (m_logDiagnostics)
            {
                Debug.Log("[死亡流程] 进入旁观（英雄数=" + (GetDriver() != null ? GetDriver().HeroEntityCount : 0) + "）");
            }
        }

        // 功能：退出副本并回到世界场景。
        // 入参：reason 退出原因（只用于日志）。
        // 返回：无。
        // 步骤：1) 让会话退出房间 2) 用 SceneFlow 载入 World 3) 结果写日志。
        // 上游/下游：ResolveDeath / Update 的 Esc 调用；下游 RuntimeNetDriver.LeaveRoom、SceneFlow.LoadAsync。
        private void ExitToWorld(string reason)
        {
            m_spectating = false;
            m_counting = false;

            RuntimeNetDriver driver = GetDriver();

            if (driver != null)
            {
                driver.LeaveRoom();
            }

            if (m_logDiagnostics)
            {
                Debug.Log("[死亡流程] 退出副本回世界（原因=" + reason + "）");
            }

            SceneFlow flow = SceneFlow.Instance;

            if (flow == null)
            {
                Debug.LogWarning("[死亡流程] 找不到 SceneFlow，直接 LoadScene(World)");
                SceneManager.LoadScene(WorldSceneName);
                return;
            }

            flow.LoadAsync(GameScene.World, (ok, error) =>
            {
                if (!ok)
                {
                    Debug.LogWarning("[死亡流程] 加载 World 失败：" + error);
                }
            });
        }

        // 功能：按模式给一行提示（世界写「秒后复活」，副本写「秒后退出/观战」）。
        // 入参：无。
        // 返回：提示文字。
        // 步骤：世界固定文案；副本按人数给两种文案。
        // 上游/下游：BeginCountdown 调用。
        private string HintForMode()
        {
            if (IsWorldScene())
            {
                return "秒后回到出生点";
            }

            RuntimeNetDriver driver = GetDriver();
            int heroes = driver != null ? driver.HeroEntityCount : 1;
            return heroes > 1 ? "秒后进入观战" : "秒后退出副本";
        }

        // 功能：从 Level 表读死亡倒计时（秒）。
        // 入参：无。
        // 返回：倒计时秒数；读不到就返回兜底值。
        // 步骤：1) 拿 LevelConfig 2) 按 m_levelId 取行 3) 夹到 1~15 秒。
        // 上游/下游：Awake 调用；下游 ConfigMgr.TryGet、LevelConfig.Get。
        private float ResolveCountdownSeconds()
        {
            LevelConfig table;

            if (ConfigMgr.Instance == null || !ConfigMgr.Instance.TryGet<LevelConfig>(out table) || table == null)
            {
                return m_countdownSeconds > 0f ? m_countdownSeconds : FallbackCountdownSeconds;
            }

            try
            {
                Config_Level row = table.Get(m_levelId);

                if (row != null && row.deathCountdownSeconds > 0)
                {
                    return Mathf.Clamp(row.deathCountdownSeconds, 1, 15);
                }
            }
            catch (Exception)
            {
                // 表里没有这一行时保持 Inspector 上的值
            }

            return m_countdownSeconds > 0f ? m_countdownSeconds : FallbackCountdownSeconds;
        }

        // 功能：判断当前是不是世界场景。
        // 入参：无。
        // 返回：true 表示 World。
        // 步骤：比较当前激活场景名。
        // 上游/下游：IsDeadNow / HintForMode / ResolveDeath 调用。
        private bool IsWorldScene()
        {
            return SceneManager.GetActiveScene().name == WorldSceneName;
        }

        // 功能：懒加载联网驱动。
        // 入参：无。
        // 返回：驱动；不在副本里返回 null。
        // 步骤：第一次调用时 FindObjectOfType 并缓存。
        // 上游/下游：IsDeadNow / BeginCountdown / ResolveDeath / ExitToWorld 调用。
        private RuntimeNetDriver GetDriver()
        {
            if (m_driver == null)
            {
                m_driver = UnityEngine.Object.FindObjectOfType<RuntimeNetDriver>();
            }

            return m_driver;
        }

        // 功能：把所有渲染器一次开/关（旁观时藏起自己）。
        // 入参：visible true 显示、false 隐藏。
        // 返回：无。
        // 步骤：遍历 Awake 缓存的渲染器数组逐个设置 enabled。
        // 上游/下游：ReviveInWorld / EnterSpectator 调用。
        private void SetRenderersVisible(bool visible)
        {
            if (m_renderers == null)
            {
                return;
            }

            for (int i = 0; i < m_renderers.Length; i++)
            {
                if (m_renderers[i] != null)
                {
                    m_renderers[i].enabled = visible;
                }
            }
        }
    }
}
```

### 5.2 DeathScreenOverlay.cs

```csharp
// 这个文件里有：
//   DeathScreenOverlay：死亡时盖在屏幕上的黑幕、标题、倒计时与提示（运行时建 UGUI，不依赖预制体）。

using UnityEngine;
using UnityEngine.UI;

namespace NBC.Game.UI
{
    // 主要功能：角色倒下后显示全屏黑幕、标题、倒计时秒数与一行提示，复活或退出时隐藏。
    // 主要数据成员：m_canvas / m_background / m_title / m_countdown / m_hint（都是运行时创建的 UGUI 对象）。
    // 主要外部方法：Ensure（拿单例）、Show（显示并给标题与提示）、SetCountdown（更新秒数）、Hide（隐藏）。
    // 谁在用它：PlayerDeathFlow（死亡倒计时与旁观提示都走这里）。
    public sealed class DeathScreenOverlay : MonoBehaviour
    {
        // 内置字体名（Unity 2022 起 Arial.ttf 改叫 LegacyRuntime.ttf）
        private const string BuiltinFontName = "LegacyRuntime.ttf";

        // 旧版 Unity 的内置字体名，第一项取不到时兜底
        private const string LegacyBuiltinFontName = "Arial.ttf";

        // 黑幕不透明度（0~1）：留一点画面能看见角色倒下的姿势
        private const float BackgroundAlpha = 0.82f;

        // 单例（全场景只允许一个）
        private static DeathScreenOverlay s_instance;

        private Canvas m_canvas;  // 全屏画布（ScreenSpaceOverlay，排序值 900）
        private Image m_background;  // 全屏黑幕
        private Text m_title;  // 标题（例如「你已倒下」）
        private Text m_countdown;  // 倒计时秒数（秒）
        private Text m_hint;  // 底部提示

        // 功能：拿到单例；场景里没有就现建一个挂在新建的 GameObject 上。
        // 入参：无。
        // 返回：单例（永不为 null）。
        // 步骤：1) 已有就返回 2) 没有就新建空物体并挂本组件 3) 返回组件。
        // 上游/下游：PlayerDeathFlow 调用；下游 Awake（建 UI）。
        public static DeathScreenOverlay Ensure()
        {
            if (s_instance != null)
            {
                return s_instance;
            }

            GameObject host = new GameObject("[DeathScreenOverlay]");
            return host.AddComponent<DeathScreenOverlay>();
        }

        // 功能：当前是否正在显示黑幕。
        // 入参：无。
        // 返回：true 表示黑幕可见。
        // 步骤：读背景对象的 activeSelf。
        // 上游/下游：PlayerDeathFlow 判断要不要重复 Show。
        public bool IsShowing
        {
            get { return m_background != null && m_background.gameObject.activeSelf; }
        }

        // 功能：登记单例并建好整套 UI。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 已有别的实例就自毁 2) 登记自己 3) 建 UI 并先隐藏。
        // 上游/下游：Unity 生命周期；下游 Build / Hide。
        private void Awake()
        {
            if (s_instance != null && s_instance != this)
            {
                Destroy(gameObject);
                return;
            }

            s_instance = this;
            Build();
            Hide();
        }

        // 功能：销毁时把单例清掉，避免下次拿到已销毁对象。
        // 入参：无。
        // 返回：无。
        // 步骤：是自己就置空。
        // 上游/下游：Unity 生命周期。
        private void OnDestroy()
        {
            if (s_instance == this)
            {
                s_instance = null;
            }
        }

        // 功能：显示黑幕并写标题与提示。
        // 入参：title 标题文字；hint 底部提示文字（空串表示不显示）。
        // 返回：无。
        // 步骤：1) 没有 UI 就先建 2) 写标题与提示 3) 倒计时先隐藏（由 SetCountdown 决定要不要出现）4) 打开黑幕。
        // 上游/下游：PlayerDeathFlow 开始倒计时 / 进入旁观时调用。
        public void Show(string title, string hint)
        {
            if (m_background == null)
            {
                Build();
            }

            m_title.text = title;
            m_hint.text = hint;
            m_countdown.text = string.Empty;
            m_background.gameObject.SetActive(true);
        }

        // 功能：更新倒计时秒数（向上取整，小于等于 0 时显示「0」）。
        // 入参：remaining 剩余秒数。
        // 返回：无。
        // 步骤：取整后拼成「N 秒后复活」；负数按 0 处理。
        // 上游/下游：PlayerDeathFlow.Update 每帧调用。
        public void SetCountdown(float remaining)
        {
            if (m_countdown == null)
            {
                return;
            }

            int seconds = Mathf.Max(0, Mathf.CeilToInt(remaining));
            m_countdown.text = seconds + " 秒";
        }

        // 功能：把倒计时文字换成一句状态提示（旁观的「等待其他玩家」用）。
        // 入参：text 要显示的文字。
        // 返回：无。
        // 步骤：直接写文字，不判空以外的逻辑。
        // 上游/下游：PlayerDeathFlow 进入旁观后调用。
        public void SetStatusText(string text)
        {
            if (m_countdown == null)
            {
                return;
            }

            m_countdown.text = text;
        }

        // 功能：隐藏整块黑幕。
        // 入参：无。
        // 返回：无。
        // 步骤：黑幕存在就关掉它的 GameObject。
        // 上游/下游：PlayerDeathFlow 复活 / 退出副本时调用。
        public void Hide()
        {
            if (m_background != null)
            {
                m_background.gameObject.SetActive(false);
            }
        }

        // 功能：一次性搭好 Canvas、黑幕、标题、倒计时和提示。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 建 Canvas 与缩放器 2) 建黑幕铺满 3) 建三段文字并摆好位置 4) 缓存引用。
        // 上游/下游：Awake / Show 调用。
        private void Build()
        {
            if (m_canvas != null)
            {
                return;
            }

            GameObject canvasObject = new GameObject("Canvas");
            canvasObject.transform.SetParent(transform, false);

            m_canvas = canvasObject.AddComponent<Canvas>();
            m_canvas.renderMode = RenderMode.ScreenSpaceOverlay;
            m_canvas.sortingOrder = 900;

            CanvasScaler scaler = canvasObject.AddComponent<CanvasScaler>();
            scaler.uiScaleMode = CanvasScaler.ScaleMode.ScaleWithScreenSize;
            scaler.referenceResolution = new Vector2(1920f, 1080f);
            scaler.matchWidthOrHeight = 0.5f;

            canvasObject.AddComponent<GraphicRaycaster>();

            m_background = CreateImage(canvasObject.transform, "Background", new Color(0f, 0f, 0f, BackgroundAlpha));
            m_title = CreateText(canvasObject.transform, "Title", 96, new Vector2(0f, 120f), new Vector2(1600f, 160f));
            m_countdown = CreateText(canvasObject.transform, "Countdown", 72, new Vector2(0f, -40f), new Vector2(1200f, 120f));
            m_hint = CreateText(canvasObject.transform, "Hint", 40, new Vector2(0f, -220f), new Vector2(1600f, 120f));

            m_title.text = string.Empty;
            m_countdown.text = string.Empty;
            m_hint.text = string.Empty;
        }

        // 功能：建一张铺满父节点的单色图片。
        // 入参：parent 父节点；name 物体名；color 颜色。
        // 返回：建好的 Image。
        // 步骤：1) 建空物体并拉伸铺满 2) 挂 Image 并上色 3) 关掉射线检测（不挡点击）。
        // 上游/下游：Build 调用。
        private static Image CreateImage(Transform parent, string name, Color color)
        {
            GameObject go = new GameObject(name);
            go.transform.SetParent(parent, false);

            RectTransform rect = go.AddComponent<RectTransform>();
            rect.anchorMin = Vector2.zero;
            rect.anchorMax = Vector2.one;
            rect.offsetMin = Vector2.zero;
            rect.offsetMax = Vector2.zero;

            Image image = go.AddComponent<Image>();
            image.color = color;
            image.raycastTarget = false;
            return image;
        }

        // 功能：建一段居中文字。
        // 入参：parent 父节点；name 物体名；fontSize 字号；anchoredPosition 相对屏幕中心的位置；size 文本框尺寸。
        // 返回：建好的 Text。
        // 步骤：1) 建空物体并设居中锚点 2) 挂 Text 设置字体、字号、对齐 3) 关掉射线检测。
        // 上游/下游：Build 调用；下游 LoadBuiltinFont。
        private static Text CreateText(Transform parent, string name, int fontSize, Vector2 anchoredPosition, Vector2 size)
        {
            GameObject go = new GameObject(name);
            go.transform.SetParent(parent, false);

            RectTransform rect = go.AddComponent<RectTransform>();
            rect.anchorMin = new Vector2(0.5f, 0.5f);
            rect.anchorMax = new Vector2(0.5f, 0.5f);
            rect.pivot = new Vector2(0.5f, 0.5f);
            rect.anchoredPosition = anchoredPosition;
            rect.sizeDelta = size;

            Text text = go.AddComponent<Text>();
            text.font = LoadBuiltinFont();
            text.fontSize = fontSize;
            text.alignment = TextAnchor.MiddleCenter;
            text.color = Color.white;
            text.raycastTarget = false;
            text.horizontalOverflow = HorizontalWrapMode.Overflow;
            text.verticalOverflow = VerticalWrapMode.Overflow;
            return text;
        }

        // 功能：取一个内置字体给 UGUI 用。
        // 入参：无。
        // 返回：内置字体；两个名字都取不到时返回 null（文字不显示，但不会崩）。
        // 步骤：先试 LegacyRuntime.ttf，再试 Arial.ttf。
        // 上游/下游：CreateText 调用。
        private static Font LoadBuiltinFont()
        {
            Font font = Resources.GetBuiltinResource<Font>(BuiltinFontName);

            if (font == null)
            {
                font = Resources.GetBuiltinResource<Font>(LegacyBuiltinFontName);
            }

            return font;
        }
    }
}
```
