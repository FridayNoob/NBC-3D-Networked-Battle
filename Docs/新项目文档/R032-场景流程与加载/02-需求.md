# 02 需求

需求：R032-场景流程与加载
所属阶段：M4
作者：AI 起草／LYF 确认　状态：待确认（2026-11-13）

## 一、业务目标（一句话）

**能用代码从一个场景切到另一个场景**：登录后进主世界、从主世界进副本/PVP，都为后续开放世界流程铺路。

## 二、用户与场景

- 用户：玩家（登录后应进 World；进副本应切 Battle；PVP 应切 PVP_Room）。
- 场景：在 Login 按一个按钮进 World；在 World 走进副本门口切 Battle；PVP 匹配成功切 PVP_Room。

## 三、功能列表

| # | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 1 | 场景枚举与地址映射 | P0 | Login/World/PvpRoom/Battle/Test → 文件名 |
| 2 | 统一加载入口 SceneFlow.LoadAsync | P0 | 优先 YooAsset，未初始化时兜底 SceneManager |
| 3 | 加载进度与错误回报 | P0 | 回调 (bool 成功, string 错误) |
| 4 | 防重复点击 | P0 | IsLoading 闸门 |
| 5 | 调试快捷键 F1~F5 | P1 | 手工验收用，正式版移除 |
| 6 | 加载遮罩（转圈/淡入淡出） | P2 | 本版不做，等美术 UI |

## 四、边界（本版明确不做）

- 不做加载遮罩/过场动画（P2）。
- 不做"登录逻辑"（账号密码校验是 R033 的事；本需求只做场景切换）。
- 不做 World 内容（地形/怪/NPC 由后续需求做）。
- 不改服务端。

## 五、优先级

**P0**。依赖：5 个场景已在 Build Settings、且位于 Assets/_Project/Scenes。

## 六、验收标准（「当…时，应…」）

- [ ] 当 GameSceneAddress.AddressOf(GameScene.World) 时，应返回 World
- [ ] 当 传未登记的场景编号时，应抛异常（不静默）
- [ ] 当 在 Login 场景按 F2 时，应切到 World 场景
- [ ] 当 在 World 按 F1 时，应切回 Login
- [ ] 当 加载中再次按快捷键时，应被拒绝并提示"正在加载中"
- [ ] 当 资源层未初始化（直接开 World 调试）时，应仍能加载（走 SceneManager 兜底）
- [ ] 当 地址配错时，Console 应出现 [SceneFlow] 加载 X 失败：...（不是黑屏无提示）
