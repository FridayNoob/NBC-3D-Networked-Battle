## 一、测试计划

## 二、操作步骤

1. 打开 Assets/_Project/Scenes/Login.unity，按 **Play**。
2. 按 **Ctrl+Shift+2**。
   - 期望：切到 World 场景；Console 出现 [SceneFlow] 相关日志（或至少没有红错）。
3. 在 World 按 **F1**，应切回 Login；再按 **F4** 进 Battle、**F3** 进 PVP_Room、**F5** 进 Test。
4. **兜底路径**：随便打开 World.unity 直接 Play（不进 Login 初始化资源），按 F1 切走。
   - 期望：仍能切（走 SceneManager），Console 无异常。
5. **错误提示**：把 GameSceneAddress 里 World 临时改成 World_XX，Play 后按 F2。
   - 期望：Console 红字 [SceneFlow] 加载 World_XX 失败：...，而不是黑屏无提示；验完改回来。
