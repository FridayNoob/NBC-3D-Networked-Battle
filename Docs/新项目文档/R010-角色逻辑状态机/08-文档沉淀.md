## 二、模块文档

### 简介与使用场景

`PlayerBrain`（`Game\Player\`）：用框架 `Framework\Fsm` 的 `StateMachine<EPlayerState>` 管角色的**逻辑状态**。
当前两态：`Idle`（禁止移动）、`Move`（可移动）。状态变化时打一条 Console 日志，并刷新两个 Inspector 调试字段。

**职责边界**：Brain 决定「该不该动」，`PlayerMove` 决定「怎么动」，`PlayerAnimation` 决定「画面怎么表现」。

### 核心接口

| 成员 | 入参 | 出参 | 说明 |
| --- | --- | --- | --- |
| `Current` | — | `EPlayerState` | 未启动返回 `Idle` |
| `CurrentName` | — | `string` | 调试用 |
| `IsMoving` | — | `bool` | = `Current == Move` |
| `RegisteredCount` | — | `int` | 应为 2 |
| `m_debugStateName`（序列化） | — | string | **Inspector 里看当前状态** |
| `m_debugRegistered`（序列化） | — | int | **Inspector 里看注册数** |
| `m_move`（序列化） | — | `PlayerMove` | 留空会自动在本物体找 |

### 使用示例（负责人亲手跑通，2026-10-31）

```text
玩家物体挂：PlayerMove + PlayerAnimation + PlayerBrain
Play → 按 W：Console 一条 [PlayerBrain] Idle → Move；Inspector 的 Debug State Name = Move
     → 松手：Console 一条 [PlayerBrain] Move → Idle；Debug State Name = Idle
     → 连续走 5 秒：不再打印
```

### 实现原理（简要）

`Update` 里：读输入 → `hasInput ? Move : Idle` → 与当前不同才 `TryChangeState` → `Tick(自增帧号)`。
状态的 `OnEnter` 开关 `PlayerMove.enabled`；`StateChanged` 事件里打日志并刷新调试字段。

### 已知限制与坑点

- **FSM 是帧驱动**（`StateTick` 只有 `Frame`/`DeltaFrames`，**没有 deltaTime**）⇒ 不能拿它算位移。
- **Inspector 只显示字段**：想看到状态就写 `[SerializeField]`，属性不显示。
- **`Idle` 会禁用 `PlayerMove`** ⇒ 站着时连「无输入转身」也不会响应（预期内）。
- 只有两态；`Attack`/`Dead`/`Stun` 未做。
- `SendEvent` 与 `TransitionRejected` 目前没有使用者（扩展点已留）。

### 修改维护注意事项

- **加新状态**：在 `EPlayerState` 加值 → 写状态类（继承 `StateBase<EPlayerState>`）→ 在 `PlayerBrain.Awake` 里 `Register` → 在 `Update` 里补「什么时候切过去」的判断。
- **想禁止某状态下移动**：状态 `OnEnter` 里 `m_move.enabled = false`；**别忘了** `PlayerMove.OnDisable` 会把速度清零（否则动画一直走）。
- **想让某状态「能动但慢」**：不要复制位移代码，改成给 `PlayerMove` 加 `SpeedScale` 参数（R010 03 的「六之二」写了这个演进方向）。
- **不要在状态里读 `Time.deltaTime`**：会把状态绑死 UnityEngine，脱离引擎无法测。
- **日志只放 `StateChanged` 里**，别放进 `Update`。

## 三、踩坑清单（现象 / 原因 / 解决）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| Inspector 找不到 `RegisteredCount` | 属性不进 Inspector | 加 `[SerializeField]` 调试字段 |
| `CS0234: NBC.Framework 中不存在 Event` | `StateChangeRecord` 在 `NBC.Framework.Fsm` | 删多余 using，改用 `Fsm` |
| Console 被状态日志刷满 | 日志写在 `Update` / 每帧切换 | 只在 `StateChanged` 打；切换前判 `wanted != Current` |
| 停了但动画还在走 | 禁用 `PlayerMove` 后速度字段残留 | `PlayerMove.OnDisable` 清零 |
| 站着按方向键没反应 | `Idle` 禁用了 `PlayerMove`，而输入判据在 Brain 里先读 | 实际上一按就有输入 ⇒ 立刻切 Move，不会卡住（已验证） |
