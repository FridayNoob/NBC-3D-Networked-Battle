## 一、子任务与设计约束

- 约束：位移仍由 `PlayerMove` 用真实时间算；FSM 只做逻辑状态（帧驱动，没有 deltaTime）。

| 子任务 | 文件 | 说明 |

## 二、功能概述

`PlayerBrain` 每帧判断「有没有方向输入」→ 决定 `Idle` / `Move` → `TryChangeState` → `Tick(自增帧号)`。
状态 `OnEnter` 里开关 `PlayerMove.enabled`；状态变化由 `StateChanged` 事件统一打一条日志。

## 三、接口与入参出参

| 成员 | 入参 | 出参 | 异常 |

| `PlayerBrain.Current` | — | `EPlayerState` | 不抛（未启动返回 Idle） |

| `PlayerBrain.RegisteredCount` | — | `int`（应为 2） | 同上 |
| `PlayerIdleState.OnEnter` | `previous` | 无 | 不抛 |
| `PlayerMove.OnDisable` | — | 无 | 不抛 |

## 四、逐段讲解

1. **为什么用自增帧号**：`Time.frameCount` 在编辑器暂停、时间缩放时语义会变；自增计数器只增不减，满足 FSM 的单调要求。
2. **为什么判据是「输入有没有方向」**：用速度判会在「按着键但被挡住」时反复切；输入是玩家的意图，更稳。
3. **为什么日志只打在一处**：`StateChanged` 事件在 Brain 里订阅，状态类不打印 —— 保证一次切换一条，不刷屏。
4. **为什么 `PlayerMove` 要加 `OnDisable`**：禁用后它不再写速度字段，`PlayerAnimation` 会读到「停之前那一帧」的旧值，动画会一直走。
5. **为什么状态类不碰 Animator**：逻辑与表现分层；动画仍由 `PlayerAnimation` 按实测速度喂参数。

```csharp
namespace NBC.Game.Player
{
    // 主要功能：标识角色的逻辑状态，供 PlayerBrain 的状态机使用。
    // 主要数据成员：Idle（站着，禁止移动）、Move（可移动）。
    // 主要外部方法：无（数组下标 / 字典键直接用）。
    // 谁在用它：PlayerBrain（状态机泛型参数）、PlayerIdleState、PlayerMoveState。
    // 注意：这是逻辑状态，不是 Animator 的 S_Idle / S_Walk —— 逻辑管规则，Animator 管画面，两层不要混。
    // 注意：以后加 Attack / Dead 直接在这里加值；Dead 要能挡住 Move 的进入（用 CanEnterFrom 判）。
    public enum EPlayerState
    {
        // 站着：当前不许移动（PlayerMove 被禁用）
        Idle = 0,

        // 可移动：PlayerMove 启用，正常读输入
        Move = 1,
    }
}
```

```csharp
// 这个文件里有：
//   PlayerIdleState（状态）：站着不动，进入时禁用 PlayerMove。
//   PlayerMoveState（状态）：可移动，进入时启用 PlayerMove。

using NBC.Framework.Fsm;

namespace NBC.Game.Player
{
    // 主要功能：代表「站着」这一逻辑状态 —— 进入时禁用它身上的 PlayerMove，让角色不能移动。
    // 主要数据成员：m_move（要开关的那个组件）。
    // 主要外部方法：OnEnter / OnExit（开关移动）、Name。
    // 谁在用它：PlayerBrain 在 Awake 时注册进状态机。
    // 注意：本状态不碰 Animator —— 停下时动画自己回 Idle，因为 PlayerMove 被禁用后速度归零（见 PlayerMove.OnDisable）。
    internal sealed class PlayerIdleState : StateBase<EPlayerState>
    {
        private readonly PlayerMove m_move;

        // 功能：记住要开关的组件，状态本身不含其它逻辑。
        // 入参：move 玩家身上的 PlayerMove（不能为 null，由 PlayerBrain 保证）
        // 返回：无
        // 步骤：直接赋值
        // 上游：PlayerBrain.Awake
        // 下游：OnEnter 用它禁用移动
        public PlayerIdleState(PlayerMove move)
        {
            m_move = move;
        }

        // 功能：状态名，日志与状态历史里显示的就是它。
        // 返回：固定字符串 Idle
        public override string Name
        {
            get { return "Idle"; }
        }

        // 功能：进入站姿时禁止移动。
        // 入参：previous 上一个状态（本状态用不到）
        // 返回：无
        // 步骤：直接禁用 PlayerMove（它被禁用时会自己把速度清零）
        // 上游：状态机在切换时调用
        // 下游：PlayerMove.OnDisable、PlayerAnimation（读到 0 速度 ⇒ 回 Idle）
        public override void OnEnter(EPlayerState previous)
        {
            m_move.enabled = false;
        }
    }

    // 主要功能：代表「可移动」这一逻辑状态 —— 进入时启用 PlayerMove，让输入重新生效。
    // 主要数据成员：m_move（要开关的那个组件）。
    // 主要外部方法：OnEnter / Name。
    // 谁在用它：PlayerBrain 在 Awake 时注册进状态机。
    // 注意：本状态只管「允许移动」，实际怎么动由 PlayerMove 决定（四向转身是 R013 定稿的，不在这里）。
    internal sealed class PlayerMoveState : StateBase<EPlayerState>
    {
        private readonly PlayerMove m_move;

        // 功能：记住要开关的组件。
        // 入参：move 玩家身上的 PlayerMove（不能为 null）
        // 返回：无
        // 步骤：直接赋值
        // 上游：PlayerBrain.Awake
        // 下游：OnEnter 用它启用移动
        public PlayerMoveState(PlayerMove move)
        {
            m_move = move;
        }

        // 功能：状态名，日志与状态历史里显示的就是它。
        // 返回：固定字符串 Move
        public override string Name
        {
            get { return "Move"; }
        }

        // 功能：进入可移动状态时启用移动组件。
        // 入参：previous 上一个状态（本状态用不到）
        // 返回：无
        // 步骤：直接启用 PlayerMove
        // 上游：状态机在切换时调用
        // 下游：PlayerMove.Update 重新开始读输入
        public override void OnEnter(EPlayerState previous)
        {
            m_move.enabled = true;
        }
    }
}
```

```csharp
// 这个文件里有：
//   PlayerBrain（组件）：用框架状态机管角色的逻辑状态（Idle / Move），并据此开关移动。

using NBC.Framework.Fsm;
using NBC.Framework.Input;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧判断「有没有方向输入」，据此在 Idle / Move 之间切逻辑状态，并把状态变化打成一条日志。
    // 主要数据成员：m_move（要开关的移动组件）、m_fsm（框架状态机）、m_frame（自增帧号，喂给 Tick）。
    // 主要外部方法：Current / CurrentName / IsMoving / RegisteredCount（只读观测）。
    // 谁在用它：挂在玩家物体上，和 PlayerMove / PlayerAnimation 同一个物体；由场景配置启用。
    // 注意：状态机是帧驱动（StateTick 只有 Frame / DeltaFrames，没有 DeltaTime）—— 位移仍由 PlayerMove 按真实时间算，别在这里算位移。
    // 注意：逻辑状态（本组件）与表现状态（Animator 的 S_Idle / S_Walk）是两层，本组件不写 Animator。
    // 注意：帧号用自增计数器而不是 Time.frameCount，避免编辑器暂停 / 时间缩放让语义变化；帧号只增不减。
    public sealed class PlayerBrain : MonoBehaviour
    {
        // 玩家身上的移动组件，Awake 时自动找（没找到会报错并停用自己）
        [SerializeField]
        private PlayerMove m_move;

        // 调试观察：当前状态名（运行时自动更新，只给人看，别手改）—— Unity 默认 Inspector 只显示字段，不显示属性
        [SerializeField]
        private string m_debugStateName = "Idle";

        // 调试观察：已注册状态数（运行时自动更新，应为 2）
        [SerializeField]
        private int m_debugRegistered;

        // 框架状态机：注册 Idle / Move，切换由「有没有方向输入」驱动
        private StateMachine<EPlayerState> m_fsm;

        // 喂给状态机的帧号：每帧 +1，从 0 起（状态机允许从 0 开始）
        private int m_frame;

        // 功能：当前逻辑状态。
        // 返回：EPlayerState 值；状态机没启动时返回 Idle
        public EPlayerState Current
        {
            get { return m_fsm == null || !m_fsm.IsStarted ? EPlayerState.Idle : m_fsm.Current; }
        }

        // 功能：当前状态名，给日志与调试面板用。
        // 返回：状态名（Idle / Move）；未启动时返回 Idle
        public string CurrentName
        {
            get { return m_fsm == null || !m_fsm.IsStarted ? "Idle" : m_fsm.CurrentName; }
        }

        // 功能：是否处于可移动状态。
        // 返回：true = Move
        public bool IsMoving
        {
            get { return Current == EPlayerState.Move; }
        }

        // 功能：已注册的状态数，用于在 Inspector 里确认装配成功（应为 2）。
        // 返回：注册数；未初始化时 0
        public int RegisteredCount
        {
            get { return m_fsm == null ? 0 : m_fsm.RegisteredCount; }
        }

        // 功能：装配状态机 —— 找移动组件、注册两个状态、订阅日志、以 Idle 启动。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 没配 m_move 就在本物体上找
        //   2) 找不到就报错并停用（否则后面每帧都会空引用）
        //   3) 建状态机、注册 Idle / Move
        //   4) 订阅 StateChanged 打日志（只在这里打，状态类不打，避免重复）
        //   5) 以 Idle 启动（启动前不能切状态）
        // 上游：Unity 引擎（物体激活时）
        // 下游：PlayerIdleState / PlayerMoveState、Debug.Log
        // 注意：必须在 Start 之前启动状态机；TryChangeState 在 Start 之前调用会抛异常
        private void Awake()
        {
            if (m_move == null)
            {
                m_move = GetComponent<PlayerMove>();
            }

            if (m_move == null)
            {
                Debug.LogError("[PlayerBrain] 找不到 PlayerMove，逻辑状态机无法开关移动。", this);
                enabled = false;
                return;
            }

            m_fsm = new StateMachine<EPlayerState>();
            m_fsm.Register(EPlayerState.Idle, new PlayerIdleState(m_move));
            m_fsm.Register(EPlayerState.Move, new PlayerMoveState(m_move));
            m_fsm.StateChanged += OnStateChanged;
            m_fsm.Start(EPlayerState.Idle);

            m_debugStateName = m_fsm.CurrentName;
            m_debugRegistered = m_fsm.RegisteredCount;
        }

        // 功能：每帧按「有没有方向输入」决定逻辑状态，然后推进状态机。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 读输入；输入被禁用或读不到时当作「没输入」
        //   2) 有方向分量（X 或 Y 非 0）就是要移动
        //   3) 期望状态与当前不一致时才 TryChangeState（同状态切是空操作，但避免每帧白调）
        //   4) Tick 推进（帧号自增），状态的 OnUpdate 在这时被调用
        // 上游：Unity 引擎每帧调用
        // 下游：StateMachine.TryChangeState / Tick、PlayerMove.enabled
        // 注意：判据用「输入有没有方向」而不是「当前速度」—— 被墙挡住时速度是 0，用速度判会反复切状态
        private void Update()
        {
            bool hasInput = HasDirectionInput();
            EPlayerState wanted = hasInput ? EPlayerState.Move : EPlayerState.Idle;

            if (wanted != m_fsm.Current)
            {
                m_fsm.TryChangeState(wanted);
            }

            m_frame++;
            m_fsm.Tick(m_frame);
        }

        // 功能：组件被禁用时停掉状态机订阅，避免残留回调。
        // 入参：无
        // 返回：无
        // 步骤：有状态机就退订
        // 上游：Unity 引擎
        // 下游：无
        private void OnDisable()
        {
            if (m_fsm != null)
            {
                m_fsm.StateChanged -= OnStateChanged;
            }
        }

        // 功能：判断本帧输入里有没有方向分量。
        // 入参：无
        // 返回：true = X 或 Y 不为 0（量化轴，范围 ±1000）
        // 步骤：
        //   1) 取 InputManager；为空或整体被禁用则视为没输入
        //   2) 看 Current 的 MoveX / MoveY 是否有非 0
        // 上游：Update
        // 下游：InputManager.Instance.Current、InputCommand.MoveX / MoveY
        private static bool HasDirectionInput()
        {
            InputManager input = InputManager.Instance;

            if (input == null || !input.IsEnabled)
            {
                return false;
            }

            InputCommand command = input.Current;
            return command.MoveX != 0 || command.MoveY != 0;
        }

        // 功能：状态变化时打一条日志（只在这里打，保证「一次切换一条」）。
        // 入参：record 状态变化记录（含 From / To / Frame / Forced）
        // 返回：无
        // 步骤：直接拼字符串输出
        // 上游：StateMachine.StateChanged
        // 下游：Console
        // 注意：日志必须只在切换时产生 —— 每帧打印会把 Console 刷满，也掩盖真正的问题
        private void OnStateChanged(StateChangeRecord record)
        {
            Debug.Log("[PlayerBrain] " + record.From + " → " + record.To);
            m_debugStateName = record.To;
        }
    }
}
```

### `Client/Assets/_Project/Game/Player/PlayerMove.cs`（改：末尾新增 `OnDisable`）

```csharp
// 这个文件里有：
//   PlayerMove（类）：四向移动（W/A/S/D 都是转身朝该方向再前进）；不斜走，朝向只由方向键决定

using NBC.Framework.Input;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧读输入，取主导轴得到 W/A/S/D 四种之一，统一「转身朝该方向 + 沿该方向前进」。
    // 主要数据成员：m_moveSpeed（米/秒）、m_turnSpeed（度/秒）、m_forwardSpeed / m_sideSpeed（给动画的分量）。
    // 主要外部方法：ForwardSpeed / SideSpeed / MoveSpeed / CurrentSpeed（只读属性）。
    // 谁在用它：挂在角色物体上；输入取自 InputManager.Instance.Current，键位在 InputMapping 里可改。
    public sealed class PlayerMove : MonoBehaviour
    {
        // 每秒走多少米。场景里 1 单位 = 1 米，5 就是每秒 5 米
        [SerializeField] private float m_moveSpeed = 5f;

        // 转身速度，度/秒。720 约等于 0.125 秒转 90 度
        [SerializeField] private float m_turnSpeed = 720f;

        // 前后分量，米/秒：W 为正、S 为负
        private float m_forwardSpeed;

        // 左右分量，米/秒：转身后基本为 0（留着给以后侧移用）
        private float m_sideSpeed;

        // 合速度，米/秒（≥ 0），给 HUD 之类用
        private float m_currentSpeed;

        // 功能：读当前的前后速度分量（米/秒，W 正、S 负）。
        // 入参：无
        // 返回：前后速度，米/秒（W 正、S 负）
        // 上游：PlayerAnimation
        // 下游：无
        public float ForwardSpeed
        {
            get { return m_forwardSpeed; }
        }

        // 功能：读当前的左右速度分量（米/秒，D 正、A 负）。
        // 入参：无
        // 返回：左右速度，米/秒（转身时会有短暂非零）
        // 上游：PlayerAnimation
        // 下游：无
        public float SideSpeed
        {
            get { return m_sideSpeed; }
        }

        // 功能：读配置的移动速度，给动画做归一化的分母。
        // 入参：无
        // 返回：配置的移动速度，米/秒（给动画做归一化的分母）
        // 上游：PlayerAnimation
        // 下游：无
        public float MoveSpeed
        {
            get { return m_moveSpeed; }
        }

        // 功能：读本帧合速度（米/秒），给 HUD 与调试用。
        // 入参：无
        // 返回：合速度，米/秒（≥ 0）
        // 上游：HUD / 调试
        // 下游：无
        public float CurrentSpeed
        {
            get { return m_currentSpeed; }
        }

        // 功能：每帧把输入压成四向之一，转身朝该方向并位移，同时算出前后 / 左右分量。
        // 入参：无（引擎每帧调用）
        // 返回：无
        // 步骤：
        //   1) 三个速度先清 0；提前 return 的分支不会残留上一帧的值
        //   2) 取 InputManager；把量化轴还原成 -1..1（x 左右、z 前后）
        //   3) 取主导轴：|z| >= |x| 用前后，否则用左右 ⇒ 只有四种方向，不斜走
        //   4) 按四种情况决定「朝向」与「位移方向」：
        //        W（z>0）  ：朝向 = 世界前方，沿该方向前进
        //        A（x<0）  ：朝向 = 世界左方，转身后沿该方向前进
        //        D（x>0）  ：朝向 = 世界右方，转身后沿该方向前进
        //        S（z<0）  ：朝向 = 世界后方，转身后沿该方向前进
        //   5) 转身用 RotateTowards 限速（0.125 秒转 90 度），位移用「目标方向」而不是当前朝向，避免转弯时走弧线
        //   6) 位移后按 forward / right 点乘，拆出前后 / 左右分量
        // 上游：Unity 引擎每帧调用
        // 下游：InputManager.Current、Transform.rotation、Transform.position
        // 注意：四向一律会转身（S 也转身，2026-10-31 由负责人改；R012 时曾是「S 不转身倒退」）
        private void Update()
        {
            m_forwardSpeed = 0f;
            m_sideSpeed = 0f;
            m_currentSpeed = 0f;

            InputManager input = InputManager.Instance;

            if (input == null || !input.IsEnabled)
            {
                return;
            }

            InputCommand command = input.Current;

            float x = (float)command.MoveX / InputCommand.MoveScale;
            float z = (float)command.MoveY / InputCommand.MoveScale;

            if (Mathf.Abs(x) < 0.0001f && Mathf.Abs(z) < 0.0001f)
            {
                return;
            }

            bool forwardWins = Mathf.Abs(z) >= Mathf.Abs(x);

            // 目标是世界坐标的四个基本方向之一（S 就是 (0,0,-1)，与 A/D 同样对待）
            Vector3 targetDirection = forwardWins
                ? new Vector3(0f, 0f, Mathf.Sign(z))
                : new Vector3(Mathf.Sign(x), 0f, 0f);

            // 四向统一：先转身朝目标方向（限速），位移仍用目标方向，避免边走边转出弧线
            Quaternion targetRotation = Quaternion.LookRotation(targetDirection, Vector3.up);
            transform.rotation = Quaternion.RotateTowards(
                transform.rotation, targetRotation, m_turnSpeed * Time.deltaTime);

            Vector3 moveDirection = targetDirection;

            Vector3 before = transform.position;
            transform.position += moveDirection * (m_moveSpeed * Time.deltaTime);

            float dt = Time.deltaTime;
            if (dt <= 0f)
            {
                return;
            }

            Vector3 moved = transform.position - before;

            // 实测位移拆成前后 / 左右：以后加碰撞，被挡住时这两个值会自然变小
            m_forwardSpeed = Vector3.Dot(moved, transform.forward) / dt;
            m_sideSpeed = Vector3.Dot(moved, transform.right) / dt;
            m_currentSpeed = moved.magnitude / dt;
        }

        // 功能：被禁用时把三个速度清零，避免下游继续读到「停之前那一帧」的旧速度。
        // 入参：无
        // 返回：无
        // 步骤：直接归零（这三个字段只在 Update 里写，禁用后不会再被刷新）
        // 上游：Unity 引擎（组件被禁用时调用）、PlayerBrain 的状态闸门
        // 下游：PlayerAnimation 读这三个值
        // 注意：不清零的话，状态机禁用本组件后动画会一直保持「在走」——因为 PlayerAnimation 读到的是旧值
        private void OnDisable()
        {
            m_forwardSpeed = 0f;
            m_sideSpeed = 0f;
            m_currentSpeed = 0f;
        }
    }
}
```

## 七、风险与幻觉自查

- 幻觉自查：用到 `NBC.Framework.Fsm` 的 `StateMachine<S>` / `StateBase<S>` / `StateTick` / `StateChangeRecord`（全部读源码确认存在）；没有引入不存在的 API。
