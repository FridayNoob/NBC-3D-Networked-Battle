- 目标：把玩家模型从 Unity-chan 换成 `CombatGirlsCharacterPack` 的 `SwordGirl_FullBody`，动画用它自带的 `Sword_Controller`。

## 四、B2 的配置契约（写进 03，由负责人在 Animator 窗口执行）

1. **参数名必须是 `Speed`、类型必须是 Float**：`PlayerAnimation` 启动时会校验，缺了会点名报错并停用自己。
2. **状态名建议 `Idle` / `Walk`**（代码不依赖状态名，只依赖参数，但便于以后维护）。
3. **转移条件**：`Idle → Walk` 用 `Speed > 0.1`；`Walk → Idle` 用 `Speed < 0.1`；两个转移都**取消 `Has Exit Time`**（否则会「走完一段才切」）。
4. **过渡时长 0.15 秒**（和 R002 定的手感一致）。

## 五、已知坑与版本兼容

1. **Trigger 是「一次性」的**：`SetTrigger` 后 Animator 在下一帧消费；连续每帧发等于反复重入 ⇒ 必须去重。
2. **回 Idle 可能靠 exit time**：包里 `WALK` 状态如果 `Has Exit Time` 打开，会「走完一段才回」；我们发 `IDLE` 触发器是想立刻回，**实际效果要 Play 才知道**（06 会验）。
3. **模型缩放/原点**：Unity-chan 与 CombatGirls 的模型原点可能不同（一个脚底 y=0、一个可能腰在原点），换模型后要按脚底贴地重摆。
4. **朝向**：若模型默认面朝 -Z，会「倒着走」，要在 prefab/场景里转 180°（不能改代码，因为代码约定 +Z 为前）。
5. **模型不在仓库**：别人 clone 后没有这个模型，`Battle.unity` 里那个物体只会是「Missing Prefab/模型」。**这是真实代价** —— 文档要写明怎么补。

## 六、结论与要改的东西

结论：**代码零改动** —— 负责人新建（或改造）一个含 Float `Speed` 的 Controller；`PlayerAnimation` 已经是喂 `Speed` 的。本需求只需「配置契约 + 验收」。
