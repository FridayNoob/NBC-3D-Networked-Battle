# 03 方案设计

需求：R014-玩家模型换成 CombatGirls（Float Speed 驱动）
所属阶段：M4
作者：AI 起草　状态：已确认（2026-10-31）

## 一、整体架构

**代码零改动**。链路不变：`PlayerMove`（算前后/左右分量）→ `PlayerAnimation`（喂 Float `Speed`）→ `Animator`（`Sword_Controller` 决定播 Idle 还是 Walk）。

本需求做的只有两件事：**换模型（场景里）** + **给控制器加 Float 参数与两条转移（Animator 里）**。

## 二、模块划分

| 模块 | 本次改动 | 不负责什么 |
| --- | --- | --- |
| `PlayerMove` | **零改动**（四向逻辑与模型无关） | — |
| `PlayerAnimation` | **零改动**（本来就喂 Float `Speed`，且启动会校验） | 不判断状态、不做过渡 |
| `FollowCamera` | **零改动** | — |
| `Sword_Controller.controller`（负责人改） | 加 **Float `Speed`**；`IDLE ↔ WALK` 两条转移用 `Speed` 条件、取消 `Has Exit Time`、0.15 秒过渡 | 不清理现有 39 个演示参数 |
| `Battle.unity`（负责人改） | 用 SwordGirl 替换 unitychan；摆位/朝向/缩放 | — |

## 三、配置契约（★ 必须逐字对齐）

```
参数
    名字：Speed
    类型：Float        ← 必须是 Float，代码启动时会校验；缺了会 LogError 并停用 PlayerAnimation

状态（沿用控制器里已有的两个）
    IDLE  ：片段 S_Idle
    WALK  ：片段 S_Walk   ← 包里已有 S_Walk.fbx

转移
    IDLE → WALK ：条件 Speed > 0.1   ｜ Has Exit Time 取消 ｜ Transition Duration 0.15
    WALK → IDLE ：条件 Speed < 0.1   ｜ Has Exit Time 取消 ｜ Transition Duration 0.15

默认状态
    进入 Play 时应停在 IDLE（不是 SP IDLE 之类的演示状态）
```

⚠️ 现有控制器里还有两条**触发器**转移（条件 `IDLE` / `WALK`）。我们不发触发器，所以它们不会触发，**留着无妨**；但如果你发现 Play 一开始播的是别的状态，就是「默认状态」没设对。

## 四、数据结构

`PlayerAnimation` 喂的值：`Speed = ForwardSpeed / MoveSpeed`（−1..1）。
因此控制器里的阈值 `0.1` 对应 **0.5 米/秒**（`m_moveSpeed = 5`），与 R002 的约定一致。

## 五、时序与流程

1. Play → `PlayerAnimation.Awake` 校验 Float `Speed` 存在。
2. 静止：`PlayerMove` 三个速度都是 0 → `Speed = 0` → 控制器停在 IDLE。
3. 按 W：`ForwardSpeed ≈ 5` → `Speed ≈ 1` → `> 0.1` → 0.15 秒过渡到 WALK。
4. 松开：`Speed = 0` → `< 0.1` → 0.15 秒回 IDLE。
5. 按 S（R013 后）：角色转身朝后，`ForwardSpeed` 仍为正 → WALK（不是倒退走）。

## 六、技术选型与理由

| 选择 | 选定 | 理由 | 被否的方案 |
| --- | --- | --- | --- |
| 驱动方式 | **Float `Speed`** | `PlayerAnimation` 现成、有平滑参数、能表达连续速度 | 触发器（要改代码，且回 Idle 靠 exit time） |
| 控制器 | **改造 `Sword_Controller`** | 负责人选定，保留自带动画与以后可能用到的演示动作 | 新建 Controller（更干净但要多配一遍） |
| 状态数 | **Idle + Walk** | 与 R002 范围一致；Run 以后加 | 三态（多一个阈值） |

## 七、风险与对策

- **参数名/类型写错** ⇒ `PlayerAnimation` 启动报错并停用（Console 有 `[PlayerAnimation]` 字样）。对策：先看 Console 再查 Animator。
- **`Has Exit Time` 没取消** ⇒ 松手后「走完一段才回 Idle」。对策：两条转移都要取消勾选。
- **模型缩放/原点不同** ⇒ 角色悬空或陷地。对策：先设 `Position.y = 0`，再按脚底微调。
- **模型朝向不是 +Z** ⇒ 会「倒着滑」。对策：在场景里把模型子物体绕 Y 转 180°（**不要**改代码，代码约定 +Z 为前）。
- **模型不进仓库** ⇒ 别人 clone 后该物体缺模型。对策：`第三方素材清单.md` 已写明补法。
- **控制器有 39 个演示参数** ⇒ 误触会播演示动作。对策：不要发送那些 Trigger；以后要清理另开需求。
