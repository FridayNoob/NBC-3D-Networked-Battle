# 04 代码实现

需求：R014-玩家模型换成 CombatGirls（Float Speed 驱动）
所属阶段：M4
作者：AI　状态：已确认（2026-10-31）

## 一、子任务与约束

- **本步不涉及代码改动**（原因见第三节）。`PlayerMove` / `PlayerAnimation` / `FollowCamera` 一行不动。
- 本步的实际产出是「**在 Unity 里怎么配**」，由负责人执行；AI 无法操作编辑器（规则 13）。

## 二、操作清单（负责人执行，按顺序）

### 阶段 1：换模型

1. 在 `Battle.unity` 里把 `unitychan` 物体**禁用或删掉**（先禁用更稳，可回退）。
2. 从 Project 窗口把 `Assets/Art/Model/CombatGirlsCharacterPack/Sword_Girl/Models/SwordGirl_FullBody.fbx` **拖进 Hierarchy**。
3. 摆位：`Position = (0, 0, 0)`，然后看脚是否贴地（陷地就 +y，悬空就 -y）。
4. **朝向检查**：按 W 时若角色「倒着滑」，在 Inspector 里把模型的 **Rotation.y 改成 180**（或把子物体转 180°），**不要改代码**。
5. 确认它身上有 `Animator`，且 `Controller` = **`Sword_Controller`**。
6. 模型若自带相机/脚本（包里的示例组件），**删掉**，避免第二套输入或第二台相机。

### 阶段 2：配状态机（Animator 窗口）

7. 打开 `Sword_Controller`（双击 Project 里的它）→ `Parameters` 面板 → `+` → **Float** → 命名 **`Speed`**。
8. 看 **`IDLE`** 与 **`WALK`** 两个状态：`Motion` 应分别是 `S_Idle` / `S_Walk`（包里已有这些片段）。
9. 选中 `IDLE` → `Make Transition` → 点 `WALK`：
   - `Conditions`：`Speed` `Greater` `0.1`
   - **取消勾选 `Has Exit Time`**
   - `Transition Duration` = `0.15`
10. 选中 `WALK` → `Make Transition` → 点 `IDLE`：
    - `Conditions`：`Speed` `Less` `0.1`
    - **取消勾选 `Has Exit Time`**
    - `Transition Duration` = `0.15`
11. 确认**默认状态是 `IDLE`**（选中 IDLE 右键 `Set as Layer Default State`）。

### 阶段 3：挂脚本

12. 给模型物体 `Add Component` → **`PlayerMove`**。
13. 再 `Add Component` → **`PlayerAnimation`**（`m_animator` **留空**，它会自动在子物体里找）。

## 三、为什么本步没有代码

`PlayerAnimation` 本来就是「读 `PlayerMove` 的分量 → 除以移动速度 → 写 `Animator` 的 Float `Speed`」，与模型无关；
新模型也是 Humanoid、也能被同一条链路驱动。**换个模型不需要改逻辑，只需要换资源与参数**。
这也是 R002 当初把它做成「只喂一个数」的好处：现在换模型，代码零改动。

## 四、验证钩子（配错了会在哪里说话）

| 配错的地方 | 会看到什么 |
| --- | --- |
| 忘了加 Float `Speed` | Console：`[PlayerAnimation] Animator Controller 里没有 Float 参数 Speed`，动画不动 |
| 参数加成了 Bool/Trigger | 同上（类型不对也算没有） |
| 两条转移还勾着 `Has Exit Time` | 松手后「走完一段才回 Idle」 |
| 默认状态不是 IDLE | 一进 Play 播的是演示动作（如 `SP IDLE`） |
| 模型朝向反了 | 走动时像「倒着滑」 |
| 模型缩放不对 | 悬空 / 陷地 / 比镜头大 |
| 忘了挂 `PlayerMove` | 角色完全不动，且 Console 不会报错（`PlayerAnimation` 会报「没有 PlayerMove」） |
