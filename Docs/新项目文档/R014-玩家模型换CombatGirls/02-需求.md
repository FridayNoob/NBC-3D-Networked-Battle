# 02 需求

需求：R014-玩家模型换成 CombatGirls（Float Speed 驱动）
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-10-31）

## 一、业务目标（一句话）

**玩家从 Unity-chan 换成 CombatGirls 的 SwordGirl**，动画用它自带的 `Sword_Controller`，由 `Float Speed` 驱动 Idle/Walk。

## 二、用户与使用场景

- 用户：开发期负责人；最终玩家。
- 场景：进游戏看到的是 SwordGirl，站着播 Idle、走动播 Walk；操作手感与 R013 完全一致（四向、转身、镜头不动）。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 玩家模型换成 SwordGirl | P0 | 替换场景里 `unitychan` 那个物体 |
| 播 Idle / Walk | P0 | 由 `Sword_Controller` 的 Float `Speed` 驱动 |
| 移动 / 转身 / 镜头行为不变 | P0 | 完全复用 `PlayerMove`（R013 的四向逻辑） |
| Run | P2 | 本版不做（只要两态） |
| 攻击 / 受击 / 死亡动画 | P2 | 以后接战斗需求再做 |

## 四、边界（**本版明确不做**）

- **不改任何代码**（`PlayerMove` / `PlayerAnimation` / `FollowCamera` 全部不动）。
- 不做 Run、不做攻击、不做表情/待机变体。
- 不把模型提交进仓库（授权不明 + 体积，已 `.gitignore`）。
- **不清理** `Sword_Controller` 里那 39 个演示参数（改造可以，但不要求清空）。

## 五、优先级

**P0**。依赖：R012/R013（移动与朝向）、R002（`PlayerAnimation` 的 Float 契约）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 进 Play 时，场景里看到的玩家应是 **SwordGirl**（不再是 Unity-chan 的少女模型）
- [ ] 当 不按键时，应播 **Idle**
- [ ] 当 按住 W/A/S/D 时，应播 **Walk**，且**0.15 秒内**切过去
- [ ] 当 松开按键时，应**0.15 秒内**回到 Idle（不能「走完一段才回」）
- [ ] 当 移动时，角色应**面朝移动方向**（不能倒退着滑）
- [ ] 当 Console 里出现 `[PlayerAnimation]` 报错时，视为**未通过**（说明参数没配对）
