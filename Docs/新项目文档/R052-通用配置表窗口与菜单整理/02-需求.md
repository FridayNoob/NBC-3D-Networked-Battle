# 02 需求

需求编号：R052
所属阶段：M4
作者：AI（负责人评审）
状态：开发中

## 业务目标（一句话）

开发者打开一个窗口，就能选任意一张配置表、改单元格、校验、导出 CSV 并重新生成；编辑器菜单只剩 `Tools/NBC` 一棵树。

## 用户与场景

- 场景 1：策划想改副本表的最大人数 → 打开 `Tools/NBC/配置表/配置表（SO ↔ CSV）` → 下拉选 `Dungeon` → 改单元格 → 校验 → 导出 → 服务端重启生效。
- 场景 2：想改怪物血量 → 同一个窗口下拉切到 `Monster`，不用再找另一个窗口。
- 场景 3：找行为树编辑器 → 以前在 `AI工具`，现在在 `Tools/NBC/行为树/`。

## 功能列表

| 优先级 | 功能 |
| --- | --- |
| P0 | 表下拉（10 张表，来自注册表） |
| P0 | 单元格编辑（文本，按字段类型解析；解析失败保留原文并提示） |
| P0 | 工具栏：刷新 / 校验 / 导出到 CSV / 从 CSV 导入 |
| P0 | 红字提示「SO 与 CSV 不一致」，并说明两个按钮各自的后果 |
| P0 | 增加一行 / 删除一行 |
| P0 | 菜单：`AI工具/BehaviorTree Editor` → `Tools/NBC/行为树/行为树编辑器` |
| P0 | 菜单：`Tools/NBC/诊断 M0 探针依赖` → `Tools/NBC/调试/诊断 M0 探针依赖` |
| P1 | 「列说明」折叠区（字段名 / 类型 / 规则） |
| P1 | 资产被外部重新导入时自动刷新 |
| P2 | 按列宽自适应、按行搜索 |

## 边界（不做什么）

1. 不做单元格类型的专用控件（枚举下拉、引用选择器）——本轮先用文本。
2. 不做多表同时编辑。
3. 不改 CSV 表头格式，不加新列。
4. 不动运行时程序集与服务器。
5. 不迁移 R050 的 `DungeonCsvBridge`（保留给它的测试）。

## 优先级

先 P0 全部；P1 顺手做（代码量小）；P2 不做。

## 验收标准（当…时，应…）

1. 当打开窗口时，应默认显示第一张表（Achievement）并能切换 10 张表。
2. 当改某个单元格时，应立刻写入 SO，并出现「SO 与 CSV 不一致」的红字。
3. 当点「校验」时，应在底部显示通过或具体错误。
4. 当点「导出到 CSV」时，应写回 CSV、重跑 ConfigKit、状态栏显示结果。
5. 当点「从 CSV 导入」时，应先弹确认（若有未导出改动），成功后表格内容刷新。
6. 当增加/删除一行时，行数应变化，且导出后 CSV 行数随之变化。
7. 当打开 CSV 时中文表头应是「编号 / 名称 / …」而不是英文列名。
8. 当点菜单 `Tools/NBC/行为树/行为树编辑器` 时应打开行为树窗口。
9. 当查看菜单栏时，应没有顶层 `AI工具`，`诊断 M0 探针依赖` 在 `Tools/NBC/调试/` 下。
10. 当 Excel 打开着 CSV 时，窗口不应崩，提示应说人话。
