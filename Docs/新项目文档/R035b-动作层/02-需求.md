# 02 需求

需求：R035b-动作层（连击 / 技能 / 冲刺 / 格挡 / 姿势）
所属阶段：M4
作者：AI　状态：开发中（2026-11-13）

## 一、业务目标（一句话）

让玩家在 World 里能打出三段普攻连击、三个技能、一次前冲、按住格挡和七个姿势，动画由现有 `ActionId` 参数驱动，动作期间不能移动。

## 二、用户与场景

- 玩家在 World 里走到村口，看见木桩（本期没有可攻击目标），想试试「砍、连、放技能」是什么手感。
- 演示者需要在一分钟内展示「战斗动作齐全」，不需要真的打死怪。
- 验收者是负责人：按固定键位逐条确认动画、帧数与回落。

## 三、功能列表

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0 | 三段普攻 | 左键或 `J`：Attack1（60 帧）→ 窗口内再按 → Attack2（60）→ Attack3（93）→ 回移动 |
| P0 | 三个技能 | `Q` / `E` / `R`：Skill1（240 帧）/ Skill2（144）/ Skill3（264），全程禁移动 |
| P0 | 前冲 | `V`：Dash（60 帧）+ 0.18 秒 8 米/秒前冲位移 |
| P0 | 格挡 | 按住右键：`ActionId=8`，定格侧身姿态；松开回移动；格挡中不能攻击/技能 |
| P0 | 姿势 | `F`：PoseIndex 0→6 轮换，90 帧后回移动 |
| P1 | 动作日志 | 每次进入动作在 Console 打一行（动作名 + 帧数），方便验收 |
| P2 | 格挡中受击 | 本期只保证受击能打断攻击/技能（受击细节在 R035c） |

## 四、边界（不做什么）

- **不做伤害**：World 没有服务端技能系统，技能只播动画；伤害与结算留给独立的服务端技能需求。
- **不做左右受击区分**：`HitLeft`/`HitRight` 的判定与硬直放 R035c。
- **不做跳跃/下落**：`Space` 留给 R035d。
- **不做根运动**：位移由脚本给，clip 不动模型根节点。
- **不改美术包控制器**：只改副本 `Client/Assets/_Project/Animator/Player_Sword_Controller.controller`。

## 五、优先级

先连击（最常用、验收最直观）→ 格挡（有状态常驻，最容易和「回落」打架）→ 技能（长动画）→ 冲刺 → 姿势（纯展示）。

## 六、验收标准

1. 当玩家连按左键三次（间隔 < 0.3 秒）时，应依次出现 `S_Attack_1` → `S_Attack_2` → `S_Attack_3`，每段之间不回到 `S_Locomotion`。
2. 当第一段播完前 4 帧内不再按时，应在第 60 帧回到 `S_Locomotion`（不空挥第二段）。
3. 当攻击起手 18 帧内连按时，应**不**排队第二段（窗口外忽略）。
4. 当按 `Q` / `E` / `R` 时，应分别进入 `S_Sp_Skill_1/2/3`，240 / 144 / 264 帧内按住 `W` 角色原地不动。
5. 当按 `V` 时，应进入 `S_QuickShift_F`，并在 0.18 秒内向前移动约 1.4 米（8 米/秒）。
6. 当按住右键时，应进入 `S_Block` 并停在闪避动作 1/4 处的侧身姿态；松开右键应在下一帧回 `S_Locomotion`。
7. 当格挡中按左键或 `Q` 时，应**没有**攻击/技能反应（`ActionId` 保持 8）。
8. 当按 `F` 时，应依次出现七个 `CBG_*` 姿态，每次 90 帧后回到移动层；第 7 次后再按回到第 1 个。
9. 当动作在蹲姿下结束时，应回到 `S_Crouch` 而不是 `S_Locomotion`。
10. 当检查控制器副本时，应看到：攻击三态 `speed=1.4`、`S_Block` `speed=0` 且进入过渡 `offset=0.25`、Active 过渡 20 条、参数仍是 49 个（没有新增 Trigger）。
11. 当连续动作 30 秒后，`PlayerAnimatorPublisher` 不应每帧重复写参数（Animator 面板数值稳定）。
