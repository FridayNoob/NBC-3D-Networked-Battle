## 2. 功能概述

玩家按左键或 J：第一段普攻；在连击窗口内再按，排队第二段，最多三段。按 Q/E/R 播三个技能，按 V 前冲 0.18 秒，按住右键定格格挡，按 F 在七个 CBG 表情动作之间轮换。所有动作期间角色不能走，动作播完自动回到当时的移动状态（站着回 Idle、蹲着回 CrouchIdle、按住方向回 Run）。

## 3. 接口与入参出参

| 接口 | 入参 | 出参 | 约定 |
| --- | --- | --- | --- |
| `PlayerStateMachine.NotifyAttack()` | 无 | bool | true = 起手或已排队；false = 已死 / 不在攻击链 / 不在窗口 |
| `PlayerStateMachine.NotifySkill(int)` | index 1~3 | bool | 越界、已死、动作中、格挡中返回 false |
| `PlayerStateMachine.NotifyDash()` | 无 | bool | 同上；位移由调用方再调 `IPlayerDash.StartDash` |
| `PlayerStateMachine.NotifyPose()` | 无 | bool | 每成功一次 `PoseIndex = (PoseIndex + 1) % 7` |
| `PlayerStateMachine.SetBlocking(bool)` | true = 按住 | 无 | 不占 `ActionBusy`；只写 `ActionId=8`，松开清 0 |
| `PlayerStateMachine.PoseIndex` | 无 | int 0~6 | 给调试与日志用 |
| `PlayerStateMachine.Blocking` | 无 | bool | 当前是否按住格挡 |
| `IPlayerDash.StartDash(float,float)` | 速度米/秒、时长秒 | 无 | <=0 忽略；重复调用覆盖上一段 |

`PlayerTimings` 现在 12 个字段，顺序固定：`Attack1Frames, Attack2Frames, Attack3Frames, Skill1Frames, Skill2Frames, Skill3Frames, DashFrames, HitFrames, StunFrames, PoseFrames, ComboWindowStart, ComboEndBuffer`；默认值 60/60/93/240/144/264/60/88/120/90/18/4（60fps 下的帧数）。

## 4. 逐段讲解

1) 连击为什么「只排队、不切段」：攻击第 1 段播到一半时按第二下，如果立刻切到第 2 段，动作会被硬切、看起来像卡顿。所以窗口内只把 `m_comboQueued` 置 true，等 `AdvanceAction` 数到 `ActionFrames` 才用 `TryStartNextCombo` 接下一段。窗口起点 18 帧（0.3 秒）避免「按下就立刻算第二段」，末端留 4 帧避免最后几帧才按、动作已经结束。

2) 第 3 段为什么不再接：`TryStartNextCombo` 只认 `Attack1→Attack2`、`Attack2→Attack3`，第 3 段返回 false，动作正常结束回移动层。三段的设计是「打完收招」，不是无限连。

3) 格挡为什么不占 `ActionBusy`：格挡是「按住就保持」的持续姿态，不是一段有始有终的动作。占 `ActionBusy` 会让每帧都要重新进入、动画反复重播。现在只写 `ActionId=8`，由控制器里的 `S_Block`（`speed=0`）定格；同时 `canMove = !m_blocking && ...` 让它不能走。

4) 冲刺为什么位移放在 `PlayerMove`：状态机是纯逻辑，不碰 `Transform`。`PlayerBrain` 在状态机接受冲刺后调 `IPlayerDash.StartDash(8, 0.18)`，`PlayerMove.Update` 里 `TryAdvanceDash` 先于移动闸门执行，所以「动作期间禁移动」不会把冲刺一起禁掉。

5) 技能与姿势为什么复用 `BeginAction`：它们和前一段动作一样都是「定时播完就回移动层」，共用排队/切换/回落的代码路径，避免三套重复逻辑。

6) 旧测试为什么只改构造参数：`PlayerStateMachineTests` 里六个帧数从 36/18/48/18/45/90 换成新的 12 项，攻击用例从「推 36 帧」改成「推 60 帧」，其余断言与语义不变。

```csharp
// 这个文件里有：
//   PlayerInput（只读结构）：一帧输入快照
//   PlayerTimings（结构）：各动作持续帧数
//   PlayerSpeeds（结构）：五档移动速度
//   PlayerStateContext（类）：状态机与外部共享的可变状态

namespace NBC.Game.Player
{
    // 主要功能：把「这一帧玩家按了什么」定格下来，状态机只读它、不碰 Input。
    // 主要数据成员：MoveX/MoveY 是 -1~1 的方向，WalkHeld/SprintHeld 是按住，CrouchToggle 是这一帧刚按下。
    // 主要外部方法：构造函数。
    // 谁在用它：PlayerBrain 每帧构造一次；PlayerStateMachine.Tick 读取。
    public readonly struct PlayerInput
    {
        // 左右方向，-1 左 ~ 1 右
        public readonly float MoveX;

        // 前后方向，-1 后 ~ 1 前
        public readonly float MoveY;

        // 是否按住「慢走」（Alt）
        public readonly bool WalkHeld;

        // 是否按住「冲刺」（Shift）
        public readonly bool SprintHeld;

        // 是否这一帧刚按下「蹲下」切换（Ctrl）
        public readonly bool CrouchToggle;

        // 功能：打包一帧输入。
        // 入参：五个值，含义与同名字段一致。
        // 返回：结构本身。
        // 步骤：直接赋值；方向由调用方保证在 -1~1。
        // 上游/下游：PlayerBrain.ReadInput 调用；PlayerStateMachine.ChooseLocomotion 读取。
        public PlayerInput(float moveX, float moveY, bool walkHeld, bool sprintHeld, bool crouchToggle)
        {
            MoveX = moveX;
            MoveY = moveY;
            WalkHeld = walkHeld;
            SprintHeld = sprintHeld;
            CrouchToggle = crouchToggle;
        }

        // 功能：判断这一帧有没有方向输入。
        // 入参：无。
        // 返回：true 表示至少一个轴不为 0（阈值 0.0001，避免摇杆漂移）。
        // 步骤：两轴取绝对值比阈值。
        // 上游/下游：PlayerStateMachine.ChooseLocomotion 调用。
        public bool HasDirection()
        {
            return System.Math.Abs(MoveX) > 0.0001f || System.Math.Abs(MoveY) > 0.0001f;
        }
    }

    // 主要功能：集中放「某个动作要播多少帧」，以及连击窗口的两个位置，方便 Inspector 调手感。
    // 主要数据成员：三个攻击段、三个技能、冲刺、受击、硬直、姿势的帧数（60fps 口径），加连击窗口起止。
    // 主要外部方法：构造函数与 Default 默认值。
    // 谁在用它：PlayerStateMachine 在 BeginAction 时按动作取帧数，NotifyAttack 判连击窗口。
    public readonly struct PlayerTimings
    {
        // 攻击第 1 段的帧数（60 帧 = 1 秒，对应 clip 84 帧 ÷ 播放速度 1.4）
        public readonly int AttackFrames;

        // 攻击第 2 段的帧数
        public readonly int Attack2Frames;

        // 攻击第 3 段的帧数（93 帧，对应 clip 130 帧 ÷ 1.4）
        public readonly int Attack3Frames;

        // 技能 1 的帧数（240 帧 = 4 秒）
        public readonly int Skill1Frames;

        // 技能 2 的帧数（144 帧 = 2.4 秒）
        public readonly int Skill2Frames;

        // 技能 3 的帧数（264 帧 = 4.4 秒）
        public readonly int Skill3Frames;

        // 冲刺的帧数（60 帧 = 1 秒）
        public readonly int DashFrames;

        // 受击的帧数（88 帧，对应 clip 1.467 秒）
        public readonly int HitFrames;

        // 硬直的帧数（120 帧 = 2 秒）
        public readonly int StunFrames;

        // 姿势的帧数（90 帧 = 1.5 秒）
        public readonly int PoseFrames;

        // 连击窗口从第几帧开始（之前按键不排队，避免起手就攒三段）
        public readonly int ComboWindowStart;

        // 连击窗口在结束前留几帧缓冲（之后按键不排队）
        public readonly int ComboEndBuffer;

        // 功能：打包全部动作时长与连击窗口。
        // 入参：十二个帧数，单位是 60fps 的帧；小于等于 0 表示「不自动结束」。
        // 返回：结构本身。
        // 步骤：直接赋值。
        // 上游/下游：PlayerBrain.Awake 用 Inspector 值构造；PlayerStateMachine.Notify* 读取。
        public PlayerTimings(
            int attackFrames,
            int attack2Frames,
            int attack3Frames,
            int skill1Frames,
            int skill2Frames,
            int skill3Frames,
            int dashFrames,
            int hitFrames,
            int stunFrames,
            int poseFrames,
            int comboWindowStart,
            int comboEndBuffer)
        {
            AttackFrames = attackFrames;
            Attack2Frames = attack2Frames;
            Attack3Frames = attack3Frames;
            Skill1Frames = skill1Frames;
            Skill2Frames = skill2Frames;
            Skill3Frames = skill3Frames;
            DashFrames = dashFrames;
            HitFrames = hitFrames;
            StunFrames = stunFrames;
            PoseFrames = poseFrames;
            ComboWindowStart = comboWindowStart;
            ComboEndBuffer = comboEndBuffer;
        }

        // 功能：给出一套按 clip 实测算好的默认值。
        // 入参：无。
        // 返回：攻击 60/60/93、技能 240/144/264、冲刺 60、受击 88、硬直 120、姿势 90、窗口 18 帧、缓冲 4 帧。
        // 步骤：直接 new。
        // 上游/下游：PlayerBrain 的 Inspector 默认值参考；测试用 PlayerTimings.Default。
        public static PlayerTimings Default
        {
            get { return new PlayerTimings(60, 60, 93, 240, 144, 264, 60, 88, 120, 90, 18, 4); }
        }
    }

    // 主要功能：集中放五档移动速度，避免把 2/5/8 这类数字散落在判断里。
    // 主要数据成员：Walk/Run/Sprint/CrouchWalk/CrouchJog，单位都是米/秒。
    // 主要外部方法：无。
    // 谁在用它：PlayerStateMachine 按当前状态取速度，写回 IPlayerMotion。
    public readonly struct PlayerSpeeds
    {
        // 慢走速度，默认 2 米/秒
        public readonly float Walk;

        // 默认跑速，默认 5 米/秒
        public readonly float Run;

        // 冲刺速度，默认 8 米/秒
        public readonly float Sprint;

        // 蹲走速度，默认 1.5 米/秒
        public readonly float CrouchWalk;

        // 蹲跑速度，默认 3 米/秒
        public readonly float CrouchJog;

        // 功能：打包五档速度。
        // 入参：五个速度，单位米/秒，必须为正。
        // 返回：结构本身。
        // 步骤：直接赋值。
        // 上游/下游：PlayerBrain.Awake 用 Inspector 值构造；PlayerStateMachine.SpeedOf 读取。
        public PlayerSpeeds(float walk, float run, float sprint, float crouchWalk, float crouchJog)
        {
            Walk = walk;
            Run = run;
            Sprint = sprint;
            CrouchWalk = crouchWalk;
            CrouchJog = crouchJog;
        }
    }

    // 主要功能：装状态机每帧要读写的全部状态，兼作「动画参数」的唯一来源。
    // 主要数据成员：Crouch/Grounded/ActionBusy/Dead 等布尔，Speed/Direction/ActionId 等浮点，以及动作计时 ActionFrame/ActionFrames。
    // 主要外部方法：BuildParams 产出参数快照、ResetAction 清动作。
    // 谁在用它：PlayerStateMachine（读写）、PlayerBrain（构造并发布参数）、EditMode 测试（直接断言字段）。
    public sealed class PlayerStateContext
    {
        // 位移能力，由 PlayerMove 实现
        public readonly IPlayerMotion Motion;

        // 当前移动速度，米/秒（0~8，按档位取值；动作中与死亡时为 0）
        public float Speed;

        // 横向分量，-1~1（左负右正；动作中与死亡时为 0）
        public float Direction;

        // 是否蹲下（Ctrl 切换）
        public bool Crouch;

        // 是否踩在地面上（R035d 之前恒为 true）
        public bool Grounded = true;

        // 竖直速度，米/秒（R035d 之前恒为 0）
        public float VerticalSpeed;

        // 是否有动作在播
        public bool ActionBusy;

        // 当前动作编号，0~11
        public float ActionId = PlayerActionId.None;

        // 受击方向，-1 左 / 1 右
        public float StackSide = 1f;

        // 姿势编号，0~6
        public float PoseIndex;

        // 是否死亡
        public bool Dead;

        // 动作已播帧数，0 表示刚开始
        public int ActionFrame;

        // 动作总帧数，0 表示不自动结束
        public int ActionFrames;

        // 功能：绑定位移能力。
        // 入参：motion 是位移实现，不能为 null。
        // 返回：无。
        // 步骤：只保存引用，不改它的任何字段。
        // 上游/下游：PlayerBrain.Awake 构造；PlayerStateMachine 每帧调 Motion。
        public PlayerStateContext(IPlayerMotion motion)
        {
            Motion = motion;
        }

        // 功能：把当前字段打成一帧动画参数。
        // 入参：无。
        // 返回：PlayerAnimatorParams 值快照。
        // 步骤：按构造参数顺序逐个取字段，不做换算（换算在状态机里）。
        // 上游/下游：PlayerStateMachine.Tick 末尾调用；PlayerBrain 交给 IPlayerAnimatorSink.Apply。
        public PlayerAnimatorParams BuildParams()
        {
            return new PlayerAnimatorParams(
                Speed,
                Direction,
                Crouch,
                Grounded,
                VerticalSpeed,
                ActionBusy,
                ActionId,
                StackSide,
                PoseIndex,
                Dead);
        }

        // 功能：清掉当前动作，让状态机可以回到移动层。
        // 入参：无。
        // 返回：无。
        // 步骤：先关标记再清编号与计时，避免中途被读到「忙碌但没有编号」。
        // 上游/下游：PlayerStateMachine.EndAction / ApplyPendingAction 调用。
        public void ResetAction()
        {
            ActionBusy = false;
            ActionId = PlayerActionId.None;
            ActionFrame = 0;
            ActionFrames = 0;
        }
    }
}
```

### 5.2 `Client/Assets/_Project/Game/Player/State/PlayerStateMachine.cs`

```csharp
// 这个文件里有：
//   PlayerStateMachine（类）：玩家分层状态机 —— 纯逻辑，不读 Time / Input / Animator，测试可直接驱动

using System;
using NBC.Framework.Fsm;

namespace NBC.Game.Player
{
    // 主要功能：按「反应 > 动作 > 移动」的优先级决定当前该在哪个状态，并把结果翻译成移动闸门与动画参数。
    // 主要数据成员：m_context（共享状态）、m_timings（动作帧数）、m_speeds（五档速度）、m_fsm（三层状态机）。
    // 主要外部方法：Tick 推进一帧；NotifyAttack/NotifyHit/NotifyDead 接收外部事件；Parameters 读当前动画参数。
    // 谁在用它：PlayerBrain 每帧调 Tick 并发布 Parameters；EditMode 测试用假 IPlayerMotion 驱动它。
    // 注意：本类不引用 UnityEngine —— 取绝对值用 System.Math，状态名用枚举，保证能在 EditMode 无场景下跑。
    public sealed class PlayerStateMachine
    {
        // 共享状态（蹲/动作/死亡等），每帧读写
        private readonly PlayerStateContext m_context;

        // 各动作持续帧数，60fps 口径
        private readonly PlayerTimings m_timings;

        // 五档移动速度，米/秒
        private readonly PlayerSpeeds m_speeds;

        // 三层状态机：移动层 / 动作层 / 反应层
        private readonly HierarchicalStateMachine<EPlayerState> m_fsm;

        // 有没有「等着这一帧执行」的动作请求
        private bool m_hasPendingAction;

        // 待执行动作的状态
        private EPlayerState m_pendingState;

        // 待执行动作的编号（写进 ActionId）
        private float m_pendingActionId;

        // 待执行动作的总帧数
        private int m_pendingFrames;

        // 连击是否已排队：窗口内按过攻击键，等当前段播完再切下一段
        private bool m_comboQueued;

        // 是否正在按住格挡；格挡不占 ActionBusy，但会关掉移动闸门
        private bool m_blocking;

        // 当前姿势序号 0~6，按 F 轮换
        private int m_poseIndex;

        // 功能：注册三层状态机并进入移动层的 Idle。
        // 入参：context 共享状态（不能为 null，且 Motion 不能为 null）；timings 动作帧数；speeds 五档速度。
        // 返回：无。
        // 步骤：1) 校验参数 2) 依次注册三层（先上层后下层，第一层下层自动成为入口）3) 启动到移动层。
        // 上游/下游：PlayerBrain.Awake 构造；内部调用 RegisterLocomotion/Action/Reaction。
        public PlayerStateMachine(PlayerStateContext context, PlayerTimings timings, PlayerSpeeds speeds)
        {
            if (context == null)
            {
                throw new ArgumentNullException(nameof(context), "[PlayerStateMachine] 缺少共享状态。");
            }

            if (context.Motion == null)
            {
                throw new ArgumentNullException(nameof(context), "[PlayerStateMachine] 共享状态里没有 IPlayerMotion。");
            }

            m_context = context;
            m_timings = timings;
            m_speeds = speeds;
            m_fsm = new HierarchicalStateMachine<EPlayerState>();

            m_fsm.RegisterUpper(EPlayerState.Locomotion, new PlayerLayeredState(EPlayerState.Locomotion), EPlayerState.Idle);
            RegisterLocomotionStates();
            m_fsm.RegisterUpper(EPlayerState.Action, new PlayerLayeredState(EPlayerState.Action), EPlayerState.Attack1);
            RegisterActionStates();
            m_fsm.RegisterUpper(EPlayerState.Reaction, new PlayerLayeredState(EPlayerState.Reaction), EPlayerState.HitLeft);
            RegisterReactionStates();
            m_fsm.Start(EPlayerState.Locomotion);

            m_context.Motion.MovementEnabled = true;
        }

        // 当前上层（Locomotion / Action / Reaction）
        public EPlayerLayer Layer
        {
            get { return PlayerStateCatalog.LayerOf(m_fsm.UpperCurrent); }
        }

        // 当前下层状态（真正的「在干什么」）
        public EPlayerState State
        {
            get { return m_fsm.LowerCurrent; }
        }

        // 当前状态路径，形如 "Locomotion/Run"；给日志与调试面板看
        public string CurrentPath
        {
            get { return m_fsm.CurrentPath; }
        }

        // 是否已死亡（死亡后 Tick 只维持参数、不再切换状态）
        public bool IsDead
        {
            get { return m_context.Dead; }
        }

        // 这一帧要写给 Animator 的参数快照
        public PlayerAnimatorParams Parameters
        {
            get { return m_context.BuildParams(); }
        }

        // 当前姿势序号 0~6；按 F 依次轮换
        public int PoseIndex
        {
            get { return m_poseIndex; }
        }

        // 是否正按住格挡
        public bool Blocking
        {
            get { return m_blocking; }
        }

        // 状态真的发生切换后触发；参数是切换记录（含帧号与前后状态名）
        public event Action<StateChangeRecord> StateChanged
        {
            add { m_fsm.StateChanged += value; }
            remove { m_fsm.StateChanged -= value; }
        }

        // 功能：推进一帧 —— 先看有没有动作要播，再决定移动状态，最后同步移动闸门与速度。
        // 入参：frame 逻辑帧号（必须单调递增，60fps 口径）；input 这一帧的输入快照。
        // 返回：无。
        // 步骤：1) 死亡时只维持零速 2) 处理蹲切换 3) 推进/消费动作 4) 动作中不选移动态 5) 同步 MovementEnabled 与速度 6) 推状态机帧。
        // 上游/下游：PlayerBrain.Update 每个固定步长调用一次；内部调用 ChooseLocomotion/ApplyLocomotion。
        public void Tick(int frame, in PlayerInput input)
        {
            if (m_context.Dead)
            {
                m_context.Speed = 0f;
                m_context.Direction = 0f;
                m_context.ResetAction();
                m_context.Motion.MovementEnabled = false;
                m_context.Motion.SetMoveSpeed(0f);
                m_fsm.Tick(frame);
                return;
            }

            if (input.CrouchToggle && !m_context.ActionBusy)
            {
                m_context.Crouch = !m_context.Crouch;
            }

            AdvanceAction();

            if (m_hasPendingAction)
            {
                ApplyPendingAction();
            }

            if (!m_context.ActionBusy)
            {
                ApplyLocomotion(ChooseLocomotion(input));
            }

            bool canMove = !m_blocking && !PlayerStateCatalog.BlocksMovement(m_fsm.LowerCurrent);
            m_context.Speed = canMove ? SpeedOf(m_fsm.LowerCurrent) : 0f;
            m_context.Direction = canMove ? ClampDirection(input.MoveX) : 0f;
            m_context.Motion.SetMoveSpeed(m_context.Speed);
            m_context.Motion.MovementEnabled = canMove;

            m_fsm.Tick(frame);
        }

        // 功能：请求播攻击；空闲时起手第 1 段，连击窗口内则排队下一段。
        // 入参：无。
        // 返回：true 表示已起手或已排队；false 表示已死、动作不在攻击链上、或不在窗口内。
        // 步骤：1) 死亡拒绝 2) 空闲直接起手第 1 段 3) 动作层里只接第 1/2 段 4) 帧号不在窗口内拒绝 5) 只做排队，不切当前状态。
        // 上游/下游：PlayerBrain 攻击键调用；内部调用 BeginAction，下一段在 AdvanceAction 里接。
        public bool NotifyAttack()
        {
            if (m_context.Dead)
            {
                return false;
            }

            if (!m_context.ActionBusy)
            {
                return BeginAction(EPlayerState.Attack1, PlayerActionId.Attack1, m_timings.AttackFrames);
            }

            if (PlayerStateCatalog.LayerOf(m_fsm.LowerCurrent) != EPlayerLayer.Action)
            {
                return false;
            }

            if (m_context.ActionId != PlayerActionId.Attack1 && m_context.ActionId != PlayerActionId.Attack2)
            {
                return false;
            }

            if (m_context.ActionFrame < m_timings.ComboWindowStart)
            {
                return false;
            }

            if (m_context.ActionFrames > 0 && m_context.ActionFrame > m_context.ActionFrames - m_timings.ComboEndBuffer)
            {
                return false;
            }

            m_comboQueued = true;
            return true;
        }

        // 功能：请求播第 index 个技能（只播动画，不产生伤害）。
        // 入参：index 取 1~3，超出范围拒绝。
        // 返回：true 表示已排队；false 表示已死、有动作在播、或正在格挡。
        // 步骤：先做前置拒绝，再按序号取状态、ActionId 与帧数。
        // 上游/下游：PlayerBrain 的 Q/E/R 调用；内部调用 BeginAction。
        public bool NotifySkill(int index)
        {
            if (m_context.Dead || m_context.ActionBusy || m_blocking)
            {
                return false;
            }

            if (index < 1 || index > 3)
            {
                return false;
            }

            EPlayerState state = (EPlayerState)((int)EPlayerState.Skill1 + index - 1);
            int frames = index == 1 ? m_timings.Skill1Frames : (index == 2 ? m_timings.Skill2Frames : m_timings.Skill3Frames);
            return BeginAction(state, PlayerActionId.OfSkill(index), frames);
        }

        // 功能：请求前冲一段。
        // 入参：无。
        // 返回：true 表示已排队；false 表示已死、有动作在播、或正在格挡。
        // 步骤：前置拒绝后进 Dash，帧数取 DashFrames；位移由 PlayerBrain 通过 IPlayerDash 触发。
        // 上游/下游：PlayerBrain 的 V 键调用；内部调用 BeginAction。
        public bool NotifyDash()
        {
            if (m_context.Dead || m_context.ActionBusy || m_blocking)
            {
                return false;
            }

            return BeginAction(EPlayerState.Dash, PlayerActionId.Dash, m_timings.DashFrames);
        }

        // 功能：轮换到下一个姿势（七个 CBG 表情动作）。
        // 入参：无。
        // 返回：true 表示已排队；false 表示已死、有动作在播、或正在格挡。
        // 步骤：先把 PoseIndex 加一并对 7 取模，再进 Pose。
        // 上游/下游：PlayerBrain 的 F 键调用；内部调用 BeginAction。
        public bool NotifyPose()
        {
            if (m_context.Dead || m_context.ActionBusy || m_blocking)
            {
                return false;
            }

            m_poseIndex = (m_poseIndex + 1) % 7;
            return BeginAction(EPlayerState.Pose, PlayerActionId.Pose, m_timings.PoseFrames);
        }

        // 功能：按住/松开格挡。格挡是常驻动作，不占 ActionBusy。
        // 入参：blocking 为 true 表示按住右键。
        // 返回：无。
        // 步骤：按住时若有动作在播就忽略；否则写 ActionId=8 并关移动闸门。松开时清回 None。
        // 上游/下游：PlayerBrain 每帧调用；动画控制器按 ActionId==8 进 S_Block。
        public void SetBlocking(bool blocking)
        {
            if (m_context.Dead)
            {
                return;
            }

            if (blocking)
            {
                if (m_blocking || m_context.ActionBusy)
                {
                    return;
                }

                m_blocking = true;
                m_context.ActionId = PlayerActionId.Block;
                m_context.ActionFrame = 0;
                m_context.ActionFrames = 0;
                return;
            }

            if (!m_blocking)
            {
                return;
            }

            m_blocking = false;
            m_context.ActionId = PlayerActionId.None;
        }

        // 功能：请求播受击；受击优先级高于攻击，会把正在播的攻击打断。
        // 入参：fromLeft 为 true 表示从左侧被打（决定 StackSide 与 HitLeft/HitRight）。
        // 返回：true 表示请求已受理；false 表示已死。
        // 步骤：死亡直接拒绝；否则写 StackSide 并排队受击。
        // 上游/下游：PlayerBrain 受击调试键 / 将来网络受击消息调用。
        public bool NotifyHit(bool fromLeft)
        {
            if (m_context.Dead)
            {
                return false;
            }

            m_context.StackSide = fromLeft ? -1f : 1f;
            m_comboQueued = false;
            m_blocking = false;
            EPlayerState state = fromLeft ? EPlayerState.HitLeft : EPlayerState.HitRight;
            return BeginAction(state, PlayerActionId.Hit, m_timings.HitFrames);
        }

        // 功能：请求进入死亡状态，之后任何移动/动作请求都无效。
        // 入参：无。
        // 返回：true 表示这次真的死了；false 表示之前已经死了。
        // 步骤：1) 置死亡标记 2) 清动作与位移闸门 3) 强制切到反应层的 Die（跳过准入检查）。
        // 上游/下游：PlayerBrain 死亡调试键 / 将来网络死亡消息调用。
        public bool NotifyDead()
        {
            if (m_context.Dead)
            {
                return false;
            }

            m_context.Dead = true;
            m_context.ResetAction();
            m_hasPendingAction = false;
            m_comboQueued = false;
            m_blocking = false;
            m_context.Motion.MovementEnabled = false;
            m_context.Motion.SetMoveSpeed(0f);
            m_fsm.ForceChange(EPlayerState.Reaction, EPlayerState.Die);
            return true;
        }

        // 功能：按输入选一个移动状态（只在没有动作在播时用）。
        // 入参：input 这一帧的输入。
        // 返回：Idle / Walk / Run / Sprint / CrouchIdle / CrouchWalk / CrouchJog 之一。
        // 步骤：没方向就站着；蹲着优先蹲三态；否则按 Shift→冲刺、Alt→慢走、默认跑。
        // 上游/下游：Tick 调用。
        private EPlayerState ChooseLocomotion(in PlayerInput input)
        {
            if (!input.HasDirection())
            {
                return m_context.Crouch ? EPlayerState.CrouchIdle : EPlayerState.Idle;
            }

            if (m_context.Crouch)
            {
                return input.SprintHeld ? EPlayerState.CrouchJog : EPlayerState.CrouchWalk;
            }

            if (input.SprintHeld)
            {
                return EPlayerState.Sprint;
            }

            return input.WalkHeld ? EPlayerState.Walk : EPlayerState.Run;
        }

        // 功能：把目标移动状态落到状态机上（同层只换下层，跨层才换上层）。
        // 入参：desired 目标移动状态。
        // 返回：无；切换被拒绝时保持原状态。
        // 步骤：当前已在移动层就 TryChangeLower，否则 TryChangeUpper(移动层, desired)。
        // 上游/下游：Tick 调用；下游 HierarchicalStateMachine.TryChangeLower/TryChangeUpper。
        private void ApplyLocomotion(EPlayerState desired)
        {
            if (m_fsm.UpperCurrent == EPlayerState.Locomotion)
            {
                if (m_fsm.LowerCurrent != desired)
                {
                    m_fsm.TryChangeLower(desired);
                }

                return;
            }

            m_fsm.TryChangeUpper(EPlayerState.Locomotion, desired);
        }

        // 功能：推进当前动作的帧计数，到点就结束动作或接上排队的下一段连击。
        // 入参：无。
        // 返回：无。
        // 步骤：没有动作直接返回；有动作就 +1 帧；到点先看有没有排队连击，能接就接下一段，否则清动作。
        // 上游/下游：Tick 调用；下游 TryStartNextCombo / PlayerStateContext.ResetAction。
        private void AdvanceAction()
        {
            if (!m_context.ActionBusy)
            {
                return;
            }

            m_context.ActionFrame++;
            if (m_context.ActionFrames <= 0 || m_context.ActionFrame < m_context.ActionFrames)
            {
                return;
            }

            if (m_comboQueued && TryStartNextCombo())
            {
                m_comboQueued = false;
                return;
            }

            m_comboQueued = false;
            m_context.ResetAction();
        }

        // 功能：把当前攻击段接到下一段（1→2、2→3）。
        // 入参：无。
        // 返回：true 表示已登记下一段；false 表示当前不是第 1/2 段。
        // 步骤：按当前 ActionId 决定目标状态与帧数，再 BeginAction 排队，下一帧生效。
        // 上游/下游：AdvanceAction 调用；下游 BeginAction。
        private bool TryStartNextCombo()
        {
            if (m_context.ActionId == PlayerActionId.Attack1)
            {
                return BeginAction(EPlayerState.Attack2, PlayerActionId.Attack2, m_timings.Attack2Frames);
            }

            if (m_context.ActionId == PlayerActionId.Attack2)
            {
                return BeginAction(EPlayerState.Attack3, PlayerActionId.Attack3, m_timings.Attack3Frames);
            }

            return false;
        }

        // 功能：把排队中的动作请求真正执行（切到对应层与状态）。
        // 入参：无。
        // 返回：无。
        // 步骤：1) 先写 ActionBusy/ActionId/帧数 2) 目标就是当前配置时只重置计时 3) 否则 TryChangeUpper，被拒绝则回滚为「没有动作」。
        // 上游/下游：Tick 调用；下游 HierarchicalStateMachine.TryChangeUpper。
        private void ApplyPendingAction()
        {
            m_hasPendingAction = false;
            m_context.ActionBusy = true;
            m_context.ActionId = m_pendingActionId;
            m_context.ActionFrame = 0;
            m_context.ActionFrames = m_pendingFrames;

            EPlayerState upper = PlayerStateCatalog.UpperOf(PlayerStateCatalog.LayerOf(m_pendingState));

            if (m_fsm.UpperCurrent == upper && m_fsm.LowerCurrent == m_pendingState)
            {
                return;
            }

            if (!m_fsm.TryChangeUpper(upper, m_pendingState))
            {
                m_context.ResetAction();
            }
        }

        // 功能：登记一个待执行动作。
        // 入参：state 目标状态；actionId 写进动画参数的动作编号；frames 总帧数（60fps，<=0 表示不自动结束）。
        // 返回：true 表示已登记。
        // 步骤：只写 pending 字段，下一帧 Tick 再执行 —— 保证一帧内只发生一次状态切换。
        // 上游/下游：NotifyAttack / NotifyHit 调用。
        private bool BeginAction(EPlayerState state, float actionId, int frames)
        {
            m_pendingState = state;
            m_pendingActionId = actionId;
            m_pendingFrames = frames;
            m_hasPendingAction = true;
            return true;
        }

        // 功能：按状态取这一档移动速度。
        // 入参：state 当前移动状态。
        // 返回：米/秒；非移动状态返回 0。
        // 步骤：switch 一一映射到 PlayerSpeeds 的五个字段。
        // 上游/下游：Tick 调用。
        private float SpeedOf(EPlayerState state)
        {
            switch (state)
            {
                case EPlayerState.Walk:
                    return m_speeds.Walk;
                case EPlayerState.Run:
                    return m_speeds.Run;
                case EPlayerState.Sprint:
                    return m_speeds.Sprint;
                case EPlayerState.CrouchWalk:
                    return m_speeds.CrouchWalk;
                case EPlayerState.CrouchJog:
                    return m_speeds.CrouchJog;
                default:
                    return 0f;
            }
        }

        // 功能：把横向输入夹到 -1~1。
        // 入参：value 原始横向输入。
        // 返回：夹紧后的值。
        // 步骤：两段比较，不调用 UnityEngine.Mathf（本类保持纯 C#）。
        // 上游/下游：Tick 调用。
        private static float ClampDirection(float value)
        {
            if (value < -1f)
            {
                return -1f;
            }

            return value > 1f ? 1f : value;
        }

        // 功能：注册移动层的九个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：Idle 必须第一个注册（它会成为入口），其余顺序无关。
        // 上游/下游：构造函数调用。
        private void RegisterLocomotionStates()
        {
            RegisterSub(EPlayerState.Idle);
            RegisterSub(EPlayerState.Walk);
            RegisterSub(EPlayerState.Run);
            RegisterSub(EPlayerState.Sprint);
            RegisterSub(EPlayerState.CrouchIdle);
            RegisterSub(EPlayerState.CrouchWalk);
            RegisterSub(EPlayerState.CrouchJog);
            RegisterSub(EPlayerState.Jump);
            RegisterSub(EPlayerState.Fall);
        }

        // 功能：注册动作层的九个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：Attack1 第一个注册（成为入口）。
        // 上游/下游：构造函数调用。
        private void RegisterActionStates()
        {
            RegisterSub(EPlayerState.Attack1);
            RegisterSub(EPlayerState.Attack2);
            RegisterSub(EPlayerState.Attack3);
            RegisterSub(EPlayerState.Skill1);
            RegisterSub(EPlayerState.Skill2);
            RegisterSub(EPlayerState.Skill3);
            RegisterSub(EPlayerState.Dash);
            RegisterSub(EPlayerState.Block);
            RegisterSub(EPlayerState.Pose);
        }

        // 功能：注册反应层的四个状态。
        // 入参：无。
        // 返回：无。
        // 步骤：HitLeft 第一个注册（成为入口）。
        // 上游/下游：构造函数调用。
        private void RegisterReactionStates()
        {
            RegisterSub(EPlayerState.HitLeft);
            RegisterSub(EPlayerState.HitRight);
            RegisterSub(EPlayerState.Stun);
            RegisterSub(EPlayerState.Die);
        }

        // 功能：把某个下层状态注册到它所属的层下。
        // 入参：sub 下层状态。
        // 返回：无。
        // 步骤：用 LayerOf 算出层，再 UpperOf 换成上层标识 —— 层归属只在这里推一次。
        // 上游/下游：上面三个 Register*States 调用；下游 HierarchicalStateMachine.RegisterSub。
        private void RegisterSub(EPlayerState sub)
        {
            EPlayerState upper = PlayerStateCatalog.UpperOf(PlayerStateCatalog.LayerOf(sub));
            m_fsm.RegisterSub(upper, sub, new PlayerLayeredState(sub));
        }
    }
}
```

### 5.4 `Client/Assets/_Project/Game/Player/PlayerMove.cs`

```csharp
// 这个文件里有：
//   PlayerMove（类）：四向移动（W/A/S/D 都是转身朝该方向再前进）；不斜走，朝向只由方向键决定

using NBC.Framework.Input;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧读输入，取主导轴得到 W/A/S/D 四种之一，统一「转身朝该方向 + 沿该方向前进」。
    // 主要数据成员：m_moveSpeed（米/秒）、m_turnSpeed（度/秒）、m_forwardSpeed / m_sideSpeed（给动画的分量）。
    // 主要外部方法：ForwardSpeed / SideSpeed / MoveSpeed / CurrentSpeed（只读属性）、SetMoveSpeed、MovementEnabled。
    // 谁在用它：挂在角色物体上；输入取自 InputManager.Instance.Current，键位在 InputMapping 里可改；World 里由 PlayerBrain 通过 IPlayerMotion 驱动。
    public sealed class PlayerMove : MonoBehaviour, IPlayerMotion, IPlayerDash
    {
        // 每秒走多少米。场景里 1 单位 = 1 米，5 就是每秒 5 米
        [SerializeField] private float m_moveSpeed = 5f;

        // 转身速度，度/秒。720 约等于 0.125 秒转 90 度
        [SerializeField] private float m_turnSpeed = 720f;

        // 是否用「参考体的坐标轴」来算方向（World 场景用相机轴；Battle 保持世界轴）
        [SerializeField] private bool m_useReferenceAxes = false;

        // 参考体：留空时用 Camera.main；只有 m_useReferenceAxes 为 true 才用
        [SerializeField] private Transform m_reference = null;

        // 是否允许位移：动作/受击/死亡期间由状态机置 false，实现「动作即停」（组件本身不禁用）
        private bool m_movementEnabled = true;

        // 冲刺速度（米/秒）；0 表示当前没有冲刺
        private float m_dashSpeed;

        // 冲刺结束时刻（Time.time 口径，秒）
        private float m_dashEndTime;

        // 功能：开始一段匀速前冲，动作期间也能位移（冲刺属于动作，但必须真的动）。
        // 入参：speedMetersPerSecond 前进速度（米/秒）；durationSeconds 持续秒数（<=0 忽略）。
        // 返回：无。
        // 步骤：记录速度与「当前时间 + 时长」，Update 每帧检查是否还在窗口内。
        // 上游/下游：PlayerBrain 在 Dash 动作开始时调用；Update 的 TryAdvanceDash 执行。
        public void StartDash(float speedMetersPerSecond, float durationSeconds)
        {
            if (speedMetersPerSecond <= 0f || durationSeconds <= 0f)
            {
                return;
            }

            m_dashSpeed = speedMetersPerSecond;
            m_dashEndTime = Time.time + durationSeconds;
        }

        // 功能：读/写位移闸门。
        // 入参：true 允许移动；false 原地站住。
        // 返回：当前是否允许移动。
        // 步骤：置 false 时顺手把三个速度清零，避免下游读到「停之前那一帧」的旧值。
        // 上游/下游：PlayerStateMachine.Tick 每帧写；Update 开头读。
        public bool MovementEnabled
        {
            get { return m_movementEnabled; }
            set
            {
                m_movementEnabled = value;

                if (!value)
                {
                    m_forwardSpeed = 0f;
                    m_sideSpeed = 0f;
                    m_currentSpeed = 0f;
                }
            }
        }

        // 功能：设置这一帧的移动速度（状态机按走/跑/冲/蹲档位传进来）。
        // 入参：metersPerSecond 米/秒；负数视为非法，直接忽略。
        // 返回：无。
        // 步骤：写 m_moveSpeed，Update 下一次位移就用新值。
        // 上游/下游：PlayerStateMachine.Tick 调用；Update 读取。
        public void SetMoveSpeed(float metersPerSecond)
        {

        public void SetReferenceAxes(bool use, Transform reference)

        // 前后分量，米/秒：W 为正、S 为负
        private float m_forwardSpeed;

        // 左右分量，米/秒：转身后基本为 0（留着给以后侧移用）
        private float m_sideSpeed;

        // 合速度，米/秒（≥ 0），给 HUD 之类用
        private float m_currentSpeed;

        // 功能：读当前的前后速度分量（米/秒，W 正、S 负）。

        // 功能：推进冲刺位移；没有冲刺或已过期就返回 false。
        // 入参：无。
        // 返回：true 表示这一帧由冲刺接管了移动，Update 不再读输入。
        // 步骤：比结束时刻；还在窗口内就沿当前朝向平移，并写上速度给调试面板。
        // 上游/下游：Update 开头调用；StartDash 设置窗口。
        private bool TryAdvanceDash()
        {
            if (m_dashSpeed <= 0f || Time.time >= m_dashEndTime)
            {
                m_dashSpeed = 0f;
                return false;
            }

            transform.position += transform.forward * (m_dashSpeed * Time.deltaTime);
            m_forwardSpeed = m_dashSpeed;
            m_currentSpeed = m_dashSpeed;
            return true;
        }

        // 功能：每帧把输入压成四向之一，转身朝该方向并位移，同时算出前后 / 左右分量。
        // 入参：无（引擎每帧调用）
        // 返回：无
        // 步骤：
        //   1) 三个速度先清 0；提前 return 的分支不会残留上一帧的值
        //   2) 取 InputManager；把量化轴还原成 -1..1（x 左右、z 前后）
        //   3) 取主导轴：|z| >= |x| 用前后，否则用左右 ⇒ 只有四种方向，不斜走
        //   4) 按四种情况决定「朝向」与「位移方向」：
        //        W（z>0）  ：朝向 = 世界前方，沿该方向前进
        //        A（x<0）  ：朝向 = 世界左方，转身后沿该方向前进
        //        D（x>0）  ：朝向 = 世界右方，转身后沿该方向前进
        //        S（z<0）  ：朝向 = 世界后方，转身后沿该方向前进
        //   5) 转身用 RotateTowards 限速（0.125 秒转 90 度），位移用「目标方向」而不是当前朝向，避免转弯时走弧线
        //   6) 位移后按 forward / right 点乘，拆出前后 / 左右分量
        // 上游：Unity 引擎每帧调用
        // 下游：InputManager.Current、Transform.rotation、Transform.position
        // 注意：四向一律会转身（S 也转身，2026-10-31 由负责人改；R012 时曾是「S 不转身倒退」）
        private void Update()
        {
            m_forwardSpeed = 0f;
            m_sideSpeed = 0f;
            m_currentSpeed = 0f;

            // 冲刺优先：动作期间 m_movementEnabled 是 false，但冲刺要真的往前挪
            if (TryAdvanceDash())
            {
                return;
            }

            // 状态机说了「动作中/已死」就不位移：这里只是不移动，组件保持启用，动画参数照常发布
            if (!m_movementEnabled)
            {
                return;
            }

            InputManager input = InputManager.Instance;

            if (input == null || !input.IsEnabled)
            {
                return;
            }

            InputCommand command = input.Current;

            float x = (float)command.MoveX / InputCommand.MoveScale;
            float z = (float)command.MoveY / InputCommand.MoveScale;

            if (Mathf.Abs(x) < 0.0001f && Mathf.Abs(z) < 0.0001f)
            {
                return;
            }

            bool forwardWins = Mathf.Abs(z) >= Mathf.Abs(x);

            // 四个基本方向：默认是世界轴；打开开关后改成"参考体的轴"（World 用相机轴）
            Vector3 forwardAxis = new Vector3(0f, 0f, 1f);
            Vector3 rightAxis = new Vector3(1f, 0f, 0f);

            if (m_useReferenceAxes)
            {
                Transform reference = m_reference != null ? m_reference : (Camera.main != null ? Camera.main.transform : null);

                if (reference != null)
                {
                    // 压到水平面：镜头俯视时也不能让角色往地里钻
                    forwardAxis = Vector3.ProjectOnPlane(reference.forward, Vector3.up).normalized;
                    rightAxis = Vector3.ProjectOnPlane(reference.right, Vector3.up).normalized;

                    if (forwardAxis.sqrMagnitude < 0.0001f)
                    {
                        forwardAxis = new Vector3(0f, 0f, 1f);
                    }

                    if (rightAxis.sqrMagnitude < 0.0001f)
                    {
                        rightAxis = new Vector3(1f, 0f, 0f);
                    }
                }
            }

            Vector3 targetDirection = forwardWins
                ? forwardAxis * Mathf.Sign(z)
                : rightAxis * Mathf.Sign(x);

            // 四向统一：先转身朝目标方向（限速），位移仍用目标方向，避免边走边转出弧线
            Quaternion targetRotation = Quaternion.LookRotation(targetDirection, Vector3.up);
            transform.rotation = Quaternion.RotateTowards(
                transform.rotation, targetRotation, m_turnSpeed * Time.deltaTime);

            Vector3 moveDirection = targetDirection;

            Vector3 before = transform.position;
            transform.position += moveDirection * (m_moveSpeed * Time.deltaTime);

            float dt = Time.deltaTime;
            if (dt <= 0f)
            {
                return;
            }

            Vector3 moved = transform.position - before;

            // 实测位移拆成前后 / 左右：以后加碰撞，被挡住时这两个值会自然变小
            m_forwardSpeed = Vector3.Dot(moved, transform.forward) / dt;
            m_sideSpeed = Vector3.Dot(moved, transform.right) / dt;
            m_currentSpeed = moved.magnitude / dt;
        }

        // 功能：被禁用时把三个速度清零，避免下游继续读到「停之前那一帧」的旧速度。
        // 入参：无
        // 返回：无
        // 步骤：直接归零（这三个字段只在 Update 里写，禁用后不会再被刷新）
        // 上游：Unity 引擎（组件被禁用时调用）、PlayerBrain 的状态闸门
        // 下游：PlayerAnimation 读这三个值
        // 注意：不清零的话，状态机禁用本组件后动画会一直保持「在走」——因为 PlayerAnimation 读到的是旧值
        private void OnDisable()
        {
            m_forwardSpeed = 0f;
            m_sideSpeed = 0f;
            m_currentSpeed = 0f;
        }
    }
}
```

```csharp
    // 主要数据成员：m_move（位移）、m_publisher（动画参数）、m_context（共享状态）、m_machine（三层状态机）。

    {

        [SerializeField]

        // World 专用的动画控制器副本（为空则沿用模型自带控制器；Battle 不挂本组件，不受影响）
        [SerializeField]

        [Header("动作时长（60fps 帧数）")]

        private int m_attack1Frames = 60;

        [SerializeField]
        private int m_attack2Frames = 60;

        // 第三段攻击帧数（93 帧 = 1.55 秒）
        [SerializeField]

        // 技能 1 帧数
        [SerializeField]
        private int m_skill1Frames = 240;

        // 技能 2 帧数
        [SerializeField]
        private int m_skill2Frames = 144;

        // 技能 3 帧数
        [SerializeField]
        private int m_skill3Frames = 264;

        // 受击帧数
        [SerializeField]
        private int m_hitFrames = 88;

        // 冲刺帧数
        [SerializeField]

        // 硬直帧数
        [SerializeField]
        private int m_stunFrames = 120;

        // 姿势帧数

        // 连击窗口起点：动作开始后第几帧才接受下一段输入（18 帧 = 0.3 秒）

        private int m_comboWindowStart = 18;

        // 连击窗口末端缓冲：结束前多少帧就不再接受（4 帧）

        // 冲刺速度（米/秒）

        [Header("按键")]
        // 攻击键（鼠标左键也可）
        [SerializeField]

        // 受击调试键
        [SerializeField]

        // 死亡调试键
        [SerializeField]

        // 技能 1 键
        [SerializeField]

        // 返回：无。
        // 步骤：1) 找 PlayerMove（找不到就禁用自己）2) 找或加 Publisher 3) 关旧动画 4) 换控制器副本 5) 建上下文与状态机 6) 订阅日志。
        // 上游/下游：Unity 生命周期；下游 PlayerStateMachine 构造函数。
        private void Awake()
        {

        // 上游/下游：Unity 生命周期；下游 PlayerStateMachine.Tick、PlayerAnimatorPublisher.Apply。
        private void Update()
        {
            if (m_machine == null)
            {
                return;
            }

            PlayerInput input = ReadInput();
            HandleActionKeys();

            // 右键是「按住格挡」：每帧同步一次，松开当帧就退出
            m_machine.SetBlocking(m_enableLocalAttack && Input.GetMouseButton(1));

            m_frameAccumulator += Time.deltaTime;
            int steps = 0;
            bool firstStep = true;

            while (m_frameAccumulator >= FixedDeltaSeconds && steps < MaxCatchUpSteps)
            {
                m_frameAccumulator -= FixedDeltaSeconds;
                steps++;
                m_frame++;

                PlayerInput stepInput = firstStep
                    ? input
                    : new PlayerInput(input.MoveX, input.MoveY, input.WalkHeld, input.SprintHeld, false);
                firstStep = false;
                m_machine.Tick(m_frame, stepInput);

                return;

            if (m_frameAccumulator > FixedDeltaSeconds * MaxCatchUpSteps)
            {
                m_frameAccumulator = 0f;

            m_publisher.Apply(m_machine.Parameters);

        // 入参：无。
        // 返回：无。
        // 步骤：调试键先判（K 左受击、L 死亡），再看攻击键（J 或鼠标左键）；编辑器里调试键始终可用，构建版本看 Inspector 开关。
        // 上游/下游：Update 调用；下游 Notify*。
        private void HandleActionKeys()
        {
            if (m_enableDebugKeys || Application.isEditor)
            {
                if (Input.GetKeyDown(m_hitKey))
                {
                    NotifyHit(true);
                }

                if (Input.GetKeyDown(m_dieKey))

                    NotifyDead();
                }

            }

            if (Input.GetKeyDown(m_attackKey) || Input.GetMouseButtonDown(0))

                NotifyAttack();
            }

            if (Input.GetKeyDown(m_skill1Key))

                NotifySkill(1);
            }

            if (Input.GetKeyDown(m_skill2Key))
            {
                NotifySkill(2);

                NotifySkill(3);

                NotifyDash();
            }

            if (Input.GetKeyDown(m_poseKey))
            {
                NotifyPose();
            }
        }

        // 功能：请求播第 index 个技能（只播动画）。
        // 入参：index 取 1~3。
        // 返回：无。
        // 步骤：转给状态机；被拒绝（动作中/格挡/已死）时什么都不做。
        // 上游/下游：Update 的 Q/E/R、外部网络消息；下游 PlayerStateMachine.NotifySkill。
        public void NotifySkill(int index)
        {
            if (m_machine != null)
            {
                m_machine.NotifySkill(index);
            }
        }

        // 功能：请求前冲：状态机接了就同时让位移组件真的往前挪。
        // 入参：无。
        // 返回：无。
        // 步骤：状态机接受后，把速度与时长交给实现了 IPlayerDash 的位移组件。
        // 上游/下游：Update 的 V 键；下游 PlayerStateMachine.NotifyDash、IPlayerDash.StartDash。
        public void NotifyDash()
        {
            if (m_machine == null || !m_machine.NotifyDash())
            {
                return;
            }

            IPlayerDash dash = m_motion as IPlayerDash;
            if (dash != null)
            {
                dash.StartDash(m_dashSpeedMetersPerSecond, m_dashSeconds);
            }
        }

        // 功能：请求轮换到下一个姿势。
        // 入参：无。
        // 返回：无。
        // 步骤：转给状态机，由它把 PoseIndex 加一。
        // 上游/下游：Update 的 F 键；下游 PlayerStateMachine.NotifyPose。
        public void NotifyPose()
        {
            if (m_machine != null)
            {
                m_machine.NotifyPose();
            }
        }

        // 功能：把这一帧的键位读成 PlayerInput。
        // 入参：无。
        // 返回：输入快照。
        // 步骤：移动轴取 InputManager（-1000~1000 除 1000）；Alt=慢走、Shift=冲刺、Ctrl 按下=切换蹲；输入被禁用时轴按 0。
        // 上游/下游：Update 调用；下游 PlayerStateMachine.Tick。
        private static PlayerInput ReadInput()
        {
            float x = 0f;
            float y = 0f;

            InputManager manager = InputManager.Instance;
            if (manager != null && manager.IsEnabled)
            {
                InputCommand command = manager.Current;
                x = (float)command.MoveX / InputCommand.MoveScale;
                y = (float)command.MoveY / InputCommand.MoveScale;
            }

            bool walk = Input.GetKey(KeyCode.LeftAlt) || Input.GetKey(KeyCode.RightAlt);
            bool sprint = Input.GetKey(KeyCode.LeftShift) || Input.GetKey(KeyCode.RightShift);
            bool crouch = Input.GetKeyDown(KeyCode.LeftControl) || Input.GetKeyDown(KeyCode.RightControl);
            return new PlayerInput(x, y, walk, sprint, crouch);
        }

        // 功能：把一次状态切换打到 Console。
        // 入参：record 切换记录（含帧号与前后状态名）。
        // 返回：无。
        // 步骤：直接用记录自带的 ToString，格式 "[f12] Locomotion/Idle -> Locomotion/Run"。
        // 上游/下游：PlayerStateMachine.StateChanged 事件。
        private void OnStateChanged(StateChangeRecord record)
        {
            Debug.Log("[PlayerBrain] " + record);
        }

        // 功能：组件销毁时退订事件，避免状态机持有已销毁的 MonoBehaviour。
        // 入参：无。
        // 返回：无。
        // 步骤：有状态机就退订。
        // 上游/下游：Unity 生命周期。
        private void OnDestroy()
        {
            if (m_machine != null)
            {
                m_machine.StateChanged -= OnStateChanged;
            }
        }
    }
}
```
