## 一、测试范围与框架

- 范围：格子计算（含负坐标）、可见性、服务端按可见集下发、恢复默认后不误删。
- 框架：`Server\_net-probe`（真 socket + 真服务端），新增 4 条用例。
- 命令：`dotnet run --project Server\_net-probe\NetProbe.csproj -m:1 --no-build`。

## 三、测试代码要点

```csharp
// ① 网格单元
var grid = new AoiGrid(2000);
grid.IsVisible(0, 0, 1500, 0);   // true（同/邻格）
!grid.IsVisible(0, 0, 4500, 0);  // true（隔两格）

// ② 端到端：调小格子，再把人拉开（注意每次只走一个 tick 的距离，要循环）
RoomBattleService.AoiCellSizeMm = 2000;
for (int i = 0; i < 200; i++) { battle.MoveTowardsPoint(heroA, 4000, 0); }
for (int i = 0; i < 200; i++) { battle.MoveTowardsPoint(heroB, -4000, 0); }
h.TickBattles(2);

// ③ 断言：互不可见 + 自己可见
Check(..., !aSeesB && !bSeesA && aSeesSelf, ...);

// ④ 恢复默认，断言不误删
RoomBattleService.AoiCellSizeMm = AoiGrid.DefaultCellSizeMm;
h.TickBattles(2);
```

## 五、自动化测不到的部分

- **真实客户端表现**：远处实体消失后，客户端是否平滑隐藏（不会闪一下）。
- 同格玩家的"一份 payload"是否真的省带宽（需要抓包统计，demo 先不测）。
- 开放世界尺度（几百个实体）下的性能（当前场地只有 5 个实体）。
