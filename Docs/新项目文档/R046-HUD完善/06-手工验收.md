## 一、计划

| 类型 | 场景 | 观察点 |
| --- | --- | --- |
| 正常 | 进副本（登录 → 开始游戏 → World → 进副本） | 左上角 BOSS 血条出现；附近有怪时目标条出现；右上角任务追踪出现（有任务时） |
| 正常 | 打怪 | 目标血条随伤害下降；打 BOSS 时 BOSS 条下降 |
| 正常 | 死亡 | 黑幕出现、标题「你倒下了」、倒计时从 5 递减、状态行有字 |
| 正常 | 复活 / 重生 | 黑幕关闭，战斗恢复 |
| 异常 | 没有任务时 | 右上角**不出现**空框 |
| 异常 | 目标全部死亡 | 目标条消失（`Kind` 里没有活怪） |
| 边界 | 只剩 BOSS | BOSS 条在、目标条隐藏 |
| 边界 | 重开副本（再来一次） | 血条与任务行跟着新一局刷新，不残留上一局数字 |
| 边界 | 返回 World | 两块 HUD 面板消失（`CloseHud`），World 里不显示血条 |
| 性能 | 副本内跑动 + 打怪 | 帧率与改前无明显变化（每帧只在 4~10 个实体上算距离） |
