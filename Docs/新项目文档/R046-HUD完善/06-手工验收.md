## 二、正常流程走查

1. 登录 → 开始游戏 → World 按 E 进副本。
2. 左上出现 BOSS 血条（狼王 1000/1000）；走近普通狼时出现目标条（野狼 300/300）。
3. 砍狼：数字掉、红条变短、飘伤害数字；再补刀，狼消失、目标条隐藏。
4. 右上任务区：副本内没有已接任务时显示「副本区域：暂无进行中的任务」。
5. 按 L 死亡：黑幕 + 「你已倒下」+ 5 秒倒计时，倒计时结束复活、黑幕消失。
6. 清完怪：只出胜利结算面板，**不**出现「你已倒下」。
7. 点「再来一次」：1 秒内怪物重刷，HUD 立刻恢复。
8. 点「返回世界」：HUD 全部收起，World 里不再残留 BOSS 条与任务区。

## 三、异常场景

1. 连不上服务器时进副本：`[HUD] 打不开 …` 只报一次，不刷屏（未单独构造，逻辑见 05）。
2. 资源层没装好就请求面板：`Bind` 提前返回、不请求，等就绪后再补（R054 已覆盖）。
3. 多人分支：单人调试环境无法构造，如实标「未构造」。

## 四、性能

- 第一次进副本到 HUD 出现：与场景同帧，无可见空窗。
- 稳态：`UpdateTargets` 每帧只遍历实体列表（≤12 个），`UpdateQuest` 每 0.25 秒一次，均无 GC 峰值（见 03 的风险条目）。
