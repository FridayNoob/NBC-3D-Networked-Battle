# 02 需求

需求编号：R046
所属阶段：M4
作者：AI（DeepSeek）
状态：开发中

## 一、业务目标（一句话）

进副本后玩家能一直看清「BOSS 还剩多少血、我现在打的是谁、任务做到哪」，不用去翻 Console 或调试窗口。

## 二、用户与场景

- 玩家进入副本 `d1001`，屏幕顶部出现 BOSS 大血条（狼王 1000 血）；打死 BOSS 后血条立刻消失。
- 玩家靠近/攻击某只怪时，屏幕上方中间显示这只怪的名字与血量，切换目标时跟着换。
- 接了任务的玩家在屏幕右侧看到当前任务与进度；没接任务时这块不出现。
- 玩家死亡时黑屏倒计时照旧（R041 的行为不能变），只是黑幕由预制体渲染。

## 三、功能列表

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0 | BOSS 大血条 | 顶部居中，显示 `BOSS（配置号）` + 当前/最大血 + 比例条；BOSS 死或不在快照里就隐藏 |
| P0 | 目标信息 | 显示最近目标：名字（按 Kind/配置号生成）+ 血量数字 + 比例条；无目标隐藏 |
| P0 | 任务追踪 | 最多 3 行「标题 · 进度」；任务本里没有进行中的任务就整块隐藏 |
| P0 | 黑幕改预制体 | `DeathScreenPanel.prefab` + `UIManager`，行为与 R041 一致 |
| P1 | 目标切换平滑 | 目标血量变化不闪（只改数字与填充，不重建面板） |
| P2 | 目标框选（鼠标点选） | 本需求不做，等 R044 打击感一起考虑 |

## 四、边界（不做什么）

- 不做技能冷却条（依赖 R043a 技能栏）。
- 不做小地图、伤害数字、血条跟随怪物（`MonsterHealthBar` 已存在，保持原样）。
- 不改服务端协议、不改 `SnapshotView.cs`。
- 不做目标框选/锁定操作，目标 = 最近的非英雄存活实体。

## 五、优先级

先 P0 四项，全部是「看得见」的东西；P1 只影响观感，放最后。

## 六、验收标准

1. 当进入副本且 BOSS 存活时，屏幕顶部应出现 BOSS 血条，数字与快照 `hp/max_hp` 一致。
2. 当 BOSS 被打死后，BOSS 血条应在 0.2 秒内消失，不再回弹。
3. 当场上只剩普通怪时，血条区域不应残留 BOSS 那一行。
4. 当玩家靠近某只怪时，目标信息应显示它的名字与当前血量。
5. 当目标死亡或离开范围时，目标信息应隐藏。
6. 当任务本里有进行中的任务时，右侧应显示最多 3 行「标题 + 进度」。
7. 当任务本为空时，任务区域应整块不显示（不是空框）。
8. 当玩家死亡时，黑幕应正常出现、倒计时递减、复活后消失（与 R041 一致）。
9. 当面板重复打开时，不应出现两份 HUD（`UIManager` 复用已有实例）。
10. 当退出副本回 World 时，三个 HUD 面板应全部关闭，不留残影。
