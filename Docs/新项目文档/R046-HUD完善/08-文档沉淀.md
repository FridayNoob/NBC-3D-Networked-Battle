## 一、文档范围

本需求只做「副本内 HUD 重做」，覆盖四块：BOSS 大血条、目标信息条、任务追踪区、死亡黑幕改预制体。技能栏、冷却、飘字样式不在范围内。

## 二、模块文档

### 2.1 `RuntimeHudDriver`

- 简介：把「服务端快照 + 会话数据」翻译成三块 HUD 的内容，是 HUD 唯一的数据入口。
- 接口：`Bind(PresentationFeed feed, NetSession session)`、`CloseAll()`。
- 示例：`RuntimeNetDriver.BindHud()` 里 `AddComponent<RuntimeHudDriver>().Bind(m_feed, m_session);`
- 原理：每帧挑目标（`Alive && Kind != 0` 中离英雄最近、`Kind == 2` 单列为 BOSS）；每 0.25 秒刷新一次任务区（任务状态来自 `LastQuestStates`，进度来自 `FindProgress`，文案来自 `QuestConfig`/`QuestConditionConfig`）。
- 坑：`CloseAll` 必须清引用（见 2.4）。
- 维护：新增一类 HUD 信息时，只加方法，不改 `Update` 的调度结构。

### 2.2 `HudTargetPanel`

- 简介：BOSS 与目标两条血条的视图，只负责「显示成什么样」。
- 接口：`SetBoss(bool visible, string label, int hp, int maxHp)`、`SetTarget(...)`、`HideBoss()`、`HideTarget()`。
- 原理：控件按 GameObject 名字收集（`BossRoot/BossLabel/BossValue/BossFill` 等）；血条填充有两条路：Filled Image 用 `fillAmount`，普通 Image 改 `anchorMax.x`。
- 坑：prefab 里没有 sprite 的 Filled 图，`fillAmount` 静默失效。
- 维护：改血条尺寸只改 prefab，不改脚本。

### 2.3 `HudQuestPanel`

- 简介：任务追踪区，最多三行。
- 接口：`SetRows(IReadOnlyList<QuestRow>)`、`SetQuest(QuestPanelModel)`、`SetHint(string)`。
- 原理：`SetRows` 有空行语义（会隐藏整块）；`SetHint` 是「占位」语义（整块显示、写一句话）。
- 坑：调用方必须自己决定「空态」用哪个方法。
- 维护：行数上限是 `MaxRows = 3`，与 `RuntimeHudDriver` 的 `MaxQuestRows` 同源。

### 2.4 面板生命周期（三块 HUD + 黑幕）

- 属于 DDOL 的 `Canvas`，不随场景销毁；谁开的谁负责关。
- 真值：面板引用必须与「是否正在显示」一致；收起（`HidePanel`）后引用要置 null。
- 坑：只 `HidePanel` 不清引用 ⇒ 第二次进副本不会再请求，面板永远不出现。

## 三、踩坑清单

1. `UIManager.ShowPanel` 返回 void，拿面板只能靠 `onShown` 回调。
2. `BasePanel` 已有 `PanelName` 字段，子类重复定义要 `new`。
3. Filled Image 无 sprite 时 `fillAmount` 不生效。
4. DDOL 上的面板不随场景卸载，不显式关就会跨场景残留。
5. 「空数据」与「不该占屏」是两种语义，不能用同一个方法表达。
6. Unity 未导入新文件时 `get_compilation_errors` 会返回旧的 0（假绿），要先 `Assets/Refresh`。
