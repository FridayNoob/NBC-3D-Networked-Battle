```

      │ ConfigKit 生成（客户端配置） + 服务端 CsvSheet 直接读

      │ 每只怪 spawn 时
      ▼

      │
      ▼

      │
      ▼

      │
      ▼
DungeonBattle（普攻/移动/钳位仍是世界的职责）
```

## 三、接口（★ 先定死）

```csharp
// MonsterAiProfile 增加射程字段（R022-1 只有三个）
public readonly struct MonsterAiProfile
{
    public readonly int AggroRangeMm;
    public readonly int MoveSpeedMmPerTick;
    public readonly int LeashRadiusMm;
    public readonly int AttackRangeMm;      // 新增：表里的 attackRangeMm（树里 rangeMm>0 时树优先）
    public readonly bool PatrolWhenIdle;
}

// MonsterRow 增加 4 个字段 + 构造函数重载
public readonly struct MonsterRow
{
    public readonly int Id, Hp, Attack;
    public readonly string Name;
    public readonly int AggroRangeMm;       // 新增
    public readonly int AttackRangeMm;      // 新增
    public readonly int MoveSpeedMmPerTick; // 新增
    public readonly int LeashRadiusMm;      // 新增
}

// 新增动作节点（都无参构造 + Configure 读参数）
[BtNode("Chase")]        public sealed class ChaseAction : BtNode;        // Tick: 移动一帧；贴脸(≤射程) Success，否则 Running
[BtNode("BasicAttack")]  public sealed class BasicAttackAction : BtNode;  // 参数 hits / intervalTicks
[BtNode("CastSkill")]    public sealed class CastSkillAction : BtNode;    // 参数 skillId：恒 Failure + 首告警
[BtNode("ReturnHome")]   public sealed class ReturnHomeAction : BtNode;   // 到家 Success，否则 Running
[BtNode("Patrol")]       public sealed class PatrolAction : BtNode;       // 清 Chasing，Success
[BtNode("Idle")]         public sealed class IdleAction : BtNode;         // 清 Chasing，Success
[BtNode("Wait")]         public sealed class WaitAction : BtNode;         // 参数 seconds，按 30Hz 换算帧

// 新大脑（DungeonBattle.Brains 的元素类型换成它）
public sealed class MonsterBrain
{
    public int EntityId { get; }
    public int HomeXmm { get; }
    public int HomeZmm { get; }
    public string StateName { get; }        // 追击 / 攻击 / 回位 / 巡逻 / 站桩
    public void Think(DungeonBattle world);
}
```

## 四、状态与动作语义

| 动作 | 对世界的影响 | 返回 |
| --- | --- | --- |
| `Chase` | `Chasing=true`；`MoveTowards` | 距离 ≤ 射程 → Success；否则 Running |
| `BasicAttack` | `TryBasicAttack`（世界判射程/冷却） | 打出去 → Success；没打出去 → Failure |
| `CastSkill` | 无 | Failure（首次告警） |
| `ReturnHome` | `Chasing=true`；`MoveTowardsPoint(家)` | 到家 ≤ 200mm → Success；否则 Running |
| `Patrol` | `Chasing=false` | Success（实体自身巡逻） |
| `Idle` | `Chasing=false` | Success |
| `Wait` | 无（自计时） | 未到点 Running；到点 Success |

**大脑每帧顺序**：`Target = 仇恨范围内最近的英雄` → `root.Tick(ctx)` → `Self.Chasing = ctx.Chasing` → 记 `StateName`。

## 五、两套默认树（代码搭）

```
wolf: Selector[ IsDead,
               Sequence[HasTarget, InAttackRange, AttackReady, BasicAttack(hits=1)],
               Sequence[HasTarget, Chase],
               Patrol/Action ]
boss: Selector[ IsDead,
               Sequence[HasTarget, InAttackRange, AttackReady, BasicAttack(hits=3, intervalTicks=5)],
               Sequence[HasTarget, Chase],
               Sequence[HomeFar, ReturnHome],
               Idle ]
```

> `AttackReady` 在 `skillId=0` 时看普攻冷却；`BasicAttack` 内部再由世界判一次冷却，二者不冲突。

## 六、配置链

1. `Configs/Design/Monster.csv` 加 4 列（4 行表头：字段名 / 中文 / 类型 / 约束）。
2. 客户端生成：`Tools\ConfigKit\src\ConfigKit.Cli\bin\Debug\net8.0\NBC.ConfigKit.Cli.exe --source Configs\Design --out Client\Assets\_Project\Game\Config\Generated --no-build`（本环境 `dotnet run` 必须 `--no-build`）。
3. 服务端：`CsvSheet` **直接读 `Monster.csv`**，新增 `IntOr(row, column, fallback)`，缺列/空值 → 兜底（`aggro 4000 / attack 2000 / speed 40 / leash 100000`）。
4. `DungeonBattle` spawn 时 `new MonsterAiProfile(row.AggroRangeMm, row.MoveSpeedMmPerTick, row.LeashRadiusMm, row.AttackRangeMm, patrolWhenIdle)`。

## 七、SOLID 自检

| 原则 | 怎么满足 |
| --- | --- |
| **S** | 动作 / 树搭建 / 大脑 / 表读取各自独立 |
| **O** | 新增动作 = 新增一个类 + `[BtNode]`；`BtTreeBuilder` 里只是"用哪些节点"，没有 switch 分派 |
| **L** | 动作契约：只有动作能改 `ctx.Chasing` 与世界；条件只读（R022-1 已写） |
| **I** | 新增 `IntOr` 只加一个只读方法，不动 `CsvSheet` 既有 API |
| **D** | 大脑只依赖 `BtNode` 接口；世界操作仍走 `BtOps`（R022-1）+ R022-2 补的动作类 Ops |
