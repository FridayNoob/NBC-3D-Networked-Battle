# 02 需求

需求：R022-2-动作节点与怪物大脑接线
所属阶段：M4
作者：AI 起草／LYF 确认　状态：待确认（2026-11-09）

## 一、业务目标（一句话）

**让游戏里的怪真的按行为树动起来**：会追、会打、会回位、会巡逻，BOSS 与普通怪全部换新大脑。

## 二、用户与场景

- 用户：玩家（看到怪的行为）；策划（编辑器里搭的树终于生效）；开发（后续加动作只需新增节点）。
- 场景：进副本 → 英雄进入 4 米 → 最近的怪转为追击 → 贴到 2 米内开始按冷却普攻 → 英雄跑远/被打死 → 怪回到出生点附近继续巡逻；BOSS 在家附近守点，离家超 200mm 就回去。

## 三、功能列表

| # | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 1 | `Chase` 动作 | P0 | 朝目标移动；未贴脸返回 Running |
| 2 | `BasicAttack` 动作 | P0 | 射程内 + 冷却好才出手；`hits>1` 分帧多段 |
| 3 | `ReturnHome` 动作 | P0 | 朝出生点走；到家成功 |
| 4 | `Patrol` / `Idle` 动作 | P0 | 清 `Chasing`；一个允许巡逻、一个站住 |

## 四、边界（本版明确不做）

- **不做技能系统**（`CastSkill` 恒失败，真实放技能是后续需求）。
- **不做 JSON 读取**（默认树用代码搭，R022-3 再切）。
- **不删旧实现**（`Ai/` 下旧文件保留，R022-3 一次替换）。
- 不改玩家侧、不改协议与快照字段。
- **不做寻路**：仍是直线移动（绕障是 R025）。

## 五、优先级

**P0**。依赖：R022-1（内核 + 条件）。被依赖：R022-3（JSON 接入后替换默认树）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 英雄进入 4 米且怪空闲时，怪应转为**追击**并在若干帧内缩短距离
- [ ] 当 怪贴到 2 米内时，`Chase` 应返回 Success（不再重复移动）
- [ ] 当 冷却好且射程内时，`BasicAttack` 应让英雄掉血；冷却中应**不出手**（不掉血）
- [ ] 当 `hits = 3` 时，一次攻击应分 3 段、按 `intervalTicks` 间隔结算
- [ ] 当 执行 `CastSkill` 时，应恒返回 Failure，且**只告警一次**，怪继续追/普攻（不卡死）
- [ ] 当 英雄跑出仇恨范围或死亡时，怪应停止追击、回到出生点附近
- [ ] 当 BOSS 离家 > 200mm 时，应往家走；进入 200mm 内应停止
- [ ] 当 怪空闲且允许巡逻时，应沿 Z 轴巡逻（位置变化）；`PatrolWhenIdle=false` 时应站住
- [ ] 当 `Wait(seconds)` 执行时，应在约 `seconds × 30` 帧后返回 Success
- [ ] 当 从追击切到站桩/巡逻时，`Chasing` 应被清掉（不再往目标走）
- [ ] 当 同输入跑两局时，怪物轨迹应逐帧一致（确定性）
- [ ] 当 观察客户端时，快照字段与玩家行为**无变化**（只改怪）
