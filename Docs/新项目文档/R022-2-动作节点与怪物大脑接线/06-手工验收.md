## 一、测试计划

- 目标：在**真游戏**里看怪的行为是否按行为树走（R022-1 那步没有表现，这步有）。
- 环境：服务端（端口 7778）+ Unity Play + 单人进副本。
- 判据：下面 7 条逐条对照；全过才算通过。

## 二、操作步骤（逐步）

1. **启动服务端**：`dotnet run --project Server\NBC.Server.Host\NBC.Server.Host.csproj -m:1 --no-build`
   - 看到 `[就绪] 已监听 7778` 才算起来。
2. **Unity 进 Play**，登录后**单人进副本**（`NetDebugWindow` 的进副本按钮）。
3. 站原地不动，观察怪：
   - 先看到**巡逻**（位置左右晃）
   - 你进入怪附近后，它转为**朝你走**
   - 贴到约 2 米（射线距离的 90%）时停下并**打你**（你掉血 + 受击表演）
4. **跑远**（往反方向走 5 米以上）→ 怪应**停止追击**、回到出生点附近继续巡逻。
5. 让怪把你打死（或看 BOSS）→ 你死后怪应**停手**（不再持续攻击）。
6. 观察 **BOSS**：它守在自己出生点附近；你靠近它才动；你把它引开 >200mm 后它会**往回走**。
7. 退出副本再进一次，确认**没有残留**（怪回到出生点、状态正常）。
