## 一、计划（正常·异常·边界·性能）

| 类型 | 场景 | 判据 |
| --- | --- | --- |
| 正常 | Login 点开始 → World 按 E 进副本 | Console 出现 `[Boot] 开始装表现层（第 1 步：等资源层）`，随后四步日志，最后 `[Boot] 表现层就绪`；HUD 正常显示 |
| 正常 | 同上 | 全程无 `[ConfigMgr] 表「…」还没加载`、无 `[AssetManager] 资源层尚未初始化`、无 `[HUD] 打不开 …` |
| 正常 | 打死 BOSS 或返回 World 再进副本 | 每次都从第 1 步重新开始，HUD 每次都能出现 |
| 异常 | 服务端没起、点开始（主菜单自身会提示） | 与本需求无关，但进副本后资源层正常 ⇒ `[Boot]` 四步仍应走完 |
| 异常 | 资源层安装失败（可在 `HpBarDemo` 里临时断网/删包构造） | 8 秒后出现 `[Boot] 失败：第 1 步（等资源层）超过 8 秒还没完成` |
| 边界 | 连点「再来一次」两次 | HUD 只出现一份；Console 里每局只有一条 `[Boot] 表现层就绪` |
| 边界 | 回 World 后立刻再进副本 | 第二次进入能看到新的 `[Boot] 开始装表现层`，不应沿用上次的编排 |
| 性能 | 进副本到 HUD 出现 | 第 1~4 步总耗时应小于 3 秒（本机冷启动约 1~3 秒），日志可见各步耗时节奏 |

## 二、正常流程走查

1. 启动服务端（`dotnet run --project Server/NBC.Server.Host`，确认 `[就绪] 已监听 7778`）；
2. Login 场景点「开始游戏」→ 进 World；
3. 走到 `[DungeonEntrance]` 按 E；
4. 看 Console 依次出现：
   - `[Boot] 开始装表现层（第 1 步：等资源层）`
   - `[Boot] 进入第 2 步：设配置来源`
   - `[Boot] 进入第 3 步：等配置表`
   - `[Boot] 进入第 4 步：挂 HUD`
   - `[Boot] 表现层就绪`
5. 看画面：左上 BOSS 大血条、靠近怪出目标条、右上任务三行（与 R046 一致）。

## 三、异常场景

1. 服务端正常但**配置表目录被临时改名**（`Configs/Design` 不可读）：应在第 3 步超时，`[Boot] 失败：第 3 步（等配置表）超过 8 秒还没完成`，同时能看到 `[Boot] 预加载配置表失败：…`；
2. 禁网/删资源包使资源层装不上：第 1 步超时，说明是资源问题而不是配置问题；
3. 返回 World 后再进：不应出现「已经装过加载器」「表没加载」这类旧日志。

## 四、性能

- 关注 `[Boot]` 日志之间的时间差（Console 时间戳）：资源层（第 1 步）通常是最大头；
- HUD 出现后 0.25 秒内任务行应有内容（`QuestRefreshSeconds = 0.25`）。
