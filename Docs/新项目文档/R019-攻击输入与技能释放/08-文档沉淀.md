## 二、模块文档

### 简介与使用场景

按 **J** 挥剑：客户端在**挥剑判定窗口**内用**剑的碰撞体**采样出「碰到了哪只怪」，把这个目标上报；
服务端按**圆形射程 + 冷却**做权威裁决。
「剑碰到谁」决定**打谁**，「服务端算」决定**是否命中**。

### 核心契约

| 项 | 值 | 谁在用 |
| --- | --- | --- |
| 攻击键 | **J**（`HpBarDemoBehaviour.m_attackKey`，Inspector 可改） | 输入装配 |
| 动作编号 | **0**（服务端约定 `ActionBits & 1` = 普攻） | 不许改 |
| 剑的骨骼 | 名字含 `weapon_sword`（找不到退 `hand_r`） | 剑碰撞体 |
| 剑的碰撞体 | 任意类型 `Collider`，**运行时强制 Trigger** | 采样 |
| 判定窗口 | `[0.10s, 0.40s)`（相对按下时刻） | `RuntimeNetDriver.HandleAttack` |
| 目标反查 | `MonsterSlotTag{ EntityId }`（每个怪物槽位挂一个） | 采样 |
| 服务端权威 | 2 米圆 + 0.5 秒冷却 | `BattleRules` |

### 使用示例（负责人亲手跑通，2026-11-05）

```text
起服 → Play → 走到狼旁边 → 剑扫到它 → 按 J
  → 角色挥剑；服务端控制台：普攻打中单位 <id>（N 点）
剑够不到时按 J → 服务端无日志（这一刀打空，不上报）
```

### 已知限制与坑点

- **只在状态同步模式**下发攻击；锁步模式的动作位未处理。
- 判定窗口是**按挥剑时长写死的**（0.10~0.40 秒），换动画/换武器要重调。
- 一次挥剑**只结算最近的一只**怪。
- 命中后**客户端没有任何反馈**（飘字/受击动画在 R020）。
- 剑的碰撞体必须 **Is Trigger**：非 Trigger 会在运行时被强制改并打一行日志（否则会推狼）。

### 修改维护注意事项

- **换玩家模型**：新模型要有一个名字含 `weapon_sword` 或 `hand_r` 的骨骼，否则打不到人（会静默留空，不崩）。
- **换武器/换动画**：同步改 `AttackWindowStart/End`，否则「挥到了却不判定」或「没挥到就判定」。
- **想让「附近有怪就能打」**：那是另一个需求（不要偷偷加兜底 —— 这正是本需求踩过的坑）。
- **别把动作编号改成别的**：服务端只认第 0 位。

## 三、踩坑清单（现象 / 原因 / 解决）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 按 J 没反应 | 从没 `TrackAction`，动作位恒 0 | 装配处登记动作 0 |
| 服务端日志「目标 0 不存在」 | `SendInput` 默认 `targetEntityId = 0` | 显式带目标 |
| **剑没碰到也算命中** | 我自己加的「回落最近怪」兜底 | 删掉，碰到才发 |
| 挥剑打不到 | 按下那帧采样，剑还没挥出 | 判定窗口 0.10~0.40 秒 |
| 剑把狼推走 | 剑碰撞体不是 Trigger | 运行时强制 Trigger |
| 剑上出现两个碰撞体 | 只认 `BoxCollider` | 按 `Collider` 基类复用 |
