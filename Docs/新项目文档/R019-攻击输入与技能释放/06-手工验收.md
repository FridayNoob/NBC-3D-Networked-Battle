## 三、异常场景

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| 剑没碰到也命中 | `FindSwordHitTarget()` 返回 0 时**回落「最近怪」** | 删掉兜底，改为「碰到才发」 |
| 按下那一帧采样，剑还收着 | 采样时机在挥剑之前 | 加判定窗口 `[0.10s, 0.40s)` |
| 非 Trigger 的剑会推狼 | 动态刚体被静态移动碰撞体挤开 | 运行时强制按 Trigger 用并打日志 |
| 只认 `BoxCollider` 会重复叠加 | 代码只 `GetComponent<BoxCollider>()` | 改成复用任意 `Collider` |

## 四、性能表现

- 每刀只在判定窗口内做**一次** `Physics.OverlapBox`，无掉帧。
