# 02 需求

需求：R019-攻击输入与技能释放
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-11-05）

## 一、业务目标（一句话）

**按 J 能打最近的怪**：角色播攻击动画、服务端扣血、日志能看到命中结果。

## 二、用户与使用场景

- 用户：开发期负责人；最终玩家。
- 场景：走到狼旁边按 J → 角色挥剑 → 狼掉血（服务端权威）→ Console 出现「普攻打中单位 X」。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| J 键登记为攻击动作 | P0 | `InputActionId.Declare(0,"Attack")` + `TrackAction` |
| 上行带目标 | P0 | 客户端选最近活怪（3 米内），命中由服务端裁决 |
| 本地播攻击动画 | P0 | `SetTrigger("ATTACK 1")` |
| 命中反馈（飘字/受击/数字） | P2 | 留给 R020 |
| 多技能 / 连招 / 技能条 | P2 | 不做 |
| 锁步模式攻击 | P2 | 不做（`SendLockstepInput` 的动作位是否处理未确认） |

## 四、边界（**本版明确不做**）

- 不改服务端与协议。
- 不做客户端预测命中（服务端说了算）。
- 不做冷却 UI / 按键提示 UI（Console 日志够用）。
- 不做目标锁定/切换（只打最近的）。

## 五、优先级

**P0**。依赖：R008（运行时会话）、R012/R013（移动）、R014（玩家动画控制器）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 站在怪 2 米内按 J 时，Console 应出现服务端的「普攻打中单位 X（N 点）」
- [ ] 当 按 J 时，本地角色应播**攻击动画**（挥剑）
- [ ] 当 周围没有怪时按 J，应**不发请求**（或服务端拒绝且有日志），本地不卡死
- [ ] 当 连续快速按 J 时，服务端应按冷却拒绝多余的攻击（日志可见），客户端不报错
- [ ] 当 移动/攻击交替时，两者都不应互相打断（移动仍正常）
