# 06 手工验收

需求编号：R042
所属阶段：M4
作者：AI（DeepSeek）
状态：待验收

## 一、计划

- 正常：清光怪 → 看到「胜利」面板 → 点「再来一次」→ 新一局能继续打。
- 异常：被怪打死 → 看到「失败」面板（不出现死亡黑幕）→ 点「返回世界」→ 回到 World 出生点。
- 边界：结果已经显示时再按 R / Esc；断线时面板的行为。
- 性能：面板出现时帧率不掉、Console 不刷屏。

## 二、正常流程走查

1) 启动服务端（`NBC.Server.Host.exe --dev-accounts`），Unity 进 Play，从 World 走到门口按 E 进副本。
2) 打光所有怪（可用控制台命令或直接打；BOSS 也算击杀）。
3) 预期：1 秒内弹出「胜利」面板，标题金色，下面一行 `用时 mm:ss · 击杀 N · 死亡 0`。
4) 点「再来一次」：预期黑屏一下 → 回到 Battle 场景 → 英雄满血、怪全部重生、可以继续打。
5) 再打一次，这次故意让怪打死自己。
6) 预期：弹出「失败」面板（不是死亡黑幕），数据行死亡数为 1。
7) 点「返回世界」：预期回到 World，角色站在出生点（村口），相机跟随正常。
8) 从门口再按 E：预期能重新进副本。

## 三、异常场景

1) 面板显示时按 R：等同点「再来一次」。
2) 面板显示时按 Esc：等同点「返回世界」。
3) 结果到达前就断线：不弹面板，玩家仍可用 Esc 退出副本（R049 已有），不应卡在黑屏或空场景。
4) 结果重复到达（理论上服务端只发一次）：面板不叠加、不重置。

## 四、性能

1) 面板出现瞬间不应有明显卡顿（一瞬间建 Canvas 属正常）。
2) Console 每次结算只应多两行：`收到**副本结算**：...` 与（点按钮后）场景切换日志。
