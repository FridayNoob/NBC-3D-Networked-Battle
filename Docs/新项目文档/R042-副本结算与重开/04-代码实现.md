## 二、功能概述

怪清光或英雄全灭时，服务端在这一帧把房间相位改成 `Finished`，并把「胜负 + 用时 + 击杀 + 死亡」广播给房里所有人；客户端收到后弹面板，两个按钮分别「再来一次」（退房、等半秒、重新进同一副本、重载 Battle）与「返回世界」（退房、把玩家挪回世界出生点、切回 World）。

## 三、接口与入参出参

见 03 第三节；实现与之逐字一致：

- `DungeonBattle.MonsterKills` / `HeroDeaths` / `ElapsedMs`：只读，循环 `_entities` 现算，不新增字段。
- `DungeonResults.Build(DungeonBattle) → DungeonResult`：纯函数，胜负判据 `AliveMonsterCount == 0`。
- `RoomBattleService.BroadcastDungeonResult(Room, DungeonBattle) → int`：返回成功发送份数。
- `NetSession.DungeonEnded`：`event Action<DungeonResult>`。
- `RuntimeNetDriver.RestartDungeon()` / `ReturnToWorld()`：无参无返回，内部起协程。
- `DungeonResultPanel.Ensure()` / `Show(DungeonResult, Action, Action)` / `Hide()` / 静态 `IsShowing`。

## 四、逐段讲解

1) **协议**：只加一个 message 与一个 oneof 分支（12 号），既有 1~11 号一个不动 ⇒ 旧客户端只是「不认识这个分支」，Protobuf 会忽略，不会崩。
2) **服务端数字现算**：没有新增 `KillCount++` 之类的状态，避免「漏加一处就少一个」；`_entities` 是唯一真源，击杀 = 怪总数 − 活着的怪。
3) **广播位置**：放在 `_recorded.Add` 成功之后、`BattleFinished` 订阅者判空之前 —— 探针环境没人订阅战绩也要让客户端收到结果；`_recorded` 保证每局只发一次。
4) **客户端事件链**：`NetSession` 只转事件，不弹 UI；驱动负责「弹面板 + 提供两个动作」，这样 UI 与网络层互不依赖。
5) **重开为什么等半秒**：`LeaveRoomRequest` 与 `JoinRoomRequest` 同一帧发出去，服务端可能按到达顺序判「你已经在房里」；等半秒让退房先落地。
6) **回世界为什么先挪人**：玩家物体是 `DontDestroyOnLoad` 的，切场景不会重置坐标；不挪就会停在副本坐标（World 里是空地外）。
7) **结算优先于死亡**：`DungeonResultPanel.Show` 里先 `DeathScreenOverlay.Hide()`，`PlayerDeathFlow.Update` 开头看到 `IsShowing` 直接返回 —— 两个流程不会抢屏。
8) **面板自建 EventSystem**：Battle 场景本来有 EventSystem，但为了在任意场景都能点按钮，`Show` 会检查并补一个。

### 5.1 服务端结果构建器

```csharp
// 这个文件里有：
//   DungeonResults：把一局副本的现状拼成结算消息（纯函数，不发送、不改房间）。

using NBC.Protocol;

namespace NBC.Server.Game;

/// <summary>
/// 副本结算构建器：把 DungeonBattle 的现状转换成下发给客户端的 DungeonResult。
/// 主要数据成员：两个结果常量 OutcomeWin / OutcomeLose（数值与协议约定一致）。
/// 主要外部方法：Build(battle)。
/// 谁在用它：RoomBattleService.RecordIfFinished（副本结束那一次），以及 _net-probe 的用例。
/// </summary>
public static class DungeonResults
{
    /// <summary>结算结果：胜（怪清光）。数值 1 与协议 DungeonResult.outcome 的约定一致。</summary>
    public const int OutcomeWin = 1;

    /// <summary>结算结果：负（英雄全灭）。数值 2 与协议约定一致。</summary>
    public const int OutcomeLose = 2;

    // 功能：把一局战斗的现状拼成结算消息。
    // 入参：battle 这一局的世界（调用方保证非空）。
    // 返回：可直接塞进 ServerMessage 的 DungeonResult。
    // 步骤：
    //   1) 怪物清光算胜，否则算负（与 RoomBattleService 的历史判据一致）
    //   2) 用时、击杀、死亡都从世界现算，不在别处另存一份
    // 上游/下游：RoomBattleService.RecordIfFinished 调用；不访问网络与数据库。
    public static DungeonResult Build(DungeonBattle battle)
    {
        return new DungeonResult
        {
            Outcome = battle.AliveMonsterCount == 0 ? OutcomeWin : OutcomeLose,
            DurationMs = battle.ElapsedMs,
            MonsterKills = battle.MonsterKills,
            HeroDeaths = battle.HeroDeaths,
        };
    }
}
```

### 5.2 客户端结算文案

```csharp
// 这个文件里有：
//   DungeonOutcomeText：把结算数字转成玩家能读的文字（纯函数，不碰 UI、不碰场景）。

using NBC.Protocol;

namespace NBC.Game.UI
{
    /// <summary>
    /// 结算文案工具：胜负标题、用时格式、统计一行字。
    /// 主要数据成员：两个结果常量 Win / Lose（数值与协议 DungeonResult.outcome 一致）。
    /// 主要外部方法：Title、FormatDuration、Stats。
    /// 谁在用它：DungeonResultPanel 画面板，EditMode 用例直接断言这三个函数。
    /// </summary>
    public static class DungeonOutcomeText
    {
        /// <summary>结算结果：胜（怪清光）。数值 1 与协议约定一致。</summary>
        public const int Win = 1;

        /// <summary>结算结果：负（英雄全灭）。数值 2 与协议约定一致。</summary>
        public const int Lose = 2;

        // 功能：把结果码转成标题。
        // 入参：outcome 服务端给的结果码。
        // 返回：胜利 / 失败 / 未知（不认识的码不抛异常，界面照常显示）。
        // 步骤：1 判胜、2 判负、其余统一给未知
        // 上游/下游：DungeonResultPanel.Show 调用。
        public static string Title(int outcome)
        {
            if (outcome == Win)
            {
                return "胜利";
            }

            if (outcome == Lose)
            {
                return "失败";
            }

            return "未知";
        }

        // 功能：把毫秒转成 mm:ss。
        // 入参：milliseconds 本局用时（毫秒；负数按 0 处理）。
        // 返回：形如 "01:23" 的字符串。
        // 步骤：负数先夹到 0，再分别算分钟与秒，两位补零
        // 上游/下游：Stats 拼接、DungeonResultPanel 显示。
        public static string FormatDuration(int milliseconds)
        {
            if (milliseconds < 0)
            {
                milliseconds = 0;
            }

            int totalSeconds = milliseconds / 1000;
            int minutes = totalSeconds / 60;
            int seconds = totalSeconds % 60;

            return minutes.ToString("00") + ":" + seconds.ToString("00");
        }

        // 功能：拼一行统计数据。
        // 入参：result 服务端结算（非空）。
        // 返回：形如 "用时 01:23 · 击杀 12 · 死亡 1"。
        // 步骤：三块数据各自格式化后用「 · 」连接，顺序固定便于验收比对
        // 上游/下游：DungeonResultPanel.Show 调用。
        public static string Stats(DungeonResult result)
        {
            return "用时 " + FormatDuration(result.DurationMs)
                 + " · 击杀 " + result.MonsterKills
                 + " · 死亡 " + result.HeroDeaths;
        }
    }
}
```

### 5.3 客户端结算面板

```csharp
// 这个文件里有：
//   DungeonResultPanel：副本结算面板（运行时 UGUI，胜/负 + 数据 + 两个按钮）。

using System;
using NBC.Protocol;
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.UI;

namespace NBC.Game.UI
{
    /// <summary>
    /// 副本结算面板：一局结束后显示胜负与数据，并给出「再来一次」「返回世界」两个动作。
    /// 主要数据成员：m_canvas / m_title / m_stats / m_hint 与两个按钮的回调。
    /// 主要外部方法：静态 Ensure、Show、Hide、静态 IsShowing。
    /// 谁在用它：RuntimeNetDriver 收到 DungeonResult 后调用；PlayerDeathFlow 靠 IsShowing 让位。
    /// </summary>
    public sealed class DungeonResultPanel : MonoBehaviour
    {
        // 运行时建的面板放在这个物体上，名字带中括号表示「系统生成」
        private const string PanelObjectName = "[DungeonResultPanel]";

        // 画布层级：比死亡黑幕（900）高，结算永远压在最上面
        private const int CanvasSortingOrder = 950;

        // 背景透明度：比死亡黑幕淡一点，能看出后面是战场
        private const float BackgroundAlpha = 0.72f;

        // 内置字体名（Unity 2022 起 Arial.ttf 改叫 LegacyRuntime.ttf）
        private const string BuiltinFontName = "LegacyRuntime.ttf";

        // 兜底字体名（老版本 Unity 还叫这个名字）
        private const string LegacyBuiltinFontName = "Arial.ttf";

        private static DungeonResultPanel s_instance;

        private Canvas m_canvas;
        private Text m_title;
        private Text m_stats;
        private Text m_hint;
        private Action m_onRestart;
        private Action m_onReturn;

        /// <summary>面板现在是不是显示着（死亡流程用它判断要不要让位）。</summary>
        public static bool IsShowing { get; private set; }

        // 功能：拿到（没有就创建）面板单例。
        // 入参：无。
        // 返回：场景里唯一的面板。
        // 步骤：1) 先找场景里已有的 2) 没有就新建一个带中括号名字的物体挂本组件
        // 上游/下游：RuntimeNetDriver 收到结算时调用；DungeonResultPanel.Awake 里 Build。
        public static DungeonResultPanel Ensure()
        {
            if (s_instance != null)
            {
                return s_instance;
            }

            DungeonResultPanel existing = FindObjectOfType<DungeonResultPanel>();

            if (existing != null)
            {
                s_instance = existing;
                return s_instance;
            }

            GameObject go = new GameObject(PanelObjectName);
            s_instance = go.AddComponent<DungeonResultPanel>();
            return s_instance;
        }

        // 功能：显示结算。
        // 入参：result 服务端结算；onRestart 点「再来一次」要做什么；onReturn 点「返回世界」要做什么。
        // 返回：无。
        // 步骤：
        //   1) 记下两个回调，并把数据写进文字
        //   2) 先关死亡黑幕（结算优先，不让「你已倒下」压在上面）
        //   3) 打开整块画布、解锁鼠标（要能点按钮）
        // 上游/下游：RuntimeNetDriver 的事件回调；下游 DeathScreenOverlay.Hide。
        public void Show(DungeonResult result, Action onRestart, Action onReturn)
        {
            if (result == null)
            {
                return;
            }

            BuildIfNeeded();
            EnsureEventSystem();

            m_onRestart = onRestart;
            m_onReturn = onReturn;

            m_title.text = DungeonOutcomeText.Title(result.Outcome);
            m_title.color = result.Outcome == DungeonOutcomeText.Win
                ? new Color(1f, 0.86f, 0.35f)
                : new Color(0.95f, 0.42f, 0.38f);
            m_stats.text = DungeonOutcomeText.Stats(result);
            m_hint.text = "R 再来一次    Esc 返回世界";

            DeathScreenOverlay.Ensure().Hide();

            m_canvas.gameObject.SetActive(true);
            IsShowing = true;

            Cursor.lockState = CursorLockMode.None;
            Cursor.visible = true;
        }

        // 功能：关掉面板。
        // 入参：无。
        // 返回：无。
        // 步骤：关整块画布（只关背景会留下文字）、清回调、复位显示标记
        // 上游/下游：两个按钮与快捷键；RuntimeNetDriver 切场景前也可调。
        public void Hide()
        {
            if (m_canvas != null)
            {
                m_canvas.gameObject.SetActive(false);
            }

            m_onRestart = null;
            m_onReturn = null;
            IsShowing = false;
        }

        // 功能：初始化时把画布建好（只建一次）。
        // 入参：无。
        // 返回：无。
        // 步骤：确保单例指向自己，然后 Build
        // 上游：Unity 生命周期。
        // 下游：Build。
        private void Awake()
        {
            s_instance = this;
            BuildIfNeeded();
        }

        // 功能：面板显示时响应快捷键（R 再来一次，Esc 返回世界）。
        // 入参：无。
        // 返回：无。
        // 步骤：只在显示时处理；先判空再 Invoke，回调里可能把面板关掉
        // 上游：Unity 生命周期。
        // 下游：m_onRestart / m_onReturn。
        private void Update()
        {
            if (!IsShowing)
            {
                return;
            }

            if (Input.GetKeyDown(KeyCode.R))
            {
                Action action = m_onRestart;

                if (action != null)
                {
                    action();
                }
            }
            else if (Input.GetKeyDown(KeyCode.Escape))
            {
                Action action = m_onReturn;

                if (action != null)
                {
                    action();
                }
            }
        }

        // 功能：第一次用到时把画布与控件建出来。
        // 入参：无。
        // 返回：无。
        // 步骤：已经建过就直接返回，避免重复建
        // 上游/下游：Awake 与 Show 调用；下游 Build。
        private void BuildIfNeeded()
        {
            if (m_canvas != null)
            {
                return;
            }

            Build();
        }

        // 功能：建画布、背景、三行文字、两个按钮。
        // 入参：无。
        // 返回：无。
        // 步骤：
        //   1) 建 ScreenSpaceOverlay 画布并设层级（压过死亡黑幕）
        //   2) 建全屏半透明背景
        //   3) 建标题、统计、提示三行字
        //   4) 建两个按钮，点击分别走「再来一次」「返回世界」
        //   5) 先关掉整块画布，等 Show 再打开
        // 上游/下游：BuildIfNeeded 调用；下游 CreateText / CreateButton。
        private void Build()
        {
            GameObject canvasObject = new GameObject("Canvas");
            canvasObject.transform.SetParent(transform, false);

            m_canvas = canvasObject.AddComponent<Canvas>();
            m_canvas.renderMode = RenderMode.ScreenSpaceOverlay;
            m_canvas.sortingOrder = CanvasSortingOrder;

            CanvasScaler scaler = canvasObject.AddComponent<CanvasScaler>();
            scaler.uiScaleMode = CanvasScaler.ScaleMode.ScaleWithScreenSize;
            scaler.referenceResolution = new Vector2(1920f, 1080f);

            canvasObject.AddComponent<GraphicRaycaster>();

            GameObject background = new GameObject("Background");
            background.transform.SetParent(canvasObject.transform, false);

            RectTransform backgroundRect = background.AddComponent<RectTransform>();
            backgroundRect.anchorMin = Vector2.zero;
            backgroundRect.anchorMax = Vector2.one;
            backgroundRect.offsetMin = Vector2.zero;
            backgroundRect.offsetMax = Vector2.zero;

            Image backgroundImage = background.AddComponent<Image>();
            backgroundImage.color = new Color(0f, 0f, 0f, BackgroundAlpha);
            backgroundImage.raycastTarget = true;

            m_title = CreateText(canvasObject.transform, "Title", 108, new Vector2(0f, 220f), new Vector2(1600f, 160f));
            m_stats = CreateText(canvasObject.transform, "Stats", 46, new Vector2(0f, 70f), new Vector2(1600f, 100f));
            m_hint = CreateText(canvasObject.transform, "Hint", 34, new Vector2(0f, -300f), new Vector2(1600f, 80f));

            CreateButton(canvasObject.transform, "RestartButton", "再来一次", new Vector2(-220f, -140f), OnRestartClicked);
            CreateButton(canvasObject.transform, "ReturnButton", "返回世界", new Vector2(220f, -140f), OnReturnClicked);

            m_canvas.gameObject.SetActive(false);
        }

        // 功能：点「再来一次」时转发给外部回调。
        // 入参：无。
        // 返回：无。
        // 步骤：直接 Invoke 记下的回调（回调由 RuntimeNetDriver 提供）
        // 上游/下游：按钮点击；下游 m_onRestart。
        private void OnRestartClicked()
        {
            Action action = m_onRestart;

            if (action != null)
            {
                action();
            }
        }

        // 功能：点「返回世界」时转发给外部回调。
        // 入参：无。
        // 返回：无。
        // 步骤：直接 Invoke 记下的回调
        // 上游/下游：按钮点击；下游 m_onReturn。
        private void OnReturnClicked()
        {
            Action action = m_onReturn;

            if (action != null)
            {
                action();
            }
        }

        // 功能：场景里没有 EventSystem 时补一个（否则按钮点不动）。
        // 入参：无。
        // 返回：无。
        // 步骤：找现有 EventSystem，没有就建一个空物体挂 EventSystem + StandaloneInputModule
        // 上游/下游：Show 调用。
        private static void EnsureEventSystem()
        {
            if (EventSystem.current != null)
            {
                return;
            }

            GameObject go = new GameObject("[EventSystem]");
            go.AddComponent<EventSystem>();
            go.AddComponent<StandaloneInputModule>();
        }

        // 功能：建一段居中文字。
        // 入参：parent 父节点；name 物体名；fontSize 字号；anchoredPosition 相对屏幕中心的位置；size 文本框尺寸。
        // 返回：建好的 Text。
        // 步骤：1) 建空物体并设居中锚点 2) 挂 Text 设字体字号对齐 3) 关掉射线检测
        // 上游/下游：Build 调用；下游 LoadBuiltinFont。
        private static Text CreateText(Transform parent, string name, int fontSize, Vector2 anchoredPosition, Vector2 size)
        {
            GameObject go = new GameObject(name);
            go.transform.SetParent(parent, false);

            RectTransform rect = go.AddComponent<RectTransform>();
            rect.anchorMin = new Vector2(0.5f, 0.5f);
            rect.anchorMax = new Vector2(0.5f, 0.5f);
            rect.pivot = new Vector2(0.5f, 0.5f);
            rect.anchoredPosition = anchoredPosition;
            rect.sizeDelta = size;

            Text text = go.AddComponent<Text>();
            text.font = LoadBuiltinFont();
            text.fontSize = fontSize;
            text.alignment = TextAnchor.MiddleCenter;
            text.color = Color.white;
            text.raycastTarget = false;
            text.horizontalOverflow = HorizontalWrapMode.Overflow;
            text.verticalOverflow = VerticalWrapMode.Overflow;
            return text;
        }

        // 功能：建一个按钮（底色 + 文字 + 点击回调）。
        // 入参：parent 父节点；name 物体名；label 按钮文字；anchoredPosition 位置；onClick 点击回调。
        // 返回：建好的按钮。
        // 步骤：1) 建带 RectTransform 的物体并挂 Image 当底 2) 挂 Button 并设目标图 3) 建子文字 4) 绑点击
        // 上游/下游：Build 调用。
        private static Button CreateButton(Transform parent, string name, string label, Vector2 anchoredPosition, Action onClick)
        {
            GameObject go = new GameObject(name);
            go.transform.SetParent(parent, false);

            RectTransform rect = go.AddComponent<RectTransform>();
            rect.anchorMin = new Vector2(0.5f, 0.5f);
            rect.anchorMax = new Vector2(0.5f, 0.5f);
            rect.pivot = new Vector2(0.5f, 0.5f);
            rect.anchoredPosition = anchoredPosition;
            rect.sizeDelta = new Vector2(320f, 96f);

            Image image = go.AddComponent<Image>();
            image.color = new Color(0.22f, 0.26f, 0.34f, 0.95f);

            Button button = go.AddComponent<Button>();
            button.targetGraphic = image;
            button.onClick.AddListener(delegate { onClick(); });

            Text text = CreateText(go.transform, "Label", 40, Vector2.zero, new Vector2(300f, 80f));
            text.text = label;

            return button;
        }

        // 功能：取一个内置字体给 UGUI 用。
        // 入参：无。
        // 返回：内置字体；两个名字都取不到时返回 null（文字不显示，但不会崩）。
        // 步骤：先试 LegacyRuntime.ttf，再试 Arial.ttf。
        // 上游/下游：CreateText 调用。
        private static Font LoadBuiltinFont()
        {
            Font font = Resources.GetBuiltinResource<Font>(BuiltinFontName);
```

## 十、返修（2026-11-16）：左键不发攻击请求 + 死亡检测被 FindHero 吞掉

06 验收时负责人报两个现象，都不是结算代码本身的问题，但都在这一版暴露：

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 进副本后攻击怪不掉血 | 网络层的攻击动作只绑了 `J`（`HpBarDemoBehaviour.m_attackKey`）；玩家用鼠标左键时 `PlayerBrain` 会本机播动画，但 `InputCommand.ActionBits` 永远是 0，服务端收不到攻击 | `InputMapping` 增加「备用键」；普攻主键仍是 `m_attackKey`，备用键绑 `KeyCode.Mouse0` |
| 血量掉光没有黑幕、角色也不倒 | `SnapshotView.FindHero` **只返回活着的英雄**（`e.Alive` 判断）；英雄一死它就返回 null，`TrackHeroHealth(null)` 提前 return，`HeroAlive` 永远停在 true ⇒ `PlayerDeathFlow.IsDeadNow()` 永远 false | 驱动自己按 `OwnerPlayerId` 扫快照（含已倒下），改成 `FindMyHeroSnapshot()`；不再用 `FindHero` |
