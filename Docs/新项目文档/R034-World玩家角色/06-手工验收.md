# 06 手工验收

需求：R034-World 玩家角色（本地可操控）
所属阶段：M4
作者：AI（计划）／LYF（实测）　状态：待确认（2026-11-13）

## 一、测试计划

- 目标：World 里能用 WASD 走动、相机跟随、人贴地形。
- 前置：场景已接线（`[Player_Hero]` + 剑士模型 + PlayerMove + WorldPlayerSetup；Main Camera 挂 FollowCamera）。

## 二、操作步骤

1. 打开 `Assets/_Project/Scenes/World.unity` → **Play**。
2. 等环境加载完（Console 有 `[WorldEnvLoader] 已叠加环境 …`）。
   - 期望：看到剑士站在场景里；Console 有 `[WorldPlayerSetup] 玩家已就位`。
3. 按 **W/A/S/D**：角色应移动并转向对应方向。
4. 观察相机：应平滑跟在他身后上方（不是瞬移、不是一个固定视角）。
5. 走到**坡地/台阶**：人不应该浮空或陷进地面。
6. 按 **Ctrl+Shift+1** 回 Login，再 **Ctrl+Shift+2** 回 World：玩家应重新出现。
