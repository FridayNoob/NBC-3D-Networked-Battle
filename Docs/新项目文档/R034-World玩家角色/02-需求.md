# 02 需求

需求：R034-World 玩家角色（本地可操控）
所属阶段：M4
作者：AI 起草／LYF 确认　状态：待确认（2026-11-13）

## 一、业务目标（一句话）

**进 World 就能用 WASD 操控角色在森林里走**，相机跟着他，人物贴着地面。

## 二、用户与场景

- 用户：玩家（登录后进 World，第一件事是"能走"）。
- 场景：Play World → 看到剑士站在出生点 → 按 W 往前走 → 相机平滑跟随 → 走到坡地上人不浮空。

## 三、功能列表

| # | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 1 | WASD 移动 + 四向转身 | P0 | 复用 `PlayerMove` |
| 2 | 相机跟随 | P0 | 复用 `FollowCamera`，运行时绑定 |
| 3 | 有玩家时关掉观察相机 | P0 | 防两套相机打架 |
| 4 | 贴地（地形起伏） | P0 | 向下射线取地面高度 |
| 5 | 出生点可配 | P1 | 场景里摆位置即可 |
| 6 | 走路动画 | P2 | 需要 Animator 参数匹配，下一版 |
| 7 | 碰撞（不穿树/墙） | P2 | 需要 CharacterController，下一版 |

## 四、边界（本版明确不做）

- 不连服务端（不做网络同步、不做其他玩家）。
- 不做战斗/攻击/技能。
- 不做碰撞与重力（能穿物件；贴地靠射线）。
- 不复用 Battle 的胶囊占位（用真实模型）。

## 五、优先级

**P0**。依赖：R033（World 场景与环境叠加）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 Play World 时，应能看到一个剑士角色站在出生点
- [ ] 当 按 W/A/S/D 时，角色应移动并转向对应方向
- [ ] 当 角色移动时，相机应平滑跟随（不是瞬移、不是不跟）
- [ ] 当 角色走到坡上时，应贴着地面（不浮空、不陷地）
- [ ] 当 有玩家时，观察相机应被关闭（不会出现两个视角）
- [ ] 当 Console 时，应有 `[WorldPlayerSetup] 玩家已就位` 日志
