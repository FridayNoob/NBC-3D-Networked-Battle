## 四、时序

1. `World` 启动 → `WorldPlayerSetup.Start`：玩家 = 自己；关观察相机；`FollowCamera.SetTarget(玩家)`。
2. 每帧 `PlayerMove.Update`：读输入 → 转身 → 位移。
3. 每帧 `WorldPlayerSetup.LateUpdate`：从玩家上方 5 米向下打射线 → 命中地面则把 y 设为命中点。
4. 每帧 `FollowCamera.LateUpdate`：平滑跟到 `玩家 + 偏移`。

## 五、选型与理由

| 选择 | 理由 | 被否方案 |
| --- | --- | --- |
| 复用 `PlayerMove` | 已有四向转身/输入量化 | 重写一套（违反 §6.1-1） |
| `LateUpdate` 里贴地 | 在移动之后修正 y，避免"先贴地再移动"导致的抖动 | `Update` 里做（顺序不稳） |
| 射线贴地而非 Rigidbody | 环境是静态地形，射线最省事 | 加刚体重力（会与 PlayerMove 打架） |
| 相机用 `SetTarget` 而不是反射 | 反射脆、且违反可读性 | 用 `SerializedObject` 改私有字段 |

## 七、风险与对策

| 风险 | 对策 |
| --- | --- |
| 玩家卡在模型里/穿模 | 本版先不做碰撞；下一版加 CharacterController |
| 地形外的空地没有碰撞体 | 射线打不到就不改 y（保持原高度） |
| 两套相机打架 | 有玩家就关观察相机 |
| 模型朝向与移动方向不符 | 先在场景里看；不对再加朝向偏移（与狼同理） |
