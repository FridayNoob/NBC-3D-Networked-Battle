# 01 技术预研

需求：R033-World 场景与环境叠加
所属阶段：M4
作者：AI　状态：待确认（2026-11-13）

## 一、调研目标与约束

- 目标：让 `World.unity` 看起来像"开放世界的一块地"，做法是**叠加**美术包自带的 `SampleScene`，而不是把它复制成 World。
- 约束：
  1. 不改美术包文件（`Art/Scenes` 被 gitignore，改了下一次导入会丢）；
  2. 149MB 场景不进 `_Project/Scenes`（否则会进 git）；
  3. 不碰服务端（World 先本地）。

## 二、核心事实（实测）

| 项 | 值 | 出处 |
| --- | --- | --- |
| 环境场景 | `Art/Scenes/StylizedEnvironement/Demo/_ShowcaseScene/SampleScene.unity` | 文件系统 |
| 体积 | **149 MB / 281 万行** | 文件大小 |
| 依赖 | 493 个资源（140 prefab / 56 材质 / 29 含 Terrain） | `AssetDatabase.GetDependencies` |
| 自带组件 | Camera 1、AudioListener 1、Directional Light 1、Terrain+TerrainCollider 1、MeshCollider 52、ReflectionProbe 29、LODGroup 9、素材脚本 4 | 场景 YAML 统计 |
| 玩家/我们的系统 | **0** | 同上 |

## 三、方案对比

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| A. 复制成 World.unity | 最快 | 149MB 进 git；素材更新难合并；加载慢 | 否 |
| **B. World 轻量 + Additive 叠加** | 层分离；大文件不进 git；以后换环境只换子场景 | 要处理相机/灯光冲突 | **采用** |
| C. 挑物件复制 | 最轻 | 124 个对象手工挑 | 暂不做 |

## 四、冲突与处理（本需求核心）

| 冲突 | 现象 | 处理 |
| --- | --- | --- |
| AudioListener ×2 | Console 红字「2 audio listeners」+ 3D 音效定位错乱 | 关掉环境场景的 |
| Camera ×2 | 重复渲染掉帧、画面闪烁 | 关掉环境场景的 |
| Directional Light ×2 | 过曝、双阴影、阴影贴图开销翻倍 | 只关**平行光**，点光/聚光（火把）保留 |
| 素材脚本改 RenderSettings | 天空盒/雾被覆盖，查不到原因 | 本版不处理，记入风险 |

## 五、已知坑

1. **Additive 加载要求场景在 Build Settings**：环境场景已追加进 Build Settings（第 6 个，enabled）。
2. **YooAsset 无法加载它**：它不在收集器路径里；本需求用 `SceneManager` 加载环境子场景，逻辑场景 World 仍走自己的门。
3. **29 个 Reflection Probe**：内存与首帧开销明显，后续可按需裁剪。
4. **加载完成前不能猜场景有效**：必须 `GetSceneByName` 后再判 `isLoaded`。
5. **只关不删**：素材包文件保持原样，换包不受影响。

## 六、结论与改动清单

- 新增 `WorldEnvLoader`（叠加加载 + 关冲突组件）
- 新增 `WorldOrbitCamera`（看环境用；右键转视角、滚轮缩放、WASD 平移）
- World 场景：加 `[WorldEnvLoader]`、给 Main Camera 挂 `WorldOrbitCamera`
- Build Settings：追加环境场景
