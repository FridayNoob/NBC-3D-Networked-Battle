## 一、整体架构

```
World.unity（逻辑层，进 git）
 ├─ Main Camera（挂 WorldOrbitCamera）
 ├─ Directional Light（我们的主光）
 └─ [WorldEnvLoader] ──Additive──▶ SampleScene（环境层，149MB，gitignore）
                                        │ 加载完成后
                                        └─ 禁用 Camera / AudioListener / 平行光
```

## 四、时序

1. World 场景启动 → `[WorldEnvLoader].Start` 起协程。
2. `SceneManager.LoadSceneAsync(envName, Additive)` → 轮询 `isDone`。
3. `GetSceneByName` 校验 `IsValid && isLoaded`。
4. 遍历根物体：禁用 `Camera`、`AudioListener`、`LightType.Directional`。
5. 打日志 `已叠加环境 X，关掉冲突组件 N 个`。

## 五、选型与理由

| 选择 | 理由 | 被否方案 |
| --- | --- | --- |
| Additive 叠加 | 149MB 不进 git；层分离 | 复制成 World（进 git、难合并） |
| 运行时禁用 | 不改素材包、换包不丢 | 删场景里的相机（升级覆盖） |
| 只关平行光 | 火把/点光当氛围，保住画面 | 全关灯（环境变死黑） |
| SceneManager 而非 YooAsset | 环境不在收集器里；本版先跑通 | 硬塞收集器（改动大） |
