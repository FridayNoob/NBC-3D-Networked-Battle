# 02 需求

需求：R033-World 场景与环境叠加
所属阶段：M4
作者：AI 起草／LYF 确认　状态：待确认（2026-11-13）

## 一、业务目标（一句话）

**进 World 就能看到真实环境**：World 场景只放逻辑，环境从美术包的样板场景叠加进来。

## 二、用户与场景

- 用户：玩家（登录后进 World，看到地形/房子/道具，能用鼠标键盘观察）。
- 场景：Play `World.unity` → 几秒内出现环境 → 右键拖动看四周 → 滚轮拉近拉远。

## 三、功能列表

| # | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 1 | 叠加加载环境子场景 | P0 | `SceneManager.LoadSceneAsync(Additive)` |
| 2 | 关掉环境自带的相机 | P0 | 防重复渲染 |
| 3 | 关掉环境的 AudioListener | P0 | 只允许一个 |
| 4 | 关掉环境的平行光 | P0 | 防过曝/双阴影；点光保留 |
| 5 | 观察相机（右键转、滚轮缩、WASD 平移） | P0 | 还没有角色，先能看 |
| 6 | 加载结果日志（关掉几个） | P1 | 排查用 |
| 7 | 环境加载进度条 | P2 | 后续和过场一起做 |

## 四、边界（本版明确不做）

- 不做玩家角色与网络（下一需求）。
- 不改环境场景文件（只运行时禁用组件）。
- 不裁 Reflection Probe（只记录开销）。
- 不处理素材脚本改 RenderSettings（记风险，后续按需关）。

## 五、优先级

**P0**。依赖：环境场景在 Build Settings（已加）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 Play `World.unity` 时，应看到地形/房屋/道具（不是空场景）
- [ ] 当 环境加载完成时，Console 应打印「关掉冲突组件 N 个」
- [ ] 当 出现两个相机时，应只有我们的 Main Camera 在渲染（环境相机被禁用）
- [ ] 当 场景里有 2 个 AudioListener 时，应被关到只剩 1 个（Console 无红字）
- [ ] 当 环境自带平行光被关掉时，画面亮度应正常（不过曝）
- [ ] 当 右键拖动/滚轮/ WASD 时，相机应能自由观察
- [ ] 当 环境场景名写错时，Console 应有明确错误（不是黑屏）
