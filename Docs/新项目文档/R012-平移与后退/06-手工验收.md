## 二、正常流程走查（**经过两轮修订才定稿**）

| 轮次 | 负责人的反馈 | 处理 |
| --- | --- | --- |
| 第 1 轮 | 「S 应该后退而不是转向之后前进，A 往左 D 往右而不是转向然后前进」 | 改成「朝向不变 + 本地平移 + S 负 Speed」 |
| 第 2 轮 | 「禁止斜着走」 | 改成主导轴（相等时前后优先） |
| 第 3 轮 | 「按 A/D 角色应面朝左/右跑动，角色转向时摄像机始终不会跟着转向」 | 恢复 W/A/D 转身；`FollowCamera` 偏移改为世界固定 |
| 最终 | **「这下对了」** | 通过 |

## 三、异常场景

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 按 A/D 时**镜头跟着转** | `FollowCamera` 用 `m_target.rotation * m_offset` | 改成 `m_target.position + m_offset`（世界固定偏移） |
| 按 S 播成「向前走」 | 只喂了速度大小，没喂符号 | `Speed` 改喂带符号的前后分量 |
| 斜着按两键会斜走 | 只做了归一化，没有禁止 | 改主导轴，只输出四种方向 |
| 转身瞬间走弧线 | 位移沿「当前朝向」 | 位移改用「目标方向」 |
