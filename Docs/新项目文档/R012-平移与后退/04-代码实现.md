# 04 代码实现

需求：R012-平移与后退（四向移动 + 镜头不跟随转身）
所属阶段：M4
作者：AI（三个脚本，Controller 与 prefab 零改动）　状态：已确认（2026-10-28，第 3 版验收通过）

## 一、子任务与设计约束

- 本单元：`PlayerMove`（四向 + W/A/D 转身 + S 倒退）、`PlayerAnimation`（双参数归一化）、`FollowCamera`（世界固定偏移）。
- 约束：禁止斜向；A/D 转身后前进；**镜头不跟随转身**；不改 Controller / prefab。

## 二、功能概述

`PlayerMove` 把输入压成 W/A/S/D 之一：W/A/D 先转身（限速）再沿目标方向前进，S 保持朝向沿反方向后退；
位移后拆出前后 / 左右分量。`PlayerAnimation` 归一化后喂 `Speed` / `Direction`。
`FollowCamera` 用世界固定偏移跟位置、`LookAt` 角色胸口，方向永不改变。

## 三、接口与入参出参

| 单元 | 入参 | 出参 | 异常 |
| --- | --- | --- | --- |
| `PlayerMove.ForwardSpeed` | — | float，米/秒（W 正 / S 负） | 不抛 |
| `PlayerMove.SideSpeed` | — | float，米/秒（转身瞬间短暂非零） | 不抛 |
| `PlayerMove.MoveSpeed` | — | float，归一化分母 | 不抛 |
| `PlayerAnimation.LateUpdate` | — | 写 `Speed` / `Direction` | 参数缺失时 `Awake` 报错并停用 |
| `FollowCamera.LateUpdate` | — | 改相机 `position` / 朝向 | Target 为空时直接返回 |

## 四、逐段讲解

1. **`forwardWins = |z| >= |x|`**：等于号让两轴相等时走前后 —— 即「禁止斜向」的规则。
2. **`backpedal = forwardWins && z < 0`**：只有 S 走「不转身」分支；W/A/D 都会转身。
3. **位移用 `targetDirection` 而不是 `transform.forward`**：转身需要 0.125 秒，若按当前朝向前进会走出弧线。
4. **`RotateTowards` 限速**：转向不会瞬移；`m_turnSpeed = 720` 度/秒 ⇒ 90° 约 0.125 秒。
5. **S 用 `-transform.forward`**：实测前后分量为负 ⇒ Controller 进 `WalkBack`。
6. **相机 `m_target.position + m_offset`**：偏移不乘旋转 ⇒ 角色转身时镜头方向恒定（需求原话「镜头始终不会跟着转向」）。
7. **两参数都 ÷ `m_moveSpeed`**：全速 = ±1，与 Controller 阈值同量纲；`divisor` 为 0 时兜底 1，避免 `NaN`。

```csharp
// 这个文件里有：
//   PlayerMove（类）：W 前进、S 倒退、A/D 转身朝左/右再前进；不斜走，朝向只由 A/D/W 决定

using NBC.Framework.Input;
using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧读输入，取主导轴得到 W/A/S/D 四种之一：W 面朝前走、A/D 先转身再前进、S 保持朝向倒退。
    // 主要数据成员：m_moveSpeed（米/秒）、m_turnSpeed（度/秒）、m_forwardSpeed / m_sideSpeed（给动画的分量）。
    // 主要外部方法：ForwardSpeed / SideSpeed / MoveSpeed / CurrentSpeed（只读属性）。
    // 谁在用它：挂在角色物体上；输入取自 InputManager.Instance.Current，键位在 InputMapping 里可改。
    public sealed class PlayerMove : MonoBehaviour
    {
        // 每秒走多少米。场景里 1 单位 = 1 米，5 就是每秒 5 米
        [SerializeField] private float m_moveSpeed = 5f;

        // 转身速度，度/秒。720 约等于 0.125 秒转 90 度
        [SerializeField] private float m_turnSpeed = 720f;

        // 前后分量，米/秒：W 为正、S 为负
        private float m_forwardSpeed;

        // 左右分量，米/秒：转身后基本为 0（留着给以后侧移用）
        private float m_sideSpeed;

        // 合速度，米/秒（≥ 0），给 HUD 之类用
        private float m_currentSpeed;

        // 入参：无
        // 返回：前后速度，米/秒（W 正、S 负）
        // 上游：PlayerAnimation
        // 下游：无
        public float ForwardSpeed
        {
            get { return m_forwardSpeed; }
        }

        // 入参：无
        // 返回：左右速度，米/秒（转身时会有短暂非零）
        // 上游：PlayerAnimation
        // 下游：无
        public float SideSpeed
        {
            get { return m_sideSpeed; }
        }

        // 入参：无
        // 返回：配置的移动速度，米/秒（给动画做归一化的分母）
        // 上游：PlayerAnimation
        // 下游：无
        public float MoveSpeed
        {
            get { return m_moveSpeed; }
        }

        // 入参：无
        // 返回：合速度，米/秒（≥ 0）
        // 上游：HUD / 调试
        // 下游：无
        public float CurrentSpeed
        {
            get { return m_currentSpeed; }
        }

        // 入参：无（引擎每帧调用）
        // 返回：无
        // 步骤：
        //   1) 三个速度先清 0；提前 return 的分支不会残留上一帧的值
        //   2) 取 InputManager；把量化轴还原成 -1..1（x 左右、z 前后）
        //   3) 取主导轴：|z| >= |x| 用前后，否则用左右 ⇒ 只有四种方向，不斜走
        //   4) 按四种情况决定「朝向」与「位移方向」：
        //        W（z>0）  ：朝向 = 世界前方，沿该方向前进
        //        A（x<0）  ：朝向 = 世界左方，转身后沿该方向前进
        //        D（x>0）  ：朝向 = 世界右方，转身后沿该方向前进
        //        S（z<0）  ：朝向不变，沿 -当前朝向 倒退
        //   5) 转身用 RotateTowards 限速（0.125 秒转 90 度），位移用「目标方向」而不是当前朝向，避免转弯时走弧线
        //   6) 位移后按 forward / right 点乘，拆出前后 / 左右分量
        // 上游：Unity 引擎每帧调用
        // 下游：InputManager.Current、Transform.rotation、Transform.position
        // 注意：A/D 会转身、S 不会 —— 这三条是负责人在 2026-10-28 明确要求的
        private void Update()
        {
            m_forwardSpeed = 0f;
            m_sideSpeed = 0f;
            m_currentSpeed = 0f;

            InputManager input = InputManager.Instance;

            if (input == null || !input.IsEnabled)
            {
                return;
            }

            InputCommand command = input.Current;

            float x = (float)command.MoveX / InputCommand.MoveScale;
            float z = (float)command.MoveY / InputCommand.MoveScale;

            if (Mathf.Abs(x) < 0.0001f && Mathf.Abs(z) < 0.0001f)
            {
                return;
            }

            bool forwardWins = Mathf.Abs(z) >= Mathf.Abs(x);
            bool backpedal = forwardWins && z < 0f;

            // 目标是世界坐标的四个基本方向之一
            Vector3 targetDirection = forwardWins
                ? new Vector3(0f, 0f, Mathf.Sign(z))
                : new Vector3(Mathf.Sign(x), 0f, 0f);

            Vector3 moveDirection;

            if (backpedal)
            {
                // 后退：不改朝向，沿「当前朝向的反方向」走 ⇒ 动画会进 WalkBack
                moveDirection = -transform.forward;
            }
            else
            {
                // 前进 / 左 / 右：先转身朝目标方向（限速），位移仍用目标方向，避免边走边转出弧线
                Quaternion targetRotation = Quaternion.LookRotation(targetDirection, Vector3.up);
                transform.rotation = Quaternion.RotateTowards(
                    transform.rotation, targetRotation, m_turnSpeed * Time.deltaTime);

                moveDirection = targetDirection;
            }

            Vector3 before = transform.position;
            transform.position += moveDirection * (m_moveSpeed * Time.deltaTime);

            float dt = Time.deltaTime;
            if (dt <= 0f)
            {
                return;
            }

            Vector3 moved = transform.position - before;

            // 实测位移拆成前后 / 左右：以后加碰撞，被挡住时这两个值会自然变小
            m_forwardSpeed = Vector3.Dot(moved, transform.forward) / dt;
            m_sideSpeed = Vector3.Dot(moved, transform.right) / dt;
            m_currentSpeed = moved.magnitude / dt;
        }
    }
}
```

`Client/Assets/_Project/Game/Player/PlayerAnimation.cs`

```csharp
// 这个文件里有：
//   PlayerAnimation（类）：把角色的前后 / 左右速度喂给 Animator 的 Speed 与 Direction 参数

using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧读 PlayerMove 的 ForwardSpeed / SideSpeed，各自除以移动速度归一化成 -1..1，
    //           写进 Animator 的 Speed（带符号，负=后退）与 Direction（-1 左 / +1 右）。
    // 主要数据成员：m_animator（目标 Animator）、m_damping（平滑时间）、m_move（同物体上的 PlayerMove）。
    // 主要外部方法：无，只有 Unity 的 LateUpdate 回调。
    // 谁在用它：和 PlayerMove 一起挂在角色物体上；状态与过渡全在 Animator Controller 里配。
    [RequireComponent(typeof(PlayerMove))]
    public sealed class PlayerAnimation : MonoBehaviour
    {
        // 前后参数：正值 = 前进，负值 = 后退（Controller 里 Speed < -0.1 会进 WalkBack）
        public const string SpeedParameter = "Speed";

        // 侧移参数：Controller 里是 1D 混合，-1 左移 / 0 前进 / +1 右移
        public const string DirectionParameter = "Direction";

        // 低于这个速度算静止，米/秒（0.1 足够滤掉浮点抖动）
        public const float WalkThreshold = 0.1f;

        // 目标 Animator：留空时自动在本物体及其子物体里找
        [SerializeField] private Animator m_animator = null;

        // SetFloat 的平滑时间（秒）。0 = 不平滑；0.1 让切换不生硬
        [SerializeField] private float m_damping = 0.1f;

        // 同物体上的位移组件（速度来源）
        private PlayerMove m_move;

        // 两个参数名的哈希值（每帧用整数查参数，不拼字符串）
        private int m_speedHash;
        private int m_directionHash;

        // 入参：无（引擎在开始帧调一次）
        // 返回：无
        // 步骤：
        //   1) 取同物体的 PlayerMove；没装就报错（本类不自己算速度）
        //   2) 找 Animator：没手填就 GetComponentInChildren，找不到就报错并停用自己
        //   3) 强制关掉 Root Motion（位移由 PlayerMove 管，动画再带位移会叠加）
        //   4) 校验 Controller 里确实有 Speed 与 Direction 两个 Float 参数，缺一个就点名报错
        // 上游：Unity 引擎
        // 下游：Animator.applyRootMotion / Animator.parameters
        private void Awake()
        {
            m_move = GetComponent<PlayerMove>();

            if (m_move == null)
            {
                Debug.LogError("[PlayerAnimation] 同一个物体上没有 PlayerMove，动画拿不到速度。", this);
                enabled = false;
                return;
            }

            if (m_animator == null)
            {
                m_animator = GetComponentInChildren<Animator>();
            }

            if (m_animator == null)
            {
                Debug.LogError("[PlayerAnimation] 没有 Animator（本物体和子物体都没找到）。", this);
                enabled = false;
                return;
            }

            m_animator.applyRootMotion = false;
            m_speedHash = Animator.StringToHash(SpeedParameter);
            m_directionHash = Animator.StringToHash(DirectionParameter);

            if (!ValidateParameter(SpeedParameter) || !ValidateParameter(DirectionParameter))
            {
                enabled = false;
            }
        }

        // 入参：无（引擎每帧在 Update 之后调）
        // 返回：无
        // 步骤：
        //   1) 取本帧的前后 / 左右实测速度（米/秒，带符号）
        //   2) 都除以配置的移动速度 ⇒ 全速时正好 ±1（与 Controller 的阈值同量纲）
        //   3) 低于阈值的分量按 0 喂（避免浮点抖动让状态来回切）
        //   4) 分别写进 Speed 与 Direction，带 damping 平滑
        // 上游：Unity 引擎（LateUpdate，保证在 PlayerMove.Update 之后）
        // 下游：Animator.SetFloat
        // 注意：不要改成 Update。同一物体上两个 Update 的先后不保证，顺序反了会喂上一帧的速度
        private void LateUpdate()
        {
            float moveSpeed = m_move.MoveSpeed;
            float divisor = moveSpeed > 0f ? moveSpeed : 1f;

            float forward = m_move.ForwardSpeed / divisor;
            float side = m_move.SideSpeed / divisor;

            if (Mathf.Abs(forward) < WalkThreshold)
            {
                forward = 0f;
            }

            if (Mathf.Abs(side) < WalkThreshold)
            {
                side = 0f;
            }

            m_animator.SetFloat(m_speedHash, Mathf.Clamp(forward, -1f, 1f), m_damping, Time.deltaTime);
            m_animator.SetFloat(m_directionHash, Mathf.Clamp(side, -1f, 1f), m_damping, Time.deltaTime);
        }

        // 入参：parameterName 要检查的参数名
        // 返回：true = 存在且是 Float；false = 不存在或类型不对
        // 步骤：
        //   1) 遍历 Controller 的参数表
        //   2) 找到同名且类型为 Float 的就通过
        //   3) 找不到就报错点名（否则每帧 SetFloat 都是无效调用，而且不报错）
        // 上游：Awake
        // 下游：无
        private bool ValidateParameter(string parameterName)
        {
            AnimatorControllerParameter[] parameters = m_animator.parameters;

            for (int i = 0; i < parameters.Length; i++)
            {
                if (parameters[i].name == parameterName &&
                    parameters[i].type == AnimatorControllerParameterType.Float)
                {
                    return true;
                }
            }

            Debug.LogError(
                "[PlayerAnimation] Animator Controller 里没有 Float 参数 " + parameterName +
                "（现有参数：" + parameters.Length + " 个）。动画不会切换。", this);

            return false;
        }
    }
}
```

```csharp
// 这个文件里有：
//   FollowCamera（类）：相机只跟「位置」，绝不跟「朝向」—— 角色转身时镜头一动不动

using UnityEngine;

namespace NBC.Game.Player
{
    // 主要功能：每帧把相机放在「角色的世界固定偏移」处，平滑追过去，再看住角色胸口高度。
    // 主要数据成员：m_target（跟谁）、m_offset（世界固定偏移）、m_smooth（跟随顺滑程度）。
    // 主要外部方法：无。只有 Unity 的 LateUpdate 回调。
    // 谁在用它：挂在主相机上，Target 槽指向角色；由引擎每帧调用。
    public sealed class FollowCamera : MonoBehaviour
    {
        // 跟着谁：把角色拖进来。留空则不做事，不报错
        [SerializeField] private Transform m_target = null;

        // 世界固定偏移：x 左右，y 高度，z 前后（负数表示在 -Z 方向）
        [SerializeField] private Vector3 m_offset = new Vector3(0f, 4f, -6f);

        // 跟随顺滑程度：0 是死贴（会硬），越大越跟手，8 比较稳
        [SerializeField] private float m_smooth = 8f;

        // 入参：无（引擎每帧调用）
        // 返回：无
        // 步骤：
        //   1) 没设 Target 就返回，避免空引用刷屏
        //   2) 想要的机位 = 角色位置 + **世界固定偏移**（不乘角色旋转）
        //   3) 用 Lerp 从当前机位追向目标机位，系数乘 deltaTime，避免帧率变化导致跟随速度不同
        //   4) 看向角色胸口高度（抬高 1.5 米），不要盯着脚
        // 上游：Unity 引擎每帧调用（在 Update 之后）
        // 下游：Transform.position、Transform.LookAt
        // 注意：**这里不能乘 m_target.rotation**。乘了相机就会跟着角色转身（2026-10-28 负责人明确要求：镜头始终不会跟着转向）
        // 注意：必须用 LateUpdate。放 Update 会拿到角色移动前的位置，画面会抖一下
        private void LateUpdate()
        {
            if (m_target == null)
            {
                return;
            }

            Vector3 desired = m_target.position + m_offset;

            transform.position = Vector3.Lerp(
                transform.position, desired, Mathf.Clamp01(m_smooth * Time.deltaTime));

            transform.LookAt(m_target.position + Vector3.up * 1.5f);
        }
    }
}
```

## 七、风险与幻觉自查

- 幻觉自查：`Quaternion.RotateTowards`、`Quaternion.LookRotation`、`Vector3.Dot`、`Mathf.Sign`、`Animator.SetFloat` 均存在。
- 已验证（读 Controller YAML）：条件只有 `Speed>0.1` / `<-0.1` / `=0` / `Rest` / `Jump`，无「进 Runs」的判定。
- 风险：转身 0.125 秒内前后分量偏小，动画可能一瞬间回 Idle；观感明显就把 `m_turnSpeed` 调到 1440。
- 风险：`Direction` 现在基本恒为 0（转身后沿 forward 走），保留为以后「侧移不转身」使用。
- 已知缺陷（不修）：脚滑（5 米/秒 vs 动画约 1.3 米/秒）。
