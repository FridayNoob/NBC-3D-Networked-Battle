# 02 需求

需求：R012-平移与后退（四向移动 + 镜头不跟随转身）
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-10-28，含两次修订）

## 一、业务目标（一句话）

**W 面朝前走、S 保持朝向倒退、A/D 转身朝左/右再前进；镜头只跟位置，角色转身时镜头不动。**

## 二、用户与使用场景

- 用户：开发期负责人；最终玩家。
- 场景：按 W 向前；按 S 倒着退（不改朝向）；按 A/D 角色转向左/右后前进；**期间镜头方向始终不变**。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| W 前进 | P0 | 朝向 = 世界前方，沿该方向走 |
| S 倒退 | P0 | **朝向不变**，沿「当前朝向的反方向」走 ⇒ 播 `WalkBack` |
| A/D 转身前进 | P0 | 朝向 = 世界左 / 右，**转身后**沿该方向前进（约 0.125 秒转 90°） |
| 镜头不跟随转身 | P0 | 相机用**世界固定偏移**，只跟位置；角色转身时镜头方向不变 |
| 禁止斜向位移 | P0 | 同时按两键取绝对值大的轴（相等时前后优先） |
| 鼠标转视角 | P2 | 以后另开需求（R013 候选） |

## 四、边界（**本版明确不做**）

- 不做鼠标控制朝向；镜头不能主动转。
- 不做斜向位移。
- 不调移动速度（仍 5 米/秒，脚滑仍是 R002 遗留）；不播跑步动画（`Walk` 之外不加 Run）。
- 不改 `UnityChanLocomotions.controller`、不改 prefab。

## 五、优先级

**P0**。依赖：R001（输入与移动）、R002（动画接线）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 按住 W 时，角色面朝**世界前方**并前进
- [ ] 当 按住 S 时，角色**保持朝向**倒退（播倒退走，`Speed` 为负）
- [ ] 当 按住 A / D 时，角色**转身朝左 / 右**，随后沿该方向前进
- [ ] 当 角色转身时，**镜头方向不变**（只有位置跟随，画面朝向恒定）
- [ ] 当 同时按 W + D 时，角色**只向前直走**（不斜走；两轴相等时前后优先）
- [ ] 当 松开所有键时，回到 Idle
