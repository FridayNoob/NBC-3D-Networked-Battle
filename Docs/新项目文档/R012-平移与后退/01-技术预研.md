# 01 技术预研

需求：R012-平移与后退（四向移动 + 镜头不跟随转身）
所属阶段：M4
作者：AI　状态：已确认（2026-10-28）

## 〇、修订说明（2026-10-28）

本需求在验收前修订了两轮：① 禁止斜走（改主导轴）；② W/A/D 转身、S 倒退、镜头不跟随转身。
本文的调研结论仍有效（Controller 的 `Speed` / `Direction` 语义与阈值不变），**最终实现以 03/04 的第 3 版为准**，修订过程见 07。

## 一、调研目标与约束

- 目标：**WASD 是平移**（W 前、S 后、A 左、D 右），**角色朝向不变**；S 播倒退，A/D 播侧移。
- 约束（负责人 2026-10-28 定）：
  1. 角色**永不自动转身**（不再「朝移动方向转」）；
  2. S 走 **`WalkBack`** 状态（Speed 负值触发）；
  3. A/D 用 **`Direction`** 参数做侧移；
  4. **保持 5 米/秒**（脚滑仍是遗留，不在本次解决）。

## 二、核心 API 清单（含证据）

| API / 数据 | 用途 | 出处 |
| --- | --- | --- |
| `transform.TransformDirection(local)` | 把「角色本地方向」换成世界方向（角色不转，所以 W 永远是角色前方） | Unity Scripting API |
| `Vector3.Dot(velocity, transform.forward / right)` | 把世界速度拆成「前后分量」与「左右分量」 | 同上 |
| `Animator.SetFloat("Speed", signed)` | 前后分量（米/秒 × 系数），**负值 = 后退** | 本需求新增语义 |
| `Animator.SetFloat("Direction", side)` | 侧移分量，归一化到 **−1..1** | 同上 |
| Controller 条件（**已实测**） | `Speed > 0.1 → Walks`、`Speed < −0.1 → WalkBack`、`Speed = 0 → Idle`、`Rest` 触发 Idle | `UnityChanLocomotions.controller` 的 `m_ConditionEvent`/`m_EventTreshold` |
| `Direction` 混合范围（**已实测**） | 1D BlendTree，阈值 **−1 / 0 / 1**（左移 / 前走 / 右移） | 同上 `m_MinThreshold=-1`、子节点 `m_Threshold` |

## 四、方案对比

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 保持现状（朝移动方向转身） | 已验收、代码不动 | 正是本次要改掉的手感：S 会转身、A/D 会转向 | 否 |
| **朝向不变 + 本地平移 + Speed/Direction 双参数** | 符合需求；Controller **零改动**（它的 `WalkBack`/`Direction` 就是为此设计的） | 要改 `PlayerMove`（删转向）、`PlayerAnimation`（多喂一个参数） | **采用** |
| 鼠标控制朝向（相机相对） | 更像 3A | 要加鼠标输入、相机解耦，工作量翻倍 | 否（以后可开 R013） |

## 五、已知坑与版本兼容

1. **角色不转 ⇒ 相机也不转**：`FollowCamera` 用的是 `m_target.rotation * m_offset`，角色朝向固定后视角就固定朝一个方向。这是本方案的**必然结果**，不是 bug。
2. **S 必须是负的 `Speed`**：Controller 靠 `Speed < −0.1` 进 `WalkBack`；如果仍传正数，会播成「向前走但人往后退」。
3. **`Direction` 必须归一化**：它期望 −1..1，直接喂米/秒（最大 5）会一直顶在右移档。
4. **转身代码要删干净**：`m_turnSpeed` 与 `Quaternion.RotateTowards`、`LookRotation` 都不再使用；保留字段会让人以为还能转。
5. **脚滑不变**：仍是 5 米/秒 vs 动画约 1.3 米/秒（R002 遗留，本次不动）。
6. **侧移/后退的动画匹配度未知**：`WalkBack` 与 `Direction` 混合片段的实际步频没验过，可能比侧移速度慢（脚滑更明显）。
7. **输入方向约定**：`InputCommand.MoveY` 正方向是对应 W 吗？必须实测确认（R001 里 W 走 +Z，所以 `MoveY=+1000` 应是前）。

## 六、结论与要改的东西

结论：**朝向不变 + 本地平移 + `Speed`（带符号）/`Direction`（归一化）双参数**；
Animator Controller、prefab、场景**都不需要改**，只改两个脚本。

- `PlayerMove`：删掉转向（`m_turnSpeed`、`RotateTowards`、`LookRotation`），位移改成本地方向，暴露「前后分量」与「左右分量」两个只读属性。
- `PlayerAnimation`：多喂一个 `Direction` 参数，`Speed` 改为带符号。
