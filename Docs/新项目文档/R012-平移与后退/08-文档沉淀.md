## 二、模块文档

### 简介与使用场景

`PlayerMove`（四向移动，W/A/D 转身、S 倒退）+ `FollowCamera`（世界固定偏移）。
适合「固定视角、角色朝四方向走」的操作：镜头不跟着转，玩家看到的是稳定的画面。

### 核心接口

| 接口 / 字段 | 入参 | 出参 | 说明 |
| --- | --- | --- | --- |
| `PlayerMove.ForwardSpeed` | — | float，米/秒 | W 正 / S 负；给动画做 `Speed` |
| `PlayerMove.SideSpeed` | — | float，米/秒 | 转身瞬间短暂非零；给 `Direction` |
| `PlayerMove.MoveSpeed` | — | float | 归一化分母 |
| `m_turnSpeed`（Inspector） | — | 度/秒，默认 720 | 90° 约 0.125 秒 |
| `m_offset`（FollowCamera） | — | `(0,4,-6)` | **世界固定偏移**，不乘旋转 |

### 使用示例（负责人亲手跑通，2026-10-28）

```text
1) 角色：PlayerMove + PlayerAnimation + Animator（UnityChanLocomotions）
2) 主相机：FollowCamera，Target = 角色，Offset = (0,4,-6)
3) Play：W 前走 / S 倒退 / A、D 转身朝左、右再走；镜头方向全程不变
```

### 实现原理（简要）

输入先压成 W/A/S/D 之一（`|z| >= |x|` 决定前后还是左右）。
W/A/D 用 `RotateTowards` 限速转身、并**沿目标方向**位移；S 不改朝向、沿 `-forward` 位移（⇒ 动画进 `WalkBack`）。
位移后用 `Dot` 拆出前后 / 左右分量，除以 `m_moveSpeed` 归一化成 ±1 喂给 Animator。
相机 `desired = target.position + m_offset`，不乘 `target.rotation`。

### 已知限制与坑点

- **脚滑**：移动 5 米/秒 vs Walk 动画约 1.3 米/秒。
- 转身 0.125 秒内动画可能闪回 Idle（`m_turnSpeed` 调大可缓解）。
- `Direction` 恒为 0（当前没有侧移）。
- 镜头方向不可主动改变（没有鼠标视角）。

### 修改维护注意事项

- **别把 `m_target.rotation` 加回相机**（会变成「镜头跟转身」）。
- 改转身速度只动 `m_turnSpeed`，不要动位移方向逻辑。
- 若以后要「侧移不转身」，只需给 A/D 换分支并启用 `Direction` 参数，配置已经就绪。

## 三、踩坑清单（现象 / 原因 / 解决）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 按 S 变成转身前进 | 只喂了速度大小，没喂符号 | `Speed` 喂带符号的前后分量 |
| 按 A/D 时镜头跟着转 | 相机偏移乘了 `m_target.rotation` | 改成 `position + m_offset` |
| 斜着按两键会斜走 | 只做了归一化，没禁止 | 主导轴（相等时前后优先） |
| 转身时走出弧线 | 位移沿当前朝向 | 位移用目标方向 |
| 转身瞬间动画闪回 Idle | 前后分量在 0.125 秒内偏小 | 调大 `m_turnSpeed` |
| 动画完全不切换且无报错 | Controller 缺参数（`SetFloat` 静默失效） | `Awake` 校验并点名 |
