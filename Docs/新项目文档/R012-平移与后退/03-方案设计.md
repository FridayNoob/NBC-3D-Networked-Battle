# 03 方案设计

需求：R012-平移与后退（四向移动 + 镜头不跟随转身）
所属阶段：M4
作者：AI 起草　状态：已确认（2026-10-28，第 3 版定稿）

## 一、整体架构

仍是两段：`PlayerMove`（四向移动 + **W/A/D 转身、S 不转**）→ `PlayerAnimation`（统一归一化后喂 `Speed` 与 `Direction`）
＋ `FollowCamera`（**只跟位置，不跟朝向**）。状态与过渡继续由 Controller 决定。

## 二、模块划分

| 模块 | 负责什么 | **不负责**什么 |
| --- | --- | --- |
| `PlayerMove`（改） | 取主导轴得 W/A/S/D；W、A、D 先转身再沿目标方向前进，S 保持朝向倒退；拆前后 / 左右分量 | 不碰 Animator |
| `PlayerAnimation`（改） | 两个分量都 ÷ `m_moveSpeed` 归一化，喂 `Speed`（负=后退）与 `Direction`；校验两个参数 | 不判断状态、不做过渡 |
| `FollowCamera`（改） | 世界固定偏移跟位置；`LookAt` 角色胸口 | **不跟朝向**（不能乘 `m_target.rotation`） |
| `UnityChanLocomotions.controller` | **零改动**（`WalkBack` 靠 `Speed<−0.1`） | 不写代码 |

## 三、接口（★ 先定死，代码必须与此逐字一致）

```
PlayerMove
    字段 m_moveSpeed = 5     保持不变
    字段 m_turnSpeed = 720   恢复（A/D 转身用）
    增：ForwardSpeed -> float   前后分量，米/秒（W 正、S 负）
    增：SideSpeed    -> float   左右分量，米/秒（转身瞬间会短暂非零）
    增：MoveSpeed    -> float   归一化分母
    保留：CurrentSpeed -> float 合速度

PlayerAnimation
    常量 SpeedParameter     = "Speed"
    常量 DirectionParameter = "Direction"
    LateUpdate：
        SetFloat(Speed,     ForwardSpeed / MoveSpeed)
        SetFloat(Direction, SideSpeed   / MoveSpeed)

FollowCamera
    字段 m_offset = (0,4,-6)  含义改为「世界固定偏移」
    desired = m_target.position + m_offset      ← 不再乘 rotation
```

## 四、数据结构与归一化

| 数据 | 类型 | 含义 / 单位 | 谁改它 |
| --- | --- | --- | --- |
| `ForwardSpeed` | float | 前后速度，米/秒，带符号 | `PlayerMove.Update` |
| `SideSpeed` | float | 左右速度，米/秒 | 同上（转身过程中短暂非零） |
| `Speed` 参数 | float | 前后 ÷ 移动速度 ⇒ −1..1 | `PlayerAnimation.LateUpdate` |
| `Direction` 参数 | float | 左右 ÷ 移动速度 ⇒ −1..1 | 同上 |
| 角色 yaw | — | W=0°、D=+90°、A=−90°；S 不变 | `PlayerMove.Update` |

## 五、时序与流程

1. `Update`：读 `(x, z)` → 取主导轴（`|z| >= |x|` 用前后）→ 得 W/A/S/D 之一。
2. **W / A / D**：目标朝向 = 该世界基本方向；`RotateTowards(m_turnSpeed)` 限速转；**位移用目标方向**（不是当前朝向）⇒ 转身过程中不会走弧线。
3. **S**：不改朝向，位移 = `-transform.forward` ⇒ 实测前后分量为负 ⇒ `Speed < −0.1` ⇒ 播 `WalkBack`。
4. 位移后按 `forward / right` 点乘拆出两个分量。
5. `LateUpdate`（动画）：两个分量各 ÷ `m_moveSpeed` 写入 `Speed` / `Direction`。
6. `LateUpdate`（相机）：`m_target.position + m_offset`（世界固定）→ 只看位置，方向永不变。

## 六、技术选型与理由

| 选择 | 选定 | 理由 | 被否的方案 |
| --- | --- | --- | --- |
| W/A/D | **转身朝该方向再前进** | 负责人明确要求（A/D 要「面朝左/右跑」） | 侧移不转身（第一版做过，被否） |
| S | **不转身、倒退** | 一致：倒退不该先转 180° | 转向后前进（R001 原行为，被否） |
| 位移方向 | **目标方向**（非当前朝向） | 转身 0.125 秒内若按当前朝向走会拐弧线 | 按当前朝向前进 |
| 相机 | **世界固定偏移** | 负责人明确要求镜头不跟随转身 | 乘 `m_target.rotation`（R001 原行为，被否） |
| 斜向 | **主导轴**（相等时前后优先） | 需求：禁止斜走 | 归一化斜走（第一版，被否） |
| 归一化 | 两参数都 ÷ `m_moveSpeed` | 全速 = ±1，与 Controller 阈值同量纲 | 各算各的 |

## 七、风险与对策

- **转身时相机不动** ⇒ 按 A/D 后能看见角色侧身/背影，画面方向不变。这是需求要求的，不是 bug。
- **`Direction` 基本恒为 0**：因为转身后位移沿 forward，侧向分量≈0；保留该参数是为以后做「侧移不转身」。
- **转身 0.125 秒内**前后分量会短暂偏小，动画可能瞬间回 Idle 再进 Walk。若观感明显，把 `m_turnSpeed` 调大（如 1440）。
- **不会误进跑步**：Controller 条件只有 `Speed>0.1` / `<-0.1` 两档（实测）。
- **脚滑**：仍 5 米/秒 vs 动画约 1.3 米/秒（R002 遗留）。
- **prefab 上残留 `m_turnSpeed` 旧值**：本次恢复使用该字段，旧值会生效（默认 720，无影响）。
