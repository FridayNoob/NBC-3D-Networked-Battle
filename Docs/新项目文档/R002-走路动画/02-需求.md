# 02 需求

需求：R002-走路动画
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-10-27）

## 一、业务目标（一句话）

**让角色动起来像个人**：站着是站姿、走起来是走路动作 —— 这是后面战斗动作、受击反馈的地基。

## 二、用户与使用场景

- 用户：开发期负责人验证；最终玩家看到的是一个「会走路的角色」而不是滑动的胶囊。
- 场景：进场景，按 W/A/S/D 时角色播走路动作；松开后回到站姿；被挡住原地不动时也是站姿。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 静止播 Idle | P0 | 没有位移时 |
| 移动播 Walk | P0 | **按实际位移速度判定**，不是按「有没有按键」 |
| 两态过渡 0.15 秒 | P0 | 淡入淡出，不要瞬间切换 |
| 被挡住时回 Idle | P1 | 速度接近 0 就算没走（本版场景无碰撞，逻辑上先成立） |
| 脚不打滑（动画速度与移动速度匹配） | P1 | **本版不做**，记遗留 |
| Run / 起步停步过渡 / BlendTree | P2 | 以后开新需求 |

## 四、边界（**本版明确不做**）

- 不做 Run、不做攻击/受击动作、不做落地与起步缓冲。
- 不接网络：只播本机角色的动作，远端角色的动作另开需求。
- **不改移动速度**（保持 R001 的 5 米/秒）；因此脚会滑，本版接受，记 07 遗留。
- 不换模型风格、不做换装。
- 不用 BlendTree（只用两状态 + 一个 `Speed` 浮点参数）。

## 五、优先级

**P0**。依赖：R001（`PlayerMove` 已能走）+ Unity-chan 模型导入（不进仓库）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 进入 Play 且不按任何键时，角色应保持 Idle 站姿
- [ ] 当 按住 W 时，角色应在 0.15 秒内过渡到 Walk
- [ ] 当 松开所有键时，角色应在 0.15 秒内回到 Idle
- [ ] 当 同时按住 W + S（方向相消、角色原地不动）时，应保持 Idle
- [ ] 当 我在 Controller 里改过渡时长/换动画后重新进 Play，应直接生效，**不需要改代码**
