## 三、异常场景（本轮三轮问题，已全部修掉）

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 模型通体**粉色** | 材质引用的卡通 shader **资产不存在**（全项目搜不到该 GUID） | 11 个材质改 `Universal Render Pipeline/Lit` 并接 Base Map（`Left/Right` 为描边材质，不改） |
| 角色**乱跑 / 速度翻倍** | 预制体自带 `UnityChanControlScriptWithRgidBody`（自己读键盘 + Rigidbody 移动），与 `PlayerMove` 两套输入 | 用 MCP 移除该组件（保留 `FaceUpdate`） |
| 位移可能**叠加漂移** | `Animator.Apply Root Motion = true` | 用 MCP 改为 `false`（代码里也强制关） |
