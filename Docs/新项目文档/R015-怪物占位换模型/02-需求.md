# 02 需求

需求：R015-怪物占位胶囊换成模型
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-11-02）

## 一、业务目标（一句话）

**怪物不再是胶囊，而是真模型**（第一只用 `Forest Wolf - Grey`），并且换模型只改一个 Inspector 字段。

## 二、用户与使用场景

- 用户：开发期负责人；最终玩家。
- 场景：进房后看到的敌人是一只狼（会站着、也许带待机动画），不是白色胶囊；本地玩家仍然只有一份真模型。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 敌人槽位实例化模型 prefab | P0 | `SnapshotSceneBinder.m_monsterPrefab` 指定，留空回落胶囊 |
| 跳过本地英雄槽位 | P0 | 避免「SwordGirl + 英雄槽位模型」两份 |
| 自动贴地 | P0 | 按 prefab 实际包围盒把脚底对到地面（狼的脚底在 y=−0.44） |
| 选中模型材质转 URP | P0 | 否则 URP 下是紫色（狼的 4 个材质） |
| 怪物走动播动画 | P1 | 当前只保证「有模型」；按速度驱动动画另说 |
| 每种怪不同外观 | P2 | 要「配置 → prefab」映射表，本次不做 |

## 四、边界（**本版明确不做**）

- 不改服务端、不改协议、不改快照数据。
- 不做「实体配置 id → 模型」的映射表（本次只有一种怪）。
- 不做怪物朝向（快照里有 `FacingDeg`，但表现层今天不写朝向）。
- 不把素材提交进仓库（`Art/Model` 仍被 `.gitignore` 忽略）。
- 不转换另外 104 个模型的材质（只转狼用的 4 个）。

## 五、优先级

**P0**。依赖：R006（位置平滑）、R014（本地玩家已是真模型）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 进房后，敌人应显示为**狼的模型**（不是胶囊），且**站在地面上**（不悬空、不陷地）
- [ ] 当 狼走动时，位置应**连续移动**（沿用 R006 的平滑，不跳格）
- [ ] 当 看本地玩家时，应**只有一份**模型（SwordGirl），没有第二个英雄槽位模型
- [ ] 当 狼出现时，材质应**正常显示**（不是紫色/粉色）
- [ ] 当 把 `m_monsterPrefab` 留空并重进 Play 时，应**回落成胶囊**（可回退）
