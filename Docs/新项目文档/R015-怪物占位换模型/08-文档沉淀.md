## 二、模块文档

### 简介与使用场景

`SnapshotSceneBinder`（`Game\View\`）负责把快照实体搬进场景。R015 之后，槽位可以实例化**模型 prefab** 而不是胶囊：
由 `HpBarDemoBehaviour.m_monsterPrefab` 指定，一路传到 `RuntimeNetDriver.MonsterPrefab` → `SnapshotSceneBinder.Ensure(view, playerId, prefab)`。

### 核心接口

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `HpBarDemoBehaviour.m_monsterPrefab` | Inspector | 敌人模型 prefab；留空回落胶囊 |
| `RuntimeNetDriver.MonsterPrefab` | 属性 | 装配时由 Boot 层传入 |
| `SnapshotSceneBinder.Ensure(view, id, prefab)` | 静态方法 | 3 参版本；2 参版本保留（转调 null） |
| `SnapshotSceneBinder.SetOwnerPlayerId(long)` | 方法 | **每帧**同步「我是谁」，用于跳过本地英雄 |
| `Slot.Body` / `Slot.Positioned` | 私有字段 | 有刚体 ⇒ 走物理；首帧归位标记 |

### 分工约定（重要）

| 谁 | 负责什么 |
| --- | --- |
| **prefab** | 刚体（重力/冻结旋转）、碰撞体（R016 工具生成）、Animator |
| **运行时代码** | X/Z 位置（`Rigidbody.velocity` 或 transform）、Y 交给重力、缩放、显隐 |
| **服务端** | 权威位置（快照）、生死 |

### 使用示例（负责人亲手跑通，2026-11-02）

```text
把怪物 prefab 指给 HpBarDemo 的 Monster Prefab → Play
  → 敌人显示为狼、脚贴地、颜色正常、移动连续
把 Monster Prefab 留空 → 回落成胶囊（可回退）
```

### 已知限制与坑点

- **怪物没有动画驱动**：模型只会滑动，不会播 Walk/Idle（下一步接）。
- **朝向未处理**：`FacingDeg` 有数据但表现层不写朝向。
- **本地英雄不建槽位**：真模型在场景里；`PlayerId` 为 0 时（还没握手完）会先建出来，靠每帧同步后隐藏。
- 模型 prefab 若被**移动目录**，Inspector 引用靠 GUID 仍然有效（本次狼被移到 `Assets/Prefabs/` 就是靠这条继续生效）。

### 修改维护注意事项

- **换模型**：只改 `HpBarDemo.m_monsterPrefab`，不用改代码。
- **新模型必须先跑 R016 工具**（生成碰撞体 + 刚体），否则会悬空或穿地。
- **不要给槽位在运行时加物理组件**（已删除该逻辑）；物理是 prefab 的事。
- 改了 `EnsureSlot` 后记得：**有刚体的槽位不能写 `localPosition`**。

## 三、踩坑清单（现象 / 原因 / 解决）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 狼悬空 | 碰撞体按 `Renderer.bounds`（蒙皮动画盒，轴系不同） | R016 改按顶点 AABB |
| 狼跟着玩家 | `PlayerId` 晚到，`m_ownerPlayerId` 永久为 0 | 每帧 `SetOwnerPlayerId` |
| 移动一顿一顿 | 写 transform 被动态刚体覆盖；未开插值 | `velocity` + `Interpolate` |
| 狼紫色 | 材质是内置 Standard | 转 URP Lit（R015 已转 4 个） |
| 狼一直往下掉 | prefab 有刚体但没碰撞体 | 跑 R016 工具补齐 |
