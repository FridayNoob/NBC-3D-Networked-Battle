# 01 技术预研

需求：R015-怪物占位胶囊换成模型
所属阶段：M4
作者：AI　状态：已确认（2026-11-02）

## 一、调研目标与约束

- 目标：把表现层那个「每个实体一个胶囊」的占位，换成真实的怪物模型（用你导入的 `Forest Creatures Pack` / `Monsters Full Pack Vol 1`）。
- 约束：
  1. 不改服务端、不改协议、不改快照数据；
  2. 素材不进仓库（`Client/Assets/Art/Model/` 已在 `.gitignore`）；
  3. 留给以后换模型的口子：**一个 Inspector 字段**就能换，不改代码。

## 二、素材实况（实测）

| 项 | 结论 |
| --- | --- |
| 新导入的包 | `Forest Creatures Pack`（12 种：狼、树精、龙、蝙蝠、蘑菇、食人花…）、`Monsters Full Pack Vol 1`（6 卷，如 Cavecrawler） |
| 每个怪都有 | `FBX/<名>.FBX`（模型）、`FBX/<名>@<动作>.FBX`（每个动作一个文件）、`Controllers/*.controller`、`Prefabs/*.prefab`、`Materials`、`Textures` |
| **prefab 数量** | **105 个**（含多种配色变体，如 `Forest Wolf - Blue/Grey/Purple.prefab`） |
| prefab 组件 | 含 **Animator** 且已绑 controller ⇒ 可以直接用，不用自己搭动画状态机 |
| 骨架导入类型 | `animationType = 2`（**Legacy**）；Animator 仍能播这些片段（只是不做人形重定向），对怪物够用 |
| **材质** | 两包里 **108 个材质仍用内置 Standard shader** ⇒ **URP 下会显示成紫色**（和 Unity-chan 当初同一个坑） |
| URP 变体 | 包里**没有** URP/HDRP 目录，也没有 `.unitypackage` |

## 三、现状（表现层怎么造单位）

| # | 事实 | 出处 |
| --- | --- | --- |
| 1 | `EnsureSlot` 用 `GameObject.CreatePrimitive(PrimitiveType.Capsule)` 造占位 | `SnapshotSceneBinder.cs:358` |
| 2 | 槽位按 `EntityId` 池化复用，稳态不新建 | `m_slots` 字典 |
| 3 | **本地英雄也会有一个槽位**（只是放大 1.4 倍） | `LateUpdate` 里 `mine ? HeroScale : 1f` |

⚠️ 事实 3 意味着：换成模型后，**本地玩家会出现两个**——真正的 SwordGirl + 一个英雄槽位模型。必须处理。

## 四、方案对比

| 方案 | 做法 | 评价 |
| --- | --- | --- |
| **A（采用）** | `EnsureSlot` 从「建胶囊」改成「实例化 `m_monsterPrefab`」，字段留空则回落胶囊；**跳过本地英雄的槽位** | 改动集中在一处；换模型只改 Inspector |

## 五、已知坑

1. **材质紫**：108 个 Standard 材质要在 URP 下转成 `Universal Render Pipeline/Lit`（贴图与颜色要跟着搬）。Unity-chan 那次已经踩过，同法处理。
2. **本地英雄双份**：必须跳过 `OwnerPlayerId == m_ownerPlayerId` 的槽位。
3. **模型尺寸/原点不一**：狼、龙、蘑菇的实际大小差别很大，`y = scale * 0.5` 那个「胶囊半径」假设不再成立，要按 prefab 的实际包围盒抬升（或让 prefab 自己贴地）。
4. **性能**：每个实体一个模型（带骨骼 + Animator）比胶囊重得多；实体多时要考虑池化与动画降频。
5. **朝向**：模型默认朝向未必是 +Z；快照里有 `FacingDeg` 但当前表现层**没写朝向**，换模型后「怪背对你走」会很显眼。
6. **旧槽位残留**：已存在的胶囊槽位在热切换时不会自动变模型（要退出 Play 重进）。

## 六、结论与改动清单（草案）

结论：**把 `EnsureSlot` 的「建胶囊」换成「实例化 prefab」，并跳过本地英雄槽位**；材质转换单独做一次（一次性资产操作）。

要改/新增：
- `SnapshotSceneBinder`：新增 `m_monsterPrefab` 字段；`EnsureSlot` 改成实例化；跳过本地英雄；`y` 抬升改为按 prefab 包围盒。
- 资产侧：选定一只怪（建议 `Forest Wolf - Grey`）做 `m_monsterPrefab`，并把它的材质转 URP。
- 文档：`第三方素材清单.md` 补两个新包。
