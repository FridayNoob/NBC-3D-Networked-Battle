# 03 方案设计

需求：R015-怪物占位胶囊换成模型
所属阶段：M4
作者：AI 起草　状态：已确认（2026-11-02）

## 一、整体架构

只改表现层的「造槽位」这一步，数据链路完全不变：

```
快照 → PresentationFeed → SnapshotSceneBinder.LateUpdate
                                  │
                     EnsureSlot（原来：CreatePrimitive(Capsule)）
                                  现在：Instantiate(m_monsterPrefab) 或回落胶囊
                                  │
                            MoveSlotTo（R006 的平滑，不动）
```

## 二、模块划分

| 模块 | 本次改动 | 不负责什么 |
| --- | --- | --- |
| `SnapshotSceneBinder`（改） | 新增 `m_monsterPrefab`；`EnsureSlot` 实例化 prefab；跳过本地英雄；按包围盒贴地 | 不改快照、不改相机、不改平滑 |
| `Slot`（同文件私有类） | 新增 `GroundOffsetY`（脚底到轴心的距离） | — |
| 狼的 4 个材质（资产） | Standard → URP/Lit，搬 `_MainTex`/`_Color` | 其余 104 个模型不转 |
| 服务端 / 协议 / 动画控制器 | **零改动** | — |

## 三、接口（★ 先定死）

```
SnapshotSceneBinder 新增序列化字段：
    m_monsterPrefab : GameObject   敌人用的模型 prefab；留空 = 回落胶囊（可回退）

Slot 新增字段：
    GroundOffsetY : float          脚底到轴心的距离（米）；实例化后按包围盒算一次

行为约定：
    1) OwnerPlayerId == m_ownerPlayerId 的实体 ⇒ 不建槽位（本地玩家已有真模型）
    2) m_ownerPlayerId == 0（还不知道自己是谁）⇒ 不跳过（宁可多一个，也不让敌人消失）
    3) 模型槽位的 y = GroundOffsetY；胶囊槽位维持原来的 y = scale * 0.5
```

## 四、数据结构

- `Slot` 多一个 `float`（8 字节级别），稳态槽位数等于实体数。
- 不新增集合、不新增每帧分配。

## 五、时序与流程

1. 实体第一次出现 → `EnsureSlot`：
   - 有 `m_monsterPrefab` ⇒ `Instantiate`（挂到 binder 下面，局部位置先归零）→ 扫一遍 `Renderer` 求 `bounds.min.y` 相对轴心的偏移 ⇒ 记进 `GroundOffsetY`
   - 没有 ⇒ 造胶囊（老行为）
2. `LateUpdate` 里：本地英雄直接 `continue`（不建、不动）。
3. 目标位置：`y = slot.GroundOffsetY`（模型）/ `scale * 0.5`（胶囊）。
4. R006 的 `MoveSlotTo` 照旧推进位置。

## 六、技术选型与理由

| 选择 | 选定 | 理由 | 被否的方案 |
| --- | --- | --- | --- |
| 用 prefab 还是 FBX | **prefab** | 包里 105 个 prefab 已绑 Animator + controller，直接用 | 运行时加载 FBX（要自己搭 Animator） |
| 贴地方式 | **按包围盒自动算** | 狼脚底在 y=−0.44、龙和蘑菇又不一样，写死一个数必然错 | Inspector 手填偏移（每个模型都要调） |
| 本地英雄 | **跳过槽位** | 真模型已在场景里，再多一个就是两个自己 | 用模型顶替真模型（会破坏 PlayerMove/PlayerBrain 那条链） |
| 材质 | **只转选中的** | 108 个全转改动面大且与本次目标无关 | 全部转（留以后） |

## 七、风险与对策

- **紫色材质**：只转狼的 4 个 `Forest Wolf - *.mat`；转完在 Play 里确认颜色正常。
- **模型浮空/陷地**：按包围盒自动算 `GroundOffsetY`，不写死。
- **怪物朝向可能反**：模型根节点旋转为 0，但朝向是否 +Z 要 Play 才知道；若反了，加一个 180° 的字段（本次先不加，观察到再说）。
- **性能**：狼带骨骼与 Animator，实体多时比胶囊重；本次只有少量实体，先观察。
- **热切换残留**：已在 Play 中的胶囊槽位不会自动变模型，退出重进即可（文档写明）。
- **回退路径**：`m_monsterPrefab` 留空 ⇒ 回到胶囊，一行都不用改。
