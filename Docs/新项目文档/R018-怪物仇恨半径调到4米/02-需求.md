# 02 需求

需求：R018-怪物仇恨半径调到 4 米
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-11-05）

## 一、业务目标（一句话）

**玩家一进副本，怪物就会过来**，不再是「贴脸才动」。

## 二、用户与使用场景

- 用户：开发期负责人；最终玩家。
- 场景：进副本后站在出生点，就能看到狼从对面走过来。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 仇恨半径 2.2 米 → **4 米** | P0 | 统一半径，不区分怪种 |
| 保留 leash（走出半径回出生点） | P0 | 已有逻辑，不改 |
| 更新守卫用例的断言 | P0 | 原断言「出生点在仇恨圈外」与 4 米冲突 |
| 按怪种区分半径 | P2 | 本版不做 |

## 四、边界（**本版明确不做**）

- 不改副本尺寸（`spawnRadiusMm` 仍是 3000）。
- 不改怪物移速（仍 40mm/tick ≈ 1.2 米/秒）。
- 不改 BOSS 的攻击力/攻击频率。
- 不改协议与客户端。

## 五、优先级

**P0**。依赖：无（纯服务端常量）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 玩家站在出生点不动时，怪物应在**几秒内朝玩家走来**（不再需要贴近）
- [ ] 当 怪物与玩家距离超过 4 米时，应**回出生点**（leash 仍生效）
- [ ] 当 跑 `_net-probe` 的 BOSS 相关用例时，应**全绿**（含改过的守卫用例）
- [ ] 当 服务端重编后，应能正常开局（无编译错误、日志无异常）
