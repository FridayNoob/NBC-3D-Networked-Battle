## 1. 计划

| 类型 | 要验什么 | 怎么造 |
| --- | --- | --- |
| 正常 | 放技能期间不掉血 | 进副本，让狼围上来，按 Q |
| 异常 | 技能放完立刻能被打 | 等技能动作结束，站着不动挨打 |
| 边界 | 冷却内连按不会续窗口 | 技能刚放完再按 Q（被冷却拒），观察是否还免伤 |
| 性能 | 无敌期间帧率正常 | 观察 Game 视图与 Profiler |

客户端不需要重新打包，但生成物 `Config_Skill.cs` 要跟着刷新过。

## 2. 正常流程走查

1. 启动服务端（`NBC.Server.Host`），Login 点「开始游戏」，进 World 按 E 进副本。
2. 走到野狼旁边，让两三条狼开始咬你（屏幕左下血量开始掉）。
3. 按 **Q**（旋风斩）。
   - 预期：角色挥剑，**血量在技能期间不再掉**，屏幕上也没有伤害飘字。
   - 预期：Console 有 `[技能] 请求释放 2001`，服务端日志有「玩家 1 释放技能 2001 → 单位 N」。
4. 技能动作结束（约 2.7 秒）后站着不动。
   - 预期：狼的普攻重新开始掉血。
5. 按 **E**（上挑斩，1.6 秒）重复第 3 步，观察窗口更短。

## 3. 异常场景

| 场景 | 预期 |
| --- | --- |
| 技能在冷却里连按 Q | 不放技能；如果此时不在免伤窗口，会正常掉血 |
| 血量很低时放技能 | 技能期间不会被咬死（血量停在原地） |
| 对着空气放（没有目标） | 放不出去（服务端拒「目标不存在」），也就没有无敌 |

## 4. 性能

- 无敌窗口是 `Dictionary<int,int>` 里一条记录，每帧只在 `ApplyDamage` 时查一次，开销可忽略。
- 观察点：放技能前后 Game 视图帧率没有变化。
