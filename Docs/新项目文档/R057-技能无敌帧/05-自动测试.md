## 2. 用例清单

### 2.1 服务端【十七·五】`Skills_Invulnerability()`（8 条）

| # | 用例 | 类型 | 断言 |
| --- | --- | --- | --- |
| 1 | 旋风斩解析出无敌帧 | 正常 | `InvulnTicks > 0`（不写死，从表读） |
| 2 | 技能放得出去 | 正常 | `TryCastSkill` 返回 true |
| 3 | 施法那一刻就进无敌 | 正常 | `IsInvulnerable(hero.Id) == true` |
| 4 | 窗口内连打 10 次不掉血 | 边界 | 血量不变且 `Alive` |
| 5 | 怪物放技能不获得无敌 | 非法 | `TryCastSkill(wolf, …)` 成功但 `IsInvulnerable(wolf.Id) == false` |
| 6 | 窗口过后不再免伤 | 边界 | 推 `InvulnTicks + 1` 帧后为 false |
| 7 | 窗口结束后伤害正常结算 | 正常 | 打 100 点，血正好少 100 |
| 8 | 免伤不影响技能自己的命中 | 正常 | `hitFrame >= 1`（命中帧仍按表） |

为什么第 1 条不写死 81 帧：`invulnMs` 是负责人可调的，写死就变成"改表必须改测试"。
探针只验"表里的数被读出来并用上了"。
