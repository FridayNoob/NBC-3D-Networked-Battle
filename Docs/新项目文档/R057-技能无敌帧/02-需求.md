# R057 技能无敌帧 —— 02 需求

> 需求编号：R057　所属阶段：M4　作者：AI（DeepSeek Harness）　状态：开发中

## 一、业务目标（一句话）

玩家按下 Q/E/R 放技能之后，在整个技能动作期间**不掉血、不会被打断**，让「先手开技能」成为能救命的选择。

## 二、用户与场景

- **玩家一个**（单人副本，剑士 1001）。进副本 → 被三只狼围住 → 按 Q 放旋风斩 → 狼照打，但血条不动、伤害数字不出现 → 技能结束那一秒开始正常掉血。
- **狼王**：它放技能时**没有**这层保护（负责人明确只给玩家）。

## 三、功能列表

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0 | 施法期间免伤 | 服务端在 `ApplyDamage` 早退，英雄血量不变 |
| P0 | 不打断 | 不产生伤害事件 ⇒ 客户端不播受击、不飘字 |
| P0 | 时长跟技能 | 旋风斩 2.67 秒、上挑斩 1.6 秒、突进斩 2.93 秒（1.5 倍速后的动作时长） |
| P0 | 表可调 | `Skill.csv` 新增 `invulnMs`；填 0 表示这个技能没有无敌 |
| P1 | 结束即恢复 | 窗口过期后同一帧起就能被打 |
| P2 | 免伤提示 | **不做**（负责人选「什么都不显示」） |

## 四、边界（不做什么）

1. 不做护盾值 / 吸收上限（那是另一个机制）。
2. 不做怪物无敌。
3. 不做「施法期间免疫控制」——现在没有控制类效果，硬做只能造一个假开关。
4. 不改协议：不加「免疫」事件、不加字段。
5. 不动 PVP 锁步路径（技能在锁步里还没做）。
6. 不改客户端代码（除测试外）。

## 五、优先级

P0 四条做完就能验收；P1 是同一份逻辑的自然结果；P2 明确不做。

## 六、验收标准（当…时，应…）

1. 当玩家在狼身边按 Q 放旋风斩，且狼在此期间普攻命中时，英雄血量**一点不掉**。
2. 当免伤期间被命中时，屏幕上**不出现**伤害飘字，角色**不播**受击动作。
3. 当技能窗口结束（旋风斩约 2.7 秒）后再次被命中时，英雄正常掉血。
4. 当狼王放技能时被打，它**照旧**掉血（免伤只属于玩家英雄）。
5. 当三个技能分别施放时，免伤时长分别约为 2.7 / 1.6 / 2.9 秒（可通过反复挨打粗测）。
6. 当 `Skill.csv` 的 `invulnMs` 填 0 时，该技能**没有**免伤。
7. 当冷却未好、技能放不出来时，**不会**获得免伤（免伤只跟随成功的施法）。
8. 当免伤期间被三只怪同时围攻时，英雄不会死亡。
9. 服务端战绩里「承受伤害」**不因免伤期的攻击而增加**。
10. 当免伤窗口过期后，服务端下一次伤害事件的剩余血量与实际扣血一致。
