## 三、测试代码

`execute_code` 片段（一次性，不落仓库），核心两步：

```csharp
// ① 预览三态/四态
var r = new BTPreviewRunner();
r.Start(data, out _);
r.Blackboard.Set("hp", BTParamValue.FromInt(100)); r.Tick(0.2f);
r.Status["n2"];   // Failure
r.Blackboard.Set("hp", BTParamValue.FromInt(10));  r.Tick(0.2f);
r.Status["n2"];   // Success

// ② 只改 SO 加节点（0 行代码）
asset.Nodes.Add(new BTNodeEntry {
    TypeName = "TmpHP90", PreviewKind = BTPreviewKind.IntCompare,
    PreviewKey = "hp", CompareOp = BTCompareOp.Less, CompareConstInt = 90,
    Category = BTNodeCategory.Condition, MaxChildren = 0 });
BTNodeRegistry.Reload();
// ← 到这里没有任何 .cs 改动，新节点即可预览；验证后 RemoveAll 回滚
```
