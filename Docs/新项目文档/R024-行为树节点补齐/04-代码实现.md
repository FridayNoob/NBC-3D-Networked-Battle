## 二、功能概述

左栏 16 个节点全部来自 SO 定义；预览按「定义里的 `PreviewKind` → 注册表求值器」算状态，四态上色（绿/红/黄/灰）。
**新增纯参数节点 = 只改 SO（0 行代码）**；新增求值配方 = 新增一个 `[BtPreviewKind]` 类（新文件），`BTPreviewRunner` 不改。

## 三、接口与入参出参

| 成员 | 入参 | 出参 | 说明 |
| --- | --- | --- | --- |
| `BTNodeRegistry.All` / `Find` / `FindEntry` | 类型名 | 定义 / SO 条目 | 唯一权威；缺资产/重名/参数引用错都抛异常 |
| `BTPreviewRegistry.Resolve(kind)` | 配方 | 求值器实例 | 每次都 new（求值器可有自己的状态） |
| `IBtPreviewNode.Tick(ctx)` | 上下文 | 四态 | 实现不得抛异常 |
| `BTPreviewContext.TickChildren` | — | 子节点状态数组 | 组合节点用 |
| `BTPreviewRunner.Start/Tick/Stop` | 树 / dt | bool / 状态表 | 200ms 限流；`Stop` 不清黑板 |

## 四、逐段讲解（关键设计落点）

1. **定义搬到 SO**：`BTNodeDefinitionAsset` 持有 `List<BTNodeEntry>`；`BTNodeRegistry` 懒加载 + 校验（空、重名、`MaxChildren`、参数键、`CompareParamKey`/`WriteBackParamKey` 引用）。
2. **预览配方化**：`BTPreviewKind` 共 10 种（含 3 个组合），6 个通用求值器即可覆盖全部叶子节点：
   `IntCompare`（IsDead / HPBelow / HasTarget）、`FloatCompare`（AttackReady）、`Flag`（InAttackRange / HomeFar）、`AlwaysSuccess`（Patrol / Idle / BasicAttack / CastSkill）、`AlwaysRunning`（Chase / ReturnHome）、`Timed`（Wait）。
3. **注册表消除 switch**：`BTPreviewRegistry` 扫描带 `[BtPreviewKind]` 的类，`Resolve` 返回新实例；没有求值器 ⇒ `null` ⇒ 灰态。
4. **第四态灰**：`BTPreviewStatus.NotPreviewed`；`BTNodeView.SetStatus` 加 `bt-status-notpreviewed` 样式类；窗口在出现灰态时提示一次。
5. **写回黑板**：`CastSkill` 成功后把 `skillCd` 写成参数 `cooldownSeconds`（`BTNodeEntry.WriteBackKey` + `WriteBackParamKey`，由 `BTPreviewNodeInstance` 统一处理，不写进求值器）。
6. **黑板扩项**：新增 `inRange`（bool）、`homeFar`（bool）两个开关，供 `Flag` 类条件在预览里手动触发。

### `Data/BTNodeDefinitionAsset.cs`（新增）

```csharp
// 这个文件里有：
//   BTPreviewKind（枚举）：预览求值器的配方种类（决定这个节点在预览里怎么算状态）。
//   BTCompareOp（枚举）：整数/浮点比较的运算符。
//   BTParamEntry（类）：SO 里的一个参数定义（可序列化）。
//   BTNodeEntry（类）：SO 里的一个节点定义（类型名、分类、子节点上限、预览配方、参数表）。
//   BTNodeDefinitionAsset（ScriptableObject）：整份节点定义集合 —— 节点定义以它为准。

using System;
using System.Collections.Generic;
using UnityEngine;

namespace NBC.EditorTools.BehaviorTree
{
    // 预览求值器配方：同一类节点共用一套求值器，避免"每个节点写一个类/一个 switch"
    public enum BTPreviewKind
    {
        // 没配配方 → 预览显示灰色（未实现）
        None = 0,

        // 恒成功（如 Patrol / Idle / BasicAttack）
        AlwaysSuccess = 1,

        // 恒运行中（如 Chase / ReturnHome）
        AlwaysRunning = 2,

        // 读黑板整数键，与常量或参数比较（如 IsDead / HPBelow / HasTarget）
        IntCompare = 3,

        // 读黑板浮点键，与常量或参数比较（如 AttackReady）
        FloatCompare = 4,

        // 读黑板布尔键（如 InAttackRange / HomeFar）
        Flag = 5,

        // 自己的计时器（如 Wait）
        Timed = 6,

        // 组合节点的三种遍历方式
        CompositeSelector = 7,

        // 顺序：遇到 Failure 就失败
        CompositeSequence = 8,

        // 并行：全成功才成功
        CompositeParallel = 9
    }

    // 比较运算符
    public enum BTCompareOp
    {
        // 小于
        Less = 0,

        // 小于等于
        LessOrEqual = 1,

        // 大于
        Greater = 2,

        // 大于等于
        GreaterOrEqual = 3,

        // 等于
        Equal = 4,

        // 不等于
        NotEqual = 5
    }

    // 一个参数定义（SO 里可编辑）
    [Serializable]
    public sealed class BTParamEntry
    {
        // 参数键（JSON 里 Params 的键）
        public string Key = string.Empty;

        // 属性面板显示名
        public string Label = string.Empty;

        // 参数类型（决定控件与 JSON 原生类型）
        public BTParamType Type = BTParamType.Int;

        // 默认值（字符串形式，按类型解析）
        public string Default = "0";
    }

    // 一个节点定义（SO 里可编辑）
    [Serializable]
    public sealed class BTNodeEntry
    {
        // 节点类型名（JSON 的 NodeType；发布后不许改名）
        public string TypeName = string.Empty;

        // 左栏与节点标题显示名
        public string DisplayName = string.Empty;

        // 分类（左栏分组、节点配色）
        public BTNodeCategory Category = BTNodeCategory.Action;

        // 子节点上限：-1 = 不限；0 = 叶子
        public int MaxChildren;

        // 预览配方
        public BTPreviewKind PreviewKind = BTPreviewKind.None;

        // 预览时读的黑板键（如 hp / targetId / skillCd / inRange / homeFar）
        public string PreviewKey = string.Empty;

        // 比较运算符（IntCompare / FloatCompare 用）
        public BTCompareOp CompareOp = BTCompareOp.Less;

        // 阈值参数键（非空则从节点参数取阈值；空则用 CompareConstInt / CompareConstFloat）
        public string CompareParamKey = string.Empty;

        // 整数比较常量（CompareParamKey 为空时用）
        public int CompareConstInt;

        // 浮点比较常量（CompareParamKey 为空时用）
        public float CompareConstFloat;

        // 预览成功时写回黑板的键（如 CastSkill 写 skillCd）；空 = 不写
        public string WriteBackKey = string.Empty;

        // 写回值：从参数取（优先）
        public string WriteBackParamKey = string.Empty;

        // 写回值：常量（WriteBackParamKey 为空时用）
        public float WriteBackConstFloat;

        // 参数表
        public List<BTParamEntry> Params = new List<BTParamEntry>();
    }

    // 主要功能：整份节点定义集合 —— 编辑器左栏、属性面板、预览配方都从这里读；策划可在此增改。
    // 主要数据成员：Nodes（节点定义列表）。
    // 主要外部方法：无（纯数据；加载与校验在 BTNodeRegistry）。
    // 谁在用它：BTNodeRegistry 启动加载；策划在 Inspector 里维护。
    // 注意：TypeName 一经发布不可改名（会破坏已导出的 JSON）；改定义不需要改代码。
    [CreateAssetMenu(fileName = "BTNodeDefinitions", menuName = "AI工具/行为树节点定义")]
    public sealed class BTNodeDefinitionAsset : ScriptableObject
    {
        // 全部节点定义（顺序即左栏显示顺序）
        public List<BTNodeEntry> Nodes = new List<BTNodeEntry>();
    }
}
```

### `Data/BTNodeRegistry.cs`（新增）

```csharp
// 这个文件里有：
//   BTNodeRegistry（静态类）：从 ScriptableObject 加载节点定义、校验、对外提供查询。
//
// 节点定义的唯一权威在这里：左栏、属性面板、端口规则、预览配方都通过它取。

using System;
using System.Collections.Generic;
using UnityEditor;
using UnityEngine;

namespace NBC.EditorTools.BehaviorTree
{
    // 主要功能：把 SO 里的节点定义读成 BTNodeDefine 并缓存；加载失败时抛带路径的异常（不静默空表）。
    // 主要数据成员：s_defines（类型名 → 定义）、s_order（保持顺序）、s_loaded（是否已加载）。
    // 主要外部方法：All / Find / Reload。
    // 谁在用它：BTGraphView、BTInspectorView、BTPreviewRunner、BehaviorTreeEditorWindow。
    // 注意：定义在 SO 里，改定义不需要改代码；但 TypeName 改名会破坏已导出的 JSON。
    public static class BTNodeRegistry
    {
        // 节点定义资产路径（固定位置；策划在这里编辑）
        public const string AssetPath = "Assets/_Project/Editor/BehaviorTree/Resources/BTNodeDefinitions.asset";

        // 类型名 → 定义
        private static readonly Dictionary<string, BTNodeDefine> s_defines =
            new Dictionary<string, BTNodeDefine>(StringComparer.Ordinal);

        // 按 SO 里的顺序保存（左栏显示顺序）
        private static readonly List<BTNodeDefine> s_order = new List<BTNodeDefine>();

        // 是否已加载过
        private static bool s_loaded;

        // 全部定义（只读，按 SO 顺序）
        public static IReadOnlyList<BTNodeDefine> All
        {
            get
            {
                EnsureLoaded();
                return s_order;
            }
        }

        // 功能：提供「该节点定义的 SO 条目」（预览配方要用）。
        // 入参：typeName 类型名
        // 返回：SO 条目；找不到返回 null
        // 步骤：查缓存里的映射
        // 上游：BTPreviewRunner
        // 下游：无
        // 注意：BTNodeDefine 是运行时值对象，SO 条目只用于预览配方；两者由 Reload 同步。
        public static BTNodeEntry FindEntry(string typeName)
        {
            EnsureLoaded();

            if (string.IsNullOrEmpty(typeName))
            {
                return null;
            }

            s_entries.TryGetValue(typeName, out BTNodeEntry entry);
            return entry;
        }

        // 类型名 → SO 条目（与 s_defines 同步维护）
        private static readonly Dictionary<string, BTNodeEntry> s_entries =
            new Dictionary<string, BTNodeEntry>(StringComparer.Ordinal);

        // 功能：按类型名取定义。
        // 入参：typeName 类型名
        // 返回：定义；找不到返回 null
        // 步骤：确保已加载 → 查字典
        // 上游：画布 / 属性面板 / 导入
        // 下游：无
        public static BTNodeDefine Find(string typeName)
        {
            EnsureLoaded();

            if (string.IsNullOrEmpty(typeName))
            {
                return null;
            }

            s_defines.TryGetValue(typeName, out BTNodeDefine define);
            return define;
        }

        // 功能：强制重新加载（改 SO 后、域重载后调用）。
        // 入参：无
        // 返回：无
        // 步骤：清缓存 → 置未加载标记（下次访问重新读）
        // 上游：AssetPostprocessor / 窗口 OnEnable
        // 下游：EnsureLoaded
        public static void Reload()
        {
            s_defines.Clear();
            s_entries.Clear();
            s_order.Clear();
            s_loaded = false;
        }

        // 功能：懒加载 SO 并做校验。
        // 入参：无
        // 返回：无；加载失败抛 InvalidOperationException（消息含资产路径）
        // 步骤：
        //   1) 读 SO；不存在 → 抛错并给出期望路径
        //   2) 遍历条目：TypeName 非空、不重复、MaxChildren 合法、参数键非空且不重复
        //   3) 预习配方校验：CompareParamKey / WriteBackParamKey 必须存在于参数表
        //   4) 建 BTNodeDefine 值对象并缓存
        // 上游：All / Find / FindEntry
        // 下游：无
        private static void EnsureLoaded()
        {
            if (s_loaded)
            {
                return;
            }

            s_loaded = true;

            BTNodeDefinitionAsset asset = AssetDatabase.LoadAssetAtPath<BTNodeDefinitionAsset>(AssetPath);

            if (asset == null)
            {
                throw new InvalidOperationException(
                    "[BT] 找不到节点定义资产：\n  " + AssetPath +
                    "\n请在 Project 里右键 → Create → AI工具/行为树节点定义，创建在该路径下（或用菜单自动创建）。");
            }

            if (asset.Nodes == null || asset.Nodes.Count == 0)
            {
                throw new InvalidOperationException("[BT] 节点定义资产里没有任何节点：" + AssetPath);
            }

            for (int i = 0; i < asset.Nodes.Count; i++)
            {
                BTNodeEntry entry = asset.Nodes[i];
                ValidateEntry(entry, i, asset.Nodes);

                BTNodeDefine define = ToDefine(entry);
                s_defines[define.TypeName] = define;
                s_entries[define.TypeName] = entry;
                s_order.Add(define);
            }
        }

        // 功能：校验单个条目（抛错时带条目序号与类型名）。
        // 入参：entry 条目；index 序号；all 全部条目（查重名）
        // 返回：无；非法抛 InvalidOperationException
        // 步骤：逐项检查类型名、重复、子节点上限、参数键、引用键
        // 上游：EnsureLoaded
        // 下游：无
        private static void ValidateEntry(BTNodeEntry entry, int index, List<BTNodeEntry> all)
        {
            if (entry == null)
            {
                throw new InvalidOperationException("[BT] 第 " + index + " 个节点定义是空的（null）。");
            }

            if (string.IsNullOrEmpty(entry.TypeName))
            {
                throw new InvalidOperationException("[BT] 第 " + index + " 个节点定义缺少 TypeName。");
            }

            for (int i = 0; i < index; i++)
            {
                if (all[i] != null && all[i].TypeName == entry.TypeName)
                {
                    throw new InvalidOperationException("[BT] 节点类型重复：" + entry.TypeName + "（第 " + index + " 个与第 " + i + " 个）。");
                }
            }

            if (entry.MaxChildren < -1)
            {
                throw new InvalidOperationException("[BT] 节点 " + entry.TypeName + " 的 MaxChildren 非法（只能 -1 或 >= 0）。");
            }

            if (entry.Params == null)
            {
                entry.Params = new List<BTParamEntry>();
            }

            for (int i = 0; i < entry.Params.Count; i++)
            {
                BTParamEntry param = entry.Params[i];

                if (param == null || string.IsNullOrEmpty(param.Key))
                {
                    throw new InvalidOperationException("[BT] 节点 " + entry.TypeName + " 的第 " + i + " 个参数缺少 Key。");
                }

                for (int j = 0; j < i; j++)
                {
                    if (entry.Params[j] != null && entry.Params[j].Key == param.Key)
                    {
                        throw new InvalidOperationException("[BT] 节点 " + entry.TypeName + " 的参数键重复：" + param.Key);
                    }
                }
            }

            ValidateParamReference(entry, entry.CompareParamKey);
            ValidateParamReference(entry, entry.WriteBackParamKey);
        }

        // 功能：校验「引用了某个参数键」的字段确实存在于参数表。
        // 入参：entry 条目；key 引用的参数键（空 = 不检查）
        // 返回：无；不存在抛异常
        // 步骤：空直接返回；否则在 Params 里找
        // 上游：ValidateEntry
        // 下游：无
        private static void ValidateParamReference(BTNodeEntry entry, string key)
        {
            if (string.IsNullOrEmpty(key))
            {
                return;
            }

            for (int i = 0; i < entry.Params.Count; i++)
            {
                if (entry.Params[i] != null && entry.Params[i].Key == key)
                {
                    return;
                }
            }

            throw new InvalidOperationException(
                "[BT] 节点 " + entry.TypeName + " 引用了不存在的参数键：" + key + "（预览配方配置错误）。");
        }

        // 功能：把 SO 条目转成运行时值对象。
        // 入参：entry SO 条目
        // 返回：BTNodeDefine
        // 步骤：复制基础字段 + 参数表（类型与默认值原样带过去）
        // 上游：EnsureLoaded
        // 下游：无
        private static BTNodeDefine ToDefine(BTNodeEntry entry)
        {
            BTParamDefine[] parameters = new BTParamDefine[entry.Params.Count];

            for (int i = 0; i < entry.Params.Count; i++)
            {
                BTParamEntry param = entry.Params[i];
                parameters[i] = new BTParamDefine
                {
                    Key = param.Key,
                    Label = param.Label,
                    Type = param.Type,
                    DefaultValue = param.Default
                };
            }

            return new BTNodeDefine
            {
                TypeName = entry.TypeName,
                DisplayName = entry.DisplayName,
                Category = entry.Category,
                MaxChildren = entry.MaxChildren,
                Params = parameters
            };
        }
    }
}
```

### `Data/BTNodeDefine.cs`（改写：删掉硬编码定义）

```csharp
// 这个文件里有：
//   BTNodeCategory（枚举）：节点分类（组合 / 条件 / 动作），决定左栏分组。
//   BTParamDefine（结构体）：一个参数的定义（键、显示名、类型、默认值）。
//   BTNodeDefine（类）：一种节点的运行时值对象（从 SO 定义映射而来）。
//
// 注意：节点定义的**数据源是 BTNodeDefinitionAsset（SO）**，由 BTNodeRegistry 加载；
//       本文件只保留"值对象"与"按定义造节点数据"这两件事，不再硬编码任何节点类型。

using System.Globalization;

namespace NBC.EditorTools.BehaviorTree
{
    // 节点分类：左栏按这个分组，也用于快速判断端口规则
    public enum BTNodeCategory
    {
        // 组合节点（有子节点）：Selector / Sequence / Parallel
        Composite = 0,

        // 条件节点（无子节点）：IsDead / HasTarget / InAttackRange / AttackReady / HPBelow / HomeFar
        Condition = 1,

        // 动作节点（无子节点）：Chase / BasicAttack / CastSkill / ReturnHome / Patrol / Idle / Wait
        Action = 2
    }

    // 一个参数的定义：告诉属性面板「出什么控件」、导出时「什么类型」
    public struct BTParamDefine
    {
        // 参数键（JSON 里 Params 的键）
        public string Key;

        // 属性面板上显示的名字（可以带中文说明）
        public string Label;

        // 参数类型：决定控件与 JSON 原生类型
        public BTParamType Type;

        // 默认值的字符串形式（新建节点时用它初始化）
        public string DefaultValue;

        // 功能：按定义造出默认参数值。
        // 入参：无
        // 返回：带类型的参数值
        // 步骤：按 Type 解析 DefaultValue，解析失败就用类型零值
        // 上游：BTNodeData.EnsureDefaults、BTGraphView.CreateNode
        // 下游：无
        public BTParamValue CreateDefault()
        {
            switch (Type)
            {
                case BTParamType.Int:
                    int.TryParse(DefaultValue, NumberStyles.Integer, CultureInfo.InvariantCulture, out int intValue);
                    return BTParamValue.FromInt(intValue);

                case BTParamType.Bool:
                    bool.TryParse(DefaultValue, out bool boolValue);
                    return BTParamValue.FromBool(boolValue);

                case BTParamType.String:
                    return BTParamValue.FromString(DefaultValue ?? string.Empty);

                default:
                    float.TryParse(DefaultValue, NumberStyles.Float, CultureInfo.InvariantCulture, out float floatValue);
                    return BTParamValue.FromFloat(floatValue);
            }
        }
    }

    // 主要功能：描述一种节点「长什么样、能配什么参数」，左栏与属性面板都靠它自动生成。
    // 主要数据成员：TypeName / DisplayName / Category / MaxChildren / Params。
    // 主要外部方法：CreateNodeData（造带默认参数的节点数据）。
    // 谁在用它：BTNodeRegistry（产出）、BTNodePalette、BTInspectorView、BTGraphView（端口规则）。
    // 注意：TypeName 就是 JSON 里的 NodeType，**改动会破坏已导出的树**，别随手改名。
    public sealed class BTNodeDefine
    {
        // 类型名（JSON 的 NodeType）；服务端按这个字符串找节点工厂
        public string TypeName = string.Empty;

        // 左栏/节点标题显示的名字
        public string DisplayName = string.Empty;

        // 分类（决定左栏分组与节点配色）
        public BTNodeCategory Category = BTNodeCategory.Action;

        // 最多能连几个子节点：-1 = 不限（组合节点），0 = 叶子（条件/动作）
        public int MaxChildren = -1;

        // 参数定义表；顺序即属性面板显示顺序
        public BTParamDefine[] Params = new BTParamDefine[0];

        // 功能：造一个带默认参数的节点数据。
```

```csharp
    [AttributeUsage(AttributeTargets.Class, Inherited = false, AllowMultiple = false)]

    // 主要数据成员：s_factories（配方 → 创建函数）、s_scanned（是否已扫描）。
    // 主要外部方法：Resolve（取新实例；没有返回 null ⇒ 灰态）、Invalidate（域重载后重扫）。
    // 谁在用它：BTPreviewNodeInstance。
    // 注意：每次 Resolve 都 new 一个实例 —— 求值器可能有自己的计时状态（如 Timed），不能共享。
    public static class BTPreviewRegistry
    {
        // 配方 → 创建函数
        private static readonly Dictionary<BTPreviewKind, Func<IBtPreviewNode>> s_factories =
            new Dictionary<BTPreviewKind, Func<IBtPreviewNode>>();

        // 是否已扫描
        private static bool s_scanned;

        // 功能：按配方取一个**新**求值器实例。
        // 入参：kind 配方
        // 返回：实例；没有对应求值器返回 null（调用方当灰态处理）
        // 步骤：确保已扫描 → 查表 → 调用工厂
        // 上游：BTPreviewNodeInstance 构造
        // 下游：无
        public static IBtPreviewNode Resolve(BTPreviewKind kind)
        {
            EnsureScanned();

            return s_factories.TryGetValue(kind, out Func<IBtPreviewNode> factory) ? factory() : null;
        }

        // 功能：清空扫描缓存（Unity 域重载后调用）。
        // 入参：无
        // 返回：无
        // 步骤：清表 + 置未扫描
        // 上游：预览开始前 / 初始化
        // 下游：无
        public static void Invalidate()
        {
            s_factories.Clear();
            s_scanned = false;
        }

        // 功能：扫描当前程序集里带 [BtPreviewKind] 的类并登记。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 遍历本程序集类型
        //   2) 找实现 IBtPreviewNode 且带特性、有公共无参构造的类型
        //   3) 登记创建函数（同配方后出现的覆盖先出现的，便于扩展）
        // 上游：Resolve
        // 下游：无
        private static void EnsureScanned()
        {
            if (s_scanned)
            {
                return;
            }

            s_scanned = true;

            Assembly assembly = typeof(BTPreviewRegistry).Assembly;
            Type[] types = assembly.GetTypes();

            for (int i = 0; i < types.Length; i++)
            {
                Type type = types[i];

                if (type.IsAbstract || !typeof(IBtPreviewNode).IsAssignableFrom(type))
                {
                    continue;
                }

                BtPreviewKindAttribute attribute = type.GetCustomAttribute<BtPreviewKindAttribute>();

                if (attribute == null)
                {
                    continue;
                }

                if (type.GetConstructor(Type.EmptyTypes) == null)
                {
                    continue;
                }

                BTPreviewKind kind = attribute.Kind;

                // 重复注册：警告并**保留先登记的**（先到先得，保证结果确定；静默覆盖会让"谁生效"取决于扫描顺序）
                if (s_factories.ContainsKey(kind))
                {
                    Debug.LogWarning("[BT] 预览配方 " + kind + " 被多个类注册，已忽略后出现的：" + type.FullName);
                    continue;
                }

                s_factories[kind] = () => (IBtPreviewNode)Activator.CreateInstance(type);
            }
        }
    }
}
```

```csharp
        // 返回：浮点值

        // 上游：求值器
        // 下游：无
        public float GetFloat(string key)
        {
            return m_values.TryGetValue(key, out BTParamValue value) ? value.AsFloat() : 0f;
        }

        // 功能：取原始参数值（界面显示用）。
        // 入参：key 键；value 命中的值
        // 返回：true = 键存在
        // 步骤：查字典
        // 上游：黑板面板 / Flag 求值器
        // 下游：无
        public bool TryGet(string key, out BTParamValue value)
        {
            return m_values.TryGetValue(key, out value);
        }

        // 功能：清空黑板。
        // 入参：无
        // 返回：无
        // 步骤：清字典
        // 上游：窗口关闭 / 停止预览（注意：Stop 不清，只有清空画布等显式操作才清）
        // 下游：无
        public void Clear()
        {
            m_values.Clear();
        }
    }

    // 运行时的一棵预览树节点：持有数据、SO 定义、求值器与子节点
    internal sealed class BTPreviewNodeInstance
    {
        // 节点 id（回传状态用）
        public string NodeId;

        // 节点数据（读 Params）
        public BTNodeData Data;

        // SO 定义（读预览配方）
        public BTNodeEntry Entry;

        // 求值器；null = 未实现（灰态）
        public IBtPreviewNode Behavior;

        // 子节点（顺序与数据一致）
        public List<BTPreviewNodeInstance> Children = new List<BTPreviewNodeInstance>();

        // 功能：跑一帧并把状态回写给调用方。
        // 入参：blackboard 黑板；deltaSeconds 帧间隔；statusMap 状态收集表
        // 返回：本节点状态
        // 步骤：
        //   1) 没有求值器 ⇒ NotPreviewed（灰）
        //   2) 组装上下文（含驱动子节点的委托）
        //   3) 调求值器；异常兜成 Failure 并写日志
        //   4) 成功时按定义做「写回黑板」（如 CastSkill 写 skillCd）
        //   5) 记录到 statusMap
        // 上游：BTPreviewRunner.Tick（根）/ 父节点
        // 下游：IBtPreviewNode.Tick
        public BTPreviewStatus Tick(BTBlackboard blackboard, float deltaSeconds,
            Dictionary<string, BTPreviewStatus> statusMap)
        {
            if (Behavior == null)
            {
                statusMap[NodeId] = BTPreviewStatus.NotPreviewed;
                return BTPreviewStatus.NotPreviewed;
            }

            BTPreviewContext context = new BTPreviewContext
            {
                Blackboard = blackboard,
                DeltaSeconds = deltaSeconds,
                Data = Data,
                Entry = Entry,
                TickChildren = () =>
                {
                    BTPreviewStatus[] result = new BTPreviewStatus[Children.Count];

                    for (int i = 0; i < Children.Count; i++)
                    {
                        result[i] = Children[i].Tick(blackboard, deltaSeconds, statusMap);
                    }

                    return result;
                }
            };

            BTPreviewStatus status;

            try
            {
                status = Behavior.Tick(context);
            }
            catch (Exception exception)
            {
                Debug.LogWarning("[BT] 预览求值器异常（按失败处理）：" + NodeId + " → " + exception.Message);
                status = BTPreviewStatus.Failure;
            }

            if (status == BTPreviewStatus.Success && Entry != null && !string.IsNullOrEmpty(Entry.WriteBackKey))
            {
                float value = string.IsNullOrEmpty(Entry.WriteBackParamKey)
                    ? Entry.WriteBackConstFloat
                    : (float)BtPreviewMath.ReadParam(context, Entry.WriteBackParamKey, Entry.WriteBackConstFloat);

                blackboard.Set(Entry.WriteBackKey, BTParamValue.FromFloat(value));
            }

            statusMap[NodeId] = status;
            return status;
        }

        // 功能：重置整棵子树的求值器状态。
        // 入参：无
        // 返回：无
        // 步骤：Behavior.Reset + 递归子节点
        // 上游：BTPreviewRunner.Start
        // 下游：无
        public void Reset()
        {
            Behavior?.Reset();

            for (int i = 0; i < Children.Count; i++)
            {
                Children[i].Reset();
            }
        }
    }

    // 主要功能：预览驱动器 —— 从画布快照建预览树，按 200ms 驱动，回收四态。
    // 主要数据成员：m_root（预览树根）、m_status（节点 id → 四态）、m_blackboard、m_accumulator。
    // 主要外部方法：Start / Tick / Stop。
    // 谁在用它：BehaviorTreeEditorWindow。
    // 注意：只跑在编辑器；**不写回画布数据**（状态只用于上色）。
    public sealed class BTPreviewRunner
    {
        // 预览树根；null = 没在预览
        private BTPreviewNodeInstance m_root;

        // 节点 id → 最近一次状态
        private readonly Dictionary<string, BTPreviewStatus> m_status = new Dictionary<string, BTPreviewStatus>();

        // 黑板
        private readonly BTBlackboard m_blackboard = new BTBlackboard();

        // Tick 间隔（秒）：200ms
        private const float IntervalSeconds = 0.2f;

        // 累积时间
        private float m_accumulator;

        // 是否正在预览
        public bool IsRunning => m_root != null;

        // 黑板
        public BTBlackboard Blackboard => m_blackboard;

        // 最近一次状态表
        public IReadOnlyDictionary<string, BTPreviewStatus> Status => m_status;

        // 最近一次状态里有没有「未实现」的节点（窗口用来提示一次）
        public bool HasNotPreviewed
        {
            get
            {
                foreach (KeyValuePair<string, BTPreviewStatus> pair in m_status)
                {
                    if (pair.Value == BTPreviewStatus.NotPreviewed)
                    {
                        return true;
                    }
                }

                return false;
            }
        }

        // 功能：用画布数据快照开始预览。
        // 入参：data 树数据（内部 Clone，彻底与画布分离）；error 失败原因
        // 返回：true = 已开始
        // 步骤：校验树 → 找根 → 递归建预览树 → 清状态与计时
        // 上游：窗口的【预览】按钮
        // 下游：BuildInstance
        public bool Start(BTGraphData data, out string error)
        {
            m_status.Clear();
            m_accumulator = 0f;
            m_root = null;

            if (data == null)
            {
                error = "没有可预览的树数据。";
                return false;
            }

            if (!data.Validate(out error))
            {
                return false;
            }

            BTGraphData snapshot = data.Clone();
            string rootId = string.IsNullOrEmpty(snapshot.RootNodeId) ? data.FindRootId() : snapshot.RootNodeId;

            if (string.IsNullOrEmpty(rootId) || !snapshot.Nodes.ContainsKey(rootId))
            {
                error = "找不到根节点。";
                return false;
            }

            m_root = BuildInstance(snapshot, rootId);
            m_root.Reset();
            error = string.Empty;
            return true;
        }

        // 功能：停止预览（**不清黑板**：黑板是用户填的测试值）。
        // 入参：无
        // 返回：无
        // 步骤：丢根、清状态与计时
        // 上游：窗口的【停止预览】/ OnDisable
        // 下游：无
        public void Stop()
        {
            m_root = null;
            m_status.Clear();
            m_accumulator = 0f;
        }

        // 功能：按 200ms 间隔推进一帧。
        // 入参：deltaSeconds 距上一帧的秒数
        // 返回：true = 这一次真的 Tick 了
        // 步骤：累积时间 → 不到间隔返回 → 扣技能冷却 → Tick 根 → 收集状态
        // 上游：窗口的 EditorApplication.update
        // 下游：BTPreviewNodeInstance.Tick
        public bool Tick(float deltaSeconds)
        {
            if (m_root == null)
            {
                return false;
            }

            m_accumulator += deltaSeconds;

            if (m_accumulator < IntervalSeconds)
            {
                return false;
            }

            float step = m_accumulator;
            m_accumulator = 0f;

            float cooldown = m_blackboard.GetFloat("skillCd");

            if (cooldown > 0f)
            {
                m_blackboard.Set("skillCd", BTParamValue.FromFloat(Math.Max(0f, cooldown - step)));
            }

            m_status.Clear();
            m_root.Tick(m_blackboard, step, m_status);
            return true;
        }

        // 功能：按数据递归建预览树（取定义 → 取求值器 → 递归子节点）。
        // 入参：data 快照；id 节点 id
        // 返回：预览树节点
        // 步骤：
        //   1) 取节点数据与 SO 定义
        //   2) 按定义的 PreviewKind 找求值器（找不到 ⇒ null ⇒ 灰态）
        //   3) 递归子节点
        // 上游：Start
        // 下游：BTPreviewRegistry.Resolve
        private BTPreviewNodeInstance BuildInstance(BTGraphData data, string id)
        {
            BTPreviewNodeInstance instance = new BTPreviewNodeInstance { NodeId = id };

            if (!data.Nodes.TryGetValue(id, out BTNodeData nodeData))
            {
                return instance;
            }

            instance.Data = nodeData;

            BTNodeEntry entry = BTNodeRegistry.FindEntry(nodeData.NodeType);
            instance.Entry = entry;

            if (entry != null && entry.PreviewKind != BTPreviewKind.None)
            {
                instance.Behavior = BTPreviewRegistry.Resolve(entry.PreviewKind);
            }

            for (int i = 0; i < nodeData.Children.Count; i++)
            {
                instance.Children.Add(BuildInstance(data, nodeData.Children[i]));
            }

            return instance;
        }
    }
}
```

## 七、风险与幻觉自查

- 幻觉自查：只用 `ScriptableObject` / `AssetDatabase` / `VisualElement` / `Toggle` / `FloatField` / `Attribute + Assembly.GetTypes`，均为既有 API。
- 实施中处理的点：
  1. `Server\_api-probe` 是**本地工程**（不进仓库），它包含 `Editor\**`，缺 `UnityEngine.UIElementsModule` / `TextRenderingModule` 引用 ⇒ 已在本地 csproj 补上（与 asmdef 闸门同一招）。
  2. 节点定义从 14 条修正为 **16 条**（`Patrol` 与 `Idle` 是两个条目、`Wait` 单独一条；02/03 的「14」是计数笔误）。
  3. `BTPreviewStatus` 从 `BTPreviewRunner.cs` 移到 `BTPreviewApi.cs`，避免一个文件承担两种职责（S）。
  4. 预览特性加 `Inherited = false`：防止子类继承特性导致同一配方被重复注册。
  5. 重复配方注册改为「警告 + 先到先得」：静默覆盖会让「谁生效」取决于扫描顺序，难排查。
- 行为变化：旧 JSON 若含 `MoveTo` 会导入失败（类型未注册），属预期（负责人已确认不用管）。
