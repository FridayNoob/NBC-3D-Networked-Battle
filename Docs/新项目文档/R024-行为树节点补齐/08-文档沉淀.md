## 二、模块文档

### 2.1 节点定义（`Data/BTNodeDefinitionAsset.cs` + `Data/BTNodeRegistry.cs`）

- **简介**：整套节点库是**一份 SO 资产**（`Resources/BTNodeDefinitions.asset`），16 条定义；注册表负责加载、校验、对外查询。
- **接口**：`BTNodeRegistry.All`（按 SO 顺序）/ `Find(typeName)` / `FindEntry(typeName)` / `Reload()`。
- **示例（加一个"血量低于 90"的条件，零代码）**：
  在 SO 里加一条 → `TypeName=HPBelow90`、`Category=Condition`、`MaxChildren=0`、`PreviewKind=IntCompare`、`PreviewKey=hp`、`CompareOp=Less`、`CompareConstInt=90` → 左栏立刻出现、预览立刻能变色。
- **原理**：定义是数据，UI（左栏/属性面板/端口规则）与预览配方都由定义驱动，所以"加定义"不改代码。
- **坑**：`TypeName` 是**协议**（JSON 的 `NodeType`），发布后不许改名；删名会让旧 JSON 导入失败。
- **维护**：改 SO 会自动热刷新（`BTNodeDefinitionsWatcher`）；注册表校验会拦住重名、空名、参数键重复、`CompareParamKey`/`WriteBackParamKey` 指向不存在的参数。

### 2.2 预览扩展点（`Preview/BTPreviewApi.cs` + `PreviewKinds.cs` + `CompositePreviews.cs`）

- **简介**：节点在编辑器里"假装跑一遍"的机制；四态（Success/Failure/Running/**NotPreviewed**）。
- **接口**：`IBtPreviewNode.Tick(ctx)` / `Reset()`；`[BtPreviewKind(kind)]` 注册；`BTPreviewRegistry.Resolve(kind)`；`BTPreviewContext`（黑板、参数、驱动子节点、写回黑板）。
- **示例（加一种全新预览行为）**：新建一个类 →
  `[BtPreviewKind(BTPreviewKind.Timed)] sealed class MyPreview : IBtPreviewNode { public BTPreviewStatus Tick(...){...} }`
  → 注册表扫描到即生效，`BTPreviewRunner` 一行不改。
- **原理**：`PreviewKind`（数据）决定用哪套通用算法；6 个通用求值器 + 3 个组合覆盖 16 个节点。
- **坑**：一个 kind 只能有一个类（重复注册会警告并保留先出现的）；求值器**不得抛异常**（Runner 会兜成 Failure 并写日志）。
- **维护**：加节点先看能不能用现有 kind + 参数表达；不能才加类。

### 2.3 校验与图操作（`Data/BTGraphData.cs` + `View/BTGraphView.cs`）

- **简介**：画布是唯一数据源，导出时由连线重建 `Children`；`Validate` 是预览/导出前的闸门。
- **接口**：`ExportData(treeId)`（去重后的快照）/ `RemoveDanglingReferences()` / `Validate(out error)`。
- **示例（排查预览失败）**：看状态栏消息 → 四类：`引用了不存在的子节点`（脏引用）/`重复引用了子节点`/`有多个父节点`/`检测到环`/`有节点无法从根到达`。
- **原理**：单父 + 多子（按 `MaxChildren`）+ 无环；根必须唯一。
- **坑**：删节点/断连线必须同步 `Children`（已由 `RemoveNode` + 三处兜底处理）；连接前要查重。
- **维护**：改连线规则只动 `OnGraphViewChanged` 与 `CompleteConnection` 两处。

## 三、踩坑清单

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 改 SO 后左栏/属性面板不更新 | 注册表缓存 + 无资产监听 | `BTNodeDefinitionsWatcher` 热刷新；绑定取最新定义 |
| 预览报「引用了不存在的子节点」 | `RemoveNode` 未清父节点 `Children` | `RemoveDanglingReferences()` + 删/导入/预览三处兜底 |
| 预览报「检测到环：n2 被重复访问」 | 同一对节点存在两条边 | 连接查重 + 导出去重 + 校验四类分开报 |
| 一段代码被重复拼接 12 次仍能编译 | 用 PowerShell 行拼接写 C#，数组被当单元素 | 改 C# 用整段替换；提交前查**最长行 < 200 字符** |
| 文档写 14 个节点，实际 16 | `Patrol/Idle/Wait` 计数笔误 | 本文与索引统一按 **16**（3+6+7） |
