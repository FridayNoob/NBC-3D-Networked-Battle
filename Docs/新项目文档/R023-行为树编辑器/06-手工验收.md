## 三、异常场景

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| 布局塌成竖排、画布高度 0 | USS 只加给 GraphView，没加窗口根 | 加在 `rootVisualElement.styleSheets` |
| 节点没有圆点 | 输入端口按「根」被删掉 | 端口常驻，改「根」徽标 |
| 拖线连不上 | GraphView 自带 EdgeConnector 不认目标 | 自研拖拽（TrickleDown + Painter2D） |
| 连第二个子节点时前一条消失 | 「一输出一连」对所有节点生效 | 按 `MaxChildren` 区分 |
| 看不见的节点仍算根 | 内建删除绕过 `graphViewChanged` | 重写 `DeleteSelection` + 导出前剪枝 |
| hp=100 却成功 | `Stop()` 清空黑板 | 不再清；预览前同步面板值 |

## 四、性能表现

- 200ms Tick 只在窗口打开且预览中运行；节点数十个以内无卡顿。
