## 二、功能概述

菜单 `AI工具/BehaviorTree Editor` 打开窗口：左节点库（拖拽/点击新建）、中画布（拖拽移动、端口连线、右键菜单）、右属性面板（按节点定义生成控件）+ 黑板（预览用）。
预览按 200ms Tick，节点三色；导出/导入严格按约定 Schema 的 JSON。

## 三、接口与入参出参

| 成员 | 入参 | 出参 | 说明 |
| --- | --- | --- | --- |
| `BTNodeRegistry.Register(BTNodeDefine)` | 节点定义 | 无 | **新增自定义节点的唯一入口** |
| `BTGraphData.Validate(out string)` | — | bool + 原因 | 空树 / 唯一根 / 悬空引用 / 环 |
| `BTGraphData.FindRootIds()` | — | 根 id 列表 | 报错时列出「是哪几个」 |
| `BTJsonUtil.Export(BTGraphData)` | 树 | JSON 文本 | 字段顺序固定、参数保持原生类型 |
| `BTJsonUtil.Import(string)` | JSON | 树 | 按节点定义强转参数类型 |
| `BTPreviewRunner.Start(data, out err)` | 树（会 Clone） | bool | 预览与画布数据分离 |
| `BTPreviewRunner.Tick(deltaSeconds)` | 帧间隔 | bool（是否真跑了一帧） | 内部按 200ms 限流 |
| `BTGraphView.CreateNode(type, pos)` | 类型 + 位置 | 节点视图 | 自动避重叠 |
| `BTGraphView.ExportData(treeId)` | 树名 | 树数据 | 位置/连线以画面为准，并清理幽灵节点 |

## 四、逐段讲解（关键设计）

1. **数据与 UI 彻底分离**：`BTGraphData/BTNodeData` 不含任何 `VisualElement`；画布只做「读数据 → 建视图 / 写视图 → 改数据」。
2. **节点定义驱动 UI**：左栏按 `BTNodeCategory` 分组自动生成；右栏按 `BTNodeDefine.Params` 自动生成控件 —— 加节点不用改界面代码。
3. **连线规则集中在两处**：`CompleteConnection`（鼠标拖拽）与 `OnGraphViewChanged`（GraphView 内建路径）都走同一套校验（自连、成环、单父、按 `MaxChildren` 决定单子/多子）。
4. **必须重写 `DeleteSelection`**：GraphView 内建的 Delete 键/右键 Delete 走 `DeleteElements`，**不触发** `graphViewChanged`，不接管就会留下「幽灵节点」（看不见但还算一个根）。
5. **输入端口常驻**：不能因为「暂时没有父节点」就把输入口删掉（那样新节点永远连不上）；「唯一根」用标题旁「根」徽标 + 导出校验表达。
6. **预览是另一套对象**：`BTPreviewNode` 由 `BTGraphData.Clone()` 构建，三色只写 USS class，绝不回写参数。
7. **黑板不在 Stop 时清空**：否则会出现「面板显示 100、条件读到 0」；开预览前用 `SyncBlackboardFromFields()` 对齐。
8. **自研 JSON**：工程没有 Newtonsoft，`JsonUtility` 不支持字典与动态类型 ⇒ 手写递归下降解析器（带行列报错）；导出时参数按类型写原生 JSON 值。

```csharp
// 这个文件里有：
//   BTParamType（枚举）：参数类型（float / int / bool / string 四型）。
//   BTParamValue（结构体）：一个参数的取值，带类型标签，导出 JSON 时保持原生类型。

using System;
using System.Globalization;

namespace NBC.EditorTools.BehaviorTree
{
    // 参数类型。JSON 里要写成原生值（数字/布尔/字符串），所以类型必须跟着值一起存。
    public enum BTParamType
    {
        // 浮点数，JSON 里是数字
        Float = 0,

        // 整数，JSON 里是数字（不带小数点）
        Int = 1,

        // 布尔，JSON 里是 true / false
        Bool = 2,

        // 字符串，JSON 里是带引号的字符串
        String = 3
    }

    // 主要功能：装一个参数的「类型 + 值」，是数据模型与 JSON 之间的唯一转换点。
    // 主要数据成员：Type（类型标签）与四个类型的取值字段。
    // 主要外部方法：FromFloat / FromInt / FromBool / FromString（构造）、AsFloat / AsInt / AsBool / AsString（读取）、ToInvariant。
    // 谁在用它：BTNodeData.Params、BTInspectorView（按类型出控件）、BTJsonUtil（写成 JSON 原生值）。
    // 注意：结构体是值类型，改它要先取出来、改完再放回字典，别指望"改副本能改到字典里"。
    [Serializable]
    public struct BTParamValue
    {
        // 这个值是什么类型；决定 JSON 里输出成数字、布尔还是字符串
        public BTParamType Type;

        // 浮点取值（Type == Float 时有效）
        public float FloatValue;

        // 整数取值（Type == Int 时有效）
        public int IntValue;

        // 布尔取值（Type == Bool 时有效）
        public bool BoolValue;

        // 字符串取值（Type == String 时有效）
        public string StringValue;

        // 功能：造一个浮点参数。
        // 入参：value 值
        // 返回：带 Float 类型标签的参数
        // 步骤：设类型与对应字段
        // 上游：节点定义里的默认值、属性面板改值
        // 下游：字典写入
        public static BTParamValue FromFloat(float value)
        {
            return new BTParamValue { Type = BTParamType.Float, FloatValue = value };
        }

        // 功能：造一个整数参数。
        // 入参：value 值
        // 返回：带 Int 类型标签的参数
        // 步骤：设类型与对应字段
        // 上游：节点定义里的默认值、属性面板改值
        // 下游：字典写入
        public static BTParamValue FromInt(int value)
        {
            return new BTParamValue { Type = BTParamType.Int, IntValue = value };
        }

        // 功能：造一个布尔参数。
        // 入参：value 值
        // 返回：带 Bool 类型标签的参数
        // 步骤：设类型与对应字段
        // 上游：节点定义里的默认值、属性面板改值
        // 下游：字典写入
        public static BTParamValue FromBool(bool value)
        {
            return new BTParamValue { Type = BTParamType.Bool, BoolValue = value };
        }

        // 功能：造一个字符串参数。
        // 入参：value 值
        // 返回：带 String 类型标签的参数
        // 步骤：设类型与对应字段
        // 上游：节点定义里的默认值、属性面板改值
        // 下游：字典写入
        public static BTParamValue FromString(string value)
        {
            return new BTParamValue { Type = BTParamType.String, StringValue = value ?? string.Empty };
        }

        // 功能：按浮点读值（别的类型会尽量转换）。
        // 入参：无
        // 返回：浮点值
        // 步骤：按类型分支转换
        // 上游：预览运行时的执行器
        // 下游：无
        public float AsFloat()
        {
            switch (Type)
            {
                case BTParamType.Float:
                    return FloatValue;
                case BTParamType.Int:
                    return IntValue;
                case BTParamType.Bool:
                    return BoolValue ? 1f : 0f;
                default:
                    float.TryParse(StringValue, NumberStyles.Float, CultureInfo.InvariantCulture, out float parsed);
                    return parsed;
            }
        }

        // 功能：按整数读值。
        // 入参：无
        // 返回：整数值（浮点会四舍五入）
        // 步骤：按类型分支转换
        // 上游：预览运行时的执行器
        // 下游：无
        public int AsInt()
        {
            switch (Type)
            {
                case BTParamType.Int:
                    return IntValue;
                case BTParamType.Float:
                    return (int)Math.Round(FloatValue);
                case BTParamType.Bool:
                    return BoolValue ? 1 : 0;
                default:
                    int.TryParse(StringValue, out int parsed);
                    return parsed;
            }
        }

        // 功能：按布尔读值。
        // 入参：无
        // 返回：布尔值（数字非 0 视为 true）
        // 步骤：按类型分支转换
        // 上游：预览运行时的执行器
        // 下游：无
        public bool AsBool()
        {
            switch (Type)
            {
                case BTParamType.Bool:
                    return BoolValue;
                case BTParamType.Int:
                    return IntValue != 0;
                case BTParamType.Float:
                    return Math.Abs(FloatValue) > float.Epsilon;
                default:
                    return bool.TryParse(StringValue, out bool parsed) && parsed;
            }
        }

        // 功能：按字符串读值。
        // 入参：无
        // 返回：字符串（数字用不变文化格式化）
        // 步骤：按类型分支格式化
        // 上游：属性面板显示、JSON 输出
        // 下游：无
        public string AsString()
        {
            switch (Type)
            {
                case BTParamType.String:
                    return StringValue ?? string.Empty;
                case BTParamType.Int:
                    return IntValue.ToString(CultureInfo.InvariantCulture);
                case BTParamType.Bool:
                    return BoolValue ? "true" : "false";
                default:
                    return FloatValue.ToString("0.###", CultureInfo.InvariantCulture);
            }
        }

        // 功能：给属性面板/节点标题用的一行文本。
        // 入参：无
        // 返回：「类型:值」
        // 步骤：拼类型名与 AsString
        // 上游：BTNodeView 标题
        // 下游：无
        public string ToDisplay()
        {
            return Type + ":" + AsString();
        }
    }
}
```

### `Data/BTGraphData.cs`

```csharp
// 这个文件里有：
//   BTNodeData（类）：一个节点的纯数据（类型、画布位置、参数、子节点 id 列表）。
//   BTGraphData（类）：整棵树的数据（TreeId / RootNodeId / Nodes）+ 校验。

using System;
using System.Collections.Generic;
using System.Text;

namespace NBC.EditorTools.BehaviorTree
{
    // 主要功能：描述「画布上的一个节点」而不含任何 UI 对象 —— 这是导出 JSON 与预览运行时共用的唯一模型。
    // 主要数据成员：NodeType（类型名）、PosX/PosY（画布位置）、Params（参数表）、Children（有序子节点 id）。
    // 主要外部方法：Clone（复制节点时用）。
    // 谁在用它：BTGraphView（增删改）、BTInspectorView（改参数）、BTJsonUtil（读写）、BTPreviewRunner（快照）。
    // 注意：Params 用字典而不是字段列表 —— 节点类型是运行时才知道的，参数集随类型变化。
    public sealed class BTNodeData
    {
        // 节点类型名，必须能在 BTNodeRegistry 里找到（同时是 JSON 里的 NodeType 字符串）
        public string NodeType = string.Empty;

        // 画布上的 X 位置（GraphView 的坐标系，单位：像素）
        public float PosX;

        // 画布上的 Y 位置（GraphView 的坐标系，单位：像素）
        public float PosY;

        // 参数表：键是参数定义里的 Key，值是带类型标签的值
        public Dictionary<string, BTParamValue> Params = new Dictionary<string, BTParamValue>();

        // 子节点 id 列表；**顺序有意义**（Selector/Sequence 按顺序跑），叶子为空表
        public List<string> Children = new List<string>();

        // 功能：深拷贝一个节点（复制节点用；避免两个节点共享同一个参数字典）。
        // 入参：无
        // 返回：新节点，字段逐项复制
        // 步骤：新建对象 → 复制基础字段 → 逐个复制参数（值类型直接赋） → 复制子节点 id
        // 上游：BTGraphView.DuplicateSelection
        // 下游：无
        public BTNodeData Clone()
        {
            BTNodeData copy = new BTNodeData
            {
                NodeType = NodeType,
                PosX = PosX,
                PosY = PosY
            };

            foreach (KeyValuePair<string, BTParamValue> pair in Params)
            {
                copy.Params[pair.Key] = pair.Value;
            }

            copy.Children.AddRange(Children);
            return copy;
        }

        // 功能：按节点定义补齐缺失的参数（导入旧 JSON、或节点定义新增参数时用）。
        // 入参：define 节点定义（可为 null，null 时什么都不做）
        // 返回：无
        // 步骤：遍历定义里的参数，字典里没有就填默认值
        // 上游：BTGraphView.CreateNode / BTJsonUtil.Import
        // 下游：Params
        // 注意：只补不覆盖 —— 已有值更可信（人是手调过的）
        public void EnsureDefaults(BTNodeDefine define)
        {
            if (define == null)
            {
                return;
            }

            for (int i = 0; i < define.Params.Length; i++)
            {
                BTParamDefine param = define.Params[i];

                if (!Params.ContainsKey(param.Key))
                {
                    Params[param.Key] = param.CreateDefault();
                }
            }
        }
    }

    // 主要功能：装一整棵树的数据，并提供「找根 / 校验（唯一根、环、悬空引用）」。
    // 主要数据成员：TreeId、RootNodeId、Nodes（id → 节点）。
    // 主要外部方法：FindRootId、Validate、Clone、NextNodeId。
    // 谁在用它：BTGraphView、BTJsonUtil、BTPreviewRunner。
    // 注意：RootNodeId 是**导出时计算出来的**；画布上允许暂时为 0 个根（还没连），导出前必须校验。
    public sealed class BTGraphData
    {
        // 树的名字；导出 JSON 的 TreeId
        public string TreeId = "new_tree";

        // 根节点 id；空表示"还没确定根"（由 FindRootId 推出来）
        public string RootNodeId = string.Empty;

        // 所有节点：键是节点 id（n1、n2…），值是该节点的数据
        public Dictionary<string, BTNodeData> Nodes = new Dictionary<string, BTNodeData>();

        // 功能：找出根节点 id —— 即「没有被任何节点当作子节点」的那个。
        // 入参：无
        // 返回：根 id；没有或有多个都返回空串（交给 Validate 报错）
        // 步骤：
        //   1) 把所有 Children 里的 id 收进一个集合
        //   2) 遍历 Nodes，找不在集合里的节点
        //   3) 恰好一个才是根
        // 上游：ExportData / Validate
        // 下游：无
        public string FindRootId()
        {
            List<string> roots = FindRootIds();
            return roots.Count == 1 ? roots[0] : string.Empty;
        }

        // 功能：列出所有根节点 id（没有父节点引用的那些）。
        // 入参：无
        // 返回：根 id 列表（可能是 0 个、1 个或多个）
        // 步骤：
        //   1) 把所有 Children 里的 id 收进集合
        //   2) 遍历 Nodes，不在集合里的就是根
        // 上游：FindRootId / Validate（报错要列出是哪几个）
        // 下游：无
        public List<string> FindRootIds()
        {
            HashSet<string> referenced = new HashSet<string>();

            foreach (KeyValuePair<string, BTNodeData> pair in Nodes)
            {
                for (int i = 0; i < pair.Value.Children.Count; i++)
                {
                    referenced.Add(pair.Value.Children[i]);
                }
            }

            List<string> roots = new List<string>();

            foreach (KeyValuePair<string, BTNodeData> pair in Nodes)
            {
                if (!referenced.Contains(pair.Key))
                {
                    roots.Add(pair.Key);
                }
            }

            return roots;
        }

        // 功能：生成下一个可用的节点 id（n1、n2…）。
        // 入参：无
        // 返回：没被占用的 id
        // 步骤：从 1 开始逐个试探，直到 Nodes 里没有
        // 上游：BTGraphView.CreateNode / Duplicate
        // 下游：Nodes
        public string NextNodeId()
        {
            int index = 1;

            while (true)
            {
                string candidate = "n" + index;

                if (!Nodes.ContainsKey(candidate))
                {
                    return candidate;
                }

                index++;
            }
        }

        // 功能：导出前的结构校验。
        // 入参：error 失败原因（成功时为空串）
        // 返回：true = 可以导出
        // 步骤：
        //   1) 空树直接失败
        //   2) 必须恰好一个根
        //   3) 所有 Children 引用必须存在
        //   4) 从根做一次 DFS，必须能到达所有节点（否则有环或被孤立的环）
        // 上游：BehaviorTreeEditorWindow 导出按钮
        // 下游：无
        public bool Validate(out string error)
        {
            if (Nodes.Count == 0)
            {
                error = "画布是空的，先拖一个节点进来。";
                return false;
            }

            string root = FindRootId();

            if (string.IsNullOrEmpty(root))
            {
                List<string> roots = FindRootIds();
                StringBuilder list = new StringBuilder();

                for (int i = 0; i < roots.Count; i++)
                {
                    if (i > 0) { list.Append(", "); }
                    list.Append(roots[i]).Append('(').Append(Nodes[roots[i]].NodeType).Append(')');
                }

                error = "必须恰好有一个根节点，当前有 " + roots.Count + " 个：" + list +
                        "。把多余的节点连到树上，或删掉它们。";
                return false;
            }

            foreach (KeyValuePair<string, BTNodeData> pair in Nodes)
            {
                for (int i = 0; i < pair.Value.Children.Count; i++)
                {
                    string child = pair.Value.Children[i];

                    if (!Nodes.ContainsKey(child))
                    {
                        error = "节点 " + pair.Key + " 引用了不存在的子节点 " + child + "。";
                        return false;
                    }
                }
            }

            HashSet<string> visited = new HashSet<string>();
            Stack<string> pending = new Stack<string>();
            pending.Push(root);

            while (pending.Count > 0)
            {
                string current = pending.Pop();

                if (!visited.Add(current))
                {
                    error = "检测到环：节点 " + current + " 被重复访问。行为树必须是有向无环图。";
                    return false;
                }

                BTNodeData node = Nodes[current];

                for (int i = 0; i < node.Children.Count; i++)
                {
                    pending.Push(node.Children[i]);
                }
            }

            if (visited.Count != Nodes.Count)
            {
                StringBuilder missing = new StringBuilder();

                foreach (KeyValuePair<string, BTNodeData> pair in Nodes)
                {
                    if (!visited.Contains(pair.Key))
                    {
                        missing.Append(pair.Key).Append(' ');
                    }
                }

                error = "有节点无法从根到达（被孤立的子图或环）：" + missing;
                return false;
            }

            error = string.Empty;
            return true;
        }

        // 功能：深拷贝整棵树（预览运行时用它做快照，避免与画布共享数据）。
        // 入参：无
        // 返回：新树
        // 步骤：复制标量 → 逐节点 Clone
        // 上游：BTPreviewRunner.Start
        // 下游：无
        public BTGraphData Clone()
        {
            BTGraphData copy = new BTGraphData
            {
                TreeId = TreeId,
                RootNodeId = RootNodeId
            };

            foreach (KeyValuePair<string, BTNodeData> pair in Nodes)
            {
                copy.Nodes[pair.Key] = pair.Value.Clone();
            }

            return copy;
        }
    }
}
```

### `Data/BTNodeDefine.cs`

```csharp
// 这个文件里有：
//   BTNodeCategory（枚举）：节点分类（组合 / 条件 / 动作），决定左栏分组。
//   BTParamDefine（结构体）：一个参数的定义（键、显示名、类型、默认值）。
//   BTNodeDefine（类）：一种节点的定义（类型名、显示名、分类、子节点上限、参数表）。
//   BTNodeRegistry（静态类）：全局节点注册表 + 内置节点（新增自定义节点的唯一入口）。

using System.Collections.Generic;
using System.Globalization;

namespace NBC.EditorTools.BehaviorTree
{
    // 节点分类：左栏按这个分组，也用于快速判断端口规则
    public enum BTNodeCategory
    {
        // 组合节点（有子节点）：Selector / Sequence / Parallel
        Composite = 0,

        // 条件节点（无子节点）：HPBelow / HasTarget
        Condition = 1,

        // 动作节点（无子节点）：MoveTo / CastSkill / Wait
        Action = 2
    }

    // 一个参数的定义：告诉属性面板「出什么控件」、导出时「什么类型"
    public struct BTParamDefine
    {
        // 参数键（JSON 里 Params 的键）
        public string Key;

        // 属性面板上显示的名字（可以带中文说明）
        public string Label;
```

```csharp
// 这个文件里有：
//   BTJsonUtil（静态类）：把 BTGraphData 写成约定 Schema 的 JSON，以及从 JSON 读回来。
//   BtJsonValue（类）：自研极简 JSON DOM（对象/数组/字符串/数字/布尔/空）。
//   BtJsonParser（类）：递归下降解析器，报错带行列。
//   BtJsonException（异常）：导入失败时抛它，窗口直接把消息给用户看。

using System;
using System.Collections.Generic;
using System.Globalization;
using System.Text;

namespace NBC.EditorTools.BehaviorTree
{
    // 导入失败时抛这个；消息里带行列，方便定位
    public sealed class BtJsonException : Exception
    {
        // 功能：构造异常。
        // 入参：message 消息
        // 返回：无
        // 步骤：转基类
        // 上游：BtJsonParser
        // 下游：BehaviorTreeEditorWindow 的 catch
        public BtJsonException(string message) : base(message)
        {
        }
    }

    // 极简 JSON DOM：只做本项目 Schema 需要的几件事，不追求通用
    internal sealed class BtJsonValue
    {
        // 值类型
        public enum EKind
        {
            Object,
            Array,
            String,
            Number,
            Bool,
            Null
        }

        // 这个值是什么类型
        public EKind Kind = EKind.Null;

        // Kind == Object 时的键值表
        public Dictionary<string, BtJsonValue> Object = new Dictionary<string, BtJsonValue>();

        // Kind == Array 时的元素表
        public List<BtJsonValue> Array = new List<BtJsonValue>();

        // Kind == String 时的文本
        public string Text = string.Empty;

        // Kind == Number 时的原始数字文本（保留是否带小数点，导入时用来判断 Int/Float）
        public string RawNumber = "0";

        // Kind == Bool 时的值
        public bool Bool;

        // 功能：取子对象里的成员，不存在返回 null。
        // 入参：key 键
        // 返回：成员或 null
        // 步骤：类型不是 Object 返回 null；否则查字典
        // 上游：BTJsonUtil.Import
        // 下游：无
        public BtJsonValue Get(string key)
        {
            if (Kind != EKind.Object)
            {
                return null;
            }

            Object.TryGetValue(key, out BtJsonValue value);
            return value;
        }
    }

    // 递归下降 JSON 解析器：支持对象/数组/字符串/数字/true/false/null，忽略空白
    internal sealed class BtJsonParser
    {
        // 待解析文本
        private readonly string m_text;

        // 当前读到的位置
        private int m_index;

        // 当前行号（1 基，报错用）
        private int m_line = 1;

        // 当前列号（1 基，报错用）
        private int m_column = 1;

        // 功能：构造解析器。
        // 入参：text JSON 文本
        // 返回：无
        // 步骤：存文本
        // 上游：BTJsonUtil.Import
        // 下游：Parse
        public BtJsonParser(string text)
        {
            m_text = text ?? string.Empty;
        }

        // 功能：解析整段文本。
        // 入参：无
        // 返回：根值
        // 步骤：跳空白 → 解析值 → 跳空白 → 必须到结尾
        // 上游：BTJsonUtil.Import
        // 下游：ParseValue
        public BtJsonValue Parse()
        {
            SkipWhitespace();
            BtJsonValue value = ParseValue();
            SkipWhitespace();

            if (!AtEnd)
            {
                throw Error("JSON 结尾还有多余内容");
            }

            return value;
        }

        // 是否已经读到结尾
        private bool AtEnd => m_index >= m_text.Length;

        // 当前字符（越界返回 '\0'）
        private char Current => AtEnd ? '\0' : m_text[m_index];

        // 功能：跳过一个字符并维护行列号。
        // 入参：无
        // 返回：无
        // 步骤：换行就 line++ 且 column 归 1，否则 column++
        // 上游：所有读取处
        // 下游：无
        private void Advance()
        {
            if (AtEnd)
            {
                return;
            }

            if (m_text[m_index] == '\n')
            {
                m_line++;
                m_column = 1;
            }
            else
            {
                m_column++;
            }

            m_index++;
        }

        // 功能：跳过空白字符。
        // 入参：无
        // 返回：无
        // 步骤：循环 Advance 直到非空白
        // 上游：Parse / ParseValue
        // 下游：无
        private void SkipWhitespace()
        {
            while (!AtEnd && char.IsWhiteSpace(Current))
            {
                Advance();
            }
        }

        // 功能：造一个带行列的异常。
        // 入参：message 原因
        // 返回：异常对象
        // 步骤：拼行列
        // 上游：各解析失败处
        // 下游：调用方 throw
        private BtJsonException Error(string message)
        {
            return new BtJsonException("[BT JSON] 第 " + m_line + " 行第 " + m_column + " 列：" + message);
        }

        // 功能：解析一个值（按首字符派发）。
        // 入参：无
        // 返回：解析结果
        // 步骤：{ → 对象，[ → 数组，" → 字符串，t/f → 布尔，n → null，其它 → 数字
        // 上游：Parse / ParseObject / ParseArray
        // 下游：对应子方法
        private BtJsonValue ParseValue()
        {
            SkipWhitespace();

            if (AtEnd)
            {
                throw Error("文本意外结束，期待一个值");
            }

            char c = Current;

            if (c == '{')
            {
                return ParseObject();
            }

            if (c == '[')
            {
                return ParseArray();
            }

            if (c == '"')
            {
                return new BtJsonValue { Kind = BtJsonValue.EKind.String, Text = ParseString() };
            }

            if (c == 't' || c == 'f')
            {
                return ParseBool();
            }

            if (c == 'n')
            {
                return ParseNull();
            }

            return ParseNumber();
        }

        // 功能：解析对象。
        // 入参：无
        // 返回：Object 值
        // 步骤：读完 '{' → 循环「字符串 : 值」→ 逗号分隔 → 遇到 '}' 结束
        // 上游：ParseValue
        // 下游：ParseString / ParseValue
        private BtJsonValue ParseObject()
        {
            BtJsonValue result = new BtJsonValue { Kind = BtJsonValue.EKind.Object };
            Advance();      // '{'
            SkipWhitespace();

            if (Current == '}')
            {
                Advance();
                return result;
            }

            while (true)
            {
                SkipWhitespace();

                if (Current != '"')
                {
                    throw Error("对象的键必须是字符串");
                }

                string key = ParseString();
                SkipWhitespace();

                if (Current != ':')
                {
                    throw Error("键 \"" + key + "\" 后面缺少冒号");
                }

                Advance();
                result.Object[key] = ParseValue();
                SkipWhitespace();

                if (Current == ',')
                {
                    Advance();
                    continue;
                }

                if (Current == '}')
                {
                    Advance();
                    return result;
                }

                throw Error("对象成员之间必须是逗号，或者是结束的 '}'");
            }
        }

        // 功能：解析数组。
        // 入参：无
        // 返回：Array 值
        // 步骤：读完 '[' → 循环值 → 逗号分隔 → 遇到 ']' 结束
        // 上游：ParseValue
        // 下游：ParseValue
        private BtJsonValue ParseArray()
        {
            BtJsonValue result = new BtJsonValue { Kind = BtJsonValue.EKind.Array };
            Advance();      // '['
            SkipWhitespace();

            if (Current == ']')
            {
                Advance();
                return result;
            }

            while (true)
            {
                result.Array.Add(ParseValue());
                SkipWhitespace();

                if (Current == ',')
                {
                    Advance();
                    continue;
                }

                if (Current == ']')
                {
                    Advance();
                    return result;
                }

                throw Error("数组元素之间必须是逗号，或者是结束的 ']'");
            }
        }

        // 功能：解析字符串（支持 \" \\ \/ \n \t \r \b \f 与 \uXXXX）。
        // 入参：无
        // 返回：字符串内容
        // 步骤：读完开引号 → 逐字符拼 → 遇到闭引号结束
        // 上游：ParseValue / ParseObject
        // 下游：无
        private string ParseString()
        {
            StringBuilder builder = new StringBuilder();
            Advance();      // 开引号

            while (true)
            {
                if (AtEnd)
                {
                    throw Error("字符串没有结束的引号");
                }

                char c = Current;

                if (c == '"')
                {
                    Advance();
                    return builder.ToString();
                }

                if (c == '\\')
                {
                    Advance();

                    if (AtEnd)
                    {
                        throw Error("转义符后面没有字符");
                    }

                    char escape = Current;

                    switch (escape)
                    {
                        case '"': builder.Append('"'); break;
                        case '\\': builder.Append('\\'); break;
                        case '/': builder.Append('/'); break;
                        case 'b': builder.Append('\b'); break;
                        case 'f': builder.Append('\f'); break;
                        case 'n': builder.Append('\n'); break;
                        case 'r': builder.Append('\r'); break;
                        case 't': builder.Append('\t'); break;
                        case 'u':
                            builder.Append(ParseUnicode());
                            continue;
                        default:
                            throw Error("不认识的转义 \\" + escape);
                    }

                    Advance();
                    continue;
                }

                builder.Append(c);
                Advance();
            }
        }

        // 功能：解析 \uXXXX 的四位十六进制（当前字符是 'u'）。
        // 入参：无
        // 返回：对应字符
        // 步骤：跳过 u → 读 4 位 → 转 char
        // 上游：ParseString
        // 下游：无
        private char ParseUnicode()
        {
            Advance();      // 'u'

            if (m_index + 4 > m_text.Length)
            {
                throw Error("\\u 后面必须跟 4 位十六进制");
            }

            string hex = m_text.Substring(m_index, 4);

            if (!int.TryParse(hex, NumberStyles.HexNumber, CultureInfo.InvariantCulture, out int code))
            {
                throw Error("\\u" + hex + " 不是合法的十六进制");
            }

            for (int i = 0; i < 4; i++)
            {
                Advance();
            }

            return (char)code;
        }

        // 功能：解析 true / false。
        // 入参：无
        // 返回：Bool 值
        // 步骤：比对文本前缀再前进
        // 上游：ParseValue
        // 下游：无
        private BtJsonValue ParseBool()
        {
            if (Match("true"))
            {
                return new BtJsonValue { Kind = BtJsonValue.EKind.Bool, Bool = true };
            }

            if (Match("false"))
            {
                return new BtJsonValue { Kind = BtJsonValue.EKind.Bool, Bool = false };
            }

            throw Error("期待 true 或 false");
        }

        // 功能：解析 null。
        // 入参：无
        // 返回：Null 值
        // 步骤：比对 null 文本
        // 上游：ParseValue
        // 下游：无
        private BtJsonValue ParseNull()
        {
            if (!Match("null"))
            {
                throw Error("期待 null");
            }

            return new BtJsonValue { Kind = BtJsonValue.EKind.Null };
        }

        // 功能：解析数字（保留原始文本，导入时判断 Int/Float）。
        // 入参：无
        // 返回：Number 值
        // 步骤：吃掉 - + 数字 + . + e/E 符号
        // 上游：ParseValue
        // 下游：无
        private BtJsonValue ParseNumber()
        {
            int start = m_index;

            if (Current == '-')
            {
                Advance();
            }

            while (!AtEnd && (char.IsDigit(Current) || Current == '.' || Current == 'e' || Current == 'E' ||
                              Current == '+' || Current == '-'))
            {
                Advance();
            }

            string raw = m_text.Substring(start, m_index - start);

            if (raw.Length == 0)
            {
                throw Error("期待一个数字");
            }

            return new BtJsonValue { Kind = BtJsonValue.EKind.Number, RawNumber = raw };
        }

        // 功能：尝试匹配一段字面量并前进。
        // 入参：literal 期望的字面量
        // 返回：true = 匹配并已前进
        // 步骤：Substring 比对
        // 上游：ParseBool / ParseNull
        // 下游：无
        private bool Match(string literal)
        {
            if (m_index + literal.Length > m_text.Length)
            {
                return false;
            }

            if (string.CompareOrdinal(m_text, m_index, literal, 0, literal.Length) != 0)
            {
                return false;
            }

            for (int i = 0; i < literal.Length; i++)
            {
                Advance();
            }

            return true;
        }
    }

    // 主要功能：行为树数据的 JSON 读写（Schema 固定，参数保持原生 JSON 类型）。
    // 主要数据成员：无（纯静态）。
    // 主要外部方法：Export / Import。
    // 谁在用它：BehaviorTreeEditorWindow 的导入导出按钮。
    // 注意：这里**不引入任何 JSON 库**（工程没有 Newtonsoft，JsonUtility 又不支持字典与动态类型）。
    public static class BTJsonUtil
    {
        // 缩进空格数（导出可读性）
        private const int Indent = 2;

        // 功能：把整棵树写成 JSON。
        // 入参：data 树数据
        // 返回：JSON 文本（带缩进、字段顺序固定：TreeId → RootNodeId → Nodes）
        // 步骤：
        //   1) 先算根 id（若 data.RootNodeId 为空则用 FindRootId 推断）
        //   2) 写 TreeId / RootNodeId
        //   3) 按 id 排序写 Nodes（保证两次导出文本一致，便于比对）
        // 上游：导出按钮
        // 下游：无
        public static string Export(BTGraphData data)
        {
            if (data == null)
            {
                throw new BtJsonException("[BT JSON] 没有可导出的数据。");
            }

            string rootId = string.IsNullOrEmpty(data.RootNodeId) ? data.FindRootId() : data.RootNodeId;
            StringBuilder builder = new StringBuilder();
            builder.Append('{').Append('\n');
            builder.Append(' ', Indent).Append("\"TreeId\": ").Append(Quote(data.TreeId)).Append(',').Append('\n');
            builder.Append(' ', Indent).Append("\"RootNodeId\": ").Append(Quote(rootId)).Append(',').Append('\n');
            builder.Append(' ', Indent).Append("\"Nodes\": {").Append('\n');

            List<string> ids = new List<string>(data.Nodes.Keys);
            ids.Sort(StringComparer.Ordinal);

            for (int i = 0; i < ids.Count; i++)
            {
                string id = ids[i];
                BTNodeData node = data.Nodes[id];
                builder.Append(' ', Indent * 2).Append(Quote(id)).Append(": {").Append('\n');
                builder.Append(' ', Indent * 3).Append("\"NodeType\": ").Append(Quote(node.NodeType)).Append(',').Append('\n');
                builder.Append(' ', Indent * 3).Append("\"Pos\": { \"x\": ")
                    .Append(Number(node.PosX)).Append(", \"y\": ").Append(Number(node.PosY)).Append(" },").Append('\n');
                builder.Append(' ', Indent * 3).Append("\"Params\": ");
                WriteParams(builder, node, Indent * 3);
                builder.Append(',').Append('\n');
                builder.Append(' ', Indent * 3).Append("\"Children\": ");
                WriteChildren(builder, node);
                builder.Append('\n');
                builder.Append(' ', Indent * 2).Append('}');

                if (i < ids.Count - 1)
                {
                    builder.Append(',');
                }

                builder.Append('\n');
            }

            builder.Append(' ', Indent).Append('}').Append('\n');
            builder.Append('}').Append('\n');
            return builder.ToString();
        }

        // 功能：从 JSON 文本读出树数据。
        // 入参：json 文本
        // 返回：树数据（已按节点定义补齐默认参数）
        // 步骤：
        //   1) 解析成 DOM
        //   2) 读 TreeId / RootNodeId / Nodes
        //   3) 每个节点读 NodeType / Pos / Params / Children，并按定义补默认参数
        // 上游：导入按钮
        // 下游：无
        // 注意：未知 NodeType 会抛异常（不静默丢弃，否则一导入就丢节点）
        public static BTGraphData Import(string json)
        {
            BtJsonValue root = new BtJsonParser(json).Parse();

            if (root.Kind != BtJsonValue.EKind.Object)
            {
                throw new BtJsonException("[BT JSON] 顶层必须是一个对象。");
            }

            BTGraphData data = new BTGraphData();
            BtJsonValue treeId = root.Get("TreeId");
            data.TreeId = treeId != null && treeId.Kind == BtJsonValue.EKind.String ? treeId.Text : "new_tree";

            BtJsonValue rootNodeId = root.Get("RootNodeId");
            data.RootNodeId = rootNodeId != null && rootNodeId.Kind == BtJsonValue.EKind.String
                ? rootNodeId.Text
                : string.Empty;

            BtJsonValue nodes = root.Get("Nodes");

            if (nodes == null || nodes.Kind != BtJsonValue.EKind.Object)
            {
                throw new BtJsonException("[BT JSON] 缺少 Nodes 对象。");
            }

            foreach (KeyValuePair<string, BtJsonValue> pair in nodes.Object)
            {
                data.Nodes[pair.Key] = ReadNode(pair.Key, pair.Value);
            }

            return data;
        }

        // 功能：读一个节点。
        // 入参：id 节点 id；value 该节点的 JSON 对象
        // 返回：节点数据
        // 步骤：读四个字段；参数值按定义类型强转
        // 上游：Import
        // 下游：ReadParam
        private static BTNodeData ReadNode(string id, BtJsonValue value)
        {
            if (value.Kind != BtJsonValue.EKind.Object)
            {
                throw new BtJsonException("[BT JSON] 节点 " + id + " 必须是对象。");
            }

            BTNodeData node = new BTNodeData();

            BtJsonValue nodeType = value.Get("NodeType");
            node.NodeType = nodeType != null && nodeType.Kind == BtJsonValue.EKind.String ? nodeType.Text : string.Empty;

            BTNodeDefine define = BTNodeRegistry.Find(node.NodeType);

            if (define == null)
            {
                throw new BtJsonException("[BT JSON] 节点 " + id + " 的类型 \"" + node.NodeType +
                                          "\" 没有注册（检查 BTNodeRegistry）。");
            }

            BtJsonValue pos = value.Get("Pos");

            if (pos != null && pos.Kind == BtJsonValue.EKind.Object)
            {
                node.PosX = ReadNumber(pos.Get("x"));
                node.PosY = ReadNumber(pos.Get("y"));
            }

            BtJsonValue parms = value.Get("Params");

            if (parms != null && parms.Kind == BtJsonValue.EKind.Object)
            {
                foreach (KeyValuePair<string, BtJsonValue> pair in parms.Object)
                {
                    node.Params[pair.Key] = ReadParam(pair.Key, pair.Value);
                }
            }

            node.EnsureDefaults(define);
            CoerceParamsToDefinition(node, define);

            BtJsonValue children = value.Get("Children");

            if (children != null && children.Kind == BtJsonValue.EKind.Array)
            {
                for (int i = 0; i < children.Array.Count; i++)
                {
                    BtJsonValue child = children.Array[i];

                    if (child.Kind != BtJsonValue.EKind.String)
                    {
                        throw new BtJsonException("[BT JSON] 节点 " + id + " 的 Children 里必须都是字符串。");
                    }

                    node.Children.Add(child.Text);
                }
            }

            return node;
        }

        // 功能：把已读到的参数值强制转成**节点定义里声明的类型**。
        // 入参：node 节点数据；define 节点定义
        // 返回：无
        // 步骤：遍历定义里的参数，类型不一致就按定义转换
        // 上游：ReadNode
        // 下游：BTParamValue.FromXxx
        // 注意：JSON 里 `1` 和 `1.0` 在文本上都可能被写成 `1`（我导出浮点时用 "R"，
        //      整数值的 float 也会写成 `1`），所以**不能靠小数点猜类型**，必须以节点定义为准。
        private static void CoerceParamsToDefinition(BTNodeData node, BTNodeDefine define)
        {
            if (define == null)
            {
                return;
            }

            for (int i = 0; i < define.Params.Length; i++)
            {
                BTParamDefine paramDefine = define.Params[i];

                if (!node.Params.TryGetValue(paramDefine.Key, out BTParamValue value) || value.Type == paramDefine.Type)
                {
                    continue;
                }

                switch (paramDefine.Type)
                {
                    case BTParamType.Int:
                        node.Params[paramDefine.Key] = BTParamValue.FromInt(value.AsInt());
                        break;

                    case BTParamType.Bool:
                        node.Params[paramDefine.Key] = BTParamValue.FromBool(value.AsBool());
                        break;

                    case BTParamType.String:
                        node.Params[paramDefine.Key] = BTParamValue.FromString(value.AsString());
                        break;

                    default:
                        node.Params[paramDefine.Key] = BTParamValue.FromFloat(value.AsFloat());
                        break;
                }
            }
        }
        // 功能：读一个参数值，并尽量按定义里的类型还原。
        // 入参：key 参数键；value JSON 值
        // 返回：参数值
        // 步骤：布尔 → Bool；字符串 → String；数字 → 整数看有没有小数点定 Int/Float
        // 上游：ReadNode
        // 下游：无
        private static BTParamValue ReadParam(string key, BtJsonValue value)
        {
            switch (value.Kind)
            {
                case BtJsonValue.EKind.Bool:
                    return BTParamValue.FromBool(value.Bool);

                case BtJsonValue.EKind.String:
                    return BTParamValue.FromString(value.Text);

                case BtJsonValue.EKind.Number:
                    if (value.RawNumber.IndexOf('.') >= 0 || value.RawNumber.IndexOf('e') >= 0 ||
                        value.RawNumber.IndexOf('E') >= 0)
                    {
                        float.TryParse(value.RawNumber, NumberStyles.Float, CultureInfo.InvariantCulture,
                            out float floatValue);
                        return BTParamValue.FromFloat(floatValue);
                    }

                    int.TryParse(value.RawNumber, NumberStyles.Integer, CultureInfo.InvariantCulture,
                        out int intValue);
                    return BTParamValue.FromInt(intValue);

                default:
                    throw new BtJsonException("[BT JSON] 参数 \"" + key + "\" 的类型不支持（只支持数字/布尔/字符串）。");
            }
        }

        // 功能：读一个数字（缺省 0）。
        // 入参：value JSON 值
        // 返回：浮点
        // 步骤：不是数字就返回 0
        // 上游：ReadNode
        // 下游：无
        private static float ReadNumber(BtJsonValue value)
        {
            if (value == null || value.Kind != BtJsonValue.EKind.Number)
            {
                return 0f;
            }

            float.TryParse(value.RawNumber, NumberStyles.Float, CultureInfo.InvariantCulture, out float result);
            return result;
        }

        // 功能：写 Params 对象（值按类型写成 JSON 原生值）。
        // 入参：builder 目标；node 节点；indent 缩进
        // 返回：无
        // 步骤：空表写 {}；否则逐项写（键排序保证稳定）
        // 上游：Export
        // 下游：无
        private static void WriteParams(StringBuilder builder, BTNodeData node, int indent)
        {
            if (node.Params.Count == 0)
            {
                builder.Append("{ }");
                return;
            }

            List<string> keys = new List<string>(node.Params.Keys);
            keys.Sort(StringComparer.Ordinal);
            builder.Append('{').Append('\n');

            for (int i = 0; i < keys.Count; i++)
            {
                BTParamValue value = node.Params[keys[i]];
                builder.Append(' ', indent + Indent).Append(Quote(keys[i])).Append(": ");
                WriteParamValue(builder, value);

                if (i < keys.Count - 1)
                {
                    builder.Append(',');
                }

                builder.Append('\n');
            }

            builder.Append(' ', indent).Append('}');
        }

        // 功能：按类型写一个参数值。
        // 入参：builder 目标；value 参数值
        // 返回：无
        // 步骤：Float/Int → 数字；Bool → true/false；String → 带引号
        // 上游：WriteParams
        // 下游：无
        private static void WriteParamValue(StringBuilder builder, BTParamValue value)
        {
            switch (value.Type)
            {
                case BTParamType.Int:
                    builder.Append(value.IntValue.ToString(CultureInfo.InvariantCulture));
                    break;

                case BTParamType.Bool:
                    builder.Append(value.BoolValue ? "true" : "false");
                    break;

                case BTParamType.String:
                    builder.Append(Quote(value.StringValue));
                    break;

                default:
                    builder.Append(Number(value.FloatValue));
                    break;
            }
        }

        // 功能：写 Children 数组。
        // 入参：builder 目标；node 节点
        // 返回：无
        // 步骤：空表写 []；否则 ["a", "b"]
        // 上游：Export
        // 下游：无
        private static void WriteChildren(StringBuilder builder, BTNodeData node)
        {
            builder.Append('[');

            for (int i = 0; i < node.Children.Count; i++)
            {
                if (i > 0)
                {
                    builder.Append(", ");
                }

                builder.Append(Quote(node.Children[i]));
            }

            builder.Append(']');
        }

        // 功能：把浮点写成不变文化的紧凑数字。
        // 入参：value 数值
        // 返回：文本（整数值不带小数点）
        // 步骤：用 "R" 格式化
        // 上游：Export
        // 下游：无
        private static string Number(float value)
        {
            return value.ToString("R", CultureInfo.InvariantCulture);
        }

        // 功能：把字符串包成 JSON 字符串（转义引号、反斜杠、换行等）。
        // 入参：text 原文
        // 返回：带引号的文本
        // 步骤：逐字符转义
        // 上游：Export
        // 下游：无
        private static string Quote(string text)
        {
            StringBuilder builder = new StringBuilder();
            builder.Append('"');

            if (!string.IsNullOrEmpty(text))
            {
                for (int i = 0; i < text.Length; i++)
                {
                    char c = text[i];

                    switch (c)
                    {
                        case '"': builder.Append("\\\""); break;
                        case '\\': builder.Append("\\\\"); break;
                        case '\n': builder.Append("\\n"); break;
                        case '\r': builder.Append("\\r"); break;
                        case '\t': builder.Append("\\t"); break;
                        default: builder.Append(c); break;
                    }
                }
            }

            builder.Append('"');
            return builder.ToString();
        }
    }
}
```

```csharp
// 这个文件里有：
//   BTPreviewStatus（枚举）：预览用的三态（成功/失败/运行中）。
//   BTBlackboard（类）：预览时的简易黑板（数值/布尔/字符串，由用户在属性面板手填）。
//   BTPreviewNode（类）：【仅编辑器】简化版行为树运行时节点（按 NodeType 字符串执行）。
//   BTPreviewRunner（类）：【仅编辑器】持有根节点并驱动 Tick。
//
// ⚠️ 本文件的代码**只在编辑器里跑**（所在程序集 NBC.Editor 的 includePlatforms = Editor）。
//    它只是给策划看"树会怎么跑"，绝不参与正式游戏与服务端逻辑。

using System;
using System.Collections.Generic;

namespace NBC.EditorTools.BehaviorTree
{
    // 预览三态
    public enum BTPreviewStatus
    {
        // 成功（节点视图显示绿色）
        Success = 0,

        // 失败（红色）
        Failure = 1,

        // 运行中（黄色）
        Running = 2
    }

    // 主要功能：预览时条件节点读的「黑板」——用户在右侧面板手填测试值（hp / targetId / skillCd）。
    // 主要数据成员：m_values（键 → 参数值）。
    // 主要外部方法：Set / GetInt / GetFloat / TryGet / Clear。
    // 谁在用它：BTPreviewNode（条件/动作）、BTBlackboardView（编辑）。
    // 注意：黑板只在预览期有效，**不序列化、不导出**。
    public sealed class BTBlackboard
    {
        // 键 → 值
        private readonly Dictionary<string, BTParamValue> m_values = new Dictionary<string, BTParamValue>();

        // 功能：设置一个黑板值。
        // 入参：key 键；value 值
        // 返回：无
        // 步骤：直接写字典
        // 上游：BTBlackboardView 的输入框
        // 下游：BTPreviewNode 读取
        public void Set(string key, BTParamValue value)
        {
            if (string.IsNullOrEmpty(key))
            {
                return;
            }

            m_values[key] = value;
        }

        // 功能：读整数（缺省 0）。
        // 入参：key 键
        // 返回：整数值
        // 步骤：查字典，命中就 AsInt
        // 上游：BTPreviewNode
        // 下游：无
        public int GetInt(string key)
        {
            return m_values.TryGetValue(key, out BTParamValue value) ? value.AsInt() : 0;
        }

        // 功能：读浮点（缺省 0）。
        // 入参：key 键
        // 返回：浮点值
        // 步骤：查字典，命中就 AsFloat
        // 上游：BTPreviewNode
        // 下游：无
        public float GetFloat(string key)
        {
            return m_values.TryGetValue(key, out BTParamValue value) ? value.AsFloat() : 0f;
        }

        // 功能：取原始参数值（给界面显示用）。
        // 入参：key 键；value 命中的值
        // 返回：true = 键存在
        // 步骤：查字典
        // 上游：BTBlackboardView
        // 下游：无
        public bool TryGet(string key, out BTParamValue value)
        {
            return m_values.TryGetValue(key, out value);
        }

        // 功能：清空黑板（停止预览时复位）。
        // 入参：无
        // 返回：无
        // 步骤：清字典
        // 上游：BTPreviewRunner.Stop
        // 下游：无
        public void Clear()
        {
            m_values.Clear();
        }
    }

    // 主要功能：一棵**预览专用**的运行时树节点 —— 只按 NodeType 执行简化行为，不含任何游戏逻辑。
    // 主要数据成员：NodeId / NodeType / Params / Children / m_elapsed（Wait/MoveTo 的计时）。
    // 主要外部方法：Tick（跑一帧，返回三态）、Reset（重置计时）。
    // 谁在用它：BTPreviewRunner（根）、自己的 Children（递归）。
    // 注意：这是**另一套对象**，与画布的 BTNodeData 完全分离；预览不会改画布数据。
    public sealed class BTPreviewNode
    {
        // 对应画布节点的 id（回传状态用）
        public string NodeId = string.Empty;

        // 节点类型（Selector / Sequence / HPBelow / …）
        public string NodeType = string.Empty;

        // 该节点的参数（从画布数据拷来的副本）
        public Dictionary<string, BTParamValue> Params = new Dictionary<string, BTParamValue>();

        // 子节点（顺序与 Children 一致）
        public List<BTPreviewNode> Children = new List<BTPreviewNode>();

        // Wait / MoveTo 用掉的秒数
        private float m_elapsed;

        // 最近一次 Tick 的结果（组合节点与叶子都记，供 UI 上色）
        public BTPreviewStatus LastStatus { get; private set; } = BTPreviewStatus.Failure;

        // 功能：跑一帧。
        // 入参：blackboard 黑板；deltaSeconds 距上一帧的秒数
        // 返回：三态
        // 步骤：按 NodeType 分派到对应的简化实现
        // 上游：BTPreviewRunner.Tick（根）/ 父节点（子节点）
        // 下游：Children 的 Tick
        // 注意：未知类型一律 Failure（并在控制台提示一次由 Runner 负责）
        public BTPreviewStatus Tick(BTBlackboard blackboard, float deltaSeconds)
        {
            LastStatus = TickCore(blackboard, deltaSeconds);
            return LastStatus;
        }

        // 功能：真正的分派（由 Tick 包一层，保证 LastStatus 一定被记录）。
        // 入参：blackboard 黑板；deltaSeconds 距上一帧的秒数
        // 返回：三态
        // 步骤：按 NodeType 分派
        // 上游：Tick
        // 下游：各 TickXxx
        private BTPreviewStatus TickCore(BTBlackboard blackboard, float deltaSeconds)
        {
            switch (NodeType)
            {
                case "Selector":
                    return TickSelector(blackboard, deltaSeconds);

                case "Sequence":
                    return TickSequence(blackboard, deltaSeconds);

                case "Parallel":
                    return TickParallel(blackboard, deltaSeconds);

                case "HPBelow":
                    return blackboard.GetInt("hp") < GetInt("hpThreshold") ? BTPreviewStatus.Success : BTPreviewStatus.Failure;

                case "HasTarget":
                    return blackboard.GetInt("targetId") > 0 ? BTPreviewStatus.Success : BTPreviewStatus.Failure;

                case "MoveTo":
                    return TickTimed(GetFloat("speed") <= 0f ? 0.4f : 0.4f, deltaSeconds);

                case "CastSkill":
                    return TickCastSkill(blackboard);

                case "Wait":
                    return TickTimed(GetFloat("seconds"), deltaSeconds);

                default:
                    return BTPreviewStatus.Failure;
            }
        }

        // 功能：重置计时状态（重建运行时树时用）。
        // 入参：无
        // 返回：无
        // 步骤：清零 elapsed 并递归子节点
        // 上游：BTPreviewRunner.Start
        // 下游：无
        public void Reset()
        {
            m_elapsed = 0f;

            for (int i = 0; i < Children.Count; i++)
            {
                Children[i].Reset();
            }
        }

        // Selector：依次跑，第一个非 Failure 就返回（都失败才 Failure）
        private BTPreviewStatus TickSelector(BTBlackboard blackboard, float deltaSeconds)
        {
            for (int i = 0; i < Children.Count; i++)
            {
                BTPreviewStatus status = Children[i].Tick(blackboard, deltaSeconds);

                if (status != BTPreviewStatus.Failure)
                {
                    return status;
                }
            }

            return BTPreviewStatus.Failure;
        }

        // Sequence：依次跑，遇到 Failure 立刻 Failure，遇到 Running 就 Running（全成功才 Success）
        private BTPreviewStatus TickSequence(BTBlackboard blackboard, float deltaSeconds)
        {
            for (int i = 0; i < Children.Count; i++)
            {
                BTPreviewStatus status = Children[i].Tick(blackboard, deltaSeconds);

                if (status == BTPreviewStatus.Failure)
                {
                    return BTPreviewStatus.Failure;
                }

                if (status == BTPreviewStatus.Running)
                {
                    return BTPreviewStatus.Running;
                }
            }

            return BTPreviewStatus.Success;
        }

        // Parallel：全部跑；有 Failure 就 Failure，全 Success 才 Success，否则 Running
        private BTPreviewStatus TickParallel(BTBlackboard blackboard, float deltaSeconds)
        {
            bool anyRunning = false;

            for (int i = 0; i < Children.Count; i++)
            {
                BTPreviewStatus status = Children[i].Tick(blackboard, deltaSeconds);

                if (status == BTPreviewStatus.Failure)
                {
                    return BTPreviewStatus.Failure;
                }

                if (status == BTPreviewStatus.Running)
                {
                    anyRunning = true;
                }
            }

            return anyRunning ? BTPreviewStatus.Running : BTPreviewStatus.Success;
        }

        // 计时型动作：跑满 duration 秒就 Success，期间 Running
        private BTPreviewStatus TickTimed(float duration, float deltaSeconds)
        {
            m_elapsed += deltaSeconds;

            if (m_elapsed >= duration)
            {
                m_elapsed = 0f;
                return BTPreviewStatus.Success;
            }

            return BTPreviewStatus.Running;
        }

        // CastSkill：冷却没到就 Failure；到了就扣冷却并 Success
        private BTPreviewStatus TickCastSkill(BTBlackboard blackboard)
        {
            float cooldown = blackboard.GetFloat("skillCd");

            if (cooldown > 0f)
            {
                return BTPreviewStatus.Failure;
            }

            blackboard.Set("skillCd", BTParamValue.FromFloat(GetFloat("cooldownSeconds")));
            return BTPreviewStatus.Success;
        }

        // 读整数参数（缺省 0）
        private int GetInt(string key)
        {
            return Params.TryGetValue(key, out BTParamValue value) ? value.AsInt() : 0;
        }

        // 读浮点参数（缺省 0）
        private float GetFloat(string key)
        {
            return Params.TryGetValue(key, out BTParamValue value) ? value.AsFloat() : 0f;
        }
    }

    // 主要功能：预览驱动器 —— 从画布快照建运行时树，按固定间隔 Tick，回收每帧状态。
    // 主要数据成员：m_root（运行时根）、m_status（节点 id → 三态）、m_blackboard、m_interval、m_accumulator。
    // 主要外部方法：Start（建树）、Tick（由窗口定时调）、Stop（清状态）。
    // 谁在用它：BehaviorTreeEditorWindow。
    // 注意：只跑在编辑器；**不写回画布数据**（三色只给节点视图加样式类）。
    public sealed class BTPreviewRunner
    {
        // 运行时根节点；null = 没在预览
        private BTPreviewNode m_root;

        // 节点 id → 最近一次状态（窗口据此上色）
        private readonly Dictionary<string, BTPreviewStatus> m_status =
            new Dictionary<string, BTPreviewStatus>();

        // 黑板（用户填的测试值）
        private readonly BTBlackboard m_blackboard = new BTBlackboard();

        // 每次 Tick 的间隔（秒）；需求要求 200ms
        private const float IntervalSeconds = 0.2f;

        // 距上次 Tick 累积的时间（秒）
        private float m_accumulator;

        // 是否正在预览
        public bool IsRunning => m_root != null;

        // 黑板（窗口暴露给右侧面板）
        public BTBlackboard Blackboard => m_blackboard;

        // 最近一次状态表（窗口拿去上色）
        public IReadOnlyDictionary<string, BTPreviewStatus> Status => m_status;

        // 功能：用画布数据快照开始预览。
        // 入参：data 树数据（内部会再 Clone 一次，确保与画布彻底分离）；error 失败原因
        // 返回：true = 已开始
        // 步骤：
        //   1) 校验树结构（唯一根、无环）
        //   2) 递归建运行时节点
        //   3) 清状态、清计时
        // 上游：窗口的【预览】按钮
        // 下游：BuildNode
        public bool Start(BTGraphData data, out string error)
        {
            m_status.Clear();
            m_accumulator = 0f;
            m_root = null;

            if (data == null)
            {
                error = "没有可预览的树数据。";
                return false;
            }

            if (!data.Validate(out error))
            {
                return false;
            }

            BTGraphData snapshot = data.Clone();
            string rootId = string.IsNullOrEmpty(snapshot.RootNodeId) ? snapshot.FindRootId() : snapshot.RootNodeId;

            if (string.IsNullOrEmpty(rootId) || !snapshot.Nodes.ContainsKey(rootId))
            {
                error = "找不到根节点。";
                return false;
            }

            m_root = BuildNode(snapshot, rootId);
            m_root.Reset();
            error = string.Empty;
            return true;
        }

        // 功能：停止预览并清空运行状态（**不动黑板**）。
        // 入参：无
        // 返回：无
        // 步骤：丢根、清状态与计时
        // 上游：窗口的【停止预览】按钮 / OnDisable
        // 下游：无
        // 注意：黑板是用户填的测试值，停预览不该清 —— 清了会出现「面板显示 100，条件读到 0」。
        public void Stop()
        {
            m_root = null;
            m_status.Clear();
            m_accumulator = 0f;
        }

        // 功能：按 200ms 间隔推进一帧（窗口每帧调它，内部自己限流）。
        // 入参：deltaSeconds 距上一帧的秒数
        // 返回：true = 这一次真的 Tick 了（窗口据此刷新颜色）
        // 步骤：
        //   1) 没在预览就返回 false
        //   2) 累积时间；不到间隔也返回 false
        //   3) 扣黑板冷却、跑根节点、记录每个节点状态
        // 上游：窗口的 EditorApplication.update
        // 下游：BTPreviewNode.Tick
        public bool Tick(float deltaSeconds)
        {
            if (m_root == null)
            {
                return false;
            }

            m_accumulator += deltaSeconds;

            if (m_accumulator < IntervalSeconds)
            {
                return false;
            }

            float step = m_accumulator;
            m_accumulator = 0f;

            // 技能冷却随时间回落（预览用的简化规则）
            float cooldown = m_blackboard.GetFloat("skillCd");

            if (cooldown > 0f)
            {
                m_blackboard.Set("skillCd", BTParamValue.FromFloat(Math.Max(0f, cooldown - step)));
            }

            m_status.Clear();
            m_root.Tick(m_blackboard, step);
            CollectStatus(m_root);
            return true;
        }

        // 功能：递归收集每个节点的最近状态（组合节点也要上色）。
        // 入参：node 运行时节点
        // 返回：该节点的状态
        // 步骤：先跑一次拿状态（子节点状态已在前面跑到）→ 对每个子节点递归
        // 上游：Tick
        // 下游：m_status
        // 注意：组合节点的状态取"再跑一次"的结果会重复执行动作节点，所以这里**只回填已算过的状态**：
        //       父节点在 Tick 时会把子节点状态留在 m_status 里，这里只补"没被记录"的组合节点。
        private void CollectStatus(BTPreviewNode node)
        {
            m_status[node.NodeId] = node.LastStatus;

            for (int i = 0; i < node.Children.Count; i++)
            {
                CollectStatus(node.Children[i]);
            }
        }

        // 功能：按画布数据递归建运行时节点。
        // 入参：data 树快照；id 当前节点 id
        // 返回：运行时节点
        // 步骤：建节点 → 拷类型与参数 → 递归子节点
        // 上游：Start
        // 下游：无
        // 注意：用 visited 防环（数据已校验过，这里只是兜底）
        private BTPreviewNode BuildNode(BTGraphData data, string id)
        {
            BTPreviewNode node = new BTPreviewNode { NodeId = id };

            if (!data.Nodes.TryGetValue(id, out BTNodeData source))
            {
                return node;
            }

            node.NodeType = source.NodeType;

            foreach (KeyValuePair<string, BTParamValue> pair in source.Params)
            {
                node.Params[pair.Key] = pair.Value;
            }

            for (int i = 0; i < source.Children.Count; i++)
            {
                node.Children.Add(BuildNode(data, source.Children[i]));
            }

            return node;
        }
    }
}
```

```csharp
                return;

        // 入参：status 三态；null = 清除（停止预览）
        // 返回：无
        // 步骤：先清三个样式类，再按状态加一个

        // 下游：无
        // 注意：只改样式类，**不改数据**（预览与画布分离）

            RemoveFromClassList("bt-status-failure");
            RemoveFromClassList("bt-status-running");

            if (status == null)
            {
                return;
            }

            switch (status.Value)
            {
                case BTPreviewStatus.Success:
                    AddToClassList("bt-status-success");
                    break;

                case BTPreviewStatus.Failure:
                    AddToClassList("bt-status-failure");
                    break;

                default:
                    AddToClassList("bt-status-running");
                    break;
            }
        }

        // 功能：刷新标题下的参数摘要。
        // 入参：无
        // 返回：无
        // 步骤：按定义顺序拼「键=值」，最多 3 项

                }

                builder.Append(param.Key).Append('=').Append(value.AsString());
                shown++;
            }

            m_subtitle.text = builder.ToString();
        }
```

```csharp
// 这个文件里有：
//   BTGraphView（类）：行为树画布（UI Toolkit / GraphView）。
//
// 【编辑器 UI 代码】画布负责：建节点、连线、删除、复制、以及把画面同步成 BTGraphData。
// 预览运行时是**另一套对象**（BTPreviewRunner），画布只接收它回传的状态来上色。

using System;
using System.Collections.Generic;
using System.Linq;
using UnityEditor;
using UnityEditor.Experimental.GraphView;
using UnityEngine;
using UnityEngine.UIElements;

namespace NBC.EditorTools.BehaviorTree
{
    // 主要功能：把 BTGraphData 画出来、把用户操作写回 BTGraphData（唯一的数据源）。
    // 主要数据成员：m_data（树数据）、m_nodeViews（id → 节点视图）、m_initialized（是否装过操作器）。
    // 主要外部方法：ImportData（载入）、ExportData（导出快照）、CreateNode（建节点）、ApplyStatus（预览上色）、ClearStatus。
    // 谁在用它：BehaviorTreeEditorWindow。
    // 注意：连线规则（单父、单子、无环、根无输入）在 OnGraphViewChanged 里**统一校验** —— 别在别处零散地加限制。
    public sealed class BTGraphView : GraphView
    {
        // 拖拽创建节点时用的数据类型标记（节点库 → 画布）
        public const string DragDataType = "NBC_BT_NODE_TYPE";

        // 当前树数据；画布上的一切都同步到它
        private BTGraphData m_data = new BTGraphData();

        // 节点 id → 节点视图
        private readonly Dictionary<string, BTNodeView> m_nodeViews = new Dictionary<string, BTNodeView>();

        // 是否已经装过操作器与样式（构造后只做一次）
        private bool m_initialized;

        // 选中节点变化（窗口用来刷新右侧属性面板）
        public event Action<BTNodeView> NodeSelected;

        // 拖拽连线的起点端口（null = 没在拖）
        private Port m_dragSourcePort;

        // 拖拽时那根预备线的可视元素
        private VisualElement m_dragLine;

        // 预备线的起点与当前点（面板坐标，绘制时再转局部）
        private Vector2 m_dragStart;

        // 预备线的当前端点
        private Vector2 m_dragCurrent;

        // 树数据（只读用；导出请走 ExportData）
        public BTGraphData Data => m_data;

        // 功能：构造画布：装缩放/框选/拖拽操作器、挂样式、监听结构变化与拖放。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 装 ContentDragger / SelectionDragger / RectangleSelector / ContentZoomer
        //   2) 载入 USS（与窗口共用一份）
        //   3) 监听 graphViewChanged（连线/删除的校验入口）
        //   4) 监听拖放事件（从节点库拖进来）
        // 上游：BehaviorTreeEditorWindow.CreateGUI
        // 下游：OnGraphViewChanged / OnDragPerform
        public void Initialize()
        {
            if (m_initialized)
            {
                return;
            }

            m_initialized = true;

            SetupZoom(ContentZoomer.DefaultMinScale, ContentZoomer.DefaultMaxScale);
            this.AddManipulator(new ContentDragger());
            this.AddManipulator(new SelectionDragger());
            this.AddManipulator(new RectangleSelector());
            this.AddManipulator(new FreehandSelector());

            StyleSheet sheet = AssetDatabase.LoadAssetAtPath<StyleSheet>(BTEditorPaths.StyleSheetPath);

            if (sheet != null)
            {
                styleSheets.Add(sheet);
            }

            graphViewChanged += OnGraphViewChanged;

            // 自己实现拖拽连线：GraphView 自带的 EdgeConnector 在「节点 + 自定义端口」组合下不认目标端口，
            // 实测拖出线但落点连不上；这里改成鼠标按下端口 → 移动 → 松开时命中端口/节点即可连。
            // TrickleDown：先于目标元素（端口）收到事件 —— 端口自己的 MouseUp 可能 StopPropagation，
            // 用冒泡阶段就收不到，表现为「松手没反应」。
            RegisterCallback<MouseMoveEvent>(OnConnectDragMove, TrickleDown.TrickleDown);
            RegisterCallback<MouseUpEvent>(OnConnectDragEnd, TrickleDown.TrickleDown);

            RegisterCallback<DragUpdatedEvent>(OnDragUpdated);
            RegisterCallback<DragPerformEvent>(OnDragPerform);

            // 选中变化：把当前选中的节点抛给窗口
            RegisterCallback<MouseUpEvent>(_ => NotifySelection());

            // 空白处右键：快速加节点菜单
            RegisterCallback<ContextualMenuPopulateEvent>(OnContextMenu);

            // 背景网格（GraphView 自带 gridBackground）
            Insert(0, new GridBackground());
        }

        // 功能：载入一棵树（导入 JSON 时用）。
        // 入参：data 树数据（内部会接管引用）
        // 返回：无
        // 步骤：
        //   1) 清空画布与字典
        //   2) 逐节点建视图（位置与参数来自数据）
        //   3) 按 Children 连线
        //   4) 统一整理根状态
        // 上游：BehaviorTreeEditorWindow 的导入按钮
        // 下游：CreateNodeView / ConnectFromData
        public void ImportData(BTGraphData data)
        {
            Initialize();
            DeleteElements(graphElements.ToList());
            m_nodeViews.Clear();
            m_data = data ?? new BTGraphData();

            foreach (KeyValuePair<string, BTNodeData> pair in m_data.Nodes)
            {
                BTNodeDefine define = BTNodeRegistry.Find(pair.Value.NodeType);
                BTNodeView view = new BTNodeView(pair.Key, pair.Value, define, false);
                view.SetPosition(new Rect(pair.Value.PosX, pair.Value.PosY, 180f, 100f));
                AddElement(view);
                m_nodeViews[pair.Key] = view;
                HookPorts(view);
            }

            foreach (KeyValuePair<string, BTNodeData> pair in m_data.Nodes)
            {
                BTNodeView parentView = m_nodeViews[pair.Key];

                for (int i = 0; i < pair.Value.Children.Count; i++)
                {
                    if (!m_nodeViews.TryGetValue(pair.Value.Children[i], out BTNodeView childView))
                    {
                        continue;
                    }

                    if (parentView.OutputPort == null || childView.InputPort == null)
                    {
                        continue;
                    }

                    Edge edge = parentView.OutputPort.ConnectTo(childView.InputPort);
                    AddElement(edge);
                }
            }

            RefreshRoots();
            NotifySelection();
        }

        // 功能：把画布导出成数据快照（导出 JSON 时用）。
        // 入参：treeId 树名（为空则用原树名）
        // 返回：树数据（位置/连线/参数都以画面为准）
        // 步骤：
        //   1) 遍历节点视图：写回位置、参数、子节点 id
        //   2) 计算根（没有输入的节点）
        // 上游：BehaviorTreeEditorWindow 的导出按钮
        // 下游：BTJsonUtil.Export
        public BTGraphData ExportData(string treeId)
        {
            PruneDetachedViews();

            BTGraphData result = new BTGraphData
            {
                TreeId = string.IsNullOrEmpty(treeId) ? m_data.TreeId : treeId
            };

            foreach (KeyValuePair<string, BTNodeView> pair in m_nodeViews)
            {
                BTNodeData node = pair.Value.Data;
                node.PosX = pair.Value.GetPosition().x;
                node.PosY = pair.Value.GetPosition().y;
                node.Children.Clear();

                if (pair.Value.OutputPort != null)
                {
                    foreach (Edge edge in pair.Value.OutputPort.connections)
                    {
                        if (edge.input != null && edge.input.node is BTNodeView child)
                        {
                            node.Children.Add(child.NodeId);
                        }
                    }
                }

                result.Nodes[pair.Key] = node;
            }

            result.RootNodeId = result.FindRootId();
            return result;
        }

        // 功能：在指定位置新建一个节点（节点库拖放 / 右键菜单都走它）。
        // 入参：typeName 节点类型；position 画布坐标
        // 返回：新节点视图（类型未注册时返回 null）
        // 步骤：
        //   1) 找定义；没有就报错返回
        //   2) 分配 id
        //   3) 建数据（含默认参数）与视图
        //   4) 入字典、加入画布、整理根状态
        // 上游：OnDragPerform / OnContextMenu
        // 下游：CreateNodeView
        public BTNodeView CreateNode(string typeName, Vector2 position)
        {
            BTNodeDefine define = BTNodeRegistry.Find(typeName);

            if (define == null)
            {
                Debug.LogError("[BT] 未知节点类型：" + typeName);
                return null;
            }

            string id = m_data.NextNodeId();
            BTNodeData data = define.CreateNodeData();

            // 避免和已有节点完全重叠：重叠会把旧节点盖住，用户会以为「只有一个节点」
            position = AvoidOverlap(position);
            data.PosX = position.x;
            data.PosY = position.y;

            m_data.Nodes[id] = data;

            BTNodeView view = new BTNodeView(id, data, define, false);
            view.SetPosition(new Rect(position.x, position.y, 180f, 100f));
            AddElement(view);
            m_nodeViews[id] = view;
            HookPorts(view);

            RefreshRoots();
            return view;
        }

        // 功能：落点上已有节点时，把新节点往右下错开，直到不重叠。
        // 入参：position 期望位置
        // 返回：可用位置
        // 步骤：循环比较已有节点位置，太近就偏移 (32, 32)，最多试 40 次
        // 上游：CreateNode
        // 下游：无
        // 注意：只比位置不比尺寸 —— 够用，也不会因节点尺寸变化而抖动
        private Vector2 AvoidOverlap(Vector2 position)
        {
            const float MinDistance = 24f;
            const float Step = 32f;
            Vector2 candidate = position;

            for (int guard = 0; guard < 40; guard++)
            {
                bool conflict = false;

                foreach (KeyValuePair<string, BTNodeView> pair in m_nodeViews)
                {
                    Rect other = pair.Value.GetPosition();

                    if (Mathf.Abs(other.x - candidate.x) < MinDistance &&
                        Mathf.Abs(other.y - candidate.y) < MinDistance)
                    {
                        conflict = true;
                        break;
                    }
                }

                if (!conflict)
                {
                    return candidate;
                }

                candidate += new Vector2(Step, Step);
            }

            return candidate;
        }

        // 功能：选中并框选指定节点（预览失败时，把「多余的根」指给用户看）。
        // 入参：nodeIds 节点 id 列表
        // 返回：无
        // 步骤：清空选择 → 逐个加入 → 框选
        // 上游：BehaviorTreeEditorWindow.OnPreview 失败分支
        // 下游：GraphView.FrameSelection
        public void FocusNodes(IEnumerable<string> nodeIds)

                    any = true;

            if (any)

                FrameSelection();
            }
        }

        // 上游：BehaviorTreeEditorWindow 的停止预览

        public void ClearStatus()

                pair.Value.SetStatus(null);
            }
        }

        // 功能：把「已经从画布上消失、但还留在字典里」的幽灵节点清掉。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 本组件自己不在面板上时不动（窗口正在关闭/重建）
        //   2) 找 panel == null 的视图，从 m_nodeViews 与 m_data 里移除
        // 上游：ExportData（导出前兜底）
        // 下游：无
        // 注意：这是**兜底**，不是主要清理路径 —— 主要路径是重写 DeleteSelection。
        private void PruneDetachedViews()
        {
            if (panel == null || m_nodeViews.Count == 0)
            {
                return;
            }

            List<string> stale = null;

            foreach (KeyValuePair<string, BTNodeView> pair in m_nodeViews)
            {
                if (pair.Value.panel == null)
                {
                    stale ??= new List<string>();
                    stale.Add(pair.Key);
                }
            }

            if (stale == null)
            {
                return;
            }

            for (int i = 0; i < stale.Count; i++)
            {
                Debug.LogWarning("[BT] 清理幽灵节点：" + stale[i] + "（已不在画布上，但数据里还留着）。");
                m_nodeViews.Remove(stale[i]);
                m_data.Nodes.Remove(stale[i]);
            }
        }
        // 功能：取选中的第一个节点（没有就 null）。
        // 入参：无
        // 返回：节点视图
        // 步骤：从 selection 里找 BTNodeView
        // 上游：窗口刷新属性面板
        // 下游：无
        public BTNodeView GetSelectedNode()
        {
            foreach (ISelectable selectable in selection)
            {
                if (selectable is BTNodeView node)
                {
                    return node;
                }
            }

            return null;
        }

        // 功能：删除当前选中的节点（根节点不允许删）。
        // 入参：无
        // 返回：无
        // 步骤：逐个判断是不是根；不是就从画布与数据里移除
        // 上游：窗口的 Delete 按钮
        // 下游：RemoveNode
        public void DeleteSelectedNodes()
        {
            List<BTNodeView> targets = new List<BTNodeView>();

            foreach (ISelectable selectable in selection)
            {
                if (selectable is BTNodeView node)
                {
                    targets.Add(node);
                }
            }

            for (int i = 0; i < targets.Count; i++)
            {
                RemoveNode(targets[i]);
            }
        }

        // 功能：删除当前选中内容（**接管 GraphView 的内建删除**）。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 节点走 RemoveNode（会同时清 m_nodeViews 与 m_data）
        //   2) 连线直接 RemoveElement
        //   3) 刷新根徽标与选中状态
        // 上游：GraphView 的 Delete 键 / 内建右键 Delete / 工具栏【删除节点】
        // 下游：RemoveNode
        // 注意：**必须重写**：GraphView 内建删除走 DeleteElements，它**不触发 graphViewChanged**，
        //       不接管的话字典里会留下"看不见但还在"的幽灵节点（预览会报多个根）。
        public override EventPropagation DeleteSelection()
        {
            List<BTNodeView> nodes = new List<BTNodeView>();
            List<GraphElement> others = new List<GraphElement>();

            foreach (ISelectable selectable in selection)
            {
                if (selectable is BTNodeView node)
                {
                    nodes.Add(node);
                }
                else if (selectable is GraphElement element)
                {
                    others.Add(element);
                }
            }

            for (int i = 0; i < nodes.Count; i++)
            {
                RemoveNode(nodes[i]);
            }

            for (int i = 0; i < others.Count; i++)
            {
                RemoveElement(others[i]);
            }

            RefreshRoots();
            NotifySelection();
            return EventPropagation.Stop;
        }

        // 功能：复制当前选中的节点（参数与位置都拷，右上偏移一点）。
        // 入参：无
        // 返回：新节点视图（没有选中返回 null）
        // 步骤：取选中 → 新建同类型节点（参数逐个覆盖）→ 偏移位置
        // 上游：窗口的 Duplicate 按钮 / Ctrl+D
        // 下游：CreateNode
        public BTNodeView DuplicateSelection()
        {
            BTNodeView source = GetSelectedNode();

            if (source == null)
            {
                return null;
            }

            Rect position = source.GetPosition();
            BTNodeView copy = CreateNode(source.Data.NodeType, new Vector2(position.x + 40f, position.y + 40f));

            if (copy == null)
            {
                return null;
            }

            foreach (KeyValuePair<string, BTParamValue> pair in source.Data.Params)
            {
                copy.Data.Params[pair.Key] = pair.Value;
            }

            copy.UpdateSubtitle();
            return copy;
        }

        // 功能：给一个节点的端口挂上「按下开始连线」的钩子（TrickleDown，抢在 GraphView 自带连接器之前）。
        // 入参：view 节点视图
        // 返回：无
        // 步骤：输入/输出端口各挂一个 MouseDown
        // 上游：CreateNode / ImportData
        // 下游：OnConnectDragStart
        private void HookPorts(BTNodeView view)
        {
            if (view.InputPort != null)
            {
                view.InputPort.RegisterCallback<MouseDownEvent>(OnConnectDragStart, TrickleDown.TrickleDown);
            }

            if (view.OutputPort != null)
            {
                view.OutputPort.RegisterCallback<MouseDownEvent>(OnConnectDragStart, TrickleDown.TrickleDown);
            }
        }

        // 功能：在端口上按下左键 → 开始拉线。
        // 入参：evt 鼠标按下事件
        // 返回：无
        // 步骤：记下源端口与起点、建预备线、吃掉事件（不让 GraphView 自带连接器介入）
        // 上游：端口 MouseDown（TrickleDown）
        // 下游：OnConnectDragMove / OnConnectDragEnd
        private void OnConnectDragStart(MouseDownEvent evt)
        {
            if (evt.button != 0 || !(evt.currentTarget is Port port))
            {
                return;
            }

            m_dragSourcePort = port;
            m_dragStart = port.worldBound.center;
            m_dragCurrent = m_dragStart;

            if (m_dragLine == null)
            {
                m_dragLine = new VisualElement();
                m_dragLine.pickingMode = PickingMode.Ignore;
                m_dragLine.style.position = Position.Absolute;
                m_dragLine.style.left = 0f;
                m_dragLine.style.top = 0f;
                m_dragLine.style.right = 0f;
                m_dragLine.style.bottom = 0f;
                m_dragLine.generateVisualContent += OnDrawDragLine;
            }

            contentContainer.Add(m_dragLine);
            m_dragLine.MarkDirtyRepaint();
            evt.StopPropagation();
        }

        // 功能：拖拽移动时刷新预备线。
        // 入参：evt 鼠标移动事件
        // 返回：无
        // 步骤：更新端点并重绘
        // 上游：鼠标移动
        // 下游：OnDrawDragLine
        private void OnConnectDragMove(MouseMoveEvent evt)
        {
            if (m_dragSourcePort == null)
            {
                return;
            }

            m_dragCurrent = evt.mousePosition;
            m_dragLine?.MarkDirtyRepaint();
        }

        // 功能：松开鼠标 → 找落点端口/节点 → 校验 → 连上。
        // 入参：evt 鼠标松开事件
        // 返回：无
        // 步骤：
        //   1) 没有源端口就返回（没在拖）
        //   2) 用 panel.Pick 找落点元素，往上找最近的 Port（找不到就找 BTNodeView 的输入口）
        //   3) 校验方向、自连、成环、单父/单子
        //   4) 连上并清预备线
        // 上游：鼠标松开
        // 下游：CompleteConnection
        private void OnConnectDragEnd(MouseUpEvent evt)
        {
            if (m_dragSourcePort == null)
            {
                return;
            }

            Port source = m_dragSourcePort;
            m_dragSourcePort = null;

            if (m_dragLine != null)
            {
                m_dragLine.RemoveFromHierarchy();
            }

            Port target = FindPortAt(evt.mousePosition);

            if (target == null)
            {
                return;
            }

            CompleteConnection(source, target);
            evt.StopPropagation();
        }

        // 功能：把面板坐标下的落点换算成端口（找不到端口就退而用落点所在节点的输入口）。
        // 入参：panelPosition 鼠标位置（面板坐标）
        // 返回：端口；没有返回 null
        // 步骤：panel.Pick → 沿父链找 Port；退化为找 BTNodeView
        // 上游：OnConnectDragEnd
        // 下游：无
        private Port FindPortAt(Vector2 panelPosition)
        {
            if (panel == null)
            {
                return null;
            }

            VisualElement picked = panel.Pick(panelPosition);
            VisualElement cursor = picked;

            while (cursor != null)
            {
                if (cursor is Port port)
                {
                    return port;
                }

                if (cursor is BTNodeView nodeView)
                {
                    return nodeView.InputPort;
                }

                cursor = cursor.parent;
            }

            return null;
        }

        // 功能：校验并建立一条连线（输出口 → 输入口），同时做单父/单子与成环检查。
        // 入参：source 源端口；target 目标端口
        // 返回：无
        // 步骤：
        //   1) 方向必须是 out → in
        //   2) 不能自己连自己
        //   3) 不能成环（目标是源的祖先）
        //   4) 目标已有父、源已有子 ⇒ 先断开旧的
        //   5) ConnectTo + AddElement
        // 上游：OnConnectDragEnd
        // 下游：BTNodeView 的端口
        private void CompleteConnection(Port source, Port target)
        {
            if (source.direction != Direction.Output || target.direction != Direction.Input)
            {
                // 允许从输入口反向拖到输出口（用户体验更宽容）
                if (source.direction == Direction.Input && target.direction == Direction.Output)
                {
                    Port swap = source;
                    source = target;
                    target = swap;
                }
                else
                {
                    Debug.LogWarning("[BT] 连线必须从输出口连到输入口。");
                    return;
                }
            }

            if (!(source.node is BTNodeView from) || !(target.node is BTNodeView to))
            {
                return;
            }

            if (from == to)
            {
                Debug.LogWarning("[BT] 不能把节点连到自己。");
                return;
            }

            if (IsAncestor(from, to))
            {
                Debug.LogWarning("[BT] 这样连会形成环（" + to.NodeId + " 是 " + from.NodeId + " 的祖先）。");
                return;
            }

            // 单父：目标已连父的，先断
            if (target.connections.Any())
            {
                foreach (Edge existing in target.connections.ToList())
                {
                    existing.input.Disconnect(existing);
                    RemoveElement(existing);
                }
            }

            // 多子还是单子由节点定义决定：组合节点（MaxChildren = -1 或 >1）允许连多个子节点；
            // 只有显式声明 MaxChildren == 1 的节点才「一个输出只留一条」。
            int maxChildren = from.Define == null ? 1 : from.Define.MaxChildren;

            if (maxChildren == 1 && source.connections.Any())
            {
                foreach (Edge existing in source.connections.ToList())
                {
                    existing.output.Disconnect(existing);
                    RemoveElement(existing);
                }
            }

            Edge edge = source.ConnectTo(target);
            AddElement(edge);
            RefreshRoots();
        }

        // 功能：画拖拽时的预备线。
        // 入参：painter 绘制器
        // 返回：无
        // 步骤：把两个面板坐标转成元素局部坐标后画一条黄线
        // 上游：m_dragLine.generateVisualContent
        // 下游：无
        private void OnDrawDragLine(MeshGenerationContext context)
        {
            if (m_dragLine == null)
            {
                return;
            }

            Painter2D painter = context.painter2D;
            Vector2 from = m_dragLine.WorldToLocal(m_dragStart);
            Vector2 to = m_dragLine.WorldToLocal(m_dragCurrent);
            painter.strokeColor = new Color(1f, 0.85f, 0.2f);
            painter.lineWidth = 2f;
            painter.BeginPath();
            painter.MoveTo(from);
            painter.LineTo(to);
            painter.Stroke();
        }
        // 功能：图结构变化的总校验入口（GraphView 的所有增删都会经过这里）。
        // 入参：change 变化描述
        // 返回：修正后的变化（返回 null 表示不应用）
        // 步骤：
        //   1) 过滤要新建的连线：自连、成环、单子（先断旧）一律处理
        //   2) 处理要删除的元素：节点删除时同步清数据；根节点拒删
        // 上游：GraphView 内部
        // 下游：RemoveNode / RefreshRoots
        private GraphViewChange OnGraphViewChanged(GraphViewChange change)
        {
            if (change.edgesToCreate != null && change.edgesToCreate.Count > 0)
            {
                List<Edge> kept = new List<Edge>();

                for (int i = 0; i < change.edgesToCreate.Count; i++)
                {
                    Edge edge = change.edgesToCreate[i];

                    if (!(edge.output?.node is BTNodeView from) || !(edge.input?.node is BTNodeView to))
                    {
                        continue;
                    }

                    if (from == to)
                    {
                        Debug.LogWarning("[BT] 不能把节点连到自己。");
                        continue;
                    }

                    if (IsAncestor(from, to))
                    {
                        Debug.LogWarning("[BT] 这样连会形成环（" + to.NodeId + " 是 " + from.NodeId + " 的祖先）。");
                        continue;
                    }

                    // 单父：目标已经有父连线的，先断掉
                    if (to.InputPort != null && to.InputPort.connections.Any())
                    {
                        foreach (Edge existing in to.InputPort.connections.ToList())
                        {
                            existing.input.Disconnect(existing);
                            RemoveElement(existing);
                        }
                    }

                    // 只有 MaxChildren == 1 的节点才强制「一个输出一条子连线」；组合节点允许多子
                    int maxChildren = from.Define == null ? 1 : from.Define.MaxChildren;

                    if (maxChildren == 1 && from.OutputPort != null && from.OutputPort.connections.Any())
                    {
                        foreach (Edge existing in from.OutputPort.connections.ToList())
                        {
                            existing.output.Disconnect(existing);
                            RemoveElement(existing);
                        }
                    }

                    kept.Add(edge);
                }

                change.edgesToCreate = kept;
            }

            if (change.elementsToRemove != null && change.elementsToRemove.Count > 0)
            {
                List<GraphElement> allowed = new List<GraphElement>();

                for (int i = 0; i < change.elementsToRemove.Count; i++)
                {
                    GraphElement element = change.elementsToRemove[i];

                    if (element is BTNodeView node)
                    {
                        if (IsRootNode(node))
                        {
                            Debug.LogWarning("[BT] 根节点不能删除（先把它连到别的节点下面，或换个根）。");
                            continue;
                        }

                        RemoveNode(node, false);
                        continue;
                    }

                    allowed.Add(element);
                }

                // 节点已经在 RemoveNode 里删掉了，这里只保留非节点元素（连线）
                change.elementsToRemove = allowed.Where(e => !(e is BTNodeView)).ToList();
            }

            RefreshRoots();
            return change;
        }

        // 功能：从画布与数据里移除一个节点（连带它的连线）。
        // 入参：node 节点视图；removeElement 是否由本方法负责从画布移除（GraphView 已移除时传 false）
        // 返回：无
        // 步骤：断所有连线 → 从画布移除 → 从字典与数据移除
        // 上游：DeleteSelection / OnGraphViewChanged
        // 下游：无
        private void RemoveNode(BTNodeView node, bool removeElement = true)
        {
            if (node == null)
            {
                return;
            }

            if (node.InputPort != null)
            {
                foreach (Edge edge in node.InputPort.connections.ToList())
                {
                    edge.input.Disconnect(edge);
                    RemoveElement(edge);
                }
            }

            if (node.OutputPort != null)
            {
                foreach (Edge edge in node.OutputPort.connections.ToList())
                {
                    edge.output.Disconnect(edge);
                    RemoveElement(edge);
                }
            }

            if (removeElement)
            {
                RemoveElement(node);
            }

            m_nodeViews.Remove(node.NodeId);
            m_data.Nodes.Remove(node.NodeId);
        }

        // 功能：判断某节点是不是祖先（用于环检测）。
        // 入参：candidate 候选祖先；node 起点
        // 返回：true = candidate 在 node 的祖先链上
        // 步骤：从 node 顺着输入连线往上走，遇到 candidate 就命中
        // 上游：OnGraphViewChanged
        // 下游：无
        private static bool IsAncestor(BTNodeView candidate, BTNodeView node)
        {
            BTNodeView current = node;

            while (current != null)
            {
                if (current == candidate)
                {
                    return true;
                }

                Edge parentEdge = current.InputPort?.connections.FirstOrDefault();
                current = parentEdge?.output?.node as BTNodeView;
            }

            return false;
        }

        // 功能：判断是否是根（没有任何输入连线）。
        // 入参：node 节点视图
        // 返回：true = 根
        // 步骤：看输入端口有没有连线
        // 上游：OnGraphViewChanged
        // 下游：无
        private static bool IsRootNode(BTNodeView node)
        {
            return node != null && (node.InputPort == null || !node.InputPort.connections.Any());
        }

        // 功能：整理根状态（有输入的节点必须有输入端口；无输入的去掉输入端口）。
        // 入参：无
        // 返回：无
        // 步骤：对每个节点判断 IsRootNode 并 ApplyRootState
        // 上游：所有结构变化之后
        // 下游：BTNodeView.ApplyRootState
        // 注意：需求要求"根节点不能有输入端口"，所以这一步是视觉效果也是规则体现
        private void RefreshRoots()
        {
            List<BTNodeView> roots = new List<BTNodeView>();

            foreach (KeyValuePair<string, BTNodeView> pair in m_nodeViews)
            {
                if (IsRootNode(pair.Value))
                {
                    roots.Add(pair.Value);
                }
            }

            // 只有一个根时才打徽标；多个根说明树还没连好（导出会被 Validate 拦下）
            for (int i = 0; i < roots.Count; i++)
            {
                roots[i].ApplyRootState(roots.Count == 1);
            }

            if (roots.Count > 1)
            {
                Debug.LogWarning("[BT] 当前有 " + roots.Count + " 个根节点（" + roots.Count +
                                 " 个没有父节点）。一棵树只能有一个根，导出前请把多余的连到树上。");
            }
        }

        // 功能：把当前选中的节点通知窗口。
        // 入参：无
        // 返回：无
        // 步骤：取选中节点并触发事件
        // 上游：鼠标抬起
        // 下游：BehaviorTreeEditorWindow.RefreshInspector
        private void NotifySelection()
        {
            NodeSelected?.Invoke(GetSelectedNode());
        }

        // 功能：拖拽进入画布时显示"可放置"光标。
        // 入参：evt 拖拽事件
        // 返回：无
        // 步骤：有我们的数据类型就接受
        // 上游：节点库开始拖拽
        // 下游：无
        private void OnDragUpdated(DragUpdatedEvent evt)
        {
            if (DragAndDrop.GetGenericData(DragDataType) is string)
            {
                DragAndDrop.visualMode = DragAndDropVisualMode.Copy;
                evt.StopPropagation();
            }
        }

        // 功能：在拖放位置创建节点。
        // 入参：evt 拖放事件
        // 返回：无
        // 步骤：读类型名 → 把屏幕坐标转成画布坐标 → CreateNode
        // 上游：节点库拖放
        // 下游：CreateNode
        private void OnDragPerform(DragPerformEvent evt)
        {
            if (!(DragAndDrop.GetGenericData(DragDataType) is string typeName))
            {
                return;
            }

            DragAndDrop.AcceptDrag();
            Vector2 local = this.WorldToLocal(evt.mousePosition);
            CreateNode(typeName, local);
            evt.StopPropagation();
        }

        // 功能：空白处右键弹出"新建节点"菜单。
        // 入参：evt 菜单填充事件
        // 返回：无
        // 步骤：按分类建子菜单，点了就在鼠标位置建节点
        // 上游：右键
        // 下游：CreateNode
        private void OnContextMenu(ContextualMenuPopulateEvent evt)
        {
            Vector2 local = this.WorldToLocal(evt.mousePosition);

            // 右键点在节点上 ⇒ 给「节点级」操作；点在空白 ⇒ 给「新建节点」菜单
            BTNodeView node = FindNodeAt(evt.mousePosition);

            if (node != null)
            {
                BTNodeView target = node;
                evt.menu.AppendAction("设为根（断开父连线）", _ => SetAsRoot(target));
                evt.menu.AppendAction("复制此节点", _ =>
                {
                    ClearSelection();
                    AddToSelection(target);
                    DuplicateSelection();
                });
                evt.menu.AppendAction("删除此节点", _ => RemoveNode(target));
                return;
            }

            IReadOnlyList<BTNodeDefine> defines = BTNodeRegistry.All;

            for (int i = 0; i < defines.Count; i++)
            {
                string typeName = defines[i].TypeName;
                string label = defines[i].Category + "/" + defines[i].DisplayName;
                evt.menu.AppendAction(label, _ => CreateNode(typeName, local));
            }
        }

        // 功能：把某个节点设为根（断开它和父节点之间的连线）。
        // 入参：node 目标节点
        // 返回：无
        // 步骤：断开该节点的所有输入连线 → 刷新根徽标
        // 上游：右键菜单「设为根」
        // 下游：RefreshRoots
        // 注意：一棵树只能有一个根；如果之前有别的根，它必须已经被连到树上，否则导出校验仍会报错。
        private void SetAsRoot(BTNodeView node)
        {
            if (node == null || node.InputPort == null)
            {
                return;
            }

            foreach (Edge edge in node.InputPort.connections.ToList())
            {
                edge.input.Disconnect(edge);
                RemoveElement(edge);
            }

            RefreshRoots();
            Debug.Log("[BT] 已把 " + node.NodeId + "（" + node.Data.NodeType + "）设为根。");
        }

        // 功能：按面板坐标找节点视图。
        // 入参：panelPosition 鼠标位置（面板坐标）
        // 返回：节点视图；没有返回 null
        // 步骤：panel.Pick → 沿父链找 BTNodeView
        // 上游：OnContextMenu
        // 下游：无
        private BTNodeView FindNodeAt(Vector2 panelPosition)
        {
            if (panel == null)
            {
                return null;
            }

            VisualElement cursor = panel.Pick(panelPosition);

            while (cursor != null)
            {
                if (cursor is BTNodeView node)
                {
                    return node;
                }

                cursor = cursor.parent;
            }

            return null;
        }
    }

    // 编辑器资源路径集中放这里，避免各处写死字符串
    internal static class BTEditorPaths
    {
        // UXML 布局路径
        public const string LayoutPath = "Assets/_Project/Editor/BehaviorTree/Resources/BehaviorTreeEditor.uxml";

        // USS 样式路径
        public const string StyleSheetPath = "Assets/_Project/Editor/BehaviorTree/Resources/BehaviorTreeEditor.uss";
    }
```

```csharp
// 这个文件里有：
//   BTInspectorView（类）：右侧属性面板（按节点定义动态生成控件）。
//
// 【编辑器 UI 代码】只负责把数值显示出来、把用户改动写回 BTNodeData。

using System.Collections.Generic;
using UnityEditor.UIElements;
using UnityEngine.UIElements;

namespace NBC.EditorTools.BehaviorTree
{
    // 主要功能：选中一个节点后，按它的 BTNodeDefine.Params 生成输入控件（float/int/bool/string），改值实时写回数据。
    // 主要数据成员：m_node（当前绑定的节点视图）、m_slot（放控件的容器）。
    // 主要外部方法：Bind（换绑定的节点）。
    // 谁在用它：BehaviorTreeEditorWindow（选中变化时调 Bind）。
    // 注意：控件是"每次重建"的（节点类型不同参数就不同）；这点开销在编辑器里可以忽略。
    public sealed class BTInspectorView : VisualElement
    {
        // 当前绑定的节点（null = 没选中）
        private BTNodeView m_node;

        // 控件容器（每次 Bind 清空重建）
        private readonly VisualElement m_slot;

        // 功能：构造面板。
        // 入参：无
        // 返回：无
        // 步骤：建容器、加入自身、显示占位提示
        // 上游：BehaviorTreeEditorWindow.CreateGUI
        // 下游：Bind
        public BTInspectorView()
        {
            m_slot = new VisualElement();
            m_slot.AddToClassList("bt-inspector");
            Add(m_slot);
            ShowPlaceholder();
        }

        // 功能：绑定一个节点并重建控件。
        // 入参：node 节点视图（null = 清空）
        // 返回：无
        // 步骤：
        //   1) 记住节点
        //   2) 清空容器
        //   3) 没有节点或没有定义 ⇒ 占位提示
        //   4) 否则逐参数建控件（按类型）
        // 上游：窗口的 NodeSelected 回调
        // 下游：AddField
        public void Bind(BTNodeView node)
        {
            m_node = node;
            m_slot.Clear();

            if (node == null || node.Define == null)
            {
                ShowPlaceholder();
                return;
            }

            Label header = new Label(node.NodeId + "  ·  " + node.Data.NodeType);
            header.AddToClassList("bt-inspector-title");
            m_slot.Add(header);

            if (!string.IsNullOrEmpty(node.Data.NodeType))
            {
                Label idLabel = new Label("节点 id：" + node.NodeId);
                idLabel.AddToClassList("bt-inspector-hint");
                m_slot.Add(idLabel);
            }

            if (node.Define.Params.Length == 0)
            {
                Label none = new Label("该节点没有可配置参数。");
                none.AddToClassList("bt-inspector-hint");
                m_slot.Add(none);
                return;
            }

            for (int i = 0; i < node.Define.Params.Length; i++)
            {
                AddField(node, node.Define.Params[i]);
            }
        }

        // 功能：按参数类型建一个控件并接好"改值即写回"。
        // 入参：node 节点视图；param 参数定义
        // 返回：无
        // 步骤：取当前值 → 建对应控件 → 注册回调写回数据并刷新副标题
        // 上游：Bind
        // 下游：BTNodeData.Params
        private void AddField(BTNodeView node, BTParamDefine param)
        {
            BTParamValue current = node.Data.Params.TryGetValue(param.Key, out BTParamValue value)
                ? value
                : param.CreateDefault();

            switch (param.Type)
            {
                case BTParamType.Int:
                {
                    IntegerField field = new IntegerField(param.Label) { value = current.AsInt() };
                    field.RegisterValueChangedCallback(evt =>
                    {
                        node.Data.Params[param.Key] = BTParamValue.FromInt(evt.newValue);
                        node.UpdateSubtitle();
                    });
                    m_slot.Add(field);
                    break;
                }

                case BTParamType.Bool:
                {
                    Toggle field = new Toggle(param.Label) { value = current.AsBool() };
                    field.RegisterValueChangedCallback(evt =>
                    {
                        node.Data.Params[param.Key] = BTParamValue.FromBool(evt.newValue);
                        node.UpdateSubtitle();
                    });
                    m_slot.Add(field);
                    break;
                }

                case BTParamType.String:
                {
                    TextField field = new TextField(param.Label) { value = current.AsString() };
                    field.RegisterValueChangedCallback(evt =>
                    {
                        node.Data.Params[param.Key] = BTParamValue.FromString(evt.newValue);
                        node.UpdateSubtitle();
                    });
                    m_slot.Add(field);
                    break;
                }

                default:
                {
                    FloatField field = new FloatField(param.Label) { value = current.AsFloat() };
                    field.RegisterValueChangedCallback(evt =>
                    {
                        node.Data.Params[param.Key] = BTParamValue.FromFloat(evt.newValue);
                        node.UpdateSubtitle();
                    });
                    m_slot.Add(field);
                    break;
                }
            }
        }

        // 功能：显示"没选中节点"的占位提示。
        // 入参：无
        // 返回：无
        // 步骤：清空后加一行灰字
        // 上游：构造 / Bind(null)
        // 下游：无
        private void ShowPlaceholder()
        {
            m_slot.Clear();
            Label hint = new Label("选中画布上的一个节点，这里会显示它的参数。");
            hint.AddToClassList("bt-inspector-hint");
            m_slot.Add(hint);
        }
    }
}
```

```csharp
// 这个文件里有：
//   BehaviorTreeEditorWindow（类）：行为树编辑器主窗口（菜单入口 + 三栏装配 + 预览驱动 + 导入导出）。
//
// 【编辑器 UI 代码】本文件只做"装配与调度"：画布在 BTGraphView、属性面板在 BTInspectorView、
// 预览运行时在 BTPreviewRunner（仅编辑器）。窗口本身在任何平台都不进包（NBC.Editor 只在编辑器编译）。

using System;
using System.Collections.Generic;
using System.IO;
using UnityEditor;
using UnityEditor.UIElements;
using UnityEngine;
using UnityEngine.UIElements;

namespace NBC.EditorTools.BehaviorTree
{
    // 主要功能：行为树编辑器窗口 —— 工具栏（导入/导出/预览/停止/删除/复制）、左中右三栏、200ms 预览驱动。
    // 主要数据成员：m_graphView、m_inspector、m_runner、m_blackboardFields、m_lastTick。
    // 主要外部方法：OpenWindow（菜单入口）。
    // 谁在用它：菜单「AI工具/BehaviorTree Editor」。
    // 注意：预览用 EditorApplication.update 驱动（窗口关闭要解绑，否则会空引用）。
    public sealed class BehaviorTreeEditorWindow : EditorWindow
    {
        // 画布
        private BTGraphView m_graphView;

        // 右侧属性面板
        private BTInspectorView m_inspector;

        // 预览运行时（仅编辑器）
        private BTPreviewRunner m_runner;

        // 预览驱动用的上次时间戳
        private double m_lastTickTime;

        // 状态栏
        private Label m_statusLabel;

        // 树名输入框
        private TextField m_treeIdField;

        // 黑板输入框（键 → 控件），用于预览时读值
        private readonly Dictionary<string, VisualElement> m_blackboardFields =
            new Dictionary<string, VisualElement>();

        // 功能：菜单入口。
        // 入参：无
        // 返回：无
        // 步骤：取已有窗口或新建并显示
        // 上游：Unity 菜单
        // 下游：CreateGUI
        [MenuItem("AI工具/BehaviorTree Editor")]
        public static void OpenWindow()
        {
            BehaviorTreeEditorWindow window = GetWindow<BehaviorTreeEditorWindow>();
            window.titleContent = new GUIContent("行为树编辑器");
            window.minSize = new Vector2(1100f, 620f);
            window.Show();
        }

        // 功能：装配整个窗口（UXML + 三栏 + 事件）。
        // 入参：无
        // 返回：无
        // 步骤：
        //   1) 载入 UXML（失败就退化成纯代码布局）
        //   2) 取出各占位容器，建画布/属性面板/节点库/黑板
        //   3) 接工具栏按钮
        //   4) 启动预览驱动（EditorApplication.update）
        // 上游：Unity 创建窗口
        // 下游：BuildPalette / BuildBlackboard / BindToolbar
        public void CreateGUI()
        {
            VisualElement root = rootVisualElement;
            root.Clear();

            // 样式表必须加在**窗口根节点**上：只加给 GraphView 的话，工具栏/三栏的 flex 规则全部不生效，
            // 界面会塌成竖排、画布高度变成 0（第一次验收就是这样）。
            StyleSheet sheet = AssetDatabase.LoadAssetAtPath<StyleSheet>(BTEditorPaths.StyleSheetPath);

            if (sheet != null && !root.styleSheets.Contains(sheet))
            {
                root.styleSheets.Add(sheet);
            }

            VisualTreeAsset layout = AssetDatabase.LoadAssetAtPath<VisualTreeAsset>(BTEditorPaths.LayoutPath);

            if (layout != null)
            {
                layout.CloneTree(root);
            }
            else
            {
                Debug.LogWarning("[BT] 找不到布局文件 " + BTEditorPaths.LayoutPath + "，用纯代码布局兜底。");

            VisualElement canvasSlot = root.Q<VisualElement>("canvas-slot");

            if (canvasSlot == null)
            {
                canvasSlot = new VisualElement();
                root.Add(canvasSlot);
            }

            m_graphView = new BTGraphView();
            m_graphView.Initialize();
            m_graphView.style.flexGrow = 1f;
            canvasSlot.Add(m_graphView);

            VisualElement inspectorSlot = root.Q<VisualElement>("inspector-slot");
            m_inspector = new BTInspectorView();

            if (inspectorSlot != null)
            {
                inspectorSlot.Add(m_inspector);

            m_graphView.NodeSelected += node => m_inspector.Bind(node);

            m_runner = new BTPreviewRunner();
            BuildPalette(root);
            BuildBlackboard(root);
            BindToolbar(root);

            m_lastTickTime = EditorApplication.timeSinceStartup;
            EditorApplication.update += OnEditorUpdate;
            SetStatus("就绪：从左侧拖节点到画布，连线后再点【预览】。");

        // 功能：窗口关闭时解绑预览驱动。
        // 入参：无

        // 上游：Unity 销毁窗口
        // 下游：BTPreviewRunner.Stop
        public void OnDisable()
        {
            EditorApplication.update -= OnEditorUpdate;

            if (m_runner != null)
            {
                m_runner.Stop();

        // 功能：每帧驱动预览（内部按 200ms 限流），并把状态刷到节点上。
        // 入参：无
        // 返回：无
        // 步骤：算 delta → runner.Tick → 真的 Tick 了才刷颜色
        // 上游：EditorApplication.update
        // 下游：BTGraphView.ApplyStatus
        private void OnEditorUpdate()
        {
            if (m_runner == null || m_graphView == null || !m_runner.IsRunning)
            {
                m_lastTickTime = EditorApplication.timeSinceStartup;
                return;
            }

            double now = EditorApplication.timeSinceStartup;
            float delta = (float)(now - m_lastTickTime);
            m_lastTickTime = now;

            if (m_runner.Tick(delta))
            {
                m_graphView.ApplyStatus(m_runner.Status);
            }
        }

        // 功能：建左侧节点库（按分类分组，可拖到画布）。
        // 入参：root 根元素
        // 返回：无
        // 步骤：取 palette-slot；按 Category 分组加标题；每个节点一个可拖拽的按钮
        // 上游：CreateGUI

        private void BuildPalette(VisualElement root)
        {

            if (slot == null)
            {
                return;
            }

            slot.Clear();

            IReadOnlyList<BTNodeDefine> defines = BTNodeRegistry.All;
            BTNodeCategory currentCategory = (BTNodeCategory)(-1);

            for (int i = 0; i < defines.Count; i++)
            {
                BTNodeDefine define = defines[i];

                if (define.Category != currentCategory)
                {
                    currentCategory = define.Category;
                    Label header = new Label(currentCategory.ToString());
                    header.AddToClassList("bt-palette-header");
                    slot.Add(header);
                }

                Button item = new Button(() => AddNodeAtCenter(define.TypeName))
                {
                    text = define.DisplayName
                };

                item.AddToClassList("bt-palette-item");
                string typeName = define.TypeName;
                item.RegisterCallback<MouseDownEvent>(evt => StartPaletteDrag(item, typeName, evt));
                slot.Add(item);
            }

            Label hint = new Label("把上面的节点拖到画布，或点击在画布中心新建。");
            hint.AddToClassList("bt-inspector-hint");
            slot.Add(hint);
        }

        // 功能：开始拖拽一个节点类型（供画布接收）。
        // 入参：source 拖拽源元素；typeName 节点类型；evt 鼠标事件
        // 返回：无
        // 步骤：PrepareStartDrag → 塞入数据类型 → StartDrag
        // 上游：节点库的 MouseDown
        // 下游：BTGraphView.OnDragUpdated / OnDragPerform
        private void StartPaletteDrag(VisualElement source, string typeName, MouseDownEvent evt)
        {
            if (evt.button != 0)
            {
                return;
            }

            DragAndDrop.PrepareStartDrag();
            DragAndDrop.SetGenericData(BTGraphView.DragDataType, typeName);
            DragAndDrop.objectReferences = new UnityEngine.Object[0];
            DragAndDrop.StartDrag(typeName);
            evt.StopPropagation();
        }

        // 功能：在画布中心创建节点（点击节点库时的兜底操作，不用拖也能加）。
        // 入参：typeName 节点类型
        // 返回：无
        // 步骤：取画布中心坐标 → CreateNode
        // 上游：节点库按钮点击
        // 下游：BTGraphView.CreateNode
        private void AddNodeAtCenter(string typeName)

                return;

            Vector2 center = new Vector2(m_graphView.layout.width * 0.4f, m_graphView.layout.height * 0.4f);
            m_graphView.CreateNode(typeName, center);
            SetStatus("已新建节点：" + typeName);

        // 功能：建预览用黑板（hp / targetId / skillCd 三个常用键）。
        // 入参：root 根元素
        // 返回：无
        // 步骤：取 blackboard-slot；按类型建控件；改动写进 runner.Blackboard
        // 上游：CreateGUI
        // 下游：BTBlackboard.Set
        private void BuildBlackboard(VisualElement root)
        {
            VisualElement slot = root.Q<VisualElement>("blackboard-slot");

            if (slot == null)
            {
                return;
            }

            slot.Clear();
            m_blackboardFields.Clear();

            AddBlackboardInt(slot, "hp", "玩家血量", 100);
            AddBlackboardInt(slot, "targetId", "目标 id（0=没有）", 0);
            AddBlackboardFloat(slot, "skillCd", "技能冷却（秒）", 0f);
        }

        // 功能：加一个整数黑板项。
        // 入参：slot 容器；key 键；label 显示名；defaultValue 默认值
        // 返回：无
        // 步骤：建 IntegerField → 注册回调写黑板 → 加进容器
        // 上游：BuildBlackboard
        // 下游：BTBlackboard.Set
        private void AddBlackboardInt(VisualElement slot, string key, string label, int defaultValue)
        {
            IntegerField field = new IntegerField(label) { value = defaultValue };
            field.RegisterValueChangedCallback(evt =>
            {
                m_runner?.Blackboard.Set(key, BTParamValue.FromInt(evt.newValue));
            });
            slot.Add(field);
            m_blackboardFields[key] = field;
            m_runner?.Blackboard.Set(key, BTParamValue.FromInt(defaultValue));
        }

        // 功能：加一个浮点黑板项。
        // 入参：slot 容器；key 键；label 显示名；defaultValue 默认值
        // 返回：无
        // 步骤：建 FloatField → 注册回调写黑板 → 加进容器
        // 上游：BuildBlackboard
        // 下游：BTBlackboard.Set
        private void AddBlackboardFloat(VisualElement slot, string key, string label, float defaultValue)
        {
            FloatField field = new FloatField(label) { value = defaultValue };
            field.RegisterValueChangedCallback(evt =>
            {
                m_runner?.Blackboard.Set(key, BTParamValue.FromFloat(evt.newValue));
            });
            slot.Add(field);
            m_blackboardFields[key] = field;
            m_runner?.Blackboard.Set(key, BTParamValue.FromFloat(defaultValue));
        }

        // 功能：接好工具栏按钮与树名输入框。
        // 入参：root 根元素
        // 返回：无
        // 步骤：逐个 Q 按钮并注册点击；状态栏初始化
        // 上游：CreateGUI
        // 下游：各种 OnXxx 方法
        private void BindToolbar(VisualElement root)
        {
            m_statusLabel = root.Q<Label>("status");
            m_treeIdField = root.Q<TextField>("tree-id");

            if (m_treeIdField != null)
            {
                m_treeIdField.value = "new_tree";
            }

            root.Q<Button>("btn-import")?.RegisterCallback<ClickEvent>(_ => OnImport());
            root.Q<Button>("btn-export")?.RegisterCallback<ClickEvent>(_ => OnExport());
            root.Q<Button>("btn-preview")?.RegisterCallback<ClickEvent>(_ => OnPreview());
            root.Q<Button>("btn-stop")?.RegisterCallback<ClickEvent>(_ => OnStopPreview());
            root.Q<Button>("btn-delete")?.RegisterCallback<ClickEvent>(_ => OnDelete());
            root.Q<Button>("btn-duplicate")?.RegisterCallback<ClickEvent>(_ => OnDuplicate());
            root.Q<Button>("btn-clear")?.RegisterCallback<ClickEvent>(_ => OnClear());
        }

        // 功能：导出当前树为 JSON 文件。
        // 入参：无
        // 返回：无
        // 步骤：取树名 → 导出数据 → 校验 → 选保存路径 → 写文件
        // 上游：工具栏【导出JSON】
        // 下游：BTJsonUtil.Export
        private void OnExport()
        {
            string treeId = m_treeIdField != null ? m_treeIdField.value : "new_tree";
            BTGraphData data = m_graphView.ExportData(treeId);

            if (!data.Validate(out string error))
            {
                SetStatus("❌ 导出失败：" + error);
                Debug.LogWarning("[BT] 导出失败：" + error);
                return;
            }

            string defaultDir = "Assets/BehaviorTrees";

            if (!Directory.Exists(defaultDir))
            {
                Directory.CreateDirectory(defaultDir);
            }

            string path = EditorUtility.SaveFilePanel("导出行为树 JSON", defaultDir, treeId + ".json", "json");

            if (string.IsNullOrEmpty(path))
            {
                SetStatus("已取消导出。");
                return;
            }

            try
            {
                File.WriteAllText(path, BTJsonUtil.Export(data));
                AssetDatabase.Refresh();
                SetStatus("✅ 已导出：" + path);
            }
            catch (Exception exception)
            {
                SetStatus("❌ 导出失败：" + exception.Message);
                Debug.LogException(exception);
            }
        }

        // 功能：从 JSON 文件导入。
        // 入参：无
        // 返回：无
        // 步骤：选文件 → 读文本 → 解析 → 载入画布 → 刷树名与属性面板
        // 上游：工具栏【导入JSON】
        // 下游：BTJsonUtil.Import、BTGraphView.ImportData
        private void OnImport()
        {
            string path = EditorUtility.OpenFilePanel("导入行为树 JSON", "Assets/BehaviorTrees", "json");

            if (string.IsNullOrEmpty(path))
            {
                SetStatus("已取消导入。");
                return;
            }

            try
            {
                string json = File.ReadAllText(path);
                BTGraphData data = BTJsonUtil.Import(json);
                m_graphView.ImportData(data);

                if (m_treeIdField != null)
                {
                    m_treeIdField.value = data.TreeId;
                }

                m_inspector.Bind(null);
                SetStatus("✅ 已导入：" + path);
            }
            catch (BtJsonException exception)
            {
                SetStatus("❌ 导入失败：" + exception.Message);
                Debug.LogWarning("[BT] 导入失败：" + exception.Message);
            }
            catch (Exception exception)
            {
                SetStatus("❌ 导入失败：" + exception.Message);
                Debug.LogException(exception);
            }
        }

        // 功能：开始预览。
        // 入参：无
        // 返回：无
        // 步骤：导出快照 → runner.Start → 失败就提示原因
        // 上游：工具栏【预览】
        // 下游：BTPreviewRunner.Start
        private void OnPreview()
        {
            // 先把面板上的值同步进黑板 —— 否则用户改过的值可能还没写进黑板（例如刚重开窗口/刚清空过）
            SyncBlackboardFromFields();

            BTGraphData data = m_graphView.ExportData(m_treeIdField != null ? m_treeIdField.value : "preview");

            if (!m_runner.Start(data, out string error))
            {
                // 根节点不唯一时，把多余的根选中并框选，用户一眼能看到它在哪
                List<string> roots = data.FindRootIds();

                if (roots.Count > 1)
                {
                    m_graphView.FocusNodes(roots);
                }

                SetStatus("❌ 无法预览：" + error);
                Debug.LogWarning("[BT] 无法预览：" + error);
                return;
            }

            m_lastTickTime = EditorApplication.timeSinceStartup;
            SetStatus("▶ 预览中（200ms 一帧）：绿=成功 红=失败 黄=运行中。改黑板数值看条件变化。");
        }

        // 功能：把黑板面板上当前显示的值写进运行时黑板（预览开始前调用）。
        // 入参：无
        // 返回：无
        // 步骤：遍历已记录的控件，按类型读值写黑板
        // 上游：OnPreview
        // 下游：BTBlackboard.Set
        // 注意：黑板是"单一事实来源"应该是面板；运行时只读，所以每次开预览都对齐一次。
        private void SyncBlackboardFromFields()
        {
            if (m_runner == null)
            {
                return;
            }

            foreach (KeyValuePair<string, VisualElement> pair in m_blackboardFields)
            {
                switch (pair.Value)
                {
                    case IntegerField intField:
                        m_runner.Blackboard.Set(pair.Key, BTParamValue.FromInt(intField.value));
                        break;

                    case FloatField floatField:
                        m_runner.Blackboard.Set(pair.Key, BTParamValue.FromFloat(floatField.value));
                        break;

                    case Toggle toggle:
                        m_runner.Blackboard.Set(pair.Key, BTParamValue.FromBool(toggle.value));
                        break;

                    case TextField textField:
                        m_runner.Blackboard.Set(pair.Key, BTParamValue.FromString(textField.value));
                        break;
                }
            }
        }
        // 功能：停止预览并清颜色。
        // 入参：无
        // 返回：无
        // 步骤：runner.Stop → 画布清状态
        // 上游：工具栏【停止预览】
        // 下游：BTGraphView.ClearStatus
        private void OnStopPreview()
        {
            m_runner.Stop();
            m_graphView.ClearStatus();
            SetStatus("已停止预览。");
        }

        // 功能：删除选中节点（根节点会被拒绝，原因打在状态栏）。
        // 入参：无
        // 返回：无
        // 步骤：调画布删除 → 刷属性面板
        // 上游：工具栏【删除节点】
        // 下游：BTGraphView.DeleteSelection
        private void OnDelete()
        {
            m_graphView.DeleteSelectedNodes();
            m_inspector.Bind(null);
            SetStatus("已删除选中节点（根节点不会被删除）。");
        }

        // 功能：复制选中节点。
        // 入参：无
        // 返回：无
        // 步骤：调画布复制 → 选中新节点 → 刷属性面板
        // 上游：工具栏【复制节点】
        // 下游：BTGraphView.DuplicateSelection
        private void OnDuplicate()
        {
            BTNodeView copy = m_graphView.DuplicateSelection();

            if (copy == null)
            {
                SetStatus("没有选中可复制的节点。");
                return;
            }

            m_graphView.ClearSelection();
            m_graphView.AddToSelection(copy);
            m_inspector.Bind(copy);
            SetStatus("已复制为 " + copy.NodeId);
        }

        // 功能：清空画布（重新开始一棵树）。
        // 入参：无
        // 返回：无
        // 步骤：停止预览 → 用空数据 ImportData → 清属性面板
        // 上游：工具栏【清空画布】
        // 下游：BTGraphView.ImportData
        private void OnClear()
        {
            OnStopPreview();
            m_graphView.ImportData(new BTGraphData { TreeId = m_treeIdField != null ? m_treeIdField.value : "new_tree" });
            m_inspector.Bind(null);
            SetStatus("画布已清空。");
        }
        // 功能：更新状态栏文字。
        // 入参：text 文案
        // 返回：无
        // 步骤：有标签就写
        // 上游：各操作
        // 下游：m_statusLabel
        private void SetStatus(string text)
        {
            if (m_statusLabel != null)
            {
                m_statusLabel.text = text;
            }
        }
    }
}
```

## 七、风险与幻觉自查

- 幻觉自查：只用 `GraphView` / `Port` / `Edge` / `Node` / `EditorWindow` / `Painter2D` / `VisualTreeAsset` / `StyleSheet`，全部 Unity 2022.3 内置 API。
- 验证过程中修掉的问题（共 8 处，详见 07）：
  1. USS 只加给 GraphView ⇒ 布局塌陷（画布高度 0）
  2. 输入端口按「根」删除 ⇒ 新节点无法连线
  3. GraphView 自带 EdgeConnector 不认目标端口 ⇒ 改为自研拖拽（TrickleDown + Painter2D 预备线）
  4. 「一输出一连」对所有节点生效 ⇒ 组合节点连第二个子节点时前一条被删
  5. `Stop()` 清空黑板 ⇒ 面板显示 100 但条件读 0
  6. GraphView 内建删除绕过回调 ⇒ 幽灵节点（看得见 1 个却报 2 个根）
  7. 导入按小数点猜类型 ⇒ Float 变 Int（改为按定义强转）
  8. 新建节点完全重叠 ⇒ 用户以为只有一个节点（改为自动避让）
- 行为边界：预览只用于策划自查，**不参与正式游戏与服务端**。
