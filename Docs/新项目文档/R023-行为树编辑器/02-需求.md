# 02 需求

需求：R023-行为树编辑器（EditorWindow + UIElements）
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-11-06）

## 一、业务目标（一句话）

策划/开发能在 Unity 编辑器里**可视化搭行为树、点预览看节点跑成什么状态、导出成服务端能直接读的 JSON**。

## 二、用户与使用场景

- 用户：开发期负责人（写怪的 AI）、以后填表的策划。
- 场景：打开 `AI工具/BehaviorTree Editor` → 从左侧拖 `Selector`/`HPBelow`/`MoveTo` 到画布 → 连线 → 填参数 → 点【预览】看三色状态 → 【导出JSON】给服务端。

## 三、功能列表（P0 / P1 / P2）

| # | 功能 | 优先级 |
| --- | --- | --- |
| 1 | 菜单入口 `AI工具/BehaviorTree Editor` | P0 |
| 2 | 左侧节点库（Selector/Sequence/Parallel、HPBelow/HasTarget、MoveTo/CastSkill/Wait）+ **注册式新增** | P0 |
| 3 | 从节点库**拖拽**到画布 | P0 |
| 4 | 节点拖拽移动 / 删除 / 复制 | P0 |
| 5 | 输入/输出端口 + 拖拽连线；**一个输出只能连一个子节点** | P0 |
| 6 | 连线可删除；**禁止自连与环** | P0 |
| 7 | 右侧属性面板：按节点定义动态生成 float/int/bool/string 字段，改值实时生效 | P0 |
| 8 | 预览：启动/停止，固定 200ms Tick，节点**三色**（Success 绿 / Failure 红 / Running 黄） | P0 |

| 11 | 导入 JSON（重建节点、连线、参数、位置） | P0 |

## 四、边界（**本版明确不做**）

- **不用于正式游戏与服务端**：预览运行时只在编辑器里跑，绝不编译进包（`NBC.Editor` 程序集 + `includePlatforms: Editor`）。
- 不引 Behavior Designer 或任何外部 BT 插件，全部自研。
- 不做多棵树管理/资产化（一次编辑一棵，靠导入导出换）。
- 不做撤销重做（Undo）的完整接入（P2；本版只做删除/复制的即时操作）。
- 不做服务端运行时（那是 R022 的范围）。

## 五、优先级

**P0**。依赖：无（全新编辑器工具）；与服务端 BT 的对接靠 JSON Schema。

## 六、验收标准（「当…时，应…」）

- [ ] 当 点菜单时，应打开窗口，看到左（节点库）/ 中（画布）/ 右（属性）三栏
- [ ] 当 从左侧拖一个节点到画布时，应在落点创建该节点
- [ ] 当 拖拽节点时，位置应跟随；删除/复制后画布与数据同步
- [ ] 当 从输出端口拖到另一个节点时，应建立父子关系；**同一输出再连第二个时**，前一条应被自动断开
- [ ] 当 试图把节点连到自己或自己的祖先时，应被拒绝并给出提示
- [ ] 当 选中节点时，右侧应显示该节点的参数并可修改，修改立即写入数据
- [ ] 当 点【预览】时，节点应按 200ms 节奏刷新三色状态；点【停止预览】应复位颜色
- [ ] 当 预览运行时，应能改黑板上的 Hp/TargetId 并看到条件节点状态随之变化
- [ ] 当 点【导出JSON】时，文件内容应与约定 Schema 完全一致（`TreeId`/`RootNodeId`/`Nodes`/`NodeType`/`Pos`/`Params`/`Children`）
- [ ] 当 导出后再【导入JSON】时，画布应完全复原（节点、连线、参数、位置）
