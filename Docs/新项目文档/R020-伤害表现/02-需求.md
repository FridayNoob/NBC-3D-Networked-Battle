# 02 需求

需求：R020-伤害与战斗反馈
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-11-05）

## 一、业务目标（一句话）

**打人和被打都有明确反馈**：怪物头顶有血条、伤害数字飘出来（按大小变色）、被打的播受击、死了播死亡；
本地玩家血条显示**服务端真实血量**。

## 二、用户与使用场景

- 用户：开发期负责人；最终玩家。
- 场景：砍狼 → 狼头飘红字、头顶血条下降、狼抖一下 → 打死后狼倒地消失；被 BOSS 打 → 自己血条掉、角色播受击。

## 三、功能列表（P0 / P1 / P2）

| # | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 1 | 怪物头顶血条 | P0 | 比例显示，掉血跟随，死亡消失 |
| 2 | 伤害数字飘字 | P0 | 快照 HP 差值，world-space TMP，1.2 秒上浮淡出 |
| 3 | 飘字样式 | P0 | 按伤害大小变色 + 变大；同屏多条随机小偏移防重叠 |
| 4 | 怪物受击动画 | P0 | `Take Damage`（参数缺失只飘字） |
| 5 | 怪物死亡动画 | P0 | `Alive` 转 false ⇒ `Die`，先播再消失 |
| 6 | **玩家侧飘字 + 受击** | P0 | 玩家被打也飘字，播 `HIT L`/`HIT R` |
| 7 | **本地血条接真实血量** | P0 | HUD 读服务端快照的血量，废掉演示假的扣血键 |
| 8 | 治疗/护盾数字 | P2 | 不做 |
| 9 | 连击数、伤害类型区分 | P2 | 不做 |

## 四、边界（**本版明确不做**）

- 不改服务端与协议（全部由 HP 差值 + `Alive` 推出来）。
- 不做战斗日志面板、不做伤害统计表。
- 不做对象池（同屏个位数，Instantiate + Destroy 够用）。
- 不做暴击（服务端没有暴击数据，凭空放大数字等于骗人）。

## 五、优先级

**P0**。依赖：R019（能打中）、R015/R017（怪物槽位与动画）、R003（HUD 血条）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 砍中狼时，狼头顶应飘「-N」（N 等于服务端扣的血），且狼头顶血条同步下降
- [ ] 当 伤害较大时，数字应更大更红；伤害小时数字小且偏黄/白
- [ ] 当 连续命中时，多条数字应各自上浮淡出，不完全重叠
- [ ] 当 狼掉血时，应播受击动画；被打死时应先播死亡再消失
- [ ] 当 新怪出现时，**不应**凭空飘满血数字；血条应从满血开始
- [ ] 当 玩家被打时，应飘字并播 `HIT L`/`HIT R`
- [ ] 当 玩家血量变化时，左下角血条 HUD 应显示服务端真实血量（不再是假数据）
- [ ] 当 怪物 controller 缺受击/死亡参数时，应只飘字、不报错
