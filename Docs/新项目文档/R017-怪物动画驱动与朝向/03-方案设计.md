# 03 方案设计

需求：R017-怪物动画驱动与朝向
所属阶段：M4
作者：AI 起草　状态：已确认（2026-11-05）

## 一、整体架构

只改表现层的槽位驱动，数据链路不变：

```
快照（含 FacingDeg）→ PresentationFeed → SnapshotSceneBinder.LateUpdate
                                              ├─ 算「到目标的水平距离」→ SetBool("Walk", 距离 > 阈值)
                                              ├─ 写 localRotation（FacingDeg + 偏移）
                                              └─ MoveSlotTo（位置，R006/R015 不变）
```

## 二、模块划分

| 模块 | 本次改动 | 不负责什么 |
| --- | --- | --- |
| `SnapshotSceneBinder`（改） | 驱动 `Walk` Bool、写朝向；新增两个 Inspector 参数；创建槽位时强制关 Root Motion | 不改位置推进、不改物理、不改相机 |
| `Slot`（同文件私有类） | 缓存 `Animator` 与「有没有 Walk 参数」 | — |
| 怪物 prefab / controller | **零改动**（参数现成） | — |

## 三、接口（★ 先定死）

```
SnapshotSceneBinder 新增序列化字段：
    m_facingOffsetDegrees      = 0f     朝向偏移（度）；模型前向不是 +Z 时用它纠正
    m_moveAnimationThreshold   = 0.05f  判定「在移动」的水平距离阈值（米）

常量：
    WalkParameter = "Walk"              controller 里的 Bool 参数名
    动画参数缺失只告警一次（记一个 bool 标记）

Slot 新增：
    Animator Animator                  子物体上的 Animator（可为空）
    bool HasWalkParameter              该 controller 是否有 Walk(Bool)
    bool WarnedMissingWalk             已经告警过（避免刷屏）

时序（每个实体每帧）：
    1) 水平距离 = |目标 - 当前|（X/Z）
    2) moving = 距离 > m_moveAnimationThreshold
    3) 有 Animator 且 HasWalkParameter ⇒ SetBool(Walk, moving)
    4) localRotation = Euler(0, FacingDeg + m_facingOffsetDegrees, 0)
    5) MoveSlotTo(...)
```

## 四、数据结构

- `Slot` 多两个引用/布尔 + 一个告警标记；每帧无新增分配。
- `WalkHash` 只在创建槽位时算一次。

## 五、时序与流程

1. 创建槽位：取 `GetComponentInChildren<Animator>(true)`；**强制 `applyRootMotion = false`**（否则「With Root Motion」那套状态会把模型再推一次）。
2. 检查参数：`Animator.parameters` 里找名字 `Walk` 且类型 `Bool`。
3. 每帧：按距离判定 → `SetBool`；按 `FacingDeg` 写旋转。
4. 参数缺失：只警告一次，之后静默（不影响位置/朝向）。

## 六、技术选型与理由

| 选择 | 选定 | 理由 | 被否的方案 |
| --- | --- | --- | --- |
| 驱动方式 | binder 内直接 `SetBool` | 改动集中、无新组件；狼 controller 只需一个 Bool | 每槽位一个驱动组件（现在没必要） |
| 移动判据 | 到目标的水平距离 | 稳定，不受刚体速度噪声影响 | 用 `Body.velocity` 大小（停下瞬间会抖） |
| 朝向来源 | 快照 `FacingDeg` | 服务端权威，与位置同源 | 用位移方向算朝向（倒退/原地时不稳） |
| 朝向偏移 | Inspector 字段 | 模型前向未知，要能不改代码纠正 | 写死 +Z（错了只能改代码） |

## 七、风险与对策

- **Root Motion 没关 ⇒ 模型自己跑**：创建槽位时强制 `false`，不依赖 prefab 配置。
- **朝向反了 180°**：把 `m_facingOffsetDegrees` 调 180 即可（不改代码）。
- **朝向每 33ms 跳一次**：已知取舍（30Hz 快照），要平滑得另外插值旋转（P2）。
- **参数名不同**：先检查再设，缺了只警告一次。
- **Animator 在子物体上**：用 `GetComponentInChildren(true)`，与 `PlayerAnimation` 的做法一致。
- **刚体冻结旋转**：`freezeRotation = true` 时写 transform 旋转安全（物理不改旋转）。
