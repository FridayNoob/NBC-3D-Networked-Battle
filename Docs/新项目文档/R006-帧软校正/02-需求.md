# 02 需求

需求：R006-帧软校正（快照插值）
所属阶段：M4
作者：LYF（口述确认，AI 落稿）　状态：已确认（2026-10-31）

## 一、业务目标（一句话）

**怪和其他玩家的移动从「每 33ms 跳一格」变成连续移动**，观感与本地玩家一致。

## 二、用户与使用场景

- 用户：开发期负责人；最终玩家。
- 场景：进房后看怪物走动 —— 现在是「一跳一跳」，改完应平滑；换局/复活时角色应**瞬间出现在新位置**，不能滑过去。

## 三、功能列表（P0 / P1 / P2）

| 功能 | 优先级 | 说明 |
| --- | --- | --- |
| 远端实体位置平滑 | P0 | 30Hz 快照 → 60fps 连续移动 |
| 瞬移兜底 | P0 | 距离超阈值直接归位（换局/复活/传送） |
| 速度钳位 | P0 | 单帧不超过 60 米/秒，防止飞出画面 |
| 参数可在 Inspector 调 | P1 | 快照间隔秒、瞬移阈值米 |
| 本地玩家也平滑 | P2 | **不做**（本地由 `PlayerMove` 直接驱动，本来连续） |

## 四、边界（**本版明确不做**）

- 不改服务端、不改协议、不改快照率（30Hz 是设计定的）。
- 不改锁步链路（它本来就是固定 tick 连续步进）。
- **不加渲染延迟**（不做「缓存两条快照 + 播 33ms 之前」）。
- 不做旋转/朝向插值（当前表现层不写朝向）。
- 不做外推（预测未来位置）。

## 五、优先级

**P0**。依赖：R008（运行时会话与表现层）。

## 六、验收标准（「当…时，应…」）

- [ ] 当 怪物以常速移动时，位置应**连续变化**（不再是每 33ms 一跳）
- [ ] 当 换局 / 复活 / 传送时，角色应**瞬间归位**，不能以最大速度横穿地图
- [ ] 当 快照突然落后（卡顿）再恢复时，不应出现「飞出去再飞回来」的抖动
- [ ] 当 本地玩家走动时，手感应**与改动前完全一致**（本地移动没被动过）
- [ ] 当 打开 Inspector 时，`SnapshotSceneBinder` 上应能看到两个可调参数（快照间隔 / 瞬移阈值）
