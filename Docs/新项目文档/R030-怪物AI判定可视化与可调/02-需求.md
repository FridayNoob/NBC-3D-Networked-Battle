# 02 需求

需求：R030-怪物 AI 判定可视化与可调
所属阶段：M4
作者：AI 起草／LYF 确认　状态：待确认（2026-11-12）

## 一、业务目标（一句话）

**在客户端就能"看见并调"怪的三条判定线**（攻击红 / 玩家检测白 / 接地蓝），调完写回 `Monster.csv`，服务端照着这份真值判定。

## 二、用户与场景

- 用户：负责人（调 AI 手感）、面试官（一眼看到"攻击范围就在这"）。
- 场景：选中怪物预制体 → Scene 视图看到三个圈/线 → 拖长/拖短 → 运行进副本 → Game 视图里红圈跟着狼走 → 满意了点「写回」→ 重生成 → 服务端判定同步。

## 三、功能列表

| # | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 1 | 三个子 Transform（`Attack`/`Aggro`/`Ground`） | P0 | 分别代表三种判定的中心；缺失时自动创建 |
| 2 | 编辑期 Gizmos | P0 | 攻击**红圈**、检测**白圈**、接地**蓝竖线** |
| 3 | 运行期 LineRenderer | P0 | Game 视图里也能看到红圈/白圈/蓝线 |
| 4 | Inspector 可调三个长度 | P0 | 攻击 / 检测 / 接地（单位毫米） |
| 5 | 默认值来自 `MonsterConfig` | P0 | 与服务端**同源**（`attackRangeMm`/`aggroRangeMm`/`groundLineMm`） |
| 6 | 覆盖未写回时红字提示 | P0 | 「显示值 ≠ 服务端值」 |
| 7 | 「写回 Monster.csv」按钮 | P0 | 按怪型写回三列，提示重生成 + 重启 |
| 8 | 非法值拦截 | P0 | 0 或负数拒绝写回并提示 |
| 9 | 运行期 0 分配 | P1 | LineRenderer 顶点/位置数组复用 |

## 四、边界（本版明确不做）

- 不改服务端判定逻辑（仍读 `attackRangeMm`/`aggroRangeMm`）。
- **不做**"选怪型"UI：组件上一个 `MonsterConfigId` 字段决定写回哪一行。
- **不做热更**：写回后必须重生成 + 重启服务端才生效（M5 再说）。
- 不做扇形/胶囊等其它形状（只画圆 + 竖线）。
- 不做多语言/美术化（颜色就是红/白/蓝）。

## 五、优先级

**P0**。依赖：`Monster.csv` 已有 4 个 AI 列（R022-2）；需新增 `groundLineMm` 列。

## 六、验收标准（「当…时，应…」）

- [ ] 当 选中怪物预制体时，Scene 视图应出现以 `Attack`/`Aggro`/`Ground` 为中心的**红圈 / 白圈 / 蓝竖线**
- [ ] 当 进入 Play 时，Game 视图应能看到同样的红圈、白圈、蓝线（**不是只在 Scene 视图**）
- [ ] 当 在 Inspector 把攻击长度从 2000 改成 3000 时，红圈应立刻变大（编辑期与运行期都变）
- [ ] 当 覆盖值未写回时，Inspector 顶部应显示红字「显示值 ≠ 服务端值」
- [ ] 当 点「写回 Monster.csv」后，该怪型的三列应被更新，并提示「请重生成 + 重启服务端」
- [ ] 当 重生成 + 重启后，未覆盖的显示值应等于 `MonsterConfig` 的表值（与服务端同源）
- [ ] 当 拖动 `Attack` 子物体时，红圈圆心应跟着移动（不写死模型原点）
- [ ] 当 三个子物体不存在时，组件应自动创建并命名为 `Attack`/`Aggro`/`Ground`
- [ ] 当 填 0 或负数时，写回应被拒绝并提示原因
- [ ] 当 连续运行 60 秒时，不应因绘制产生每帧堆分配（位置数组复用）
