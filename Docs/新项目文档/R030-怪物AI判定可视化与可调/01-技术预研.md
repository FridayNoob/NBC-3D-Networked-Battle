# 01 技术预研

需求：R030-怪物 AI 判定可视化与可调
所属阶段：M4
作者：AI　状态：待确认（2026-11-12）

## 一、调研目标与约束

- 目标：编辑期用 **Gizmos**、运行期用 **LineRenderer** 显示怪的三条判定线（**攻击=红、玩家检测=白、接地=蓝**）；
  长度与位置可在 Inspector 调；调的**攻击/检测**值可写回 `Monster.csv` 成为真值。
- 约束：
  1. 不引入新依赖（LineRenderer + Gizmos 都是内置）；
  2. **不出现两把尺子**：显示的圈默认读服务端同一份真值（`Monster.csv` → 生成配置），只有"显式覆盖且未写回"时才不同，且要给提示；
  3. **按 AGENTS.md §0.4**：三条判定（攻击 / 玩家检测 / 接地）**全部进 `Monster.csv`**，客户端可视化调完写回；
     接地服务端不参与判定，但**一样入表留档**（一份真值，避免"只活在预制体里"）；
  4. 不改服务端判定逻辑（真值仍在 `Monster.csv` 的 `attackRangeMm` / `aggroRangeMm`）；
  5. 代码量预估 **≈470 行**（见 §七）。

## 三、方案

```
怪物预制体
 ├─ MonsterAiDebugView（新组件）
 │    ├─ Attack（子 Transform）：攻击判定的中心与朝向
 │    ├─ Aggro （子 Transform）：玩家检测的中心
 │    └─ Ground（子 Transform）：接地点
 ├─ Gizmos（编辑期）：红圈 / 白圈 / 蓝色接地竖线
 └─ LineRenderer（运行期）：红圈 + 白圈（挂在运行时创建的子物体上）

MonsterAiDebugViewEditor（新）
 └─ 按钮「写回 Monster.csv」：把攻击/检测长度写回该怪型的两列
```

**子 Transform 名字固定为 `Attack` / `Aggro` / `Ground`**（负责人 2026-11-12 确认）；缺失时组件在 `Awake` 自动创建，位置可自行拖。

**真值优先级**：

1. 未覆盖 ⇒ 运行期显示值 = `MonsterConfig.Get(ConfigId)` 的表值（**与服务端同源**）；
2. Inspector 覆盖了但**没写回** ⇒ 显示覆盖值，同时在 Inspector 顶部红字提示「显示值 ≠ 服务端值」；
3. 点了「写回」⇒ 改 `Monster.csv` 两列 → 需重生成配置 + 重启服务端才生效。

**接地**：`Monster.csv` 新增一列 `groundLineMm`（毫米），客户端读它画蓝色竖线；服务端不读该列（保持权威判定不受影响）。
写回按钮一次写回 **三列**（attackRangeMm / aggroRangeMm / groundLineMm）。

## 四、关键技术判断

| 判断 | 理由 |
| --- | --- |
| 运行期用 LineRenderer、编辑期用 Gizmos | Gizmos 只在 Scene 视图可见，Game 视图看不到；你要"运行能看到红圈" |
| 三个子 Transform 由脚本自动创建 | 少一步手工；也便于按需移动判定中心 |
| 显示值默认读生成配置 | 避免"显示 3 米、实际 2 米"的另一把尺子 |
| 写回走 CSV 而不是新建配置 | 真值只有一份（`Monster.csv`），生成物不手改 |
| 不把长度写进预制体序列化值当真相 | 预制体是表现，表才是规则 |

## 五、已知坑

1. **两把尺子**：如果 Inspector 的覆盖值悄悄生效而服务端不变，就是上次那个 bug 的翻版 → 必须显式提示。
2. **写回后不重生成**：CSV 改了但 `Config_Monster.cs` 没重生成 → 客户端显示还是旧值 → 要在写回成功后提示"请重生成 + 重启服务端"。
3. **LineRenderer 粉线**：必须给材质（`Sprites/Default`），否则默认材质缺失显示粉色。
4. **Y 轴位置**：怪模型轴心不在脚底，接地线的起点要挂在 `Ground` 上，别写死 0。
5. **实例绑定时机**：`Bind(ConfigId)` 必须在 `EnsureSlot` 实例化后立刻调用，否则第一帧显示的是默认值。

## 六、结论与改动清单

- 新增：`Game/View/MonsterAiDebugView.cs`（Gizmos + LineRenderer + 参数覆盖）
- 新增：`Editor/MonsterAiDebugViewEditor.cs`（Inspector 按钮：写回 CSV）
- 新增：`Editor/MonsterAiCsvWriter.cs`（按 monsterId 改 CSV 三列，含 CSV 逗号安全处理）
- 修改：`SnapshotSceneBinder.EnsureSlot`（实例化后 `Bind(e.ConfigId)`，约 10 行）
- 数据：`Configs/Design/Monster.csv` 新增 `groundLineMm` 列 + 重生成（客户端 `Config_Monster` 多一个字段）
- 不改：服务端判定、`Monster.csv` 的列结构（只改数值）
