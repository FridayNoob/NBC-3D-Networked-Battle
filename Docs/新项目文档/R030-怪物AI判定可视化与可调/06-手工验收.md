# 06 手工验收

需求：R030-怪物 AI 判定可视化与可调
所属阶段：M4
作者：AI（计划）／LYF（实测）　状态：待确认（2026-11-12）

## 一、测试计划

- 目标：确认"看得见 + 调得动 + 写回生效"三件事。
- 前置：Unity 已打开该工程（桥接可用）。
- 判据：下面 6 条逐条对照。

## 二、操作步骤

1. **编辑期看圈**：Project 里选中 `Assets/Prefabs/Forest Wolf - Grey.prefab` → Scene 视图
   - 期望：红圈（半径 2 米）、白圈（4 米）、蓝色竖线（向下 300mm），圆心在 `Attack`/`Aggro`/`Ground` 三个子物体上。
2. **调长度**：Inspector 把 `Attack Range Mm Override` 填 **3000**
   - 期望：红圈立刻变大；顶部出现红字「显示值 ≠ 服务端值」。
3. **拖锚点**：把 `Attack` 子物体往前拖 1 米
   - 期望：红圈圆心跟着前移（不是固定在模型原点）。
4. **运行期看圈**：进 Play，登录进副本 → Game 视图
   - 期望：狼身上能看到红圈 + 白圈 + 蓝线（不是只在 Scene 视图），且跟着狼移动。
5. **写回**：点 Inspector 的「写回 Monster.csv（攻击 / 检测 / 接地）」
   - 期望：弹窗提示已写回 + 给出重生成命令；点完覆盖值被清空。
   - 检查 `Configs\Design\Monster.csv` 里 6001 行的 `attackRangeMm` 是否变成 **3000**。
6. **端到端生效**：
   - 跑重生成命令：`Tools\ConfigKit\src\ConfigKit.Cli\bin\Debug\net8.0\NBC.ConfigKit.Cli.exe --source Configs\Design --out Client\Assets\_Project\Game\Config\Generated`
   - Unity 里跑一次「Tools/NBC/配置表/导入 TSV → ScriptableObject」
   - 重启服务端 → 再进副本
   - 期望：未覆盖时红圈 = 3 米，且**狼在 3 米内就能打到你**（服务端判定同步变了）。
   - 验完把 CSV 里 6001 的 `attackRangeMm` 改回 **2000** 并重生成（恢复原状）。
