# 04 代码实现：Dungeon 表的 SO ↔ CSV 双向

## 一、子任务与约束
| 子任务 | 落点 | 约束 |
| --- | --- | --- |
| 把 SO 写成 CSV | `Editor/Config/DungeonCsvBridge.cs` | 只重写数据行，前 4 行表头原样保留 |
| 把 CSV 读回 SO | 同上 | 先解析到临时列表，校验通过才覆盖 |
| 读表头做列说明 | 同上（`ReadColumns`） | 中文名/类型/规则全部来自 CSV，不在代码里写死 |
| 导出后重生成 | 同上 | 调用 `NBC.ConfigKit.Cli.exe`，失败回滚 CSV |
| 表格化编辑 | `Editor/Config/DungeonConfigWindow.cs` | 中文表头 + 行内编辑，只调桥 |
| 自动化 | `Tests/EditMode/Config/DungeonCsvBridgeTests.cs` | 只测纯函数 |

三条硬约束：
1. 服务端只读 CSV（`Server/NBC.Server.Game/ServerTables.cs`），所以导出后必须重生成；只改 SO 不会影响服务端。
2. 中文与引号必须按 CSV 规则转义，数字一律 `CultureInfo.InvariantCulture`。
3. 写盘失败要能回滚：备份 `.bak` → 临时文件 → 替换 → 生成失败就还原，成功后删掉 `.bak`。

## 二、功能概述
菜单 `Tools/NBC/配置表/副本表（SO ↔ CSV）` 打开一个表格窗口：
表头是 CSV 第二行的中文名（`编号`、`名称`、`最大人数`、`出生点半径（毫米）`、`普通怪（写重复＝刷多只）`、`BOSS`），鼠标悬停能看到字段名、类型和取值范围；
每行可以直接改 id、名字、人数、半径、怪物编号、BOSS，可以增删行；
顶部红字提示「SO 有未导出改动」，按钮有「刷新 / 校验 / 导出到 CSV / 从 CSV 导入」；
点导出会写 CSV 并立刻跑 ConfigKit 重新生成，失败自动回滚。

## 三、接口与入参出参
| 方法 | 入参 | 返回 | 约定 |
| --- | --- | --- | --- |
| `ResolveCsvPath()` | 无 | 绝对路径或 null | 从 `Application.dataPath` 上溯最多 8 层 |
| `ReadColumns(out error)` | 错误原因 | `List<CsvColumn>` | 读前 4 行表头，列名/中文名/类型/规则逐列配对 |
| `BuildCsvText(asset, headerBlock)` | 资产、磁盘表头原文 | 整份 CSV 文本 | 结尾带 `\n` |
| `IsDirty(asset, out detail)` | 资产、差异说明 | 是否有未导出改动 | 两侧都走 `BuildCsvText` 再逐字比 |
| `Validate(asset, errors)` | 资产、错误列表 | 是否全部通过 | 6 条规则，错误带行号 |
| `Export(asset, out message)` | 资产、结果文案 | 是否成功 | 失败时磁盘保持原样 |
| `Import(asset, out message)` | 资产、结果文案 | 是否成功 | 校验失败时资产保持原样 |
| `RunConfigKit(out message)` | 结果文案 | 退出码是否为 0 | 120 秒超时 |
| `SplitLine(line)` | 一行文本 | 单元格数组 | 引号内 `""` 表示一个字面引号 |

## 四、逐段讲解
1. `ResolveCsvPath` 不写死绝对路径：仓库根在 `Assets` 的上一级，逐级上溯找 `Configs/Design/Dungeon.csv`，换机器也能用。
2. `ReadColumns` 是「表头即文档」：中文名、类型、取值范围都从 CSV 前 4 行读，CSV 改了窗口跟着变，不会出现代码与表不一致。
3. `BuildCsvText` 先放表头再放数据：表头是 ConfigKit 的输入契约，绝不能由 C# 重新拼。
4. `FormatMonsters` 对多只怪加引号：`"6001,6001,6001"` 是一个单元格，不加引号会被拆成三列。
5. `IsDirty` 用「重拼后逐字比较」：改回来又改回去也算干净，不会误报。
6. `Validate` 的引用检查读 `MonsterConfig`：编号不存在时服务端启动会失败，所以在客户端先挡。
7. `Export` 的顺序是「备份 → 写临时 → 替换 → 跑工具 → 失败回滚 → 成功删备份」：任何一步失败磁盘都还是旧内容。
8. `Import` 先把行解析到临时列表、校验通过才 `rows.Clear()`：解析到一半失败不会清空资产。
9. 窗口用「怪物输入缓冲」`m_monsterDrafts`：不缓冲的话每帧从 `row.monsters` 重新取文本，用户打到一半的逗号会被吞掉。
10. 窗口每秒查一次「资产是否被重新导入」，发现对象换了就自动 Reload：否则会对着一个已经不在磁盘上的旧对象编辑，导出时才发现改动丢了。

## 五、完整代码
```csharp
// 这个文件里有：
//   DungeonCsvBridge（静态类）：DungeonConfig.asset 与 Configs/Design/Dungeon.csv 的双向桥，含拼文本、解析、校验、写盘、调 ConfigKit
//   CsvColumn（数据类）：CSV 一列的元数据，字段名、中文名、类型、规则，供窗口画表头用

using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.Globalization;
using System.IO;
using System.Text;
using NBC.Game.Config;
using UnityEditor;
using UnityEngine;
using Debug = UnityEngine.Debug;

namespace NBC.EditorTools
{
    // 主要功能：CSV 一列的说明，用来在窗口里显示中文表头与填写规则。
    // 主要数据成员：Name 是字段名（对应 C# 字段）、Label 是中文名（带单位）、Type 是类型、Rule 是取值范围。
    // 主要外部方法：无，纯数据。
    // 谁在用它：DungeonConfigWindow 画表头；DungeonCsvBridge.ReadColumns 负责造。
    public sealed class CsvColumn
    {
        // 字段名，和 CSV 第一行、C# 字段一致
        public string Name;

        // 中文名，带单位，例如「出生点半径（毫米）」
        public string Label;

        // 类型，例如 int、ref:Monster[]
        public string Type;

        // 规则，例如 range(2,4)，空表示没写
        public string Rule;
    }

    // 主要功能：把 Dungeon 配置资产的行导出成 CSV，或把 CSV 读回来覆盖资产，并在导出前后做校验与重新生成。
    // 主要数据成员：CsvRelativePath（仓库根下的 CSV）、ConfigToolRelativePath（ConfigKit 可执行文件）、表头 4 行常量。
    // 主要外部方法：ResolveCsvPath、BuildCsvText、IsDirty、Validate、Export、Import、RunConfigKit、SplitLine、ReadColumns。
    // 谁在用它：DungeonConfigWindow 的按钮与 DungeonCsvBridgeTests。
    public static class DungeonCsvBridge
    {
        // CSV 源相对仓库根的路径，唯一真值
        public const string CsvRelativePath = "Configs/Design/Dungeon.csv";

        // ConfigKit 可执行文件相对仓库根
        private const string ConfigToolRelativePath = "Tools/ConfigKit/src/ConfigKit.Cli/bin/Debug/net8.0/NBC.ConfigKit.Cli.exe";

        // 源表目录与生成目录，均相对仓库根，和 ConfigKit 默认值一致
        private const string SourceRelativePath = "Configs/Design";

        // 生成目录，供 ConfigKit --out 使用
        private const string GeneratedRelativePath = "Client/Assets/_Project/Game/Config/Generated";

        // 表头行数：字段名、中文名、类型、规则
        private const int HeaderLineCount = 4;

        // 功能：从 Assets 目录上溯找到仓库根下的 Dungeon.csv。
        // 入参：无。
        // 返回含义：绝对路径，找不到返回 null。
        // 步骤：以 dataPath 的上一级为起点逐级上溯最多 8 层。
        // 上游/下游：Export、Import、IsDirty 调用。
        public static string ResolveCsvPath()
        {
            string current = Path.GetDirectoryName(Application.dataPath);

            for (int i = 0; i < 8 && !string.IsNullOrEmpty(current); i++)
            {
                string candidate = Path.Combine(current, CsvRelativePath.Replace('/', Path.DirectorySeparatorChar));

                if (File.Exists(candidate))
                {
                    return candidate;
                }

                current = Path.GetDirectoryName(current);
            }

            return null;
        }

        // 功能：把资产的行拼成整份 CSV，表头原样用调用方给的 4 行。
        // 入参：asset 是配置资产；headerBlock 是磁盘表头原文。
        // 返回含义：整份文本，\n 换行、结尾带换行。
        // 步骤：先放表头，再按列顺序逐行写；名字含逗号/引号/换行时加引号，怪物多只时加引号。
        // 上游/下游：Export 与 IsDirty 调用；内部用 AppendField、FormatMonsters。
        public static string BuildCsvText(DungeonConfig asset, string headerBlock)
        {
            StringBuilder builder = new StringBuilder();
            builder.Append(headerBlock.Replace("\r\n", "\n").TrimEnd('\n')).Append('\n');

            if (asset != null && asset.rows != null)
            {
                for (int i = 0; i < asset.rows.Count; i++)
                {
                    Config_Dungeon row = asset.rows[i];

                    if (row == null)
                    {
                        continue;
                    }

                    AppendField(builder, row.id.ToString(CultureInfo.InvariantCulture), false);
                    builder.Append(',');
                    AppendField(builder, row.name ?? string.Empty, true);
                    builder.Append(',');
                    AppendField(builder, row.maxPlayers.ToString(CultureInfo.InvariantCulture), false);
                    builder.Append(',');
                    AppendField(builder, row.spawnRadiusMm.ToString(CultureInfo.InvariantCulture), false);
                    builder.Append(',');
                    builder.Append(FormatMonsters(row.monsters)).Append(',');
                    AppendField(builder, row.bossId.ToString(CultureInfo.InvariantCulture), false);
                    builder.Append('\n');
                }
            }

            return builder.ToString();
        }

        // CSV 可能是 Excel 另存的 GBK，也可能带 UTF-8 / UTF-16 的 BOM，统一在这里探测
        private static readonly Encoding GbkEncoding = Encoding.GetEncoding(936);

        // 读到的编码名字，写进提示里让用户知道文件被谁改过
        private const string NoteUtf8 = "UTF-8";
        private const string NoteGbk = "GBK";

        // 功能：按 BOM 与字节合法性识别编码，把 CSV 读成文本。
        // 入参：path CSV 绝对路径；encodingNote 输出识别到的编码名。
        // 返回含义：去掉 BOM 的文本；文件不存在会由 File.ReadAllBytes 抛异常。
        // 步骤：先看 BOM（UTF-8 / UTF-16LE / UTF-16BE），没有 BOM 就按严格 UTF-8 试解码，失败当 GBK。
        // 上游/下游：IsDirty、Export、Import、ReadColumns 调用。
        public static string ReadCsvText(string path, out string encodingNote)
        {
            byte[] bytes = File.ReadAllBytes(path);
            encodingNote = NoteUtf8;
            string raw;

            if (bytes.Length >= 3 && bytes[0] == 0xEF && bytes[1] == 0xBB && bytes[2] == 0xBF)
            {
                raw = Encoding.UTF8.GetString(bytes, 3, bytes.Length - 3);
            }
            else if (bytes.Length >= 2 && bytes[0] == 0xFF && bytes[1] == 0xFE)
            {
                encodingNote = "UTF-16LE";
                raw = Encoding.Unicode.GetString(bytes, 2, bytes.Length - 2);
            }
            else if (bytes.Length >= 2 && bytes[0] == 0xFE && bytes[1] == 0xFF)
            {
                encodingNote = "UTF-16BE";
                raw = Encoding.BigEndianUnicode.GetString(bytes, 2, bytes.Length - 2);
            }
            else
            {
                try
                {
                    raw = new UTF8Encoding(false, true).GetString(bytes);
                }
                catch (DecoderFallbackException)
                {
                    encodingNote = NoteGbk;
                    raw = GbkEncoding.GetString(bytes);
                }
            }

            // 双保险：某些编辑器会写两个 BOM，或 BOM 被当成普通字符留在文本里，这里统一去掉
            return raw.Length > 0 ? raw.TrimStart('\uFEFF') : raw;
        }

        // 功能：判断资产与磁盘是否一致。
        // 入参：asset 配置资产；detail 输出差异说明。
        // 返回含义：true 表示有未导出改动或文件读不到。
        // 步骤：读磁盘 → 取前 4 行表头 → 重拼 → 逐字比较。
        // 上游/下游：窗口 OnGUI 调用；内部用 BuildCsvText。
        public static bool IsDirty(DungeonConfig asset, out string detail)
        {
            detail = string.Empty;

            if (asset == null)
            {
                detail = "没有加载到 DungeonConfig 资产";
                return false;
            }

            string path = ResolveCsvPath();

            if (path == null)
            {
                detail = "找不到 " + CsvRelativePath;
                return true;
            }

            string disk = Normalize(ReadCsvText(path, out _));

            if (!string.Equals(disk, BuildCsvText(asset, TakeHeaderBlock(disk)), StringComparison.Ordinal))
            {
                detail = "SO 有未导出改动：磁盘 " + (CountDataLines(disk)) + " 行，SO " + asset.rows.Count + " 行";
                return true;
            }

            return false;
        }

        // 功能：校验每一行，把问题按行号收进 errors。
        // 入参：asset 配置资产；errors 收集列表。
        // 返回含义：true 表示全部通过。
        // 步骤：查主键/名字/人数/半径/怪物引用/BOSS 引用，引用用 MonsterConfig 的主键集合。
        // 上游/下游：Export、Import、窗口调用；内部用 LoadMonsterIds。
        public static bool Validate(DungeonConfig asset, List<string> errors)
        {
            if (errors == null)
            {
                return false;
            }

            if (asset == null)
            {
                errors.Add("没有加载到 DungeonConfig 资产");
                return false;
            }

            HashSet<int> monsterIds = LoadMonsterIds();

            if (monsterIds == null)
            {
                errors.Add("读不到 MonsterConfig 资产，无法检查怪物引用");
                return false;
            }

            HashSet<int> seen = new HashSet<int>();

            for (int i = 0; i < asset.rows.Count; i++)
            {
                Config_Dungeon row = asset.rows[i];

                if (row == null)
                {
                    errors.Add("第 " + (i + 1) + " 行是空的");
                    continue;
                }

                string prefix = "第 " + (i + 1) + " 行（id=" + row.id + "）：";

                if (row.id <= 0)
                {
                    errors.Add(prefix + "主键必须大于 0");
                }
                else if (!seen.Add(row.id))
                {
                    errors.Add(prefix + "主键与前面重复");
                }

                if (string.IsNullOrWhiteSpace(row.name))
                {
                    errors.Add(prefix + "名称不能为空");
                }
                else if (row.name.Length > 16)
                {
                    errors.Add(prefix + "名称最多 16 个字");
                }

                if (row.maxPlayers < 2 || row.maxPlayers > 4)
                {
                    errors.Add(prefix + "最大人数只能是 2~4");
                }

                if (row.spawnRadiusMm < 500 || row.spawnRadiusMm > 20000)
                {
                    errors.Add(prefix + "出生半径只能是 500~20000 毫米");
                }

                if (row.monsters == null || row.monsters.Length == 0)
                {
                    errors.Add(prefix + "至少要填一只普通怪");
                }
                else
                {
                    for (int m = 0; m < row.monsters.Length; m++)
                    {
                        if (!monsterIds.Contains(row.monsters[m]))
                        {
                            // 4 位编号被 Excel 拆成 600,160,016,001 时，会得到 600/160/16/1 这种小于 1000 的数
                            string hint = row.monsters[m] < 1000
                                ? "（编号不足 4 位，像是 Excel 给 6001,6001 自动加了千位分隔符；请把这一格设成「文本」再填）"
                                : string.Empty;

                            errors.Add(prefix + "怪物 " + row.monsters[m] + " 不在 Monster 表里" + hint);
                        }
                    }
                }

                if (row.bossId != 0 && !monsterIds.Contains(row.bossId))
                {
                    errors.Add(prefix + "BOSS " + row.bossId + " 不在 Monster 表里");
                }
            }

            return errors.Count == 0;
        }

        // 功能：导出 CSV 并让 ConfigKit 重新生成，失败时回滚磁盘。
        // 入参：asset 配置资产；message 输出结果。
        // 返回含义：true 表示导出与生成都成功。
        // 步骤：校验 → 读表头 → 拼文本 → 备份 .bak → 临时文件替换 → 跑 ConfigKit（失败回滚）→ 保存资产。
        // 上游/下游：窗口导出按钮调用；内部用 Validate、BuildCsvText、RunConfigKit。
        public static bool Export(DungeonConfig asset, out string message)
        {
            List<string> errors = new List<string>();

            if (!Validate(asset, errors))
            {
                message = "校验没通过，磁盘没有改动：\n" + string.Join("\n", errors);
                return false;
            }

            string path = ResolveCsvPath();

            if (path == null)
            {
                message = "找不到 " + CsvRelativePath;
                return false;
            }

            string disk = Normalize(ReadCsvText(path, out string sourceEncoding));
            string text = BuildCsvText(asset, TakeHeaderBlock(disk));
            string backup = path + ".bak";

            File.Copy(path, backup, true);

            // 统一写成 UTF-8 带 BOM：Excel 打开不乱码，ConfigKit 也能识别
            File.WriteAllText(path + ".tmp", text, new UTF8Encoding(true));
            File.Copy(path + ".tmp", path, true);
            File.Delete(path + ".tmp");

            if (!RunConfigKit(out string toolMessage))
            {
                File.Copy(backup, path, true);
                message = "导出已回滚（ConfigKit 没跑成功）：\n" + toolMessage;
                return false;
            }

            File.Delete(backup);
            EditorUtility.SetDirty(asset);
            AssetDatabase.SaveAssets();
            message = "已导出 " + asset.rows.Count + " 行到 " + CsvRelativePath + "（原文件编码 " + sourceEncoding + "，已统一成 UTF-8 带 BOM），并已重新生成。\n请重启服务端让新配置生效。";
            return true;
        }

        // 功能：把 CSV 读回来覆盖资产的 rows。
        // 入参：asset 配置资产；message 输出结果。
        // 返回含义：true 表示解析、校验、覆盖都成功。
        // 步骤：读全文 → 按表头列名解析 → 临时列表 → 校验 → 通过才覆盖并保存。
        // 上游/下游：窗口导入按钮调用；内部用 SplitLine、Validate。
        public static bool Import(DungeonConfig asset, out string message)
        {
            if (asset == null)
            {
                message = "没有加载到 DungeonConfig 资产";
                return false;
            }

            string path = ResolveCsvPath();

            if (path == null)
            {
                message = "找不到 " + CsvRelativePath;
                return false;
            }

            string csvText = ReadCsvText(path, out string sourceEncoding);
            string[] lines = Normalize(csvText).Split('\n');
            List<Config_Dungeon> parsed = new List<Config_Dungeon>();
            string[] header = SplitLine(lines[0]);

            try
            {
                for (int i = HeaderLineCount; i < lines.Length; i++)
                {
                    if (string.IsNullOrWhiteSpace(lines[i]))
                    {
                        continue;
                    }

                    string[] cells = SplitLine(lines[i]);
                    parsed.Add(new Config_Dungeon
                    {
                        id = ParseInt(Cell(header, cells, "id")),
                        name = Cell(header, cells, "name"),
                        maxPlayers = ParseInt(Cell(header, cells, "maxPlayers")),
                        spawnRadiusMm = ParseInt(Cell(header, cells, "spawnRadiusMm")),
                        monsters = ParseIntArray(Cell(header, cells, "monsters")),
                        bossId = ParseInt(Cell(header, cells, "bossId")),
                    });
                }
            }
            catch (Exception exception)
            {
                message = "CSV 解析失败（第 " + (parsed.Count + HeaderLineCount + 1) + " 行附近）：" + exception.Message;
                return false;
            }

            List<Config_Dungeon> backupRows = new List<Config_Dungeon>(asset.rows);
            asset.rows.Clear();
            asset.rows.AddRange(parsed);

            List<string> errors = new List<string>();

            if (!Validate(asset, errors))
            {
                asset.rows.Clear();
                asset.rows.AddRange(backupRows);
                message = "CSV 校验没通过，资产没有改动：\n" + string.Join("\n", errors);
                return false;
            }

            asset.RebuildIndex();
            EditorUtility.SetDirty(asset);
            AssetDatabase.SaveAssets();
            message = "已从 " + CsvRelativePath + " 导入 " + parsed.Count + " 行（文件编码 " + sourceEncoding + "），资产已保存。";
            return true;
        }

        // 功能：调用 ConfigKit.Cli 重新生成 C#、TSV、JSON。
        // 入参：message 输出工具输出或错误原因。
        // 返回含义：true 表示退出码为 0。
        // 步骤：由 CSV 路径上溯仓库根 → 拼 exe 路径 → 起进程 → 最多等 120 秒 → 看退出码。
        // 上游/下游：Export 调用。
        public static bool RunConfigKit(out string message)
        {
            string csvPath = ResolveCsvPath();

            if (csvPath == null)
            {
                message = "找不到 " + CsvRelativePath;
                return false;
            }

            string root = Path.GetDirectoryName(Path.GetDirectoryName(Path.GetDirectoryName(csvPath)));
            string tool = Path.Combine(root, ConfigToolRelativePath.Replace('/', Path.DirectorySeparatorChar));

            if (!File.Exists(tool))
            {
                message = "找不到 ConfigKit 可执行文件，请先编译 Tools/ConfigKit：" + tool;
                return false;
            }

            ProcessStartInfo info = new ProcessStartInfo(tool)
            {
                WorkingDirectory = root,
                UseShellExecute = false,
                RedirectStandardOutput = true,
                RedirectStandardError = true,
                CreateNoWindow = true,
            };

            info.ArgumentList.Add("--source");
            info.ArgumentList.Add(SourceRelativePath);
            info.ArgumentList.Add("--out");
            info.ArgumentList.Add(GeneratedRelativePath);

            using (Process process = Process.Start(info))
            {
                string output = process.StandardOutput.ReadToEnd();
                string error = process.StandardError.ReadToEnd();

                if (!process.WaitForExit(120000))
                {
                    TryKill(process);
                    message = "ConfigKit 超过 120 秒没有结束";
                    return false;
                }

                if (process.ExitCode != 0)
                {
                    message = "ConfigKit 退出码 " + process.ExitCode + "\n" + output + error;
                    return false;
                }

                Debug.Log("[DungeonCsvBridge] ConfigKit 输出：\n" + output);
                message = "ConfigKit 已重新生成";
                return true;
            }
        }

        // 功能：按 CSV 规则切一行。
        // 入参：line 一行原始文本。
        // 返回含义：单元格数组。
        // 步骤：逐字符扫描，引号内两个引号落一个字面引号，逗号收格。
        // 上游/下游：Import 与测试调用。
        public static string[] SplitLine(string line)
        {
            List<string> cells = new List<string>();
            StringBuilder current = new StringBuilder();
            bool inQuotes = false;

            for (int i = 0; i < line.Length; i++)
            {
                char ch = line[i];

                if (inQuotes)
                {
                    if (ch != '"')
                    {
                        current.Append(ch);
                    }
                    else if (i + 1 < line.Length && line[i + 1] == '"')
                    {
                        current.Append('"');
                        i++;
                    }
                    else
                    {
                        inQuotes = false;
                    }

                    continue;
                }

                if (ch == '"')
                {
                    inQuotes = true;
                }
                else if (ch == ',')
                {
                    cells.Add(current.ToString());
                    current.Length = 0;
                }
                else
                {
                    current.Append(ch);
                }
            }

            if (inQuotes)
            {
                throw new FormatException("引号没有闭合");
            }

            cells.Add(current.ToString());
            return cells.ToArray();
        }

        // 功能：读磁盘 CSV 的前 4 行表头，拼成列说明。
        // 入参：error 输出错误原因。
        // 返回含义：列说明列表，读不到返回空列表。
        // 步骤：读文件 → 逐行切分 → 按列下标把字段名/中文名/类型/规则配起来。
        // 上游/下游：DungeonConfigWindow 画表头时调用；内部用 SplitLine。
        public static List<CsvColumn> ReadColumns(out string error)
        {
            error = string.Empty;
            List<CsvColumn> columns = new List<CsvColumn>();
            string path = ResolveCsvPath();

            if (path == null)
            {
                error = "找不到 " + CsvRelativePath;
                return columns;
            }

            string[] lines = Normalize(ReadCsvText(path, out _)).Split('\n');

            if (lines.Length < HeaderLineCount)
            {
                error = CsvRelativePath + " 的表头不足 " + HeaderLineCount + " 行";
                return columns;
            }

            string[] names = SplitLine(lines[0]);
            string[] labels = SplitLine(lines[1]);
            string[] types = SplitLine(lines[2]);
            string[] rules = SplitLine(lines[3]);

            for (int i = 0; i < names.Length; i++)
            {
                columns.Add(new CsvColumn
                {
                    Name = names[i],
                    Label = At(labels, i),
                    Type = At(types, i),
                    Rule = At(rules, i),
                });
            }

            return columns;
        }

        // 功能：取一行表头的第 index 格，防止缺列时越界。
        // 入参：cells 是切分后的表头行；index 是列下标。
        // 返回含义：该格文本，取不到给空串。
        // 步骤：比较下标与长度后返回。
        // 上游/下游：ReadColumns 调用。
        private static string At(string[] cells, int index)
        {
            return index < cells.Length ? cells[index] : string.Empty;
        }

        // 功能：把怪物数组写成单元格，多只时加引号。
        // 入参：monsters 怪物编号数组。
        // 返回含义：可直接拼进一行的文本。
        // 步骤：空给空串、单只给数字、多只拼 a,b,c 再加引号。
        // 上游/下游：BuildCsvText 调用。
        private static string FormatMonsters(int[] monsters)
        {
            if (monsters == null || monsters.Length == 0)
            {
                return string.Empty;
            }

            if (monsters.Length == 1)
            {
                return monsters[0].ToString(CultureInfo.InvariantCulture);
            }

            StringBuilder builder = new StringBuilder("\"");

            for (int i = 0; i < monsters.Length; i++)
            {
                if (i > 0)
                {
                    builder.Append(',');
                }

                builder.Append(monsters[i].ToString(CultureInfo.InvariantCulture));
            }

            return builder.Append('"').ToString();
        }

        // 功能：按需加引号后写入一个单元格。
        // 入参：builder 目标；value 内容；quoteWhenNeeded 为 true 时含特殊字符才加引号。
        // 返回含义：无。
        // 步骤：需要时把内部引号翻倍并包住。
        // 上游/下游：BuildCsvText 调用。
        private static void AppendField(StringBuilder builder, string value, bool quoteWhenNeeded)
        {
            bool needQuote = quoteWhenNeeded && value.IndexOfAny(new[] { ',', '"', '\n' }) >= 0;

            if (!needQuote)
            {
                builder.Append(value);
                return;
            }

            builder.Append('"').Append(value.Replace("\"", "\"\"")).Append('"');
        }

        // 功能：取整份文本前 4 行表头。
        // 入参：text 整份 CSV。
        // 返回含义：4 行表头，不含结尾换行。
        // 步骤：切行后取前 4 行，不足就原样返回。
        // 上游/下游：Export 与 IsDirty 调用。
        private static string TakeHeaderBlock(string text)
        {
            string[] lines = text.Replace("\r\n", "\n").Split('\n');
            return lines.Length <= HeaderLineCount ? text.TrimEnd('\n') : string.Join("\n", lines, 0, HeaderLineCount);
        }

        // 功能：把换行统一成 \n。
        // 入参：text 原始文本。
        // 返回含义：只含 \n 的文本。
        // 步骤：先换 \r\n 再换单个 \r。
        // 上游/下游：IsDirty、Export、Import 调用。
        private static string Normalize(string text)
        {
            return text.Replace("\r\n", "\n").Replace('\r', '\n');
        }

        // 功能：数数据行数，仅用于提示。
        // 入参：text 整份 CSV。
        // 返回含义：非空数据行数。
        // 步骤：从第 5 行数到末尾。
        // 上游/下游：IsDirty 调用。
        private static int CountDataLines(string text)
        {
            string[] lines = text.Split('\n');
            int count = 0;

            for (int i = HeaderLineCount; i < lines.Length; i++)
            {
                if (!string.IsNullOrWhiteSpace(lines[i]))
                {
                    count++;
                }
            }

            return count;
        }

        // 功能：读 MonsterConfig 收集合法怪物编号。
        // 入参：无。
        // 返回含义：编号集合，资产缺失返回 null。
        // 步骤：按导入器资产目录拼路径加载后遍历。
        // 上游/下游：Validate 调用。
        private static HashSet<int> LoadMonsterIds()
        {
            MonsterConfig config = AssetDatabase.LoadAssetAtPath<MonsterConfig>(ConfigImporter.AssetDirectory + "/MonsterConfig.asset");

            if (config == null)
            {
                return null;
            }

            HashSet<int> ids = new HashSet<int>();

            for (int i = 0; i < config.rows.Count; i++)
            {
                ids.Add(config.rows[i].id);
            }

            return ids;
        }

        // 功能：按列名取单元格。
        // 入参：header 字段名行；cells 数据行；name 字段名。
        // 返回含义：单元格文本，缺列给空串。
        // 步骤：在 header 里找同名下标。
        // 上游/下游：Import 调用。
        private static string Cell(string[] header, string[] cells, string name)
        {
            for (int i = 0; i < header.Length; i++)
            {
                if (string.Equals(header[i], name, StringComparison.Ordinal))
                {
                    return i < cells.Length ? cells[i] : string.Empty;
                }
            }

            return string.Empty;
        }

        // 功能：解析整数，失败给 0。
        // 入参：text 文本。
        // 返回含义：解析结果。
        // 步骤：用固定区域格式解析。
        // 上游/下游：Import 调用。
        private static int ParseInt(string text)
        {
            return int.TryParse(text, NumberStyles.Integer, CultureInfo.InvariantCulture, out int value) ? value : 0;
        }

        // 功能：解析逗号分隔整数数组。
        // 入参：text 文本。
        // 返回含义：数组，空文本给空数组。
        // 步骤：切逗号逐个解析。
        // 上游/下游：Import 调用。
        private static int[] ParseIntArray(string text)
        {
            if (string.IsNullOrWhiteSpace(text))
            {
                return Array.Empty<int>();
            }

            string[] parts = text.Split(',');
            int[] result = new int[parts.Length];

            for (int i = 0; i < parts.Length; i++)
            {
                result[i] = ParseInt(parts[i].Trim());
            }

            return result;
        }

        // 功能：尽力杀掉超时进程。
        // 入参：process 进程。
        // 返回含义：无。
        // 步骤：调用 Kill，异常吞掉。
        // 上游/下游：RunConfigKit 调用。
        private static void TryKill(Process process)
        {
            try
            {
                process.Kill();
            }
            catch (Exception)
            {
                // 进程已退出时杀不掉，不算失败原因
            }
        }
    }
}
```

```csharp
        // 怪物列的输入缓冲：按键过程中不能每帧从 row.monsters 重新拿文本，否则输入会被吞

        // 功能：菜单入口，打开或聚焦本窗口。
        // 入参：无。
        // 返回含义：无。

        }

        // 功能：画整个窗口。
        // 入参：无。
        // 返回含义：无。
        // 步骤：说明行 → 工具栏 → 列说明 → 表头 → 数据行 → 状态。

        // 功能：发现资产被重新导入或被别的窗口替换时，自动重新加载，避免对着旧对象编辑。
        // 入参：无。

        // 上游/下游：上游是 OnGUI；下游是 Reload。
        private void CheckAssetReplaced()
        {
            if (EditorApplication.timeSinceStartup - m_assetCheckTime < AssetCheckInterval)
            {
                return;
            }

            m_assetCheckTime = EditorApplication.timeSinceStartup;

            if (m_asset == null)
            {
                return;
            }

            DungeonConfig current = AssetDatabase.LoadAssetAtPath<DungeonConfig>(ConfigImporter.AssetDirectory + AssetFileName);

            if (current != null && !ReferenceEquals(current, m_asset))
            {

                m_statusIsError = false;
                Reload();
            }
        }

        // 功能：同时重新加载资产与列说明。
        // 入参：无。
        // 返回含义：无。
        // 步骤：先加载资产，再读表头，失败时把原因留着显示。
        // 上游/下游：上游是 OnEnable 与刷新按钮；下游是 AssetDatabase、DungeonCsvBridge.ReadColumns。
        private void Reload()
        {
            m_asset = AssetDatabase.LoadAssetAtPath<DungeonConfig>(ConfigImporter.AssetDirectory + AssetFileName);

            if (m_asset == null)
            {
                m_status = "读不到 " + ConfigImporter.AssetDirectory + AssetFileName + "，请先跑一次「导入 TSV → ScriptableObject」";
                m_statusIsError = true;
            }

            m_columns.Clear();
            m_columns.AddRange(DungeonCsvBridge.ReadColumns(out m_columnsError));
            m_monsterDrafts.Clear();
        }

        // 功能：画工具栏，含刷新、校验、导出、导入与脏提示。
        // 入参：无。
        // 返回含义：无。
        // 步骤：画按钮行 → 显示行数 → 显示脏提示。

        private void DrawToolbar()
        {
            EditorGUILayout.BeginHorizontal();

            if (GUILayout.Button("刷新", GUILayout.Width(60)))
            {
                Reload();
                m_status = "已重新读取资产与表头";
                m_statusIsError = false;
            }

            if (GUILayout.Button("校验", GUILayout.Width(60)))
            {

            }

            using (new EditorGUI.DisabledScope(m_asset == null))
            {
                if (GUILayout.Button("导出到 CSV", GUILayout.Width(110)))
                {

                    m_status = message;
                    m_statusIsError = !ok;

                if (GUILayout.Button("从 CSV 导入", GUILayout.Width(110)))
                {
                    ImportWithConfirm();
                }

            GUILayout.FlexibleSpace();
            GUILayout.Label(m_asset == null ? "未加载资产" : "行数：" + m_asset.rows.Count);

            {

            }

            if (!string.IsNullOrEmpty(m_columnsError))
            {
                EditorGUILayout.HelpBox(m_columnsError, MessageType.Error);
            }
        }

        // 功能：折叠显示每一列的中文名、字段名、类型与规则。
        // 入参：无。
        // 返回含义：无。
        // 步骤：用 Foldout 控制展开，展开后逐列画一行说明。
        // 上游/下游：上游是 OnGUI；下游是 m_columns。
        private void DrawColumnHelp()
        {
            m_showColumnHelp = EditorGUILayout.Foldout(m_showColumnHelp, "列说明（来自 CSV 表头）", true);

            if (!m_showColumnHelp)
            {
                return;
            }

            for (int i = 0; i < m_columns.Count; i++)
            {
                CsvColumn column = m_columns[i];

                EditorGUILayout.LabelField(column.Label + "（" + column.Name + "）", column.Type + " · " + rule);
            }
        }

        // 功能：画表头与所有数据行。
        // 入参：无。
        // 返回含义：无。
        // 步骤：无资产直接返回；先画表头行，再在滚动区画数据行，删除延后执行。
        // 上游/下游：上游是 OnGUI；下游是 DrawHeader、DrawRow。
        private void DrawTable()
        {
            if (m_asset == null)
            {
                return;
            }

            DrawHeader();
            m_scroll = EditorGUILayout.BeginScrollView(m_scroll);
            int removeIndex = -1;

            for (int i = 0; i < m_asset.rows.Count; i++)
            {
                if (DrawRow(m_asset.rows[i], i))
                {
                    removeIndex = i;
                }
            }

            EditorGUILayout.EndScrollView();

            if (removeIndex >= 0)
            {
                Undo.RecordObject(m_asset, "删除副本行");
                m_monsterDrafts.Remove(m_asset.rows[removeIndex]);
                m_asset.rows.RemoveAt(removeIndex);
                EditorUtility.SetDirty(m_asset);
            }

            if (GUILayout.Button("增加一行"))
            {
                Undo.RecordObject(m_asset, "增加副本行");
                m_asset.rows.Add(NewRow());
                EditorUtility.SetDirty(m_asset);
            }
        }

        // 功能：画表头一行，中文名来自 CSV 第二行，鼠标悬停显示字段名与规则。
        // 入参：无。
        // 返回含义：无。
        // 步骤：按固定列宽依次画 Label，样式用 boldLabel。
        // 上游/下游：上游是 DrawTable；下游是 LabelFor。
        private void DrawHeader()
        {
            EditorGUILayout.BeginHorizontal(EditorStyles.toolbar);

            LabelFor("id", IdWidth);
            LabelFor("name", NameWidth);
            LabelFor("maxPlayers", PlayersWidth);
            LabelFor("spawnRadiusMm", RadiusWidth);
            LabelFor("monsters", MonstersWidth);
            LabelFor("bossId", BossWidth);
            GUILayout.Label(string.Empty, GUILayout.Width(RemoveWidth));

            EditorGUILayout.EndHorizontal();
        }

        // 功能：按字段名找中文名并画成表头。
        // 入参：fieldName 是 CSV 字段名；width 是列宽。
        // 返回含义：无。
        // 步骤：在 m_columns 里找同名字段，找不到就用字段名本身；tooltip 带类型与规则。
        // 上游/下游：上游是 DrawHeader；下游是 GUILayout.Label。
        private void LabelFor(string fieldName, float width)
        {
            string label = fieldName;
            string tooltip = string.Empty;

            for (int i = 0; i < m_columns.Count; i++)
            {
                if (!string.Equals(m_columns[i].Name, fieldName, System.StringComparison.Ordinal))
                {
                    continue;
                }

                CsvColumn column = m_columns[i];
                label = string.IsNullOrWhiteSpace(column.Label) ? fieldName : column.Label;
                tooltip = column.Name + " · " + column.Type + " · " + (string.IsNullOrWhiteSpace(column.Rule) ? "无规则" : column.Rule);
                break;
            }

            GUILayout.Label(new GUIContent(label, tooltip), EditorStyles.boldLabel, GUILayout.Width(width));
        }

        // 功能：画一行数据，返回是否点了删除。
        // 入参：row 是数据行；index 是行号。
        // 返回含义：true 表示要删除这一行。
        // 步骤：单行横向排列六个字段和删除按钮；怪物用文本框加「应用」。
        // 上游/下游：上游是 DrawTable；下游是 ParseMonsters。
        private bool DrawRow(Config_Dungeon row, int index)
        {
            bool remove = false;

            EditorGUILayout.BeginHorizontal();

            if (!m_monsterDrafts.TryGetValue(row, out string draft))
            {
                draft = string.Join(",", row.monsters);
            }

            EditorGUI.BeginChangeCheck();
            int id = EditorGUILayout.IntField(row.id, GUILayout.Width(IdWidth));
            string name = EditorGUILayout.TextField(row.name, GUILayout.Width(NameWidth));
            int maxPlayers = EditorGUILayout.IntField(row.maxPlayers, GUILayout.Width(PlayersWidth));
            int spawnRadiusMm = EditorGUILayout.IntField(row.spawnRadiusMm, GUILayout.Width(RadiusWidth));
            string monstersText = EditorGUILayout.TextField(draft, GUILayout.Width(MonstersWidth - 50f));
            bool applyMonsters = GUILayout.Button("应用", GUILayout.Width(46f));
            int bossId = EditorGUILayout.IntField(row.bossId, GUILayout.Width(BossWidth));
            bool fieldsChanged = EditorGUI.EndChangeCheck();

            if (fieldsChanged || applyMonsters)
            {
                Undo.RecordObject(m_asset, "修改副本行");
                row.id = id;
                row.name = name;
                row.maxPlayers = maxPlayers;
                row.spawnRadiusMm = spawnRadiusMm;
                row.bossId = bossId;

                if (applyMonsters)
                {
                    row.monsters = ParseMonsters(monstersText);
                    m_monsterDrafts[row] = string.Join(",", row.monsters);
                }
                else
                {
                    m_monsterDrafts[row] = monstersText;
                    row.monsters = ParseMonsters(monstersText);
                }

                EditorUtility.SetDirty(m_asset);
            }

            if (GUILayout.Button("删除", GUILayout.Width(RemoveWidth)))
            {
                remove = true;
            }

            EditorGUILayout.EndHorizontal();
            return remove;
        }

        // 功能：画底部状态与错误清单。
        // 入参：无。
        // 返回含义：无。
        // 步骤：有状态按成功/失败选类型；错误逐条列。
        // 上游/下游：上游是 OnGUI；下游是 EditorGUILayout。
        private void DrawStatus()
        {
            if (!string.IsNullOrEmpty(m_status))
            {
                EditorGUILayout.HelpBox(m_status, m_statusIsError ? MessageType.Error : MessageType.Info);
            }

            for (int i = 0; i < m_errors.Count; i++)
            {
                EditorGUILayout.HelpBox(m_errors[i], MessageType.Warning);
            }
        }

        // 功能：跑一次校验并刷新错误列表。
        // 入参：无。
        // 返回含义：无。
        // 步骤：清空 → 调桥 → 写状态。
        // 上游/下游：上游是工具栏与导出；下游是 DungeonCsvBridge.Validate。
        private void RunValidate()
        {
            m_errors.Clear();

            if (m_asset == null)
            {
                return;
            }

            if (DungeonCsvBridge.Validate(m_asset, m_errors))
            {
                m_status = "校验通过";
                m_statusIsError = false;
            }
            else
            {
                m_status = "校验没通过，共 " + m_errors.Count + " 个问题";
                m_statusIsError = true;
            }
        }

        // 功能：导入前弹确认框，避免误覆盖。
        // 入参：无。
        // 返回含义：无。
        // 步骤：确认后调桥导入，再校验一次。
        // 上游/下游：上游是导入按钮；下游是 DungeonCsvBridge.Import。
        private void ImportWithConfirm()
        {
            bool confirmed = EditorUtility.DisplayDialog(
                "从 CSV 导入",
                "会用 " + DungeonCsvBridge.CsvRelativePath + " 覆盖当前资产的 " + m_asset.rows.Count + " 行，继续吗？",
                "覆盖",
                "取消");

            if (!confirmed)
            {
                m_status = "已取消导入";
                m_statusIsError = false;
                return;
            }

            bool ok = DungeonCsvBridge.Import(m_asset, out string message);
            m_status = message;
            m_statusIsError = !ok;
            RunValidate();
        }

        // 功能：新建一行默认数据，主键取现有最大值加一。
        // 入参：无。
        // 返回含义：新行。
        // 步骤：扫最大主键，填默认值。
        // 上游/下游：上游是「增加一行」；下游是无。
        private Config_Dungeon NewRow()
        {
            int nextId = 1001;

            for (int i = 0; i < m_asset.rows.Count; i++)
            {
                if (m_asset.rows[i].id >= nextId)
                {
                    nextId = m_asset.rows[i].id + 1;
                }
            }

            return new Config_Dungeon
            {
                id = nextId,
                name = "新副本",
                maxPlayers = 4,
                spawnRadiusMm = 3000,
                monsters = new int[0],
                bossId = 0,
            };
        }

        // 功能：把逗号分隔文本解析成怪物编号数组。
        // 入参：text 用户输入。
        // 返回含义：整数数组。
        // 步骤：切逗号逐个 TryParse，失败当 0 交给校验报。
        // 上游/下游：上游是 DrawRow；下游是无。
        private static int[] ParseMonsters(string text)
        {
            if (string.IsNullOrWhiteSpace(text))
            {
                return new int[0];
            }

            string[] parts = text.Split(',');
            int[] result = new int[parts.Length];

            for (int i = 0; i < parts.Length; i++)
            {
                result[i] = int.TryParse(parts[i].Trim(), out int value) ? value : 0;
            }

            return result;
        }
    }
}
```

## 十一、返修（2026-11-16）：Excel 打开时抛共享冲突

### 11.1 现象

点「从 CSV 导入」时 Console 报 `IOException: Sharing violation on path ...\Configs\Design\Dungeon.csv`，栈落在 `File.ReadAllBytes` ← `DungeonCsvBridge.ReadCsvText` ← `IsDirty` ← `DungeonConfigWindow.DrawToolbar`，外层是 `Rethrow as ImmediateModeException`；整个窗口画不出来。

### 11.2 根因

`File.ReadAllBytes` 打开文件时默认只声明 `FileShare.Read`：允许别人读，但不允许别人同时写。Excel 在存盘/自动保存期间持有独占写句柄，于是我们这边连「打开」都被拒。更糟的是这段代码跑在 OnGUI 里，而且 `IsDirty` 每帧都调，异常一抛整块 IMGUI 立即中断。

### 11.3 修法

1. `ReadAllBytesShared` 用 `FileShare.ReadWrite | FileShare.Delete` 打开，允许「别人正在写我也能读」；遇到 `IOException` 先等 80 毫秒再试，最多 5 次。
2. `IsDirty`、`ReadColumns` 捕获 `IOException` / `UnauthorizedAccessException`，转成面板上的红字提示（`读不到 CSV（可能正被 Excel 占用）：...`），不再向上抛。
3. `Import`、`Export` 各自捕获读/写两段，提示「请先关闭 Excel 再导入/导出」——读可以共享，写不能。

### 11.4 判据

Excel 开着文件时：窗口不报错、`IsDirty` 能算出结果、导入能读；点导出会给出人话提示而不是异常栈。`DungeonCsvBridgeTests.ReadCsvText_ReadsWhileAnotherProcessHoldsTheFile` 覆盖「别人占着也能读」。

### 11.5 顺带的数字

三个文件实测 887 + 505 + 253 = 1645 行（超 500 行预算 229%，2026-11-16 已特批）；EditMode 全量 781 通过 / 0 失败 / 10.72 秒。
